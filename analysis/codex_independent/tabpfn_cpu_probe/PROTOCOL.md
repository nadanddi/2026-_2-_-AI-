# TabPFN v2 혼합 CPU 재현성 선별 — 실행 전 계획

기존 연구가 사전 기준을 통과했다고 기록한 EC TabPFN v2를 CPU 환경에서
실제로 재생성할 수 있는지 확인한다. 이는 새 설정 탐색이 아니라 기존
후보의 재현 가능성 검사다. 확인용 DIAG10 폴드 8·9는 잠근 상태로 둔다.

고정 파일/환경: 현재 작업 사본의 rl_ec_v1/v2 인과 특징 및 정확한 입력
해시 캐시, 원본 공개 train_X·train_y. `.analysis-tools/extra`의 CPU
PyTorch/TabPFN 버전을 기록한다. 외부 서비스·다운로드를 막는 offline 환경
변수를 켜고 로컬 사전학습 가중치만 사용한다. 예측 과정의 외부 조회 없음.

고정 실행: 탐색 폴드 0, 기준 시드 7, TabPFN 문맥 시드 1, 문맥 표본
2,000행(훈련 행에서 무가중 비복원 추출), TabPFN v2 모델,
`n_estimators=4`, CPU float32. 기준 3회차 구성 80% + TabPFN 20%,
기존 인과적 당일 누적 수축 0.5, 훈련 EC 범위로 제한한다.
폴드 0은 v1~v4에서 이미 탐색에 사용한 자료이므로 새 독립 확인이 아니다.

판단 기준은 성능 채택이 아니라 (1) 로컬 로딩·적합·예측 성공,
(2) 반복 예측 결정성, (3) 기존 GPU 기록과 비교 가능한 대략적 수치,
(4) 실제 CPU 소요 시간 측정이다. 성공하면 여러 문맥과 나머지 탐색 폴드로
확장 계획을 별도 고정한다. 실패하면 원인과 재현 가능한 오류를 남긴다.
비공개 정답·test_X는 읽지 않으며 기존 파일·제출물은 수정하지 않는다.
