# H5: TabPFN 네 문맥의 평균 대신 중앙값

2026-09-29 실행 전 등록. 기준 EC v2는 TabPFN 문맥
시드 1·2·3·4 예측을 단순 평균하고 20% 섞는다.
D5에서 3회차-TabPFN 불일치 행 646개가 오차제곱의
47.9%를 차지했고, 이 행의 네 문맥 예측 표준편차
평균은 0.126이었다. H4의 불일치 게이트는 평균적으로
좋았지만 한 폴드에서 악화해 기각됐다. 따라서 같은
게이트의 문턱·비중을 조정하지 않고, **문맥 하나의
극단 예측에 덜 민감한 집계**를 별도 가설로 시험한다.

## 단일 후보

각 현재행의 네 문맥 예측을 `t1..t4`라 하고,
`m = mean(t1..t4)`, `q = median(t1..t4)`라 한다.
기존 v2 출력 `p`를 고치되, `d=q−m`을 기존 인과적
당일 수축(현재행과 0시~현재행 평균을 반반)한 값의
20%만 더한다:

`p_H5 = p + 0.2 × [0.5d + 0.5 mean(d_0..d_h)]`

이는 원래 혼합에서 TabPFN 평균을 중앙값으로 바꾼
효과를 출력 수준에서 구현한다. 원래 마지막 범위 제한
바깥에서의 수치는 미세하게 다를 수 있으므로 별도
제한을 추가하지 않는다. 네 문맥의 중앙값은 짝수
표본 정의에 따라 가운데 두 값의 평균이다.
농장·날·기온·불일치·고EC 여부에 따른 추가 게이트나
튜닝은 없다. 모든 행에 동일한 식을 적용한다.

## 선별·검증

저장된 공개 OOF 여섯 폴드(0·2·4·6·8·9)에서
동일 행의 v2와 비교한다. 여섯 폴드와 양 농장 모두
RMSE 엄격 개선, 하루 단위 재표집 20,000회
(시드 2907)의 MSE 차이 95% 상한<0을 요구한다.
실패하면 H5 기각, 다른 순서통계량·문맥 시드·비중으로
같은 아이디어를 다시 맞추지 않는다.

통과하면 A/B/DIAG10 각 ≥2시드 모두 v2보다 개선,
DIAG10 각 `p_worse<0.005`(H1~H5 다중성 보정),
EXT10·EXT12 각 시드 무악화를 시험한다. 통과한
경우 미사용 시드와 최종 잠금 40일 단 한 번 확인하고
미래 입력 교란·온실 격리·결정성 검사까지 한다.
후속 실행 계획은 먼저 커밋한다.

문맥 예측과 수축은 현재·이전 입력만 쓴다. 저장 OOF
모델의 학습에 최종 잠금일 라벨이 간접 포함되었으므로
이 선별은 완전 독립 시험이 아니다. 최종 확인 모델은
잠금일±1일을 학습에서 제외해 새로 만든다.
`test_X` 통계·비공개 정답·리더보드 점수를 사용하지
않고 온도·제출 파일을 만들지 않는다.
