# H11 / F1-1: 고정 격일 출처 사슬의 입력 누적

2026-09-29 실행 전 등록. 카탈로그 1.14에서 같은 출처의 직전 달력날은 흔히 기록상 d−2이고, 6.16에서 장기 밀폐 사슬의 EC 잔차가 +0.21이었다. 하루 안 특징만 쓰는 기존 v2에 사슬의 **이전 입력**으로 계산한 누적 상태를 추가한다. 고정 d−2는 연결 정확도가 낮을 수 있으므로 F1의 단순 구현으로 먼저 시험한다. 실패하면 H12에서 입력 연속성 연결로 바꾸되 H11의 문턱·시드·결합률을 재조정하지 않는다.

## 사전 고정된 특징과 후보

F13·F47 각각 `train_X`만으로 특징을 만든다. 현재 행의 과거 입력은 같은 기록의 d−2와 d−4일 전체 24시간 입력이다. 각 이전 날에서 일사 양수 누적, 실내 온습도 기반 VPD 양수 누적, 환기·순환팬·난방·커튼·포그의 일평균, 밀폐 대리(환기 0 비율≥0.85 및 순환팬 평균<10)를 계산한다. 각 lag의 값과 두 lag의 일사·VPD 합, 밀폐 연속일 수(0/1/2)를 특징으로 쓴다. 빠진 과거 날은 NaN이며 미래 날로 채우지 않는다. 학습 특징을 만들 때 `test_X`는 읽지 않아 MASK 조건을 만족한다. 평가 특징 생성은 별도 검증에서 같은 기록의 과거 입력만 사용한다. 정답 EC, 다른 온실, 비공개 정답, 공식 점수는 특징에 사용하지 않는다.

ExtraTreesRegressor(`n_estimators=400`, `max_features=1.0`, `min_samples_leaf=2`, `n_jobs=4`, `random_state=seed`)를 기존 인과 `FULL`과 이 사슬 특징 전체로 학습한다. 결측은 학습일 중앙값으로 대체한다. 시드 7·101 두 개를 독립 학습한다. 학습은 기존 H8처럼 검증일과 최종 잠금 40일 ±1일을 제외한다. 단독 모델 출력은 같은 날 현재까지의 누적 평균과 0.5:0.5 수축 후 학습 EC 범위로 제한한다. **H11 후보는 0.8·v2 + 0.2·사슬 모델**로 고정한다. 이는 사슬 입력으로 훈련한 별도 예측 모델을 결합하는 것이며 v2 출력의 잔차 확대나 사후 보정 규칙은 아니다. 비교에는 저장된 v2 OOF를 그대로 쓴다.

## 검증과 판정

먼저 이전 캠페인의 저장 OOF 폴드 0·2·4·6·8·9를 선별에 쓴다. 각 시드×폴드 전체 RMSE가 v2보다 엄격히 낮고 두 농장별도 개선하며, 날 단위 20,000회 재표집 MSE 차이에서 `p_worse<0.025/12`여야 다음 단계로 간다. H11~H22 최대 12개를 동시에 고려하는 보수적 보정이다. 실제 고EC(일평균≥1.2) 19일과 나머지 날의 오차, 날짜·농장별 변화, 사슬 특징 결측률을 함께 보고한다. 연결 정확도는 `research/local/deep_cal_10_links.csv`의 과거 분석용 연결을 **진단 정답**으로만 사용해 d−2 적중률·커버리지와 농장·전후반 차이를 보고한다. 그 연결 파일은 EC·배지온도 라벨로 확인된 자료이므로 모델의 학습/특징/선별에는 절대 주입하지 않는다. 이 정확도는 독립적인 참 출처 ID가 없어 대리 기준에 대한 적중률이라고 명시한다.

선별 통과 시 A·B·DIAG10 × 두 시드 전칸 개선, DIAG10 `p_worse<0.025/12`, EXT10·EXT12 무악화를 같은 고정 모델로 검사한다. 이 다음 단계의 실행 코드는 수행 전에 따로 커밋한다. 통과 시 미사용 시드와 잠금 40일을 딱 한 번 확인하고 미래 입력 교란·온실 격리·결정성 검사까지 수행한다. 선별 탈락이면 H11 기각; 다른 계열 구현은 새 번호로 기록한다. 잠금 40일의 점수는 채택 전 열지 않는다.

온도 예측과 기존/제출 파일은 건드리지 않고 제출 파일도 만들지 않는다.
