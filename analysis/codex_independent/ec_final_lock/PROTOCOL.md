# 새 EC 캠페인의 최종 확인 날짜 잠금

2026-09-29. 기존 EC v2 OOF 234일(탐색 0·2·4·6,
확인 8·9)에 들어 있지 않은 공개 학습 166일 중 40일을
이번 캠페인 **최종 1회 확인**용으로 고정한다. `train_y`,
`test_X`, 예측값, 체제 통계는 선택에 쓰지 않는다.

F13·F47 각각 전반(day<179) 15일, 후반(day≥179) 5일을
뽑는다. 각 농장×구간 후보를
`SHA256("ec-final-lock-20260929|farm|day")`로 정렬해
앞에서 고른다. 같은 농장의 잠금일 ±1일은 모델 학습에서
제외한다. 잠금 목록의 행 ID와 해시는 Git에 커밋한다.

이 40일은 **이번 새 가설 10개에 대해** 한 번도 점수화하지
않는 확인 집합이다. 과거 연구가 공개 자료 전체를 여러 방식으로
본 적이 있으므로 완전 독립 외부 시험이라고 부르지 않는다.
최종 후보가 채택 규칙을 통과한 뒤 한 번도 쓰지 않은 시드로
이 날짜들을 딱 한 번 점수화한다. 후보가 없으면 열지 않는다.
