# EC 제출 판단 정정 — 남은 기회와 검증 범위

작성일: 2026-09-29. 이 문서는 `EC_제출판단_2026-09-28.md`의
제출 기회 해석을 정정한다. 이전 파일은 추적 가능하도록 그대로 둔다.

최신 `HANDOFF.md`에 따르면 남은 기회는 **사용자 개인 1회**이고,
**공용 7회는 마지막용으로 보류**되어 있다. 이전 메모의 “팀 25회에서
유효 제출 5회를 빼면 20회”라는 계산은 개인별 배분과 다른 팀원의
사용량을 무시한 것이므로 현재 의사결정에 사용할 수 없다. 따라서
EC v2를 시험 제출한 뒤 07 조합으로 되돌리는 두 번의 업로드를
당연한 순서로 제안해서는 안 된다.

EC v2는 공개 확인 구간에서 기준 0.290792→0.281418(−3.22%)였지만,
평가 날짜 범위의 공개 10일에서는 개선이 약 −0.32%에 그쳤고 이득이
몇 날짜에 집중됐다. 비공개 EC 점수는 아직 없다. 조합안은 원본의
사전 검증 규칙을 통과했으나 EXT12와 별도 전이 진단에서 악화 위험이
반복돼 현재 제출 후보로 권하지 않는다. 새로 확인한 0시 출처 군집의
계절별 잔차 설명력도 순열 검증을 통과하지 못했다.

현재 실행 방침은 제출 기회를 쓰지 않고 EC의 오차 원인을 더 분석하되,
새 모델은 미리 정한 다중 검증 기준을 통과할 때만 후보로 올리는 것이다.
사용자가 제출을 지시하기 전에는 새 제출 파일이나 확정 구성을 만들지
않는다. 개인 1회를 언제 쓸지와 공용 7회 사용 여부는 팀의 결정이다.
