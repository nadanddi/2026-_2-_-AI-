# 같은 외부 날씨 날짜군의 EC 잔차 동행성 — 사전 진단

작성 2026-09-29, 결과 전. F13·F47 공개 학습 400일의 외부 온도·
일사 24시간 벡터가 0.01 정밀도에서 완전히 같은 날을 하나의
날짜군으로 둔다. 하루 전체 날씨를 쓰는 것은 **진단 전용**이며,
평가 행 특징으로 만들지 않는다. EC v2의 저장 OOF 234일·5,616행에
날짜군을 붙이고, 날짜군×전반(<179)/후반(≥179)에서 농장별
평균 일잔차를 구한다. 양 농장이 모두 있는 셀만 사용한다.

출처가 다르더라도 같은 실제 날씨·재배 시기에는 공동 미관측
EC 수준 요인이 남을 수 있다는 가설이다. 셀별 두 농장 평균
잔차의 피어슨 상관과 부호 일치율을 계산한다. 농장별 전·후반
평균 잔차는 먼저 제거한다. 영가설은 같은 구간의 F47 날짜군
잔차를 10,000번 섞고 F13과의 상관을 다시 계산한다.

진행 조건: 양 농장 공통 셀 ≥30, 전체 상관 ≥0.35,
후반 공통 셀 ≥8 및 후반 상관 >0, 순열 단측 비율 <0.01을 모두
충족해야 한다. 만족해도 날짜군을 그대로 예측 특징으로 사용하지
않는다. 같은 농장의 **현재·과거 시각 외부 날씨**만으로 역사적
학습 날짜를 식별하고, 공개 학습 라벨로 학습된 날짜 효과가 실제
홀드아웃에서 재현되는지 별도 인과·검증 계획을 세운다.

이 공개 OOF는 이전 실험에 재사용되었으므로 순열 비율은 완전
독립 확증이 아니다. 미래 평가 입력과 비공개 정답은 사용하지
않는다. 제출 파일도 만들지 않는다.
