## 현재 우선 검토

기존 연구는 TabPFN v2의 4문맥 혼합이 온도와 EC에서 재현되는 개선을
보였다고 기록했다. EC v3/v4 변형은 반증됐으므로 EC v2 혼합 설정을
바꾸는 작은 탐색보다 **CPU에서 실제 재생성 가능성과 끝단 검증**이 더
중요하다. 원본 연구의 web_tabpfn_v2.py 및 v2_gpu.py는 읽기 전용으로
확인했다. GPU 결과만으로 최종 패키지를 만들지 않는다. CPU 1개 폴드와
1개 문맥에서 동일 특징·시드의 재현성·시간·자원 비용을 먼저 측정하고,
가능하면 새 파일로 CPU 재생성 파이프라인을 작성한다. 기존 GPU 결과와
비트 일치를 기대하지 않고 성능/인과성 검증을 별도로 한다.
