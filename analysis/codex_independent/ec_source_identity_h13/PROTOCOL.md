# H13 / F2-1: 운영 패턴의 다일 출처 정체 표현

2026-09-29 실행 전 등록. F1의 H12는 입력만으로 이전 출처 날을 대리 기준 135/170일(79.4%) 맞혔으나 일사·VPD·밀폐의 원시 사슬 특징을 넣은 ET는 단독 성능이 악화했다. 카탈로그 1.5·1.6에 따르면 난방 설정점·구동기 일정은 출처별로 다르다. H13은 물리량의 누적 대신 **동일 출처의 운영 지문**을 간결하게 표현하여 출처별 관리 수준을 모델이 구별할 수 있는지 시험한다. 같은 날 0시 지문만 쓴 과거 `ec_source_season_probe`는 v2 잔차 신호가 유의하지 않았으므로, H13의 새 입력은 이전 출처 날들의 야간 패턴이다.

F13/F47 각각 `train_X`만으로 H12의 입력 인과 링크를 재생성한다. 현재 행의 0시 구동기 7열과 연결된 이전 출처 날 최대 세 개의 야간(0~6시) 난방·보온커튼·순환팬·CO₂공급·환기·차광·포그 평균을 읽는다. 이전 날 패턴은 최근일 가중 1, 그 이전 1/2, 세 번째 1/4로 평균하며 누락은 이용 가능한 날의 가중치만 재정규화한다. 현재 날 1시 이후 입력과 다른 온실 입력은 쓰지 않는다. 학습 특징 구축 시 `test_X`를 읽지 않아 MASK 조건을 지킨다. 원시 7차원 이력과 현재 0시 7차원을 연결한 운영 지문 14차원에 대해 학습 폴드 내부의 날만으로 중앙값 대체·표준화하고, F13/F47별 KMeans(`n_clusters=4`, `n_init=10`, `random_state=2913`)를 적합한다. 각 날에서 자기 기록의 네 중심까지의 제곱거리와 7차원 이력 평균을 모델 특징에 추가한다. 검증 날·잠금 날 입력은 KMeans 적합에 넣지 않는다. KMeans 중심, 거리 변환과 본 모델은 검증 폴드마다 새로 학습한다.

H12와 동일하게 시드 7·101 및 같은 학습일의 `FULL` 전용 ExtraTrees와 `FULL+F2` ExtraTrees를 짝지어 학습한다(`n_estimators=600`, `max_features=1.0`, `min_samples_leaf=1`, `n_jobs=4`). 두 예측 차이의 같은 날 인과 0.5 수축을 `0.24` 배로 저장 v2에 반영한다. 이는 이전 날 운영 입력의 모델 내 추가 효과를 절제하는 시험이며 v2 출력의 사후 확대 규칙은 아니다. 세 시드·혼합률이나 군집 수를 결과로 고르지 않는다. 단독 두 모델 RMSE도 보고한다.

저장 OOF 0·2·4·6·8·9를 먼저 시험하고 고EC 19일/나머지 215일, F13/F47, 전후반, 연결 가능 여부를 분리한다. 두 시드×6폴드와 양 농장 모두 v2보다 엄격히 개선, 날 단위 20,000회 재표집 `p_worse<0.025/12`를 선별 기준으로 한다. 통과한 경우에만 A/B/DIAG10 ×두 시드 전칸, EXT10·EXT12 무악화, 미사용 시드·최종 잠금 40일 1회, 미래 입력 교란·온실 격리·결정성 검사를 실행 전에 별도 등록해 수행한다. 실패하면 출처 지문의 정보 부재와 연결/학습기의 구현 한계를 구분하고 H14에서 다른 정체 학습 구조를 시험한다. 공식 점수·비공개 정답·다른 날 EC 라벨은 특징이나 군집에 쓰지 않는다. 온도·제출 파일은 건드리지 않는다.
