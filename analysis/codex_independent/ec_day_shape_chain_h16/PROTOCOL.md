# H16 / F3-2: 출처 사슬 상태를 하루 수준에만 주는 수준·모양 분해

2026-09-29 실행 전 등록. H15의 고EC 전문가는 8~12개 학습일과 약한 분류 확률 때문에 실패했다. EC 오차의 87.6%가 하루 수준이라는 D1을 이용해 모든 학습일로 하루 평균을 배우고, 시각별 편차는 별도 모델로 배운다. 과거 카탈로그 6.25의 당일 입력만 쓰는 하루 수준+모양 2단계는 실패했으므로, H16은 H12에서 대리 연결 정확도 79.4%를 보인 **이전 출처 날의 입력 상태를 하루 수준 모델에만 추가**한다. 같은 날 입력의 재가공만 반복하지 않는다.

학습일의 24시간 `sub_ec` 평균을 각 행의 수준 목표로, 해당 행 EC−그날 평균을 모양 목표로 한다. 정답은 학습 목표에만 쓰고 다른 날 정답을 특징에 넣지 않는다. 현재 행의 `FULL` 인과 특징을 두 모델의 공통 입력으로 쓴다. H12 입력만의 출처 링크에서 이전 최대 3일 입력으로 만든 `rad_total_chain3`, `vpd_total_chain3`, `sealed_run`, `vent_mean_chain1`, `fan_mean_chain1`, `link_gap` **6열**만 수준 모델에 추가한다. 모든 현재·이전 입력은 같은 F13 또는 F47 기록에 속하고, 현재 날은 0시~현재 행만 쓴다. 학습 특징은 `train_X`만으로 만들어 `test_X`는 MASK한다.

대조 수준 모델은 `FULL`만, 사슬 수준 모델은 `FULL+6열`을 쓴다. 둘 다 `HistGradientBoostingRegressor(max_iter=250, learning_rate=.05, max_leaf_nodes=7, min_samples_leaf=100, l2_regularization=10, early_stopping=False, random_state=seed)`로 학습일 전체 행을 적합한다. 모양 모델은 `FULL`만의 ExtraTrees(`n_estimators=400`, `max_features=1.0`, `min_samples_leaf=2`, `n_jobs=4`, `random_state=seed`)로 모든 학습 행의 중심화 라벨을 적합한다. 시드 7·101. 대조/사슬 각각 수준+동일 모양 출력을 만들고 단독 RMSE·하루 수준/시간 안 오차를 보고한다. **H16 후보는 `0.8·저장 v2+0.2·(사슬 수준+모양)`**으로 고정해 새 모델을 직접 조합한다. 사슬 입력 절제 비교도 보고하되 대조 점수로 계수나 특징을 고르지 않는다. v2 출력 값에 따른 사후 문턱·확대는 없다.

저장 OOF 폴드 0·2·4·6·8·9에서 검증일·잠금 40일 ±1일을 세 모델 모두의 학습에서 제외한다. 각 시드×6폴드·양 농장 엄격 개선 및 날 단위 20,000회 MSE 재표집 `p_worse<0.025/12`를 선별 기준으로 한다. 고EC 19일/나머지 215일, 수준/모양 분해, 사슬 특징 결측률을 보고한다. 통과 시 A/B/DIAG10 ×두 시드, EXT10·EXT12 무악화, 미사용 시드·최종 잠금 40일 1회와 규정 검사를 실행 전에 별도 등록해 수행한다. 실패하면 H16의 구조·정보 결핍을 대조/사슬 단독 점수로 분리하고 시드·계수만 바꿔 재실행하지 않는다. 온도·제출 파일은 만들거나 변경하지 않는다.
