# D8: 6시까지 합법 입력에 v2의 남은 하루 수준 신호가 있는가

2026-09-29 실행 전 등록. H1~H8은 EC v2를 엄격한
재현 기준에서 개선하지 못했다. D1의 오차 대부분은
하루 수준이고 D7은 유사한 6시 입력만으로도 대체로
EC 수준이 가깝다고 보였지만, H7에서 그 정보가
v2에 추가 이득은 주지 않았다. H9를 정하기 전에
**v2의 이른 시각 예측이 설명하지 못한 입력 신호**를
고정 목록으로 검사한다. 모델 채택 검증으로 사용하지
않고 새 가설 슬롯도 소비하지 않는다.

공개 OOF 폴드 0·2·4·6·8·9의 234일만 사용하고
최종 잠금 40일은 제외한다. 각 날의 목표는 `그날
sub_ec 정답 평균 − 6시 v2 예측`이다. 6시 예측과
원시 `train_X`의 0~6시 입력만 사용하며, 그날
7시 이후 입력·다른 온실 입력·`test_X`는 쓰지 않는다.

검사할 14개 입력 신호를 미리 고정한다: 0시의 외기
온도·습도·일사·풍속, 0~6시의 실내 온도·습도·CO₂
순변화, 같은 시간 실내 온도·습도·CO₂의 변동폭,
0~6시 평균 차광·난방·순환팬·환기. 신호별 결측은
온실별 중앙값으로 대체하고 표준편차가 0이면 제외한다.
농장 표시·전후반 표시·날 번호·6시 v2 예측(선형과
제곱)을 공통 통제변수로 두고 목표와 각 신호를 각각
선형 잔차화한 뒤 Pearson 부분상관을 구한다. 신호
선택의 다중비교를 보정하려고 농장×전후반 층 안에서
목표 잔차를 10,000회 섞고(시드 2910), 매번 14개
상관 절댓값의 최댓값과 관측 최댓값을 비교한다.

사전 진행 조건: 보정 비율 `p_max<0.01`, 가장 큰
신호의 양 농장 부분상관 부호가 같고 각 농장 절댓값
≥0.15이면 그 단일 신호를 H9 후보 기작으로 검토한다.
미달이면 14개 신호를 보정식으로 쓰지 않는다.
이는 선형 잔차 진단에 불과하며, 신호가 없다고 모든
합법 입력 정보의 부재나 RMSE 하한을 뜻하지 않는다.

실행 전 `codex-ec`에 프로토콜·코드를 커밋한다.
정답으로 평가 행 특징을 만들거나 최종 잠금일을
채점하지 않는다. 공식 점수·비공개 정답·제출 파일
사용 없음.
