# 비공개 정답 없는 EC 예측 이동 진단

실제 `test_X.csv`에서 로컬 TabPFN 후보와 기존 미제출 안전 조합
`submission_07.csv`의 EC 예측 차이를 기록한다. 1,440행의
row_id와 온도 열 일치를 검사한다. 전체·온실별·밀폐일별 예측
변화의 방향과 크기, 날짜별 큰 이동을 보고한다. 밀폐일은 하루
전체 입력으로 정의하므로 **진단에만** 사용한다. 실제 정답,
RMSE, 리더보드 점수 또는 어느 후보가 더 나은지는 알 수 없다.

이 결과로 혼합 비율·예측·후보 파일을 바꾸지 않는다. 원본 자료와
이미 생성한 제출/후보 파일도 수정하지 않는다.
