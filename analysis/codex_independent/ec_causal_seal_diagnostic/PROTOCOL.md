# D3: 밀폐 오차를 현재 입력으로 구별할 수 있는가

2026-09-29 실행 전 등록. D1에서는 하루 전체 `act_circfan`과
`act_vent`로 사후 정의한 밀폐일 39개가 EC v2 오차제곱의
58.9%를 차지했다. 이 밀폐 표시는 미래 시각 입력을 담으므로
그대로 평가 특징이 될 수 없다. H1의 전체 고값 보정은 폴드
3개에서 악화해 기각됐다. 현재 행의 운영 입력으로 고오차
체제를 구별할 수 있는지 진단한다.

기존 공개 OOF 234일·5,616행의 현재 행에서만 다음 표시를
계산한다: `gate = (act_circfan < 10) & (act_vent == 0)`.
`p_high = (v2 >= 0.6)`도 현재 행 예측만 사용한다. 2×2
네 칸의 행수·날수·평균 잔차(정답−v2)·RMSE·전체 제곱오차
몫을 기록한다. 농장별, 폴드별로도 각 칸의 평균 잔차를
기록하고, 각 농장-날의 0시 gate와 0시 p_high로 하루 전체
평균 잔차를 분류한다. 하루 중 gate의 비율과 사후 밀폐일의
연관은 진단 용도로만 기록하고 모델 특징으로 쓰지 않는다.

**진행 기준:** `gate & p_high`가 전체 20일 이상에서 관측되고,
그 칸의 평균 잔차가 양 농장 모두 +0.05 이상이며 6개 폴드
중 적어도 4개에서 양수라면, H2로 **현재 행 운영 상태에 따른
잔차 모델**을 사전 등록한다. 하나라도 실패하면 이 gate
가설은 기각하고 다른 기작을 찾는다. 이는 효과 크기/안정성
선별일 뿐 최종 채택 검정이 아니다. 여러 문턱이나 다른
게이트를 사후 탐색해 H2로 되살리지 않는다.

`test_X`, 새 잠금 40일 정답, 비공개 정답, 리더보드 점수를
읽지 않는다. 제출 파일은 만들지 않는다.
