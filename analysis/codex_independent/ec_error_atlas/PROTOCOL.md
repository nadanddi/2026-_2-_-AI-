# EC v2 남은 오차 지도 D1 — 실행 전 계획

2026-09-29. 비교 대상은 저장된 v2 공개 OOF 234일·5,616행과
그때의 3회차 기준 예측이다. DIAG10 탐색 0·2·4·6과 기존
확인 8·9 파일을 사용한다. 파일별 예측 열을 따로 맞춘 후
행 5,616개·날 234개·유한값을 검사한다. 새 모델은 학습하지
않는다. 공개 train_X/train_y만 읽고 test_X는 읽지 않는다.

체제 정의를 결과 전에 고정한다.

- 밀폐: 하루 순환팬 평균 <10, 환기 0인 시각 비율 >0.85.
  미래 입력을 쓰는 **진단 표지**이며 예측 특징으로 금지.
- 저온: 같은 날 0시 실내온도 ≤10℃. 현재 시각부터 사용 가능.
- 전후반: 일차 <179 / ≥179.
- 출처 근사: F13·F47 각각 공개 학습일의 0시 실내 3개·구동기
  7개 값을 중앙값 보간·표준화한 뒤 KMeans 4군집(seed 0,
  n_init 20). 군집은 입력만 사용하며 실제 출처 정답이 아니다.
- 높은 EC: 하루 실제 평균 ≥1.2. 진단 전용 정답 층이다.

각 층은 날 수, v2/기준 RMSE, v2 평균 잔차(정답−예측),
전체 v2 오차제곱 몫, 하루 수준 제곱오차 몫을 출력한다.
상호작용 층은 농장×전후반×밀폐×저온과 농장×전후반×군집이다.
하루 단위 오차제곱 총합에서 기여가 큰 안정적인(≥5일)
체제부터 다음 가설의 표적으로 삼는다. 소수 날짜의 높은 손실을
확정적 편향으로 보정하지 않는다.

기존 확인 폴드는 **이 진단에서 이미 사용됐으므로**, 새 목표의
최종 확증에는 새로 잠글 날짜 분할과 한 번도 쓰지 않은 시드가
필요하다. 이 결과를 새 후보의 독립 확인으로 부르지 않는다.
