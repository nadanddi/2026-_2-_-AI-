# 온도 최고 제출 구성 + EC 네 문맥 혼합: 로컬 후보 작성 계획

온도는 이미 제출해 0.5456을 기록한 5회차 `submission_06.csv`의
값을 그대로 사용한다. 미제출 `submission_07.csv`의 온도와 전 행
일치하는지 확인한다. EC는 독립 재현에 성공한 실제 3회차
ExtraTrees·LightGBM Tweedie·MLP 3시드 원시 예측 80%와,
CPU에서 끝단 검사를 통과한 TabPFN v2 네 문맥(시드 1~4) 평균
20%를 혼합한다. 그 뒤 기존 당일 인과적 수축 0.5와 전체 공개
학습 EC 범위 제한을 적용한다. 모든 값은 test_X의 원래 row_id
순서로 쓴다.

이 작업은 **로컬 검토용 후보 CSV만** 새 이름으로 만든다.
원본 제출 파일, 원본 자료, 플랫폼 기록은 수정하지 않는다.
sample_submission의 열/행/유한값 조건과 출처 파일 해시,
기준 EC 6자리 재현, 온도 행별 동일성을 검사한다. 정답이 없어
후보의 실제 RMSE는 계산하지 않는다. 평균·범위·기준 대비 변화량은
이상 여부를 살피는 진단이지 점수 대체 지표가 아니다.

가중치의 정확한 별도 라이선스 문구와 재현 ZIP, 최종 제출 결정은
후속 단계로 남긴다. 여기서는 후보를 채택·업로드하지 않는다.
