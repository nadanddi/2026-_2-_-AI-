# TabPFN EC 네 문맥의 추가 탐색 구간 — 실행 전 계획

기존 `tabpfn_cpu_bag`의 설정을 바꾸지 않고 탐색 폴드 4·6에 그대로 적용한다.
폴드 0·2에서 나타난 평균 2.36% RMSE 감소가 다른 날짜에서도 반복되는지
확인하는 재현 시험이다. 새 시드나 혼합 비율을 탐색하지 않는다.

고정 설정: ModelVersion.V2, CPU float32, n_estimators=4, 훈련행 2,000개를
비복원 추출하는 문맥 시드 1·2·3·4, 네 예측의 단순 평균, 기존 EC 기준
모델 시드 7·101, 기존 예측 80% + TabPFN 20%, 원래의 인과적 수축과
훈련 범위 제한. 기존 폴드 0·2 결과는 입력/코드/분할/행 ID를 확인해서
그대로 집계한다. 확인용 폴드 8·9와 인접일은 학습·평가에서 제외한다.

사전 통과 기준: 네 탐색 폴드(0·2·4·6) × 기준 시드 2개 = 8개 비교가
모두 RMSE를 낮추고, 여덟 상대 감소율의 평균이 1% 이상이어야 한다.
각 온실의 방향과 일자 블록별 오차 분포도 보고한다. 블록 분석은 효과의
불확실성을 보여주며, 이 단계에서 임의의 블록 유의성 문턱을 추가하지
않는다. 하나라도 실패하면 고정 구성을 재현 후보에서 제외한다.

기존 연구가 공개 정답 전체를 이미 사용했으므로 이 시험은 완전한 독립
검증이 아니다. 여기서 통과해도 최종 채택/제출 근거로 단독 사용하지
않는다. test_X나 비공개 정답은 읽지 않는다. 문맥별 CSV를 저장하고,
중단 시 동일 해시 및 검증 행 순서를 확인한 뒤 완료 문맥만 재사용한다.
