# D7: 관측 입력이 비슷한 날의 EC 수준 차이

2026-09-29 실행 전 등록. 목적은 EC v2 잔여 오차가 입력 잡음만으로
설명되는지 살피는 것이다. H7~H10의 모델 점수 선별이나 최종 확인은
이 진단으로 대체하지 않는다.

공개 OOF 234일(폴드 0·2·4·6·8·9)에 한해, 각 온실-일의 6시까지
관측 가능한 입력을 요약한다. 사용 열은 0시와 6시의 실내 온도·습도·
CO₂, 0~6시 실내 세 열과 환기·팬·CO₂ 공급의 평균, `day/30`이다.
원시 `train_X`의 같은 온실·같은 날 0~6시만 사용하며 미래 입력,
`test_X`, 검증일의 EC 정답은 특징 계산에 쓰지 않는다. 최종 잠금
40일은 행·정답 모두 분석 대상에서 제외한다.

온실별로 각 특징의 중앙값으로 결측 대체하고 IQR(0이면 표준편차,
그것도 0이면 1)로 나눈다. 각 날은 같은 온실에서 2~30일 떨어진
날 중 표준화 유클리드 거리가 최소인 하나와 짝짓는다. 거리와
짝을 확정한 **뒤**에만 두 날의 EC 정답 하루 평균과 v2 하루
잔차를 읽어 차이를 계산한다. 같은 두 날의 중복 방향 짝은 따로
기록하되 통계적 독립 표본으로 주장하지 않는다.

사전 출력: 짝 수, 거리 사분위, EC 수준 절대차 중앙값·90백분위,
거리 하위 25% 짝 중 EC 수준 차이≥0.4인 수와 비율, 그 사례의
입력·정답·v2 하루 평균, 그리고 무작위 허용 짝 10,000회(시드
2907)의 EC 수준 차이 중앙값 분포와 비교한다. 둘 이상의 온실에서
가까운 짝의 큰 정답 차이가 반복되면 관측되지 않은 급액·관수 등
관리 변수를 **가능한 설명**으로 남긴다. 이 결과는 특정 원인을
증명하거나 달성 가능한 RMSE 하한을 제시하지 않는다. 가까운
짝에서도 정답 차이가 작으면 입력 견고화 H7을 우선 검토한다.

프로토콜·코드를 `codex-ec`에 먼저 커밋하고 실행한다. 공식 점수,
비공개 정답, 최종 잠금일 정답을 읽거나 제출 파일을 만들지 않는다.
