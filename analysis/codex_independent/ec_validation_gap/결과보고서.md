# EC 검증–평가 격차: 후반 하루 수준 오차와 체제 차이

2026-09-29. `PROTOCOL.md`를 작성한 뒤 공개 EC v2 OOF
234일·5,616행과 입력 전용 평가 60일을 비교했다. 실행 초안
`run.py`는 탐색·확인 예측 열 이름이 다른데도 결합 후 한 열만
읽어 확인 분할을 누락했다. 그 출력의 후반 RMSE 0.099는
**무효**다. 초안을 보존하고 파일마다 열을 맞춘 `run_v2.py`로
전체 5,616행의 예측값 비결측을 확인한 후 다시 계산했다.

올바른 후반 OOF 36일 RMSE는 **0.38226**이다. 이를 하루
평균 오차와 하루 안의 모양 오차로 직교 분해하면 각각
**0.37593**, **0.06923**이며, 제곱오차의 **96.7%**가 하루
수준 오프셋이다. F47 후반 밀폐 OOF는 4일뿐인데 RMSE
0.866이고, 그중 229·231일은 실제 일평균 EC 1.79·2.18을
모델이 약 0.86·0.76으로 과소예측했다. 극단적 두 날에 수치가
민감하다.

| 입력 체제 | 후반 OOF | 평가 입력 |
|---|---:|---:|
| 밀폐 날 | 8/36 (22.2%) | 20/60 (33.3%) |
| 자정 실내온도 ≤10℃ | 10/36 (27.8%) | 27/60 (45.0%) |
| F13 밀폐 날 | 4/19 (21.1%) | 13/30 (43.3%) |
| F47 밀폐 날 | 4/17 (23.5%) | 7/30 (23.3%) |

전체 밀폐 비율은 1.5배로 사전 지정한 “2배 이상이면 후반
OOF가 체제를 대표하지 못함” 문턱에는 미달했다. 그러나 F13만
보면 약 2.1배이며, 저온 비율도 크게 다르다. 후반 OOF는
밀폐 날 8개와 특히 F47 극단 2일에 의존한다. 반대로 실제
제출 EC 0.2055가 후반 OOF 0.382보다 낮다는 사실은 평가의
미관측 밀폐 EC 수준이 이 극단 공개일들과 같지 않거나 다른
조건이 작용함을 시사하지만, 어느 날짜가 어떤 정답인지는
알 수 없다. **후반 검증의 절대 RMSE를 숨은 점수로 외삽하지
않는다.**

하루 평균 EC를 설명할 관수·배액·급액 기록이 F13·F47에는
없다. 다음 모델은 단순한 시간 안 모양 개선보다, 현재·과거
입력으로 하루 수준 오프셋을 안정적으로 추정하는 근거가
있어야 한다. 밀폐 판정은 하루 전체 입력을 쓴 진단용이고
평가 예측 특징으로 사용하지 않았다. 평가 정답이나 새 제출
파일은 사용하지 않았다.
