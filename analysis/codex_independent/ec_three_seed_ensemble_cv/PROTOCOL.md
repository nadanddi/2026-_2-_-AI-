# 실제 EC 세 시드 평균 구성의 CPU 교차검증 — 실행 전 계획

앞선 12개 비교는 기존 기준 모델 시드 7·101·2024를 **각각**
평가했다. 실제 후보는 이 세 시드의 ExtraTrees·LightGBM·MLP
원시 예측을 구성원별로 평균한 뒤 TabPFN 네 문맥 평균 20%와
혼합한다. 비선형 범위 제한 때문에 개별 시드 RMSE가 모두 개선해도
최종 세 시드 평균의 RMSE를 확인해야 한다.

고정된 탐색 폴드 0·2·4·6에서 저장된 정확한 입력별 기준 모델
원시 예측 캐시와 TabPFN 문맥 1~4 평균을 재사용한다. 캐시는
입력·코드·환경 해시와 row_id를 확인하고, 각 시드의 기존
저장 최종 예측과 1e-12 이내 일치해야 한다. 세 시드 원시 예측을
평균한 기준과, 같은 기준 80% + TabPFN 20%를 각각 당일 수축
0.5·훈련 EC 범위 제한으로 마무리한다.

사전 확인 기준: 네 폴드 모두 RMSE 감소, 네 폴드 검증 행을
합친 RMSE 감소율 1% 이상. 온실별·날짜별 개선 방향,
온실-일 및 5일 묶음 재표본 구간, 개선의 일자 집중도를
보조 지표로 전부 보고한다. 이 보조 지표를 보고 혼합 비율이나
문맥을 선택하지 않는다. 확인용 폴드 8·9와 인접일은 사용하지
않고 test_X·비공개 정답도 읽지 않는다. 기존 공개 자료를
반복 검토했으므로 완전히 독립적인 유의성 검정이 아니다.
