# TabPFN EC 두 번째 독립 문맥 묶음 CPU 검증

2026-09-28. 사전 계획 `PROTOCOL.md`대로 문맥 시드 5·6·7·8을
CPU float32에서 새로 적합했다. 각 문맥의 훈련 샘플은 2,000행,
4개 예측을 평균하여 기존 기준 EC 원시 예측과 20:80으로 혼합했다.
당일 인과적 수축 0.5와 훈련 EC 범위 제한은 기존 후보와 동일하다.
탐색 폴드 0·2·4·6, 기준 시드 7·101·2024를 모두 평가했다.

−4.02%로, 사전 기준(전부 개선 및 평균 1% 이상 개선)을 통과했다.
첫 묶음 대비 우세 구간은 0·4, 열세 구간은 2·6으로 나뉜다.
따라서 특정 네 문맥 표본에서만 개선이 생긴 결과일 가능성은
낮아졌지만, 두 묶음 중 더 좋아 보이는 것을 사후 선택하지 않는다.
실제 로컬 후보와 재현 패키지는 기존 문맥 1~4 그대로다.
