# EC 새 정보원 캠페인 H11~H22 최종 보고서

2026-09-29, `codex-ec`. 이 보고서는 공개 `train_X`·`train_y`와 이미 저장된 v2 OOF를 이용한 연구 결론이다. 온도 모델, 기존 제출·사용 파일, 비공개 정답, 공식 점수로 가설을 고르는 작업은 하지 않았다. 새 제출 파일이나 실제 제출도 없다.

## 결론과 적용 범위

**v2를 확실하게 이기는 새 EC 모델은 찾지 못했다.** 사용자 종료 조건에 따라 H11~H22 열두 가설을 소진하고 멈춘다. F1 출처 사슬 다섯, F2 출처 정체 두, F3 고EC 학습 구조 두, F4 생리·질량수지 세 구현을 각각 실행 전에 프로토콜로 고정했다. 모든 가설의 코드·결과·판정은 `CAMPAIGN.md`와 각 폴더의 `PROTOCOL.md`·`결과보고서.md`에 있다. 사용한 두 시드는 7·101이다.

선별 자료는 v2 저장 OOF 234 온실-일·5,616행, 폴드 0·2·4·6·8·9이다. 기준 RMSE는 **0.213819**. 같은 학습일·시드의 대조 ExtraTrees와 신규 특징 ExtraTrees를 짝지어 비교하고, 사전 고정한 비중으로 v2에 차이를 반영했다. 각 실험의 검증일과 잠금 40일 ±1일은 신규 모델의 학습에서 제외했다. 어느 H도 양 시드×6폴드 전칸 개선과 날 단위 다중비교 기준 `p_worse<0.025/12≈0.00208`을 통과하지 못했다. 따라서 A/B/DIAG10 별도 재학습, EXT10·EXT12, 미사용 시드, 최종 잠금 40일 한 번 확인과 인과 교란 검사는 **진행할 자격을 얻은 후보가 없어 실행하지 않았다**. 이 단계들은 통과했다고 주장하지 않는다. 저장 v2 OOF를 만드는 원래 학습기가 잠금일 정답을 과거에 사용했을 가능성도 있으므로, 잠금일을 완전 독립 평가셋이라고 부르지 않는다.

## 제출 시 예상 범위와 반증 기준

이번 캠페인에서 **새 모델 제출안은 없다**. 기존 v2를 훗날 그대로 제출한다는 가정에서만, EC 리더보드 RMSE의 실무적 예상 범위를 **0.19~0.24**로 둔다. 중심은 마지막 유효 제출 EC **0.2134** 근방이다. 이 범위는 공개 OOF 0.213819, v2의 공개 확인 구간 기준 대비 −3.22%, 평가 60일의 밀폐·저온 체제 차이를 고려한 **주관적 사전 예상**이며 보정된 신뢰구간이 아니다. 실제 v2 제출 점수가 **0.24보다 나쁘면**, “v2의 공개 이득이 평가일에도 큰 성능 악화 없이 이전된다”는 이 예상 가설을 기각한다. 0.19~0.24 안에 들어도 H11~H22의 어느 새 정보 가설이 맞았다는 증거는 아니다. 평가 정답·공식 점수를 보고 범위를 사후 수정하지 않는다. 제출은 하지 않았다.

경쟁팀의 **0.1245**와 우리 마지막 제출 **0.2134**의 차이는 같은 리더보드라면 RMSE **0.0889**이다. 새 v2는 제출하지 않았으므로 v2와 경쟁팀의 실제 차이는 모른다. 가장 그럴듯한 현재 설명은 급액·배액/관수와 실제 출처 정체처럼 하루 EC 수준을 정하는 관리 상태가 제공 입력에 직접 없고, 우리 파생 대리는 센서 잡음·출처 연결 오류·고EC 학습일 부족에 묻힌다는 것이다. 상대 팀이 다른 합법 상태 표현을 찾았는지, 우연히 평가일에 잘 맞았는지, 다른 학습 구성을 썼는지는 알 수 없다. 0.1245만으로 규정 위반이나 비공개 정답 접근을 추정하지 않는다.

## 재현·규정 감사

각 `PROTOCOL.md`의 커밋 ID가 실행보다 앞서 있고, `run.py`가 사용한 입력·코드·프로토콜 해시, 폴드별 행 예측, 집계를 `analysis/local/ec_*` 시간 폴더에 저장했다. 해당 `analysis/local` 원시 산출물은 크기가 커 Git 관리 밖에 있으나 실행 코드와 수치 보고서는 `codex-ec`에 남긴다. 가설 H11의 연결 실패를 H12에서 입력 기반 연결로 바꾼 것처럼, 다음 구현은 실패 원인에 맞춰 다른 **사전 가설**로 등록했다. 기각된 구현을 시드만 바꿔 재선별하지 않았다.

특징은 F13/F47 같은 기록의 현재·이전 입력에서 인과적으로 계산했고, 학습 특징은 `train_X`만으로 만들었다. 다른 날 EC 정답은 특징으로 사용하지 않았다. 저장 OOF의 라벨은 검증 점수와 고EC 하위집단 진단에만 사용했다. `test_X`로 학습 특징을 채우거나 비공개 정답·리더보드로 후보를 고르지 않았다. 최종 잠금 40일은 선택 전에 봉인한 채 **채점 0회**다. 새 후보가 없으므로 이 보고서는 제출 성능 보증이나 규정 최종 검사 통과 증명서가 아니다.
