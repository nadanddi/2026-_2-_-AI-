# H14 / F2-2: 출처별 EC 수준을 학습하는 부분공유 전문가

2026-09-29 실행 전 등록. H13은 이전 출처 날 운영 지문을 ET의 추가 열로 넣었으나 단독 RMSE가 0.239→0.262로 악화했다. 출처 정체 신호가 없는지와, ET가 소수 출처 상태를 분할로 못 배우는지를 가르기 위해 H14는 출처별 EC 수준 계수를 **학습 구조 자체**에 둔다. F2 첫 구현의 원시 특징 확장과 다른 구현이다.

각 검증 폴드에서 F13/F47별로 H13의 현재 0시 구동기 7열+같은 출처 이전 최대 3날의 야간 구동기 가중 평균 7열을 만든다. 출처 연결은 H12 입력 전용 알고리즘을 그대로 쓰고, KMeans 4군집·중앙값·표준화는 그 폴드의 학습일에서만 적합한다. 그 군집을 현재 행의 출처 정체 대리로 쓴다. 검증일·잠금일·`test_X` 입력은 군집 학습에 넣지 않는다.

전역 대조 모델은 `FULL` 입력을 학습일 중앙값 대체·표준화한 Ridge(`alpha=100`, `solver='lsqr'`)이다. 부분공유 전문가는 같은 전역 입력에 각 농장×군집의 절편 및 네 현재/0시 입력(`in_temp`, `in_temp_h0`, `act_heating_h0`, `act_vent`)과의 곱을 추가한 같은 Ridge(`alpha=100`, `solver='lsqr'`)이다. 군집·농장에 따른 이 추가 계수는 EC 학습 라벨로 모델 적합 시 배운 **매개변수**이며, 다른 날 EC 정답을 추론 특징으로 붙이는 target encoding은 아니다. 이 규정 해석을 채택 전에 다시 감사한다. 두 모델은 같은 학습 행·시드로 적합하고, 검증 출력 차이의 인과 0.5 수축을 0.24배로 저장 v2에 반영한다. Ridge는 결정적이지만 검사 일관성을 위해 시드 7·101의 날짜 순열 학습 두 실행을 수행하며, 두 결과가 수치 오차 내 동일해야 한다. 시드에 따라 이득이 갈리면 실패로 본다.

저장 OOF 폴드 0·2·4·6·8·9에서 전칸 v2 개선, 양 농장 개선, 날 단위 20,000회 MSE 재표집 `p_worse<0.025/12`를 선별 게이트로 한다. 고EC 19일/그 밖 215일, 출처 군집별 훈련일 수·평균 EC, 농장·전후반, 대조/전문가 단독 RMSE를 기록한다. 군집별 평균 EC는 **진단에만** 보고하고 모델 특징으로 넣지 않는다. 선별 통과 때만 A/B/DIAG10 ×2시드, EXT10/12, 미사용 시드·최종 잠금 40일 1회 및 규정 검사를 실행 전 별도 등록한다. 실패 시 F2 계열의 결론을 출처 정보 부재/모형 제한/표본 부족 중 증거 수준에 맞춰 보고한다. 군집 수·Ridge 규제·계수 비중의 사후 조정은 하지 않는다. 온도·제출 파일은 건드리지 않는다.
