# H15 / F3-1: 고EC 상태 분류와 수준 회귀를 함께 학습하는 전문가 혼합

2026-09-29 실행 전 등록. OOF 오차의 74.2%가 실제 일평균 EC≥1.2인 19일에 집중한다. 이전 H3는 분류 확률로 v2 출력을 사후 가감해 실패했고 H9의 고라벨 가중도 실패했다. H15는 v2 출력에 따른 문턱/보정 없이, **학습에서부터** 고EC일과 다른 날의 수준 회귀기를 분리한다. F3의 첫 구현이다.

학습일의 24시간 `sub_ec` 평균≥1.2를 고EC 클래스 목표로만 쓴다. 각 행 특징은 현재 시각까지의 인과 `FULL` 열이다. 고EC 분류기는 `HistGradientBoostingClassifier(max_iter=150, learning_rate=.05, max_leaf_nodes=7, min_samples_leaf=100, l2_regularization=10, early_stopping=False, random_state=2915)`이며 각 학습 행에 같은 일 가중치 1/24를 준다. 분류 확률은 같은 날 현재 행까지의 누적 평균으로 평활한다. 고EC 전문가와 그 밖 전문가는 각각 자기 클래스의 학습일만으로 ExtraTrees(`n_estimators=400`, `max_features=1.0`, `min_samples_leaf=2`, `n_jobs=4`, `random_state=seed`)를 적합한다. 전역 ExtraTrees도 모든 학습일에 같은 설정으로 적합한다. 결측은 각 모델 자신의 학습 행 중앙값으로 대체한다. 시드 7·101을 독립 실행한다.

전문가 출력은 `q·고EC전문가+(1−q)·일반전문가`, 새 모델 출력은 `0.5·전역+0.5·전문가출력`으로 정한다. H15 후보는 `0.8·저장 v2+0.2·새 모델`이며 학습 EC 범위로 제한한다. 이는 고EC 분류·수준 회귀를 학습 안에서 결합한 별도 모델이고 v2의 높은 출력이나 잔차를 사후 확대하는 규칙이 아니다. 확률·전문가 예측은 현재·과거 입력에서만 계산한다. 학습 행 특징은 `train_X`만으로 만들어 `test_X`를 MASK한다. 다른 날 EC 정답을 특징으로 쓰지 않으며 학습 목표를 만드는 데만 쓴다.

저장 OOF 폴드 0·2·4·6·8·9에서 검증일과 최종 잠금 40일 ±1일을 훈련에서 제외한다. 각 시드×6폴드와 양 농장 모두 v2보다 엄격히 개선하고 날 단위 20,000회 재표집 `p_worse<0.025/12`일 때만 A/B/DIAG10 ×두 시드, EXT10·EXT12 무악화로 진행한다. 고EC 19일/나머지 215일 RMSE, 클래스별 학습일 수, 분류 확률의 고/일반 분리, 전문가 단독 오차를 보고한다. 최종 채택은 미사용 시드·잠금 40일 단 1회와 규정 검사까지 통과해야 한다. 선별 탈락 시 확률 오류와 희소 전문가 표본을 분리해 진단하고 확률 문턱·혼합률·트리 설정을 조정하여 같은 가설을 재시도하지 않는다. 제출 파일·온도 모델은 만들거나 변경하지 않는다.
