# H12 / F1-2: 입력 연속성으로 잇는 출처 사슬

2026-09-29 실행 전 등록. H11에서 d−2 고정 연결은 분석용 대리 참조 170일 중 89일만 맞았고 후반은 7/27일이었다. H11의 모델 자체 약세와 연결 오류를 분리하기 위해, H12는 카탈로그 1.14 및 읽기 전용 `research/deep_cal_feats.py`의 **입력만 쓰는 인과 연결**을 새 구현으로 옮겨 사용한다. 이전 연구의 78%는 다른 집합의 대리 정확도이므로 H12 성능으로 간주하지 않는다.

## 입력·연결 규칙

F13·F47을 각각 따로 처리한다. 학습 특징은 오직 `train_X`에서 구축하고 `test_X`는 전부 NaN으로 가린 것으로 취급한다. 검증일에도 연결은 같은 기록에서 **현재 날짜보다 작은 기록 인덱스**의 입력과 현재 0시 입력만으로 판정한다. 현재 날의 1시 이후 입력은 연결 판정에 쓰지 않는다. 이전 날의 24시간 입력은 허용한다. 두 번째 달력 순환 때문에 기록 인덱스가 실제 날짜를 뜻하지 않는 점은 한계로 기록하며, 평가에서 같은 기록의 이전 입력을 쓰는 규정 해석은 카탈로그 1.14 및 사용자 명시 기준을 따른다. 실제 출처 ID, 정답 EC, 다른 기록 입력, 이후 시각 입력을 사용하지 않는다.

연결 알고리즘은 `deep_cal_feats.build2`의 상수와 순서를 고정해 포팅한다. 0시 외부 기상 4열(out_temp/out_hum/out_rad/out_wspd)의 정규화 거리 임계 0.02로 과거 동일날씨 쌍(twin)을 찾고, 그 쌍의 저장된 전날 달력군을 우선한다. 쌍이 없으면 가장 최근 과거 다른 날의 외부날씨 자정 연속 비용<3.0일 때 그 달력군을 쓰며, 아니면 모든 과거 후보에서 외부 연속 비용+`2·log1p(기록 간격)` 최소를 고른다. 후보 군 안의 이전 출처는 실내 3열 자정 연속 제곱비용(척도 1/5/40)과 난방·커튼·팬·환기 자정 상태 차이/50의 합이 최소인 날이다. 동률은 작은 기록 인덱스로 고정한다. 부재·불확실 연결은 NaN으로 남긴다. 코드에는 미래 입력 교란과 타 기록 교란 불변성 검사를 포함한다.

이렇게 연결한 직전 날부터 최대 3개 이전 날을 역추적하되, 매 단계는 더 작은 기록 인덱스여야 한다. 각 날의 양수 일사·양수 VPD 합, 환기 0 비율, 팬·난방·커튼·포그 평균과 연속 밀폐 횟수(환기 0 비율≥0.85, 팬 평균<10)를 특징으로 한다. 현재 시각까지의 `FULL` 특징과 이 **이전 입력** 특징을 ExtraTrees에 넣는다.

## 모델·진단·판정

같은 시드·학습일로 `FULL` 전용 대조 모델과 `FULL+사슬` 모델을 짝지어 학습한다: ExtraTrees(`n_estimators=600`, `max_features=1.0`, `min_samples_leaf=1`, `n_jobs=4`, `random_state=seed`), 학습일 중앙값 결측 대체. 시드 7·101. 저장 v2에 두 모델의 차이를 고정 계수 0.24로 반영하고, 그 차이는 같은 날 현재까지의 누적 평균과 0.5:0.5 수축한다. 즉 **사슬 입력의 학습 시 추가 효과만** v2에 반영하며, v2 점수나 잔차를 보고 출력 문턱을 조정하지 않는다. 대조와 사슬 모델의 단독 RMSE도 보고해 H11의 독립 모델 약세와 정보 부족을 구별한다. H11의 가중치만 재조정한 안이 아니다.

기준은 v2 저장 OOF 폴드 0·2·4·6·8·9. 검증일과 최종 잠금 40일 ±1일은 두 모델 학습에서 제외한다. 분석용 대리 연결 `deep_cal_10_links.csv`는 **채점 후 연결률 보고에만** 읽으며 모델 특징·선택에 사용하지 않는다. 연결 커버리지/정확도는 전체·농장·전후반·고EC 여부(라벨은 진단에만)로 보고하고 대리 기준임을 명시한다. 고EC 19일과 그 밖 215일 RMSE를 분리한다.

두 시드×6폴드 및 양 농장 모두 v2보다 엄격히 개선하고, 날 재표집 20,000회 `p_worse<0.025/12`일 때만 A·B·DIAG10 전칸, EXT10·EXT12로 진행한다. 최종 채택은 최신 목표의 미사용 시드·잠금 40일 단 1회·규정 검사까지 통과해야 한다. 통과 전 단계 코드는 실행 전에 별도 커밋한다. 탈락하면 연결이 개선됐는데 모델 이득이 없는지, 연결 자체가 부족했는지 분리해 기록하고 고정 매개변수 재탐색은 하지 않는다.

온도·기존 제출 파일은 변경하지 않고 새 제출 파일도 만들지 않는다.
