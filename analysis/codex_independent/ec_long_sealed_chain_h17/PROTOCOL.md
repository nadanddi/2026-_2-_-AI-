# H17 / F1-3: 4일 이상 밀폐 상태의 긴 출처 사슬 기억

2026-09-29 실행 전 등록. 카탈로그 6.16에서 같은 출처의 4일 이상 연속 밀폐 사슬 17일의 EC 잔차가 +0.21이었다. H12는 최대 3일·29개 원시 사슬 열이었고 H16의 최대 3일 수준 모델은 고EC 19일에 거의 무효였다. H17은 **4~7일에 걸친 밀폐 지속·증산/구동기 누적**이라는 다른 물리 상태를 소수 열로 검증한다. H12/H16의 시드나 혼합률만 바꾸는 재시험이 아니다.

F13/F47 각각 `train_X`만으로 H12의 입력 전용 인과 출처 링크를 만들고, 현재 날의 직전 출처 날부터 최대 7개 과거 날을 연결한다. 현재 날 링크 판정에는 0시 입력만, 이전 날 요약에는 해당 날 전체 입력만 쓴다. 하루 밀폐 대리는 환기 0 비율≥0.85 및 순환팬 평균<10으로 고정한다. 특징은 (1) 최근부터 첫 비밀폐 전까지의 연속 밀폐 일수, (2) 7일 중 밀폐 일수, (3~6) 일사 양수 합·VPD 양수 합·환기 평균·포그 평균의 과거 출처 날 가중 누적이다. 가중치는 직전 날부터 `0.7^(lag−1)`로 고정하며 존재하는 날에 대해서만 합하고 총 가중치로 나눈다. 이전 날이 전혀 없으면 NaN이다. 7일의 물리 기억을 시험하므로 짧은 H12 특징을 더 넣지 않는다. 이전 출처 날의 EC 정답은 특징으로 사용하지 않는다.

동일 시드·훈련일에서 `FULL` 전용 ExtraTrees와 `FULL+긴 사슬 6열` ExtraTrees를 짝지어 학습한다(`n_estimators=600`, `max_features=1.0`, `min_samples_leaf=1`, `n_jobs=4`, `random_state=seed`, 학습일 중앙값 결측 대체). 시드 7·101. 저장 v2에 두 모델 예측 차이의 당일 인과 0.5 수축을 `0.24`배로 반영한다. 이는 긴 출처 입력을 학습 단계에 더한 효과를 절제하는 것으로, v2 출력 수준별 사후 보정이 아니다. 단독 두 모델 RMSE도 보고한다.

저장 OOF 0·2·4·6·8·9에서 검증일과 잠금 40일 ±1일을 모델 학습에서 제외한다. 두 시드×6폴드·양 농장 전부 v2보다 엄격히 개선하고 날 단위 20,000회 MSE 재표집 `p_worse<0.025/12`일 때만 A/B/DIAG10 ×두 시드, EXT10·EXT12 무악화, 미사용 시드·최종 잠금 40일 1회 및 규정 검사로 진행한다. 고EC 19일/그 밖 215일, 4일 이상 사슬 날, 링크의 1~4단계 대리 적중률과 유효 표본을 따로 보고한다. 분석용 대리 연결은 점수 확정 **후** 정확도 보고에만 사용하고 모델 특징·선택에 넣지 않는다. 긴 사슬의 연결 오류가 커지면 물리 가설 실패와 구현 한계를 분리한다. 계수·시드·문턱 사후 조정은 하지 않는다. 온도·제출 파일은 만들거나 바꾸지 않는다.
