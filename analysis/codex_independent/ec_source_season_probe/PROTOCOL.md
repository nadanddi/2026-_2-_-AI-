# EC 잔차의 출처×계절 구조: 모델 학습 전 진단

작성일 2026-09-29. 이전 EC 후보·검증 결과를 이미 본 상태의
**탐색적 진단**이다. 이 분석만으로 새 후보를 채택하거나 제출하지
않는다.

가설: F13·F47은 여러 실제 출처의 날을 이어붙였다. 모델에는 0시
구동기 지문과 `day`가 따로 있지만 출처별 계절 궤적을 직접
표현하지 않는다. 출처×1·2차 구간마다 EC 하루 오차의 계통 편향이
남으면, 별도의 인과적 출처별 추세 모델을 시험할 근거가 생긴다.

진단 방법을 결과 전에 고정한다.

1. `train_X`의 F13·F47 각 날 **0시 한 행**에서 실내 3종과 구동기
   7종만 추출한다. F13·F47 각각 결측 중앙값 대치, 표준화 후
   KMeans `k=4`, `random_state=0`, `n_init=20`으로 군집한다.
   정답·평가 입력은 군집 적합에 넣지 않는다. 0시 이후 입력은
   사용하지 않는다.
2. 이미 저장된 EC v2 탐색 폴드 0·2·4·6과 확인 폴드 8·9의
   공개 예측만 합친다. 기준과 후보 각각의 온실-일 평균 잔차
   `정답−예측`을 만든다. 각 날 24행과 고유 `row_id`를 확인한다.
3. 각 온실×구간(일차 <179/≥179) 내부에서 군집별 평균 잔차가
   얼마나 다른지, 그 내부 변동의 설명 비율을 계산한다. 군집
   라벨을 같은 온실×구간 내부에서 10,000회 섞어 얻은 탐색적
   단측 비율도 기록한다. 기준·v2 모두 표시한다.
4. 진행 조건: v2 잔차의 군집 추가 설명 비율이 5% 이상이고
   순열 비율 <0.01이며, 2차 구간 각 온실에서 최소 한 군집이
   절대 편향 0.05 이상·5일 이상이어야 한다. 이 조건을 통과해도
   새 모델의 성능 증거는 아니고, 별도 사전 고정 모델 실험만
   허용한다. 미달이면 출처×계절 가설을 여기서 중단한다.

공개 정답 전체는 과거 연구에 이미 쓰였다. 순열 비율은 다중
탐색과 모델 선택을 보정하지 않으며 실제 점수 개선 확률이 아니다.
평가 정답·예측 파일·제출 파일을 만들지 않는다.
