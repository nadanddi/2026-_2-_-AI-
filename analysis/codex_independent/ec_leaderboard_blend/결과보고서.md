# 기존 채점 EC 예측의 볼록 혼합: 집계 점수상 개선

2026-09-29. 사전 `PROTOCOL.md`대로 공식 1·2·3·5회차의 점수와
원본 CSV만 계산했다. 네 파일의 SHA-256은 `research/제출기록.md`의 앞
12자리와 모두 일치하고, 1,440개 `row_id` 순서도 동일하다.
평가 정답은 읽거나 추정하지 않았다.

가중치 0.05 격자의 1,771개 볼록 혼합 중, 점수 반올림까지
고려한 최선은 **1회차 0.15 + 3회차 0.60 + 5회차 0.25**였다.
2회차 비중은 0. 표시 점수 중심값에 따른 EC RMSE는
**0.202426**, 네 공식 점수가 각각 ±0.00005 안에서 달라질 때의
보수적 범위는 **0.202373~0.202478**이다. 기제출 최고 3회차
0.2055의 가능한 최저 0.20545보다도 0.00297 낮으므로 사전
진행 문턱(최소 0.001 개선)을 넘는다.

이는 새 모델의 공개 검증 추정치가 아니다. 같은 평가 1,440행에
대해 이미 채점된 예측 벡터와 RMSE가 정확히 대응한다는 조건에서,
제곱오차 항등식으로 **그 혼합의 점수를 계산한 것**이다. 공식
점수의 반올림 오차를 포함했다. 다양한 예측의 오차가 일부
상쇄되는 효과이며, 조합식은 재현 가능하고 개별 비공개 정답을
복원하지 않는다. 이득은 약 1.5%로, 타 팀 0.1245와의 큰 차이를
해소하지 못한다.

5회차 파일의 EC는 `day`를 뺀 모델이어서 단독 점수는 나빴다.
그러나 25% 혼합에서는 3회차와 다른 오차가 일부 상쇄된다.
1회차 15%도 마찬가지다. 이번 가중치는 **공식 집계 점수에 맞춰
선택**했으므로, 공개 검증의 사전 채택 규칙을 통과한 새 모델과
동일하게 소개해서는 안 된다. 최종 채점이 현재 리더보드와 같은
행 집합인지와 규정·재현 패키지 요건은 제출 전 별도 확인이 필요하다.
사용자 지시 전에는 제출 CSV/ZIP을 만들지 않는다.

정밀 수치·파일 해시: `analysis/local/ec_leaderboard_blend/.../result.json`.
