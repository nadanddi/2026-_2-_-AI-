# 기존 공식 EC 점수로 혼합 가능성 계산 — 사전 계획

작성 2026-09-29. 공식 제출 1·2·3·5회차의 **전체 RMSE 네 값**과
당시 제출 CSV의 EC 예측값만 사용한다. 개별 평가 정답을 복원하거나
근사하지 않는다. 4회차 EC는 3회차와 같으므로 제외한다.

같은 평가 1,440행에 대해 `D_ij=mean((p_i-p_j)^2)`와 공식
`E_i=RMSE_i^2`가 주어지면, 합이 1인 혼합의 제곱오차는
`sum(w_i E_i) - sum_{i<j}(w_i w_j D_ij)`로 정확히 계산된다.
공식 점수는 소수 넷째 자리 반올림이므로 각 RMSE가 표시값
±0.00005 범위에 있을 때 가능한 상·하한도 함께 계산한다.

목표는 **볼록 혼합**만이다. 가중치는 0.05 격자, 모두 0 이상,
합 1로 제한한다. 최선 기준은 3회차 EC 0.2055. 모든 반올림
가능성에서 0.001 이상 낮은 혼합이 있을 때만 후속 독립 검증
대상으로 삼는다. 그렇지 않으면 공식 점수만으로 새 혼합을
추천하지 않는다. 이 임계값은 계산 전에 고정한다.

이 계산은 같은 평가 집합의 집계 점수를 활용하며 사용자 허용 범위
안의 진단이다. 점수 기록이나 파일 정체성이 틀렸다면 결론도 틀린다.
비볼록 외삽, 구간별 점수 역산, 개별 평가 정답 추정은 하지 않는다.
새 제출 파일은 만들지 않는다.
