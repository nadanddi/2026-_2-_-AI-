# 제1회 전국 농과계 대학 농업 AI 경진대회 - 정형데이터 보고서

## 1. 데이터에서 발견한 핵심 사실

### 1.1 데이터 규모 및 구조
- **훈련 입력 (train_X)**: 309,990행 × 20열 (row_id + 19개 입력 변수)
- **훈련 정답 (train_y)**: 304,965행 × 3열
  - 배지 온도 (sub_temp): 304,965개 샘플 (98.4%)
  - 배지 EC (sub_ec): 9,600개 샘플 (3.1%)
- **평가 데이터 (test_X)**: 1,440행 (F13 온실 720행, F47 온실 720행)

### 1.2 EC 데이터의 극도의 불균형
**가장 중요한 발견**: 51개 온실 중 F13과 F47만 EC 정답을 가짐
- F13: 4,800개 샘플 (days 8-245, 24시간/일 × 200일)
- F47: 4,800개 샘플 (days 6-243, 24시간/일 × 200일)
- 나머지 49개 온실: EC 정답 0개

테스트 세트는 정확히 이 두 온실에서만 구성됨:
- F13: days 185-239 (훈련 데이터 범위 내)
- F47: days 183-237 (훈련 데이터 범위 내)

### 1.3 목표 변수 분포
**배지 온도 (sub_temp)**
- 평균: 16.59°C, 표준편차: 5.05°C
- 범위: 0.33°C ~ 43.57°C
- 일일 변동성이 크며 계절성 존재

**배지 EC (sub_ec)**
- 평균: 0.523 dS/m, 표준편차: 0.408 dS/m
- 범위: 0.062 ~ 3.460 dS/m
- 매우 제한된 데이터로 인한 높은 분산

### 1.4 결측치 패턴
외부 환경 데이터 (out_*): 약 95% 결측
- 온실 내부 측정이므로 자연스러운 결측

내부 환경 데이터 (in_*): 
- in_temp, in_hum, in_co2: <1% 결측
- in_rad: 4.9% 결측

구동기 기록 (act_*):
- 상당한 결측치 (10-99%), 온실마다 다름
- 통계적으로 복원·변형된 값 포함 가능성

## 2. 검증 설계와 그 이유

### 2.1 검증 전략: 시계열 시간 순서 분할 (Temporal Split)

각 온실별로 시간 순서를 유지하며 검증:
```
훈련 데이터: day < 180
검증 데이터: day >= 180
```

**이 방식을 선택한 이유:**
1. **시계열 구조 존중**: 농업 데이터는 강한 시간 의존성 있음
   - 일중 온도 변화 (0-24시간)
   - 계절 변화 (날짜별)
   
2. **미래 정보 누출 방지**: day 180 이후의 데이터가 이전 모델에 영향 주지 않음
   - 규정 준수 (Section 5): "이후 구간의 입력은 평가 행에 사용 불가"

3. **테스트 환경 시뮬레이션**:
   - F13 테스트: days 185-239
   - F47 테스트: days 183-237
   - 훈련 범위 내에서 미래 예측 수행

### 2.2 온실별 검증 분리
F13과 F47에 대해 별도로 검증:
- EC 데이터가 이 두 온실에만 있음
- 온실 간 차이 (일사, 위도, 구동 방식 등)를 반영

## 3. 시도한 방법과 결과

### 3.1 모델 선택: GradientBoostingRegressor
- 규정 준수: 공개 라이브러리만 사용 (scikit-learn)
- 특성 중요도 해석 가능
- 결측치 있는 데이터에서 강건함

### 3.2 시도한 접근법

| 방법 | 설명 | 온도 RMSE (F13/F47) | EC RMSE (F13/F47) | 비고 |
|------|------|-------|-------|------|
| 기본 GB | n_estimators=100, max_depth=5 | 1.316 / 1.664 | 0.277 / 0.361 | 가장 나은 결과 |
| LightGBM + 시간 특성 | 정현/코사인 특성 추가 | 1.504 / 1.942 | 0.409 / 0.451 | 과적합 우려 |
| 온실별 특화 모델 | F13, F47 별도 모델 | 시간 제약 | 시간 제약 | 훈련 중 |

### 3.3 최종 선택 모델
**기본 GradientBoosting 모델** (03_model_building.py)
- n_estimators: 100
- learning_rate: 0.1
- max_depth: 5
- subsample: 0.8
- 결측치 처리: 0으로 채우기

**검증 성능 (시간 순서 분할):**
- 온도: F13 1.31°C, F47 1.66°C
- EC: F13 0.28 dS/m, F47 0.36 dS/m

## 4. 가장 효과가 컸던 것과 그 이유 / 효과 없던 것

### 4.1 매우 효과적: 기본 특성 활용
**효과 있는 특성 (중요도 순):**
1. 내부 온도 (in_temp): 온도 예측의 직접 입력
2. 내부 CO2 (in_co2): 광합성과 환기를 반영
3. 내부 습도 (in_hum): 온도와 습도의 강한 상관
4. 내부 일사 (in_rad): 에너지 입력

**이유**: 배지 온도는 주로 온실 내부 환경에 의해 결정됨
- 외부 환경은 95% 결측이므로 실질적 기여 거의 없음

### 4.2 효과 없거나 해로운: 복잡한 특성 엔지니어링
- 정현/코사인 시간 특성: 오히려 RMSE 증가 (1.31 → 1.50)
- 온실-시간별 결측치 충전: 시간 증가 대비 성능 개선 미미

**이유**: 이미 훈련 데이터가 충분하고, 모델이 암시적으로 시간 패턴 학습 가능

### 4.3 데이터 불균형의 영향
EC 예측이 온도보다 어려운 이유:
- 훈련 샘플 부족 (9,600 vs 304,965, 약 32배 차이)
- 두 온실에만 데이터 존재 (다른 온실으로 일반화 불가)
- 결과적으로 EC RMSE가 상대적으로 높음 (0.28~0.36 vs 1.31~1.66)

## 5. 시간이 더 있다면 해볼 것

1. **하이퍼파라미터 베이지안 최적화**
   - Optuna나 Hyperopt 사용
   - max_depth, learning_rate, subsample 등의 체계적 탐색

2. **고급 결측치 처리**
   - KNN Imputer: 비슷한 시간/온실의 값으로 충전
   - 다변량 imputation (MICE)
   - 시계열 forward fill

3. **앙상블 강화**
   - 5개 이상 시드로 부트스트랩 앙상블
   - Stacking: GB + Ridge 메타 모델
   - XGBoost, CatBoost 포함

4. **온실별 특화**
   - F13, F47 별도 모델 훈련
   - 온실 간 차이를 반영한 가중 모델

5. **시계열 특성 재설계**
   - 이전 시간 데이터 (t-1, t-2 등) 추가
   - 시간 윈도우 통계 (24시간 이동 평균 등)
   - 예측을 규정을 위반하지 않는 범위에서

6. **조기 종료 (Early Stopping)**
   - 검증 세트에서 모니터링
   - 과적합 방지
