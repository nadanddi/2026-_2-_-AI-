# C1 실행 전 계획 비평 기록

이 문서는 결과 열람 전에 대화로 전달한 PLAN_v1 비평을 보존한 것이다. 작성 시점에 결과는 아직 없으며 재설계나 사후 기준 변경을 요청하지 않는다.

결론: C1 실행 계획에서 중단할 결함은 발견하지 못했다. realg/realn은 계수 학습에 사용하지 않지만 원본 H2 문턱 보정에는 사용한다는 RULES_v2 보완이 정확하다. 완전 평가 전용으로 표현하지 않는다.

- G판1800장의 source/group는 원본과 동일하게 유지하고 모든 파생본을 같은 폴드에 둔다.
- GPT 치수 pool은 값뿐 아니라 순서와 SHA도 고정한다. 원본보다 큰 목표 치수도 가능하므로 항상 축소라고 설명하지 않는다.
- E_f 계수와 그 문턱만 변경한다. 다른 전문가 점수/문턱 및 게이트 밖 출력은 불변 검산한다.
- filter 손실은 정답→놓침 전이 수이며 다른 행의 개선으로 상쇄하지 않는다.
- newreal/realg/realn FP 감소는 θ 보정에 사용한 자료의 개선으로 독립 일반화 증거가 아니다.
- h3j 게이트 밖 진짜가 θ 풀에 들어가는 H2의 기존 한계는 유지한다. 이번에 풀 정의를 바꾸면 별도 실험이 된다.
- 실패 시 후속 수정 없이 종료한다. 통과할 때만 이미 허용된 패키지 제작/검증 단계로 진행한다.

계획 승인 범위는 위 절차에 따른 탐색 실행이다. 후보 성능 통과나 제출 완료를 뜻하지 않는다.
