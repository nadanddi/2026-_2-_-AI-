# A2 실행 전 계획 비평 기록

이 문서는 결과 열람 전에 대화로 전달한 PLAN_v2 비평을 보존한 것이다. 결과는 아직 없으며 재설계나 사후 기준 변경이 아니다.

결론: 사용자 지정 D1분기 A2, 나단9에 전문가 하나 추가, C1 혼합 금지를 지킨다. 첫 샘플 추출 전에 토큰/마스크 정렬과 원래 출력 불변 검사가 필요하다는 조건으로 진행 가능하다.

- transformer 출력 축을 확인하고 CLS 제외196개 token이 행 우선14x14인지 검산한다. ln_post가 전체 token에 적용되는 실제 구현을 확인한다.
- 사진과 마스크 해상도/방향,54개224px조각의 좌표/순서가 일치해야 한다. 마스크를0~1로 정규화하고16x16셀 평균≥.3 양성, 정확0 음성, 중간 제외를 고정한다.
- 중첩 조각의 반복 token은 독립 사진 수가 아니다. 사진별32음성/64양성 표집은 결과와 무관한 고정 RNG로 수행한다.
- scaler/LR는 각 fold의 학습 사진 token만 사용한다. θ용 OOF 사진 점수는 표집 token이 아닌 전체54x196 token 최댓값이다. fold별 양/음성 및 양성token0개 사진 수를 확인한다.
- 새 backbone pass가 없어도 ln_post/표준화/선형점수/중간출력 비용은 추가된다. 추가비용0으로 설명하지 않으며 T4 실측이 필요하다.
- 전체 token max는 오탐에 민감하다. 사진 단위 θ와 최종 신규오탐 기준을 사용하고, 결과 후 평균/상위분위 집계로 변경하지 않는다.
- h3j는 계수학습에 포함하되 게이트 밖 θ풀에서는 제외한다. 단일θ, 보정자료 비독립성, 수치실패 시 변형 없이 종료하는 조건을 유지한다.

이후 정적 구현 검토에서 저장소 vit.py는 실제 전체[N,197,768]에 ln_post를 적용함을 확인했다. 이는 계획상 정렬 확인의 일부이며 GPU 실행검사 자체를 대신하지 않는다.
