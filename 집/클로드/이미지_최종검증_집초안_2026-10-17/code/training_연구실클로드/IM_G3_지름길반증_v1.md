# G3 지름길 반증 실험 (2026-10-13 저녁, 결과 보기 전 등록)

## 질문
G3a(GPT 250장 학습)가 v3를 잘 잡는 것이 진짜 "GPT 생성 흔적" 때문인가? 아니면 **처리 경로**(원본 크기·축소 배율·무손실 PNG에서 출발) 때문인가?

## 자료 (모두 학습에 쓰지 않음, `im28_shortcut_sets.py`)
- **v3R** (200장): v3 PNG를 진짜 사진 경로로 바꾼다.
  - AI허브 원본 크기 분포에서 무작위로 뽑은 긴 변에 맞춰 LANCZOS로 확대 → JPEG Q90(카메라 저장 흉내) → 배포 처리(덮게 축소·크롭·Q92)
- **realN** (300장): 원본2·원본3 진짜(학습에 쓰지 않은 AI허브 사진)를 보통 배포 처리한다.
- **realG** (300장): 같은 진짜를 GPT 경로로 바꾼다.
  - GPT v3 출력 크기 분포에서 뽑은 긴 변으로 축소 → PNG(무손실) → 배포 처리

## 비교
- 모델: A(제출 01 구성)와 G3a를 `IM_GPT학습_G3_v2.md`와 같은 방식으로 쓴다(농장 5폴드, 시드 0/1/2, 시험 세트는 폴드 모델로 예측).
- 진단용 실험이므로 이미 본 시드를 써도 된다.

## 판정 (시드 3개 중 하나라도 걸리면 '지름길 있음')
- **S1 (경로를 바꾸면 효과가 사라지나):** 아래 둘 중 하나라도 해당하면 지름길이다.
  - G3a의 v3R 탐지율 < v3 탐지율 − .10
  - CLIP 단독 AUC(v3R 대 OOF 진짜) < v3 기준 − .03
- **S2 (진짜도 GPT 경로면 가짜로 보나):** G3a의 (realG 오탐 − realN 오탐)이 A의 같은 차이보다 .03 넘게 크면 지름길이다.
- 결과 해석
  - 지름길 없음 → G3c 등록으로 진행한다.
  - 지름길 있음 → GPT 자료를 진짜 경로로 처리해서 학습하는 안을 별도로 등록한다.
