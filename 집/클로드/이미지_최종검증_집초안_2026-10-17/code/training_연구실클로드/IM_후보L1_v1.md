# 후보 L1: 원본 대조 특징 결합 (2026-10-12, 결과 보기 전 고정)

## 근거
- 공개 21장을 AI허브 152,043장 지문 DB(IM11)와 대조했다(IM12).
  - 실제 2/3은 원본과 거의 같았다(1.4).
  - 가짜 5장은 원본은 찾았지만 변형돼 있었다(d1 4~16, 간격 5~12).
- 학습 자료 분포(IM13, 공개 미사용): 원본이 없는 실제는 간격이 작다(95% ≤ 8.06). 원본이 있는 변형 가짜는 간격이 크다.

## 정의
- 특징(지문 12x16 RGB, 같은 방향만): d1, d2, 간격 = d2 − d1, log(d1), log(간격 + .1).
- 결합 모델: 로지스틱(표준화). 입력 = [logit(stack OOF 확률), 위 특징 5개, 상호작용 logit×log(간격+.1)].
  - stack = 기준(CLIP + 저수준 평균), 기존 OOF/전체 학습 그대로.
- **실제 사진의 1/3**(원본 파일 단위로 고정 난수)은 자기 원본을 DB에서 뺀 상태로 특징을 계산한다(원본 없는 평가 실제 모사).
  - 가짜는 원본 포함(우리 가짜의 원본은 모두 AI허브).
- 평가: 같은 농장 그룹 5겹 OOF, 시드 3개.
  - 지표: 균형 정확도(실제 정답률 0.5 + 공개 6유형 탐지 평균 0.5)
  - 실제 오탐을 '원본 있음 / 원본 없음'으로 나눠 따로 본다.
- 공개 21장: 이번 규칙 설계에 이미 봤으므로 **참고 서술만** 한다.

## 판정
- 채택 후보 조건(로컬)
  - OOF 균형 정확도가 시드 3개 모두 기준보다 높다.
  - '원본 없는 실제' 오탐이 기준보다 2%p 넘게 늘지 않는다.
- 최종 판정은 리더보드(사용자 결정).
