평가: im05g, 계획 v3 규칙 + **한 번에 5개 비교, 본페로니 문턱 .025/5 = .005**.
- 공개 21장 열람은 이 묶음 전체로 1회다(상한 초과 → 사용자 지시로 진행, 기록).

## 계획 비평 반영 (실행 전, 10-11)
- D4 내부 3겹을 농장 그룹 단위로 바꿨다(치명-1).
- **D0 대조군 추가**(치명-2): stack + 단일 문턱(학습 폴드 안, 농장 그룹 내부 OOF에서 실제 오탐 5%) → sigmoid(logit p − logit τ). 후보 6개, 문턱 .025/6 = .0042.
- D3은 OOF Platt 보정 뒤 저수준과 평균(중요-4). D1 중간층 CLS는 l2 없이 표준화만(경미-7).
- 기록
  - D5 성분에 D4는 넣지 않았다.
  - 공개·빨강 예측은 90% 부분표본 모델에서 나온다(제출 모델은 100% 학습).
  - 보조 세트는 공개 유형 라벨로 최근접을 고른다.
- **대체 결정(사전 고정)**: 전부 불채택이면 stack을 유지하고 묶음 D를 종료한다. 수치가 좋아 보이는 안을 골라 쓰지 않고, 공개 21장도 다시 보지 않는다.
  - 채택안이 여럿이면 p_worse 최소 1개만 리더보드 후보로 넘긴다.
- 제출 시 할 일: 조각 수 고정(1024×768·768×1024 외 해상도 대비), openclip 시각부만 fp16으로 떼어 저장, T4 실측.
