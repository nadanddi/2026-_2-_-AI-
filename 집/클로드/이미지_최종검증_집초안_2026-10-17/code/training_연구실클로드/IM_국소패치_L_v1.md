# 후보 L: 마스크 지도 국소 조각 판별기 (2026-10-14, 결과 보기 전 등록)

## 목적
- 부분생성·부분스타일(사진의 작은 일부만 바뀐 가짜)을 잡는다.
- 지금 모델은 9조각 평균이라 작은 편집이 희석된다(D1 진단: 마스크 넓이에 따라 AUC가 단조로 변함).

## 조각 판별기
- 격자: 배포 형식 사진(768×1024 또는 1024×768)에서 224px 창을 112px 간격으로 → 6×9 = 54조각.
- 특징: open_clip **ViT-B/16 (openai)** 이미지 임베딩, 조각마다 L2 정규화. T4에서 524장 × 54조각이 5분 안에 들어가도록 가벼운 모델을 골랐다.
- 조각 라벨
  - 가짜(1)
    - 6판 부분생성 · 5판 partial_style_xl에서 마스크가 조각의 25% 이상을 덮는 조각 (마스크는 생성 시드로 재현, 기록된 area와 대조해 검산)
    - GPT 학습용 부분 편집에서 원본과의 차이 마스크가 25% 이상 덮는 조각
    - GPT 전체생성·전체스타일 조각 전부(사진당 12개 무작위)
  - 진짜(0)
    - 진짜 사진 조각(사진당 12개 무작위)
    - 위 부분 편집 가짜에서 마스크와 겹침 0인 조각(사진당 6개 무작위, 되붙임판이라 원본 픽셀)
  - 0 < 겹침 < 25%인 조각은 학습에서 뺀다.
  - 그 밖의 가짜 유형(합성·필터 등)은 조각 학습에 쓰지 않는다. 이미지 판정에는 그대로 들어간다.
- 분류기: 표준화 + 로지스틱(C=.05). 진짜와 가짜 조각의 가중 합을 같게 맞춘다.
- 이미지 점수: 조각 확률의 최댓값 `top1`.

## 결합 규칙 (학습형 메타 없음, 고정 규칙)
- `p = L2규칙(p_A)`. 그다음 `top1 ≥ θ`이면 `p ← max(p, .9)`.
- θ: OOF 진짜 사진 가운데 `p_A`로는 진짜(<.5)인데 `top1 ≥ θ`로 뒤집히는 비율이 **1.0%**가 되는 값.
  - 시드 3개에서 구한 값의 평균 하나를 쓴다.
  - 리더보드는 쓰지 않는다.

## 검증
- 자료 B(v4 + SD2 + 5판) + 6판 + GPT. 농장 5폴드 × 시드 0/1/2.
  - 조각 판별기는 폴드 학습분으로만 학습한다.
  - A의 OOF는 기존 구성 그대로 쓴다(6판·GPT는 A 학습에 넣지 않는다).
- **GPT 학습/검증 분할:** 부분생성·부분스타일(v1 + v2, 200장)을 농장 코드 crc32 % 2로 나눈다.
  - 검증용 절반은 어떤 폴드에서도 학습에 쓰지 않는다.
  - GPT 전체생성·전체스타일 50장은 학습용으로 쓴다.
  - 이 200장은 D1c·D1d에서 한 번 본 표본이다. 두 안 모두 불채택이라 이 표본에 맞춘 선택은 없었다.
- **추정 정확도:** `.5 × (1 − 진짜 오탐) + .5 × 6유형 평균 탐지`
  - 부분생성·부분스타일 탐지는 GPT 검증용에서 잰다.
  - 나머지 4유형은 우리 자료 OOF에서 잰다.

## 판정 (안 1개, α=.025, 시드 3개 **모두**)
1. GPT 검증용 부분생성 + 부분스타일 탐지율 > A
2. 추정 정확도 > A
3. 진짜 오탐 ≤ A + .012
4. 추정 정확도 차에 농장 단위 짝 부트스트랩(GPT 검증용 + 진짜 + 우리 가짜 행, 시드 평균, 2000회) → p_worse < .025
