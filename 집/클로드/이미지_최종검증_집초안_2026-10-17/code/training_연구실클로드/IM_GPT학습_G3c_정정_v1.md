# G3c 정정 (2026-10-13 밤, 결과 열람 전, 계획 비평 반영)

`IM_GPT학습_G3c_v1.md`는 고치지 않는다. 아래 사항을 결과를 보기 전에 덧붙인다.

1. **판정 3(진짜 오탐 ≤ A + .005)은 '확인용'으로 둔다.**
   - τ를 오탐률이 같아지도록 정하므로 구조상 거의 자동으로 통과한다. 통과해도 근거로 세지 않는다.
   - 판정 1·2·4·5는 그대로다. 실제로 가르는 조건은 판정 4(GPT 외 균형 ≥ A − .003)다.
2. **G3c2는 새 시드로 다시 돌린 G3a + τ다.**
   - 판정 1·2·5는 G3a에서 이미 통과한 내용의 반복이다.
3. **제출 시 τ 구현을 고정한다.** 후보가 되어 제출할 때 아래를 쓴다.
   - 출력 확률은 단조 구간선형 변환 g를 거친다: p < τ이면 .5·p/τ, 아니면 .5 + .5·(p − τ)/(1 − τ). 그러면 g(τ) = .5다.
   - 최종 모델의 τ = **최종 모델(전체 학습)로 OOF 진짜 확률의 분위수를 다시 계산하지 않고**, 시드 3·4·5 교차적합 τ의 평균을 쓴다.
   - 척도 차이 위험은 적어 둔다.
4. **결과와 함께 추가로 볼 진단**(판정과 무관)
   - τ > .9인 폴드 수(L2 규칙의 .9 고정과 겹치는지)
   - 공개 logloss는 원확률 기준과 g(p) 기준을 모두 본다.
