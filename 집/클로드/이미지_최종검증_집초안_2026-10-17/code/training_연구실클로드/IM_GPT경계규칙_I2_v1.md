# IM 후보 I2 — GPT식 재그리기 경계 규칙 (실행 전 등록 2026-10-15 15:35)

- 규칙(고정): 5 < dg1 < 20 그리고 0.35 ≤ p < 0.5 → p = 0.55
  - p = 나단8 출력, dg1 = 정밀 지문 1위 거리
  - 구간은 gpt3 놓친 9장을 보고 정했다(과적합 위험, 비평 지적). 그래서 가짜 쪽 효과는 참고만 한다.
- 판정은 진짜 쪽 위험으로만 한다(im52_gpt_rule_sim.py)
  - 진짜 = R3 진짜 429 + 봉인 진짜 750
  - 원본 제외 대조 시나리오 3가지
    - (a) 자기 원본만 제외
    - (b) 자기 원본 + 같은 묶음 ±3프레임 제외
    - (c) 같은 묶음 전체 제외
  - p는 정밀 대조를 끈 나단8 p(원본이 없으면 정밀 대조가 발동하지 않으므로)
- 기준(모두): 시나리오 (b)·(c) 진짜 발동률 ≤ 0.5%, 그리고 gpt3 가짜 고침 장수 > 진짜 예상 오탐 장수(262 × 발동률)
- 미달이면 규칙을 버린다. 통과해도 새 봉인 R4의 GPT 가짜가 없으므로 "탐색적"으로만 표시한다.
