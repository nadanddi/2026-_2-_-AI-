# 후보 G: GPT 생성·편집 가짜 추가 (2026-10-13, 결과 보기 전 등록)

자료: 연구실 코덱스가 GPT 내장 imagegen으로 만든 100장(`연구실/코덱스/local/ai_gen_work_20261013_v1/`, 유형마다 25장, 편집 75장은 원본 75개 중복 없음, 9개 농장).
- 1_전체생성 → AI_gen, 2_전체스타일 → full_style, 3_부분생성 → partial_gen, 4_부분스타일 → partial_style.
- 배포 형식 변환(`im21_gpt_set.py`): 덮게 축소(가로는 1024×768, 세로는 768×1024) → 가운데 크롭 → JPEG Q92 4:2:0. 원래 PNG는 손대지 않음.
- 묶음(폴드) 키: 편집 = 원본의 AI허브 농장 코드(C번호, 기존 자료와 같은 규칙), 전체생성 = `GPTGEN` 한 묶음.

기준: **A = 제출 01 구성(B2 9조각 + 저수준, 자료 B = v4 + SD2 + 5판, 모두 +L2)**, GPT 행은 학습에서 뺀다(예측만 받음).

| ID | 변경 |
|---|---|
| G1 | GPT 100장을 학습에 그냥 추가(기존 가중 규칙: 유형마다 같은 몫 → GPT 몫은 유형 안에서 장수 비례, 아주 작음) |
| G2 | G1 + GPT 가중 상향: 각 유형 안에서 GPT 행 합계 몫 = 25% |

평가: 서버, im05o와 같은 방식(시드 0/1/2, 같은 농장 폴드, 90% 부분표본 모델로 공개 예측). 모든 지표에 L2 덧씌움.
- 지표: GPT 가짜 OOF 탐지율(전체·유형별), 실제 OOF 오탐, GPT 외 OOF 균형 정확도, 공개 21장 정확도·로그손실.
- 판정(시드 3개 **모두**):
  1. GPT 가짜 OOF 탐지율 > A
  2. 실제 OOF 오탐 ≤ A + .01
  3. GPT 외 OOF 균형 정확도 ≥ A − .003
  4. 공개 로그손실 ≤ A
  → 넷 다 만족하면 다음 제출 후보. 둘 다 만족하면 GPT 탐지율이 높은 쪽.
- 진단(판정과 무관, 먼저 보고): A가 GPT 100장을 유형별로 몇 % 잡는지. 이미 거의 다 잡으면 GPT 자료의 추가 가치는 작다.
- 한계: 운영진 생성기가 GPT 계열인지는 모른다. 100장은 작아 GPT 탐지율은 시드·폴드 잡음이 크다(25장 유형에서 1장 = 4%p).
