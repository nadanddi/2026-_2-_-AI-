# 후보 D1d: D1c + 오탐 맞춤 임계값 (2026-10-13 밤, 결과 보기 전 등록)

## 근거
`IM_부분생성_D1c_v1.md` 결과(서버 `logs/D1c_eval.log`)
- 가려내는 힘은 확실히 늘었다: GPT 부분생성 125장 대 실제 AUC가 시드 3개 모두 상승, +.018, p_worse .0035.
- 그런데 판단 기준(.5)이 그대로라 실제 점수도 함께 올라 불채택됐다.
  - 실제 오탐 +1.0~1.4%p
  - 균형 정확도 −.004~−.005
- 질문: 실제 오탐을 A와 같게 맞추는 임계값을 쓰면 전체 정확도가 A보다 나은가.

## 안
- **D1d:** D1c 모델(6판 넓이 ≥10% 추가) + 임계값 τ.
- τ는 **OOF 실제 사진(L2 적용 후)의 오탐률이 A의 시드 평균 오탐률과 같아지는 값**이다. 시드 3개에서 구한 값의 평균을 하나로 쓴다.
- 리더보드 점수는 쓰지 않는다(규정 5 해석 준수). L2 규칙(p ≥ .9로 올림)은 τ와 무관하게 그대로 둔다.

## 판정
- 누적 안 4개 → α = .025 × 2/4 = **.0125**.
- A(.5) 대비 시드 0/1/2 **모두**에서 아래를 만족하면 후보:
  1. GPT 외 OOF 균형 정확도(τ) > A
  2. GPT 부분생성 125장 탐지율(τ) > A
  3. 실제 오탐(τ) ≤ A + .005
  4. 농장 부트스트랩(GPT 부분생성 + 실제 행, 시드 평균 예측)으로 본 '탐지율 − 오탐률' 차의 p_worse < .0125
- 한계: τ를 같은 OOF에서 정하므로 약간 낙관적이다. 시드 평균 τ 하나만 쓰는 것으로 그 영향을 줄인다.
