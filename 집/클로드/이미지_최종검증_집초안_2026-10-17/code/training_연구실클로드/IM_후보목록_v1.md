## 제약
- 제출 용량 1GB: CLIP L/14 시각부 fp16 약 0.6GB + ResNet18 45MB + 저수준 모델 수 MB → 들어감. DINOv2-B를 더하면 약 0.17GB 추가.
- T4 5분/524장: CLIP 10보기 + CNN 20패치 + 저수준(CPU 0.2s/장 → 4장 병렬 약 30초) → 추정상 여유 있음. 패키지를 만들 때 실측한다.

  - 공개 21장 열람 1회 사용(남은 상한 2: C7, B).
- **평가 v4(진짜 시드 변동)의 기준 stack**: 공개 18/14/16(시드별), AUC 1.00/1.00/.98, 실제 오탐 0. → 앞선 '17/21'은 잡음 범위 안의 값이다.
- **진단(판정 아님)**
  - 공개 21장에서 실제 최대 .16~.19 < 가짜 최소 .19~.20이다. 오답은 모두 '0.5 미만 가짜'다.

  - 우리 실제 오탐 상위는 **자연 흐림·흔들림·잡음 사진**이다. 문제설명서는 "촬영 과정의 흔들림·초점 흐림·센서 잡음만으로 라벨 1이라 단정하지 않는다"고 명시한다 → 평가 실제에도 있을 것이다. 공개 21장으로 문턱을 낮추는 안은 채택하지 않는다.
- **다음 후보 아이디어(열람 상한 때문에 사용자 확인 필요)**
