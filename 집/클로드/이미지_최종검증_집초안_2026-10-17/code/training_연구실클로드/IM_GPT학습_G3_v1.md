# 후보 G3: GPT 가짜 학습 추가 → 처음 보는 GPT v3로 판정 (2026-10-13, 결과 보기 전 등록)

## 질문
GPT로 만든 가짜(v1·v2 250장)를 학습에 넣으면, **GPT식으로 사진 전체를 다시 그린 처음 보는 가짜(v3)**를 진짜 오탐 증가 없이 더 잡는가.

## 근거
- 제출 01은 v3 1단계(사진 전체 사실적 재그리기)를 .5 기준에서 38%만 가짜로 판정한다.
- 반면 원본3 진짜 대비 AUC는 .90이다. 점수가 진짜보다 높지만 .5 아래에 몰려 있다.
- G1·G2(`IM_GPT가짜_v2.md`)가 던진 질문은 "GPT를 학습하면 SD 계열 가짜를 잡나"였고 불채택이었다. 이번 질문은 그와 다르다.

## 자료
- 학습 추가: `im_set_gpt1`(100) + `im_set_gpt2`(150)
  - 유형: 전체생성 → AI_gen, 전체스타일 → full_style, 부분생성 → partial_gen, 부분스타일 → partial_style
- 시험대: `im_set_gpt3` = 코덱스 v3(`ai_gen_work_20261014_v3`) 전량. 어떤 안에서도 학습에 쓰지 않는다.
  - 최종 부분생성 100 → partial_gen, 최종 부분스타일 50 → partial_style
  - 1단계 재그리기 50 → full_style(진단용 분류)
  - 배포 형식 변환은 im21과 같다. 농장 키는 원본3 목록의 C번호다.
- **v3 생성이 끝난 뒤 한 번만 실행한다.**

## 안 (2개 → 본페로니 α=.0125)
- A: 제출 01 구성(B2 + 저수준, 자료 B = v4 + SD2 + 5판, +L2). GPT는 학습에 쓰지 않는다.
- G3a: A + GPT 250장(기존 가중 규칙)
- G3b: G3a + 유형 안 GPT 몫 25%

## 평가
- 농장 5폴드 × 시드 0/1/2. v3 행은 자기 농장이 빠진 폴드 모델로 예측한다(학습에는 원래 쓰지 않음).

## 판정 (A 대비, 시드 3개 **모두**)
1. v3 전체(최종 + 1단계) 탐지율(.5, L2 후) ≥ A + .05
2. 진짜 OOF 오탐(L2 후) ≤ A + .01
3. GPT 외 OOF 균형 정확도 ≥ A − .003
4. 농장 단위 짝 부트스트랩(v3 행 + 진짜 행, 시드 평균 확률을 .5로 판정)으로 본 '(v3 탐지율 − 진짜 오탐)' 차의 p_worse < .0125
- 둘 다 후보면 v3 탐지가 높은 쪽.

## 진단 (판정과 무관)
- v3를 최종 부분생성, 최종 부분스타일, 1단계로 나눈 탐지율
- 편집 종류별 탐지율(기록에 있으면)
- v3 대 진짜 AUC
- 공개 21장
- 유형별 탐지
