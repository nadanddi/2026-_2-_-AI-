## ⑤ 후처리 (임계값·확률 보정·앙상블)

계산 순서와 값은 다음과 같습니다(`inference.py`, `model/config.json`).
- 아래 수치 문턱과 θ는 학습 자료나 봉인 검증 묶음에서 정했습니다. 리더보드 점수로 계산한 값은 없습니다.
- 다만 형식 게이트의 기준(JPEG 4:2:0, 품질 92)은 공개 샘플 21장의 실측에서 왔습니다.
- 공개 점수를 어디에 썼는지는 이 절 끝 "공개 점수 사용 범위"에 적었습니다.

1. **기본 확률:** `p = (p_의미 + p_저수준)/2` (0.5/0.5 고정 평균).
2. **원본 대조 R1:**
   - 조건: 1위 거리 3.5 < d1 < 20, 1·2위 차 gap > 8, p ≥ 0.25
   - 조건을 모두 만족하면 `p ← max(p, 0.9)`
   - 근거(학습 자료 분포): 원본 있는 실제의 d1 99분위 3.29(축소·재확대 대조군 3.72), 이웃 프레임만 있는 실제의 gap 95분위 8.06
3. **전문가 E_pg·E_ps·E_L:**
   - `g(s) = 0.5·s/θ` (s < θ) 또는 `0.5 + 0.5·(s−θ)/(1−θ)`, `p ← max(p, g)`
   - θ = 0.7262 / 0.8969 / 0.99908
   - 근거: 농장 5겹 교차 예측에서 기본이 실제로 본 실제 사진의 0.4%만 뒤집는 값(시드 3 × 5폴드 평균)
4. **정밀 원본 대조 F:**
   - 원본 판정: 1위 ≤ 1.011, 1·2위 차 ≥ 3.474
   - 가짜 확정: 국소 차이 loc_g > 6.569 또는 loc_e > 52.95 → `p ← max(p, 0.95)`
   - 진짜 확정(rc): loc_g ≤ 3.933, loc_e ≤ 24.24, |glob_e| ≤ 13, p < 0.8 → `p ← min(p, 0.3)`
   - 근거: 학습용 실제 사진을 축소 방식 4종·JPEG 70~95로 흔든 1,500장의 분위수(99.5%·99.9%·95%)
5. **전문가 H2(E_f·E_ps2·E_g7)와 E_gr:**
   - 형식 게이트 안에서만 `p ← max(p, g(s, θ))`
   - θ = 실제 풀에서 실제를 0.25%만 뒤집는 분위. 진짜 확정 사진은 더 엄격하게 0.1% 분위(`config.json` "h")
6. **E_gpt:**
   - 형식 게이트 안이고 진짜 확정이 아닐 때만 `p ← max(p, g(s, 0.9073))`
   - θ = 실제 풀 0.25% 분위
7. **판정:** 별도 임계값 없이 운영위원회 기준 0.5 그대로. 확률 보정은 없습니다.
8. **예외 대체:** 저수준 실패 → 의미 갈래만, CLIP 실패 → 저수준만, 둘 다 실패나 NaN → 0.5, 원본 대조·전문가 실패 → 그 단계 미적용.

### 공개 점수 사용 범위 (사실대로)
- 공개 점수로 문턱·θ·가중을 계산하거나 모델을 고치지 않았습니다.
- **제출 후보끼리 비교:** 판마다 미리 만든 후보를 제출하고, 공개 점수로 어느 판을 유지할지 골랐습니다(주최 측 10/5 추가 안내: 제출끼리 비교 허용).
  - 나단8·9·11은 사전 기준 일부를 채우지 못한 채 낸 가설 검증 제출입니다.
- **마지막 선택은 사전 규칙과 달랐습니다.**
  - 사전 규칙: 마지막 날 후보의 Accuracy가 0.98 이상이면 유지하고, 아니면 나단9로 돌아가 다시 제출합니다.
