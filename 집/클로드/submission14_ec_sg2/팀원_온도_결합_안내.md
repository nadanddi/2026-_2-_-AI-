# 팀원 온도 결합 안내 (submission_14)

이 EC 전달본의 `sub_temp`는 사용자 지시로 비어 있습니다. 모델을 다시 실행해도 온도 빈칸 CSV가 만들어집니다.

팀원 온도 결과가 준비되면 다음 명령으로 합칠 수 있습니다.

```
python merge_temperature.py --temperature 팀원온도CSV --ec submission_14.csv --output 새합본CSV
```

- row_id 1,440개 집합이 같은지 확인하고, EC 답안의 행 순서를 유지합니다.
- 양쪽 숫자 문자열을 그대로 복사합니다.
- 기존 파일은 덮어쓰지 않습니다.
- 온도 모델을 다시 학습하지 않습니다. 최종 답안으로 낼 때는 팀원 온도 모델과 이 EC 패키지를 함께 묶은 재현 자료와 합본 검산이 별도로 필요합니다(운영 안내 2026-10-05 5·6절: 제출마다 코드·모델·설정 보관).
- 플랫폼 업로드는 하지 않습니다.
