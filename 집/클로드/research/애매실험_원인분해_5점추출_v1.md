# p값이 애매했던 실험: 원인 분해와 5점 발표용 추출 (2026-10-16 집 클로드)

- 근거: 카탈로그와 각 실험 로그, 그리고 EC는 저장된 OOF로 날짜별 SSE 변화를 다시 계산했습니다.
- 분해는 에이전트 두 개가 나눠 했고, 정리는 제가 했습니다.

## 3. 5점 발표에 쓸 수 있는 것 (추출본)

### 3-1. 데이터가 문턱을 정한 사례
- **추위 문턱 재발견(STK4, 7.017):** 사람이 정한 "실내 8~10℃ 아래면 TabPFN을 끈다"를 데이터가 학습하게 했습니다. 데이터도 약 8.5℃(다른 그룹은 10~11℃)를 골랐습니다.
- **TX3 보정량(7.026):** 사람이 정한 보정(+.25℃, 10℃ 아래)을 데이터가 다시 고르게 했습니다. 데이터는 더 강한 보정(+.5℃, 14℃ 아래)을 골랐고 12칸 모두 좋아졌습니다. 범위를 더 넓히자 다른 배치가 나빠져서(7.027) 상한을 두었습니다.
- **학습 범위 밖 판단(OOD1, 7.025; STK2·3):** "학습해 본 온도보다 얼마나 추운가"를 넣으면, 두 독립 그룹이 같은 곡선을 학습했습니다. 학습 최저보다 2℃ 아래면 외삽에 안정적인 모델로 60%, 5℃ 아래면 95% 옮기는 곡선입니다.

### 3-2. 현장에서 성립하는 물리·운영 관찰
- **배지의 열관성:** 같은 동이면 자정에 공기 온도가 튀어도 배지는 따라가지 않았습니다(기울기 ≈ 0, DTC1). 그래서 "어제 저녁 배지 → 오늘 새벽 배지"가 가장 강한 정보입니다. 반영 곡선(시정수 약 4~8시간)도 데이터가 학습했습니다.
- **난방과 배지−공기 차:** 배지−공기 온도 차는 난방을 켰을 때 0.5~1.0℃, 껐을 때 1.8~2.9℃였습니다.
- **EC의 지속성:** 배지 EC는 하루를 넘어 이어집니다. 전날 저녁 값을 출발점으로 쓰면 0시 오차가 15~21% 줄었습니다. 한 시각보다 저녁 여러 시각 평균이 과잉 보정을 줄였습니다.
- **운영 순서와 EC(DP1):** 그 시각까지의 밀폐 지속, 첫 환기 시각, 커튼 전환 수, CO₂ 공급 시간처럼 제어기 기록으로 만든 특징이 2차 구간 EC 오차를 2~6% 줄였습니다.
- **밀폐 중 습도 누적과 EC(H20):** 밀폐 중 실내 절대습도가 쌓인 날은 모델이 EC를 낮게 보는 경향이 있었습니다(두 온실 같은 방향). 물리 해석은 일반 지식에 기댄 추론이라고 표기합니다.

### 3-3. 실패에서 얻은 일반 교훈
- **추운 외삽 위험:**
  - 학습에 비슷한 날이 없는 추위로 학습형 모델(GRU)을 넓히자 한 검증에서 오차가 6.5% 늘었습니다.
  - 6℃ 이하에서는 배지와 공기의 관계가 이른 철과 늦은 철에 정반대였습니다. 그래서 보정하지 않고 안전한 쪽을 택했습니다.
  - 추운 날 학습 가중을 높여도 더 추운 날 예측은 좋아지지 않았습니다.
- **오늘 입력의 한계:** 그날 배지 수준은 그날 공기 센서로는 드러나지 않았습니다.
  - 51개 온실 모두에서 입력 요약의 설명력이 음수였습니다.
  - 공기 열수지 잔차로도 하루 전체 기준 R² −.03이었습니다(PHY1).
  - 그래서 "어제 상태"를 쓰는 구조를 택했습니다.
- **학습형 섞기의 불안정:** 구성원 예측끼리 상관이 .77~.92로 높아서, 자유롭게 학습한 비중은 자료 절반만 바뀌어도 뒤집혔습니다. 일관되게 학습된 것은 "범위 밖이면 외삽 안정 모델" 하나였습니다.
- **목적 분리:** 드문 고EC를 잘 잡게 모델을 키우면 일반 날이 9% 나빠졌습니다. 경보 목적과 일상 관리 목적은 따로 다뤄야 합니다.
- **검증 원칙:**
  - 모든 칸이 0.2%씩 좋아진 작은 신호가 새 검증 묶음에서는 재현되지 않았습니다.
  - p .037로 통과한 안이 확인 시험에서 뒤집혔습니다.
  - 그래서 채택은 새 자료로 한 확인 시험이나 사전 고정한 묶음 판정을 통과한 것만 했습니다.
  - 오차가 소수 날에 몰려 있어(EC 상위 5일 = 53%) "상위 날을 뺀 뒤에도 유지되는가"를 함께 봤습니다.

### 3-4. 발표에 쓰면 안 되는 것
- 기록 사이 전날 연결(링커)과 여러 링커 일치(TAG1)
- 기록 번호 순서, 완충일
- ±3일 미래 이웃 정답(SG2·HG), DC7 계절 쌍둥이
- 표를 보고 고른 상한값(HG4 1.8, EM1 문턱), 농장 코드별 계수
- 현장 설명에서는 연결을 "연속 측정의 마지막 값을 이어 쓴다"로 바꿔 말합니다.

## 4. 다시 시험할 것 (원인을 피하는 설계)
1. **TX3L 확인 시험:** 상수를 c .5·T0 14·e0 1.0으로 고정하고, 고를 때 안 쓴 N·CK2·CV8 배치로 판정합니다. 사전 조건에 "상위 3기록 제외 후 유지"를 넣습니다.
2. **EC 묶음:** DP1 운영 순서 + HG4 과거 정답판(이웃은 과거만, 상한은 1차 자료로 고정) + H20 한 열을 하나로 묶어 판정합니다. 사전 조건은 두 가지입니다. F47_229·231을 빼도 개선이 유지될 것. F47_210 손해에 상한을 둘 것.
3. **온도 묶음:** TX3L + TAG2(현장형, 대체 PASS) + OOD1을 묶습니다. 서로 다른 행에 작용합니다(8~14℃ 고EC / 연결 기록 / 범위 밖 추운 행). 다만 OOD1은 검증기로 확정할 수 없습니다.
