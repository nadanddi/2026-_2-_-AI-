# 0시 보정 모델 '다 넣기' 계획 v2 (2026-10-12 집 클로드) — 비평 전 초안

## 목표
기록마다 0시 잔차 r0 = y(0h) − q(0h) (q = 현재 최종 사슬 직전 예측: 온도 섞기+v18, EC R3+SG2) 를 예측하는 작은 보정 모델을 만들고,
0시 보정분을 시각별 측정 반영률로 하루에 퍼뜨린 뒤 **기존 앵커(EA2/v22)까지 붙인 최종 사슬**에서 판정한다. EC 우선, 온도 동시.

## 후보 특징 (모두 규정 안: 대상 0시 입력·같은 ID 앞번호 입력·학습 자료)
1. 대상 0시 입력 13개, 농장, 계절(학습 PAV 곡선 보간값), q0, 0시 이후 정보는 없음(0시 판단).
2. 짝찾기 1단계(v7): p, 정답 유무, 다른 ID 여부, 정답 있으면 앵커 차이 A1−q0 (p<.8 포함; 모델이 p로 신뢰를 배우게).
3. 짝찾기 2단계 직접 짝(6.582 방식, 중간 평가 기록 판단 미사용): p2, 앵커 차이 A2−q0.
4. 소프트 앵커: 같은 동 전날 기록(1단계 선택)의 모델 23시 예측 − q0 (정답 불필요; 앞번호 평가 기록이면 입력 허용). **E1(전날의 앵커 보정 예측)은 규정 문제로 제외.**
5. 앞 번호 기록(같은 ID n−1, n−2)의 모델 23시 예측 − q0, 자정 실내온도 점프.
6. SG2 정보: 이웃 정답 날 수준 − q0, 이웃 수, 보호 차단 여부.
7. 1단계 후보 상위 2개의 정답 23시 값과 그 확률(후보 합의).

## 모델
LightGBM 작은 것(leaves 4~8, min_child 30, 강한 규제) 또는 릿지. 목표 r0. 학습은 EV 폴드의 학습 기록만(검증 기록·삭제 기록 제외), 특징은 그 폴드의 숨김 규칙으로 계산.
퍼뜨리기: pred_h = q_h + c_h · r0_hat, c_h는 학습 기록에서 r0 지속률 측정(EC ~.9, 온도 1→.08).
그 뒤 기존 EA2/v22 앵커를 그대로 적용 (앵커 있는 기록은 앵커가 덮어씀 → 효과는 앵커 없는 기록에서).

## 검증 (사전 고정)
- EV 8폴드, 짝찾기 선택은 EV 숨김 그대로 다시 실행(비평 6.624-5 반영).
- 판정: 최종 사슬 RMSE가 EV 전체 검증 행에서 모든 시드 개선 AND 군집(덩어리) 부트스트랩 P < .025, 2차 검증 행 악화 없음(평균), 앵커 없는 기록 / 있는 기록 분해 보고.
- 특징 묶음별 제거 실험(1~7 하나씩 빼기)으로 기여 보고(판정 아님).

## 예상 실패 방식
과적합(학습 0시 행 ~350개), 1차/2차 분포 차이, 앵커와 겹침(SE1·RS1 교훈), 짝 오류 전파.
