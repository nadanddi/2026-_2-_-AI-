# DS1 — EC 하루 안 모양 보정기 (2026-10-12 집 클로드) — 실행 전 고정 계획

## 질문
기존 EC 예측 q 위에, 0시는 그대로 두고 1..23시의 '0시 대비 변화'만 고치는 보정기 g_h 를 얹으면 RMSE 가 줄어드는가?

## 기준 예측
- EV: `ev_validator/ec/out_v1/v2_ev_ec_rows.csv`, arm==BASE, seed∈{7,101,2024}, q=EA2, 폴드=fold(각 기록 1회 val, 400기록).
- DIAG10: `연구실/클로드/results/ec_rv1_preds_v1.csv`, validator==DIAG10, tag==CUR, seed∈{47,1414,6464}, q=sg, y=sub_ec, 폴드 10개(360기록).

## 대상·특징
- 대상 r_h = (y_h − q_h) − (y_0 − q_0), h=1..23 (학습 기록의 OOF 예측 q 사용).
- 특징(같은 기록 0..h 입력만, base.pkl 의 OUT/IN/ACT): h, q_0, q_h, q_h−q_0, 0..h 천창(ACT0) 평균·누적, 차광(ACT1)·보온(ACT2)·난방(ACT3)·유동팬(ACT4) 0..h 평균, h시 값, 일사(OUT2) 0..h 누적, 외기온(OUT0) h시, 실내온·습도(IN0, IN1) h시−0시, CO₂(IN2) h시·0..h 평균, 농장(F47=1). sub_temp(정답 열)는 쓰지 않음.
- 보정기 학습: 검증 폴드 k 의 기록은, 같은 검증기·같은 시드의 다른 폴드 기록(OOF q, y)으로만 학습. (q 자체는 각 폴드 모델이 만든 OOF 이므로 2단 쌓기의 통상적 약한 누설은 남음 — 보고에 명시.)

## 안(3개, 본페로니 α = .025/3 = .00833)
- M1 릿지: 위 특징 표준화 + 시간대 블록(1-5,6-11,12-17,18-23) 상호작용, alpha=30 고정.
- M2 LightGBM: 시간 쌓은 행(기록×h), num_leaves 7, min_data_in_leaf 200, lr .03, 300회, feature_fraction .8, seed 고정.
- M3 상승 게이트: q_0 ≥ τ 이고 h≥12 인 칸에 b_h = (학습 기록 중 q_0≥τ 인 것의 r_h 평균) 더함. 나머지 0.
- 비중 s ∈ {0.25, 0.5, 0.75, 1.0} (M3 는 τ ∈ q_0 학습 분위 {.5,.7,.8,.9} 도 함께) — **EV 1차(번호<179) 기록, 세 시드 평균 RMSE(실제 상태)로만 고름.** 고른 값으로 나머지 전부 판정.

## 두 상태
- 실제 상태: p_h = q_h + s·g_h (h≥1), p_0 = q_0.
- 0시 오라클 상태(진단): 기준 b_h = q_h + (y_0 − q_0) (완전 이월), 보정 b_h + s·g_h. 참고로 c_h 감쇠 이월(1차로 추정) 기준도 출력.

## 채택 기준(실제 상태, 바꾸지 않음)
1. 모든 시드 × 두 검증기(EV 3시드, DIAG10 3시드)에서 전체 RMSE(0..23시 전체 칸)가 기준보다 낮음.
2. DIAG10 기록 부트스트랩(시드 평균 기록별 SSE 차, 10000회, seed 20261012): P(worse)=P(Σ차 ≥ 0) < .00833.
3. 최대 기록 몫(가장 이득 큰 한 기록의 SSE 감소 / 전체 SSE 감소) ≤ 50%.
4. 보고만: 2차(번호≥179) 방향(EV, DIAG10), 덩어리(번호//10 × 농장) 부트스트랩, 오라클 상태 이득.
