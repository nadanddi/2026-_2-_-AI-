# VERIFY3 계획 — 앵커 후보와 현재 예측이 크게 엇갈리는 평가 기록의 진위 판정 (2026-10-12 집 클로드, 실행 전 고정)

## 대상
- 주 대상: F47_221(후보 F47_145, 23시 EC 2.144), F47_233(F47_137, .508), F13_228(F13_141, .832).
- 추가: 평가 60 중 짝찾기 v7 1등 후보가 정답 있는 학습 기록이고 |후보 23시 EC − submission_19 0시 EC| > .3 인 기록 전부(코드가 자동 선정).
- 참고로 정답 있는 1등 후보를 가진 평가 기록 전부의 사후확률도 함께 표로 낸다(판정은 위 대상만).

## 증거 (평가 대상 t, 후보 c, 판단 시각 h ∈ {0, 6, 12, 23})
규정: t 는 0..h 시 입력만. '보이는 기록' = 학습 기록 전부(다른 온실·뒤 날짜 포함) + 같은 ID 앞 번호 평가 기록. 다른 ID 평가 기록·뒤 번호 평가 기록 입력은 어떤 단계(날짜·경쟁 후보 포함)에도 안 씀. 차례 배정 없음(기록별 독립 판단).
- (a) 날짜: t 의 0시 외기 4개가 정확히 같은 보이는 기록 → t 날짜 집합 S0. 학습 정답 확실 연결(truth.pkl cert, 양쪽 모두 학습이고 숨김 아님 — 학습 자료 사용) 중 뒤 기록이 S0 날짜인 것들의 앞 기록 날짜 최빈값 → 전날 날짜 D1. 날짜 동일 = 하루 외기 칸 90% 이상 일치. date_ok = c 가 D1 에 속함. D1 을 못 정하면 date_na=1.
- (b) 자정 연속: mid(c) = Σ_8변수 min(|V_c(23) − V_t(0)|/sdV, 6) (linker v4 정의, 실내 3 + 구동기 5). 경쟁 후보 = D1 의 보이는 기록 중 c 아닌 것(정답 있는 학습 + 같은 ID 앞 평가 기록, 다른 ID 학습 포함). mid_margin = min_경쟁 mid − mid(c) (클수록 c 우세; 경쟁 없으면 0, comp_na=1).
- (c) 운영 지문: fp_h(c) = linker v6 fp_dist(t, c, h). fp_margin_h = min_경쟁 fp_h − fp_h(c).
- (d) 엇갈림: dis = |A_c23 − pred0|. 평가 pred0 = submission_19 0시, 학습 CV pred0 = DIAG10 CUR OOF(3시드 평균 sg). (상황 자체가 증거: 진짜 짝이면 dis 는 모델 0시 오차 분포, 가짜면 다른 동 EC 차 분포.)
- (e) 이틀 전 일관성: c 의 전날 c' (학습 정답 EC 연속 — feat4.label_successor, 학습 라벨만 사용) 가 있으면 fp2_h = fp_dist(t, c', h) 의 경쟁 대비 순위(c' 날짜의 보이는 기록 중 1등이면 1). 없으면 na. → 보조표에만(특징 수 제한).
- 짝찾기 v7 확률 p (linker v7m, h=0).

## 보정 (학습 거울 CV)
- 표본: cv_all400_choice_v7m.csv 에서 1등 후보가 '정답 있는 같은 ID 학습 기록'(prev_is_labelled & !xf)이고 truth cert 가 있는 행. 각 행의 숨김 세계는 cv400_v7m_critic.py 의 블록 정의 그대로 재구성(같은 ID 블록 s..s+9 + 이웃 s−1, s+10 삭제 + 다른 ID 거울 블록 m−1..m+10, m = s∓2). 숨김 기록은 정답·입력 모두 '평가 기록'처럼 취급: 같은 ID 블록 앞 번호는 입력만 보이고, 삭제·거울 블록은 안 보임.
- 정답 = (c == truth a1).
- 모델(고정): 로지스틱 회귀(L2, C=1, 표준화), 특징 5개 = logit(p), date_ok(+date_na), mid_margin, fp_margin_h, dis. 시각 h 별로 따로 적합. 판단 성능은 블록 단위 빼기 교차검증 OOF 예측으로만 평가(Brier, 로그손실, 사후확률 구간별 실제 정확도).
- 단순 조합표(과적합 대비 병행): date_ok × (c 가 mid 1등) × (c 가 fp_h 1등) × (dis > .3) 칸별 정확도·n.
- 0시 기대값: E0 = pred0 + P·β·(A − pred0). β = CV 정답 행에서 (y0 − pred0) ~ (A − pred0) 원점 통과 기울기. CV 같은 상황 행에서 '앵커 그대로 / 예측 그대로 / E0(OOF P)' 0시 RMSE 비교.

## 판정 기준 (실행 전 고정)
- 모델 신뢰 조건: OOF Brier 가 기저율 상수 대비 낮고, OOF 사후 ≥ .8 구간 실제 정확도 ≥ .85 (n ≥ 10). 미달이면 사후확률을 '참고'로 낮추고 조합표 칸 정확도로 말한다.
- 기록별: '앵커 맞음(확신)' = h=0 사후 ≥ .8 이고 모델 신뢰 조건 충족. '앵커 틀림 쪽' = 사후 ≤ .3. 그 사이 '불확실'. 늦은 시각(h=6/12/23) 사후는 그 시각 이후 행에 대한 판단으로 따로 표기.
- 이 판정은 서술용이며, 제출 파일·제출 구성은 만들지 않는다. 리더보드 점수는 쓰지 않는다.
