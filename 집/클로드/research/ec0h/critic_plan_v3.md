## 문제
1. [치명] **판정 불가.** 1차 판정 가능 8기록·5덩어리 → 덩어리 군집 부호 최소 P = 1/32 = .031 > .025. 2차 2기록. 기준을 미리 고정해도 PASS가 수학적으로 불가능. 수정: 실행하지 않거나 '서술'로 미리 선언.
2. [치명] **'23시 판단' 가정이 틀림.** KD1(6.639)의 .89~.99는 **날짜를 오라클로 준** 값. 실제 짝찾기는 날짜를 0시 외기로 정하고(6.576) 계획의 날짜 규칙(p 0시 vs 후보 23시 자정 연속)도 v5/v6가 이미 쓰는 것과 같음. 검산: v6 시각별 선택 0시=23시 일치 95%(396기록), v3 대상 p 48개에서 0시·23시 모두 a를 고른 것 **4/48**, p≥.8인데 틀림 23. 고칠 점: 날짜 후보를 오라클 없이 정하는 새 기제가 없으면 KD1 수치를 근거로 쓰지 말 것.
3. [높음] **E1이 이미 이 구조를 시험했고 실패.** E1 = p가 정답 앵커를 가진 상태에서 p의 23시 최종 예측을 t로 넘김: 1차 27기록 0시 +1.2%, 최종 +0~+1.7%, P .48. v3는 E1에 '더 낮은 확신(p<.8)의 p→a'를 추가하는 것뿐이라 기대 방향은 E1보다 나쁨. EC0-S(6.626)도 p<.8 연결의 이득은 단일 기록·다른 농장 연결은 해롭다고 결론.
4. [높음] **이중 계산.** 평가 대상 2기록의 p(F13_221, F47_221)는 EC0-SF(6.629) 평가 후보 목록 그 자체. v3 평가 효과 = EC0-SF 앵커 p + SA 이어받기. 새 가설로 세면 같은 2기록 신호를 두 번 셈. 고칠 점: 'EC0-SF⊕SA 조합'으로 이름 붙이고 EC0-SF와 같은 LB 가설 한 건으로 묶기.
5. [중간] **k=2 정보량이 최종 사슬에 미치는 크기.** 6.639 진실 사슬 1차 0시 −28%, 하루 −8%(계수 .42); 2차 n4. 평가 영향 2/60기록 → 오라클로 두 기록 0시를 완벽히 맞혀도 하루 수준은 계수 .42·.70 퍼뜨림 → 전체 EC RMSE 변화는 1% 안팎이 상한(추정, 계산 안 함). 틀린 a를 고르면 EC0-S F13_214처럼 한 기록이 +4 SSE.
6. [중간] **규정.** p 하루 전체 입력 사용은 6.631(같은 ID 앞 번호)로 허용. a는 학습 기록 → 허용. 위험: p→a 선택에서 'p의 형제가 이미 쓴 a 제외' 같은 배제가 들어가면 차례 배정 금지 위반. 고칠 점: 상태 없는 재계산(대상마다 처음부터)으로 명시. t의 h>0 예측에 p 정보 쓰는 것은 문제 없음.
7. [중간] **w·c_h 측정 집단.** "다른 폴드 1차에서 측정"인데 대상 8기록/폴드당 0~2 → w가 SA·E1 대상까지 섞여야 측정 가능, 그러면 v3 고유 효과와 섞임. EC0-S처럼 폴드별 β .39~.96 흔들림 재현될 것.
8. [낮음] '한 기록 몫 ≤50%'는 8기록에서 거의 확실히 걸림(E1-SA 상위 6기록이 93%).
