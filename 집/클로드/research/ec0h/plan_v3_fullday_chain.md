# EC 0시 계획 v3 '전날 평가 기록 하루 전체 연결 → 오늘 0시' (2026-10-12 집 클로드) — 비평 전

## 아이디어
대상 t(덩어리 안, 앵커 없음)의 같은 ID 전날 p가 평가 기록(정답 없음)일 때, p의 **하루 전체 입력**(t보다 앞 → 0시에 허용, 6.631)으로
p의 같은 동 전날 a(정답 있는 학습 기록)를 찾는다(자정 연속성 + 하루 운영 지문; 6.639에서 지문 정확도 12~23시 .89~.99, 0시 .79).
p의 23시 EC 추정 E_p = q_p,23 + (A_a23 − cm_p,23) (EA2와 같은 꼴, cm = p의 0~23시 예측 평균) 을 t의 0시 출발점으로:
pred_t,h = q_t,h + c_h · w · (E_p − q_t,0).   정보량 근거: 진실 사슬 k=2, 1차 0시 −28%·계수 .69 (6.639).

## 기존 시도와 차이
E1(6.631 이후, 1차 +0~1.7%): p의 앵커를 p의 **0시** 판단(p≥.8)으로만 정해 해당 p가 적고 확신 낮음. v3는 p의 판단을 **23시(하루 전체)** 로.
6.600 TB1(여러 단계 사슬): 단계마다 0시 판단 정확도 곱해짐 → v3는 p 단계의 정확도를 하루 전체로 높임.

## 규정
p는 같은 ID 앞번호 → 입력 전부 허용; a는 학습 기록(제한 없음, 6.630); t는 0시 입력만. 차례 배정 없음(각 기록 독립 판단).

## 구현(사전 고정 예정)
- EV 폴드, linker v6 지문 + v7 후보(다른 온실 학습 포함). p의 판단 시각 23시. 날짜는 자정 외기 연속(p의 0시 vs 후보 23시)으로.
- p→a 확신 문턱 .8, t→p는 v7m 선택(같은 ID, 정답 없음, p≥.8).
- w, c_h: 다른 폴드 1차에서 측정, 2차는 방향만.
- 판정: 1차 대상 3시드 개선 + 덩어리 군집 P < .025 + 한 기록 몫 ≤ 50%; 0시 오차와 최종 사슬 하루 오차 둘 다 보고.
