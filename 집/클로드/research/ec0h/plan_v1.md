# EC 0시 추정 계획 v1 (2026-10-12 집 클로드) — 비평 전 초안

## 목표
앵커(같은 동 전날 정답, p≥.8 1단계)가 없는 평가형 기록의 EC 0시 수준(=하루 수준)을 규정 안 정보로 추정해 **최종 제출 사슬(R3 → SG2 → EA2)** 의 오차를 줄인다.
오라클: 0시를 정확히 알면 2차 −55% (6.607/6.623). 지금 EV 2차 최종 사슬 .2043, 앵커 없는 37기록 .2460, 앵커 있는 19기록 .0714 (6.621).

## 이미 닫힌 길 (재시도 금지, 카탈로그 번호)
입력 기반: 닮은 날/시간대 kNN(6.594·6.620), 0시·밤 전용 모델(6.617·6.619), 같은 날짜 다른 동(6.616A·6.211), 메타 지문·차광 방식(6.599), 고EC 전조(6.603), 체계 편향(6.601·6.610).
정보 경로: 동 고유 장기 오프셋(6.597), 중간날 입력 브리지(6.596), 다음날 앵커(6.591·6.602·6.609), 여러 단계 사슬 온도(6.600), 소프트 앵커=전날 모델 예측(6.616B, EC 무효), 계절 보정 SE1(6.621).

## 남은 가설 (실행 전 고정)
- **E1 '앵커 이어받은 전날 예측' (체인 소프트 앵커)**: 대상 t의 짝찾기 전날 p가 정답 없는 같은 ID 기록(평가형)이고 p≥.8, 그리고 p 자신은 확신 1단계 앵커(정답 있는 전날 a)를 가졌을 때 → t의 0시 추정 = p의 **EA2 보정 후** 23시 예측. 즉 라벨 정보가 2단계로 전달(오라클 2일 앵커 β .42, 6.582). t의 보정: pred_t,h = q_t,h + w·(Ep23 − cm_t,h) 형태(EA2와 같은 꼴), w는 1차에서 측정.
- **E2 '2일 직접 짝'(6.582 재판정)**: 1단계 앵커 없는 t에 대해, 학습 자료 + t의 0시 입력만으로 이틀 전 같은 동 정답 기록을 직접 짝찾기(중간 평가 기록 판단 미사용) → A2 = 그 기록 23시 EC, β = 1차 측정(≈.4~.5).
- **E3 E1·E2 결합**: 둘 다 있으면 평균, 하나면 그것.

## 검증 (사전 고정)
- 검증기: EV(ev_validator/ev_folds_v1.csv). 기반 예측: EV EC 채점 결과의 BASE 계절 사슬 행 예측(ev_validator/ec/out_v1/v2_ev_ec_rows.csv; R3·SG2·EA2 단계, 시드 7/101/2024).
- 짝찾기: linker v7 거울 CV 선택(cv_all400_choice_v7m.csv, EV와 같은 덩어리 모양). E2용 2일 직접 짝은 6.582 스크립트 재사용.
- 계수(w, β)는 1차 구간 기록에서만 측정, 2차로 판정.
- 판정: **최종 사슬(EA2 이후)** 2차 검증 행 RMSE가 3시드 모두 개선 AND 기록 단위 P(worse) < .025(E1·E2·E3 세 안 → 본페로니 .0083). 전체 행도 악화 없음. 앵커 없는 기록 / 있는 기록 분해 보고.

## 규정 점검 (rule-safety checklist)
- E1: t 예측에 같은 ID 앞번호 평가 기록 p의 '예측값'을 씀(p의 입력 + 학습 정답 a로 계산). 금지 항목 '평가 입력·예측값으로 모델·판정 기준을 학습·갱신'에 해당하는가? → 학습·갱신은 아니고 고정 규칙의 특징값이지만, '앞선 평가 판단 이어받기'에 가까움 — 비평가 판단 요청.
- E2: 학습 자료 + 대상 0시 입력만 → 안전.

## 예상 실패 방식

- EA2의 누적평균 구조와 겹쳐 SE1처럼 계단 편향.
