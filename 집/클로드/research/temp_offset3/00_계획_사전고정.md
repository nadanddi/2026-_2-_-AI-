## 1. 자료·정의
- 기준 예측 q: EV `ev_all.pkl` 의 `v22_*` 열 평균(현재 최종). 400 학습 기록 × 24시. 2차 = 번호 ≥179.
- 하루 오프셋 o_b = mean_h(y − q). 큰 날 = |o| 상위 10%(1차·2차 각각의 분위수). 보조 검증기 DIAG10(4칸 평균, 370기록).
- 전날 같은 동: 진단용 정답 연결 `linker_v3/truth.pkl` a1(같은 ID·cert) — 서술(포렌식) 단계에만. 인과 단계는 짝찾기 v7(`cv_all400_choice_v7m.csv`, p) 만.
- 같은 날짜 형제: 외기 4변수 24칸 중 ≥70% 동일한 기록(feat4 components 와 같은 정의). 같은 농장 다른 동 / 다른 농장.
- 입력: train_X 14변수(외기 4, 실내 3, 구동기 7).

## 3. 비인과 상한 → 인과 (관문)
- U1: o_b 를 '그날 24시간 전체 입력 요약 + 전날 같은 동(진실 연결) 입력·정답 요약 + 형제 차'로 교차적합(기록 덩어리 5겹, 릿지 α 고정 1, 그리고 LGB 얕게 고정 설정) → 2차·F47 R², 그리고 q 에 o_hat 을 더했을 때 EV 1차/2차 RMSE 변화.
- **관문**: 비인과 상한이 EV 2차 RMSE −5% 이상 **그리고** DIAG10 2차 −3% 이상(같은 방향)일 때만 인과 보정기(ii) 진행. 미달이면 '정보 부족'으로 종료.
- 인과 보정기(진행 시): 평가 h 특징 = 같은 기록 0..h 입력 + 같은 ID 앞번호 평가 기록 입력/계산된 예측 + 학습 자료. 짝찾기 v7 p 만 사용(진실 연결 금지).
- 채택 기준(진행 시, 실행 전 고정): 모든 시드 × 검증기(EV, DIAG10, G, EL1) 같은 방향 + DIAG10 기록 단위 P(worse) < .025(안 k개면 .025/k) + 최대 기록 몫 ≤ 50% + EXT10/EXT12 악화 없음. 훑기(축소 계수 등)는 1차로 고르고 2차로 판정.

## 4. 규정
평가 행 h 특징은 같은 기록 0..h 입력 + 같은 ID 앞번호 평가 기록 입력만. 다른 ID 평가 입력·뒤 입력 금지. 학습 자료 제한 없음. 진실 연결(truth.pkl)은 서술 진단에만.
