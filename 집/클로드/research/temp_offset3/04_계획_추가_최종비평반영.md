# 계획 추가 4 — 최종 비평 반영 재측정(f5), 실행 전 작성
비평 요지: U1(번호순 연속 덩어리 겹)은 '상한'이 아니라 1차→2차 외삽 검정이었고 LGB 도 1차에서 악화(고장 난 추정기), U1b 가 이미 아는 oa 신호도 못 잡음; H9 기준(외기 대비)은 여름 정상 기록을 섞음.
## 재측정 고정
- 겹: 농장별 번호를 4개씩 묶은 작은 덩어리를 무작위로 10겹 배정(시드 3개: 1,2,3) — 외삽 대신 '같은 분포 안' 상한.
- 축소: ô·λ, λ∈{0,.25,.5,.75,1} 을 **1차 OOF 로 고르고 2차로 판정**.
- 추정기 4종: (A) U1a LGB(02 설정), (B) U1a 릿지 α=300 + 특징을 학습 겹 1~99% 분위로 자르기, (C) 저차원 U1b: o ~ oa + ra23 (진실 연결, 없으면 0 + 표시자), (D) 저차원 U1a: q0−실내0, 밤 실내, 하루 (실내−외기), 밤 난방, 밤 보온커튼.
- 관문(01 6항 그대로): (A)/(B)/(D) 중 하나라도 EV 2차 오프셋 SSE ≥ 15% 감소 그리고 DIAG10 2차 ≥ 10% 감소(3시드 평균, 3시드 모두 같은 방향). (C)는 진실 연결이라 관문에 쓰지 않음(신호 검출력 확인용: (C)가 1차에서 양수 감소를 못 내면 추정 틀 자체가 고장).
## H9' 형제 대비 실내 편차 (진단, 학습 기록만)
- 밤 0~5시 실내 − 같은 날짜 형제들의 밤 실내 평균 ≤ −3℃ 인 기록: + 부호 ≥ 80%, 평균 o ≥ +0.5, n ≥ 5 이면 합격. (평가 기록에선 다른 ID 형제 입력 사용 금지 → 합격해도 인과 사용 불가, 정보 위치만 확인.)
