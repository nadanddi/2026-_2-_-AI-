## H9 실내 입력 이상(물리적으로 어색한 밤 실내 < 외기)
- 흔적: 밤 0~5시 평균 (실내 − 외기) ≤ −2℃ 인 기록은 o 가 + 쪽(배지가 모델보다 따뜻)이어야 함.
- 보이면 안 되는 것: 그런 기록 o 평균 ≈ 0 또는 − 쪽.
- 합격(탐색): 해당 기록 ≥ 5개, + 부호 ≥ 80%, 평균 o ≥ +0.5. 해당 기록이 5개 미만이면 '드문 사건, 판정 불가'.
## H10 − 날 = 낮 반응 폭 감소(배지가 공기 일교차를 덜 따라감)
- 흔적: 큰 − 날에서 (배지 하루 폭 / q 하루 폭) < 0.8, 다른 날은 ≈ 1.
- 보이면 안 되는 것: − 날 폭 비율 ≈ 1 (그러면 수준 이동).
- 인과 사용 가능성: 폭은 정답에서만 보임 → 같은 ID 앞 날 정답(학습 기록)의 폭 비율이 오늘과 상관 ρ ≥ .3 일 때만 정보원 후보.
