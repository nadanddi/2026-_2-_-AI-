# ABL1 정형 "어제 이어 붙이기" 끄기 실험 결과 (2026-11-02, 집 클로드, 서술용)

- **무엇을 쟀나:** 정형 최종 답안(submission_35e)의 구성에서 대회 자료 규칙성에 기대는 부분을 끄면, 학습 자료 검증기에서 오차가 얼마나 커지는지 쟀습니다.
  - 대상은 FL 링커로 "같은 동의 어제"를 찾아 붙이는 처리입니다: 어제 정답 앵커와 예측 사슬.
- **성격:** 서술용이고 채택 판정이 아닙니다. 최종 답안·모델·제출물은 바꾸지 않았습니다.
- **사전 고정:** 실행 전에 코드와 계획을 커밋했습니다(`45ac69c5`). 첫 실행은 EC 부분 소스를 자르는 위치 버그로 멈췄고(`abl1_v1_crash.log`), 그 한 곳만 고쳐 다시 돌렸습니다(`ABL1 EC 부분 소스 자르기 위치 버그 수정` 커밋). 안 정의는 바꾸지 않았습니다.
- **코드·기록:** `집/클로드/research/abl1_link_modules_off_v1.py`, `abl1_v1.log`, 결과표 `research/local/abl1_link_modules_off_v1.csv`
  - 틀은 기존 판정 코드를 그대로 썼습니다. 온도는 TXP2(카탈로그 7.055, 35e 온도와 같은 34 구조), EC는 ECT2(7.044, ECT2 안 = 35e EC 앵커)입니다.

## 비교한 안

| 목표 | 안 | 구성 |
|---|---|---|
| 온도 | A0 | NX 기본 예측만 |
| 온도 | A1 | NX + TX3 = **일반 방법만**(어제 이어 붙이기 없음) |
| 온도 | A2 | A1 + 어제 정답 앵커(p ≥ .8 + TAG2) |
| 온도 | A3 | A2 + 예측 사슬(CH5 + CHT) = **최종 구성** |
| EC | E0 | pre + HR5 = **일반 방법만**(앵커 없음) |
| EC | E1 | E0 + 어제 EC 앵커(p ≥ .8) |
| EC | E2 | E1 + TAG2 EC 앵커 = **최종 구성** |

- 검증기는 모두 F13·F47 **학습 기록**을 가려서 만든 것입니다. 평가 자료가 아닙니다.
  - 온도: EXT10·EXT12(추운 날을 학습에서 뺌), DIAG10(10겹 무작위). 시드·구성원 셀 평균입니다.
  - EC: DIAG10·EL1·P2LOO. 시드 3개 평균입니다.
- "2차 행" = 기록 번호 179 이상입니다. 평가 60기록은 모두 2차 구간입니다.

### 단계별로 나누면 (온도, 2차 행, 최종 대비)
| 검증기 | NX만 | +TX3 | +앵커 | +사슬(최종) |
|---|---|---|---|---|
| EXT10 | +10.8% | +10.4% | +2.4% | 0 |
| EXT12 | +3.2% | +3.1% | +3.1% | 0 |

- 앵커는 EXT10·DIAG10에서 크고, EXT12에서는 0입니다. EXT12의 2차 판정 기록에 앵커가 붙은 기록이 없기 때문입니다.
- 사슬은 EXT12(+3.1%p)와 EXT10(+2.4%p)에서 큽니다.

### EC 참고
- DIAG10 전체 행에서는 TAG2 앵커를 더한 최종(E2 .2053)이 p ≥ .8 앵커만 쓴 판(E1 .1969)보다 4.1% 나쁩니다.
  - 원인은 이미 알려진 F47_132(고EC 날의 틀린 연결)입니다(카탈로그 7.044).
  - 2차 행에서는 E2가 조금 낫습니다(−0.2%).

## 쉬운 말로 정리
- **기본 예측이 성능의 대부분을 냅니다.** 온도 RMSE는 기본만으로도 .74~.91℃이고, 어제 이어 붙이기를 더하면 .71~.88℃가 됩니다.
- 하지만 **어제 이어 붙이기가 주는 개선이 작지 않습니다.**
  - 온도: 2차 행에서 3~10%
  - EC: 2차 행에서 8~31%. 특히 EC는 어제 23시 실측 EC가 다음 날 수준을 크게 알려 줍니다.
- 현장에서 이 개선을 얼마나 유지할 수 있는지는 부품마다 다릅니다.
  - **예측 사슬**(어제의 내 예측을 이어 씀): 현장에서도 쓸 수 있습니다. 어제는 달력으로 정해지므로 링커가 필요 없습니다.
  - **어제 정답 앵커**: 전날 배지 센서 실측이 있을 때만 쓸 수 있습니다. 배지 센서가 없어 이 예측이 필요한 현장이라면 쓸 수 없습니다.
- 그래서 현장에서 확실히 남는 성능은 **"일반 방법만" 줄과 "사슬" 몫 사이**로 봐야 합니다.

## 한계 (발표 노트에 같이 적을 것)
- 검증기는 같은 학습 자료 안에서 기록을 나눈 것입니다.
  - 링커 가중도 같은 학습 정답으로 맞췄습니다.
  - 검증기 일부는 부품 선택에도 썼습니다(정형README ⑤). 그래서 최종 쪽이 조금 낙관적일 수 있습니다.
- 2차 행의 판정 기록 수가 적습니다(EXT10 9기록, EXT12 26기록, DIAG10 52기록).
- **계절 지표**(2차 날짜를 외기 쌍둥이로 복원)는 모든 안에 남아 있습니다. 이것까지 뺀 성능은 **미실시**입니다.
- **현장형 사슬**(링커 대신 실제 어제로 사슬을 거는 판)도 **미실시**입니다.
- EC 최종 단계의 "학습 EC 범위로 자르기"는 이 틀에 넣지 않았습니다. 이 단계의 평가 예측 변화는 미미합니다.
- 비평 서브에이전트 검토는 하지 않았습니다. 계산은 기존 판정 코드의 같은 함수를 썼습니다.
  - A3는 TXP2의 기준과 같은 식 `assemble2(x, A_tag, CHfull, …)`입니다.
  - E2는 ECT2 안과 같은 앵커 집합입니다.
