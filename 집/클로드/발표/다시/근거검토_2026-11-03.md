# 근거 검토: 모델 선정·가중치·데이터 파악·문제 해결 과정 (2026-11-03, 집 클로드)

사용자 기준은 "모든 결정에 근거가 있어야 한다"입니다. 덱 v4와 최종 검증 자료(정형·이미지 README ④⑤, 카탈로그)를 대조해 결정마다 근거를 확인했습니다.

판정은 네 가지로 나눴습니다.
- **충분**: 학습 자료 측정이나 실행 전에 고정한 기준 통과처럼, 데이터로 정한 근거가 있음
- **약함**: 근거는 있지만 리더보드 비교, 사후 결정, 작은 표본에 기댐(자료에 이미 밝혀 둠)
- **기록 미확인**: 값은 있지만 정한 근거를 이번 검토에서 찾지 못함
- **덱 수정 필요**: 덱의 문장이 근거보다 강하게 말함

## 1. 덱 문장 중 바로 고칠 것

- **1.5 부제목 "실행 전에 고정한 기준을 통과한 변경만 리더보드에서도 좋아졌다"는 사실보다 강합니다.**
  - 17·23·24회차는 사전 기준을 통과하지 않았습니다(제출 비교로 채택). 그런데도 리더보드에서는 좋아졌습니다.
  - 확인된 사실은 "통과한 19·21회차는 좋아졌고, 근소하게 못 넘은 20·22회차는 크게 나빠졌다"까지입니다.
  - 고칠 문장 예: "기준을 통과한 변경은 실제로도 좋아졌고, 근소하게 못 넘은 변경은 크게 어긋났다"
- **표본이 작다는 점도 밝혀야 합니다.** 통과 2건, 미달 2건이라 경향을 보여 줄 뿐 증명은 아닙니다. 노트에 한 줄 추가가 필요합니다.

## 2. 정형

### 근거 충분
- **추위 게이트 8~10℃**: TabPFN이 학습 범위 밖 추위에서 크게 틀림(추운 날 편향 +1.8℃, 카탈로그 6.67·6.70). 나중에 데이터로 학습한 스위치가 문턱을 약 8.5℃로 다시 찾음(7.017).
- **FL 링커 가중치, 앵커 감쇠 β_h**: 학습 정답의 이어지는 짝으로 적합했습니다(README ②⑤).
- **앵커 확신 문턱 p ≥ .8**: 앵커가 손해를 보지 않는 링커 정밀도가 약 .8로 측정됐습니다(6.944).
- **앵커 상수 0.36, 자정 변화 |dT| ≤ 1.5**: 자정 전달을 학습 정답으로 측정했습니다(y0−A = −.38 + .53·dT, 6.583). 조합은 1차 구간에서 고르고 2차 구간에서 판정했습니다.
- **TX3 0.25 / 0.8 / 10℃**: 학습 정답으로 측정했고 사전 기준을 통과했습니다(44칸 모두 개선, P .0047).
- **예측 사슬 0.9·exp(−h/8)**: 사전 기준을 통과했습니다(P .0003). 다른 49개 온실에서도 확인했습니다(48곳 개선).
- **사슬 확신 문턱 p ≥ .5**: 확신 구간별 진짜 연결 비율로 정했고, 사전 기준을 통과했습니다(P .0029).
- **EC 구성원·shrink·0.8/0.2**: 9회차 판정표를 통과했습니다.
- **HR5 λ 0.5**: 판정 전에 DIAG10에서 골랐습니다. 다만 채택은 제출 비교였습니다(아래 '약함').
- **데이터 파악**
  - 하루 수준 오차가 '어제'와 이어진다는 근거: DLV1, 학습 자료 온실 전체(6.997)
  - 기록 번호 = 공식 상대 일차: 문제설명서
  - 어제 이어 붙이기의 기여: ABL1 끄기 실험, 계획을 실행 전에 고정(7.069)

### 근거 약함 (자료에 이미 밝혀 둠)
- **TabPFN 비중 0.4**: 내부 검증이 엇갈려 리더보드 비교 한 번으로 정했습니다(A7).
- **제출 비교로 채택된 부품**: 로컬 방향은 좋았지만 사전 기준은 다 채우지 못했습니다. 아래 부품들입니다.
  - 계절 지표(`day` → 계절)
  - day·second 제거: 검증기 4종에서 결과가 섞임
  - FL 앵커 첫 채택: P .093
  - TAG2: P .12
  - CHT: 결론 없음
  - HR5
  - EC 앵커 0.8: P .35
  - EC TAG2: DIAG10 한 기록 손해
  - → 발표에서는 "검증 방향을 보고 제출로 확인한 부품"이라고 정확히 말해야 합니다. 덱 1.4의 근거 각주와 A1 4번에는 반영돼 있습니다.

### 기록 미확인 (이번 검토에서 근거를 찾지 못함)
- **BASE 안 비율(LightGBM 0.65, Ridge 0.25, Nystroem 0.10)**: README ②에 값만 있습니다. 정한 근거는 초기 기록(9월 말 W30G 이전)에 있을 수 있어 추가로 찾아야 합니다.
- **학습 행 가중 0.2**: 복원 의심 행과 잡음 낀 날 상위 4분의 1에 주는 가중입니다. 0.2와 '상위 4분의 1'을 정한 근거를 찾지 못했습니다.
- **"같은 동이 두 ID를 오감, 확실한 짝의 약 4분의 1"**: README ④에는 적혀 있지만, 계산한 스크립트나 카탈로그 번호가 인용돼 있지 않습니다. 덱 1.1에 쓰는 숫자라서 **다시 계산해 출처를 붙이기를 권합니다.**

## 3. 이미지

### 근거 충분
- **백본(CLIP ViT-L/14@336)**: 백본 7종 비교에서 1위였습니다(.927, 실제 오탐 2.7%). 2개 앙상블은 단독 이하였습니다(연구실 10-12 작업일지).
- **기본 판별 0.5/0.5 평균**: 교차검증에서 단일 갈래보다 균형 정확도가 높았습니다(재현 패키지 01).
- **R1의 거리 문턱 3.5·20·8**: 학습 자료 분포로 정했습니다(원본 있는 실제 d1 99분위 3.29, gap 95분위 8.06).
- **형식 게이트 조건**: 공개 21장 실측 형식과 같고, 전문가가 그 형식으로만 학습됐습니다.
- **교차검증 방식**: 촬영 묶음·농장 단위로 나눠 같은 원본이 다른 폴드에 갈리지 않게 했습니다.
- **현장 의존도**: 지문 DB 끄기(10-20)와 ABL2(R2)는 모두 계획을 실행 전에 고정했습니다.

### 근거 약함 (자료에 이미 밝혀 둠)
- **가짜 제작 5판 포함**: 사전 규칙상 실제 오탐이 +1~2%p라 로컬에서는 채택하지 않았습니다. 초기 후보 선택에 **공개 21장**(5회 이상 열람)을 지표로 썼고, 리더보드 후보로 넘겼습니다. 21장은 표본이 작습니다.
- **E_gpt 진짜 확정 사진 제외**: 불통과를 본 뒤 같은 자료로 정한 사후 변형입니다(README에 낙관적일 수 있다고 적음).
- **최종 나단11 선택**: 미리 정한 규칙은 "LB Accuracy ≥ .98"이었는데, 규칙과 다르게 환산점수 비교로 유지했습니다(README에 이유를 적음).
- **봉인 묶음 수치**: 후보 채택에 쓴 자료이고, 농장·촬영 묶음이 학습과 겹칩니다(A4 정정).

### 기록 미확인 (값을 고른 이유가 없음)
- **R1의 나머지 두 값(p ≥ .25 일 때 p ← .9)**: 거리 문턱과 달리 근거가 적혀 있지 않습니다.
- **전문가 문턱의 '뒤집는 비율'(0.4%, 0.25%, 진짜 확정 0.1%)**: 문턱 자체는 데이터 분위로 정했지만, **왜 0.4%·0.25%인지**는 적혀 있지 않습니다. 정책 선택으로 보입니다.
- **정밀 원본 대조 분위(99.5%, 99.9%, 95%)**: 같은 이유로 분위 선택의 근거가 없습니다.
- **가짜 확정 0.95, 진짜 확정 0.3·0.8 조건**: 값의 근거가 적혀 있지 않습니다.
- **학습용 실제 사진의 붉은 LED 제외 기준(R−G > 25)**: 기준값의 근거를 찾지 못했습니다.

## 4. 권하는 조치

1. **덱 1.5 부제목을 고치고**, 노트에 "통과 2·미달 2라 경향일 뿐"을 추가합니다. (덱 v5)
2. **'약 4분의 1'을 다시 계산**해 스크립트와 숫자를 남기고, 덱 1.1 각주에 출처를 붙입니다.
3. **기록 미확인 항목은 연구실(이미지)과 초기 기록(정형 BASE 비율·행 가중)에서 근거를 찾습니다.** 못 찾으면 부록에 "손으로 정한 값(근거 기록 없음)"으로 정직하게 적습니다. 운영위는 '미확인' 표기를 허용합니다.
4. 발표에서는 "모든 값은 데이터로 정했다"고 말하지 않습니다. 대신 이렇게 말합니다. "핵심 상수는 학습 자료로 측정했고, 일부는 제출 비교로 확인했으며, 일부 문턱 비율은 정책으로 정했다."
