# EC 재분석 1단계 · 2026-10-01 · 집 · 코덱스

## 기존 합의에 따른 문제 정의
- 목적: 입력이 담고 있는 EC 정보를 다시 점검하고, EC v2 대비 재현 가능한 개선 가설을 찾는다.
- 대상: F13/F47 배지 EC(sub_ec), 평가 지표 RMSE. 단위는 기존 설명의 dS/m이며 센서 정의·온도 보상 방식은 미확인이다.
- 추론 경계: 같은 온실의 현재·이전 입력만. 과거 정답·다른 온실 특징·미래 입력 금지. 학습 특징에도 평가의 MASK 적용.
- 학습 자료: 배포 train_X/train_y. 평가 입력은 스키마와 결측 MASK만 확인하고 분포·가중치·정제 결정에 사용하지 않는다.
- 잠금: ec_final_lock/locked_days.json의 40일은 EC 값을 숫자로 변환하기 전에 제외. 이번 분석은 잠금 점수화를 하지 않는다.
- 성능 판정: A/B/DIAG10 여러 시드, DIAG10 p_worse<0.025/k, EXT10/12 무악화 및 인과·결정성 확인. 개선 크기 기준 없음.
- 기존 문제가 합의된 후속 요청이므로 스킬의 반복 승인 절차는 생략. 정제는 아직 하지 않는다.

## 실행 전에 정한 질문
1. 키·스키마·정답 조인·시간 격자는 정상인가?
2. EC 대상 온실의 가용 입력과 다른 온실의 가용 입력은 어떻게 다른가?
3. 가용 센서에 결측·범위 이상·반복값이 있는가? 제거 대신 먼저 기록한다.
4. EC 자체의 변동 중 온실 간·온실 하루 간·하루 안 변동은 각각 얼마인가?
5. 두 온실에서 EC의 범위와 하루 변동폭이 비슷한가?
6. 상대 날짜 구간에 따라 EC 분포가 달라지는가? 날짜는 실제 달력 날짜로 해석하지 않는다.
7. 후속 탐색에서 관리정책·일내 변화·센서 이상을 어떤 순서로 구별할 것인가?
