2026-10-10 · 집 코덱스 · 실제 여섯 유형 제작 및 첫 학습 작동 시험

이번 단계에서 확인한 것
개발 농장 AIF005(금실)·AIF007(설향)의 원본 각 1장으로 실제 사진 2장과 양성 12장을 만들었다. 양성은 전체 생성, 생성 잎 합성, 의도적 필터, 전체 스타일 변환, 부분 생성, 부분 스타일 변환 각 2장이다. imagegen 실제 호출 8회 모두 성공했고 재시도는 없었다. 프롬프트·참조 파일·계보·생성 자산·파일 SHA를 보존했다. 서비스가 모델 버전과 시드를 공개하지 않아 unknown으로 기록했다. 동일 서비스 결과의 재생성 재현을 보장하지 않는다.

제작 검증
14개 파일 모두 512×512, 같은 JPEG 품질 90/4:2:0 출력이다. 원본별 검정 여백을 양성에도 복원했다. NumPy 제작 결과를 PIL ImageChops와 Python 픽셀 집계로 별도 검산한 qa_verification_v2.json은 PASS다. 합성/부분 편집 6장은 JPEG 이전 마스크 밖 변화 0이지만 JPEG 이후 밖으로 113~732픽셀 변화가 번졌다. 16픽셀 확장 경계 밖과 먼 여백 변화는 0이다. JPEG에서도 마스크 밖이 완전히 동일하다는 주장은 하지 않는다.

실제 학습 및 재검증
ImageNet ResNet18, 384 입력, RTX 4050 AMP, 배치 4(실제 2+양성 2), seed 20261010, AdamW lr 0.0001/weight_decay 0.01, clip 1로 사전 고정한 12 optimizer steps를 완료했다. 학습 표본 투입은 총 48회이며 실제 사진 24회, 여섯 양성 유형 각각 4회다. 이는 같은 원본 2장을 반복한 작동 시험이다.
모든 단계에서 loss/gradient/clip 후 gradient 유한성, 분류기 gradient 비영, 실제 가중치 변경, optimizer step 증가를 검사했다. 첫 step 체크포인트에서 나머지 11steps를 재개했다. 체크포인트는 각각 134,257,747B와 134,259,987B다. CUDA allocator 최고 할당은 재개 구간 397,560,832B이며 전체 GPU 메모리 사용량이나 본격 학습 여유를 뜻하지 않는다.
CPU 재로드, 배치 1/3/7, 역순, 빈 입력, 확률 범위, 파라미터와 버퍼 불변 검사를 통과했다. 별도 검산 스크립트가 다시 가중치를 불러와 배치 2/역순 배치 5로 계산한 최대 차이는 1.1920928955078125e-7로 사전 허용치 1e-5 이내였다. train_verification_v1.json에서 모델/state SHA, 12단계 이력, optimizer 상태, 14 입력 SHA, 격리 ID 제외, 표본 투입 횟수와 자원 예산을 재확인했다. GPU 재학습의 비트 단위 재현성은 검증하지 않았다.

비평과 수정
계획 비평으로 출력 여백·압축 횟수·실패 포함 호출 상한·CPU 비교 기준을 명확히 했다. 학습 전 비평으로 clip 후 finite/nonzero gradient 및 재개 계보 검사를 추가하고 실행 코드 SHA를 고정했다.
학습 중 비평에서 등록 파일은 강화 QA v2의 SHA를 가리키지만 첫 학습 코드가 QA v1 PASS를 읽은 버전 참조 불일치를 발견했다. 두 QA 결과와 입력은 같고 모두 PASS였으나 처음부터 v2를 강제했다고 주장할 수 없다. 기존 코드·등록·첫 결과는 보존했다. 새 run_finish_v2.py와 resume_registration_v1.json이 동결 파일 7개와 QA v2 SHA/PASS, 첫 체크포인트 SHA를 실제 재개 전에 강제했다. resume_preflight_v1.json이 해당 통과 기록이다.
최종 독립 비평의 범위와 남은 사항은 critic_train_final_v1.json을 함께 읽는다.

현재 한계와 판정
신뢰도 높음: 위 14개 제작·12회 업데이트·CPU 재로드 작동 사실. 근거는 실제 파일 SHA, 별도 실행 검산과 로그다.
성능·일반화 판단 보류: 독립 검증 정확도/AUROC/과적합 격차를 측정하지 않았다. 공개21·보류 농장 AIF014/015는 이번 단계에서 열람하거나 평가하지 않았다. 팀원 v5/외부 0.77은 참고 전용이다. 증강 채택·성능 개선·제출 준비를 완료했다고 주장하지 않는다.
원본 2장은 카메라 출처를 전제로 실제 라벨을 부여했으며 각 사진의 과거 편집 여부는 인증되지 않았다. 중앙 사각형 경계, 하나의 생성 서비스, 재사용 스타일 자산, 원본별 조명과 유형별 색감 차이가 남았다. 분홍색 지표가 실제 약 0.825에서 유형별 약 0.722~0.849로 달라 색감 지름길이 해결됐다고 볼 수 없다. 필터는 blur 1.0 한 종류뿐이다. 원본 2장·14 파일은 기존 목표 8원본·56장 제작 QA의 완료가 아니다.

자원 및 보존
별도 검산 시 기존 작업 포함 로컬 캐시 11,572,412,802B로 고정 16GiB 이내, 이번 작업 291,562,641B로 1GiB 이내, C 여유 176,561,598,464B로 30GiB 이상이었다. 기본 .codex 생성 이미지 원본의 별도 점유량은 resource_generated_v2.json에 기록한다. 삭제·원본 수정·전체 350GB 압축 해제·제출물 생성은 없었다. 기존 EC 작업 중지 상태를 유지한다.
