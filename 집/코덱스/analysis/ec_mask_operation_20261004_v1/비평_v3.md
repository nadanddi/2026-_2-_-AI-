# DP1 입력 감사 v2 최종 코드·주장 범위 비평

2026-10-04 · 집 코덱스. audit_inputs_v2.py/input_audit_v2.json을 읽었다. 본 비평자는 새 모델 학습·추론·채점이나 원시 정답·잠금·test·EL1·제출 조회를 하지 않았다. 수치는 root 실행의 저장 결과를 확인한 것이며 본 비평자의 별도 재실행 수치가 아니다.

새 finite assert가 모든 제어5열의 유한성을 확인했다. 기존 두 범위의 missing0/negative0·24시간 완전 격자·9특징 scalar 일치도 재현되었다. 각 농장과 day<179/≥179의 네 층 모두 결측0이다. 전수 층의 일수는 F13 171+29, F47 173+27로400일이고 공개 층은156+24+158+22로360일이다. 공개 후기24+22=46일은 새 독립 관측일을 뜻하지 않는다.

각 일의0/6/12/23시 prefix를 잘라 재계산한9특징은 원 전체재생의 동일 prefix와 일치했다. 기록된 비교 원소162,000과145,800은 각각400/360일×(1+7+13+24)행×9열이며 수식과 맞는다. 이 검사는 해당 operation 함수의 실제 관측 prefix 재생을 지지한다. 임의 미래변조·다른 농장 perturbation·전체 모델 특징/출력의 인과 안전성 검사로 확대하지 않는다. 합성 결측 반례 및 일반 결측 안전성도 claim하지 않는 것이 맞다.
