## 이번 결과가 허용하는 결론

저장 결과는 F13/F47 전수 9,600행·400일과 기존 공개 DIAG10/seed7 ID의 8,640행·360일 모두에서 제어 5열의 결측과 음수가 0이라고 기록한다. 모든 일의 hour가 정확히 0..23이다. 원 DP1 벡터 함수와 독립 scalar 루프가 각각 86,400/77,760 특징 원소에서 일치했다. 따라서 이 감사 범위에서는 **실제 결측의 0 치환 또는 누락 시간의 행 위치 계산이 DP1 결과를 왜곡했다는 설명을 기각해야 한다.** 원입력의 모든 부분집합에도 새 NaN을 만들어 넣지 않는 한 해당 5열의 결측은 없다.

이는 결측에 강건한 일반 구현이라는 뜻이 아니다. 실제 결측이 0이므로 missing→0과 missing→1의 특징 차이 0은 자명한 불변이다. 원자료를 정제한 것도 아니며 대체한 것이 없는 민감도 재생이다. 두 대입은 모든 가능한 실제 관리값의 상·하한도 아니다. 특히 vent_max에서 1은 알려지지 않은 실제 최대를 제한하지 않는다.

## 코드 확인

- 현재 파일 위치에서 ROOT.parents[4]는 C:/work/farmai를 가리킨다. env.DATA로 train_X를 찾으며 DP1 모듈이나 p3.prepare를 import하지 않는다. AST에서 run_len/day_feats 두 함수만 선택해 np/pd 환경으로 실행한다.
- train_X는 usecols로 row_id와 제어 5열만 pandas에 적재한다. csv.DictReader의 별도 파서와 missing/zero/positive를 대조한다. 예측/정답 수치나 모델을 계산하는 호출은 없다.
- row_id 유일성, 공개 ID 집합의 8,640개 일치, 매일 hour 0..23을 확인한다. row_id 문자 위치로 farm/day/hour를 파싱하는 방식은 upstream core.identify와 같다.
- 독립 scalar는 원 함수의 zero-fill·행 위치 의미를 재현한다. 완전 격자와 결측 없는 실자료에서 둘의 일치는 구현 재생을 지지한다. 원 함수의 결측 의미가 올바르다는 검증과 구분해야 한다.
- --verify는 같은 코드로 같은 입력을 반복 실행하고 JSON 전체 일치를 검사한다. 재현성 확인이며 별도의 독립 설계 검증은 아니다.

공개 CSV는 DictReader가 행 전체를 문자열 사전으로 파싱한 뒤 validator/seed/row_id만 조회한다. target_values_accessed=0은 '정답 필드를 조회하거나 수치로 사용하지 않음'으로 해석할 수 있다. 공개 파일의 다른 필드 바이트 자체를 전혀 읽지 않았다는 뜻으로 과장하지 않는다. 원시 train_y는 읽지 않는다.

## 남아 있는 감사 범위

이번 실행에는 합성 NaN 반례, 비유한 값 명시 검사, 미래/다른 농장 perturbation, prefix truncation, 순서 permutation 검사가 없다. 또한 농장·초기/후기별 상세 분포를 출력하지 않았다. 이들을 수행하지 않았다면 '결측 의미 안전성·일반 시간격자 안전성·인과 perturbation PASS'라고 보고하지 않는다. 실제 값에서 zero+positive=row count이고 negative/missing0인 것은 보고할 수 있으나 양의 무한대는 positive로 세어질 수 있어 유한값 검사는 별도다.

synthetic NaN 검사는 [0,NaN,0]의 밀폐 누적, [양수,NaN,양수]의 가짜 curtain 전환/heat 단절을 확인하는 데 유용하다. 그러나 현재 실자료 문제나 성능 개선의 증거가 아니다. 이를 추가할 필요가 없다면 현 보고서를 입력 재생 PASS 범위로 한정하는 것만으로 충분하다.

공개 ID 부분집합은 과거 저장 공개 예측의 범위다. 실제 DP1의 p3.prepare가 그 시점에 구성한 lab·split·lock 선택을 다시 복원하지 않았다. 이번 규정상 그 파일들을 읽지 않았으므로 actual lab exact restoration이라고 부르면 안 된다. 마찬가지로 제어 입력 일치가 R3S/실제 계절v2 기준선 출력 복원을 뜻하지 않는다.

제어 5열 감사에는 DC7 weather missing coverage가 포함되지 않는다. DC7의 h>=5/nanmean이 6시간 완전 관측을 보장하지 않는다는 소스 지적은 별개로 남아 있다. DCP1에서 DP1/DC7 기여 분리, 같은 후기46일 재사용의 선택편향, 평가 입력에 대한 일반화, 운영과 EC의 인과관계 역시 이번 감사가 판단하지 않는다.

최종 비평 판정: **현재 감사의 좁은 입력 재생 PASS를 수용한다. 현 F13/F47 제어 입력에서 MASK/NaN→0 왜곡이라는 실패 원인 가설은 지지되지 않는다. 일반 결측 의미 안전성 또는 새 모델의 성능을 확인한 것으로 확대해서는 안 된다.**
