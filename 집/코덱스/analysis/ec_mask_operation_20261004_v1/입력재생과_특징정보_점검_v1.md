# 운영 특징의 결측·시간·정보 재생 점검

2026-10-04 · 집 코덱스. EC 개선 연구의 중간 진단이며, 새 모델 학습이나 개선 점수는 없다.

## 결측 가설을 현재 입력에서 좁혔다

DP1의 `fillna(0)`가 미관측을 닫힘·꺼짐으로 잘못 표현할 수 있다는 코드상 우려를 실제 입력에서 확인했다. F13/F47의 원입력 **9,600행/400일**, 기존 공개 DIAG10 입력 **8,640행/360일**에서 환기·보온·차광·난방·CO₂ 제어 5열의 명시적 결측, 음수, 비유한 값은 모두 0이었다. 모든 날에 0~23시 24행이 있었다. 농장별·전후반 구간별 결과도 같다.

따라서 이 범위에서는 명시적 NaN의 0 치환이나 행 누락으로 인한 시간 계산 오류가 발생했다는 설명이 지지되지 않는다. 이 의심을 근거로 결측 보정 모델을 새로 학습할 이유는 없다. 다만 제공된 숫자 0이 실제 꺼짐인지 센서의 별도 미관측 표기인지는 확인하지 않았다. 실제 DP1 학습 lab와 모델 예측도 복원하지 않았으므로 전체 실패 원인을 규명했다는 뜻은 아니다.

`audit_inputs_v1.py`에서 pandas 집계와 별도 csv 파서의 결측·0·양수 개수를 대조했다. 원 DP1 함수는 AST로 두 순수 함수만 추출했고, 9특징을 별도 스칼라 반복문으로 재계산했다. 원입력과 공개 입력의 164,160개 특징 대조가 일치했다. 중복되는 입력 범위를 합한 비교 횟수이며 고유 표본 수가 아니다.

새 `audit_inputs_v2.py`는 파일 SHA를 확인하고 입력을 다시 로드해 수치를 재현했다. 전체 날의 0·6·12·23시까지 관측 행만 남긴 특징을 전체 계산의 해당 prefix와 비교했다. 원입력 162,000개, 공개 입력 145,800개 비교가 일치했다. 이는 해당 9특징의 prefix 재생 검사이며 전체 모델의 인과 안전성 검사는 아니다. v2 반복 자체는 동일 구현의 재현 검사이고, 별도 수치 방법은 v1의 csv 파서와 스칼라 반복문이다.

## 같은 특징도 모델에 따라 추가하는 정보가 다르다

완전한 0~h시 관측과 비음수 제어값에서 다음 식이 성립한다.

```
환기 개방 누적 시간 = (h + 1) × (1 − 환기 0 비율)
CO₂ 가동 누적 시간 = (h + 1) × (1 − CO₂ 0 비율)
```

원 시각의 sin/cos로 h를 복원하고 기존 core의 누적 0 비율을 사용해 원입력 9,600행에서 두 count 19,200개를 대조했다. 최대차는 1.77635684e-15였다. 이 항등식은 결측·음수·시간 누락이 생기면 일반적으로 보장되지 않는다.

ET의 FULL에는 누적 0 비율과 시각 sin/cos가 이미 있어서 이 두 count를 정보적으로 재구성할 수 있다. LGB와 MLP의 BASE에는 누적 0 비율이 없어 이 count가 새로운 누적 이력을 전달한다. DC5의 구성원별 FS/BS 전달도 텍스트로 확인했다.

따라서 운영 특징을 모든 구성원에 넣고 얻은 결과만으로 각 모델의 기여를 분리할 수 없다. ET에서 결정론적으로 중복이어도 한 열로 제공하면 분할 표현을 도울 수 있으므로 무용하거나 삭제해야 한다고 판단하지 않는다. 이 결과는 구성원별 특징 배치를 별도로 대조할 이유가 되며, 성능 개선을 입증하지는 않는다.

근거는 `audit_count_identity_v1.py`, `count_identity_v1.json`, 독립 비평 v4다. 비평가는 core 상수와 실제 DC5 전달을 확인하고 수식·주장 범위를 검토했다. 저장 수치의 별도 모델 재학습은 하지 않았다.

## 저장 범위와 다음 순서

- 원입력은 수정하지 않았다. 민감도 점검용 복사본에만 결측 0/1 대입을 했고 실제 결측이 없어 결과가 같았다.
- 공개 예측 CSV는 ID 선정을 위해 문자열로 파싱했지만 target 필드를 조회하거나 수치로 사용하지 않았다. 원시 EC 정답·잠금·EL1 재채점·test·새 제출·fit/predict/score는 0이다.
- TabDPT family20의 source·66셀·15칸·p<.00125·조정 CI 기준은 바꾸지 않았다. 실행 중인 worker도 재시작하지 않았다.
- 다음 후보는 기존 실제 계절v2를 기준으로 구성원별 운영 특징 전달을 분리하는 단일 변경을 검토한다. 이전 DP1/DP2와 중복되는 부분을 확인하고, 실행 전에 코드·판정 기준을 고정해야 한다. 아직 새 후보를 학습하거나 제출 추천으로 분류하지 않았다.
- 중간 Claude 갱신에서 새 카탈로그6.286의 submission13 제작 기록을 읽었다. 이는 동료 보고의 출처 확인이며 해당 CSV/ZIP/test 예측을 읽거나 형식·재현·성능을 독립 검산하지 않았다. 현재 분석의 개선 근거로 사용하지 않는다.
