# submission_10 EC 계절 v2 제작 사전 고정 · 2026-10-02 집 코덱스

사용자가 8회차 요청서대로 제작을 승인했고, 후속 지시로 온도는 팀원 모델이 채우도록 빈칸으로 변경했다. CSV는 row_id,sub_temp,sub_ec 1440행이며 sub_temp는 모두 빈 문자열이다. 아직 완성 합본 또는 플랫폼 제출로 기록하지 않는다.

- F13/F47 정답이 있는 전체 400일 9600행으로 최종 fit. 이미 소비한 잠금 40일도 fit에 포함하며 해당 구간 재채점/튜닝은 하지 않는다.
- 기존 검증 통과 계절 v2 그대로: .8×(.6ET+.3LGB+.1MLP의 시드7/101/2024 평균)+.2×PFN V2 문맥1..4 평균. day만 제거한 뒤 season을 마지막 열에 추가(FULL38/BASE14). 후처리는 현재/당일현재까지평균 .5/.5 및 전체 학습 EC 범위 clip.
- DC4의 학습 1차(day<179) 날씨 4×24 벡터 표준화, 거리≤.05 짝 기준점, PAV 등위회귀, 동일 온실 일차 보간. 평가 날씨/다른 평가 온실/미래 평가 입력은 계절 변환에 사용하지 않는다. 학습한 전처리와 모델 파라미터는 고정한다.
- ET600/leaf1, LGB Tweedie800/lr.03, MLP128/64/alpha.01의 기존 설정 유지. R3 fit/BLAS2, ET predict는 결정적 합산을 위해1스레드. PFN CPU float32/estimator4/context2000/random1..4/preprocessing1/torch4, 체크포인트 SHA256 2ab5a07d5c41dfe6db9aa7ae106fc6de898326c2765be66505a07e2868c10736. 새 비중/시드 선택 없음.
- 학습 RAW10은 평가 MASK 허용 열만, 학습 변환에만 외기4열 사용. 평가 특징은 같은 온실의 현재까지 입력만. 다른 온실·미래 평가 RAW 변조와 평가 행 순서 변경으로 대상 특징이 불변인지 확인. PFN 각 문맥에서 대상8행만 별도 예측하여 전체 평가 배치의 대상8행과 bit 동일인지 확인.
