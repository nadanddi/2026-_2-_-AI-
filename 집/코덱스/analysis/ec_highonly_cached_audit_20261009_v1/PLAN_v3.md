# 고EC 전용 EC 수치 모델의 저장 검증 재집계 계획

사용자 질문은 일반일을 제외하고 학습한 고EC 전용 모델의 고EC일 수치 예측 성적이다. 고EC 여부만 분류하는 해석에서는 상수 고EC 판정으로100%가 가능해 의미가 없음을 설명한다. 수치 해석으로 기존 MX1 저장 예측을 검증하고, 중복 학습은 하지 않는다. 기준은 일평균 sub_ec>=1.2 고정이다.

MX1 DIAG10 저장 CSV10개(공개360일8640행)에서 고EC26일624행을 평가한다. H_3737/5858/7979는 학습 fold 내 고EC날만 사용한 R3(.6ET+.3LGB+.1MLP)이고, BASE는 전체 날을 사용한 같은 모델이다. 시드별 및 동일3시드 평균을 보고한다. 고EC일 선택은 정답을 알고 만든 조건부 모집단이며, 실전 전체 성능이나 고EC 구분 성능과 다르다. 이 저장 검증은 묶음 DIAG10이고 LOOCV가 아니다.

중요한 한계: H 모델의 supervised fit과 모델 내 전처리는 고EC 부분만 사용하지만, MX1의 입력 season은 전체 fold 입력으로 계산하고, 공통 shrink 및 전체 학습 라벨 범위 clip 후처리가 있다. 따라서 일반일의 모든 정보가 특징 생성과 후처리에서도 완전히 삭제됐다고 주장하지 않는다. 엄격하게 일반일 정보를 전부 제거한 새 LOOCV는 이번 작업에서 수행하지 않는다. 일반일 추가학습0, 새fit0, 새최종모델0, 제출0이다.

기존 분류기 metadata/registration 및 CT1 공개 OOF를 키·정답 참조로 검산한다. MX1의 query 키/시간/정답이 같은지, H 학습 고EC날 수가 같은 제외 규칙의 공개 학습날 수와 일치하는지 확인한다. 공식train_y 값 추가읽기0·소비40 성능재검증0·공식test0·이전대회자료0. 원본CSV/모델코드/참조등록파일 SHA와 고정 계획/코드 SHA를 등록한다.

주 지표는 고EC일의 시간별 sub_ec RMSE다. MAE/bias, 실제와 예측 평균·표준편차, 하루평균 EC의 MAE/RMSE, 일평균 절대오차<=.1/.2/.3일수, 농장×앞/뒤구간, 시드별 RMSE 범위를 함께 보고한다. 사전 정의된 모든 표본/시드/구간을 보고하고 좋은 것만 선택하지 않는다. 고EC 학습날의 상수평균 예측을 같은 fold 규칙과 원공개 정답으로 재생성해 비교한다. 이 상수는 고EC라는 사실을 이미 아는 기준이라 분류 성능과 무관하다. 검정이나 채택 판정은 하지 않는다.

계획→처음2fold의 중간 집계→전체10fold의 최종 독립 비평. 동일26일 평가와 각날24행을 assert한다. 중간/최종 분석표의 숫자는 별도 CSV loop·math.fsum 산술로 교차확인한다. 신뢰도는 산술 높음/새로운날 일반화 낮음, 한계는 고EC를 미리 안다는 조건·작은26일·기존자료노출·위의 일반 입력/후처리 공유이다. 다른AI 파일은 읽기만 하고 내 새 폴더에만 산출물을 쓴다. PLAN_v1의 미완성 문안을 보존하고 이 PLAN_v2를 실행 계획으로 고정한다.

## 계획 비평 반영

원 CT1 코드도 SHA에 추가하고 모든 저장 숫자의 유한성을 검사한다. 전이 참조 코드를 모두 복원한 학습 재현은 아니라서 누수가 전부 배제됐다거나 일반일 정보가 모든 단계에서 삭제됐다는 주장은 하지 않는다. 코드는run_v2로고정,최종결과는 기존조건부회귀성적과 분류단일class의100%무의미를 구분해서 설명한다.
