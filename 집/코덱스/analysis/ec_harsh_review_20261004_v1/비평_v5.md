# HM1 완전 nested 비중 사전안 비평 · 2026-10-04

실행 전 사전안은 통계적으로 가능하다. 외부 정답을 쓰지 않고 inner의 실제 계절v2 손실로 비중을 학습하므로 이전 HM1의 고정50%와 구분된다. 아래 세 경계만 더 명확히 고정할 필요가 있다. 코드 작성·학습·새 점수 계산 없이 기존 CPU/HM1/support 코드만 읽었다.

1. **비중의 단위·분모·clip과 prefix 순서를 명시한다.** w는 outer×seed마다 scalar1개인지, 두 farm/모든hour의 전체 innerquery행을 같은 비중으로 사용하는지 고정한다. 게이트0행을 mean 분모에서 빼면 같은 λ.01도 다른 수축이 된다. 제시식은 전체 innerquery의 `mean((base−y+w·d)²)+.01w²`를 최소화한 뒤[0,.5]로 제한하는 계산이다. innerR3S는 `clip(shrink(r3raw),inner 전체훈련 범위)`, innerbase는 `clip(shrink(.8r3raw+.2PFNbag),inner 전체훈련 범위)`, sp는 `clip(shrink(spraw),inner 고EC훈련 범위)`로 분리한다. gate는 이미 shrink된 R3S의 farm/day별0..h 누적평균≥.9이고, raw R3 평균으로 바꾸지 않는다. d에는 .8을 한 번만 넣으며 추가 .8/.48 또는 후보 전체의 두 번째 shrink를 하지 않는다. innerquery의 d가 전부0이면 w=0이다. hightrain이 비어 specialist를 fit할 수 없는 경우의 사전 fallback/중단 정책도 명시한다.

2. **완료 CPU의 정합성은 충분히 감사하고 HM1 원캐시의 provenance 한계를 숨기지 않는다.** 기존 CPU 코드는 row_id/inner_train_id/context_row_id와 분할·배치 반복을 검사하므로, 전체22CPU+88PFN의 완료·유한성·동일행·context∈innertrain·±1 buffer·season-last/checkpoint 정합성 확인 후 재사용하는 방향이 맞다. HM1 코드의 specialist CSV는 row ID와 n_spec_days만 보존하고 훈련행 ID/hash/key를 직접 저장하지 않았다. 오늘 계산한 훈련 hash와 과거 CSV 자체 hash가 있다고 과거 학습 provenance가 새로 증명되는 것은 아니다. 공개 cached labels로 각fold의 정확한 hightrain 행/목표/FS순서/season/범위·기존 코드/의존성 출처를 재구성하고 첫fold 재fit을 대조하되, 이는 첫fold 수치 확인과 전fold 정적 정합성 확인이라는 범위로 보고한다. 출처 또는 fold별 count/행 정합성이 맞지 않는 캐시는 조용히 재사용하지 않는다. 직접 provenance가 확보되지 않으면 추가 outer specialist 재fit 또는 캐시재사용 한계를 명시하는 별도 고정 절차가 필요하다.

3. **목표식과 유효성 주장의 범위를 한정한다.** inner의 w는 clipping 전 correction과 L2 벌점에 대한 해이며 최종clip 후 RMSE를 정확히 최적화하는 해는 아니다. 또한 작은 inner specialist와 전체 outer specialist의 고EC일 수·정답범위·계절anchor가 달라 교정량이 이동할 수 있다. w=0/상한에 붙는 빈도, 표지행·날짜 수, inner/outer hightrain 수·범위·anchor 차이를 기록하되 결과를 본 뒤 λ·bounds·gate를 고르지 않는다. 원자료24시간을 신뢰구간에서 독립24표본으로 세지 않고 기존 farm/date block 검증을 유지한다. 실제 계절v2의15칸 및 family17 기준을 통과해야 하며 R3S 기준의 과거9칸 도함수 음수로 이 시험의 성공을 예단하지 않는다. PFN.2는 원시 대수의 비중이 고정이라는 의미이고 final clip 이후 유효 기여도가 항상 .2라는 뜻은 아니다. 기존 자료로 누적 설계한 사후 후속안임을 기록하고 완전 독립 신규 발견처럼 표현하지 않는다.

기존 모든15칸 방향 기준, family17, 전체 CPU 완료 선행조건, EL1/잠금/test0을 유지한다. 이 비평은 새안의 합격 판정이 아니다.
