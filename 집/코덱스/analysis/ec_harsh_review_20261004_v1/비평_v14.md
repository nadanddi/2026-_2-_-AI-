# 완료 family19 LOG 혼합 독립 감사 · 2026-10-04

**사전 고정한 LOG 혼합안의 기각은 타당하다. 계산식에 검증 실패를 설명할 오류를 발견하지 못했다.** DIAG10과A의6칸은 개선되지만B의3칸은 악화하고 EXT10·EXT12의6칸은 동률이다. 내부에서 학습한 단일 비중이 외부에서 항상 이득을 보장하지 않았다는 범위로 해석한다. 모든 가변 비중·LOG 계산법·EC 개선 가능성을 기각하는 결과는 아니다.

15칸 점수를 csv/math.fsum과 Decimal로 다시 합산했으며 저장 score와 일치했다. 농장층화·5기록 block·20,000회 bootstrap도 공개 OOF에서 다시 계산해 p_worse/CI가 정확히 일치했다. 부모의1,864,728검사 PASS와 첫fold oldET/LOG/ratio leaf 반복적합 차이0·배치 차이0·미래변조 PASS는 저장 검증 증거로 읽었다. 이번 감사에서 해당 모델 반복적합은 하지 않았다. v10·v11의 실행 전 source/guard 감사와 이번 산출물 계산 정합성 확인은 반복 공개검증의 독립성을 대신하지 않는다.

## 2. B2의 큰 비중은 계산 오류가 아니다

B2의 비중은7/101/2024에서 **.555192/.477923/.554123**이다. 저장된 내부1,680행에서 num=mean(e*d)는−.007529/−.006349/−.007546이고 den=mean(d²)+.01은.013561/.013286/.013617이다. 비중식·Decimal·KKT 모두 일치했다. 내부 MSE는 각각 .055827→.048565, .053858→.048540, .056714→.049463으로 감소했으며, 벌점 포함 목적도 감소했다.

같은 endpoint 방향에 대해 외부B2의1,224행에서 mean((base−y)*d)는 **+.000229/+.001169/+.000951**였다. 내부와 외부의 이 cross term 부호가 달랐다. 외부 손익은 `delta_MSE=2*w*cross+w²*mean(d²)`로 정확히 재현된다. 이 고정 B2 endpoint에서 cross와d²가 모두 양수이므로 양의 비중 경로는 외부 제곱오차를 늘리는 방향이다. 이 수학 진단으로 새 비중을 선택하지 않았다.

반론: 외부에서 작은 비중을 다시 고르면 살릴 수 있지 않은가. 답: B2의 고정 endpoint에 대한 사후 산술은 이 구간의 양의 비중 방향 한계를 보여준다. 하지만 이를 이용해B2를 끄거나 새 gate를 고르면 외부 정답으로 재선택하는 것이다. 현재 기각을 유지하고 새로운 안은 별도 사전등록·독립 검증이 필요하다. **B2 기여와 수식 확인 신뢰도는 높음**, 기여의 원인 규정은 낮음이다.

## 3. 0비중 fold의 의미와 검증 한계

총66cell 중 **25개w=0**,41개는0<w<1이며w=1은0개다. DIAG10은13/30개0, A는0/15개0, B는6/15개0, EXT10·EXT12는각3/3개0이다. 모든0비중cell은 내부 num≥0과 경계 KKT를 충족했다. 이때0은 고정된 내부 목적의 해이며 계산 실패나 결측 fallback이 아니다. 내부 num>0인 경우 λ가 양의 denominator를 바꾸는 것만으로 비중의 부호가 바뀌지는 않으므로, “λ가 커서0이 된 것”만으로 설명할 수도 없다.

다만0이 외부에서 최선이라는 뜻은 아니다. **B1의3시드는 내부 num>0으로w0**였지만 외부 cross는−.001789/−.001677/−.001235였다. 내부 방향 판단이 외부에 그대로 전달되지 않은 사후 사례다. 반대로B4는 내부·외부 cross 모두 양수였다. 이 결과는 외부 정답을 보고0비중 fold를 켜는 근거가 되지 않는다. EXT의 동률은 학습 규칙이0을 선택해 기준선 예측을 그대로 사용한 결과이며, LOG endpoint가 외삽에서 검증됐거나 개선됐다는 주장도 아니다.

outer query 정답을 비중 학습에 넣은 경로는 소스와 저장 산술에서 발견하지 못했다. 그러나 모든 결과는 이미 반복해서 본 공개 검증이다.3시드는 같은 온실·정답·분할을 공유하고, 내부 최적화 뒤 내부 MSE 감소는 독립 성능 증거가 아니다. 무접촉 최종 검증이나 실전 일반화 증거는 이번에 추가되지 않았다.

후속 원인 분리가 필요하면 family19 자체의 같은 날짜/조건에 대한 **e·d·cross term 전이**를 기존 고정 캐시에서 먼저 기록해야 한다. v13의 다른 보정식에서 얻은 x 집계 부호를 이 LOG 방향의 원인으로 옮기면 안 된다. 내부 표본·학습량·추정 b·예측수준 구성이 함께 움직이므로 모델이나 threshold를 바꾸는 실험은 변수 하나를 고정해 별도 계획으로 다룬다. 지금B2 제외·0비중 재선택·새후처리·가중치 변경은 하지 않았다.

새 모델 fit/원시 정답 파일/EL1/잠금/test/제출물은0이다. 이번 재계산에서 저장 점수·비중·방향에 정정할 수치는 발견하지 못했다.
