## F47/132가 낮게 계산되는 경로를 실제 트리로 추적

후속 `../ec_routing_trace_20261004_v1/trace_routing_v1.py`는 알려진 어려운 DIAG10 fold5, 시드7의 원 ET를 다시 학습하고 각 tree→leaf→훈련 날짜 가중치를 복원했다. 학습274일/6,576행, 검증28일. 가중치 합/캐시/예측 분해604검사 통과, 예측복원 최대차8.22e−15. 성능 개선 후보가 아닌 **사후 계산경로 진단**이다.

F47/132의0시 실제 EC2.796, 실제 계절v2 예측1.199591, ET구성원1.236382. ET가 평균하는 학습행 가중치의63.3333%는 학습 일평균≥1인 날짜에서 왔지만, 선택된 그 행들의 평균은1.57695다. 나머지36.6667%의 평균은.6481273이다.

`0.6333333×1.57695 + 0.3666667×0.6481273 = 1.2363817`.

즉 해당 ET는 높은 EC 학습사례도 이용했으나, 선택한 높은 사례의 크기가 실제보다 작고 일반 사례가 섞여 낮아졌다. 주요 출처는 F13/120(18%), F47/229(16%), F47/216(12%), F47/231(10.17%), F13/214(10%). 이는 실제 함수의 계산 분해이며 **그날 입력에 정보가 없다는 증명이나 관리 원인의 식별이 아니다**. 선택된 한 어려운fold를 전체 실패에 일반화하지 않는다. 진단용 학습 정답 고EC 분류를 추론 특징으로 넣지 않았다.

## 현재 진행과 다음 확인

- CPU 내부 정합 보정: 원tool60252가 사라지고 B0 CPU까지 멈춘 기록 확인 후 같은 소스·기존캐시를 번들Python으로 재개했다. 실패한 사용자Python 실행은 run_resume_v2.log, 정상재개는 run_resume_v3.log/tool68739. DIAG10/A 완료·B0 완료·B1 PFN 진행. 프로세스가 살아 있으면 중복 실행 금지.
- LOG_PARTITION_MEAN: 사전d7d1e53/family16, tool39880. train-only 계절기준 b, log(y/b) 분할, 각 leaf에서 학습 ratio 산술평균을 저장해 b_query로 복원한다. 원 LR1 기하평균보다 같은 분할의 raw는 올라가지만 일반 사례도 올라갈 수 있다. 첫fold 원ET/LR1 재현·재학습·배치·인과 검사 통과, 전체 검증 미판정.
- 로그 수식 한계: ratio 산술평균은 ratio SSE 최적이다. leaf 안 b_i가 서로 다르면 원 EC SSE 최적은 sum(b_i*y_i)/sum(b_i²), 즉 b_i² 가중 ratio 평균이다. 현재 후보를 원단위 정확최적이라고 부르지 않고, 진행 중 코드에 다른 계산을 추가하지 않는다.
- HM1 후속: R3S 기준 작은 혼합 방향은9/9 유리하나 실제 계절v2는6/9뿐이다. 오라클 w≈.1을 그대로 후보로 채택하지 않는다. 동일레시피 내부예측 완료 후 train-only로 비중을 학습하는 완전중첩 시험을 별도 사전 정의할 여지가 있다.
- 문헌 검토는 `../ec_papers_20261004_v1/문헌검토_v1.md`. 희귀회귀 손실/SMOGN/조건부 diffusion의 목적과 평가 한계를 조사했다. SERA의 희귀구간 개선이 원전체MSE 개선을 보장하지 않으며, 국내 Kang 논문은 초록·공식 발표·저장소 일부만 확인했다(본문 미확인). 외부 데이터와 합성표본을 현재 모델에 넣지 않았다.
