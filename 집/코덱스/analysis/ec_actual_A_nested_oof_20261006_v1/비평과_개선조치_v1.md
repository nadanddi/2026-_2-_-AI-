# 혹독한 사전 비평과 개선책 반영

2026-10-06 집 코덱스. 사용자 요청에 따라 독립 비평가가 설계·코드·검산·복구 절차를 세 차례 검토했다. 실제 학습 전 비평이며 결과 비평을 대신하지 않는다.

모델 함수와 분할 함수 AST, 준비 데이터의 records/runtime/inputs/features/params/seeds 등은 초기안과 동일하다는 독립 검토를 통과했다. 실제 A를 대리 모델로 바꾸지 않았다. 최종 run_v4.py/verify_v4.py/preparation_v4.json을 main 441d975에서 실제 fit 전에 등록했다.

실행 PID와 시작 시각은 launch_v4.json에 저장했다. 이 문서 작성 시점은 학습 진행 중으로, 첫 재학습 검산·전체 OOF·완료 검산은 아직 완료를 주장하지 않는다.

완료 뒤 남은 독립 감사: receipt 파일 집합의 완전성, 부수 배열·checkpoint SHA, ZIP 항목별 원 파일 SHA, 전체 예측의 실제 분할/정답/산술 및 경계 사례 집계를 다시 확인한다. 전체 결과를 혹독하게 평가한 뒤 문제별 개선책과 해결되지 않은 한계를 함께 전달한다. 새 분류기 성능·RMSE 개선은 별도 실험 대상이다.
