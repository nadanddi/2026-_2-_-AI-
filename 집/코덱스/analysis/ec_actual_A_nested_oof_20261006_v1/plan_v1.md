# 실제 A 중첩 학습 예측 — 실행 전 고정

사용자 요청: 각 외부 학습 집합 안에서 실제 A를 다시 교차 학습한다. 새 분류기/전문가 결합/제출은 이 작업에 포함하지 않는다.

- 외부: 기존 DIAG10 10개·A 5개·B 5개, 잠금 EL1 제외. 공개 360일의 감사된 기존 OOF 정답만 사용한다.
- 내부: 각 외부 학습 집합에서 농장별 정렬한 날짜의 5일 블록을 `(순번 // 5) % 4`로 배정. 각 검증 날짜와 같은 농장의 ±1일은 내부 학습에서 제외. 날짜의 24시간을 같이 묶고 전체 외부 학습 행을 정확히 한 번 예측한다. 이전 대리 실험과 같은 분할이며 정답을 보고 바꾸지 않는다.
- 외부 검증 행은 내부 학습·내부 query·TabPFN context 어디에도 들어가지 않는다. 내부 query 정답은 학습이나 전처리에 쓰지 않는다.
- season 변환은 매 내부 학습 날짜만으로 재적합. 외기 표준화는 내부 학습 1차 기록만. 내부 query 외기 전체·미래 입력을 보지 않는다. 원래 FULL/BASE 입력, 현재 및 prefix 특징 유지.
- 실제 A: R3=.6ET+.3LGB Tweedie+.1MLP, 시드7/101/2024. TabPFN V2 CPU float32 4estimators, context max2000, 문맥 시드1/2/3/4. raw=.8R3+.2평균PFN, 이후 .5현재raw+.5같은날prefix raw평균, 내부 학습 EC min/max clip. 모델·하이퍼파라미터·특징 순서는 원 A와 동일.
- 예상 80개 내부분할, R3 240개(구성원720적합), PFN320개(내부추론 앙상블4는 유지). 별도로 첫 내부분할의 R3 seed7 및 PFN seed1 재현 검산. 첫 PFN query 첫8행 prefix 배치 일치도 확인.
- 개별 구성원 NPZ+JSON 해시·입력·학습/query/context ID·runtime·source 서명 저장. 일부 결과를 성능 개선으로 판정하지 않는다. 중단되면 같은 등록 코드·동일 데이터만 검증하여 재개한다. 기존 파일 변경 금지.
- 완료: 각 외부 학습 집합/시드의 전체 OOF CSV(60개), 경계 사례 및 시드 합의 CSV, 전체 receipt, 독립 stdlib/fSum 산술·분할·포괄성·context 감사. 실험용 재현 ZIP·설명 문서. 정의 문턱은 high1.0, low score1.2, 선택.9 및 h0/6/12/23 유지.
- 이 내부 OOF와 해당 외부 검증의 원 A 예측은 이후 분류기 학습/검증의 올바른 쌍이다. 전체 nested OOF를 외부 fold 구분 없이 섞어 재분할하지 않는다. 새 구별기 성능 및 RMSE 개선은 별도 실험에서 측정한다.
- 운용위 원 PDF 미확보; 저장소 추가안내 요약에 기반. 평가 input 통계 적합/잠금 정답/리더보드 계수 선택 없음. 기존 TabDPT 작업에 간섭하지 않는다.
