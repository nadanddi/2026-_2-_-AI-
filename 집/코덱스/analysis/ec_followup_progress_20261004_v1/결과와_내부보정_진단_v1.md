# EC 후속 실험과 내부 보정 진단 · 2026-10-04 · 집 코덱스

완료한 두 후보는 채택 기준을 통과하지 못했다. 새로 남은 단서는 **높은 예측값에서 필요한 보정의 방향이 내부 검증과 외부 검증 사이에 달라진다**는 것이다. 이 차이의 원인은 아직 식별하지 않았다. family19의 내부 학습 LOG 혼합은 별도로 실제 학습 중이며, 이 문서 작성 시점에는 전체 성능을 판정하지 않았다.

## 비교 기준과 정보 범위

- 실제 EC 계절 v2: .8 R3 + .2 기존 PFN, R3 = .6 ET + .3 Tweedie LGB + .1 MLP. 기존 인과적 shrink와 학습 범위 clip을 사용한다.
- 공개 검증 DIAG10/A/B/EXT10/EXT12 × 시드 7/101/2024, 22 outer fold × 3 seed. 전체 83,160행은 검증기 사이에 같은 온실일이 재등장하는 발생행이며 독립 관측 수가 아니다.
- DIAG10은 시드별 360온실일·8,640시간행이다. 정답 일평균≥1인 고EC 31일·744행, 일반일 329일·7,896행. 정답으로 나눈 구간은 설명용이며 평가 행 특징으로 넣지 않았다.
- 원시 EC train_y, 잠금, EL1 재채점, test 예측, 외부 데이터 학습, 새 제출물은 사용하거나 만들지 않았다. 온도 새 실험도 없다.
- 실행 전에 고정한 모든 시드 × 모든 검증기 같은 방향 및 DIAG10 p_worse < .025/k, 조정 CI 상한<0 기준을 유지했다. 클로드의 C6.247 제안과 직접 제공 AGENTS/메모리의 차이는 소급 적용하지 않았다. p_worse는 고정 bootstrap에서 손실차≥0인 비율이다.

## 3. 내부와 외부에서 보정 방향이 뒤집히는 단서

같은 고정 예측을 0/6/12/23시 현재까지의 평균 x와 정답 일평균으로 다시 조사했다. 31,236발생행/수동 prefix 31,236대조 PASS. 별도 검산에서 outer 13,860행도 원 OOF로 prefix·보정식을 재구성해 최대차 2.22e−16이었다.

사후 설명 구간 x≥.9의 seed7:

| 시각 | 내부 필요 보정 | 외부 필요 보정 | 외부에 적용한 평균 보정 | 내부 발생/고유일 | 외부 발생/고유일 |
|---|---:|---:|---:|---:|---:|
| 0시 | −.057438 | +.073326 | −.008165 | 72/32 | 39/39 |
| 23시 | −.044576 | +.115942 | −.005351 | 77/32 | 42/42 |

나머지 두 시드도 같은 부호 역전이다. 필요 보정은 `정답 일평균 − 현재까지 baseline 평균`이다. 0시 실제 시간별 잔차와 같지 않으며 23시 적용 보정도 하루 평균 보정과 같지 않다. 23시 x의 평균은 내부 약1.202, 외부1.211~1.221인데, 실제 고EC 비율은 내부 약52%, 외부71~73%였다.

이 결과는 **레시피 정합성 수리만으로 내부/외부의 조건부 관계 차이가 없어지지 않았다**는 근거다. 여러 outer fold에 같은 내부 날짜가 반복되므로 77발생을 77독립일로 세면 안 된다. 농장·시기·학습량·예측 구간 선택이 섞여 있어 표본 선택, 수축, 분포 차이 중 하나를 원인으로 확정할 수 없다. 같은 날짜의 내부/외부 예측 변화와 구성 차이를 먼저 조사할 가치가 있다.

근거: `diagnose_full_shift_v1.py`, `full_shift_diagnostic_v1.json`, `full_shift_summary_v1.csv`, own local `full_shift_records_v1.csv`; `비평_v12.md`의 독립 csv/fsum 검산. 집계 부호의 신뢰도는 높음, 원인 규정은 낮음이다.

## 4. family19 실제 학습 진행

사전 커밋 **ce6a835**, 실제 소스 **run_v3.py**, source SHA f3a66402c3dba9fff5585d9c64e478d2f271fb57593c2f683682d72db0d9f542. 기존 ratio 산술 LOG/b_query endpoint와 실제 v2 사이의 비중만 내부 자료에서 배운다.

내부 query 전체의 e=p0−y, d=이미 clip한 p1−p0에 대해

`w = clip(−mean(e*d)/(mean(d²)+.01), 0, 1)`

를 고정하고 outer에는 `p0+w*(p1−p0)`를 적용한다. 외부 정답으로 w를 고르지 않는다. 양 endpoint가 같은 학습 범위 안에 있으므로 마지막 clip은 항등이다. w=0인 폴드도 제외하지 않는다.

현재 공개 baseline/내부22CPU/88PFN/원 LOG66cache·ordered ID·source/input/feature SHA·런타임 5종을 preflight와 cell resume에서 검사한다. 첫 fold 원 ET/LOG/ratio leaf 재학습 차0, raw 배치 차0, 미래 및 다른 농장 변조 6대조 PASS, KKT 및 prefix PASS다. 부분 파일과 runtime 불일치는 적합 전에 중단한다.

14:44 KST 기준 DIAG10 10fold 완료, A4 진행. **전체 점수/채택 미판정**. 완료 후 `verify_full_v3.py --experiment ec_nested_log_blend_20261004_v1 --recipe logblend --family 19` 및 독립 비평을 실행한다. 별도 고EC specialist family17은 준비만 했고 학습하지 않았다.

## 5. 다음 행동과 보존

1. 실행 중인 family19를 재시작하지 않고 끝까지 검산한다.
2. 고정 CPU 예측에서 동일 온실일의 내부/외부 이동과 농장·시기 구성 차이를 조사한다. 사후 진단을 새 성능 점수나 비중 선택으로 사용하지 않는다.
3. TabDPT 공식 태그/체크포인트·의존성·배치 독립성의 적용 준비를 마친다. 이 문서 시점에는 가중치 다운로드/설치/성능 측정0. 기존 HF hub와 충돌하므로 자신의 local에 분리된 환경을 준비한다. 별도 PFN3.5 라이선스 사용자 동의는 미응답이며 동의나 우회로 간주하지 않는다.
4. 완료 결과·코드·비평·문헌과 공유 상태를 저장한다. 새로운 제출 권장 후보는 아직 없다. 기존 W40G/EC 계절 v2를 유지한다.

이 자료는 반복 열람한 공개 검증 결과다. 튜닝에 쓰지 않은 최종 홀드아웃 성능을 보고한 것이 아니며, 독립 재학습은 명시한 첫 fold 감사에 한정된다. 전체 후보 검산을 전체 모델 독립 재학습으로 표현하지 않는다.
