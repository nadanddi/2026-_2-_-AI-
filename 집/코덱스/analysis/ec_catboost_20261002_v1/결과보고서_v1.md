# EC CatBoost 단독 비교 결과와 독립 검산

2026-10-02 · 집 · 코덱스. **고정 CatBoost 단독 1안은 기각한다. 기존 EC v2를 유지한다.** 시드 3개 × 5개 검증기에서 2/15칸만 개선했고, 각 시드 DIAG10 본페로니 통계 기준도 실패했다. 최종잠금 40일 채점·평가 입력값 사용·제출물 생성은 없다.

## 무엇을 비교했는가

사전등록 main `672addc`. 동일 FULL38 특징·기존 22폴드·잠금 및 검증일 ±1일 제외·시드 7/101/2024를 사용했다. CatBoost 1.2.10, CPU 2스레드, 깊이 6, 1,200회, 학습률 .03, L2 3, Bernoulli .8, rsm .8, native 결측 Min으로 고정했다. 외부 검증 정답을 학습에 넘기거나 조기종료하지 않았다. 후보에는 기존과 동일한 당일 인과 수축 .5 및 학습 정답 범위 자르기를 적용했다. 비교 기준은 잠금 제외 재학습 phase3의 동일 시드 v2다.

CatBoost 단독 대 v2 앙상블의 비교이므로, 알고리즘만의 순수 효과를 분리한 실험은 아니다. 결과 뒤 설정·가중치·특징을 고르거나 다른 안으로 변경하지 않았다. 같은 캠페인의 멤버 제거 4안과 합쳐 family는 5안이다.

## 원시 예측·후처리와 학습 격차

DIAG10 시드 평균 원시 RMSE는 **.226582**, 후처리 **.230302**, v2 **.213874**다. 표준 후처리는 이번 후보 DIAG10 점수를 악화시켰지만, 원시 예측도 v2보다 나쁘다. 따라서 후처리를 빼기만 하면 기존 모델을 이긴다는 근거는 없다. A/B/EXT10에서도 개별 시드 후처리가 원시 점수를 .80~1.28% 악화시켰으며, EXT12에서는 .54~.94% 개선했다. 이는 후처리 설정 재선택 근거로 사용하지 않는다.

DIAG10의 저장 학습폴드 평균 RMSE는 원시 .027212~.027254, 후처리 .051919~.051960이다. 검증폴드 평균은 .220294~.223072다. 학습과 검증 사이의 격차가 크지만, 이를 과적합 한 가지 원인으로 단정하지 않는다. 숨은 하루 상태, 표본·구간 차이도 설명이 될 수 있다. 학습 점수는 원 실행 manifest를 집계한 수치이며, 학습 예측을 다시 생성해 독립 재현한 수치는 아니다.

## 독립 검산과 한계

`audit_catboost_v1.py`를 학습과 별도로 실행했고 `audit_verified_v1.json`의 상태는 PASS다.

- 66개 fold×seed 캐시의 파일 해시, 원 실행 코드·프로토콜 해시, 같은 v2 캐시와의 row_id·수치 대응을 확인했다.
- 원시 train_y를 csv.DictReader로 다시 읽고, 잠금일은 EC 숫자 변환 전에 제외한 뒤 모든 발생행 라벨과 대조했다.
- 15개 시드×검증기 RMSE를 math.fsum으로 다시 계산해 원 요약표와 대조했다.
- 모델 코드를 재사용하지 않고 접두 누적평균 및 학습 정답 범위 clip을 직접 계산했다. 최대 차이는 **8.88e−16**이었다.
- Python 사전과 math.fsum으로 만든 농장×블록 SSE에서 각 시드의 부트스트랩을 독립 재계산했다. p_worse·MSE/RMSE 구간이 공통 계산과 일치했다.
- 모든 진단의 제곱오차 = 하루 수준 + 시간 모양 항등식을 검산했다.

검산 초기에는 시스템 Python의 pandas 불완전 설치로 실행이 시작되지 않았다. 원 학습과 동일한 Codex Python 3.12.14를 사용해 정상 완료했으며, 원본 모델·원 결과는 변경하지 않았다. 검산에서 모델을 재학습하지 않았다.

누수 규칙은 공통 고정 분할과 동일 인과 특징으로 유지했다. 공통 특징의 미래·다른 온실·순서·자정 결측 검사 결과와 사전 코드 검토를 사용하며, CatBoost 전체 재학습 반복까지 수행한 결정성 검증이라고 주장하지 않는다. 원 실행은 각 모델에서 첫 8행의 반복 예측을 확인했다. 특징 중요도 해석과 새 알고리즘 조합은 이번 범위 밖이다.

반론: “후반은 좋아졌으니 실제 평가도 좋을 수 있다.” 후반은 46일의 재사용한 사후 집단이며, 전체 15칸 및 통계 기준은 실패했다. 평가 일반화의 증거로 삼을 수 없다. “설정을 바꾸면 CatBoost가 좋아질 수 있다.” 가능성을 배제하지 않지만 이번 고정 설정의 실패를 설정 탐색의 성공으로 바꿀 근거는 없다. **CatBoost 전체 계열이나 모든 합법 입력의 정보 한계를 기각한 것이 아니다.**
