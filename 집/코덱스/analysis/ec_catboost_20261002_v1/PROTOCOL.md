# EC CatBoost 단독 비교 — 사전 고정 v1

2026-10-02 · 집 · 코덱스. 실행 전에 코드와 이 프로토콜을 main에 커밋한다. 이 문서는 새 알고리즘 한 설정의 비교 계획이며, 개선 결과나 제출 구성 선언이 아니다.

## 질문과 범위

현재 합법 입력의 동일 38개 특징을 CatBoost의 대칭 트리 부스팅으로 학습하면 기존 EC v2보다 낮은 오차를 얻는가? 기존 정보원 조사와 기각된 RF/HGB·leaf4·날짜 배깅 설정의 재조정과 구별되는 새 알고리즘 단독 1안이다. 향상 폭은 미리 예상하지 않는다. CatBoost 단독 대 v2 앙상블의 비교이므로 알고리즘만의 순수 효과를 분리한 비교로 해석하지 않는다.

이번 전체 캠페인은 멤버 4개 제거안과 CatBoost 단독 1안, 총 5안이다. CatBoost의 혼합 비중·특징·깊이·반복 수·시드·결측 처리를 결과에 맞춰 변경하지 않는다. 비교 뒤 새 조합을 만들지 않는다.

## 데이터·검증

- 공통 구현 `../ec_model_common_20261002_v1/common.py`의 `prepare`와 `split_fold`를 사용한다. phase3와 동일한 DIAG10 10폴드, A 5폴드, B 5폴드, EXT10 1폴드, EXT12 1폴드, 합계 22폴드다.
- F13/F47의 비잠금 360일·8,640행 정답을 사용한다. 최종잠금 40일은 EC 값을 숫자로 변환하기 전에 제외하며, 각 학습에서 검증일과 잠금일의 앞뒤 1일도 제외한다. 최종잠금 정답 채점은 하지 않는다.
- `core.FULL`의 기존 38개 특징만 사용한다. MASK의 직접 관리 5개 전결측 채널은 포함하지 않는다. 행 ID·농장 ID 자체는 모델 특징에 넣지 않는다. day·시각 파생값은 기존 v2와 동일하다.
- 현재·당일 0시·현재까지의 입력 집계만 사용한다. 공통 인과 특징과 분할 검사를 유지한다. 평가 입력값, 평가 통계, 리더보드 점수, 다른 온실 입력, 공개 정답 파생 특징은 사용하지 않는다.
- 시드 7·101·2024를 모두 실행한다. 동일 검증행의 동일 시드 v2를 기준선으로 삼는다. A/B 발생단위 pooled 점수와 고유행 예측평균 점수를 구분한다.

## 모델·후처리

CatBoostRegressor의 설정을 다음과 같이 고정한다.

| 설정 | 값 |
|---|---|
| loss_function / eval_metric | RMSE / RMSE, 원래 sub_ec |
| iterations | 1200 |
| depth | 6 |
| learning_rate | 0.03 |
| l2_leaf_reg | 3 |
| bootstrap_type / subsample | Bernoulli / 0.8 |
| rsm | 0.8 |
| nan_mode | Min, 수치 NaN의 native 처리 |
| task_type / thread_count | CPU / 2 |
| use_best_model | False |
| allow_writing_files | False |

외부 검증 정답을 `fit`에 전달하지 않고 eval_set·조기종료·overfitting detector를 사용하지 않는다. 모든 1,200회를 학습한다. 별도 결측 대체·스케일링·범주 인코딩을 추가하지 않는다. CatBoost가 native NaN을 지원한다는 [공식 설명](https://catboost.ai/docs/en/concepts/algorithm-missing-values-processing)을 확인했다. 결측 모드는 실행 전 Min으로 고정했으므로 -999 대체와 나란히 시험하지 않는다.

원시 모델 예측을 보관하고, 기존 `core.shrink`의 `0.5×현재 예측 + 0.5×당일 현재까지 예측평균`을 적용한 후 해당 학습 정답 min/max로 clip한다. 비교에는 후처리 결과를 사용하며 원시 예측·학습 점수는 진단용이다.

## 사전 판정

1. 시드 3개 × 검증기 5개, 총 15개 pooled 점수에서 후보 RMSE가 같은 시드 v2보다 엄격히 낮아야 한다. 시드별 결과와 폴드 평균·표준편차를 전부 보고한다.
2. DIAG10은 농장별 기존 5일 block을 짝지어 20,000회 재표집한다. 재표집 단위는 각 block의 모든 시간 행이다. 각 시드의 후보 RMSE−v2 RMSE 차이에 대해 `p_worse < 0.025/5 = 0.005`, 본페로니 99% 양측 구간의 상한 < 0을 모두 요구한다. 재표집 RNG는 공통 평가와 동일한 918로 고정한다. 공통 `evaluate`의 결과를 보관하고 별도 산술과 같은 재표집으로 교차 확인한다.
3. 시드 평균 예측의 수치도 별도로 보고하되, 평균이 좋다는 이유로 개별 시드 실패를 덮지 않는다.
4. 고EC·밀폐·후반·농장·시각별 진단은 원인 분석용이며 모델·비중·문턱을 고르는 근거로 사용하지 않는다. 최종 채택은 부모 실험의 독립 검산·인과성·결정성·추가 확인 절차까지 완료한 뒤 판정한다. 이 실행 단독으로 채택을 선언하지 않는다.

코드·프로토콜·공통 구현·core·행 정합성을 해시로 묶고 캐시 재사용 시 일치 여부를 검사한다. 원시 예측, 후처리 예측, 기준선, 실제 비잠금 정답, row_id, fold, seed, farm, day, hour, block을 내 `local/ec_catboost_20261002_v1/`에 저장한다. 학습 점수는 독립 검증 성능으로 주장하지 않는다. 파이썬·NumPy·pandas·CatBoost 버전도 기록한다.

CatBoost 1.2.10은 내 `local/ec_model_packages_20261002_v1/`의 별도 패키지 경로를 우선한다. 미설치 시 명시 오류로 중단하며 실행 중 자동 설치하지 않는다. root의 사전등록 커밋 뒤 `PYTHONPATH="" python -u 집/코덱스/analysis/ec_catboost_20261002_v1/run_catboost.py --run`으로 실행한다. 기존 파일·다른 AI 폴더·공유문서·제출물·최종잠금은 수정하지 않는다.
