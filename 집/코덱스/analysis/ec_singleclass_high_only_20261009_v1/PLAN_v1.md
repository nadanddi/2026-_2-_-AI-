# 고EC만 학습하는 단일 클래스 분류 확인

사용자 최종확정: EC수치가 아닌 고EC 여부만 분류. 이전 수치 회귀 캐시 감사는 중간1고EC일만 계산했고 추가 진행 중단, 새fit0. 이번은 일반일을 제거한 binary classifier의 퇴화 확인이다.

기준일평균EC>=1.2, 기존73현재prefix특징/ET3seed 동일. 공개positiveLOO26fold에서 학습 인덱스 중 high==1만 남기고 모든fold학습라벨이1뿐임을확인한다. 실제fit은 첫fold1개를3seed로 시행하며 20고EC일만학습하고 held고EC1일24행과 일반334일8016행을추론한다. 일반일은학습에서완전히빠졌으므로 모두학습미사용이다. 같은농장±1/다른농장±3/잠금40±1 제외는기존fold유지. imputer는고ECtrain만fit,일sampleweight1/24,재균형0/threshold.5고정. 원자료/정답/특징추가생성0,40성능재점수0,test0,이전대회자료0.

단일class=[1]인분류기는전부고EC라고답하는퇴화가예상된다. 실제held고EC탐지100%,일반일오탐100%이면분리력없음으로해석한다. 이를성능개선이나새분류기성공으로채택하지않는다. 실제LOO26fit했다고주장하지않고모든fold단일class검산+첫1fold3seed실행으로구분한다. first seed→독립중간→나머지2seed→최종독립비평,sourceSHA 고정/예측과판정 CSV 저장. 모델저장/제출0.
