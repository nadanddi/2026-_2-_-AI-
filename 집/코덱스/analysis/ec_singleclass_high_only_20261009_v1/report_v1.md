# 고EC날만 학습한 일반 분류기의 결과

사용자는 실제 EC수치가 아닌 고EC 여부 분류라고확정했다. 일반날을모두학습에서제외한기존ExtraTreesClassifier는학습정답이1뿐이라모든입력을고EC로판정한다.

고EC20일480행으로첫LOO fold를3시드학습한실제확인결과:

|검증대상|일수|행수|고EC판정|결과|
|---|---:|---:|---:|---|
|학습에서뺀고EC일|1|24|전부|탐지율100%|
|학습미사용일반일|334|8016|전부|오탐률100%|

세시드8383/1919/7171의예측점수는모든8040행에서정확히1이었다. 고EC만검증하면정확도100%가되지만일반날도전부고EC로답하므로구분실력이없다. 이일수비율로합친전체정확도는고EC1일대일반334일의인위적구성이므로제시하지않는다.

기존positiveLOO26fold의각학습에서고EC만남긴라벨집합이모두[1]임도검산했다. 모든26fold를다fit했다고주장하지않고첫1fold를3seed로실행했다. 각날24행모두제외/같은농장±1·다른농장±3·소비40주변제외규칙유지. imputer와모델은고EC행만fit,일sampleweight1/24. 입력은원등록73개같은농장당일현재prefix특징이다. EC수치예측fit0·모델저장0·제출0·소비40성능재점수0다.

산술신뢰도높음: stdlibCSV loop로3seed의TP/FN/FP/TN,정확히1인점수8040행과일수1/334를재계산했다. 기존등록sourceSHA·모든26학습라벨·학습/검증무교집합확인. 계획/중간/최종독립비평을받아현재일반supervised분류기의단일class퇴화임을명시한다. 일반날이없는학습법전체를불가능하다고일반화하지않는다.

고EC만학습하여그패턴과의유사도를판정하는단일클래스탐지모델은별도방법이다. 그것도검증에는일반일을남겨야무조건고EC라고답하는모델과비교할수있다. 현재실험에서는그방법을실행하지않았다.
