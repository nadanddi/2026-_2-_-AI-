# EC 재분석 3단계 · 기준선과 검증 구조 감사

2026-10-01 집 코덱스. 사용자 승인: 입력 활용도 비교 및 날짜 분할/MASK/출처 반복 점검. 기존 합의의 후속 실행, 반복 승인 생략.

## 고정 비교
공개 train_X/train_y의 F13/F47, 최종잠금40일 정답은 숫자변환 전 제외. 모든 모델 학습에서 잠금일 ±1일 및 각 검증일 ±1일 제외. 잠금일 점수화 없음. 모델 전처리 fit은 해당 학습 fold만.

가용14열 외5열은 입력에서 제외(MASK). 평가 test_X는 row_id만 읽어 관측 간격을 점검한다. 평가 특징값/분포/가중치 사용 금지.

- M0 학습 EC 전체 평균, M1 학습 온실별 평균.
- M2 가용14 현재값+day/hr_sin/hr_cos/midnight(18열), 학습중앙값 대체+표준화+Ridge alpha10.
- M3 동일18열 ExtraTrees 600trees/leaf1, seed7/101/2024, 학습중앙값 대체.
- M4 기존38열 ExtraTrees 동일600trees/leaf1. M3→M4는 특징만 바꾸는 절제 비교.
- R3: 기존 core.members 그대로 ET38열/LGB Tweedie14열/MLP14열, .6/.3/.1, 시드7/101/2024. day포함 버전으로 고정. 원시평균을 .5현재+.5당일현재까지평균으로 축소한 뒤 학습정답 min/max clip.
- V2: .8 R3 원시+.2 TabPFN V2 원시평균 후 같은 축소/clip. TabPFN38열, 문맥2000행×4개(시드1/2/3/4), 각각 n_estimators4, 로컬 checkpoint/CPU float32/offline. R3세시드 평균 버전과 시드별 V2도 기록. 0.8/0.2 고정, 재튜닝 없음.
- M2/M3/M4에도 같은 축소/clip 적용하여 후처리 차이를 없앤다. M0/M1은 상수로 축소해도 동일.

## 검증 고정
DIAG10: 원래400 온실-일을 온실별 정렬하여5일씩10폴드 순환 배분한 원래 splits.csv 사용. 잠금40일 제외360일 모두 정확히1번 검증. A/B: 기존 geometry layout E5/T8/E10/T8/E10/T3/E5, shifts A70/85/100/113/126, B63/77/92/107/120. 중첩 검증행은 fold발생단위 pooled와 row_id별 fold예측 평균을 모두 기록하며 독립 표본으로 간주하지 않는다.
EXT10/EXT12: 학습입력만으로 ph_in_temp_3(온실별 causal EWM half-life3h, ignore_na)의 하루 최소<th인 비잠금일 전체를 동시에 검증. ph는 분할 정의용, 예측 특징에 추가하지 않는다. EWM의 입력은 잠금일 입력도 포함(정답 사용0), 원래검증정의 보존.

## 감사
각fold 학습일수/검증일수/인접 purge/최단 학습행 시간거리/구간 범위·후반 비중. weather4 전체하루 지문 및 가용14 전체하루 지문의 train-validation 정확중복을 집계(사후 감사전용, 예측특징 아님). 평가 row_id↔원래학습ID 및 잠금제외학습ID의 최단거리 비교. 반복 날씨가 라벨누수라는 자동 판정 금지. test ID로 검증/모델/표본가중치 변경 금지.

## 판정·보고
이번은 기준선/활용도 감사이며 모델채택 실험 아님. 성능차이는 전체·온실·전후반·0/6시·고EC일 사후분해. DIAG10 5일블록 재표본20000회, 3개 M2/M3/M4와V2의 차이에 본페로니99%에 가까운 1−.05/3구간 및 p_worse 기록. 전검증기×전시드 방향·EXT무악화 충족 여부 기록하되 후속 미사용시드/확인 없이 채택하지 않는다. fold RMSE 평균/표준편차는 변동 참고자료, 개선크기 컷으로 사용하지 않는다.

모델 미사용 최종잠금 유지, 제출물 없음. 실행 전 main에 프로토콜·코드만 경로 지정 커밋. checkpoints는 집/코덱스/local 아래 새폴더에 저장. 입력/코드/레시피/checkpoint해시 검증하고 미래/타온실/결측자정 특징 불변검사, 결정성·독립 CSV산술 검산 후 결론 보고.
