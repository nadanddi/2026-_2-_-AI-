# X2 — EC와 다른 값의 결정적 관계 조사

2026-10-02 · 집 · 코덱스. 요청서 v2의 정답 쪽 X2를 수행했다. 원 보고서 초안은 보존하고, 이 문서를 전달용으로 사용한다.

시험한 16개 단순식에서는 사전 기준을 충족하는 관계를 찾지 못했다. 이 결과는 시험한 식에 한정하며, 모든 정보원이나 함수가 없다는 뜻은 아니다.

## 범위와 검증

최종 잠금 40일은 원본 CSV에서 ID를 확인한 뒤 정답 숫자로 변환하기 전에 제외했다. 분석 표본은 360일, 8,640행이다. 기존 DIAG10 날짜 분할을 사용했고, 학습에서는 검증일과 잠금일의 앞뒤 1일도 제외했다. `test_X`를 읽지 않았다.

온도·구동기·시간의 단순 선형 관계 10식을 main `1c28d15`에 등록한 후 실행했다. 독립 검토에서 곱셈 온도 관계가 빠졌다는 지적을 받아, 로그 EC와 온도의 관계 6식을 별도 폴더에 main `6041005`로 사전 등록하고 추가 실행했다. 기존 코드와 결과는 수정하지 않았다.

기준 v2의 동일 표본 RMSE는 전체 **0.213874**, 하루 수준 **0.199237**, 시간 모양 **0.077760**이다. 원시 정답 정합성, NumPy와 `csv/math.fsum` 산술, 현재·과거 입력 특징의 미래 및 다른 온실 교란 불변 검사를 통과했다.

## 해석과 반론

- **단순 생성식 발견 실패** — 신뢰도 높음. 16개 고정식 중 기준 통과 0개다. 재현 코드는 각 폴더의 `run.py`다. 다만 복잡한 함수, 처리별 계수, 시험하지 않은 변수의 가능성은 남는다.
- **로그·온도 관계도 거의 결정적이지 않았다** — 신뢰도 높음, 시험한 공통 계수 식의 범위에 한정한다. 이것은 온도 연관성이 없다는 뜻이 아니다. 기존 카탈로그 6.27의 센서 온도보상 확정 해석은 6.29·6.128·6.130에서 미식별로 정정됐으며, 이번 기울기도 센서 기작을 확정하지 않는다.
- **상한과 합법 입력을 구분했다.** 배지온도 정답, 하루 전체 입력, 실제 하루 평균 EC가 필요한 식은 진단 상한이다. 평가 행의 예측 특징으로 쓰지 않는다. 공기온도·구동기·시각의 일내 편차식은 현재·과거 입력만 사용하지만, 하루 수준을 알아냈다는 의미는 아니다.
- **보고 누락을 보완했다.** 첫 실행의 저장 결과에는 사전 문서의 0~6시·고EC 층화와 절대 기준 부트스트랩 통과 비율이 빠져 있었다. 독립 audit가 저장 OOF에서 추가 계산했다. 새 식의 선택이나 재학습은 하지 않았다.
