## 구현

A=실제 계절v2 최종출력. B=동일농장·동일pass·이전 공개 학습일의 인과적 입력서명 최근접3일로 만든 기존 제한 이웃 보정 출력. B는 고EC만 학습한 모델이 아니다. 전체1/2차 구간에 적용하고 이웃없음은 A 유지. 입력23개와 정규화 .01, prior g=.05 및 sigmoid선형 모델/최적화 설정을 사전 고정했다. 출력은 A+g(B-A), 학습 목적은 내부 혼합 MSE+prior 중심 L2. hard threshold나 승패 분류 라벨 없음.

내부 A는 outer train 안 a에서 적합된 원모델의 b 예측, B 참조는 a만 사용. gate scaler/fit는 heldout b만 사용. 외부 y는 최종 채점에만 사용. 내부자료는 전체 crossfit가 아닌 이전 matched heldout b 부분집합이다. 원모델 재학습이 아닌 캐시 SHA/ID/참조purge/문맥/기준선 재생 검사 후 게이트만 학습했다.

사전 main b2c097a, registration_v2.json의 run/verify/preparation/prereg SHA를 매 fit 직전에 확인. v1 준비 PASS 후 tuple/list JSON 왕복 비교 보완을 v2에 반영했으며 모델·수치 설정 변경0. 시스템 Python3.12.10 준비 실패와 샌드박스 패키지 읽기 실패는 별도 환경실패 기록에 보존. 정상 실행은 기존 Python3.12.14.

## 검산과 반론

- 전체22fold×3seed=66셀, OOF83160행(검증기 사이 반복행 포함, 고유 학습표본수가 아님). 원입력/캐시/ID/purge/기준선 및 인과prefix 절단·미래변조 검사 재실행.
- 첫 실제셀 fresh fit 재현, 계수직렬화·행역순·단독행·다른query 변화 독립성 검사 PASS. 이후 전66셀 계수재생 최대오차0.
- 전66 scaler는 math.fsum 평균/분산과 대조. 학습 목적함수와 gradient는 별도 math.exp/fsum 공식 대조, 최대gradient 8.07987e-9. 학습전 finite-difference synthetic 검사 PASS. 손실 비선형 최적화의 전역최적성은 주장하지 않는다.
- 15개 전체 RMSE와 고EC/일반/농장/pass 수치는 NumPy 대 math.fsum으로 독립 재계산. DIAG 각3seed의 bootstrap 첫 추출은 원행 dictionary와 수동 fsum으로 별도 대조 PASS. 근거 verification_v2.json, scores_v2.csv, segments_v2.csv.
- 반론: soft gate 전체가 무효인가? 아니다. 이번 A/B,23특징,정규화,내부분할 구현의 기각이다. 다른 전문가와 다른 정보의 효과는 이 실험으로 판정하지 않았다.
- 반론: 검증자료가 적어서 채택 못했는가? 이번에는 DIAG 전seed 및 B 전seed 악화가 직접 관측됐다. 단순 검정력 부족으로 성공처럼 해석하지 않는다.
- 반론: 내부 학습과 외부 분포가 같은가? 보장하지 않는다. 모델별 내부/외부 MSE는 verification learning_checks에 남겼으며 훈련 적합을 일반화 근거로 삼지 않는다. 반복 공개 검증이고 미사용 holdout이 아니다.

수치/기각의 신뢰도 높음(독립 재생 검산 완료). 실패 원인·다른 gate 가능성의 신뢰도 낮음. 다음 단서는 내부에서 유리한 보정 방향이 외부 고EC에서 유지되지 않는 경로 확인이며, 이번 결과로 정규화/비중/문턱을 바꿔 재채택하지 않는다.
