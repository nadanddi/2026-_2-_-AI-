# family24 최종 독립 검산: 기각

exact Tweedie leaf 후보는 사전 기준으로 **기각**한다. 15점수 중6개 개선했지만 DIAG10 세 시드는 모두 악화했고, 세 bootstrap도 실패했다. 변화가 작다는 이유로 strict15와 alpha=.025/24를 완화하지 않는다. 이 판정의 신뢰도는 높다. 완료된 공개 출력의 계산과 고정 기준에 대한 판정이며, 새로운 독립 holdout 결과는 아니다.

## 새로 실행한 독립 증거

`crosscheck_complete_v5.py`(SHA `9643a9ae6958a93d205f43e99175b137e0813347c53511964bf200e685c3d803`)가 정상 종료했다. `crosscheck_complete_result_v5.json`에 PASS와 public_pass=false를 저장했다.

- 원 등록15파일 SHA와 두 repair의 실제 전체 diff·추가 핀·실패 로그·진단·합성 SHA를 다시 검사했다. 원 runner/preparation/preregistration과 모델은 그대로다. 보완 verifier는 실제 학습 후 수정됐으므로 학습 전 등록본이라고 설명하지 않는다.
- 66 metadata와 서명·CSV/model SHA·fit audit 순서, Newton66 제어 기록, 모든 cache SHA를 확인했다. 기존 공개 원본의8640 정답과 검증기/fold/seed별 baseline을 직접 대조했다. stdlib CSV로 읽은83160행 aggregate의 문자열 내용과 순서는 셀 연결과 완전히 같았다.
- 체크포인트는 native 모델로 로드하지 않고 plain text로 검사했다. BASE14 특징 순서와 canonical 원 파라미터, requested800, lr.03, bag.8/freq1, col.8, rho1.5, lambda_l2=1/lambda_l1=0, leaf31/min40 및 seed/thread 설정이 일치했다. 실제 트리 수는 모든66모델에서800이며 root 기록과 같았다.
- scalar fsum으로 raw mix, .24 원 LGB 차이, 한 번의 prefix shrink와 train clip을 검산했다. 최대 prefix 차이는8.881784197001252e−16, raw delta 차이는4.0852737859253807e−16이었다.
- 모든15 RMSE를 stdlib fsum와 별도 Decimal45자리 계산으로 확인했다. 제곱·합산·나눗셈·제곱근을 같은 Decimal context에서 계산했으며 root의 수치와 개선 방향이 일치했다. DIAG의 세 bootstrap은 farm별5개 정렬 관측일, 고정20k draw를 별도 record와 draw별 fsum·수동 quantile로 계산해 p·CI·판정을 재현했다. 18개 구간 수치도 재계산했다.

새 native 학습·예측과 원시 EC/test/EL1 읽기는 모두0이다. root whole의3,154,214대조와 native checkpoint 예측은 root 실행 증거이며 위 검산 수에 합산하지 않는다. 앞서 독립 진단한 첫 trace24,800 leaf와 Decimal80 근은 별도 파일에 보존돼 있다.

## 구간과 까다로운 반론

구간 서술의 신뢰도는 중간이다. 공개 고정자료의 사후 진단이며 인과 설명은 아니다.

- 고EC는 일평균 정답≥1인31일/744행이다. 세 시드 모두 악화했다(+.131635/+.133699/+.118291%). 일반329일/7896행은 seed7만 개선했고(−.225167%),101/2024는 악화했다(+.287691/+.171469%). 따라서 일반일은 항상 개선한다는 주장도 성립하지 않는다.
- F13의180일/4320행은 seed7만 개선했다(−.027397%, 나머지+.369140/+.302967%). F47의180일/4320행은 모두 악화했다(+.036167/+.063225/+.022678%). day≥179 후기46일/1104행과 hour0의360행도 모두 악화했다. 후기 변화는+.254325/+.269233/+.327754%, hour0은+.139843/+.457287/+.434140%다.
- 고EC bias는 seed7/101에서 더 음수가 됐지만2024는−.288188→−.287374로 개선하면서 RMSE가 악화했다. 평균 bias 하나로 성능 변화의 원인을 확정할 수 없다.

“정확한 root인데 왜 개선되지 않았나?” 이번 root는 현재 inbag·현재 tree leaf의 정규화 Tweedie 목적함수에 대한 local 해다. Newton 분할과 gain 계산은 유지되며 F가 바뀌어 후속 트리 구조도 달라질 수 있다. 계산 정확성이 전체 boosted ensemble의 글로벌 최적화나 검증 RMSE 개선을 보장하지 않는다. 이 고정 레시피가 공개 기준을 실패했다는 사실만 확인됐다. exact leaf 방법 전체의 무효성이나 운영정보 부재의 증명으로 확대하면 안 된다.

“seed나 구간을 골라 쓰면 되지 않나?” 사전 기준은 모든15 개선과 DIAG 각 seed의 bootstrap 통과다. 단일 seed·구간의 성공으로 재판정하면 사후 기준 변경이다. 별도 실험을 같은 후보의 성공으로 소급하지 않는다.

누수·재현 범위도 구분한다. root whole는 원 입력·공개 정답·캐시·purge·특징·source/runtime과 최초 native trace를 검증했다. 여기서는 SHA와 공개 출력의 독립 산술을 재확인했다. 실제 sklearn wrapper는 훈련 Dataset을 해제하므로 첫 실제 fit의 private cache를 직접 읽은 것은 아니다. 같은 DLL의 합성 cache 증거, 실제 F 재귀·membership, 독립 Decimal 근을 구분한다. 후속65모델의 모든 내부 trace나 optimizer를 재실행하지 않았다. 공개360일을 반복 사용했으며 새로운 untouched holdout은 없다.

## 보존한 보완

checker v4 첫 실행은 기존 공개 CSV의 UTF8 BOM 때문에 헤더를 못 찾아 후보 CSV 읽기·점수 계산 전에 중단됐다. 실패를 `crosscheck_bom_failure_v1.json`에 보존하고, 새 checker v5에서 CSV decoder만 utf-8-sig로 바꿨다. 원 데이터·모델·기준·숫자는 바뀌지 않았다.

whole의 앞선 두 실패는 한글 파일 경로와 독립 Newton 종료 버그였다. 모델을 재학습하지 않았고 두 repair의 핀·diff·근거를 최종 checker에서 다시 검사했다. 자세한 진단은 기존 별도 보고서에 보존돼 있다. 이번 결과를 Claude의 온도 후보나 다른 운영정보 가설의 유효성 판정으로 사용하지 않는다. 새 제출물은 만들지 않았다.
