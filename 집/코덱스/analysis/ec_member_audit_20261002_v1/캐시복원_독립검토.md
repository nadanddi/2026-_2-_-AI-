# EC 멤버 캐시 복원과 새 실험 기준선 독립 검토

2026-10-02 집 코덱스. **기존 phase3 캐시에서 TabPFN 평균 예측과 R3 원시 평균을 복원할 수 있다.** 22폴드의 R3/v2 clipping이 모두 비활성이라 선형 역변환이 유효하다. 기존 npz/CSV와 원자료의 수학만 검사했으며 모델 fit/predict·새 실험 학습·제출물 생성·최종잠금 채점은 실행하지 않았다.

## 복원 근거와 한계

`run_benchmark.py`의 R3 원시값은 .6·ET + .3·LGB Tweedie + .1·MLP, v2 원시값은 .8·R3 + .2·TabPFN 4문맥 평균이다. 두 값에 같은 후처리를 적용한다.

`S(p)_h = .5 p_h + .5 mean(p_0, ..., p_h)`

`final(p) = clip(S(p), 해당 학습폴드 EC 최소, 최대)`

22개 캐시·**27,720 검증 발생행**(A/B 반복행 포함)의 `r3`, `v2` 및 시드7/101/2024 각각에서 경계값 **0개**, 경계까지1e-12 이내도 **0개**였다. 학습경계는 하한 .063(EXT12 .064), 상한 2.739/2.825/3.232로 폴드에 따라 다르다. 원자료에서 잠금40일·검증일 ±1일을 제거해 학습 경계를 다시 계산했다.

clipping이 없으므로 다음 복원이 가능하다.

`S(TabPFN 평균) = (v2 − .8 r3)/.2 = 5 v2 − 4 r3`

`n = h+1`, `q = S(p)`일 때 하루의 시각 순서대로:

`p_h = (2 n q_h − sum(p_0, ..., p_{h−1}))/(n+1)`

시각0에서는 `p_0=q_0`이다. 같은 농장·같은 기록일 안에서 계산하며 자정을 넘기지 않는다. 이번 캐시는 하루24행·시각0~23이 모두 존재한다. 시각 누락이 있는 다른 표본에는 `n=h+1`을 바로 적용하면 안 된다.

독립 검산 결과:

- 세 시드에서 복원한 같은 TabPFN 평균의 최대 차 **3.55e-15**.
- 순차 역변환 뒤 정방향 후처리 최대 차 **4.44e-16**.
- 복원 R3/TabPFN을 원래 .8/.2로 섞어 원 v2 재구성 최대 차 **4.44e-16**.
- 다른 방법인 24×24 선형방정식 해와 순차 역변환의 차 **1.78e-15**. 후처리 행렬 rank24, 2-norm 조건수 **2.40585**.
- 실제 기존 `core.shrink` 함수와 독립 계산의 최대 차 **4.44e-16**.

근거: `inspect_cache.py`, `cache_audit.json`, `verify_inverse.py`, `inverse_verification.json`. **현재 캐시의 복원 가능성은 신뢰도 높음**이다. 역변환은 네 TabPFN 문맥의 평균만 식별한다. 문맥별 예측·학습 모델·학습행 예측·LGB/MLP 개별 예측은 이 평균으로 분해할 수 없다. 향후 clipping에 걸린 다른 캐시를 같은 방식으로 역변환하면 잘못된 값이 된다.

## 기준선 재현 수준

검증기별 전체 발생행을 분모로 기존 기준선을 다시 계산했다. A/B의 같은 날짜 중복은 폴드별 발생행으로 유지한다.

| 검증기 | R3 3시드 평균 RMSE | v2 3시드 평균 RMSE |
|---|---:|---:|
| DIAG10 | .216479557087779 | .213873693619454 |
| A | .239277471351748 | .230302008881172 |
| B | .223303075025640 | .218769428749023 |
| EXT10 | .420759657345702 | .414090827487633 |
| EXT12 | .415247090024513 | .416128078204738 |

csv/math.fsum 점수와 신선하게 계산한 NumPy OOF 점수의 최대 차는 **2.78e-17**였다. 이 표는 이미 학습된 기준선의 재계산이며 새로운 모델 개선을 뜻하지 않는다.

새 실험은 다음 조건을 만족시켜야 한다.

1. 각 `(validator, validation_fold, seed, row_id)`를 정확히 맞추고 기존 NPZ 행순서·해시를 확인한다. DIAG10 각 시드는360일8640행이다.
2. 입력 생성·학습일·validation/lock ±1일 제거·MASK·후처리를 고정한다. 복원 멤버로 원 v2를 먼저 재구성해 모든 행에서 차1e-12 이하를 확인한다.
3. 후처리된 PFN과 원시 신규 R3를 바로 더하지 않는다. 새 원시 멤버 조합이면 PFN도 역변환한 원시 bag를 사용한 뒤 **shrink와clip을 한 번** 적용한다. 후처리 선형 결합을 쓰는 경우는 clipping 비활성 근거와 같은 S가 유지되어야 한다.
4. 후보 판단은 3시드×5검증기의15칸과 DIAG 사전 본페로니 규칙을 모두 검사한다. 단일 전체 RMSE나 3시드 평균만으로 통과시키지 않는다. 보고용 3시드 평균과 채택 판정을 구분한다.
5. 기존 OOF bag는 해당 outer-fold 검증행의 고정 앙상블 멤버로 재사용할 수 있다. 전체 OOF를 새 outer-fold의 학습 특징·잔차 정답으로 그대로 쓰면 다른 폴드의 모델이 현재 검증 라벨을 학습했던 교차 누수가 생길 수 있다. 그런 학습에는 outer-tr 안에서 별도 학습/교차 예측이 필요하다.
