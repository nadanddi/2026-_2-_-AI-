# CatBoost 실제 결과의 공통 평가 대조 · 2026-10-02

**공통 평가와 CatBoost 자체 부트스트랩이 일치했고, 사전 채택 기준에서는 기각이다.** 실제 저장 OOF를 읽어 두 함수를 각각 실행한 교차 구현 검산이다. 모델을 다시 학습하거나 예측하지 않았다. 원시 라벨·캐시·해시를 별도 방법으로 검산하는 다른 감사 작업과는 범위를 구분한다.

## 자료와 방법

- 완료된 CatBoost OOF **83,160 발생행**, **22폴드×3시드**, 시드×검증기 **15칸**을 공통 누락/중복 게이트로 확인했다.
- 각 시드 DIAG10은 비잠금360일8640행이며, 농장별 층화한 기존80블록·seed918·20,000회 대응 부트스트랩을 그대로 사용했다.
- 공통 함수의 NumPy 점수30개(기준선+CatBoost)를 다른 math.fsum RMSE와 대조해 모두1e-12 이내 일치했다.
- `common.evaluate`와 `run_catboost.paired_bootstrap`을 실제 동일 표에 각각 호출했다. 시드별 RMSE 차이 신뢰구간 최대 차 **5.55e-17**, `p_worse` 최대 차 **0**.
- 선행 동일값 후보 검사와 달리, 이번에는 실제 비영 오차 차이를 가진 후보를 사용해 두 집계 구현의 정합을 확인했다.

근거 코드: evaluation_sanity_v1.py의 실제 CatBoost 모드. 결과: actual_catboost_bootstrap_v1.json.

15칸 중 개선은 **2칸**(EXT12의101·2024)이며 나머지13칸은 악화다. 각 시드 DIAG 신뢰구간의 상한이0보다 크고 `p_worse`도 사전 기준 .005를 넘는다. 따라서 방향 조건과 DIAG 통계 조건 모두 실패해 공통 함수의 **adopted=False**와 일치했다.

신뢰도: **이 저장 결과의 수치 정합과 사전 기각 판정 높음**. CI가0을 포함하므로 CatBoost가 모든 상황에서 나쁘다는 통계적 확정으로 확대하지 않는다. `p_worse`는 이 블록 재표본에서 비개선이 나온 비율이며, 실제 숨은 평가에서 나쁠 사후 확률이라고 해석하지 않는다. 고정 CatBoost 설정1안의 결과이며 다른 설정·알고리즘 전체의 부재를 뜻하지 않는다.

## 검증 범위

전체 원자료 정답 정합·NPZ 무결성·별도 구현의 블록 산술 감사는 담당 감사의 보고서를 함께 참고해야 한다. 이번 검사는 두 실제 평가 구현을 직접 실행하고, 점수를 math.fsum으로 교차 확인했다. 반복 사용한 검증기 및 기록일 블록의 실제 달력/출처 독립성 한계는 남는다.

감사 파일 외 수정0, 모델 fit/predict0, 최종잠금 채점0, 제출물 생성0. 동일값 검사 보고서를 보존하고 실제 결과 검사는 이 새 파일에 별도로 기록했다.
