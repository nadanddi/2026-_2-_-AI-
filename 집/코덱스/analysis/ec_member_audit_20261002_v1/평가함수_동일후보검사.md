# 공통 평가 함수 동일값 후보 검사 · 2026-10-02

사전 main 672addc의 common.py를 읽고, 모델 학습 없이 기존 phase3 OOF의 세 시드 예측을 평가했다. **동일값 후보는 기각되고 누락/중복 반례도 거부됐다.** 이 결과는 실제 새 모델의 개선 판정이 아니다.

## 고정 입력과 결과

기존 OOF를 3시드 긴 표 **83,160 검증 발생행**으로 구성했다. 각 시드 DIAG10은8640행·360일이고, A/B/EXT 발생행은 기존22폴드와 같다. `fake_same_as_v2 = v2`를 한 열 복사하여 공통 evaluate에 넣었다.

- 3시드×5검증기 **15칸 ΔRMSE = 0**, 상대 차이0.
- 각 시드 DIAG의 농장별 층화 **80개 기존 블록**, seed918·20,000회 대응 부트스트랩: **ΔMSE=0, MSE/ RMSE CI=[0,0], p_worse=1**.
- 개선 **0/15칸**, direction/DIAG 통계 조건 모두False, **adopted=False**.
- NumPy 평가 점수30개(기준선+동일후보)를 csv값 기반 math.fsum RMSE와 대조해1e-12 이내 일치했다.

다음 고정 반례4종은 모두 AssertionError로 거부됐다.

1. B 검증기의 시드101 전체 누락.
2. 시드7의 DIAG10 폴드0 누락.
3. 검증 발생행1개 누락.
4. 검증 발생행1개 중복.

common.py의15칸·22폴드·폴드별 행집합 완전성 게이트가 이 반례들을 잡았다. 이 검사는 모든 가능한 입력 훼손을 검사한 것은 아니다. 실제 산출물은 최종 검산에서 원시 라벨·기준선 값·해시 정합도 별도로 확인해야 한다.

## CatBoost 대응 함수 대조 범위

동일값 후보를 CatBoost의 paired_bootstrap 입력 열로도 배치했다. 세 시드에서 common evaluate의 RMSE CI와 CatBoost paired_bootstrap의 CI/p 차이가 **0**이었다.

**동일값 후보는 어떤 재표본에서도 차이가0이므로 이 수치만으로 일반적인 RNG 정합을 입증하지 않는다.** 코드상 두 함수는 seed918에서 F13·F47 순으로 같은 블록 개수/shape의 난수를 생성한다. 실제 CatBoost OOF가 완료되면 다음 준비된 경로로 실제 비영 차이를 비교한다.

`evaluation_sanity_v1.py --actual-catboost <실제 CatBoost oof_predictions.csv> --output-prefix actual_catboost_bootstrap_v1`

이 실행은 CatBoost 모델을 다시 학습하거나 예측하지 않고 저장된 OOF만 평가한다. 신규 결과가 생기기 전 실제 CatBoost RNG/CI 정합이 완료됐다고 보고하지 않는다.

## 근거 및 금지 작업

실행 코드 `evaluation_sanity_v1.py`, 결과 `evaluation_sanity_v1.json`. 검산 파일은 기존 파일을 보호하도록 동일 출력 이름의 재실행을 거부한다. 공통 코드·분석 파일·공유 문서·기존 보고서는 수정하지 않았다. 모델 fit/predict0, 최종잠금 채점0, 제출물0.
