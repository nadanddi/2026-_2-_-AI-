**기각 — 공개 검증 수치의 산술 정합 신뢰도 높음.** 전체 verifier 종료 후에만 공개66cell·83160행을 읽었다. 별도 `crosscheck_complete_v1.py`를 새로 실행해 stdlib CSV, Decimal 제곱손실/RMSE, scalar fsum prefix, 수동 farm/day 5일 block 합 및 sorted quantile로 재계산했다. `crosscheck_complete_result_v1.json`은 PASS이며 public_pass=false다. 새 fit/predict/raw EC target/test/EL1 읽기·채점은0이다.

## 정합 검증 범위

- 22준비manifest/66meta의 서명·CSV SHA·fitcells 동일성과 전 cache hash를 재확인했다. 원 first/fit/prep/runner/verifier/prereg/score/segment/aggregate SHA가 whole report와 일치했다. aggregate는 각 CSV를 연결한83160행과 **CSV문자열 전열**까지 동일했다.
- 각셀 ordered query ID digest·키·bounds·finite 검사 및14BASE/23new/38full 특징 이름 구성과 prep/runtime/deps 결속을 확인했다. 독립 scalar .48ET+.24LGB+.08MLP+.20PFN→prefix shrink.5→one clip은 baseline/candidate 모두 일치하며 최대차8.88e−16이었다.
- 15 RMSE와18segment RMSE/bias/daycounts,3bootstrap을 별도 경로에서 재계산했다. Decimal multiplication/division/sqrt는45자리 context이며 Python sum 누적은 기본 Decimal context를 사용한다. 이에 따른 독립 합산 수치 차이는 출력 RMSE의1e−12 문턱 아래이고 엄격 개선 방향은 원 fsum/NumPy와 동일했다. '처음부터 끝까지 모든 Decimal 연산45자리'로 과장하지 않는다.
- first saved audit의 수치와 signature는 확인했다. first originalBASE14 재현·fresh/order/single/prefix model 감사는 **worker가 저장한 수치/출처를 확인한 것**이다. 독립 모델 replay는하지 않았다. 전체v3가 prefix/feature_causal의 정확farm/day/hour schema와 유한·문턱을 검사했으며 별도 교차검산이 그 모델 동작을 다시 실행한 것은 아니다.

## 까다로운 반론과 답

1. **EXT가 좋아졌는데 채택할 수 있지 않은가?** family21은 최초fit전 strict15와3seed bootstrap을 고정했다. DIAG/B의 실패만으로도 기각이고 결과 후 검증기나 시드를 제외하면 선택 편향이다.
2. **한 시드만 좋은 것은 라이브러리나 캐시 오류 아닌가?** source/runtime/cache SHA·metadata·raw member/후처리/aggregate 산술과 독립 점수는 일치한다. 따라서 확인된 산술오류로 설명되지는 않는다. 다만 독립 재학습은 금지되어 모든fold 모델을 재현한 것은 아니며 저장 provenance가 실제 실행의 모든 순간을 증명하지도 않는다.
3. **새9특징이 무용하다는 증거인가?** 아니다. 이 실험은 기존계절v2에서 LGB 한 구성원에23특징을 넣은 특정 고정 대조다. ET/MLP/PFN 입력·혼합이 고정되어 있다. 전체9특징/개별특징의 일반적 무용·물리 메커니즘을 결론내릴 수 없다.
4. **시드2024 일반일 악화가 작으니 무시해도 되는가?** 크기무관 방향일관 규칙이다. 따라서 +.142167%도 사실대로 기록한다. high31일만 보면 ordinary 손실을 숨기게 된다.
5. **전체 감사PASS가 누수 없는 새홀드아웃 성능을 입증하는가?** 공개 반복검증이며 untouched holdout이 아니다. 준비 SHA와 원R3공개 ID·target·train/query 특징 재구성, 최초prefix오염 감사는 누수통제 증거이지만 전fold 독립 causality/model replay의 대체물이 아니다. 학습 RMSE가 산출되지 않아 과적합 격차도 평가하지 않았다.
