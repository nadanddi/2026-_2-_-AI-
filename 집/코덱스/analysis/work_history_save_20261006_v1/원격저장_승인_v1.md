# GitHub 저장 승인

2026-10-06 사용자는 현재 설정된 https://github.com/nadanddi/2026-_2-_-AI- 의 main에 저장된 분석 기록·코드를 업로드하는 질문에 **“GitHub 업로드 승인”**이라고 답했다.

처음 git push는 원격 목적지에 대한 명시적 승인 근거가 없다는 자동 승인 검토로 거절되어 실행되지 않았다. 이후 받은 위 사용자 승인에 따라 동일 목적지의 main에 일반 push만 수행한다. 강제 push, 실행 중 rebase/pull, 타 AI 파일 삭제는 하지 않는다.

큰 모델 캐시 백업 ZIP은 GitHub에 넣지 않고, 저장소 지침의 Google Drive farmai_sync에 별도 보존한다. 백업 ZIP과 manifest의 드라이브 복사는 SHA 일치로 확인한다. Drive 서비스의 원격 업로드 완료 확인과는 구분한다.
