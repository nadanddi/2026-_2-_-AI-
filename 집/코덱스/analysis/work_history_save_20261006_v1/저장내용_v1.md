## 저장 방식

Git에는 이력·코드·분석·검산·비평과 진행 정보를 저장한다. 크기가 큰 예측·모델 캐시는 Git 대신 현재 시점의 ZIP 스냅샷으로 보존하고 기존 farmai_sync의 home_codex_local에 복사한다. ZIP에는 실제 포함 파일별 SHA256 manifest를 넣고 다시 읽어 검증한다.

실행 중인 .staging/partial 캐시와 worker.lock은 복원용 산출물에서 제외한다. 완성된 캐시만 포함한다. 진행 로그는 읽은 순간의 내용으로 저장한다. 파일 수·완료 문맥 수·프로세스 정보·원본 Git HEAD를 manifest에 기록한다. 이 백업을 전체 학습 완료본으로 취급하지 않는다. 로컬 스냅샷 뒤 새로 생성된 결과는 계속 원 산출물 폴더에 저장된다.
