## 단일 후보 SOFT_RESID10
기준선 = 현재 실제 EC 계절 v2의 저장 공개 OOF. support.loadec의 동일한 22폴드, 시드7/101/2024, 검증기 DIAG10/A/B/EXT10/EXT12 유지.

실행 전 SE2(6.211)가 추가되어 계획 수정: 과거 정답 수준 대신 과거 **독립 예측 잔차**를 이용. 이전 수준 보정 초안은 실행하지 않음. 기존 statistical_experiments의 해당 outer fold 내부 CPU+PFN4문맥 캐시를 재사용. inner train/validation 둘 다 outer validation 정답 제외, inner validation 날짜의 잔차만 과거 정보로 사용. inner 학습 데이터가 줄어 잔차 크기가 실제 기준선과 달라질 수 있고 이력 표본도 감소하는 한계. 계열 분류기는 outer 허용 입력만 fit하며 inner EC 정답을 학습하지 않는다.

1. 각 폴드의 허용 학습일에서만 외기4채널 24시간 완전 동일한 **연속 일차 쌍** 발견. 양쪽 모두 허용 학습일이어야 한다. 첫 기록0/둘째1은 계열 대리표지이며 진짜 동 정답으로 부르지 않는다. 3연속 중복 등 역할 충돌 시 전체 그룹 제외.
2. 각 온실×현재 시각별 로지스틱 C=1, max_iter=2000. 내부10채널의 0..h 누적평균만 입력. 결측대체/표준화는 해당 폴드의 쌍 학습기록 안에서 fit. 표지가 한쪽만/없으면 p=.5.
3. query 계열확률에는 외기/다른 온실/당일 미래 입력을 사용하지 않는다. 모든 과거 기록 역시 분류기로 확률을 예측하며 실제 쌍 역할로 강제 덮어쓰지 않는다. 과거에는 23시 입력까지 가용.
4. 같은 온실·같은 전후반 구간·현재보다 앞선 12기록 내 허용 학습일 중 inner validation 예측이 있는 날만 이력 참조. 하루 잔차 = mean(공개EC라벨 - inner 기준선 예측). inner 기준선 = clip(shrink(.8*r3_seed+.2*PFN4평균),inner학습범위). 이력 가중치 = exp(-(현재일차-과거일차)/6) × [p_query*p_past+(1-p_query)*(1-p_past)].
5. residual = 이력 잔차 가중평균. correction = .1*exp(-가장최근 이력거리/6)*residual. 이력 없으면0. candidate=max(baseline+clip(correction,-.5,.5),0). 계수/감쇠/창/상한 사후 변경 금지. 새 잔차 보정기 학습 없음.
