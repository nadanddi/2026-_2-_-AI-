# 분석 결과에 대한 혹독한 비평 절차

2026-10-06 사용자 명시 지시: “무언가 분석을 진행해서 결과가 나왔을 때, 혹독한 비평가가 평가 후, 문제점을 점검하고 개선책 피드백까지 진행해.”

앞으로 분석·모델 결과를 보고하기 전에 아래 절차를 적용한다.

1. 수치와 재현 코드를 근거로 결론 후보를 작성한다.
2. 혹독한 비평가가 누수·표본 편향·분할 타당성·재현·과적합·비교 공정성·수치 검산·과장된 해석을 검토한다. 독립 리뷰가 가능하면 결과 작성자와 다른 리뷰어를 사용한다.
3. 각 지적을 사실 확인하고 심각도·결론 영향·해결 여부를 기록한다. 반론을 근거 없이 기각하지 않는다.
4. 개선책을 구체적인 코드/검증/추가 실험으로 연결하고 필요한 조치를 실행한다. 실행 전 기준을 바꿨다면 새 버전으로 등록한다.
5. 핵심 수치를 다시 독립 검산한다. 해결되지 않은 문제는 결과의 한계에 포함한다. 성능 개선과 검증된 정의·재현만의 결과를 구분한다.

비평 기록, 문제별 조치, 개선책 피드백을 분석 산출물에 남기고 최종 답변에는 핵심 지적과 조치만 간단히 전달한다. 작업이 진행 중일 때의 중간 현황을 완료나 성능 개선으로 표현하지 않는다.
