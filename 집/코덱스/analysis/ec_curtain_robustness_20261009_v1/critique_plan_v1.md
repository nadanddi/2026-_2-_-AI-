# 독립 계획 비평 v1 — 2026-10-09 집 코덱스

판정: 저장 CT1 OOF를 이용한 보강 진단으로 진행할 만하다. 새 성능 개선 실험·독립 확증·채택 판정으로 표현하면 안 된다. 자료와 검증기를 고정하고 CT2와 중복 학습하지 않는 범위는 타당하다.

검토 자료: PLAN_v1.md, 공용/ai-memory/harsh-critic-every-result.md. 아직 실행 코드·등록 파일·캐시는 생성 전이므로 산술/행 정합/클리핑 재현을 검증했다고 주장하지 않는다.

1. 중복과 집계 단위: A/B 중첩 OOF를 단순 합치면 일부 날짜가 더 큰 가중치를 받는다. 원 실험의 행 가중 점수 재현과 별도로 고유 농장×일의 반복 수 범위를 기록하고, A/B 숫자를 DIAG의 독립 증거로 합산하지 말 것. farm×day만으로 중복을 지워 임의의 첫 fold를 고르는 것도 금지한다. 시간대 내 동일 일의 모든 시간은 함께 bootstrap 표집해야 한다.
2. 클리핑 재현: 각 구성원 가중합 → 해당 fold의 고정 lo/hi clip → 3시드 평균의 순서가 원 코드와 일치하는지 확인할 것. REF/THS의 범위가 같은지, 다른 경우 원 이유와 값을 기록할 것. 전체 RMSE 재현만으로 시드별·농장별 매핑 오류를 배제할 수 없으므로 키를 validator/fold/seed/farm/day/hour/row_id로 점검할 것.
3. 작은 표본과 선택 편향: 2차 46일, 두 농장별 블록 수는 작다. 블록을 상대기록번호//5로 만든 것은 합법적 근사지만 연속 달력 5일이나 독립 블록의 증거가 아니다. 시간대별 전체 p_worse<.0125는 모든 농장×시드가 통계적으로 유의하다는 의미가 아니다. 각 셀의 방향 조건과 합산 bootstrap 조건을 구분하고 블록 수·95% CI를 같이 제시할 것.
4. 사후 상위5 제거: 순이득이 작거나 음수면 상위5 기여율이 100%를 넘거나 해석 불가능할 수 있다. 분모가 0 이하이면 비율을 NA로 두고 절대 SSE 이득과 상위5/나머지 SSE를 보여줄 것. 이 스트레스 검사는 좋은 날짜를 의도적으로 제거한 사후 조건부 점수이므로 독립 검증, 보정된 p값, 채택 근거로 쓰지 말 것.
5. 오전 분할과 고EC층: h0..8에는 밤도 포함된다. '오전 전체'보다 'h0..8 구간'을 본문에 정확히 적을 것. 고EC≥1.2가 일평균 정답 EC 기준인지 시간행 기준인지 실행 전에 고정해야 하며 실제 평가에서 이 층을 골라낼 수 있다고 주장하면 안 된다.
6. 중간안내 규정과 원 특징: 저장 OOF 진단은 새 누설을 만들지 않지만 원 CT1 특징의 미래 참조/타 온실 참조/계절 추정 학습범위 문제를 해결하지 않는다. CT1 소스 검토는 prefix 사용과 fold 내부 fit 범위를 실제로 확인하고, 캐시 진단으로 인과성 증명이라고 표현하지 말 것. 기존 OOF가 재사용 자료라는 한계는 마지막 결론까지 유지할 것.

진행 전 보강: 고EC 층 기준을 일평균/행 기준 중 명시; A/B 반복 횟수 요약 추가; 원 혼합/clip 순서와 fold별 한계값 확인; 상위5 기여율 분모 예외 처리. 이 네 사항은 코드와 등록 파일에 고정할 수 있는 경미한 보강이며 추가 학습은 필요 없다. 중간 점검에서 DIAG 행수·키 정합·원 점수·예시 일별 SSE를 독립 검산하겠다.
