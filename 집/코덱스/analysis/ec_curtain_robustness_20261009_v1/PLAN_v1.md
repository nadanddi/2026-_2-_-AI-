# CT1 커튼 특징 개선의 집중도·시간대 진단 — 실행 전 계획 v1

질문: (1) 2차 구간 두 온실에서 모두 이득인가? (2) 오전 h0..8에도 개선이 남는가? (3) 최고 이득 5일을 제거해도 방향이 남는가?
자료: 집 클로드 CT1의 고정된 76개 OOF CSV만 읽는다. 공식 평가 입력/정답, 추가40일 정답, 이전 대회 데이터는 읽지 않는다. 새 학습·새 제출·혼합 가중 조정은 없다. CT2가 진행 중이므로 중복 학습하지 않는다.
비교: 기존 REF와 THS의 ET .6 + LGB .3 + MLP .1, 각 seed2121/4343/6565를 저장 lo/hi로 clip 후 3시드 평균. 원 코드와 같은 순서. 비교 대상행은 항상 동일. DIAG10은 중복 없는360일, 2차46일. A/B는 중첩 OOF가 존재하므로 행수와 고유일수를 구분한다.
실행 전 기준: 2차 DIAG10 두 시간대(0..8/9..23) 각각 두 농장×세 시드 모두 개선, 시간대별 농장×상대기록번호//5 블록bootstrap 20000회 seed202610091/202610092에서 p_worse<.0125(.025/2). 이를 '시간대·온실 진단 지지'로만 판정하며 채택 기준을 대체하지 않는다. 효과크기 CI도 보고한다. 모든 날짜는 상대기록번호이며 실제 달력 5일이라고 부르지 않는다.
최고 이득일 제외: DIAG10 2차의 24시간 ensemble SSE 이득 상위5일을 사후 산술로 고른 뒤 동일한 두 시간대를 재집계한다. 학습/특징/검증선정에 사용하지 않는다. 이는 결과 의존 스트레스 검사이며 독립 검증이나 p값 근거가 아니다. 일별 양/음/0 개수와 순이득 대비 상위5 기여를 함께 보고한다.

품질: cache 76개·파일hash/CT1codehash 사전등록, 필수열 유한수·일24시간·hour0..23·fold별row_id중복0·REF/THS 공통행검사. 원 CT1 코드가 시간 prefix를 사용한다는 소스 검토의 한계(새 원자료 모델 재학습 인과성 검사가 아님)를 명시한다.
순서: 계획 비평 → DIAG만 중간 계산/비평 → 전체 캐시 진단/독립 산술 crosscheck → 최종 비평 → 결과 기록. 최종모델/제출을 제작하지 않는다.
