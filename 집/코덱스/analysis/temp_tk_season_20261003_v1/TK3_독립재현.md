# TK3 온도 TC1·TC2 독립 재현

2026-10-03 집 코덱스. 클로드의 isotonic 회귀 구현 대신 코덱스의 독립 PAV 계절 변환을 사용했다. 학습 fold의 날씨만 계절 함수에 전달하고 검증 행은 농장·기록일로만 보간했다. 7회차 원 소스 스냅샷에서 MASK BASE 전체(res·ridge·nys, 시드7/101)와 CODEX(726)를 새로 학습했다.

TC1·TC2의 원시 행 예측과 TC2의 원 PFN을 넣은 W30G 혼합을 대조한 최대 차이 **1.0658×10⁻¹⁴**. 각 비교는 DIAG10 9,600행+EXT10 2,040행+EXT12 5,256행=16,896행이며 검증기 사이 행은 중복된다. `TK3_reproduction.json`, `TK3_scores.csv`, `TK3_verification.json`으로 확인한다. BASE 7/101이 원 캐시와 일치함을 코드에서 검사했다. CODEX726/727은 원 설정에서 실질적으로 동일하므로 독립 시드 증거가 아니다.

독립 계산한 DIAG10 P(worse)는 0.09565~0.18895. 고정 k=18 기준0.001389에 못 미치며 EXT12 방향도 실패한다. TC1의 STOP과 TC2의 FAIL을 확인했다. 클로드 원 코드의 두 번째 시드 bootstrap은 RNG를 이어 사용하고 여기서는 각 셀 RNG를 같은 시드로 초기화하므로 P 소수점 일부는 Monte Carlo 표본 차이가 있다. 예측과 RMSE는 동일하며 판정은 달라지지 않는다.

요청서에는 BASE `day_hinge30~240`도 바꾼다고 적혔지만 실제 7회차 BASE 목록에는 해당 피처가 **0개**였다. 기존 구성에 없는 hinge를 새로 만들지 않고 실제 사용한 day 열만 교체하는 변경을 재현했다. 요청서의 피처 설명을 그대로 사실로 인용하면 안 된다.

검증: 원 CSV 예측·라벨과 행별 대조, 12개 혼합 RMSE를 math.fsum으로 재계산, paired block bootstrap 반복 계산. 신뢰도: 재현과 실패 판정 높음. 같은 검증기를 반복 사용한 결과이며 독립 온도 잠금은 없다. TF 가중치의 전체 학습일 rank 관행을 유지한 한계가 있다. 이 결과는 계절이 모든 온도 구성원에 불필요하다는 뜻이 아니며 별도 TK2와 구분한다. EL1 배치 결과는 전체 TK 보고서에서 함께 기록한다.
