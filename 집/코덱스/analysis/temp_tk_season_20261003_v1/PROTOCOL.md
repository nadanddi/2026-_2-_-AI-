# 온도 TK1–TK3 사전 고정 (2026-10-03 집 코덱스)

사용자가 클로드 요청서 확인·실행을 직접 지시했다. 온도 작업 예외 승인에 해당한다. 기존 7회차 W30G 비교, 리더보드 선택 금지. TK4 제출물은 별도 지시 전 생성하지 않는다.

1. TK1: 저장 OOF를 행 ID로 정렬해 BASE/CODEX/PFN/G_C2/W30G/게이트 없는 W30의 RMSE, 편향, 하루 평균 오차 SSE 비중을 비교한다. 전후반(day 179), 달력 70, 밀폐(하루 act_vent=0 비율 > .85) 경계를 고정. 달력과 밀폐 표지는 사후 진단만 사용한다.
2. TK2 단일 변경: TabPFN 89개 문맥 피처 중 day 값만 독립 DC4 계절 값으로 교체. 샘플 확률/행/순서, V2 체크포인트, n_estimators=4, 2000행, float32 CUDA, 문맥 시드 1–8 및 17–24를 유지한다. 두 8개 문맥 평균, BASE 7/101 및 CODEX 726/727, W30G 비중 고정. 변경 전후 PFN을 모두 재학습해 환경 차이를 제거하며 기존 OOF와도 비교한다.
3. DIAG10/EXT10/EXT12 전체 12칸 W30G 방향 개선 및 DIAG10 20,000회 농장×5일 paired bootstrap p_worse < .025/18, CI 상단 < 0을 모두 요구한다. 이전 코덱스 16안+TK2+클로드 전체변경 TC2를 보수적으로 k=18로 보정. PFN 단독과 전후반은 진단이며 그 점수로 설정 선택하지 않는다.
4. EL1: 농장별 후반 정답일을 기록 순으로 5개씩 묶고 그 농장만 검증. 기존 split_mask의 ±1일 버퍼, 다른 농장 정답 유지. 모든 후반 행이 한 번만 검증된다. BASE 7/101, CODEX 726, PFN 두 8문맥을 변경 전후 재학습하여 W30G 비교. EL1은 독립 잠금 검증이 아니며 기존 검증 중 어느 하나 실패를 덮지 못한다. TK2가 통과하면 날씨그룹 GUARD와 CPU 재현을 추가해야 채택 가능하다.
5. TK3: 클로드 TC1/TC2 실제 코드의 BASE 전체(day 사용 피처)와 CODEX day 교체를 독립 계절 PAV로 재학습, 원시 행 예측과 비교. TC1/TC2 자체 판정 및 k=18 보정 판정을 구별. 실제 BASE 피처 목록에 day_hinge가 있는지 실행 감사하며 없는 피처를 새로 추가하지 않는다.
6. 계절 fit은 외부 학습 날짜의 날씨만 전달. 검증 행에는 농장·기록일만 사용하여 보간한다. 입력 특징은 MASK 세계로 재구성, 원 PFN FULL 특징과 학습행 값 동일 여부 감사. 기존 TF 전체 학습 입력 rank 가중치를 유지하는 한계 명시. 평가 test_X를 학습·계절 fit·예측에 사용하지 않는다.
7. 모든 fit을 local 새 폴더에 즉시 저장. 실행 전 이 프로토콜과 코드를 main 커밋한다. 최종 CSV로 수치 재계산, math.fsum 교차 검산, 분할·계절 학습 날짜·재현 해시·fold 분산·bootstrap 독립 확인 후 보고한다.
