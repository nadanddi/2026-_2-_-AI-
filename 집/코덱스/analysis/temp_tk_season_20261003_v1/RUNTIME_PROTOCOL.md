# 실행 속도 확인 (모델 선택과 별도)

TK2의 float32 CUDA, 4 estimators, 표본과 모든 시드는 그대로 유지한다. 작은 GPU에서 자동 메모리 절약이 연산을 8조각으로 나눠 1쌍에 약44초가 걸린다. 이미 계산된 첫 fold/시드1 두 팔과 `memory_saving_mode=False` 결과를 비교해 maxdiff <= 1e-5이며 메모리 오류가 없을 때만 같은 연산의 배치 방식을 바꾼 v2 worker를 사용할 수 있다. 통계 점수로 이 실행 옵션을 고르지 않는다. 조건 불만족 시 v1을 계속 사용한다. v1 체크포인트를 보존하고 v2와의 실수 연산 차이는 보고한다.
