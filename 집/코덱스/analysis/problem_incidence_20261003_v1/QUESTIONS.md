# 현상 빈도와 잘 맞힌 사례: 계산 전 정의

2026-10-03 집 코덱스. 기존 공개 OOF만 분석, 새 모델 학습·채택·제출·EC 잠금 사용 없음.

1. 현상이 있는 농장-날짜 비율과 해당 행들의 전체 SSE 비중은?
2. 현상이 있는데도 하루 24행 RMSE가 작게 나온 날의 빈도와 사례는?
3. 현상 중 큰 예측 실패가 겹친 부분의 비율은?
4. 온실·전후반 층화 및 다른 seed/context/validator에서도 어떤가?

- 대표 모델: 온도 W30G BASE7/CODEX726/PFN1–8, EC 계절v2 seed7. DIAG10은 각 공개 검증일을 한 번씩 합친 전체 집합(온도400/EC360 농장-날짜). EXT/A/B는 겹치는 별도 검증기로 합산하지 않는다.
- EC 현상: 정답 하루평균 >=1.0. 그중 과소예측 문제: 예측 하루평균−정답 하루평균 <=−0.2. 잘 맞힘: 그날 전체행 RMSE <=0.1.
- 온도 현상: |정답 배지 하루평균−실내 하루평균| >=2℃, 따뜻/차가움 별도. 차이를 놓친 실패: 일평균 예측오차의 부호가 실제 배지−실내 차이와 반대이고 |일평균 예측오차| >=0.5℃. 잘 맞힘: 그날 전체행 RMSE <=0.5℃.
- 온도 실내 입력은 train_X in_temp의 관측행 평균. 누락이 있으면 일평균 가용행 수를 기록하며, 주표는 24행 관측이 있는 날만 분류하고 전체400일을 분모로 둔다. 불완전일 빈도도 공개한다.
- 민감도: 온도 차이 1/2/3℃. EC 기준은 이전 답변의 1.0을 유지. 기준은 탐색 목적이며 대회나 물리적 이상 판정 기준이 아니다.
- 반론: 일정한 실내-배지 차이는 정상적일 수 있어 차이만으로 '이상 현상'이나 원인을 입증하지 않는다. 실제 목표값으로 만든 사후 분류이며 추론 피처로 사용할 수 없다. 잘 맞힘 기준도 분석용 허용오차이지 공식 합격 기준이 아니다.
