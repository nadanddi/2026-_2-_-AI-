# 검증 표현 및 검사 코드 정정 기록

기존 산출물은 보존하며 다음 사항을 정정한다.

1. 기존 비평의 ‘48시간 purge’ 표현은 부정확하다. 실행된 규칙은 같은 농장의 ±1 상대 기록번호 제외이며, 실제 달력의 연속 48시간을 보장하지 않는다. 모델 및 CV 분할은 변경하지 않았다.
2. verify_model_causality_v1.py는 두 번째 구간의 검사에서 앞선 구간 probe 입력도 포함됐는데 예상 허용 행수를 계산할 때 이를 빠뜨렸다. v1 실패 로그를 보존하고, v2에서 입력에 실제 존재하는 같은 농장의 이전 기록 수로 assert를 계산했다. 모델·선정·점수 변경 없이 8개 검사를 모두 통과했다. 해당 결과는 final_model_causality_v2.json에 있다.
3. 최종 비평자는 크레딧 제한으로 최종 산출물 파일 재열람·직접 기록을 하지 못했다. 앞선 코드 및 직접 실행한 CV 독립 검산, 루트가 전달한 최종 검사 결과를 바탕으로 메시지 비평을 완료했다. 루트가 원문을 critique_final_v1.md에 저장했다. 최종 독립 특징·9개 구성원 예측 검산은 비평자가 작성한 코드를 루트가 실행한 결과다.
4. full_cleaning_recheck_v1.json은 공식 원자료 400일의 일평균·5NN 삭제 규칙·삭제 ID·원본 값 보존·정제 X/Y 순서 일치·390일 9360행을 독립 재계산해 PASS를 확인했다. 표준화 특징 행렬 자체는 소스 검토 범위이며 별도로 독립 재구축하지 않았다. 소비된 추가 40일의 예측 점수는 계산하지 않았다.
5. 조건부 검증 342일은 검증 정답 EC로 제외 여부를 판단한 모집단이다. 훈련 특징에는 검증 정답이 들어가지 않았지만 실제 평가에서 이 모집단을 선택할 수 없으므로 실전 성능 근거로 삼을 수 없다. 최종 400일 정제 학습 모델에 대해 별도의 새 홀드아웃 평가를 수행하지 않았다.
