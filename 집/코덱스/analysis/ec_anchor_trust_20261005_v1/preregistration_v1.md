# EC 이웃 신뢰도 순차 실험 — 실행 전 고정

현재 실제 EC 계절 v2를 기준으로, 이웃의 높은 EC가 일반 날 예측을 과도하게 올리는 문제를 다룬다. 가족25 GATE를 먼저 전체 검산한 뒤 가족26 RIDGE를 실행한다. 후자는 조건부 시간별 잔차를 예측해 보정량을 작게 제한하는 대조 실험이다. 둘의 설정은 결과를 보기 전에 고정하며 모델 선택/문턱/피처를 결과로 조정하지 않는다.

run_v2.py CFG의 설정이 기준이다. 엄격한 5검증기×3시드 15점수 모두 감소, 각 DIAG10 시드의 농장별 정렬된 관측5일 블록 bootstrap 20000회, p_worse<.025/26 및 조정CI[.025/26,1-.025/26] 상한<0을 요구한다. 일반 날(실제 일평균 EC<1)의 DIAG10 RMSE가 어느 시드에서도 2% 넘게 악화하면 추가 보류한다. EL1·잠금·test 예측을 새로 만들거나 평가하지 않는다. 이 조건을 모두 통과해도 반복 공개 검증/2차 구간 새배치 확인 미실시 한계로 즉시 제출 구성으로 확정하지 않는다.

평가용 이웃은 같은 농장·같은 pass에서 현재 기록보다 앞선 공개 학습 날짜만 참조한다. 현재 시각까지의 입력 평균으로 서명을 만들고, 결측 대체와 거리 표준화는 시간별 참조 집합만 사용한다. 원시 EC 정답은 읽지 않고 기존 공개 OOF의8640행을 재사용한다. train_X에서 이8640행의 입력만 보존하며 test_X 값은 읽지 않는다.

메타 학습은 기존 matched inner에서 a로 학습한 v2 예측을 b에 적용한 출력으로 수행한다. b의 이웃은a만, 외부 검증 q의 이웃은outer tr만 참조한다. 둘 모두 validation ±1일 제거를 감사한다. b의 정답은 메타 모델 학습에만 쓰고 외부 정답은 피처/보정/모델 선택에 쓰지 않는다. 모든 outer training행의 완전한crossfit은 아니고 기존 단일 heldout b 하위집합이라는 한계를 기록한다.

GATE: 후보 보정 .5*clip(이웃3개 EC평균−현재 prefix v2평균,−.6,.6), 비용 가중 로지스틱 C1로 보정의 제곱오차 개선 여부 학습, 적용 문턱0.5. 비용=후보와 baseline의 내부 제곱오차 차 절댓값, 평균1로 정규화. 후보가 없는 행과pass1은 baseline그대로.

RIDGE: 같은 정보에서 시간별 내부 v2 잔차를 Ridge alpha100으로 학습하고 .2*clip(예측잔차,−.3,.3) 보정. 메타 표준화는 eligible b로만 fit. 외부 보정은 원 v2 최종 출력 뒤 더하고 outer tr 정답범위 clip한다. 기존 rawmix→shrink→clip과 구별되는 새 후처리이며 원 baseline을 바꾸지 않는다.

v1 준비는 원입력NaN을 불허한 assertion에서 fit/score전에 실패. v2는 관측값 prefix집계 및 시간별 reference median으로 처리하며 원v1/로그는 보존했다. 점수 보고나 문턱 변화 전에 수정된 준비 버전을 다시 고정한다.

기존 TabDPT family20은 별개이며 재시작·소스변경·부분점수 계산을 하지 않는다. 클로드 FZ0이 세 오탐 날짜의 생성과정 진단을 사전등록한 것(04394fc)을 발견했으므로 동일 진단 실행을 중복하지 않고 완료 결과를 읽기 전용으로 갱신한다.
