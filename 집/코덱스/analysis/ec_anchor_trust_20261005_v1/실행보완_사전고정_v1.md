# 최종 실행 버전 및 한계

사전 설정의 숫자·피처·모델·문턱·검증기는 변경하지 않았다. 실제 worker는 run_v6.py, 전체 verifier는 verify_v5.py, 별도 내부 목적함수 검산은 verify_learning_v4.py, 독립 Decimal/bootstrap은 crosscheck_v1.py다. 모두 모델 학습 전에 등록한다.

v1은 결측값 assertion 실패(fit0); v2/v3는 준비만 완료(fit0). v4는 준비파일 경로를 일괄 치환하다 외부 이전 감사 경로도 바뀌어 FileNotFoundError(fit0); v5에서 외부 preparation_v3 경로를 복구했고 v6에 최초 감사 모든 오차 영수증과 training ID/feature/cost SHA를 추가했다. 기존 파일/로그는 모두 보존했다. 이 오류들은 모델 피처·채택 규칙을 바꾸지 않았다.

거리 계산을 벡터화했으며 첫 검증일24행에서 원 slow 방식의 거리/feature/anchor IDs와1e-12로 대조한다. 원 입력 prefix 잘라내기·미래 입력 바꾸기 6건, 첫 실제 모델 재학습 재현/serialized 계수 재생/단독행/순서/다른query 변경/scalar clipping 감사를 통과해야 한다. 내부 scaler·표본ID·가중 목적함수 gradient를 독립 검산한 뒤 전체66셀·83160행의 산술 검산에서만 점수를 계산한다.

메타 학습은 내부 b 하위집합이고 전체 outer training행에 대한 완전한 crossfit이 아니다. ref-hour 표준화/결측중앙값은 두 농장의 reference 행을 모아서 학습한다(정답은 통계에 쓰지 않음); 실제 후보검색은 같은 농장/pass/앞선 날로 제한한다. 모든reference 해당열 결측이면0, 관측 prefix 없음도 reference median으로 채운다. 비용 절댓값≤1e-14인 내부 행은 GATE 학습에서 제외하며 후보없는/pass1은 두모드 모두 보정하지 않는다. 모든 타깃/anchor는 이미 공개된 OOF만 사용한다.

현재 baseline의 원시 모델 checkpoint를 다시 학습하지 않는다. 이전 preparation의 불변 SHA(df4ff2c3b7617676c61e4cee4b8e9690f9312a7cca448c0caec189cb5051b860)와 모든cache 파일 SHA, ordered IDs, 범위 및 기존 감사 영수증을 재사용한다. 이를 원래 모든 모델을 새로 재생성한 감사라고 표현하지 않는다. 반복 공개 검증을 새 미사용 holdout이라고 표현하지 않는다.

클로드 FZ0/FZ1은 별도 수행 중이므로 동일 생성과정 진단을 실행하지 않는다. FZ0의 full-day L2 logistic AUC만으로 입력 정보가 없다고 증명할 수 없으며 최적모델의 상한도 아니다. 해당 결과는 모델·표본의 제한 아래 구분에 실패한 근거로만 읽는다.
