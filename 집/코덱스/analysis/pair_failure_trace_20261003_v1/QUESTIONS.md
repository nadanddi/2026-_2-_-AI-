# F13/194 성공·F47/191 실패 추적

1. 하루 수준과 시간 모양 중 어디에서 오차가 생겼는가? 0–6/7–16/17–23시 고정 구간도 확인.
2. BASE/CODEX/PFN 전체가 같은 방향으로 실패하는가? 시드·문맥에 견고한가? 시간별 비음수 혼합의 정답 사용 오라클 하한은 얼마인가?
3. 두 날 외기 동일인데 실내 및 배지 차이가 예측과 어떻게 달라지는가?
4. 각 사례 실제 outer train의 같은 온실·같은 전후반 입력 유사 사례 상위5개와 앞뒤 기록은 어떠한가? 외기만 동일한 학습일도 확인.
5. 실제 원인과 관측된 실패 구조를 구분한다. 사후 하루 평균/정답/미래 관측은 추론 피처로 사용하지 않는다.

기존 프로파일·DIAG10 공개 온도 OOF 사용. 새로운 모델/유의성 검정/채택 없음. EC 값과 잠금 파일은 읽지 않음. 입력 유사도는 14개 하루 평균, 실제 outer train만 중위수/표준편차 계산. 현재 입력 전체 MASK 피처 공간의 거리를 대체하는 진단임을 명시.
