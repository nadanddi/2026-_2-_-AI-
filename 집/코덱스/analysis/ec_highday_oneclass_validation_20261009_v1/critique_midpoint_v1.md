# 독립 중간 비평

판정: 고정된 run_v2.py의 나머지 25폴드 실행 가능. 중간 결과에 근거한 성능 채택·설정 변경은 불가.

critic_recheck_v1.py midpoint를 별도 표준 라이브러리 계산으로 실행해 INDEPENDENT_ONECLASS_VALIDATION_PASS를 확인했다. 27개 원 분할의 온실·날짜 purge와 고EC 학습 부분집합을 재구성했고, 완료 2폴드의 1,632행 키·정답·시간·원 ET 점수, 등록 source SHA, 16개 지표 그룹 및 2개 구간 집계를 검산했다. 학습/검증 교집합은 없으며 일반일을 검증에서 유지한다. 8,040행 단일클래스 ET 실험과 다른 실험이다.

run_v2.py는 고EC 학습행에만 imputer, scaler, OneClassSVM 파이프라인을 fit한다. 등록 학습행과 실행 receipt의 fit 행수·일반 학습일 0·수렴 상태가 일치한다. 이는 소스와 실행 기록 감사이며 모델을 독립 재학습해 증명한 것은 아니다. 모든 예측의 native +1과 decision_function > 0가 일치한다. 0은 고EC로 판정하지 않는다. nu=.1은 학습 고EC의 정확히 90% 통과나 일반일 오탐률 10%를 보장하지 않는다. 점수는 확률이 아니다.

첫 두 DIAG 폴드 h15에는 고EC 1일과 일반 67일뿐이다. OneClassSVM은 TP 0/FN 1/FP 4/TN 63, ET는 TP 1/FN 0/FP 1/TN 66이다. 이 수치는 산술 확인용 중간 집계다. 고EC 한 사례로 탐지 성능·열등성·개선 가능성을 판단할 수 없다. 시간별 결과는 동일 날짜의 중복 관측이며 독립 표본이 아니다.

남은 실행은 이미 등록한 커널·nu·gamma·73특징·native 경계·27분할을 그대로 유지한다. 두 모델 사이에는 모델 계열과 학습 데이터 범위가 함께 바뀌어 차이를 고EC 전용 학습의 원인 효과로 해석할 수 없다. 결정적 모델의 반복 시드는 새로운 증거가 아니며, 전체 공개 검증일의 재사용도 새 홀드아웃이 아니다. 학습 24시간 통과율과 h15 검증 탐지율을 직접 비교해 과적합 크기를 산정하지 않는다.

추가 학습은 부모의 고정된 rest25 실행만 필요하다. 이번 검토에서는 추가 모델 fit·소비 40일 정답/성능 로드·최종 모델 저장·튜닝·제출을 하지 않았다. 최종 판정에는 전체 고EC와 일반일의 탐지/오탐, 농장 및 구간을 함께 확인해야 한다.
