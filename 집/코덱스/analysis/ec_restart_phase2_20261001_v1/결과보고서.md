# EC 재분석 2단계 · 0/6시 입력과 하루 수준

2026-10-01 · 집 · 코덱스. 사전 등록 main `d8d5ac8`.

## 결과와 다음 판단
**순환팬·난방 입력은 하루 EC 수준과 관련되지만, 0시 정보를 넘는 6시 추가 신호는 이번 사전 기준을 통과하지 못했다.** 기존 원시 운영 신호를 다시 확인한 결과이며 v2를 개선하는 새 정보라고 부르지 않는다. 다음 단계는 같은 데이터 격리 조건의 단순 기준선과 v2 재현이다. 이번 결과로 팬·난방의 보정식 또는 센서 거칠기 가중치를 만들지 않는다.

## 방법·분모
- 최종 잠금 40일 입력과 정답 제외. 360 온실-일·8,640행, 각 온실 180일. 하루 평균 EC>=1.2는 26일, 해당 민감도 분석은 334일. 상위5일 제외는 355일.
- 0시 현재 입력 15개, 6시 현재/누적/변화 입력 28개. 기본 연관 43검사와 0시 전체 입력을 추가 통제한 6시 28검사를 합친 **71개 가족**.
- 기본 통제: 온실, 상대 day, 온실×day, 전후반(day>=179), 온실×전후반. 추가 통제: 위 통제 + 0시 가용14값과 결측표시.
- Pearson 부분상관: 정답/특징 각각 통제변수로 잔차화 후 상관. 예측 점수 또는 인과 효과가 아니다.
- 87개 온실×5일 묶음, 2,000회 묶음 재표본 95% CI, 9,999회 묶음 부호 뒤집기 전체71개 최대통계 p_max. 시드261001. CI는 통제 적합 고정/다중 미보정인 설명용, p_max는 다중보정한 근사값이다.
- 모든 특징은 해당 온실 현재·이전(0~h)만 사용. 전체 하루 정답은 사후 목표 요약에만 사용한다. train_X/train_y만 읽고 test_X는 읽지 않았다. 정제·모델훈련·제출파일 없음.

## F3. 6시 추가 정보는 사전 조건을 통과하지 못했다

## F4. 결측·거칠기는 추가 수준 신호로 확인되지 않았다

- 0~6시 습도 거칠기: 기본 r=−.1620/CI [−.2427,−.0711]/p_max=.0336, n=359. 전반 −.2083에서 후반 +.0992로 방향이 반대. 0시정보 추가 통제 후 r=−.0231/p_max=1.
- 온도/CO₂ 거칠기의 추가 부분상관도 각각 −.0636/−.0593, p_max=1.
- 코드: features의 인접 관측쌍 평균 절대 변화, analyze의 동일 가족 검정. 신뢰도: 이 목록의 선형 추가정보 미확증은 높음. 한계: 결측일이 드물고, 거칠기는 센서 고장과 실제 변화 둘 다 반영할 수 있다. 센서 이상이 없다는 뜻이 아니다.
