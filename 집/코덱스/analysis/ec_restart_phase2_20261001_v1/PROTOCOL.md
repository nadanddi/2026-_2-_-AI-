# EC 재분석 2단계: 0/6시 입력과 하루 수준

2026-10-01 · 집 · 코덱스. 실행 전 main에 이 문서와 코드를 경로 지정 커밋한다.

## 질문 및 기존 연구와의 구분
1. 0시·6시 입력의 EC 하루 평균 연관은 온실·상대날짜·전후반을 통제해도 남는가?
2. 6시 입력의 연관은 0시의 14개 원시 입력을 모두 통제한 뒤에도 남는가?
3. 두 온실/전후반에서 방향이 일치하는가? 고EC≥1.2일 및 EC 상위5일 제외에 민감한가?
4. 결측·거칠기 신호가 관리 입력 연관과 구별되는가?

H2 자정 수준 Ridge, H7 유사일, H8 평활, H19~22 CO2/수분 대리, H23 중간반응은 이미 선별 실패. 이번은 그 모델의 재선별이 아니라 원시 입력의 설명적 연관 지도다. v2 잔차를 대상으로 하지 않으므로 v2보다 추가 정보가 있다는 주장 금지.

## 데이터·특징·대상 고정
- train_X에서 F13/F47, 최종잠금40일 입력/정답 모두 제외. EC 정답은 잠금일을 숫자변환 전에 건너뛴다. test_X 읽기 금지. 평가 MASK는 기존 확정된 가용14열 목록으로 고정.
- 관측단위: 온실-일 360개(각24행), 정답: 일평균 EC(사후 분석용, 예측 특징 아님).
- h0: 14개 현재 원시값 + 현재 실내3센서 결측 개수 = 15검사.
- h6: 14개 현재 원시값 + 7개 장치의 0~6시 평균 + 실내3센서의 0~6시 평균 절대 1시간 변화(두 시점이 관측된 인접쌍만) + 실내3센서의 6시−0시 변화 + 0~6시 실내3센서 결측 개수 = 28검사.
- 총 기본43검사. 추가 조건부 h6검사28개. **동일 다중비교 가족71개**, 상수/추정불가도 제외하지 않고 p=1로 유지.
- 결측 수치 특징은 해당 검사에서 완전관측 일만 사용. 0시 추가 통제의 결측값은 이 설명적 자료의 열평균+각 열 결측표시로 표현(모델 학습 전처리가 아님). 다른 열의 결측은 무관한 검사의 표본을 지우지 않는다.

## 분석 사전 고정
- 기본 통제: 절편, F47, 표준화 day, F47×day, 후반(day>=179), F47×후반.
- 추가 통제: 기본 통제 + 0시 가용14값 + 각 열의 결측표시. 통제값은 열표준화.
- 효과: 원시 Pearson r, 통제 후 잔차 Pearson r. 선형 통제이며 인과 효과가 아니다.
- 불확실성: farm×floor(day/5) 묶음으로 재표본 2000회, 잔차 Pearson r의 95% percentile CI. 통제 적합 고정의 조건부 근사 CI, 다중보정 안 된 설명용으로 표시.
- 검정: 잔차 x*y를 동일5일 묶음으로 합쳐 S=sum(U), T=S/sqrt(sum(U²)); 9999회 동일 묶음 Rademacher 부호 뒤집기(시드261001), 전체71개 최대|T| 분포로 p_max 계산. 묶음별 독립·대칭 근사를 가정하고 미지 출처 반복 의존성 한계 명시. 정확한 무작위실험 p값 아님.
- 진행 판단: p_max<.01, 두 온실 부분상관 같은 방향 및 각|r|>=.15, 고EC일 제외도 전체와 같은 방향이면 후속 후보 검토 가능. 이는 모델 채택 규칙을 대체하지 않는다. 통과해도 기존 H가설과 같은 원시 정보를 재포착한 것인지 대조한다.
- 층화/민감도는 전71개에 같은 규칙 적용, 별도 유의성 검정하지 않는다. 최고 신호만 선택적으로 제외 분석하지 않는다.
