# X3 magnitude 통제 구현 차이 사전 정정

2026-10-02 집 코덱스. 사전 main `e7684d7`로 원래 run.py 실행을 시작한 뒤 코드 감사에서 발견한 차이: PROTOCOL은 하루 십진수 magnitude **중앙값** 통제를 지시했지만 원래 코드는 magnitude_mean(**평균**)을 통제한다. 아직 원래 결과를 확인하지 않은 상태에서 이 문서와 추가 코드를 사전 작성한다.

원래 코드·산출물은 보존한다. `run_stats_median_v2.py`는 원문 row_features.csv의 magnitude로 날별 중앙값을 만들고 원래 통계 15비교를 **중앙값 통제**로 반복한다. 원래 5개 지문·그룹 threshold·표본수·층화·5일블록·seed3103/3104·20,000회·p_adjusted<.01 판정은 같다. 바뀌는 것은 magnitude 교란 통제의 평균→중앙값뿐이다. 최종 해석은 원래 사전문서와 일치하는 중앙값 통계로 판정하고 평균 통제를 민감도 자료로 병기한다.

추가 안정성 검산: 원시 지표/결과가 상수이면 통계는 UNTESTABLE_CONSTANT로 기록한다. 원래 회귀의 극소 잔차에서 계산된 상관은 해석하지 않는다. 상수 지표는 두 그룹 중 하나가 0일이라 원래 발견 기준도 통과하지 못한다. 이 조치는 가설·그룹·유의 기준 변경이 아니다.

신규 출력은 `stats_median_v2.csv`, `day_magnitude_median_v2.csv`, `results_stats_median_v2.json`. 원래 산출물 덮어쓰기 없음. root가 추가 코드와 본 문서를 main에 커밋했음을 확인한 뒤 실행한다. 모델·제출·최종잠금 채점 없음.
