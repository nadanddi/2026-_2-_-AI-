## 지금 자료로 할 수 있는 것

1. 이레아이에스에서 센서 이상·시간 키·관수량의 누적/구간 의미를 먼저 확인한 뒤 **실내/배지 온도 차이와 관수·배지 무게의 동시 변화**를 탐색한다. 온도 모델 개선은 Claude에게 자료/품질 결과만 인계한다.
2. 더아이엠씨/그린씨에스에서 **현재·과거 환경으로 창/커튼 상태를 얼마나 추정할 수 있는지** 조사한다. 대회 입력에 제어가 없으므로 제어값을 평가 피처로 직접 넣지 않는다. 상태 추정 피처도 대회 학습fold 안에서 생성하고 별도 검증해야 한다.
3. EC는 자료별 센서 척도·측정 위치·0값 의미를 확인한 뒤 농가 단위로 사용할 구간을 결정한다. 지금 0을 자동 결측으로 바꾸거나 목표를 섞지 않는다. 높은 배지 EC의 하루 수준을 개선한다는 증거는 아직 없다.

이 순서는 조사 우선순위이며 모델 채택/성능 향상 결론이 아니다. 외부자료와 대회의 중복·가용입력·규정 점검도 모델 실험 전에 필요하다.

## 재현·검산과 한계

- `inspect_zip_v1.py`: 원본 헤더·행수·결측·중복·기본 범위. `inspect_items_v1.py`: 항목/농가/시간별 분리와 원본 보존.
- `inspect_candidates_v2.py` 뒤 v3에서 **2024 품목명 열의 숫자코드80400을 딸기로 처리**. v2의 금화 `strawberry_rows=0`은 필터 오류였으며 기각한 사실이 아니다. v3/최종 검산본을 사용한다.
- 기업 페이지2/3의 초기 수집은 페이지 이동 직후 오래된 목록이 섞였다. 선택된 페이지를 확인하고 다시 읽은 `enterprise_overview_corrected_v2.json`24고유 항목이 최종 목록이다.
- `verify_findings_v1.py` 종료0. 원본을 다시 읽어 EC 행수·0값·소수값·고유값·농가수를 **pandas와 표준csv.DictReader/Counter**로 독립 비교, 모든 assertion 통과. RDA원본도 다시 읽었다. 원본/보존본 SHA256 동일.
- 수집행에는 빈값이 없더라도 존재하지 않는 시간·센서 행이 있을 수 있다. 농가별 시간 공백/중복은 상세 JSON에 기록했으며 빈칸0개를 완전한 패널로 해석하지 않았다.
