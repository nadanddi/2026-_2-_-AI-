# 낮은 예측의 진짜 고EC와 일반날 오탐 공동 학습

2026-10-06 집 코덱스. 10-05 시작한 실험 폴더 이름을 유지했다. 공동 학습을 실제 실행했지만, 기존 고EC 포착을 유지하며 오탐을 줄이는 목표는 달성하지 못했다. 두 후보 모두 채택하지 않는다.

사전 커밋은 94c2ba9다. 기존 DIAG10·A·B와 시드 7·101·2024를 그대로 사용했다. 각 외부 검증의 학습 날짜 전체에 4분할 교차 예측을 만들었다. 같은 온실의 검증 날짜와 ±1일을 해당 학습에서 제외했다. 외부 평가 날짜의 정답은 대리 예측기·참조 특징·구별기 학습에 들어가지 않았다. 다른 외부 검증에서 만들어진 OOF를 섞는 방식도 사용하지 않았다.

경계 사례를 찾기 위해 기존 R3의 LightGBM Tweedie 구성만 새로 교차 학습했다. 이는 완전한 기존 A(R3·TabPFN 혼합)의 재현이 아니라 EC 대리 예측이다. 실제 계절v2 A를 외부 비교 기준과 첫 고EC 판정으로 유지했다. SG2 최신 합본 위 실험은 아니다.

동일 데이터·22개 특징·로지스틱 회귀 C=1·판정 문턱 0.5에서 두 가중치만 비교했다.

- UNIFORM: 고EC와 일반날의 총 가중치를 균형 있게 맞췄다.
- HARD: 위 가중치에 더해, 진짜 고EC이면서 해당 시각 대리 누적 예측이 1.2 미만이거나 일반날이면서 0.9 이상인 행의 가중치를 4배로 했다. 최종 평균 가중치를 1로 정규화했다.

GUARD는 기존 A 누적 예측≥0.9가 잡은 날 중 새 구별 점수≥0.5인 날만 남긴다. DIRECT는 새 구별기만으로 판정한다. 외부 정답을 보고 문턱·가중치를 바꾸지 않았다. 가중치를 적용한 구별 점수는 실제 고EC 발생 확률로 교정된 값이 아니다.

## 검증 결과

하루 끝 23시 DIAG10 외부 360개 온실별 기록일(고EC 31일, 일반 329일)의 결과다.

| 방식 | 고EC 포착/31 | 일반날 오탐/329 |
|---|---:|---:|
| 기존 A |30|11~12|
| UNIFORM + GUARD |24|8~9|
| HARD + GUARD |27~28|9|

| 시드 | UNIFORM 포착/오탐 | HARD 포착/오탐 | 기존 포착/오탐 |
|---|---:|---:|---:|
|7|24/9|27/9|30/12|
|101|24/9|28/9|30/11|
|2024|24/8|27/9|30/11|

HARD는 같은 조건의 UNIFORM보다 DIAG에서 고EC를 3~4일 더 포착했다. 하지만 기존 A보다 고EC를 2~3일 더 놓치면서 일반날 오탐을 2~3일 줄였다. HARD DIRECT는 포착27~29/오탐41~44로 기존보다 포착 감소·오탐 증가였다. GUARD의 오탐 비증가는 구조적으로 보장되므로 그 자체가 학습 성능 증거는 아니다.

다른 검증에서는 가중치 효과의 방향이 달랐다. A·B는 원 검증기의 중복 날짜 출현 단위로 집계했다(A264/B263 출현). 아래 고EC 출현 수를 독립 날짜 수로 해석하면 안 된다.

| 검증기 | 고EC 출현 | 기존 포착/오탐 | UNIFORM 포착/오탐 | HARD 포착/오탐 |
|---|---:|---:|---:|---:|
|A|43|41/8~10|20~21/2~3|19/3~4|
|B|29|25/11~12|21/9|19/9~10|

HARD는 A·B에서 UNIFORM보다 고EC 포착이 감소했다. 모든 시드×검증기에서 포착 감소 없이 오탐 감소를 요구한 사전 관문은 두 방식 모두 실패했다(비악화0/9). DIAG 오탐 엄격 감소는 각각3/3이지만 포착 감소 때문에 통과하지 못했다. 전문가와 결합한 RMSE나 원래의 RMSE 통계 채택 기준을 통과했다고 주장하지 않는다.

0·6·12·23시 및 온실×기간별 결과는 verification_v5.json에 보존했다. 하루 끝 포착률을 이른 시각 성능으로 해석하지 않는다.

## 공동 학습 사례와 남은 문제

각 외부 학습 구간은 246~274일, 고EC 13~26일이었다. 23시 대리 예측 기준의 낮게 예측된 진짜 고EC는 6~20일, 일반날 오탐은 1~18일이었다. 두 종류가 각3일 이상인 구간은57/60이었다. 일부 구간은 일반날 오탐이1일뿐이므로 모든 학습 구간의 정보가 충분했다고 주장할 수 없다. 내부 대리 예측기의 고EC 학습일은 최소4일로, 이전의 고EC0건 모델 문제는 피했다.

추가로 놓친 DIAG 고EC는 F13_137·F13_177(세 시드)과 F13_120(시드7·2024)이었다. 제거한 일반날 오탐과 혼재되어 있다. 원 CSV를 다시 읽은 사후 진단에서 시드7의 사례는 다음과 같았다.

| 실제 고EC 기록일 | 기존 A 하루 누적 예측 | 대리 누적 예측 | 구별 점수 |
|---|---:|---:|---:|
|F13_120|1.165|0.740|0.468|
|F13_177|0.938|0.876|0.325|
|F13_137|1.307|0.875|0.277|

기존 A가 잡은 고EC 신호를 대리 예측이 충분히 유지하지 못한 사례가 확인됐다. 이는 단순히 학습 사례 수만의 문제가 아니며, 대리 예측과 실제 A의 경계 차이도 남아 있다는 단서다. 한편 대리 예측의 낮은 값이 실패의 유일한 원인이라는 인과 증명은 아니다. A에서 추가로 놓친 고EC도 같은 온실·기간의 학습 고EC가0인 경우는 없었다.

학습 데이터의 분류기 포착률은 DIAG DIRECT 기준99.15%였으나, 이는 OOF 대리 특징에 구별기를 적합한 학습 점수다. 구별기의 독립 OOF 검증 점수가 아니다. 또한 train GUARD의 첫 예측은 대리, outer GUARD의 첫 예측은 실제 A이므로 둘의 격차를 동일 게이트의 순수 과적합 정도로 해석하지 않았다.

가중치 효과는 같은 데이터·대리 모델·특징 안에서 비교했다. 학습 범위 확대의 순수 효과를 이전 실험과 정량 분리하지는 못했다. 이전과 대리 모델도 달라졌기 때문이다.

## 독립 검산과 불확실성

최종 검산 대상은 대리 EC 모델300개·구별기120개·학습/외부 CSV240개다. 원 참조 날짜·특징/정답/가중치 해시, 내부/외부 날짜 분리와 ±1일 제외, 학습 전처리, 예측과 판정 규칙을 재생했다.

- 로지스틱 확률의 수식 재생 최대 오차2.33e-15.
- Tweedie 트리의 개별 행 계산과 누적 계산 오차7.22e-16.
- 학습 목적함수·전처리 독립 검산의 최대 기울기6.81e-8.
- 대리 모델2개와 구별기2개를 새로 학습해 정확히 재현.
- 원 CSV에서 TP/FN/FP/TN과 분자·분모 비율 재계산, 순위/sklearn AUC와 양성×음성 쌍 비교 일치.

DIAG의 온실별 기록 순서5일 블록,3시드 평균,10,000회 재표본 진단에서 HARD의 전체 오분류 증가량은 평균+0.333일,95% 구간[-4.333,+4.667]일이었다. 비개선 비율0.5849로 개선을 확정할 근거가 없었다. 일반날 오탐 차이는 평균−2.333일,95% 구간[-6,0]일이었다. GUARD 구조상 오탐은 증가할 수 없으므로 오탐 구간만 보고 채택하지 않는다. 이 통계는 분류 진단이며 RMSE 검정이 아니다.

근거는 verification_v5.json·fresh_numbers_v3.json·diagnostic_v1.json, 실행 코드는 verify_v5.py·fresh_numbers_v3.py·diagnostic_v1.py다. 구별 점수의 AUC는 순위 진단이며 가중 점수를 실제 발생 확률로 해석하지 않았다. 기존 EC 예측값으로 계산된 Brier 항목도 확률 교정 지표로 쓰지 않았다.

## 판정과 범위

- 양쪽 경계 사례를 함께 학습했는가? 예 — 신뢰도높음. 날짜별 재계산으로 확인했다. 다만 대리 예측 기준이고 일부 구간의 일반날 오탐 사례가 적다.
- 기존 고EC 포착을 유지하며 오탐을 줄였는가? 아니오 — 신뢰도높음.3시드·3검증기에서 사전 목표를 통과하지 못했다.
- 가중치가 항상 도움이 되는가? 입증하지 못했다. DIAG와 A·B의 방향이 달라 재현성이 부족했다.
- 입력 정보가 없거나 모든 구별기가 불가능한가? 미확정. 실제 A와 대리의 차이·표본 희소성·현재22개 특징과 선형 분류기의 표현력·고정 문턱이 함께 남아 있다.

다음 관문은 실제 A와 같은 독립 교차 예측으로 경계 정의를 맞추고, 새로 놓친 고EC와 제거한 일반날의 특징·출처 차이를 비교하는 것이다. 이번 외부 날짜의 정답을 보고0.5문턱이나4배 가중치를 바꾸지는 않았다. 고EC 크기 전문가와의 결합 RMSE는 별도 검증이 필요하다.

실행 기록: 순차 실행에서 완료한10구간은 그대로 재사용했다. 미완료 산출물도 보존하고 새 이름으로3프로세스 재개했다(65f6cd8). 모델·특징·가중치·문턱은 바꾸지 않았다. 검산기의 보조 함수 이름은 학습 전 새 버전으로 수정했고, v4의12시간 표본은 일별 누적 검산에 부족해 새v5에서24시간으로 교정했다. 원 실패 로그를 보존했고 성공 로그는verify_v5_ready.log다. 쉘 인용 오류로 새 검산 파일이 만들어지지 않았던 실행 로그도 보존했다.
