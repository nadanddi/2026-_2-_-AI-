# 작업일지 밖의 파일도 교차 확인 (2026-10-03)

Git 미추적 파일 AG0 고EC 상태 지속기간 진단의 소스·로그를 읽었다. 고EC31일에서 잔차와 정답 기준 상태기간 상관 .10, 이전 입력 예측 기준 기간 -.05, 전체 .10으로, 로그상 단서 판독 실패다. 숫자는 이번에 독립 재계산하지 않았으며 모델 성능 증거로 사용하지 않는다. 동 배정 대리표지와 전체 공개 OOF 이력 사용은 실제 fold 내부에서 재구현해야 하는 제한이다.

RD4 날짜별 정밀도 로그도 확인했다. 대응하는 precision_by_day 소스는 발견하지 못했으며 rd4_f13f47_processing_v1.py는 관련 다른 진단 소스다. 원시 정답과 train/test 통계를 사용하는 관련 코드는 재실행하지 않았다. 이 로그로 전처리 여부나 합법적인 개선 효과를 확정하지 않는다. 다른 AI 미추적 파일은 수정하거나 커밋하지 않았다.
