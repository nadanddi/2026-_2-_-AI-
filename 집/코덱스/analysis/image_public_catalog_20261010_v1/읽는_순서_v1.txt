공개샘플21 설명서와 실제 이미지 정리

1. 공개21_이미지목록_v1.html
   사진 21장을 원본 JPEG 바이트로 내장한 독립 파일이다. 유형별 선택과 사진 확대 기능 코드를 포함한다. 각 카드에 공식 설명, 직접 관찰, 확인 불가 정보, AI허브 선정 참고, 후속 증강 방식을 함께 적었다. 외부 이미지·스크립트 다운로드가 없다.
2. 유형별_사진별_정리_v1.txt
   PDF 쪽 번호를 붙인 7개 분류 정의와 21개 사진 설명을 읽는 자료다. 부분 생성·스타일의 정확한 편집 위치를 추측해 표시하지 않는다.
3. 공개21_개별정리_v1.csv / catalog_v1.json
   후속 AI허브 원본 선별·증강에 사용할 구조화 목록이다. 파일별 타입/라벨/PDF쪽/관찰/미확정/선별조건/증강 정의/원본 크기·경로·SHA를 보존한다.
4. 집/코덱스/local/image_public_catalog_20261010_v1/*_유형판_v1.jpg
   각 유형의 3장을 모은 그림 7개다. 유형과 라벨, 파일명, 크기, PDF 쪽, 공식 설명 요약을 표시했다. 가로·세로 사진의 전체 화면을 보존했다.

검산 및 비평
verification_v1.json: CSV/JSON/HTML/TXT 21개 ID·순서·내용 일치, HTML 내장 JPEG 21개 원본 바이트 동일, 타입/라벨/크기 SQLite 독립 집계, PDF 파일명·쪽 번호 대조, 그림 7개 SHA 확인 PASS.
실제 사진 21개와 PDF 렌더 3쪽을 모두 직접 확인했고 유형판 7개도 육안 확인했다. 공식 설명을 사진에서 추측한 라벨과 혼합하지 않았다.
HTML의 실제 브라우저 조작은 로컬 file: URL이 브라우저 정책으로 차단되어 검증하지 못했다. 코드/구조/내장 이미지 검사는 통과했으며 우회 실행은 하지 않았다.
독립 비평 결과는 critic_mid_final_v1.json에 기록한다.

다음 작업 상태
이 자료를 기준으로 AI허브 원본을 넓게 선별한다. 직전 검색은 캐시 VS금실2/설향3의 1000개에만 한정, 색감/치수/격리 조건 통과 513개를 모두 유사한 사진이라고 판정한 것이 아니다. 후보별 공개21 유사도 점수 전체는 별도 image_sample_matched_20261010_v1/selection_all_scores_v2.json에 있다.
원본 2개만 본 제작에 쓰는 제한은 폐기했다. 첫 전체 생성/배경 교체 2개는 제작 품질 확인 사례로 보존한다. 사용자 최신 요청을 우선해 원본100장 선정·필터300장·추가 생성은 아직 실행하지 않았다. Python 필터 허용 답변은 이후 작업에도 유지한다.
학습·정확도·증강 효용·채택·제출 판정은 이번 작업에 없다.
