## 원형과 이번 변경

카탈로그 6.64·6.71 및 `집/클로드/research/ec_pfnbag8_v2_gpu.py`를 읽었다. E40_8 원형은 **.6×R3 + .4×TabPFN 8문맥 평균**이고, 짝 기준 v2는 **.8×같은 R3 + .2×첫 4문맥 평균**이다. 실내 당일 평균 3열을 추가한 41열 조합(6.77)을 이 안으로 혼동하지 않는다. 과거 통계 기준 및 EXT 악화를 명시하며, 이미 실패한 결과를 통과한 것으로 바꾸지 않는다.

K2: 기존 FULL38과 고정 E40_8을 새 R3 시드 401·402·403 및 새 PFN 문맥 5~12로 재확인한다. K3: 문맥 5~8 자료를 22폴드에 추가 생성하여 같은 폴드의 새 짝 기준과 클로드 ST1용 자료를 제공한다. **K3는 별도 제출 후보·별도 혼합안이 아니다.** .2×8문맥의 새 안은 만들지 않는다.

검증 조건은 기존대로 DIAG10·A·B·EXT10·EXT12이며 EXT의 무악화/개선 요구를 제거하지 않는다. 공개·리더보드 점수나 평가 입력 통계로 비중·방향을 정하지 않는다.

## 데이터·분할·입력

공통 `../ec_model_common_20261002_v1/common.py`의 prepare/split_fold/feature_checks를 그대로 쓴다. F13/F47 비잠금360일·8,640행, DIAG10 10 + A5 + B5 + EXT10/12 각1 = 22폴드. 잠금40일은 EC 숫자 변환 전에 제외하고, 모든 fit에서 검증일 및 잠금일±1일도 제외한다. 학습 입력은 MASK, 평가 행 특징은 같은 온실의 현재·이전 입력만 허용한다. 평가 원본 test_X 값은 읽지 않는다. 원시 라벨로 만든 새 특징·다른 온실 입력·미래 입력은 쓰지 않는다.

## 고정 학습과 예측식

- R3: 시드401/402/403, 기존 읽기 전용 core의 ET600 leaf1(FULL38) 60% + LGB Tweedie800(BASE14) 30% + MLP(128,64; alpha .01; 학습률 .001; max_iter800; 기존 내부 행분할 조기종료) 10%. ET/LGB 및 BLAS/torch 계산 스레드는 2로 제한한다. MLP 조기종료에 외부검증 라벨은 넘기지 않는다. 이번에 날짜 조기종료 방식으로 바꾸지 않는다.
- PFN: 현재 로컬 V2 reg 체크포인트, CPU float32, 내부 n_estimators4, 각 문맥은 해당 폴드 학습행에서 2,000행(부족하면 전부)을 비복원 추출한다. 문맥 시드5~12 각각을 sample seed와 model random_state로 같이 사용한다. telemetry 및 HF/Transformers 네트워크를 비활성화한다. local model_path를 명시하며 체크포인트 파일 해시를 남긴다.
- PFN 문맥표본 및 예측은 R3 시드 간에 공유한다. 3개 R3 시드가 PFN의 별도 3개 독립 표본까지 의미한다고 주장하지 않는다.
- `bag4 = mean(PFN5,6,7,8)`; `bag8 = mean(PFN5..12)`.
- 같은 새 R3마다 `v2_fresh = finish(.8×R3 + .2×bag4)`; `E40_8 = finish(.6×R3 + .4×bag8)`.
- `finish = 기존 .5현재예측+.5당일현재까지평균 → 해당 학습정답 min/max clip`. 원시 멤버를 섞고 마지막에 후처리한다. 후처리된 성분을 먼저 따로 clip해서 더하지 않는다.
- 추가 고정 기준 `v2_fixed = mean(phase3 v2_seed7,101,2024)`를 모든 새 R3 시드의 공통 기존 후보 기준으로 둔다. phase3 캐시의 row_id/라벨/파일 해시를 확인하고 사용한다.

## 판정: K2 단일안, 기준2개 모두 통과

각 기준(v2_fresh, v2_fixed)에 대해 R3 시드3×검증기5의 15칸 전부 E40_8 pooled RMSE가 엄격히 낮아야 한다. A/B는 발생행 pooled 점수로 판정하고, 고유행 예측평균 점수도 따로 보관한다. 시드 평균은 진단용이며 개별 실패를 덮지 않는다.

DIAG10 각 R3 시드, 각 기준과의 대응 비교를 농장층화 기존5일블록(80개)로 20,000회 재표집, RNG918로 고정한다. 양쪽 비교를 모두 통과하도록 보수적으로 `p_worse < .025/2 = .0125`, **97.5% MSE 차이 양측 구간 상한 < 0**을 요구한다. 두 기준 총30칸·DIAG6검정의 결과를 전부 남긴다. 새 후보·비중을 여러 개 시험한 family로 확대하지 않는다. 이 추가 보정은 두 고정 기준 비교에 적용한다.

전체 검증기 및 신뢰구간을 통과하기 전 후보 채택·제출 구성을 선언하지 않는다. 최종잠금 채점·제출 CSV·재현 ZIP 생성은 이 실험 코드 범위가 아니다. K1 산출물은 별도 담당이다.

## 분할 실행·캐시·수집

`run_stage2_tabpfn.py --run --shard I` (I=0/1/2)는 공통 folds의 **순번 modulo3**가 I인 그룹만 학습한다. 총3개 그룹은 겹치지 않고 22폴드를 전부 덮는다. `--run --fold NAME:INDEX`는 장애 복구용 단일 고정 폴드 실행이다. 통계 선택에는 쓰지 않는다.

폴드별 O_EXCL lock으로 중복 fit을 막고, NPZ와 JSON은 같은 출력 폴더 임시 파일에서 원자 치환한다. 검증 캐시는 코드·프로토콜·공통/core·데이터·fold행·환경·PFN체크포인트·시드 해시가 일치할 때만 재사용한다. 비정상 종료로 남은 lock은 자동 제거하지 않는다. 담당자가 프로세스가 끝난 것을 확인한 뒤 해당 lock 한 파일을 제거하고 같은 그룹을 재개한다. 유효한 모델 캐시는 다시 학습하지 않는다. 완료 NPZ만 존재하고 JSON이 없거나 해시가 다른 경우 실패를 보고하며 덮어쓰지 않는다.

R3 66개 및 PFN 176개 원시 예측·문맥 인덱스/행ID·관련 메타데이터를 `집/코덱스/local/ec_stage2_tabpfn_20261002_v1/`에 영속 저장한다. 각 폴드 raw PFN5~12, 평균4/8, raw R3 각시드, 정답/row_id를 보관한다. `--collect`는 **22폴드×8문맥과22폴드×3R3시드 전수 완료·해시·행 정합 확인 후에만** wide OOF(27,720발생행)와 long OOF, NPZ, 요약/판정을 새 파일로 작성한다. 이는 공개 학습 검증자료이며 플랫폼 제출용 CSV가 아니다. 이미 완료된 collect 결과는 해시 검증 후 읽기만 한다.

라이브러리 버전·코드·원본데이터/잠금/split·기준캐시·PFN 파일 해시, 학습/검증일 수와 행 목록, 학습 점수, 폴드 점수 평균/표준편차를 남긴다. 추가 모델 튜닝·비중/문턱 재선택·평가 통계 학습·외부 원천 추적은 하지 않는다. 데이터 재사용과 PFN 표본 공유에 따른 해석 한계를 최종 보고에 적는다.
