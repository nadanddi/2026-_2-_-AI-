# 평가 고EC 부재 가설: 별도 집계 하한 진단 사전 계획

- 기존 학습 제거 실험의 코드·임계값·판정 기준에는 영향 없음.
- 고정 가정: 모든 평가 온실-일의 실제 EC 일평균 <= 1.0.
- 실제 9회차 submission_14.csv(sha f2fe5cf7e5299c2c0f2ac39f0e071066744b0c75ea19e1d7dff1e3a6282ba18a)만 사용, 숨은 정답 사용 없음.
- 각 온실-일 24행, 현재 test_X의 1440 row_id와 일치 확인. Jensen 부등식으로 전 행 균등 RMSE 하한 L=sqrt(mean_days(max(제출 EC 일평균-1,0)^2)).
- EC 표시 점수 .1384의 보수적인 상한은 .1385(통상 반올림과 절사 포괄). L > .1385이면 전 행 균등 채점이라는 전제 아래 부재 가설과 양립 불가.
- 채점 범위가 숨은 일부 평가행일 수 있으면 조건부 결과만 보고한다. 임계값을 스캔하거나 개별 평가일의 실제 정답/고EC 여부를 역산하지 않는다.
- sqrt/float/f-sum과 Decimal(precision60)으로 독립 산술 교차 확인. 새 모델·가중치·제출 파일 생성하지 않음.
