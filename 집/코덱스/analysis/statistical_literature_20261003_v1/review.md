# 최종 주장 반론·재현성 검토

- 수학적 비중 한계: 원본 CSV에서 28셀을 별도 표준 라이브러리 프로세스로 재계산. 진단 코드의 벡터 연산과 독립된 스칼라 산술·math.fsum 일치. 원본 SHA256 일치. 온도 3멤버/EC 2묶음, 비음수 합1 제약으로 범위를 제한했다. 음수 비중·새 전문가·편향 보정에는 같은 한계를 적용하지 않았다. 오라클 하한을 달성 가능한 개선율로 표현하지 않았다.
- 날씨 그룹: 400일/122그룹 CSV 재확인, 기존 감사 폴드의 공유 일 합291 확인. 기존 분할을 새로 재학습한 검증이 아니다. 공유를 정답 누수로 판정하지 않았다. 추가 GUARD의 학습량 감소 혼동을 명시했다.
- 잔차 보정: 과거 값과 원시 목표의 상관은 추가 예측정보의 증거가 아니다. PAR1/MW1/GPBoost 실패를 고려하고 잔차 추가 정보 검사를 선행한다. 필터 파라미터·메타 OOF는 외부 학습 안에서 생성, 외부 정답 상태 업데이트/미래 평활화 제외. 이 조건을 실행한 새 모델은 없으므로 성능 주장은 없다.
- 게이트: FFORMA 원문 목표와 최종 혼합 MSE를 구별. 제안식의 M은 편향을 포함한 2차 모멘트. 기존 G1 실패와 표본 수 제약 명시. 전체 PFN 포함 내부 OOF 비용과 지역 수축 필요. 조건별 게이트가 반드시 성공한다고 주장하지 않았다.
- 분포 변화: IWCV의 P(y|x) 불변 가정을 명시. 평가 전체 입력을 새 변환 적합에 쓰는 제안 제외. 계절 표현 성공을 실제 달력 복원 또는 인과 증거로 해석하지 않았다.
- 외부 문헌: 기술 근거는 저자 논문/학술지/공식 문서. 국내 논문 전체 원문 미확인, 서지와 검색 노출 초록·일부 본문만 조사한 제한 명시. 의료 분류/온라인 분류/대규모 시계열 성과를 우리 회귀의 개선 증거로 전용하지 않았다.
- 데이터 경계: EC 공개 DIAG10과 온도 기존 검증 예측만 사용. EC 잠금·평가 test·제출 생성 없음. 본 연구는 사후 진단, 튜닝/비중 선택/유의성 판정 없음. 기존 성능·후보 변경 없음.
- 재현: diagnose.py, verify.py, QUESTIONS.md, diagnostic.csv/json, verification.json 보존. 실행된 진단 스크립트 수정 없음. 결과의 타당성 위협은 보고서 각 절에 기록. 기존 TK2 계산은 별도 작업이며 완료를 주장하지 않았다.
