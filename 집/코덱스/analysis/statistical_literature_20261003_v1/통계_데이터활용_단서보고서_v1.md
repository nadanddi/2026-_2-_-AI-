# 온도·EC 개선을 위한 통계·데이터 활용 단서

작성: 2026-10-03 집 코덱스. 사용자 요청에 따른 문헌 조사와 기존 공개 검증 예측의 사후 진단. 새 모델의 성능 개선을 입증한 보고서가 아니다. 기존 제출물·평가 예측·EC 잠금 데이터는 읽거나 생성하지 않았다. 기존 TK2 PFN 계절 실험은 별도 GPU 작업으로 계속 실행 중이다.

## 직접 다시 계산한 사실

계산 전에 `QUESTIONS.md`에 질문을 기록했다. `diagnose.py`는 저장된 DIAG10 예측으로 28개 조건을 계산했고, 별도 프로세스의 `verify.py`는 pandas/numpy를 쓰지 않고 CSV 행·스칼라 산술·math.fsum으로 전부 다시 계산했다. `verification.json` PASS. 원본 및 코드 SHA256도 일치한다.

| 진단 대상 | 조건 수 | 정답이 모든 구성원 예측 범위 밖에 있는 행 | 비중만 바꾸어도 남는 최소 SSE / 기존 SSE |
|---|---:|---:|---:|
| 온도 BASE·CODEX·PFN, 전체 | BASE 2시드 × PFN 2문맥 | 63.61–63.99% | 62.57–63.58% |
| 온도 같은 세 구성원, 후기 F47 | 위와 같음 | 77.16–77.62% | 76.05–76.45% |
| EC 계절 R3·PFN 두 묶음, 전체 | 3시드 | 82.84–83.76% | 66.73–67.77% |

SSE는 오차제곱합이다. 비중이 음수가 아니고 합이 1이면 예측은 구성원 예측의 최솟값과 최댓값 사이에 놓인다. 정답을 그 구간으로 투영한 값이 가능한 최소 오차다. 정답을 사용하는 계산이므로 배포할 수 없으며, 남은 몫의 반대쪽도 실제로 달성 가능한 개선량을 뜻하지 않는다. RMSE 개선율과도 다르다.

대표 온도 BASE7/PFN1–8의 전체 RMSE는 .6585665044, 구간 투영 하한은 .5213319602. F47 후기 RMSE는 1.0344959246, 하한은 .9038188725다. 대표 EC seed7의 전체 RMSE는 .1811248371, 하한은 .1491097726이다. **EC의 R3는 여러 모델을 이미 섞은 묶음이다. 그 내부 모델까지 자유롭게 조절한 한계로 확대 해석하면 안 된다.** 온도와 EC는 표본·단위가 달라 RMSE를 서로 비교하지 않는다.

해석: 행별 비중 학습에는 여지가 있지만, 온도 F47 후기에서는 구성원들이 함께 틀리는 부분을 설명할 정보나 보정식의 중요성이 크다. 한계: 기존 분할과 저장된 예측에만 해당하며, 이것으로 공통 오차의 원인·보정 가능성·불가피한 잡음을 구별할 수 없다. 시드와 문맥은 독립된 새 데이터가 아니다. 근거 코드 `diagnose.py`, `verify.py`; 원본 경로와 해시는 JSON에 보존했다.

기존 날씨 구조 감사도 다시 확인했다. 400 온실·일은 122 날씨 연결 그룹으로 나뉘고, DIAG10의 검증일 291/400은 학습일과 날씨 그룹을 공유한다. `weather_groups.csv`의 행·그룹 수와 `audit.json`의 폴드 합을 독립 검산했다. **날씨 공유는 정답 누수의 증거가 아니다.** 이 구조는 보간과 새로운 상황 예측을 구별해야 한다는 단서다. 기존 GUARD는 추가로 학습일을 제거하므로, 점수 차이를 전부 의존성 효과로 돌릴 수도 없다.

## 1. 검증에서 정답이 비는 모양을 재현하기 — 공통 우선순위

[Roberts 등(2017), 구조 있는 데이터의 교차검증](https://florianhartig.github.io/publications/roberts2017cross/)은 의존성을 고려한 분할을 권하면서, 블록을 잘못 잡으면 원래 보간 문제를 외삽 문제로 바꾸는 부작용도 설명한다. 우리 데이터에서는 검증일과 학습일의 거리, 날씨 그룹 공유, 사용할 수 있는 과거 정답의 간격을 함께 기록해야 한다.

적용 제안: 현재 DIAG10·EXT10·EXT12·EL1은 그대로 유지한다. 추가 진단에서 동일 학습량으로 (a) 가까운 기록일의 정답이 남아 있는 경우, (b) 연속 여러 기록일의 정답이 비는 경우를 비교한다. 새 분할을 기존 실패 후보의 채택 기준을 완화하는 도구로 쓰지 않는다. 결과는 시간당 행보다 온실·일 또는 의존 그룹 단위로 요약한다.

특히 EC의 이전 정답 특징은 학습에서 2일 가까운 값이 자주 남고 검증에서는 더 멀리 떨어진 값만 남는다면, 상관이 높아도 적용 시 실패할 수 있다. 이것은 현재 확인된 원인이 아니라 검증할 가설이다. 각 외부 학습 집합 안에서만 결측 블록을 만들어 피처와 보정기를 학습한다. 외부 검증 정답은 상태 갱신·피처·계수 선택에 전혀 사용하지 않는다.

## 2. 원시 상관 대신 현재 모델의 잔차에 대한 추가 정보 확인 — EC 우선

기존 EC 직전 정답 PAR1과 다일 날씨 MW1은 실패했다(공용 카탈로그 C6.166·6.175). 원시 EC와 과거 값의 상관, 또는 사후 구간 상관만으로 새 피처를 넣는 근거가 부족하다. 평균적인 계절 변화는 기존 계절 지표가 설명하고 있을 수 있다.

먼저 확인할 양은 `현재 실제값 − 기존 모델 예측`과 과거에 관측 가능한 정보의 관계다. 학습 안에서 새로 만든 OOF 잔차를 사용해, 계절 위치·기록 구간·관측 간격을 통제한 뒤 과거 정보가 추가 설명력을 가지는지 본다. 외부 검증을 포함한 전역 OOF를 메타모델 학습에 재사용하면 외부 정답이 다른 모델의 학습을 통해 간접 유입될 수 있으므로 금지한다.

추가 정보가 여러 검증기에서 유지될 때만 저용량 상태 보정을 고려한다. 예: 계절 모델의 예측에, 과거 관측 잔차로 갱신한 작은 잠재 수준을 더하고 관측 간격이 길수록 보정 크기를 줄인다. [statsmodels 공식 상태공간 설명](https://www.statsmodels.org/stable/statespace.html)은 filtering과 smoothing을 구분한다. 여기서는 과거 관측만 이용하는 필터를 사용하고, 미래 정답을 이용하는 평활화는 사용하지 않는다. 쿼리의 정답은 없으므로 해당 시점의 정답으로 상태를 갱신하지 않는다. 파라미터도 외부 학습 안에서만 추정한다.

[Sigrist(2022), Gaussian Process Boosting](https://jmlr.org/papers/v23/20-322.html)은 비선형 평균 예측과 관측 간 의존성을 결합한다. 다만 우리 프로젝트는 이미 GPBoost의 독립 날짜 효과를 시도해 실패했다(카탈로그6.39). 모델 이름을 다시 적용하는 것이 새 단서가 아니다. 계절 보정 후에도 남는 잔차의 연결 구조가 있는지부터 확인해야 한다. 이 가설이 부정되면 상태 보정 실험을 중단한다.

## 3. 조건별 가중치의 학습 목표와 추정 오차 개선 — 온도 중심, EC도 가능

[Jacobs 등(1991), Adaptive Mixtures of Local Experts](https://www.cs.toronto.edu/~hinton/absps/jjnh91.pdf)는 입력에 따라 전문가를 선택하는 게이트의 근거다. 이 연구는 전문가도 함께 전문화하는 구조라서, 이미 고정된 모델의 비중만 바꾸는 우리 상황과 동일하지 않다.

[FFORMA, Montero-Manso 등(2020)](https://robjhyndman.com/papers/fforma.pdf)는 시계열 특징과 검증 손실을 이용해 모델 비중을 학습한다. 본문 식의 목표는 구성원별 손실의 가중합이다. **가중 예측을 합친 후의 제곱오차와 동일한 식은 아니다.** 따라서 그대로 복사하기보다 우리 평가 손실에 맞춰야 한다. 다수 시계열 대규모 실험이어서 우리의 적은 후기 날짜에서 같은 효과를 보장하지 않는다.

우리 G1은 BASE/CODEX의 상대 비중만 학습하고 PFN 비중은 고정했다. 내부 목표도 PFN을 제외한 두 모델 풀의 오차였으며 전 검증에서 악화했다. 다음 검토할 차이는 세 구성원의 **최종 혼합 예측 오차**를 목표로 삼고, 지역별 추정치를 전체 추정치 쪽으로 수축시키는 것이다. 이것은 기존 G1의 성공 주장이나 단순 재실행 제안이 아니다.

제안 식: 전문가 오차 벡터를 e, 예측 시 알 수 있는 조건을 z라고 하면 `M(z)=E[e eᵀ | z]`, 혼합의 조건부 MSE는 `wᵀ M(z) w`다. 중심화된 공분산만 쓰면 편향 항을 빠뜨리므로 오차의 2차 모멘트를 사용한다. 지역 M을 전역 M으로 수축하고 기존 비중에서 크게 벗어나는 것을 벌점으로 제한한다. 이는 위 문헌을 우리 제곱오차 문제에 적용한 **제안자의 추론**이며 FFORMA 원문 식이 아니다. [예측 결합 50년 리뷰](https://arxiv.org/abs/2205.04216)는 비중 추정의 불확실성과 단순 결합의 경쟁력을 검토한다.

모든 구성원과 메타 학습 자료는 각 외부 학습 안에서 재생성한다. 조건은 현재·과거 입력으로 한정하고 미래 하루 전체 요약은 제외한다. 후기 56일을 세밀한 분야로 나눌수록 과적합 위험이 커지므로 저용량 모델과 수축이 필요하다. 앞의 구간 투영 결과상, 공통 편향이 큰 온도 F47 후기는 비중만 조절하는 실험의 우선순위를 낮춰야 한다.

## 4. 계절 위치·분포 변화와 날짜 암기를 구별하기

[Sugiyama 등(2007), Importance Weighted Cross Validation](https://jmlr.csail.mit.edu/beta/papers/v8/sugiyama07a.html)은 입력 분포가 바뀌고 `P(y|x)`는 유지되는 경우를 다룬다. 우리 EC 계절 개선은 날짜 표현을 바꾸는 중요성을 보여주지만, 이것만으로 실제 달력을 정확하게 복원했다거나 조건부 관계가 불변이라고 결론낼 수 없다.

적용 제안: 기존 학습 데이터 내부의 전·후기 차이를 진단용 대리 분포로 삼아, 날짜·계절·현재 환경 특징 중 무엇이 구간을 식별하는지 확인한다. 중요도 가중 실험은 외부 학습 내에서만 분류기와 변환을 적합하고 극단 가중치를 제한하며 유효 표본 수 `(Σw)²/Σw²`를 보고한다. 실제 평가 전체 입력을 분포 학습에 끌어오는 방식은 현재·과거 입력 규칙과 충돌할 수 있어 제안하지 않는다. 조건부 관계 자체가 달라지면 입력 가중만으로 해결되지 않는다.

[Anchor Regression](https://arxiv.org/abs/1801.06229)은 환경 변화에 대한 강건성을 목표로 한다. 온실·기록 구간과 연결되는 잔차 성분을 제한하는 보정식은 탐색 후보지만, 그 식별자들이 자동으로 유효한 인과 도구가 되지는 않는다. [Group DRO](https://arxiv.org/abs/1911.08731)는 최악 그룹 최적화에서 강한 정규화가 필요함을 보여준다. 기존 하루 수준 손실 가중·농장별 기울기도 실패했으므로, 이름을 바꾼 같은 손실 재실행은 우선하지 않는다. 회귀·소표본 데이터로의 적용은 별도 검증이 필요하다.

## 5. 값과 함께 관측의 신뢰도를 표현하기 — 낮은 우선순위

[Che 등(2018), GRU-D](https://www.nature.com/articles/s41598-018-24271-9)는 결측 표시와 관측 후 경과 시간을 모델에 제공한다. 의료 분류 연구이며 온도·EC RMSE 개선의 직접 증거는 아니다. 가져올 단서는 대형 RNN보다, 같은 현재 값이어도 최근 유효 관측 수·경과 시간·결측 패턴이 다른 상황을 구별하는 것이다.

기존 reset 계열 피처와 중복되지 않는 정보인지 먼저 감사한다. 학습 MASK를 적용한 뒤 실제로 보이는 과거 관측만으로 유효 개수와 간격을 계산하고, 전체 하루를 보고 신뢰도를 계산하지 않는다. 인접 행이 많다는 사실은 독립 표본이 많다는 뜻도 아니다. 기존 피처가 이미 같은 정보를 담고 있으면 이 실험은 제외한다.

## 국내 연구의 활용과 제한

김영덕·박정희(2017), 「컨셉 변동 스트리밍 데이터를 위한 적응적 가중치 조정을 이용한 동적 앙상블 방법」, 정보과학회논문지44(8),842–853의 서지는 [저자 연구실 목록](https://dmml.cnu.ac.kr/publications.html)에서 확인했다. 검색에 노출된 초록·본문 일부와 [학회 PDF](https://jok.kiise.or.kr/digital-library/manuscript/file/99990/NODE07226482.pdf)를 조사했으나 전체 원문 접근은 확인하지 못했다. 세부 실험 설정과 우리 회귀 문제 적합성은 미확인이다.

국내에도 변동에 맞춰 앙상블 비중을 조절하는 연구가 있다는 참고 자료다. 온라인 갱신은 새 정답이 제공되는지에 따라 구현 가능성이 달라진다. 우리 평가 정답으로 성능을 계산해 비중을 갱신하는 방식은 적용할 수 없다. 학습·내부 검증에서만 학습하고 평가에는 고정한 규칙을 사용한다.

## 실행 순서와 판정 경계

1. 공개 학습·검증 안에서 관측 간격/결측 블록 차이와 조건부 잔차의 추가 정보부터 검사한다. EC 직전 값·다일 이력의 실패와 모순되는지 먼저 검토한다.
2. 추가 정보가 있으면 저용량 잔차 보정을 한 가지씩 실험한다. 온도에서는 F47 후기의 공통 수준 오차가 보정 가능한지, EC에서는 계절 보정 후 잔차의 과거 정보가 유효한지 별도로 판정한다.
3. 조건별 비중은 내부 OOF 비용을 감수할 때 세 구성원 전체 손실·수축을 한 안으로 사전 고정한다. 이번 하한 진단은 성능 예측이나 채택 기준이 아니다.
4. 이후 분포 가중·강건 보정·관측 신뢰도는 정보 중복과 표본 수를 먼저 확인한다. 모든 시드×기존 검증기 같은 방향 및 사전 고정 본페로니 기준을 만족해야 채택한다.

[Cawley·Talbot(2010)](https://www.jmlr.org/beta/papers/v11/cawley10a.html)은 모델 선택 기준 자체에 과적합할 수 있음을 설명한다. 본페로니는 반복된 탐색과 검증 재사용의 모든 편향을 제거하지 않는다. 사후 진단을 예측 성능 입증으로 취급하지 않고, 새 가설·기준을 실행 전에 기록한다.

현재 확정한 것은 문헌 단서와 기존 예측의 수학적 한계다. 새 후보 채택·성능 향상·제출 준비는 하지 않았다. 논문 방법이 효과가 있었다는 사실은 우리 데이터에서의 성공 증거가 아니며, 기존 실패는 해당 구체 구현의 실패로 한정한다.
