# 온도 분리 날과 EC — 탐색 검토

클로드 요청서를 사용자가 검토하도록 지정한 뒤 수행하는 기술 집계다. 온도 모델은 만들지 않는다.

질문: (1) over/under/normal/other의 EC 평균·일내 범위·달력상 d−1 변화 차이, (2) 같은 날 EC v2 OOF 잔차 부호 차이, (3) 기존 6시 수분 축적·팬·난방 신호 차이.

최종잠금 40일은 온도 표·EC 정답 모두 수치 변환 전에 제외한다. 원래 400일 집단의 표본 수는 문자열 group만으로 세며 집계에 쓰지 않는다. 기존 360일 프로파일 CSV의 EC 평균/범위를 독립 csv 산술로 교차 확인한다. EC 잔차는 현재 저장된 DIAG10 체크포인트만 사용하고 부분 표본임을 명시한다. 완성된 10폴드 결과는 별도 새 버전으로 낸다.

잔차 정의는 EC/온도 모두 예측−정답. 날짜·온실 교란은 farm×late 층화 표와 farm/late/day 통제 회귀의 over−under 차이를 함께 기록한다. 추론 검정·모델 선택 없음. 원자료 재사용이며 잠금제외·미완성 OOF·작은 그룹·온도 오차를 기준으로 한 사후 선택 때문에 공통 관수 원인을 확정하지 않는다. 같은 출처의 전날 연결은 인증된 연결이 없어 이번에 계산하지 않는다. 달력상 d−1을 같은 출처 전날이라고 부르지 않는다.

train_y 평가 특징 허용은 공용 메모리의 사용자 결정도 확인했다. 현재 사전 고정된 기준선 실험의 피처를 바꾸지 않으며, 이후 별도 과거 라벨 실험에서 검증 행/잠금/미래 정답을 배제한다.
