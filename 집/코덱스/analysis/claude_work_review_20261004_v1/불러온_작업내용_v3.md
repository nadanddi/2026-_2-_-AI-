## 불러온 내용

**온도:** TC1/TC2 계절 지표, 문헌 단서, W40G-S 독립 검증, 공개 이레아이에스 배지온도의 이전 시험이 기록되어 있다. 채택한 새 온도 후보는 없다. W40G-S는 개선 방향이 일치했지만 통계 기준을 넘지 못했고, 외부 온도 모델의 고정 혼합은 악화했다는 원본 로그를 확인했다. 이 두 온도 실험은 이번 요청에서 독립 재학습·재채점하지 않았다.

**외부 자료:** 이레아이에스·골든플래닛의 EC/온도 이전(X0~X2), 관수·배액·무게·지습 대리변수(X3), 온도차와 관수(X4), 관수 이력(X5)을 조사했다. 클로드가 시험한 구성에서 개선 후보는 확인되지 않았다. 이레 EC는 **배액EC**이므로 대회 **배지EC**와 같은 정답으로 취급하지 않는다. 외부 자료 전체가 무용하다는 판정으로 확대하지 않는다.

**EC 오차 구조:** HC0~HC6, 초기 시간 흔적 MN3, 트리 예측 산포 PR1, 검증기 관계 VA1을 조사했다. 같은 동 이전 EC 보정 HG1, 고EC 전용 HM1, 밀폐일 전용 HM2, 외기 유사도를 통한 계절 수정 DC7, 예측 배지온도 특징 TF1을 시험했다.

## 의문과 해석 경계

- 숫자 재계산 일치는 학습 적법성·누수 없음의 전면 인증이 아니다. HG1의 다른 OOF 폴드 잔차 회귀에는 외부 fold 내부 완전중첩이 아닌 한계가 있다.
- X2는 외부 농가의 연속 이력과 대회 검증 하루 이력의 정의가 다르며 검증 배치 중앙값 결측 대체도 있다. 엄밀한 이전 검증에는 이를 보완해야 한다. 기존 실패 원인이 이것이었다고 입증하지 않았다.
- DC7의 '외기 쌍둥이'는 실제 코드상 표준화 거리≤.05를 포함한다. 완전 동일 외기만 사용하는 것으로 읽지 않는다.
- PR1의 트리 간 산포는 보정된 예측분포와 같지 않다. 상관·후보 실패만으로 입력 정보 부재나 관수·관리의 인과를 단정하지 않는다.
- 같은 공개 검증 자료에 반복 탐색한 결과다. 새 독립 홀드아웃 증거가 아니며 이번 검토로 새 모델을 채택하지 않는다. 검산한 기각 유지의 신뢰도는 높고, 일반적인 정보 한계·원인 추정의 신뢰도는 제한적이다.
- EC 판정 규칙 변경 기록6.247은 불러왔으나 직접 제공된 AGENTS 및 메모리와 일치하지 않는 부분을 유지해서 알린다. 이번에는 규칙을 수정하거나 결과를 소급 채택하지 않았다.

## EC 작업에 반영할 것

1. 고EC 여부 판별과 고EC 크기 추정을 구분하고, 진짜 고EC 이득과 오탐 손해를 함께 확인한다.
2. 실제 제출 계절v2를 기준선으로 두고, 혼합 비중은 공개 검증 정답 대신 외부 학습 fold 안 내부 예측에서 정한다. 공개 OOF 최적 혼합비를 고르지 않는다.
3. 로그 복원 계산과 완전중첩 내부 보정은 별도 사전 실험으로 다룬다. 같은 이름의 기각 안을 그대로 반복하지 않는다.
4. 클로드 최신 TF1은 완료됐으므로 진행 중으로 다시 기록하거나 중복 실행하지 않는다. 온도 후보 유지, 실제 제출 W40G·EC 계절v2 유지.

별도 진행 EC 작업의 로그도 인계용으로 확인했다. LOG_PARTITION_ORIGINAL은 **ALL_FITS_COMPLETE**, 전체 점수 검산은 아직 안 했다. CPU matched calibration은 B3 완료/B4 PFN1까지이며 전체 완료 전 판정하지 않는다. 이 상태는 클로드 작업과 구분한다. 기존 지속 EC 목표는 active이며 새 제출물 생성은 없다.
