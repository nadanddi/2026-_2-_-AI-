# 클로드 작업 갱신과 후속 검토 · 2026-10-04 · 집 코덱스

v1을 보존한 추가 기록이다. 집 클로드 작업일지 10-03 세션1~4, 이후 코드·로그·카탈로그를 Git **4ab2a52**까지 확인했다. 클로드의 10-04 작업일지는 아직 없어 git 기록으로 보완했다. 연구실 클로드/코덱스에는 10-01 이후 새 작업일지가 없다. 카탈로그6.254 번호 충돌은6.255에 정정됐으며 클로드 TF1은 **C6.254**로 구분한다.

## 이번에 갱신한 결과

**TF1 예측 배지온도 특징은 완료됐고 기각이다.** 각 외부 학습 fold 안에서 배지온도 모델을 만든 뒤, 학습행에는 내부5분할 교차예측, 검증행에는 외부학습 전체 적합의 예측을 제공한다. tpred와 실내온도 대비 차이를 EC R3 구성원에 넣는 시험이다. 온도 정답을 검증 EC 특징으로 직접 사용하는 시험은 아니다.

기준선은 클로드 **R3S**이며 실제 제출 EC 계절v2(.8R3+.2PFN)의 점수로 바꿔 설명하지 않는다. DIAG10 360일/8,640행의 farm×5기록일 클러스터 부트스트랩20,000회 P(worse)=.4652/.7452/.18395. 공개15점수를 NumPy와 math.fsum으로 독립 재계산했고 로그와 일치했다. 신뢰도: 해당 구현의 기각은 높음. 한계: 같은 공개 날짜를 반복 활용했으며 배지온도 이전 접근 전체의 불가능성을 증명하지 않는다.

클로드의 EL1·후반·고EC 수치는 로그에서 읽었으며 이번 검산에서 EL1을 다시 채점하지 않았다. 특히 “배지온도 정답이 EC 크기에 추가 정보를 주지 않는다”는 문장은 **이 예측온도 특징과 R3 구성에서 전체 개선을 확인하지 못했다**로 한정한다. 센서 온도 자체의 조건부 정보나 다른 다중과제 학습을 배제한 결과가 아니다.

## 이미 확인한 내용에서 이어갈 단서

- 고EC의 크기 과소가 핵심이다. v1에서 검산한 고EC31/360일의 공통 과소와 날짜별 차이 모두 남아 있다. HG1/HM1/HM2/DC7 네 후보는 공개60점수 독립 검산 후 기각 유지.
- HM1은 진짜 고EC 표지644행을 개선하고 오탐284행을 크게 악화시켰다. 고정50% 혼합이 실패했다고 전용모델의 모든 활용을 포기할 근거는 부족하다.
- 비평가가 혼합량0에서의 손실 미분을 재계산했다. R3S에서는 DIAG/A/B9칸 모두 작은 혼합이 유리한 방향이지만 **실제 계절v2에서는6/9칸만 유리**하다. 상위 에이전트도 별도 math.fsum으로 다시 확인했다. 공개 정답을 이용한 사후 방향 진단이며 작은 최적 비중을 새 후보로 선택한 결과가 아니다.
- HG1의 OOF 메타 회귀 독립성, X2의 검증 배치 결측 대체·하루 이력 재설정, LR1의 로그 역변환과 원단위 손실 차이는 수리해서 재시험할 여지가 있다. 기존 실패의 원인이 그 문제였다고 입증한 것은 아니다.
- PR1 트리 간 산포는 보정된 예측분포와 같지 않다. q10~q90의 약75% 포함률 하나로 불확실성의 정확성을 확정할 수 없다. 상관·전용모델 실패만으로 입력 정보 부재를 단정하지 않는다.

## 내 작업에 반영한 것

1. 실제 EC 계절v2를 기준선으로 유지한다. 공개 OOF의 오라클 혼합비는 선택하지 않는다. 내부 예측까지 같은 레시피로 만드는 CPU 작업은 기존 프로세스 종료를 확인한 뒤 **동일 소스·기존 캐시로 재개**했다(현재 tool68739, 원tool60252는 존재하지 않음).
2. 선형 추세를 먼저 적합하고 ET가 잔차를 배우는 RERF 단일안은 전체66학습 완료 후 기각했다. 고EC 손실 일부를 줄여도 일반 날짜 손해가 더 컸다. 별도 결과 보고서 참조.
3. LR1의 분할을 사용하되 로그 기하평균 대신 학습 leaf의 ratio 산술평균을 복원하는 LOG_PARTITION_MEAN을 새 사전 실험으로 실행했다. 아직 전체 성능 미판정이다. ratio 평균은 ratio SSE 최적이며 leaf 안 계절 기준값 b가 다르면 원 EC SSE의 정확한 최적은 b² 가중평균이다. 현재 시험에 가중식을 몰래 추가하지 않는다.
