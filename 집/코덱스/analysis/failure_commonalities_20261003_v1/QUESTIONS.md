# 실패 사례 공통점 전수 탐색 — 실행 전 고정

사용자 요청: 온도 실내·배지 관계 차이, EC 고값 과소예측으로 점수를 나쁘게 한 사례의 데이터 공통점을 넓게 조사한다. 기존 문제 정의·공개 DIAG10 OOF 기준선을 유지한다. 새 모델·제출·잠금 데이터 접근 없음.

주분석 온도: 실내24시간 완전관측, |배지−실내 일평균|≥2℃, 일RMSE>.5℃. EC: 배지일평균≥1, 일RMSE>.1dS/m. EC 핵심 하위군 평균편향≤−.2, 온도 하위군 gap×bias<0이고 |bias|≥.5를 별도 보존한다. 경계 민감도는 온도 RMSE>.75/>1, EC>.15/>.2. 정답을 사용하는 사후 분류이며 배포 가능한 실패 판별기 아니다.

3. 실내/외기, 온습도/CO2, 환기/차광/보온/난방과 환경 사이 관계·응답시차·이력 변화를 공유하는가?
4. 실패 특징이 일반 사례에도 흔한가? 동일 온실×전후반 층화 및 문제발생 성공사례 비교에서 남는가?

모든 유한 원입력에 미리 고정한 요약을 계산한다. 후보 조건은 0/결측/급변 같은 고정 물리측정 규칙과, 각 대상 전체일의 입력만으로 정한 q25/q50/q75 이상·이하. 컷은 설명용이며 학습·평가 분할을 대체하지 않는다. 전부 출력하고 실패≥50% 조건을 별도 모아 다수(≥75%)와 구분한다. 일반 사례가 같은 온실×전후반 구성일 때의 빈도와 차이를 계산한다.
