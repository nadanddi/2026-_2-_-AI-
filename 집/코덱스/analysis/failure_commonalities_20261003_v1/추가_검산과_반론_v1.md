# 추가 검산과 해석의 한계

최종 보고서 생성 뒤에도 원자료 CSV 사전과 math.fsum, 독립 Pearson 계산으로 명시 조건22개 중 정답파생/동일날씨 조건을 제외한 모든 원입력 조건의 집합별 빈도·관측가능분모를 다시 확인했다. `audit_rules.py` / `raw_rule_audit.json` 340개 검사 PASS. 본문과 목록의 주요 빈도는 그대로다.

온도 실패16일 중 따뜻한배지3일만의 제곱오차는 전체온도 제곱오차의17.6712%, 실패16일 제곱오차의53.2410%다. 최종검산760일의 sse를 math.fsum으로 분자·분모 합산하면 같다. 사례 수로는 차가운배지13일이 많지만, 오차 크기로는 따뜻한3일의 비중이 훨씬 크다. 두 방향을 섞은 공통점을 해석할 때 이 차이를 고려해야 한다.

- 공통점이 원인인가? 아니다. 어떤 사례를 골랐는지에 따라 공통점이 생긴다. 고EC 조건이어서 겨울 운영처럼 보이는 입력들이 많이 나오고, 실내보다차가운배지를 골라 큰실내낮밤차가 많이 나올 수 있다.
- 온도 일사/CO2 조합12/16 대 성공0/4는 확실한가? 이 집합에서의 빈도는 확인했지만, 독립날짜가 적고 조합탐색 후 선택이라 외부 검증이 필요하다. 날짜통제 단일조건에서도 온도 BH신호0개다.
- 학습지원부족이 모든 실패인가? 아니다. 온도 성공2/4도 최근접5일에 같은방향 큰gap이 없다. EC핵심17일 중10일은 근처에고EC가있다. 따라서 모델 관계학습·희귀값평균화·미측정상태가 모두 가능한 설명이고 단일원인을 확정하지 않았다.
- EC의 저환기/차광/보온이 실패를 가르는가? 성공2일에도 공통된다. 현상/상태 배경을 요약할 뿐 실패 충분조건이 아니다.
- 모든 입력 관계를 조사했나? 제공된19열의400개 고정 요약·관계·이력,3328단일 조건과612개의 입력조건 쌍(온도/EC × 주실패/핵심집합 포함)을 조사했다. 임의의 모든 비선형·고차 관계까지 조사했다는 뜻은 아니다.
- 모델 성능이 좋아졌나? 새학습·채택·제출은0이며 이번 작업은 반복적인 실패 구조와 다음 가설의 자료를 남긴 것이다.
