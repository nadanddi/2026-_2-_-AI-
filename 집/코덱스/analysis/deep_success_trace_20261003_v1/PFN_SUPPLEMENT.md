# PFN 보강 범위 — CPU 결과 이후 고정한 설명 실험

CPU만으로 전체 모델의 영향 순위를 단정하지 않기 위해 원 PFN도 확인한다. 온도 성공4일+F47/191, EC성공2일. 원8개/4개문맥 전체 사용, 원검증학습ID 및 캐시contextID 그대로. 각 입력 그룹에 CPU 실험의 제1근접 donor1개 사용. CPU5donor보다 민감도 범위가 좁다는 한계가 있다.

온도는 기존 CUDA float32 원8문맥, EC는 원CPU float32 캐시와 새CUDA float32의 원본24행 차이≤1e−5를 요구한다. 이때 허용되는 작은 연산차이를 공개하고, PFN 영향은 캐시 원예측에 대체에 따른 출력차를 가산해 원최종혼합 기준으로 계산한다. 허용초과 시 PFN 영향 판정에서 제외한다. 학습시드/문맥을 새로 선택하지 않는다. 각 그룹 같은시각 전파는 기존CPU 합성피처 민감도와 동일하며 물리 인과 아님.

새 후보·성능향상 판정 없음. source hidden lock/EC rawlabels/test prediction 접근 없음. CPU+PFN 전체 영향을 결합할 때 동일donor 제1개로만 결합한다. 다른donor/조건 간 영향 숫자를 합산하지 않는다.
