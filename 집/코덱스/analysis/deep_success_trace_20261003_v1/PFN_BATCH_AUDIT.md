# PFN 배치 수치차와 보강 프로토콜

원 전체 검증 행으로 원 PFN을 재현하면 최대 차0이다. 같은 모델을24행만 예측하면 최대 .00026703℃ 차가 난다. 입력 피처 차는0이고 문맥ID도 같다. 첫문맥에서 모든그룹을 원전체배치와 축소배치로 각각 계산한 실측은 예측 최대차 .00013161℃, **대체에 따른 변화량 차 .00011826℃**다.

초기축소배치 원예측 차≤1e−5조건은 불합격으로 기록하고 v1 결과는 제외한다. 전체배치 v2는 정확하지만 전체검증960행×각그룹×40문맥 반복으로 목적에 비해 큰 반복계산이 생긴다. 보강 v3는 축소배치의 설명값을 **근사 민감도**로 별도 표시한다. 채택·성능검정 기준을 바꾸는 것이 아니다.

v3: 원문맥/원피처 동일성을 유지하고 원예측 캐시와 축소배치 차≤.001을 요구한다. 캐시 원출력에 같은배치에서 구한 대체−원출력 차를 가산한다. 원모델 전체배치 정확재현은 위독립probe PASS. PFN 설명 숫자는 소수3자리 이하까지만 해석하며 .001보다 작은 영향이나 비슷한 순위는 확정하지 않는다. 모든 문맥의 원출력 차와 첫전체배치-축소배치 변화량 차를 보고한다. 이실측오차는 모든미실행전체배치의 엄밀한상계는 아니다.

원엄격조건 불합격, 배치차의 원인 검산, 정확v2와 근사v3를 명확히 구분한다. 핵심실패 구조와 CPU 민감도는 별도정확재현/독립검산 완료. 최종 전체영향은 PFN 보강이 근사임을 명시한다.
