# 실패 원인·성공 영향 심층 추적 사전 범위

목적: F47/191 실패의 자료/입력/학습/계산 경로를 좁힌 다음, 온도 성공4일과 EC 성공2일의 공통 관계 및 실제 모델 민감도를 조사한다. 독립적인 새 성능평가나 후보 채택이 아니다.

1. 정답·입력·예측의 시간 정렬, 결측, 고착, 하루 경계가 실패를 설명하는가? ±6시간 정답 사용 정렬은 사후 진단만.
2. 실제 MASK 피처 공간에서 각 사례의 학습 지지와 따뜻한 배지 사례의 존재/가중치는 어떠한가?
3. 원 CPU 구성원을 정확히 재현해 어느 계산 단계에서 평균/모양 오차가 만들어지는지 확인한다.
4. F47/178 따뜻한 학습일 제거, 훈련 가중치 제거를 각각 적용하면 F47/191 및 F13/194 출력은 어떻게 움직이는가? 단일fold 원인 민감도이며 채택시험 아님.
5. 온도4성공·EC2성공과 기존 같은층 실패사례의 입력·파생관계·정답곡선·예측곡선 중 무엇이 겹치는가? 기존 전체20/31현상 사례도 대조한다.
6. 그룹 입력 대체 시 성공 사례의 예측/오차에 가장 큰 영향을 주는 묶음은 무엇인가? 같은온실·같은전후반 실제학습일 중, 대체하지 않는 피처의 표준화 평균거리 가까운5일을 고른다. donors는 정답으로 고르지 않는다. donor의 같은시각 그룹값을 넣는다. 상관·범위 이탈·파생피처 비일관성 한계 명시.
7. 두 시드, donor5일의 범위, 성공기준 완화, 반례 및 모델 구성원 간 차이에서 영향 순위가 유지되는가?

고정: 온도 DIAG10 seed7/101·PFN1–8 원출력; EC DIAG10 seed7/101, PUBLIC360일만. EC raw train_y/잠금/예약 정답 접근 금지. 원 분할/훈련가중치/원모델 재현 후 CPU부분만 대체실험; PFN은 고정한다. 따라서 PFN 자체 내부 중요도라는 주장 금지. 실제원자료 전체 입력 교환 효과와 혼동 금지. 모델합성입력 민감도는 물리 인과를 입증하지 않는다.

온도8묶음: 실내온도 / 외기온도 / 습도·CO2 / 일사·풍속 / 난방 / 나머지구동기 / 시간·온실·구간 / 나머지파생상호관계. EC12묶음: 실내온도/습도/CO2/7구동기 각각/계절/시간. 컬럼명 고정규칙으로 나눈다. 시계열 파생은 같은 그룹 안에서 함께 교환한다.

검산: 원OOF CPU 재현 최대차≤1e−7, 원최종혼합≤1e−7; fsum 독립 주요 통계; 대체비그룹값 불변·donor원피처 일치·학습ID/평가ID분리; 최초fit 독립재실행. 유의성 검정 추가0, 선택사례 사후 분석임을 유지.
