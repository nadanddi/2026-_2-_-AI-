# 후반 기준 표시 단서의 추가 통제

같은 전후반 donor 실험은 `second`가 고정되어 있어 전후반 표시 자체의 영향을 판별하지 못한다. F47/178의 따뜻한 학습일이 전반에만 있었으므로 원인 진단을 보강한다.

원 CPU fold5 두 시드에서 `day`와 `second` 두 피처만 학습·추론에서 제거한다. 시간·온실·다른 상태 피처는 유지한다. 전체 검증 fold 및 F13/194·F47/191 모두 보고한다. 새 채택안이 아니다. 따뜻한 학습178일을 원 모델이 훈련 시 얼마나 맞추는지도 확인한다. 표시 제거 효과가 작아도 다른 날짜 지문 모두의 영향 부재라는 뜻은 아니다. 이전 메모의 제목 오타만 정정한 새 버전이다.
