# EC 기초 재점검 계획 v1 — 2026-10-07 집 코덱스

사용자 지정 기준선은 계절 v2 + DP1 + TabPFN 0.4 + SG2이다. 제출14의 0.2 구성과 구분한다.
14개 원입력, row_id, 동일 온실의 입력 이력, 공개 EC·온도 정답과 전체 공개 학습 자료의 보조학습 가능성을 포함한다. 외부 수치 자료는 제외한다.

① 사용자 도메인 자료·일반 지식 24후보, ② 논문·인터넷 24후보, ③ 데이터 기반 탐색은 배치당 256후보 상한이다. 앞 단계 완료·독립 비평 전에 다음 단계 실행을 열지 않는다.
기존 기각 후보는 카탈로그 번호와 이전과 다른 점을 기록한 것만 시험한다. 차이가 없는 중복은 실행하지 않는다.
동일 기록일 1/2/3/4/6시간 지연·창, 1차/2차 차분, 전환, 연속 시간, 전환 후 경과시간을 우선 구현한다. 12/24시간은 보완이다.
하루 안 모양은 0~h시까지만 이용한다. 전날 비교는 연결 신뢰도·판단 보류·가용률을 별도 감사하며, row_id 연속을 물리적 연속으로 가정하지 않는다.

TM111·P2LOO·EL1과 탐색 시드 47/1414/6464를 고정한다. 상수·원입력 CPU 모델은 기초 대조이며 지정 기준선을 대신하지 않는다.
저장 sg4 OOF는 산술 참조이다. 정확한 기준선 CPU 재현과 전체 처리의 미래 입력·다른 온실·순서·단일 질의 불변성 감사가 정식 개선 비교의 선행 조건이다.
기준선 재현 또는 인과성 문제를 해결하기 전에는 후보 구현·자료 진단만 수행하고 개선을 주장하지 않는다.
외부·내부 검증 행의 EC와 온도 정답을 학습·참조·문맥에서 함께 숨긴다. 학습 특징은 평가 결측 MASK를 적용한다.
TM은 과거 전체일 평가 입력 유사성으로 선정된 집합이다. 사용자 지정 고정 진단으로 사용하며 test 통계를 특징 fit·계수 조정에 전달하지 않는다. 반복 사용의 선택 편향을 명시한다.
최종 판정은 전체 이력을 대조해 처음 쓰는 시드·폴드 배치를 봉인한 뒤 한 번만 한다. 모든 시드×세 검증기 개선, TM 시드평균 온실×5기록일 블록 bootstrap P(worse)<.025/k를 요구한다.
선별·재시험한 모든 variant를 다중비교 장부에 기록한다. k는 단 한 번의 확인에 들어가는 전체 후보 수이다. 탐색 결과를 확정 판정으로 쓰지 않는다.
순위는 기준선에 대한 재학습 추가/제거 ΔRMSE, 시드·검증기 안정성, 일반/고EC일, 시각/온실/구간별 효과와 블록 CI로 정한다.
원열 14개의 비공집합 16383개는 유한한 원열 공간이다. 파생 변환은 무한하므로 후보 문법을 배치별 확장하고 전체 등록·실행·보류 수를 공개한다.
독립 비평의 지적 ID→수정→재검사 근거를 연결한다. 체크포인트는 원본·코드·환경·학습/참조/문맥/검증 ID·후처리·시드 해시 일치와 저장 예측 재채점 후 원자적으로 완료한다.
RUNNING은 PID·시작시각·명령/도구 핸들로 확인한다. 파일 존재만으로 재사용하거나 재시작하지 않는다.
