# 추가 안내를 활용한 고EC 구별 모델 실험

2026-10-05 집 코덱스. 새 구별 모델을 실제로 만들었지만 이번 설계는 기존 방식보다 나빠 채택하지 않는다. 이는 모든 구별 모델이나 추가 정보의 가치가 없다는 증명이 아니다.

현재 확인된 추가 안내는 뒤 날짜를 포함한 공개 학습 정답의 참조 허용이다(사용자 메모리/카탈로그6.309). 운영위 PDF 원문은 확보하지 못했다. Downloads의 현장 지식 조사 문서는 운영위 자료로 확인되지 않았으며 과학적 주장을 검증된 사실로 사용하지 않았다. 새 측정 변수가 추가됐다고 가정하지 않았다.

고EC는 정답 하루 평균≥1. 비교는 같은 로지스틱 분류기22특징에서 공개 참조를 이전 날짜만(PAST) 쓰는지 전체 학습 날짜(ALL)를 쓰는지만 바꿨다. 평가 입력은 현재 시각까지의 같은 온실만; 참조는 해당 검증 날짜를 제외한 공개 학습 기록만 사용했다. 목표는 기존 B승리 분류나 잔차 회귀와 달리 고EC 여부 자체다.
