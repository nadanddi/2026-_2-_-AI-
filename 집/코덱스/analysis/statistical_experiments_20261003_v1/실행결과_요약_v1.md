# 통계 단서 1–4 실행 결과

2026-10-03, 집 코덱스. **다섯 구현 모두 사전 채택 기준을 충족하지 못했다. 온도 W30G와 EC 계절 v2를 유지한다.** 이번 고정 검증에서의 판정에는 높은 신뢰도를 부여하지만, 각 방법의 모든 변형이 불가능하다는 뜻은 아니다.

RMSE 변화율은 기존 모델 대비이며, 음수면 개선이다. 범위는 온도 2시드×2PFN문맥, EC 3시드의 결과다.

| 요청 | 적용한 변경 | DIAG10 | 개선이 유지되지 않은 검증 |
|---|---|---:|---|
| 1. 온도 공통편향 | 전체 혼합의 내부 잔차를 현재·과거 조건으로 보정 | +0.59~+0.67% | EXT12 +2.23~+2.62% |
| 1. 보완안 | 온실×전후반 교차항 추가 | +0.41~+0.47% | EXT12 +2.23~+2.62% |
| 2. EC 과거 상태 | 과거 관측 평균−현재 예측, 과거 변화율, 관측 간격 감쇠 | −0.86~−0.84% | B +0.82~+0.85% |
| 2. 보완안 | 과거 관측 출처를 같은 날짜 홀짝으로 제한 | −0.45~−0.45% | B +0.60~+0.67% |
| 3. 문제별 가중치 | BASE·CODEX·PFN 전체 혼합 오차를 학습해 행별 비중 변경 | −0.80~−0.71% | EXT10 +0.03~+0.22%, EXT12 +0.15~+0.22% |

1번 두 안은 EXT10에서는 약 1.07~1.21% 개선됐으나 DIAG10·EXT12에서 악화됐다. 3번은 사용자가 제안한 세 모델의 문제별 비중 변경을 실제 적용했지만, 이번 조건 특징과 고정 수축·제약으로는 다른 검증 구간까지 개선이 유지되지 않았다.

4번은 외부 학습 안에 5개 기록일 묶음의 내부 검증과 ±1일 제외 구간을 만들고, 그 안에서 원 전문가부터 새로 학습했다. 평가 행의 값이나 정답은 사용하지 않고 날짜 구조만 확인했다. 평가 60일·1,440행에서 EC의 실제 기준 학습 306일을 관측 출처로 삼으면 직전 관측 간격 중앙값은 5.5일, 90백분위는 10일이다. 공개 관측 360일 전체를 출처로 삼을 때의 중앙값 5일과 구별했다.

미리 정한 EC 관측 5일 추가 지연 점검에서는 일반 상태 보정의 DIAG10 변화가 **−0.013~+0.010%**로 줄었고, A에서는 **+0.116~+0.140%**로 악화됐다. 같은 홀짝 보정은 DIAG10에서 −0.292~−0.277%를 유지했지만 B에서는 +0.424~+0.447% 악화됐다. 과거 관측의 최신성이 보정 효과에 영향을 준다는 단서다. 이 점검은 전문가를 고정한 보정기만의 진단이며, 전체 모델을 재학습한 새로운 독립 검증 결과는 아니다. 계산은 `stress_audit.py`의 numpy 평균과 독립 math.fsum으로 교차 확인했다.

EC에서는 현재 예측·계절·온실·구간·시각을 통제한 추가 내부 검증 132조건 중 54조건에서 과거 정보 추가가 개선됐다. 서로 겹치는 표본이며 정규화 변화도 영향을 줄 수 있다. 따라서 과거 정보가 안정적인 추가 예측 정보를 제공한다는 근거는 부족하며, 정보가 전혀 없다는 결론도 내리지 않는다.

전체 66점수 조건, 내부/외부 분리 34분할, 회귀 계수 276개, DIAG 블록 bootstrap 18조건을 검산했다. 첫 CPU 전문가의 완전 재학습 차는 온도 0, EC 4.44e−16이고, 첫 PFN 문맥의 재학습 차는 0이다. 채택 기준은 실행 전 고정한 전체 시드×검증기 개선 방향과 DIAG `p_worse < 0.025/32` 및 신뢰구간 상한 <0이었다.

내부 적합 오차 감소를 외부 성능 개선으로 취급하지 않았다. 반복 CV, 내부/외부 전문가 학습량 차이, 기존 입력 rank 가중치, 시드의 실질 중복 등의 한계는 남는다. EC 잠금 재열람·재채점, 제출 파일 생성은 없었다. 기존 TK2 계절 PFN 실험은 원 설정으로 별도 재개됐으며 아직 진행 중이다.
