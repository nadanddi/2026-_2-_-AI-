# EC 잔차 추가정보 진단 — 새 후보 점수 확인 전 고정

과거EC−현재예측과 잔차y−현재예측은 공통 빼기 항이 있으므로 단순 상관은 추가정보의 증거가 아니다. 내부 meta holdout을 다시 5일 묶음 교대2분할한다. 현재예측·계절·온실·기록구간·시각의 Ridge100 잔차보정 대조와 같은 조건+과거상태2피처의 Ridge100을 별도 내부 검증에서 비교한다. Scaler는 그 진단 학습집합에서만 fit한다. 전문가 fit은 모든 meta 목표를 제외하므로 두 번째 분할에서도 meta 목표 유입 없음. 모델 채택/ESTATE 튜닝에는 쓰지 않는 고정 진단이다. 모든 outerfold/seed에서 완료하고 개선 개수·분포와 의존/표본수 한계를 보고한다.
