# 통계 단서 1–4 실행 전 고정

2026-10-03 집 코덱스. 사용자의 1–4 진행 지시로 온도/EC 실험을 모두 수행한다. 기존 파일 수정·제출 생성·평가 입력값·EC잠금 파일/정답 열람 없음.

세 후보를 따로 비교한다. 온도 원 W30G, EC 계절 v2가 기준이다. TBIAS: 세 전문가 혼합의 내부 검증 잔차를 현재/과거 8조건으로 Ridge(alpha100) 적합, 보정 ±0.35℃ 제한, 기존 저온 gate 곱함. TGATE: 세 전문가 혼합 MSE를 직접 목표로, BASE−PFN/CODEX−PFN × 같은 조건의 선형 설계, Ridge(alpha1000)로 기존 비중 쪽 수축. 각 비중 변화 ±0.10, 비음수 합1로 투영, ≤8℃ 기존 보호 유지. ESTATE: 같은 온실·같은 기록 구간의 과거 관측 일평균 EC와 현재 계절v2 예측의 차이 및 과거 일평균 변화율, exp(−과거관측간격/6)로 감쇠. 내부 검증 잔차 Ridge(alpha100, intercept없음), 보정 ±0.15 EC, 외부 학습 범위 clip. 셋을 합치거나 결과를 보고 설정을 고르지 않는다.

각 outer 학습 안에서 온실별 정렬된 5일 묶음 중 매4번째를 meta 검증으로 고정하고 ±1일 buffer를 제거한다. 원형 전문가를 남은 inner fit 데이터에 새로 적합한다. 온도 BASE7/101·CODEX726/727와 PFN V2 문맥1–8/17–24를 전부 포함한다. EC R3(ET/LGB/MLP .6/.3/.1)7/101/2024와 PFN V21–4를 포함한다. 이는 하나의 고정 내부 holdout이며 완전 내부 Kfold가 아님을 명시. 외부 정답이 내부 전문가·피처·보정계수에 들어가지 않는다. 전역OOF를 메타 학습에 사용하지 않는다. 원 외부 전문가 캐시는 평가 예측으로만 재사용한다.

온도 DIAG10/EXT10/EXT12의 2BASE시드×2문맥 12조건, EC DIAG10/A/B/EXT10/EXT12의3시드15조건 모두 같은 개선 방향이어야 한다. 통합 누적 family_k32, DIAG10 온실층화 5일 block bootstrap20,000 p_worse<.025/32와 CI상한<0. 온도 통과시 추가 GUARD/EL1을 실행하기 전 채택하지 않는다. 새 EC잠금 채점은 하지 않는다. 작아도 기준 통과시만 후보.

1번은 TBIAS, 2번은 ESTATE와 조건부 잔차 진단, 3번은 TGATE. 4번은 모든 inner split을 실제 5일 결측 블록처럼 만들고, 기준 외부 분할과 내부 분할의 직전 과거 관측 간격/날씨 공유/결측 블록 길이를 기록한다. ESTATE는 과거 관측 가능성을 추가로 5일 지연시킨 보정기 전용 스트레스도 보고한다. 그 스트레스는 원 전문가를 새로 학습한 별도 검증이 아니며 채택용 성적이 아니다. 관측 없는 경우 상태 보정0. 미래/다른 온실/다른 기록 구간 정답 불변 검사. 과거 실제 공개 학습 정답만 사용하며 외부 검증 정답은 상태 갱신에 쓰지 않는다.

| 피처/자료 | 예측 시 이용 가능 | 점검 |
|---|---|---|
| 온도 8조건 | 현재/과거 입력·온실·기록 구간 | 기존 MASK/인과 피처, 외부 학습 fit scaler |
| BASE/CODEX/PFN 예측 | 현재 피처로 생성한 예측 | inner fit와 outer query 분리 |
| EC 과거 일평균/변화 | 같은 온실, 이전 공개 관측일 | 시간 엄격 < query day, 구간 분리, 외부 정답 제외 |
| 계절 변환 | 외부/내부 학습 입력에서만 적합 | query 날씨 미사용, inner 변환 재적합 |
| 하루 목표 평균 | 내부 fit 정답에서만 | 평가 정답 요약·상태갱신 없음 |
| 검증 정답 | 채점/사후 진단에만 | 계수/전문가 fit 미포함 |

GPU는 현재 TK2 체크포인트를 보존하고 이 실험의 내부 PFN을 우선 계산한 뒤 TK2를 원스크립트로 재개한다. 실행 전 main 커밋, 소스해시/분할행 보존, 개별 체크포인트 새파일 생성. 실행후 수치 fsum 독립검산·원라벨 대조·혼합/회귀식·인과 불변·재현 점검. 보고는 시드/검증별 평균·fold SD, 전체/전후기/농장, 사후 추가정보의 방향과 실패도 포함한다.
