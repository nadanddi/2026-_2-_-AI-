# 온도 학습·계산·피처·추론 개선4안 · 2026-10-03

사용자 요청의 네 영역을 원 CODEX 구성원에 각각 적용해 별도로 비교했다. 새 후보를 섞거나 기존 W30G 비중을 바꾸지 않았다. 네 안 모두 채택 기준 불통과로 기존 W30G 유지.

## 구현

- A1: 원 in-sample 물리 잔차 대신 외부 학습일 내부3fold physics OOF를 빼서 잔차 트리 학습. 각 내부fold도 같은 온실 인접 ±1일을 제외. 외부query 정답은 물리/트리/계수 적합에서 전부 제외.
- B1: y 대신 y−in_temp_reset3를 원19열 Ridge100으로 적합하고 그 입력 anchor를 다시 더함. 선형 함수 공간은 원래와 같지만 Ridge 정규화가 온도 기울기를0으로 당기는 대신 공기추종값으로 당기는 계산 변경이다. 모델의 공기추종 prior가 적합하다는 가설만 시험하며 물리 법칙 확정 주장은 아니다.
- C1: 원89열 유지, in_temp_h0/mean/reset1/3/8−현재in_temp와 reset3−reset8 총6열 추가. 물리식·잔차타깃·모델 설정은 동일. 새 정보원을 만든 것이 아니라 기존 입력의 상대적 표현을 트리가 직접 사용하도록 바꾼다.
- I1: 같은 내부3fold의 원 physics/LGB OOF에서 잔차 계수 gamma를 학습한다. gamma=clip((Σw*r*(y−physics)+100)/(Σw*r²+100),0,1.25). 추론은 physics+gamma*residual. 고정100은1에대한정규화. 출력평활이 아니며 외부검증정답으로 계수를 고르지 않았다.
