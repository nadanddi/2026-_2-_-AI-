# 팜모니 — 이미지 미션 제출물 v5

## 1. 사용 모델
- **구조**: 고정 고주파 잔차층(HighPass) + ResNet18 백본 + 듀얼 헤드 (`inference.py`의 `DualHeadResNet18`)
  - HighPass: `x - GaussianBlur5x5(σ=1)(x)` 에 상수 8을 곱한 값. **학습하지 않는 고정층**으로, 색·형태(장면 내용)를 줄이고 노이즈·압축·스무딩 흔적을 남깁니다.
  - binary head: 생성 이미지일 확률 (최종 출력으로 사용)
  - multi head: 7개 유형 분류. **학습 때 보조 손실로만 쓰고 최종 출력에는 쓰지 않음**
- **입력**: 리사이즈하지 않은 원본 해상도의 224×224 패치
- **용량**: `model/weights.pt` 약 45MB

## 2. 사전학습 가중치 출처
- torchvision `ResNet18_Weights.IMAGENET1K_V1` (ImageNet-1k 분류, BSD-3-Clause 라이선스)
- 학습할 때만 초기값으로 썼습니다. 미세조정한 전체 가중치는 `model/weights.pt`에 들어 있습니다. 추론 코드는 `resnet18(weights=None)`로 구조만 만든 뒤 이 파일을 읽으므로, 실행 중 다운로드는 없습니다.

  | 재현 방법 | AI Hub에서 같은 데이터를 받은 뒤 `python src/aihub_index_v5.py` → `python src/prep_aihub_v5.py --n_train 40 --n_val 15` → `python src/models/train_v5.py --mode cv_final --threads 4`를 실행합니다(난수 시드 42 고정). 최종 검증에서 원본 제출이 필요하면 운영위원회의 권리·접근 제한 자료 처리 안내를 따르겠습니다. |

- **표준화(배포 형식 맞춤)**: 공개 실제 사진 qube.jpg 와 같은 AI Hub 원본 사진을 찾아 비교해 보니, 긴 축 1024·짧은 축 768 을 덮도록 축소한 뒤 가운데를 768×1024(가로 사진은 1024×768)로 자르고 JPEG 품질 92로 저장한 것과 일치했습니다. AI Hub 사진도 같은 방식으로 표준화했습니다. 파생 가짜는 표준화한 사진(필터의 60%는 원본 해상도)에 조작을 적용한 뒤 같은 JPEG 품질 92로 한 번만 저장해, 실제와 저장 이력을 같게 했습니다.
- **파생 가짜 강도**: 공개 생성 사진의 노이즈·소금후추·블러 강도를 측정해, 그와 비슷한 범위(약~중간)로 맞췄습니다. 부분 편집 위치는 70%를 AI Hub 라벨의 잎·줄기 영역에 두었습니다.
- **쌍(pair) 패치**: 파생본 패치마다, 같은 원본 실제 사진에서 **같은 좌표·같은 공통 처리**로 자른 패치를 실제(0)로 함께 학습했습니다. 두 패치는 조작 흔적만 다르므로 장면 내용으로는 구분할 수 없습니다.
- **공통 처리**(라벨과 무관하게 실제·생성 양쪽에 같게 적용): 25%는 처리하지 않고, 나머지는 밝기·대비·채도를 ±8~10% 바꾸고, 0.75~1.0배로 축소한 뒤 JPEG 품질 88~95로 다시 저장합니다.
- **공개 생성 사진 사용 방식**: 전체가 조작된 유형(AI_gen, filter, full_style)은 1장당 16개 패치를 생성(1)으로 학습했습니다. 일부만 조작된 유형(composite, partial_gen, partial_style)은 조작 위치를 모르므로 패치 라벨을 쓰지 않고, **MIL**(격자 9개 패치 중 최대 logit이 생성(1)이 되도록) 손실로만 학습했습니다. 실제 사진도 "9개 패치 중 최대 logit도 실제(0)"가 되도록 학습했습니다.
- **학습 설정**: AdamW(lr 2e-4, weight decay 1e-4), OneCycle 스케줄, 3 epoch, batch 32입니다. 손실은 BCE(binary) + 0.3 × CE(7-class) + 0.5 × MIL이고, 좌우·상하 반전을 적용했습니다.

## 4. 최종 출력 처리 (10/5 중간 안내 3절 항목)
| 항목 | 내용 |
|---|---|
| 패치 위치 | 이미지 1장을 리사이즈하지 않고, 224×224 패치를 **이미지 전체를 덮는 고정 격자**로 자름 (`grid: "cover"`, 가로 ceil(W/224) × 세로 ceil(H/224); 768×1024 → 4×5 = 20개, 1024×768 → 5×4 = 20개) |
| 패치 집계 | 패치별 sigmoid 확률 중 **상위 5개의 산술평균**을 반환 (`aggregation: "top5"`) |
| 계산식 | `p_i = sigmoid(binary_logit(HighPass(patch_i)))`, `p = mean(top5(p_1..p_20))` |
| 결정 근거 | 두 검증을 함께 봤습니다. (1) 공개샘플 21장 3-fold 교차검증(fold마다 실제 1장 + 유형별 생성 1장을 학습에서 제외, 운영진이 만든 생성 사진의 탐지율). (2) 학습에 쓰지 않은 AI Hub 개체 21개의 실제 315장과 그 파생본 315장(새 개체 실제 사진의 오판율). 평가셋이 실제·생성 반반인 점을 반영해 `추정 정확도 = 0.5 × 검증 실제 정답률 + 0.5 × (0.5 × 공개 생성 탐지율 + 0.5 × 검증 생성 탐지율)`이 가장 높은 규칙을 골랐습니다. 후보: 3×3 / 전체 덮기 격자 × 평균 / 상위3 / 상위5 / 최댓값. 결과: 전체 덮기·상위5 0.739(검증 실제 0.793, 공개 생성 0.67), 전체 덮기·상위3 0.731, 3×3·평균 0.646 등. |
| 결정에 사용한 자료 | 공개샘플 21장, AI Hub 학습·검증 자료와 그 파생본만 사용. 평가 자료나 그 통계는 쓰지 않음 |
| 실행 중 갱신 | 없음 |
| 임계값 | 없음 (운영위원회 판정 기준 0.5를 그대로 따름) |
| 확률 보정 | 없음 |
| 앙상블 | 없음 |

## 5. 특이사항
- GPU가 없으면 CPU로 동작합니다(`torch.cuda.is_available()` 분기).
- 네트워크 접근·다운로드·패키지 설치 코드가 없습니다. 추가 패키지도 없습니다(torch, torchvision, numpy, pillow만 사용).
- 각 이미지는 독립적으로 처리하므로, 입력 순서와 무관하게 같은 결과가 나옵니다.
