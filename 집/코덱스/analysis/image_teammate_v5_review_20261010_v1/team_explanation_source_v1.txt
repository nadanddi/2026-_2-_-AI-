## 1. 한 줄 요약

**사진을 리사이즈하지 않고 224×224 패치 20개로 자른 뒤 → 고주파 잔차(조작 흔적)만 남겨서 → ResNet18이 패치마다 '생성 확률'을 내고 → 상위 5개 패치 확률의 평균을 최종 확률로 쓴다.**

- 과제: 딸기 재배 사진이 실제(0)인지 생성·합성·변형(1)인지. `predict`가 이미지별 생성 확률(0~1)을 반환하고 **0.5 기준 Accuracy**로 채점.
- 평가: 실제 262 + 생성 262 = 524장, 768×1024 또는 1024×768 JPEG.

## 2. 모델 구조 (`inference.py` + `config.json`)

```
원본 이미지 (768×1024, 리사이즈 안 함)
   │  224×224 패치, grid="cover" → 가로 4 × 세로 5 = 20개 (이미지 전체를 덮음)
   ▼
[HighPass]  (x − GaussianBlur(x)) × 8      ← 학습 안 하는 고정 층 (σ=1.0, 5×5 커널)
   ▼
ResNet18 백본 (ImageNet 사전학습에서 시작, fc 제거 → 512차원)
   ├─ binary_head : Linear(512→1)  생성 여부  ← 최종 판정에 사용
   └─ multi_head  : Linear(512→7)  조작 유형  ← 학습 보조용, 추론에선 버림
   ▼
패치 20개의 sigmoid 확률 → aggregation="top5" (상위 5개 평균) → 이미지 확률
```

실제 `config.json` 핵심 값:

| 키 | 값 | 의미 |
|---|---|---|
| `highpass` | `true` | 고주파 잔차 입력 사용 |
| `patch` | `224` | 패치 크기 |
| `grid` | `"cover"` | 이미지 전체를 덮는 4×5=20 패치 |
| `aggregation` | `"top5"` | 상위 5개 패치 확률 평균 |
| `epochs` / `lr` / `seed` | 3 / 2e-4 / 42 | 학습 설정 |
| `mil_p` / `mil_w` | 0.3 / 0.5 | MIL 손실 사용 확률 / 가중치 |
| `train_patches` | 5829 | 최종 학습 패치 수 |
| `class_map` | real 0, filter 1, composite 2, full_style 3, partial_style 4, partial_gen 5, AI_gen 6 | 보조 헤드 유형 |

### 설계 이유

| 요소 | 왜 |
|---|---|
| **고주파 잔차 입력** | 색·형태(장면)를 지우고 노이즈·압축·스무딩 흔적만 남김 → 학습 때 본 장면을 외우는 걸 막음 |
| **리사이즈 없는 패치** | 리사이즈하면 조작 흔적이 뭉개짐 |
| **cover 격자 (20패치)** | 이미지 일부만 편집된 가짜도 어딘가 패치에 걸리게 |
| **top5 집계** | mean은 부분 편집을 희석시키고, max는 실제 사진 오탐이 많음 → 중간 지점 (3절 검증표 참고) |
| **듀얼 헤드** | 유형 분류를 보조 손실(α=0.3)로 같이 학습해 특징을 풍부하게 |

임계값 보정·확률 보정·앙상블 없음. 패치 좌표는 고정이라 입력 순서가 바뀌어도 결과 동일.

| v5b | + 클래스 보정, 5 epoch, MIL 강화 | v5와 차이 없어 폐기 |

### v5의 핵심 발견 (`versions\v5\ANALYSIS.md`)
1. **공개샘플 원본 = AI Hub 596 「지능형 수직농장 통합 데이터(딸기)」**. 공개 실제 `qube.jpg`가 AI Hub `C22_B02_006_414409`와 **픽셀 단위로 일치**(ORB 정렬 오차 2.5). 공개 가짜 다수도 같은 개체 사진 기반.
2. **운영진 배포 처리 역산**: 짧은 축 768 / 긴 축 1024를 덮도록 축소 → 가운데 크롭 → **JPEG 품질 92**. 우리 학습 자료도 똑같이 맞춤 (실제·가짜 모두 JPEG 92 한 번만 저장 → 저장 이력이 단서가 되지 않게).
3. **운영진 가짜는 약하다**:

   | 지표 | 운영진 | v4 생성본 | v5 생성본 |
   |---|---|---|---|
   | 소금후추 점 비율 | 0.28% | 2.87% | 0.37% |
   | 블러 고주파 표준편차 | 1.90 | 0.15 | 1.66 |
   | 노이즈 인접 픽셀 상관 | 0.23 | −0.06 | 0.27 |

   → 노이즈 상관이 양수 = 원본 해상도에서 필터 적용 후 축소한 것으로 추정. v5는 필터 가짜 60%를 원본 해상도에서 적용.
4. **검증 방법 교체**: 공개 실제가 3장뿐이라 공개 CV로는 실제 오판을 못 본다 → **학습에 없는 개체 21개**의 실제 315 + 파생 315 = 검증 630장을 추가.

## 4. 학습 방법

### 4-1. 학습 루프 (`src\models\train_v3.py`, v5가 그대로 사용)
1. **쌍(pair) 패치**: 가짜 패치마다 같은 원본 실제 사진의 *같은 좌표·같은 처리* 패치를 실제(0)로 같이 학습 → 차이는 조작 흔적뿐.
2. **MIL**: 부분 편집 가짜는 어느 패치가 가짜인지 모르므로 "9패치 중 최댓값 = 가짜", 실제 사진은 "최댓값도 실제"로 학습.
3. **공통 처리**(라벨 무관, 실제·가짜 동일): 축소 0.75~1.0, JPEG 88~95, 밝기·대비 ±8%, 채도 ±10%. 25%는 처리 없음.
4. 상하·좌우 반전, AdamW(weight decay 1e-4) + OneCycleLR, batch 32.
5. 손실 = BCE(생성 여부) + 0.3 × CE(유형) + [확률 0.3로] 0.5 × MIL.

### 4-2. 학습 자료 (최종 모델)

| 구분 | 내용 | 양 |
|---|---|---|
| AI Hub 실제 | 학습용 1,160 + 검증용 315 (아래 참고) | 1,475 |
| AI Hub 파생 가짜 | 실제 1장당 1장, 운영진 강도로 보정 | 1,475 |
| 공개 샘플 | 실제 3 + 가짜 18 | 21 |
| 기존 파생 가짜 | 공개 실제 3장에서 만든 것 중 샘플 | 450 |

- AI Hub 실제: 학습용 1,160장(Training 29묶음 × 40장, 개체 23) + 검증용 315장(학습에 없는 개체 21 × 15장). 설향 1,035 / 금실 440.
- 파생 가짜 유형: filter 4종, composite, full_style 3종, partial_style, partial_gen 3종(bilateral·cv2 인페인팅·저해상도 재생성). 부분 편집 위치 70%는 AI Hub 라벨 JSON의 잎·줄기 bbox 중심.
- 최종 모델은 위 자료를 **전부 합쳐** 학습 (검증 630장도 포함).

### 4-3. 집계 규칙 선택 근거 (공개 21장 3-fold CV + 검증 630장)

추정 정확도 = 0.5 × 검증 실제 + 0.5 × (0.5 × 공개 가짜 + 0.5 × 검증 가짜)

| 규칙 | 공개 실제 | 공개 가짜 | 검증 실제 | 검증 가짜 | 추정 정확도 |
|---|---|---|---|---|---|
| v4 (3×3 mean) | 3/3 | 15/18 | 0.390 | 0.794 | 약 0.60 |
| **v5 cover / top5 (채택)** | 3/3 | 12/18 | 0.793 | 0.706 | **0.739** |
| v5 cover / top3 | 3/3 | 14/18 | 0.675 | 0.795 | 0.731 |
| v5 3×3 / mean | 3/3 | 4/18 | 0.984 | 0.392 | 0.646 |

- top3 → top5로 갈수록 실제 오판은 줄고 가짜 탐지는 조금 줄어든다. mean은 실제는 거의 다 맞히지만 가짜를 못 잡는다.
- 공개 21장으로 돌린 공식 `self_check`: **accuracy 0.857 · AUROC 1.000 · F1 0.909, RESULT: PASS** (학습에 쓴 21장이라 참고용).
- holdout 실험(공개 21장 안 쓰고 학습)에서는 공개 가짜를 18장 중 3장만 잡음 → **운영진 가짜 예시와 여러 개체의 실제 사진이 둘 다 필요**했다.

### 뜯어볼 때 추천
- **패치 확률 지도**: `predict` 안의 `pp`를 이미지별로 20칸(4×5)으로 찍어 보면 어느 위치를 가짜로 보는지 알 수 있다. holdout 결과 `versions\v5\holdout_public_patch_probs.csv`에 공개 21장의 패치 확률이 이미 있다.
- **HighPass 출력 보기**: `model.pre(x)`를 이미지로 저장하면 모델이 실제로 보는 입력(노이즈·엣지 위주)을 확인할 수 있다.
- **보조 헤드**: `predict`에서 버리는 두 번째 출력(`multi_head`)을 softmax 하면 모델이 생각하는 조작 유형을 볼 수 있다.
