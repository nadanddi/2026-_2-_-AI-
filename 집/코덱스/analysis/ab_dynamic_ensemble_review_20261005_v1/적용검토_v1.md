# A B 동적 앙상블 전략 적용 검토

2026-10-05 집 코덱스. 사용자 제공 DOCX 본문 OOXML 읽기 검토이며 모델 성능을 새로 분석하거나 재채점하지 않았다. 원본 수정 없음. 문서에 적힌 제안은 검토 자료이며 실행 지시로 취급하지 않았다.

## 판단
EC 회귀에 적용 가능한 구조다. 개선 효과는 미검증이다. 문서 5절과 6절의 식은 g=alpha일 때 동일하다. A 일반 전문가, B 특수 전문가라는 역할은 실제 내부 OOF에서 확인해야 한다.

## EC로 바꿀 점
A를 현재 비교 기준의 실제 최종 EC 출력으로 고정하고 B는 규정 감사가 끝난 전문가 또는 이웃 보정 출력 하나로 고정한다. 원시 구성원 출력과 후처리 완료 출력을 혼동하지 않는다.

최종 예측 = a + g(x)*(b-a), 0<=g<=1.
분류용 A-only/B-only, 0.5 confidence, entropy, Macro-F1/최종 분류 문턱은 그대로 쓰지 않는다. EC 목표는 제곱오차이며 모든 내부 행의 혼합 손실을 최소화하는 작은 정규화 게이트가 후보 설계다. B 승리 확률은 MSE 최적 혼합 비중과 같지 않다. 동률/둘 다 큰 오차인 행도 혼합 학습에 포함한다. 예측 불일치와 내부 문맥별 분산은 후보 특징일 뿐 정확성 보증이 아니다.

## 기존 실험과의 차이
카탈로그 6.248/249의 고EC/밀폐 전문가 혼합, 6.322의 비용가중 LogisticRegression 신뢰도 게이트 및 제한 Ridge가 관련된다. 가족25 run_v6.py 확인: 내부 heldout b에서 보정 이득의 부호를 라벨로 삼고 절대 비용 차로 가중한다. 적용은 probability>=.5로 보정 켜기/끄기다. 따라서 확률을 연속 혼합률로 사용하는 문서의 soft gate와 동일 구현은 아니다. 그러나 기존 실패를 근거 없이 새 이름으로 반복해서는 안 된다. 기존실험 기각이 전체 게이트 계열 불가능성의 증거도 아니다.

## 누수 방지와 검증
외부 평가 fold를 먼저 제외하고 그 학습 영역 내부에서 A/B OOF를 새로 만들거나 출처가 검증된 동일 구조 캐시를 사용한다. 게이트와 전처리는 이 내부 자료만 학습한다. 게이트까지 학습한 전역 OOF를 같은 행에서 평가하는 것은 최종 일반화 검증이 아니다. 날짜/온실 묶음 및 purge 규칙을 유지한다. 현재/이전 허용 입력만 특징에 사용하고 test_X나 전체 테스트 예측 분포로 전처리/가중치/문턱을 맞추지 않는다.

실행 시 A/B 정의, 피처, 정규화, 시드, 분할, 후처리와 판정 기준을 먼저 코드에 고정한다. EC 새 후보 일반 프로토콜 DIAG10/A/B 전시드 개선 및 DIAG10 p_worse<.025/k와 안전장치를 적용한다. 2차 전용 후보이면 별도 새 시드/미사용 배치 확인 절차가 적용된다. 이전에 본 후보를 새 규칙으로 소급 채택하지 않는다.

## 추천
