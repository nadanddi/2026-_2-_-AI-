## 주의 및 내 EC 작업에 반영

1. 최신 CT1·NS1·CT2는 아직 10-09 일지 본문과 카탈로그6.460까지에 반영되지 않았다. 일지의 'EC 방향이 남지 않음'을 현재 상태로 읽으면 안 됨.
2. CT1은 라벨을 본 뒤 발견한 일정 패턴이다. 새 시드는 모델 난수에 대한 확인이며 새 데이터 독립성은 보장하지 않는다. A/B는 같은 공개 데이터의 재분할이다. R3 통과를 현 EC14 제출 구성 전체의 개선으로 확장하지 않는다. CT2 완료 후 판단.
3. 다른 온실 동시기 정답 제외는 최종 평가와 학습 가능 정보를 맞추는 중요한 검증 설계 쟁점이다. 기록번호±3은 실제 동일 달력일과 자동으로 같지 않으며 입력 대응 확인이 필요하다. 내 직전 DIAG10 결과는 기존 설계 진단으로 유지하고, 다른 온실 제외를 적용한 결과와 직접 등치하지 않는다.
4. CT2 코드에서 R3/PFN 학습은 forb를 적용하지만 SG2 ref는 labset-vd로 별도 구성된다. SG2 correction은 같은 온실만 사용하므로 다른 온실 정답이 직접 들어간다고 단정하지 않는다. 다만 같은 온실±1 제외가 SG2 참조까지 동일하게 적용된다는 설명도 성립하지 않으므로 학습 제외와 참조 제외를 구분해 감사해야 한다.
5. 커튼 특징 계산은 같은 farm/day의 0..h 누적이며 h9 이전 NaN 처리로 소스상 미래시간 사용을 피함. 전체 실제 모델에 대한 인과성·학습 재현 검사를 새로 수행한 것은 아님. 제출 여부 판단·메시지 전송 없음.

근거: recheck_v1.py, independent_metrics_v1.json 및 읽은 클로드 로그. 처음 두 재계산 시도는 기본 Python/py3.12에 numpy가 없어 중단했으며, 외부 패키지 없이 표준 라이브러리 검산으로 완료했다. 다른 AI 실행 중 프로세스에는 손대지 않았다.
