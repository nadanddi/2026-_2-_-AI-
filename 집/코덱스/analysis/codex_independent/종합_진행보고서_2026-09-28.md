# 농업 AI 정형데이터 경진대회 모델 개선 진행보고서

작성일: 2026-09-28  
범위: 현재까지의 실제 제출, 로컬 실험, 재현성 검사 및 미제출 후보  
상태: 연구 진행 중; 새 후보의 대회 점수는 아직 없음

## 1. 현재 판단

온도와 EC의 실제 대회 최고 성과는 서로 다른 제출에 있다. 온도는
5회차 제출의 RMSE **0.5456**, EC는 3회차 제출의 **0.2055**다.
현재 플랫폼의 마지막 유효 제출은 5회차이므로 그 점수는 온도
0.5456, EC 0.2134다. 두 최고 열을 합친 `submission_07.csv`는
로컬에서 만들었으나 **제출하지 않았으며**, 예상 점수
0.5456/0.2055는 동일한 열을 재사용했다는 산술적 예상이다.

새 로컬 후보는 5회차 온도 열을 그대로 두고, 3회차 EC 기준
모델 80%와 TabPFN-v2 네 문맥 평균 20%를 결합했다. EC는
탐색 네 폴드와 사전 지정한 확인 두 폴드에서 기준보다 낮은
RMSE를 보였다. 확인 1,920행의 EC RMSE는 0.290792에서
0.281418로 **3.22% 감소**했다. 이는 공개 데이터 검증 결과다.
비공개 평가의 RMSE나 순위 개선은 아직 확인되지 않았다.
특히 평가 입력과 같은 날짜 범위에 속하는 공개 확인 자료 10일만
떼어 보면 감소율은 **0.32%**로 작아진다. 이 사후 점검은 후보의
평가 이전에 더 살펴봐야 할 전이 위험을 보여준다.

별도로 EC 비율 0.4·TabPFN 여덟 문맥·당일 누적 실내 평균을
결합한 조합은 원본 연구의 **사전 공개 검증 기준을 통과**했다.
그 조합의 더 엄격한 한랭 외삽에서는 두 시드 모두 **1.29%,
1.82% 악화**했다. 따라서 사전 기준 통과와 별개로 현재 단계에서
제출 권고로 승격하지 않는다. 새 제출용
CSV나 비공개 점수는 없다. 앞 문단의 로컬 CSV·재현 ZIP은 여전히
EC 비율 0.2 후보를 가리킨다.

## 2. 실제 제출과 실패에서 배운 점

| 제출 | 온도 RMSE | EC RMSE | 판단 |
|---|---:|---:|---|
| 1회차 | 0.7450 | 0.2442 | 초기 기준 |
| 2회차 | 0.6666 | 0.2287 | 두 목표 모두 개선 |
| 3회차 | 0.5624 | **0.2055** | 현재 EC 최고 |
| 4회차 | 0.5697 | 0.2055 | 한랭 보정이 온도를 악화 |
| 5회차, 현재 마지막 유효 제출 | **0.5456** | 0.2134 | 학습행 가중치로 온도 개선; EC의 `day` 제거는 악화 |

3회차 대비 5회차의 온도 개선은 입력 복원 행과 잡음이 큰 날의
훈련 가중치를 낮춘 데서 나왔다. 반대로 EC에서 날짜 특징 `day`를
제거하면 실제 점수가 0.2055에서 0.2134로 나빠졌다. 따라서 새
후보의 EC 기준 모델은 `day`를 유지하는 3회차 구성이다.

이후 별도 EC 탐색에서는 후보 선택용 밴딧, 센서의 당일 누적
통계, 온도 보조 목표 학습, 온실 ID 특징을 시험했다. 각각의
사전 선별 기준에서 탈락했다. 특히 온실 ID 추가는 탐색 평균
RMSE를 8~10% 악화시켰다. 밴딧은 **후보 모델을 고르기 위한
실험**이며 온실을 제어하는 강화학습 정책의 성과가 아니다.
실패한 후보를 결과가 좋았던 일부 시드만 골라 재사용하지 않았다.

이 대회의 EC 과제는 고정된 입력에서 정답 수치를 예측한다.
예측값 `a`에 보상을 `−(EC−a)²`로 주는 한 단계 정책을
정의할 수는 있지만, 그 최적 행동은 조건부 평균
`E[EC | 현재까지의 허용 입력]`으로 일반적인 제곱오차 회귀의
해와 같다. 제출 예측이 다음 온실 상태나 보상 자료를 바꾸는
상호작용은 제공되지 않는다. 따라서 PPO·DQN 같은 제어 정책을
추가하는 것만으로 새로운 EC 정보를 얻을 수 없다. 앞선 밴딧
후보 선택도 사전 검증에서 개선되지 않아 채택하지 않았다.

원본 연구 장부에는 이 작업 사본 밖에서 병행한 추가 실험도 있다.
EC TabPFN 비율 0.4와 여덟 문맥 구성이 여러 검증 조합에서
개선 방향을 보였으나, 미리 정한 다중 비교 기준을 두 차례
근소하게 넘겨 **기각**됐다. 극단적 추위 외삽 검사에서도 EC
비율 상향에 불리한 결과가 있었다. 밀폐일 전용 모델, 구동기만
쓰는 모델, 밀폐일 학습 가중치도 기각됐다. 이 결과는 당시
EC 비율 0.2를 유지하는 근거였으며, 원본 연구의 GPU 계산을
이 보고서의 CPU 확인 결과와 같은 독립 시험으로 합산하지 않는다.

온도는 원본 연구 장부에 TabPFN 여덟 문맥과 추위 구간의 입력
기반 게이트를 결합한 **별도 미제출 후보**가 기록돼 있다.
극저온 외삽을 포함한 여러 로컬 검증에서 유망하다고 보고됐지만,
이번 로컬 CSV·재현 ZIP의 온도 열은 그 후보가 아니라 **실제
5회차 제출과 같은 온도 열**이다. 따라서 이 보고서에서 말하는
실제 온도 최고 0.5456은 제출로 확인된 점수이며, 별도 온도
후보의 비공개 성능을 뜻하지 않는다.

## 3. 새 EC 후보의 검증

후보는 기존 EC 원시 모델(ExtraTrees·LightGBM·MLP를 세 시드로
평균) 80%와 CPU TabPFN-v2-reg 문맥 시드 1·2·3·4의 평균
20%를 결합한다. 각 시각의 예측에는 같은 온실의 그 시각까지
관측 가능한 입력만 사용한다. 기존 당일 수축 0.5와 훈련 EC
범위 제한을 그대로 적용했다.

| 검증 | 기준 EC RMSE | 후보 EC RMSE | 상대 변화 |
|---|---:|---:|---:|
| 탐색 폴드 0 | 0.151355 | 0.147450 | −2.58% |
| 탐색 폴드 2 | 0.123521 | 0.120868 | −2.15% |
| 탐색 폴드 4 | 0.259026 | 0.254291 | −1.83% |
| 탐색 폴드 6 | 0.115837 | 0.106336 | −8.20% |
| 탐색 합산 3,696행 | 0.173012 | 0.168307 | −2.72% |
| 확인 폴드 8 | 0.333539 | 0.329091 | −1.33% |
| 확인 폴드 9 | 0.240565 | 0.223811 | −6.96% |
| **확인 합산 1,920행** | **0.290792** | **0.281418** | **−3.22%** |

확인 폴드 8·9와 같은 온실의 양옆 하루는 탐색 학습에서
제외했다. 후보와 통과 기준을 먼저 고정한 뒤 두 폴드를 한 번
평가했다. 사전 기준인 **두 폴드 모두 개선 및 합산 1% 이상
개선**을 충족했다. 세 기준 시드를 따로 비교한 확인 결과도
6개 모두 개선됐다.

문맥 표본 운을 점검하려고, 기존 연구가 미리 정했던 다른 네
문맥(시드 5·6·7·8)을 CPU에서 독립 재적합했다. 탐색 네 폴드와
기준 세 시드의 12개 비교가 모두 개선됐고 단순 평균 감소율은
4.02%다. 실제 세 시드 평균으로 합친 사후 진단은 탐색 합산
0.173012→0.166371(−3.84%)이었다. 두 문맥 묶음의 직접 우열은
폴드마다 바뀌었으므로 더 좋아 보이는 묶음으로 후보를 바꾸지
않았다. 확인 폴드에는 원래 고정한 문맥 1·2·3·4만 사용했다.

## 4. 우연한 저점수와 분포 차이에 대한 점검

탐색 154개 온실-일 중 110일, 확인 80일 중 56일에서 개선됐다.
그렇지만 이득의 크기는 고르지 않다. 양의 제곱오차 감소 총량
중 상위 5일이 차지하는 비율은 탐색 57.8%, 확인 75.8%다.
사후 스트레스 검사에서는 5일 묶음 16개 중 13개가 개선됐고,
어느 한 묶음을 빼도 합산 개선 방향은 유지됐다. 이득이 가장
큰 5일을 모두 빼면 감소 폭은 −0.71%까지 줄어든다. 이 검사는
후보를 고른 뒤의 진단이므로 새로운 독립 증거로 더하지 않는다.
탐색의 5일 묶음 재표집 95% 상대 변화 구간은
**−4.96%~+0.14%**로 0을 포함한다. 확인은
**−7.62%~−0.95%**다. 이는 이미 학습된 예측을 재표집한 값이며
모델 재학습의 불확실성이나 많은 후보를 검토한 선택 효과를
포함하지 않는다. 따라서 확인 구간 통과를 비공개 점수 개선의
확률 보증으로 읽을 수 없다.

밀폐일은 하루 전체 순환팬 평균이 10 미만이고 환기 0의 비율이
85% 초과인 날로 **진단에만** 정의했다. 이 정의는 미래 시각
입력을 포함하므로 예측 특징이나 게이트에는 사용하지 않았다.
탐색의 밀폐일 25일에서는 EC RMSE가 0.278449→0.278914로
0.17% 악화했으나, 확인의 밀폐일 14일에서는
0.566020→0.557880으로 1.44% 개선됐다. 비밀폐일에서는
탐색 −4.87%, 확인 −6.84%였다. 평가 입력은 60일 중 20일이
밀폐일(33%)로, 확인의 14/80일(17.5%)보다 많다. 확인 구간의
체제별 오차가 평가에서도 같다고 **가정**하여 비율만 바꾸면
개선 폭은 약 2.37%로 줄어든다. 이는 실제 평가 점수의 추정이
아니며, 밀폐일만 골라 혼합 비율을 바꾸는 근거로 쓰지 않았다.

비공개 정답 없이 예측 이동 자체도 검사했다. 새 후보−기존 조합
EC 차이의 RMS는 확인 구간 0.02277, 평가 입력 0.02750으로
평가 쪽이 1.21배 크다. 평균 이동은 확인 +0.00902에서 평가
−0.00714로 방향이 바뀐다. 밀폐일 변화 RMS는 확인 0.02860,
평가 0.03920(1.37배)이고, F47 밀폐일도 0.03511에서
0.04784(1.36배)로 증가한다. 이 구간의 평가 정답은 없으므로
오차 방향을 판단할 수 없지만, 공개 확인 결과가 그대로 옮겨갈
것이라는 가정에는 불리한 분포 차이다.

평가 입력의 날짜 범위는 F13 185~239일, F47 183~237일이다.
그 범위에 들어가는 공개 확인 폴드 자료는 10일·240행뿐이며
RMSE 0.622250→0.620271(−0.32%)이었다. F13의 해당 5일은
오히려 **1.38% 악화**했다. 탐색 폴드의 같은 날짜 범위 10일은
0.106741→0.091237(−14.53%)로 좋아 보이지만, 기준 오차가
확인 구간의 1/6 정도인 훨씬 쉬운 사례다. 두 집합을 합친
20일·480행은 0.446424→0.443317(−0.70%)이며 F13 합산은
1.12% 악화했다. 날짜에 따른 공개 구간의 난도가 크게 달라
이 합산 수치도 평가 점수의 추정으로 사용할 수 없다.

원인을 더 살펴보면 같은 날짜 범위의 확인 10일 중 6일이
밀폐일이고, 그 6일은 0.801113→0.798855(−0.28%)에 그쳤다.
반면 탐색 10일에는 밀폐일이 1일뿐이다. 밀폐 여부는 하루 전체
입력으로 판별한 **사후 진단**이므로 후보 모델이나 제출 시점의
분기 기준으로 쓰지 않았다. 이 분석은 확인 결과를 본 뒤
정한 날짜·체제 부분집합이며 표본도 작다. 독립 확인 횟수에
더하지 않고, 비공개 EC 개선 주장을 약하게 만드는 위험으로
기록한다.

입력 분포 차이를 다른 방식으로도 확인했다. 학습 400일과 평가
60일의 하루 요약 입력만으로 구분한 뒤, 평가와 비슷한 공개
검증일에 큰 가중치를 줬다. 실내온도 평균·밀폐 여부만 사용하면
구분 AUC는 0.685, 추가로 최저온도·구동기·CO₂ 변화량을 쓰면
0.704였다. 기존 확인 80일의 EC 감소율 −3.22%는 두 가중
방식에서 각각 **−1.94%, −1.98%**로 줄었다. 234일의 탐색·
확인을 합치면 무가중 −3.02%, 가중 −1.74%/−1.54%다.
가중 확인 결과는 F13과 F47 모두 개선 방향이지만, 온실별
유효 일수는 확장 요약에서 각각 약 19일·31일에 불과하다.
확장 요약 방식의 확인 유효 표본은 약 39일로 줄어 불확실성이
크다. 가중 확인의 긍정적 오차 감소분 중 상위 5일 몫도 두 방식에서
각각 **71%·70%**다. 이 5일을 제외하면 RMSE 개선은
**0.25%·0.13%**로 거의 사라진다. 하루 전체 입력을 쓴
**사후 전이 진단**이며 급액 미관측,
라벨 관계 변화, 과거 후보 선택 효과를 해결하지 못한다. 비공개
점수의 추정이나 새 채택 게이트로 사용하지 않는다.

공개 데이터는 이전 연구에서 이미 폭넓게 살펴봤다. 이번에
남겨두었던 폴드 8·9의 점수는 후보를 고정한 뒤 처음 열었지만,
그 자료가 역사 전체에서 완전히 새로운 독립 시험은 아니다.

## 5. 규정·재현성·제출 상태

대회 규정의 같은 온실 현재/과거 입력 제한을 기준으로 실제
평가 입력 1,440행에서 특징과 모델의 끝단을 검사했다. 행 순서
변경, 미래 입력 교란, 다른 온실 입력 교란에서 앞선 예측은
변하지 않았고, 같은 CPU 설정에서 반복 적합·추론이 일치했다.
3회차 EC 기준 모델의 원본 제출값도 1,440행 전부 소수 6자리로
독립 재현했다.

## 7. EC 전담 요청서 반영과 병행 실험 결과

사용자가 지정한 원본 `research/Codex_요청_EC전담_2026-09-28.md`에
따라 이 작업은 EC 개선에 집중한다. 온도 신규 후보 연구는 별도로
진행 중이다. 요청서의 EC 0.2 혼합은 이 보고서의 후보와 같은
구성이며, 원본 연구의 여러 문맥·검증기에서도 개선 방향이
일치했다. 그 수치는 이번 작업의 독립 확인 횟수에 더하지 않는다.

원본의 `ec_combo_v1_gpu.py`는 EC 비율 0.4와 당일 누적 실내
평균 특징을 합친 한 후보를 새 시드로 시험했다. 2026-09-28
약 11:10 KST에 사전 규칙이 요구한 여섯 비교가 모두 개선됐다.
A의 두 시드는 −3.56%/−3.35%, B는 −1.82%/−2.12%,
DIAG10은 −2.14%/−2.71%였으며 `p_worse`는
0.0095/0.0000(로그 표시 자릿수)으로 둘 다 0.025 미만이다.
스크립트 판정은 **ADOPT**다. 이는 기존 EC v2에 대한 공개
검증의 채택 기준 통과를 뜻한다. 평가 날짜·밀폐 체제의 전이,
후보 탐색의 선택 효과, 비공개 점수는 여전히 확인되지 않았다.
사전 채택 규칙 밖의 한랭 위험 검사 EXT10은 두 시드 모두
−0.54%/−0.13%로 소폭 개선됐다. 더 엄격한 EXT12는
0.4663→0.4723(**1.29% 악화**), 0.4632→0.4716
(**1.82% 악화**)로 두 시드에서 같은 방향이다. 채택 게이트와
별개로 평가 한랭 전이의 경고이므로 새 조합을 제출 권고로
승격하지 않는다. 실험 프로세스는 최종 출력을 남기고 종료됐다.
별도 종료 코드는 확인하지 못했다. 실행 중에는 같은 노트북에서
무거운 CPU 학습을 겹치지 않았다. 원본
연구 파일은 읽기 전용으로 참고하고 결과는 이 작업 사본에
기록한다. 사용자 지시 전에는 새로운 제출 파일이나 플랫폼
제출을 진행하지 않는다.

자세한 결과와 원본 코드·로그 해시는
`ec_combo_v1/결과보고서.md`에 기록했다.
새 조합의 일별 전이 진단도 `ec_combo_transfer/PROTOCOL.md`에
고정한 뒤 실행했다. 공개 DIAG10 폴드 8·9의 80일에서 두
시드 평균 개선은 **0.79%**였으나, 폴드 8은 0.33% 악화,
F47은 0.99% 악화했다. 평가 날짜 범위의 공개 확인 10일은
**1.36% 악화**, 밀폐 14일은 **0.95% 악화**했다. 긍정적
오차 감소의 82.1%가 상위 5일에 몰리고, 그 5일을 제외하면
1.83% 악화한다. 두 시드 개별 결과도 평가 날짜 범위와
밀폐일에서 모두 악화했다. 사후 부분집합 분석이므로 독립
기각 판정으로 삼지 않지만, 새 조합을 제출 권고로 승격하지
않는 판단을 강화한다. 자세한 수치와 재현 근거는
`ec_combo_transfer/결과보고서.md`에 기록했다. 원본 조합의
행별 예측이 남아 있지 않으므로 별도 구현과 원본 GPU 실행의
비트 단위 일치 여부는 확인하지 못했다.

추가 데이터 경로도 점검했다. 원본 카탈로그 6.19에 따르면 EC
정답은 F13·F47에만 있고 다른 49개 온실에는 없어, 다른 온실의
EC 감독학습 행을 더할 수 없다. 급액 정보가 없고, EC 오차는
소수의 밀폐일에 크게 좌우된다(6.8, 6.14, 6.52~6.53).
미래 시각 입력까지 쓴 비인과 진단도 충분한 설명을 주지
못했으나(6.49, 6.51), **이 입력으로 도달 가능한 RMSE 하한을
확정했다는 뜻은 아니다.** 해당 하한 결론은 평가의 밀폐일
비율 차이 때문에 원본 카탈로그 6.51~6.52에서 철회됐다.
지금 확보된 자료만으로 타 팀 점수 0.128의 원인이나 정당한
달성 가능성을 단정할 수 없다.

EC v2의 보존된 공개 확인 예측에 평가 입력의 F13/F47×밀폐일
구성만 적용한 사후 진단에서는 상대 RMSE 감소가 **3.22%에서
2.34%로 축소**됐다. 같은 층 안의 날을 복원추출한 분포는 개선
방향이었지만, 이는 확인일과 평가일의 교환 가능성을 가정한
조건부 계산이다. 평가 날짜 범위의 공개 확인 10일은 실제로
**0.32% 개선**에 그쳤으므로 비공개 성능의 신뢰구간으로
