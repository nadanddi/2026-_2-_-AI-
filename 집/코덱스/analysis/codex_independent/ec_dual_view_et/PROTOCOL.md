# H8: 원본·인과 평활 이중 학습 뷰의 EC ExtraTrees

2026-09-29 실행 전 등록. EC 공개 검증 오차의 87.6%는 하루
수준이고 밀폐 39일이 전체 제곱오차의 58.9%를 차지한다.
원본 학습 실내 센서 3종에는 일부 거친 날이 있으며,
카탈로그 6.20의 **평활값으로 대체**하는 방식은 새 시드에서
재현되지 않아 기각됐다(6.29). 6.13의 잡음 판정도 실제
CO₂ 공급을 오인한다. H8은 잡음일 판정·날 가중치·원본값
대체 없이, 같은 학습 정답을 가진 두 입력 뷰로 센서 잡음에
대한 국소 불변성을 학습할 수 있는지 검증한다.

## 단일 후보와 기준

EC v2의 3회차 ExtraTrees 구성원만 변경한다. 원래
`FULL` 특징과 같은 열·600개 트리·최소 잎 1·특징
비율 1.0을 사용한다. 학습일마다 원본 입력 뷰와,
실내 온도·습도·CO₂만 같은 온실·같은 날의 0시부터
현재까지 `alpha=0.5, adjust=False` 지수평활한 뷰를
만든다. 두 뷰의 각 행에 동일한 `sub_ec` 정답을 붙이고
각각 0.5 가중치로 ExtraTrees를 적합한다. 환기·팬
등 구동기와 원본 출력 라벨은 바꾸지 않는다. 검증
입력은 **원본만** 쓴다. 비교용 ExtraTrees는 동일한
학습일·동일한 시드에서 원본 뷰만 적합한다.

두 ET 차이를 저장 v2 OOF에 원래 구성원 경로의 비율
`0.8×0.6×0.5=0.24`로 반영한다. 즉 후보는
`v2 + 0.24×causal_shrink(ET_dual−ET_raw)`로 정하고
학습 정답 범위로 자른다. 0.5는 ET 내부에서 원본
효과 절반을 유지하는 고정 혼합이다. 저장 v2가 범위
절단 경계에 닿은 행이 있으면 델타 근사는 성립하지
않으므로 점수를 내기 전 중단한다. 시드 7·101을
각각 같은 3시드 앙상블 v2와 비교하고 평균 후보도
기록한다. 새 시드를 보고 비율을 바꾸지 않는다.

여섯 공개 OOF 폴드 0·2·4·6·8·9에서 원래 분할의
학습일을 사용하되 최종 잠금 40일과 각 ±1일을 두 ET의
학습에서 공통 제외한다. 저장 v2는 과거 학습으로 잠금일
라벨을 포함했을 수 있으므로 이것은 **탐색 선별**이고
완전히 독립적인 확인이 아니다. 두 ET 간 차이는 같은
정답·학습일에서 계산한다. 학습 행 특징은 공개
`train_X`만으로 만들며 `test_X`를 합치지 않는다.

## 중단 및 후속 검증

각 시드의 여섯 폴드 모두 v2보다 RMSE가 엄격히
낮고, 두 농장도 각 시드에서 개선하며, 하루 단위
20,000회 재표집(시드 2909) MSE 차이 95% 상한<0이면
다음 검증으로 간다. 하나라도 실패하면 H8 기각, 평활
상수·뷰 가중치·ET 혼합률을 재탐색하지 않는다.

선별 통과 시 A/B/DIAG10×두 시드의 모든 칸 개선,
DIAG10 `p_worse<0.025/8`, EXT10·EXT12 무악화를
요구한다. 이어 미사용 시드와 잠금 40일 단 한 번의
새 기초 모델 재학습 확인, 미래 입력 교란·온실 격리·
결정성 검사를 한다. 후속 실행 계획은 별도 실행 전
커밋한다. 온도·비공개 정답·공식 점수·평가 입력 통계를
사용하지 않으며 제출 파일을 만들지 않는다.
