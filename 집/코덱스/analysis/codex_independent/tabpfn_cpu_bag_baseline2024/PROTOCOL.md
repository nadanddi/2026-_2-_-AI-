# EC 기존 제출의 세 번째 시드 교차 확인 — 실행 전 계획

원래 3회차 EC 제출 구성은 기준 모델 시드 7·101·2024를 평균한다.
앞선 CPU 네 문맥 검증은 기준 시드 7·101만 사용했다. 이미 저장된
TabPFN 네 문맥 예측(시드 1~4)을 변경하지 않고, 기존 기준 모델의
남은 시드 2024를 같은 탐색 폴드 0·2·4·6에서 새로 적합해 비교한다.

각 폴드의 고정 혼합은 기준 모델 원시 출력 80% + TabPFN 평균 20%,
당일 인과적 수축 0.5, 훈련 EC 범위로 제한한다. 사전 확인 기준은
네 폴드에서 시드 2024의 RMSE가 모두 감소하는 것이다. 평균 감소율과
온실별 효과도 기록하지만 이를 보고 혼합 비율이나 문맥 시드를 바꾸지
않는다. 확인용 폴드 8·9와 인접일, test_X는 사용하지 않는다.

이 시험은 모델 시드 변화의 재현성을 더 살펴보는 것이며, 이미 여러
설정을 검토한 공개 자료이므로 독립적인 최종 유의성 검정이 아니다.
