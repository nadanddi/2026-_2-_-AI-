# H4: 따뜻한 불일치 행에서만 TabPFN 쪽으로 이동

2026-09-29 실행 전 등록. 기준은 저장된 EC v2 예측이다.

D5에서 3회차 저장 예측 `b`와 TabPFN 4문맥 평균 `t`의
현재행 차이 `|b−t|≥0.15`인 646행은 v2 오차제곱의
47.9%였다. 이 구간에서 `t`가 v2보다 양 농장·5/6폴드에서
좋았지만, 현재 `in_temp<10℃`에서는 반대로 나빴다.
고값/밀폐 여부의 사후 정답을 쓰지 않고, **예측 불일치와
현재 실내온도**만으로 불확실성이 큰 따뜻한 행을 구분한다.

## 단일 후보

해당 행의 3회차 저장 예측 `b`, TabPFN 문맥 평균 `t`,
원래 혼합 출력 `p=v2`, 현재 `in_temp`를 사용한다.

`g = (|b−t|≥0.15) & (in_temp≥10)`

`p_H4 = 0.75p + 0.25t` if `g`, otherwise `p_H4=p`.

수축 후 v2와 원시 `t`의 **출력 수준에서** 결합한다.
기존 v2의 원시 멤버 혼합식을 대체하지 않는다. 별도
범위 제한을 추가하지 않는다. 불일치 문턱 0.15는 D5
사전 기준이며, 10℃는 이전 EC 외삽 위험 분기다.
추가 비중 0.25는 한 가지 고정 후보로만 시험한다.
폴드·농장·밀폐·정답·평가 입력 분포에 따라 바꾸지 않는다.

`b`, `t`, `p`는 해당 행의 현재·과거 입력만으로 나온
예측이고 `in_temp`도 현재행 값이다. 평가 시 미래
입력·다른 온실 입력·`test_X` 통계가 없다.

## 단계와 중단 기준

먼저 기존 공개 OOF 6폴드(0·2·4·6·8·9) 3시드
평균 v2 예측에 이 식을 적용한다. 6개 폴드와 양 농장
각각 RMSE 엄격 개선, 하루 단위 20,000회 재표집
(시드 2906)의 MSE 차이 95% 상한<0을 **모두**
만족하면 다음 단계로 간다. 하나라도 실패하면 H4를
기각하고 문턱·온도·비중을 조정하지 않는다.

선별 통과 시 A/B/DIAG10 각 ≥2시드의 모든 칸에서
v2보다 개선, DIAG10 각 시드의 `p_worse<0.00625`
(캠페인 H1~H4 네 후보를 보수적으로 셈), EXT10·EXT12
각 시드 무악화를 요구한다. 이후 한 번도 사용하지 않은
시드와 최종 잠금 40일을 단 한 번 확인하고 미래 입력
교란·온실 격리·결정성 검사를 한다. 후속 실행 계획은
실행 전에 별도 커밋한다. 기존 OOF 모델은 잠금일
라벨을 학습에 사용한 적이 있으므로 이번 선별은 완전
독립 시험이 아니며, 최종 확인 모델은 잠금일±1일을
학습에서 제외해 새로 적합해야 한다.

온도 모델·제출 파일은 만들지 않는다. 비공개 정답 및
리더보드 점수는 사용하지 않는다.
