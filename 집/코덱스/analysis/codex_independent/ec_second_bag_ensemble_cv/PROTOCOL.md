# 두 번째 문맥 묶음의 실제 세 시드 평균 구성 — 사후 진단

문맥 5~8의 개별 기준 시드 12개 비교가 끝난 뒤 수행하는 **탐색
진단**이다. 이미 결과를 본 자료이므로 독립 확인이라고 부르지 않는다.
문맥 5~8 예측과 정확 입력별 기준 모델 원시 예측 캐시를 이용해,
실제 후보 구조인 기준 시드 7·101·2024의 원시 평균과 TabPFN
20% 혼합을 네 탐색 폴드에서 재계산한다. 첫 문맥 1~4의 같은
구성도 행별로 비교한다. 비율·수축·범위 제한은 고정한다.

폴드별·합산 RMSE, 온실별 결과, 개선일 비율 및 5일 묶음
재표집 구간을 보고한다. 이 결과로 현재 로컬 후보의 문맥 묶음,
혼합 비율 또는 확인 구간의 사전 기준을 바꾸지 않는다.
확인용 폴드 8·9와 test_X는 사용하지 않는다.
