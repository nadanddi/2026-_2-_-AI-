# D6: H4·H6이 공통으로 실패한 폴드 0의 반례 구조

2026-09-29 실행 전 등록. H4는 전체 −3.27%, H6의
편향 가능한 선별은 전체 −6.21%였으나 둘 다 폴드 0
악화로 기각됐다. 이 진단은 **왜 폴드 0이 반례인지**
살피며 새 점수 규칙이나 H4/H6 재판정을 만들지 않는다.

공개 OOF 폴드 0의 각 농장-날에 대해 H4 변경 행수,
v2와 H4의 제곱오차 차이, 정답·예측 하루 평균,
변경행의 현재 `in_temp`·`act_circfan`·`act_vent`
평균, `t−b` 부호를 기록한다. 다른 다섯 폴드도
동일 집계를 하여 폴드별 손해 날 수와 상위 손해 1·2일의
몫을 보고한다. H4는 저장 예측에 프로토콜의 같은
식 `|b−t|≥0.15 & in_temp≥10`, 변경행에서
`0.75·v2+0.25·t`를 그대로 재적용한다. H6은
재구성하지 않고 기존 결과의 폴드 0 악화만 참고한다.

다음 방향을 정하는 사전 해석 기준:

- 폴드 0 순손해의 80% 이상이 1~2일에 집중되면
  소수 반례 위험으로 기록하고, 그 날짜 ID만 피하는
  가설을 만들지 않는다.
- 3일 이상에서 손해가 분산되고 공통 현재 입력 체제가
  있으면 그 체제를 새 입력 신호 후보로 검토하되,
  별도 사전 가설과 독립 검증이 필요하다.
- 입력 체제가 구별되지 않으면 관측되지 않은 관수·급액
  등 하루 수준 원인 가능성을 높게 보되 단정하지 않는다.

최종 잠금일의 정답, `test_X`, 비공개 정답 및 공식
점수는 읽지 않는다. 제출 파일을 만들지 않는다.
