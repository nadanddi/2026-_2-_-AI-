# 자정 저온일 EC 학습 가중치 — 사전 탐색 규칙

작성 2026-09-29, 결과 실행 전. F13·F47의 공개 학습 400일 중
0시 실내온도 ≤10℃는 80일(20%), 평가 입력은 60일 중 27일(45%).
이 관측 분포 이동을 반영해 3회차 ExtraTrees 구성원의 해당 **학습
날 전 행**에 표본 가중치 2, 나머지는 1을 준다. 문턱과 배수는
이 한 가지로 고정하고 결과 후 조절하지 않는다. 온실별 같은 날
0시 입력만 사용하므로 인과적이다. 평가 입력은 모델 학습에
사용하지 않는다. LightGBM·MLP·TabPFN은 기존 v2 그대로 둔다.

기존 EC v2의 탐색 집합 DIAG10 폴드 0·2·4·6, 기준 시드
7·101·2024의 12칸을 기존 저장 예측 및 같은 분할과 비교한다.
새 모델은 ExtraTrees만 재학습하고, 다른 멤버는 같은 입력 해시의
저장된 예측을 사용한다. 사전 탐색 통과 조건: 12칸 전부 RMSE
개선, 전체 합산 ≥1% 개선, F13·F47 각각 개선. 이 중 하나라도
미달이면 추가 확인 폴드 8·9는 보지 않고 기각한다.

탐색 통과하더라도 채택은 별도. 고정 확인 폴드 8·9,
A/B/DIAG10 및 추위 외삽 검증을 추가해 모든 시드×검증기 방향
일치와 DIAG10 p_worse<0.025 조건을 만족해야 한다. 공개 검증
자료는 여러 이전 가설에 재사용됐으므로 단일 개선을 확증으로
해석하지 않는다. 제출 파일은 만들지 않는다.
