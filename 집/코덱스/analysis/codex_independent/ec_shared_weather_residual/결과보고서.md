# 같은 외부 날씨 날짜군의 EC 잔차 동행성: 근거 없음

2026-09-29. 사전 `PROTOCOL.md`대로 공개 학습 입력의 24시간
외부 온도·일사 벡터가 정확히 같은 날을 묶고, EC v2의 저장된
공개 OOF 234일 잔차를 비교했다. 두 농장 모두에 OOF가 있는
날씨 날짜군×전후반 셀은 **44개**, 전반 42개·후반 **2개**였다.

농장×구간 평균을 제거한 일잔차의 F13–F47 상관은 전체
**0.0045**, 전반 **−0.161**이었다. 후반은 두 셀뿐이라 상관을
정의할 수 없다. 잔차 부호 일치율은 50%, 구간 안에서 F47
날짜군을 섞는 1만 회 단측 순열 비율은 **0.857**이었다.
사전 진행 조건(공통 30셀 이상, 전체 상관 ≥0.35, 후반 8셀
이상·양의 상관, 순열 <0.01)을 충족하지 못했다.

F13 178일과 F47 177일처럼 큰 EC가 함께 나타난 일부 사례가
있어도, 그것만으로 다른 날짜에 공유 보정 규칙을 적용하면
사후 선택에 의존한다. 정확히 같은 외부 날씨로 정의한 **이
가설은 기각**하고 역사적 다른 농장의 EC 라벨을 가져오는
특징을 만들지 않는다. 더 느슨한 날씨 매칭이나 다른 날짜군
정의까지 부정하는 증거는 아니다. 전체 24시간 벡터는 진단용으로만
사용했으며 평가 입력·비공개 정답은 읽지 않았다.

수치·입력 해시: `analysis/local/ec_shared_weather_residual/`의
실행 결과 JSON.
