# H6: 훈련 OOF에서 구성원 신뢰도를 학습한 EC 보정

2026-09-29 실행 전 등록. 비교 대상은 EC v2다.

D5에서 3회차-TabPFN 큰 불일치가 오차의 47.9%를
차지했고 따뜻한 불일치에서는 TabPFN이 더 나았다.
H4의 고정 게이트는 전체 −3.27%였으나 한 폴드에서
악화해 기각됐다. H5 문맥 중앙값도 실패했으므로
불일치의 원인은 단일 극단 문맥보다 **행별 두 모델의
상대 신뢰도**에 가까울 수 있다. H6는 문턱을 다시
고르는 대신, 현재행 입력·예측만으로 작은 조건부
선형 보정을 학습한다.

## 단일 모델

현재행 v2 출력 `p`, TabPFN 네 문맥 원시 평균 `t`,
문맥 표준편차 `s`, 현재 실내온도 `T`, 팬 `F`, 환기 `V`를
쓴다. `d=t−p`라 할 때 잔차 학습 설계행은 다음 5열이다.

`[d, d·1(T≥10), d·1(F<10 & V=0), d·1(p≥0.6), d·s]`

절편 없이 `y−p`를 목표로 Ridge를 적합한다. 각 열은
학습 행의 날 균등 가중 RMS로 **나누기만** 하고 평균
중심화하지 않는다. 가중치는 행당 `1/24`, Ridge
`alpha=50`; 표준화 RMS가 1e−12 이하이면 1로 둔다.
계수는 `XᵀWX + 50I`의 해이며 난수는 없다. 후보는
`p_H6 = p + clip(Xβ,−0.25,+0.25)`이다. `d=0`이면
보정도 0이다. 다른 열·가중치·범위를 결과에 맞춰
바꾸지 않는다.

## 선별의 정보 경계

저장된 공개 OOF 여섯 폴드 중 하나를 검증하고 나머지
다섯 폴드 OOF로 위 Ridge를 적합하는 6회 교차 적합을
한다. 각 행의 원래 v2는 그 행의 정답을 보지 않은
모델의 예측이다. **하지만 다른 폴드의 v2 모델은
현재 검증 폴드의 정답을 학습했을 수 있다.** 따라서
이 재사용은 낙관 편향 가능성이 있는 **선별**이지
정직한 외부 검증이 아니다. 선별 통과 시 기존 예측을
근거로 채택하지 않고, 각 외부 폴드 안의 학습일만으로
내부 OOF와 결합기를 새로 만드는 중첩 재학습을
별도 프로토콜로 커밋한다.

선별은 여섯 폴드와 양 농장의 RMSE가 모두 엄격 개선,
하루 단위 재표집 20,000회(시드 2908) MSE 차이
95% 상한<0을 모두 요구한다. 실패하면 H6 기각;
Ridge 강도·열·클립을 조정해 다시 쓰지 않는다.

중첩 검증까지 통과한 경우에만 A/B/DIAG10 각 ≥2시드
모든 칸 v2 개선, DIAG10 각 `p_worse<0.025/6`,
EXT10·EXT12 각 시드 무악화, 미사용 시드·새 잠금
40일 단 한 번, 인과성·격리·결정성을 요구한다.
각 단계 실행 계획은 먼저 커밋한다.

현재행 예측·입력과 같은 날 과거 입력만 허용한다.
`test_X` 통계·비공개 정답·리더보드 점수를 쓰지
않고 온도·제출 파일은 건드리지 않는다.
