# EC 기준 재현 — 실행 전 계획

현재 연구용 EC 기준 구현이 플랫폼 3회차 제출
`research/submissions/submission_04.csv`의 EC 열과 실제로 같은지
확인한다. 원본 제출물과 학습자료는 읽기만 한다. 같은 학습행,
특징 14+24개, 모델 종류·하이퍼파라미터, 시드 7·101·2024의
단순 평균, 당일 수축 0.5, 훈련 EC 범위 제한을 사용한다.

원본 CSV는 소수점 6자리이므로 동일 row_id 순서에서 예측을
6자리로 반올림해 전 행이 같은지 검사한다. 일치하지 않으면
최종 후보 조합을 만들기 전에 차이를 추적한다. test_X 정답은
읽지 않고 원본 CSV 파일을 수정하지 않는다. 기준 예측은 새
로컬 파일에 저장해 추후 TabPFN 혼합의 정확한 기준으로 쓴다.
