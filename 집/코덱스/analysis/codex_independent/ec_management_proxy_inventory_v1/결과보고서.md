# EC 관리·수분 상태의 간접 입력 목록

2026-09-29 집 코덱스. 새 모델은 학습하지 않고 기존 D8·D9·H18~H22와
공개 OOF 고EC 진단 결과를 재검토했다. 최종 잠금 40일 미채점.

| 입력·파생 특징 | 간접 반영할 수 있는 상태 | 실제 확인 수준 |
|---|---|---|
| `in_temp`, `in_hum`, `out_temp`, `out_hum`, `act_vent`로 계산한 절대습도 차이·환기 수분 배출 | 증산·수분 이동·건조 | H20: v2 대비 −1.48/−1.11% 평균이나 개선 폴드 3/6·2/6, 다중비교 기준 실패. 가장 유망한 약한 추가 신호이나 후보 아님 |
| `act_vent`, `act_circfan`의 현재·누적 운전 | 밀폐/환기·수분 방출 운영체제 | 공개 OOF 고EC 19일 중 밀폐 12일, 보통EC 215일 중 27일. 하루 전체 밀폐는 진단 전용, 두 입력 자체는 v2에 이미 포함 |
| `in_temp`, `in_hum`, `out_rad`, `out_wspd`, `act_heating` | 증산 구동력·난방·운영 시간표 | 물리적 연결은 있으나 D8 0~6시 평균 난방량의 v2 잔차 부분상관 r=−0.1644, 14개 신호 보정 p_max=.1569로 추가 신호 불확실 |
| `act_co2`, `in_co2`의 공급 반응 | 운영 상태·식물 흡수의 간접 흔적 | H22: 유효 52/234일, 평균 −0.29/−0.36%이나 3/6·2/6폴드만 개선. H19 무공급 CO₂ 감소는 +0.14% 악화 |
| 0시 입력·당일 누적 구동기·출처 연결 | 서로 다른 운영자·온실의 관수 관행 대리 | v2 기본 특징에 일부 포함. H18 전환·H21 이전 수분·H13/14 출처 전문가는 안정적 추가 예측력 미확인 |
| `act_fog` | 실내 공기 가습·냉각 | 뿌리 급액량이나 배액량이 아니다. H20 수분수지에 보조 입력으로 사용 |
| `act_pump`, `act_valve`, `in_rad`, `act_side`, `act_cool` | 펌프·밸브는 직접 관수에 가장 가까울 수 있음 | D9: F13·F47 각 4,800행에서 다섯 열 전부 비결측 0/4,800. 사용 불가 |

증산은 일사·온도·습도·공기 흐름의 영향을 받으므로 이 입력들은 수분 이동의
대리변수로 물리적 근거가 있다. 그러나 공급 양액의 EC·양, 배액 EC·양, 배지
함수율은 제공되지 않는다. 현재 입력으로 관수량을 직접 복원했다고 주장하지 않는다.
특히 밀폐와 고EC의 연관은 인과성이 아니며, 하루 전체 운영 요약을 미래 시각의
EC 예측 특징으로 쓰는 것은 규정 위반이다.
