# EC 후반 검증일과 평가 입력의 체제 차이 — 진단 계획

2026-09-29. 기존 EC v2 공개 OOF 234일(탐색 0·2·4·6,
확인 8·9)을 하루 단위로 묶는다. 입력만으로 정의한 밀폐 날은
하루 순환팬 평균 <10이고 환기 0인 시각 비율 >0.85이다.
저온 날은 0시 실내온도 ≤10℃. F13·F47 각 농장별로 전반·후반
OOF의 날 수, 밀폐·저온 비율, EC RMSE의 하루 수준/시간 안
분해를 출력한다. 후반의 **전체 라벨일**과 평가 입력 60일의
체제 분포도 입력만으로 비교한다.

판단 질문: 후반 OOF에 평가의 어려운 밀폐·저온 날이 충분히
있는가? 평가 밀폐 비율이 후반 OOF의 두 배 이상이면, 후반
OOF의 낮은 RMSE를 숨은 평가 정확도의 직접 추정치로 쓰지
않는다. 이 진단은 모델 채택 기준이 아니며, 밀폐 정의는 하루
전체 입력을 사용하므로 평가 예측 특징으로 쓰지 않는다.

평가 정답과 새 제출 파일은 사용하지 않는다.
