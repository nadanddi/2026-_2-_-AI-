# D11: D10 조기 수분 신호의 극단일·시간 블록 민감도

2026-09-30 집 코덱스. D10에서 선택된 `closed_rise_cum`의 부분상관은
이미 본 공개 자료의 사후 선택이다. 이 검사는 그 결과를 확증하지 않고
기작과 취약점을 진단한다. 실행 전 이 절차·코드를 main에 커밋한다.

같은 공개 OOF 234일의 매일 6시 `closed_rise_cum`, v2 6시 예측,
실제 하루 평균 EC를 사용한다. D10과 같은 공통 통제(절편, F47, 후반,
day, v2 예측·제곱)로 부분상관을 재계산한다. 비교는 다음을 고정한다.

1. 전체, D10 통제 후 잔차 절댓값 상위 5일 제외, 실제 고EC 19일 제외,
   F13/F47 각각, 전반/후반 각각의 부분상관.
2. 농장×전후반 안에서 day 정렬 5일 묶음을 만들고 3,000회 묶음 재표본
   (시드 300931)에서 통제변수를 다시 적합한 부분상관의 95% 구간.
3. 저장 H20의 시드 7·101에서 하루 평균 수정량과 v2 하루 평균 잔차의
   상관, 6시 수분 신호와 수정량의 상관을 계산한다. 수정 방향이
   관측된 잔차 방향과 맞는 비율도 보고한다.

최종 잠금 40일과 test_X는 읽지 않는다. H20 비중·특징·시드 및
기존 예측은 수정하지 않는다. 이 결과는 새 후보 채택 근거가 아니며,
특히 소수일 제외와 하위집단 분석은 D10 관찰 뒤의 민감도 검사다.
