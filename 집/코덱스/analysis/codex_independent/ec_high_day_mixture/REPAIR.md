# H3 첫 실행의 데이터 범위 수정

`run.py`는 실행 직후, 모델 적합이나 점수 계산 전에
`len(daily)==360` 무결성 검사에서 중단됐다. `train_y.csv`는
전체 온실 304,965행이고 EC 정답이 있는 F13/F47은
9,600행이다. 원본 코드는 잠금일을 제외했으나 F13/F47
필터를 빠뜨려 정답 없는 다른 온실이 `daily`에 남았다.

기존 `run.py`를 보존하고 `run_v2.py`에서 EC 대상 온실
필터와 9,600행·결측 없음 검사를 추가했다. H3 가설,
특징, 파라미터, 분할, 중단 기준은 `PROTOCOL.md` 그대로다.
이 수정 버전을 실행 전에 커밋한다.
