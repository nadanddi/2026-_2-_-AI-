# H3 두 번째 실행의 병합 열 수정

`run_v2.py`는 첫 폴드의 분류기 학습까지 완료했지만, 검증
특징을 합칠 때 이미 있던 `day` 열을 다시 가져와 pandas가
`day_x/day_y`로 바꾼 탓에 확률 예측 전 `KeyError`로
중단됐다. 모델 예측·점수·결과 파일은 생성되지 않았다.

`run_v3.py`는 검증 행에 이미 있는 `day`를 그대로 두고,
입력 테이블에서 나머지 특징만 합친 뒤 모든 특징 열을
확인한다. H3 가설과 하이퍼파라미터 및 사전 중단 기준은
그대로다. 사용한 스크립트는 수정하지 않고 새 버전을
실행 전에 커밋한다.
