# H20 / F4-2: 실내외 수증기 격차와 환기 배출로 추정한 증산 상태

2026-09-29 실행 전 등록. H19의 CO₂ 감소는 센서 잡음·기류에 섞여 고EC일에 도움이 되지 않았다. 수분은 CO₂와 다른 물리 흐름이다. 작물이 방출한 수증기가 실내에 쌓이거나 환기로 배출되는 정도는 급액 상태·증산과 관련될 수 있다. v2의 핵심 `FULL`에는 외기 온습도가 없으며, 과거 기각된 6.38의 단순 일사·VPD 누적과 달리 H20은 **실내외 수증기 농도 차×환기**와 밀폐 중 수분 증가를 질량수지 대리로 계산한다.

같은 F13/F47 기록 현재 날의 0~h 입력만 사용한다. 온도 T℃·상대습도 RH%에서 포화증기압 `6.112·exp(17.67T/(T+243.5))` hPa, 절대습도 `216.7·증기압·RH/100/(T+273.15)` g/m³로 계산한다. 현재행 실내−외 절대습도 격차 `gap`, `max(gap,0)·clip(act_vent/100,0,1)`을 환기 수분배출 대리 `flux`로 고정한다. 직전 시각 대비 실내 절대습도 증가의 양수 부분을 현재·직전 환기=0, 현재 포그=0인 때만 밀폐 수분축적 대리 `rise`로 둔다. 특징은 (1) 현재 `gap`, (2) 현재까지 `flux` 누적합, (3) 현재까지 `rise` 누적합 세 열이다. 결측 입력에서 계산 불가능한 값은 NaN으로 남기고 현재 날 h+1 이후·다른 온실·다른 날 EC 정답은 보지 않는다. 학습 특징은 `train_X`만으로 구축해 MASK(test_X=NaN) 조건을 지킨다.

동일 시드·학습일의 `FULL` 대조 ExtraTrees와 `FULL+수분 3열` ExtraTrees(`n_estimators=600`, `max_features=1.0`, `min_samples_leaf=1`, `n_jobs=4`, `random_state=seed`, 학습 중앙값 결측 대체)를 적합한다. 시드 7·101. 새 특징에 따른 두 예측 차이를 저장 v2에 고정 `0.24×` 반영하고 당일 현재까지 0.5:0.5 인과 수축한다. 두 단독 모델 RMSE도 보고한다. v2 출력에 따른 사후 확대/문턱은 없다.

저장 OOF 0·2·4·6·8·9에서 검증일과 잠금 40일 ±1일을 두 모델 학습에서 제외한다. 두 시드×6폴드·양 농장 전칸 v2보다 엄격히 개선하고 날 단위 20,000회 MSE 재표집 `p_worse<0.025/12`일 때만 A/B/DIAG10 ×두 시드, EXT10·EXT12 무악화, 미사용 시드·잠금 40일 1회, 미래 교란·온실 격리·결정성 검사로 진행한다. 고EC 19일/나머지 215일과 수분 flux가 있는 날/없는 날, 이른 시각의 오차를 분리한다. 실패 시 기존 VPD 누적 실패와 구별되는 수분수지 특징의 정보/센서 한계를 보고하고 수식·가중치·시드 재조정은 하지 않는다. 온도·제출 파일은 만들거나 수정하지 않는다.
