# D9: v2 핵심 특징에서 빠진 입력 채널의 가용성 감사

2026-09-29 실행 전 등록. 원본 `train_X` 헤더에는 `in_rad`, `act_side`, `act_valve`, `act_cool`, `act_pump`가 있지만 EC v2의 기본 ExtraTrees `FULL`은 이 다섯 채널을 사용하지 않는다. 급액·배액 관리 상태가 병목일 수 있으므로, 특히 밸브·펌프가 살아 있는 입력인지 **EC 정답이나 v2 잔차를 보기 전에** 입력만으로 확인한다.

F13·F47의 `train_X` 행만 읽는다. 각 채널×기록별 비결측 비율, 0이 아닌 비율, 서로 다른 유효 값 수, 일별 변동이 있는 날 수와 날별 최소·최대의 범위를 보고한다. `test_X`·정답·공식 점수는 읽지 않는다. 사전 진행 기준: 다섯 채널 중 하나라도 각 F13/F47 모두에서 유효 행≥10%이고 비영값이 존재하며, 적어도 한 기록에서 5% 이상의 날에 일내 값이 변하면 H18의 새 입력 후보로 진행한다. 아니면 `FULL` 밖의 다른 제공 열을 동일 규칙으로 별도 진단 등록한다. 이 진단은 가설 H 슬롯에 세지 않고, 모델 결과를 낸 뒤 입력 채널을 고르는 수단으로 사용하지 않는다.

원본 파일과 스크립트 해시·코드·입력 집계를 기록한다. 기존/제출 파일과 온도 모델을 수정하지 않는다.
