# EC v2 실행 전 고정 계획

## 가설

EC 기준 모델의 지문은 구동기의 당일 누적 이력을 포함하지만 실내 센서는
현재와 0시 값 중심이다. 원시 입력을 보존하면서 현재까지의 실내 센서 요약을
추가하면 잡음에 덜 민감하게 현재 관리 상태를 알아낼 수 있다는 가설이다.
기존 학습 입력을 평활값으로 교체한 실험을 반복하지 않는다.

두 후보를 고정한다. 둘 다 기준 모델의 ExtraTrees 입력에만 추가한다.

- `prefix_moments`: 실내 온도·습도·CO₂ 각각 현재까지의 평균, 표준편차,
  최솟값, 최댓값, 현재값-평균(총 15개).
- `prefix_robust`: 세 센서 각각 현재까지의 중앙값, 사분위범위,
  현재값-중앙값, 현재까지 관측 비율(총 12개).

모든 집계는 같은 온실의 같은 일차 0시부터 현재 시각까지만 적용한다.
통째 하루 평균이나 이후 시각을 사용하지 않는다. 범위와 결측 처리는
v1과 같고, 정답은 변경하지 않는다. 모델 구성·매개변수·후처리는 v1 기준선과 같다.

## 고정 탐색 규칙

v1의 폴드와 확인 제외 규칙을 그대로 재사용한다.
초기 탐색은 폴드 0·2 × 시드 7·101(후보마다 네 조합)이다.
기준 대비 상대 RMSE 감소가 네 조합에서 모두 양수이고 평균 1% 이상인 후보만
폴드 4·6 × 시드 7·101을 추가로 평가한다. 확장 후보가 없으면 이 가설군을 종료한다.
이는 계산 절약용 선별이지 유의성 검정이 아니다. 후보를 고르는 지표는
같은 폴드·시드 대조군 대비 상대 RMSE 감소 보상이다.

8개 조합 모두 개선하고 평균 1% 이상이어야 후속 검증 후보로 남긴다.
통과 여부와 무관하게 이번 실행에서는 확인용 폴드 8·9를 채점하지 않는다.
최종 채택에는 캠페인 전체 후보 수를 반영한 검정, A/B·DIAG10,
최신 후보와의 비교 및 끝단 인과성 검사가 추가로 필요하다.

## 산출물과 검사

실행 전 코드·계획·분할·원본 데이터·라이브러리 버전 해시를 기록한다.
미래·다른 온실 입력 교란, 행 순서, 실제 여러 접두 구간만 넣은 계산과의 일치,
모든 미래 값을 없앤 입력과의 일치를 검사한다. 기존 원시 특징은 변경하지 않는다.
각 폴드별 예측을 보존해 원인 분석과 검증에 사용한다. 확인 자료 결과는 생성하지 않는다.
기준 예측 캐시는 학습/검증 행과 특징값·정답·설정·실행 코드·환경 해시가 같은 때만 재사용한다.
캐시는 계산 절약이며 이전 점수를 새 독립 증거로 세지 않는다.
