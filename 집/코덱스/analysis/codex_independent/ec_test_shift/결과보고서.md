# 실제 평가 입력에서 EC 후보 예측의 이동

2026-09-28. 비공개 정답 없이 `test_X.csv` 1,440행에서 기존
미제출 안전 조합 `submission_07.csv`와 새 TabPFN 로컬 후보를
비교했다. 행 ID와 온도 1,440개 예측은 모두 동일했다. EC
예측의 새 후보−기존 조합 차이만 계산했으며 두 파일과 입력은
수정하지 않았다.

| 평가 입력 집합 | 행 수 | 평균 EC 변화 | 변화 RMS | 절댓값 0.05 초과 |
|---|---:|---:|---:|---:|
| 전체 | 1,440 | −0.00714 | 0.02750 | 8.8% |
| 비밀폐일 | 960 | −0.01066 | 0.01913 | 2.7% |
| 밀폐일 | 480 | −0.00010 | 0.03920 | 21.0% |
| F47 비밀폐일 | 552 | −0.00899 | 0.01667 | 1.8% |
| F47 밀폐일 | 168 | +0.00242 | 0.04784 | 36.3% |

가장 많이 변한 날 8개 중 6개가 밀폐일이다. 최대 행별 절대
변화는 F47 밀폐일에서 0.11247이다. 밀폐일 구분은 하루 전체의
입력을 사용한 **진단 전용** 값으로, 새 후보의 예측 특징이나
사후 게이트로 사용하지 않았다. 이 차이가 실제 정답 쪽으로
움직였는지는 알 수 없다.

기존 탐색에서 밀폐일 전체 개선은 거의 없었고 F47 밀폐일은
악화했다. 남겨둔 확인 구간에서는 밀폐일이 소폭 개선됐지만
F47 밀폐일은 단 5일이었다. 평가 입력 F47 밀폐일은 7일이며,
여기서 후보와 기존 조합의 차이가 특히 크다. 따라서 공개
검증의 전체 −3.22% 개선을 실제 평가에 그대로 옮겨 기대하기
어렵다. 결과는 `analysis/local/ec_test_shift/`의 새 실행 폴더
`result.json`에 저장했다. 비공개 정답과 플랫폼 점수는 읽지
않았고 후보 파일도 변경하지 않았다.

## 확인 구간과의 이동 크기 비교

기존 확인 폴드의 저장 예측에서는 정답 열을 읽지 않고
`후보−기준` 차이만 새로 계산했다. 확인 1,920행에서는
평균 **+0.00902**, RMS 0.02277이었으나 평가 입력에서는
평균 **−0.00714**, RMS 0.02750이다. 즉 평균 이동 방향이
반대이고 평가 입력의 변화 RMS가 1.21배 크다. 밀폐일만 보면
확인 0.02860 대비 평가 0.03920으로 1.37배, F47 밀폐일은
0.03511 대비 0.04784로 1.36배다. F47 밀폐일의 `|변화|>0.05`
비율도 확인 13.3%에서 평가 36.3%로 높다.

이는 후보가 평가 입력, 특히 검증 근거가 약한 밀폐일에서 더
크게 움직인다는 경고다. 이동 방향 반전만으로 오차가 나빠진다고
단정할 수는 없다. 비공개 정답을 사용하지 않았고, 이 결과를
보고 후보 비율이나 예측을 조정하지 않았다. 상세 비교 결과는
`analysis/local/ec_test_shift_confirmation_comparison/`의 새
실행 폴더에 저장했다.
