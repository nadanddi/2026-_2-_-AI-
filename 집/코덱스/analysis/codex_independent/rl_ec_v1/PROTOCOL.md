# EC 보상 기반 탐색 v1 — 실행 전 고정 계획

2026-09-27. 실제 실행 전에 작성. 원본·기존 제출물은 변경하지 않는다.

## 범위

단일 상태 다중 선택 밴딧(UCB)을 사용해 EC 학습 설정을 선택한다. 이는
보상 기반 실험 선택이며 PPO/DQN이나 온실 제어 정책 학습은 아니다.
온도 모델 변경과 플랫폼 제출은 이번 실험 범위에서 제외한다.
기존 3회차 EC 구성(ET600 60%, Tweedie800 30%, MLP 10%, 당일 누적 수축)을
동일 분할·동일 시드로 다시 학습해 대조군으로 사용한다. TabPFN 포함 최신
후보보다 우수하다는 결론은 이 실험만으로 내리지 않는다.

## 미리 고정한 선택지

1. `leaf4`: ExtraTrees 최소 말단 표본 수 1 → 4. 나머지 유지.
2. `daybag`: ExtraTrees를 온실·일 단위 복원추출 8묶음 × 75트리 평균으로 교체.
   하루의 24시간을 독립 표본처럼 취급하는 문제를 완화하는 가설.
3. `l2fp`: Tweedie 구성원만 같은 현재·과거 지문을 받는 L2 LightGBM으로 교체.
   EC의 평가 손실과 학습 손실을 맞추는 가설. 다른 구성원 유지.

## 탐색과 확인 분리

- 기존 DIAG10의 온실별 5일 묶음 배정 규칙을 복제한다.
- 8·9번 폴드의 정답은 탐색 학습/보상 모두에서 제외하고 마지막 확인에만 사용한다.
- 확인일 앞뒤 하루도 탐색에서 제외한다. 내부 탐색은 남은 자료의 0·2·4·6번
  폴드, 시드 7·101을 순서대로 사용한다(총 8개 환경).
- UCB 12회. 처음 각 선택지를 한 번씩, 이후 평균 상대 RMSE 감소 보상과
  탐색 항으로 선택한다. 동일 선택지·동일 환경을 중복 보상으로 세지 않는다.
- 최상 후보 하나는 8개 환경을 모두 평가한 뒤 잠근다. 이 보완 평가에서
  실패해도 다른 후보로 갈아타지 않는다. 모든 환경에서 개선해야 확인 통과
  가능하다. 평균 보상 <= 0이면 중단한다.
- 잠근 후보만 시드 7·101로 확인 폴드 8·9 각각 재학습·평가한다.
- 확인 네 조합 전부 개선, 시드 평균 예측의 풀링 RMSE 1% 이상 감소,
  짝지은 온실·5일 블록 부트스트랩 98.333% 구간 상한 < 0이 모두 필요하다.
  세 후보에 대한 보수적인 Bonferroni 보정이다. 행 단위 독립 부트스트랩 금지.
- 과거 연구에서 공개 정답 전체가 이미 쓰였으므로 이 확인 자료는 이 실행에만
  미사용이다. 완전히 새로운 독립 평가 자료라고 부르지 않는다. 통과해도
  DIAG10 전체·A/B·최신 TabPFN 후보 비교 및 최종 인과성 검사 전에는 채택하지 않는다.

## 누출·재현 방지

학습 특징은 train_X만으로 생성한다. 검증도 온실·일 단위이며 특징이 날을
넘지 않으므로 검증 입력이 다른 학습일의 특징으로 들어가지 않는다.
정답은 특징에 넣지 않는다. 현재 값, 정확히 0시 값(결측 유지), 현재까지의
누적 구동기 평균/0 비율만 사용한다. 입력 정제나 채점 행 제거는 하지 않는다.
전처리와 범위 제한은 각 학습 분할에만 맞춘다. 시드 선택 금지.
미래 입력 변조, 다른 온실 변조, 행 순서 변경, 결측 0시의 역방향 채움 방지,
검증일 버퍼/분할 격리, 기존 지문 구현 일치 검사를 수행한다.
