# EC 네 문맥 후보 — 끝단 규칙·재현 검사 사전 계획

탐색 폴드에서 선택을 마친 기존 TabPFN v2 네 문맥(시드 1~4, 각 2,000행,
CPU float32, n_estimators=4)을 실제 배포 입력 구조에 맞춰 검증한다.
train_X와 train_y의 F13·F47 공개 학습행만 문맥으로 사용하고, test_X의
정답은 읽지 않는다. test_X 입력을 학습 특징에 결합하지 않는다.

우선 train/test의 온실·일 중복 여부, test_X 행의 완전성, 특징 열 순서,
원본 순서와 섞인 순서의 특징 일치를 확인한다. test_X의 각 온실에서
여러 시간 절단점 뒤 입력을 큰 값/결측으로 교란해 이전 행의 특징이
비트 단위로 불변인지 확인한다. 다른 온실 전체 교란도 확인한다.
훈련 특징은 어떤 test_X 교란에도 변하지 않아야 한다.

그 다음 네 문맥 모델을 각각 적합해 원본 1,440행 예측과 역순 배치
예측을 비교한다. 각 문맥의 같은 행 예측은 비트 단위로 같아야 한다.
한 절단점의 미래 입력 교란에 대해 네 모델을 다시 예측해 절단점 이전
예측이 각각 불변인지 확인한다. 문맥1은 독립 재적합을 한 번 반복해
결정성을 확인한다. 최종 네 문맥 평균과 기존 EC 기준 예측의 인과적
수축에 대해서도 저장된 행/특징 불변성을 확인한다.

어느 항목이라도 실패하면 최종 패키지로 채택하지 않는다. 수치 허용오차
없이 동일성을 검사하되, NaN은 같은 위치에서 같게 취급한다. 이 검사는
규칙 준수와 실행 재현성에 대한 것이며 숨겨진 RMSE 향상을 증명하지
않는다. 원본 자료와 기존 제출물은 수정하지 않고, 결과는 새 로컬
체크포인트에만 저장한다. 오프라인 로컬 모델 가중치만 사용한다.
