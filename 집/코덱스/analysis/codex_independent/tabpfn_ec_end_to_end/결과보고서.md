# EC TabPFN 네 문맥 — 실제 평가 입력 끝단 검사

2026-09-28. 대회 문제설명서 5절(평가 행에는 같은 온실의 현재·이전
입력만 사용)과 8절(최종값 재현)에 맞춰 CPU 최종 후보의 특징 생성부터
모델 예측과 당일 수축까지 확인했다. test_X 1,440행, 60일은 모두
24시간 완전일이었고 train_X의 온실·일과 겹치지 않았다.

`features_check.py`는 train_X로 만든 학습 특징 9,600행과 test_X로
만든 평가 특징 1,440행이, 둘을 결합해서 계산한 특징과 같은지
확인했다. 평가 행 순서를 섞어도 같았다. F13·F47 각각 네 절단점
뒤의 입력을 크게 교란하고 일부를 결측으로 만들었을 때 이전 행의
38개 특징은 비트 단위로 같았다. 다른 온실 입력 전체를 바꿔도
해당 온실 특징은 같았다. 결과:
`analysis/local/tabpfn_ec_end_to_end/20260928_021653/features_result.json`.

`model_check.py`는 로컬 TabPFN v2 회귀 가중치, CPU float32,
문맥 2,000행씩 시드 1·2·3·4를 사용해 실제 평가 행을 예측했다.
네 문맥 각각에서 원래 순서와 역순 배치 예측이 비트 단위로 같았고,
F13의 중간 절단점 뒤 360행의 입력을 교란해도 그 앞 360행의
예측은 같았다. 문맥 1의 독립 재적합 결과도 전 행 동일했다.
네 문맥 평균과 당일 누적 수축 뒤의 앞선 예측도 불변이었다.
네 문맥 모델 적합과 13개 예측 호출은 약 3,398초에 종료 코드 0으로
완료됐다. 문맥별 체크포인트와 최종 평균은
`analysis/local/tabpfn_ec_end_to_end/20260928_022031/`에 있다.

미래 입력을 바꾼 **모델 예측** 검사는 F13의 한 절단점에서 실시했다.
F13·F47 네 절단점과 다른 온실 교란은 **특징 단계**에서 검사했다.
모델의 행 순서 독립성과 앞선 특징 불변성을 합쳐 나머지 절단점의
인과성을 뒷받침하지만, 모든 가능한 입력 조합을 전수 검사한 것은
아니다. 비공개 정답을 읽거나 RMSE를 계산하지 않았다. 규칙·결정성
검사를 통과한 것이 숨겨진 성능 개선을 보증하지 않는다.

로컬 사전학습 가중치의 위치와 SHA-256은 `가중치_출처_메모.md`에
기록했다. 원본 제출 기준 모델이 독립 구현과 일치하는지, 세 번째
기준 시드에서도 개선하는지 확인하기 전에는 최종 제출 구성으로
채택하지 않는다.
