# EC TabPFN 두 번째 독립 문맥 묶음 — 실행 전 계획

원래 `web_tabpfn_v2.py`가 미리 정한 두 번째 문맥 묶음 시드
5·6·7·8을 CPU float32에서 재생성한다. 첫 묶음 1·2·3·4의
성과가 문맥 표본 운인지 확인하는 목적이며, 비율과 모델 설정을
다시 고르지 않는다. 각 문맥은 해당 훈련 폴드에서 EC 정답
2,000행을 비복원 균등 추출, ModelVersion.V2,
n_estimators=4, CPU float32. 네 예측의 단순 평균을 20%로
혼합하고 기존 EC 기준 원시 출력 80%, 당일 인과적 수축 0.5,
훈련 범위 제한을 그대로 사용한다.

탐색 폴드 0·2·4·6, 기준 시드 7·101·2024의 12개 비교를
모두 기록한다. **사전 확인 기준**은 12개 전부 RMSE가 감소하고
상대 감소율 단순 평균이 1% 이상인 것이다. 첫 묶음과 직접 비교해
어느 묶음이 더 좋은지도 보고하지만, 결과를 보고 최종 묶음이나
비율을 선택하지 않는다. 통과하지 못하면 현재 후보의 문맥 시드
안정성에 의문이 있다는 결론을 기록한다.

확인용 폴드 8·9와 인접일은 학습·평가에서 제외하고, test_X와
비공개 정답은 읽지 않는다. 공개 정답 전체가 과거 연구에서 이미
검토됐으므로 이 시험은 완전 독립 검증이 아니다. 문맥별 예측을
체크포인트로 저장하며 정확한 입력·코드·분할 해시와 행 ID가
맞을 때만 재사용한다. 외부 다운로드·원격 추론은 사용하지 않는다.
