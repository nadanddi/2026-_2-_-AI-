# H9: 학습 정답이 높은 날의 ExtraTrees 손실 비중

2026-09-29 실행 전 등록. D1에서 공개 OOF 234일 중
실제 하루 평균 EC≥1.2인 19일이 v2 제곱오차의 74.2%를
차지하며 평균 잔차는 +0.450이었다. H1의 **출력 고값
일괄 확대**와 H3의 **고EC일 분류확률 보정**은 폴드
간 방향이 달라 기각됐다. 카탈로그 6.65의 밀폐일
가중치는 학습 정답을 보지 않고 입력상 밀폐일을
2·3배로 셌으며 실패했다. H9는 고EC를 이미 아는
**학습일에 한해서** ExtraTrees의 제곱손실 비중을
높여 고EC 지도 신호를 더 보존할 수 있는지 보는
서로 다른 단일 가설이다. 평가일 정답·고EC 여부는
특징이나 게이트에 쓰지 않는다.

## 고정 단일 후보

각 학습일의 24시간 `sub_ec` 평균≥1.2이면 그날
24행의 `sample_weight=2`, 아니면 1이다. EC v2의
3회차 ExtraTrees 구성원과 동일한 `FULL` 특징,
600개 트리, 최소 잎 1, `max_features=1.0`,
시드 7·101을 쓴다. 같은 학습일·시드의 원래 ET와
고EC 가중 ET를 적합한다. 검증 입력은 동일하며
후보는 `v2 + 0.24×causal_shrink(ET_weighted−ET_raw)`를
학습 정답 범위로 자른다. 0.24는 원래 v2에서 ET
경로 비율 0.8×0.6의 절반이다. 기존 v2가 범위
절단 경계에 닿은 행이 있으면 델타 근사가 성립하지
않아 점수를 내기 전에 중단한다. 문턱·가중치·혼합률을
결과에 맞춰 바꾸지 않는다.

원래 6개 공개 OOF 폴드(0·2·4·6·8·9)의 검증일과
최종 잠금 40일±1일을 두 ET 학습에서 공통 제외한다.
기초 v2 저장 예측은 과거에 잠금일 라벨을 학습했을
수 있으므로 이번 비교는 탐색 선별이다. `train_X`
원본으로만 학습·검증 특징을 만들고 `test_X` 통계와
비공개 정보는 사용하지 않는다.

## 선별·후속 기준

시드별 6폴드와 양 온실 각각 RMSE가 v2보다 엄격히
작고, 하루 단위 20,000회 재표집(시드 2911)의
MSE 차이 95% 상한<0이면 후속 검증으로 간다.
실패하면 H9 기각하고 1.2 문턱·2배 가중·0.24
혼합을 재탐색하지 않는다. 통과 시 A/B/DIAG10×
두 시드 전칸 개선, DIAG10 `p_worse<0.025/9`,
EXT10·EXT12 무악화가 필요하다. 이후 미사용 시드·
최종 잠금 40일 한 번 확인과 미래 교란·온실 격리·
결정성 검사를 거친다. 이 단계의 계획은 실행 전
별도 커밋한다. 온도·제출 파일은 만들지 않는다.
