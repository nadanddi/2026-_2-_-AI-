# EC 고값일 구별력 D2 — 실행 전 계획

2026-09-29. D1에서 실제 하루 평균 EC≥1.2인 공개 19일이
v2 오차제곱의 74.2%였다. 그 19일을 v2의 **하루 평균 예측값**이
순위상 얼마나 찾는지 공개 OOF 234일만으로 진단한다.
하루 평균 예측에는 평가 시각보다 늦은 시간의 입력을 포함하므로
**진단 전용**이며 평가 특징이나 실시간 예측 규칙으로 사용하지
않는다. 대안으로 0시 예측값의 구별력도 계산해 인과적으로
사용 가능한 첫 시각의 정보량을 가늠한다.

정의: 고값일=실제 하루 평균 ≥1.2. 전체·F13/F47·전후반·밀폐
층의 ROC AUC, 평균정밀도(AP), 실제 양성 수만큼 상위 예측일을
선택했을 때의 재현율을 산출한다. 예측 수준 구간은 사전에
`<0.6`, `0.6–0.9`, `0.9–1.2`, `≥1.2`로 고정하고 각 구간의
실제 평균·고값 비율·평균 잔차를 출력한다. 양성·음성 중 하나가
3일 미만인 층은 AUC 판정을 하지 않는다.

후속 가설 선택: 하루 평균 예측 AUC가 전체 ≥0.85이고 양성·음성
각 3일 이상인 두 농장 모두 ≥0.75이면, 높은 날을 구별하지만
수준을 낮게 잡는 **보정 가능성**을 H1로 검사한다. 둘 중
하나라도 미달하면 수준 보정보다 0시·과거 입력에서 새 고값
식별 신호를 찾는 H1을 세운다. 후반·밀폐 결과는 작고 편향된
표본이므로 별도 불확실성으로 보고, 선택 규칙을 사후 수정하지
않는다. 새 모델·제출 파일은 만들지 않는다. test_X는 읽지 않는다.
