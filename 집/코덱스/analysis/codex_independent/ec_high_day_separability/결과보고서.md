# D2: v2는 높은 EC 날을 구별하지만 수준을 낮게 잡는다

2026-09-29. 결과 확인 전에 `PROTOCOL.md`·코드를 `codex-ec`
커밋 `ab343e3`에 등록했다. 공개 OOF 234일·5,616행을
기존 저장 예측으로만 진단했다. `test_X`는 읽지 않았다.

실제 일평균 EC≥1.2인 날은 19/234일(8.1%)이다. v2 하루
평균 예측의 고값일 ROC AUC는 **0.9745**, 평균정밀도 0.773,
실제 양성 수와 같은 상위 19일의 재현율은 13/19(68.4%)였다.
0시 한 행의 예측만 써도 AUC **0.9638**, 평균정밀도 0.724,
상위 19일 재현율 12/19(63.2%)였다. 농장별 하루 평균 AUC는
F13 **0.9537**, F47 **0.9907**이므로 사전 선택 조건
(전체 ≥0.85, 양 농장 ≥0.75)을 통과했다. 후반 36일의
AUC 0.9806은 양성 5일뿐이므로 불확실하다.

고값 19일의 실제 평균은 **1.593**, v2 예측 평균은 **1.143**,
잔차(실제−예측)는 **+0.450**이다. 그러나 높은 예측 자체가
항상 과소라는 뜻은 아니다. 하루 평균 v2 예측 구간별 실제−예측
평균은 `<0.6`: −0.010(163일), `0.6–0.9`: +0.075(51일),
`0.9–1.2`: +0.116(12일), `≥1.2`: +0.076(8일)이다.
고값일 과소예측과 그 근처 저값일 과대예측이 섞이므로,
고값일 정답을 안다고 가정한 +0.45 보정은 위법하고 실패 위험이
크다.

**해석:** 주된 병목은 고EC 날을 완전히 못 알아보는 것보다
높은 수준에서 예측을 수축하는 데 가깝다. 이것은 공개 OOF의
연관이며 숨은 평가일에서도 같은 보정이 맞는다는 증명은 아니다.
다음 H1은 오직 현재 시각의 v2 예측값에 적용하는 고정된
완만한 고값 보정을 시험한다. 하루 평균 예측은 미래 입력을
포함하므로 진단에만 썼고, 평가 특징으로 사용하지 않는다.
