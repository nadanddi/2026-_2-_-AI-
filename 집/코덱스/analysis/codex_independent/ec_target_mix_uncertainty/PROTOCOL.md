# EC v2 후보의 평가 입력 구성 표준화 진단

작성 시점: EC v2의 탐색·확인 및 여러 사후 전이 진단을 이미 본 뒤.
**독립 확인 또는 새 채택 게이트가 아니다.** 후보나 혼합 비율을
조정하지 않는다.

목적: 보존된 공개 확인 폴드 8·9의 행별 예측과 평가 입력의
온실×밀폐일 수만 이용하여, 평가 구성으로 바꾼 공개 오차 차이와
하루 표본의 변동성을 함께 표시한다. 평가 EC 정답은 사용하지 않는다.

1. v2 후보는 저장된 세 시드 평균 `candidate`, 기준은 `baseline`.
   각 공개 확인일의 24행 제곱오차합을 계산한다.
2. 밀폐일은 해당 날 전체 `act_circfan` 평균 <10 및
   `act_vent=0` 비율 >0.85로 분류한다. **미래 입력까지 쓰는
   사후 진단 분류**이며 모델 특징이나 게이트로 쓰지 않는다.
3. 온실×밀폐 여부의 네 층에서 평가 입력과 같은 일수를
   확인일로부터 복원추출한다. 각 반복의 합산 RMSE 상대 변화를
   계산한다. 난수 시드 20260928, 반복 100,000회,
   분위수 2.5/50/97.5%와 악화 비율을 기록한다.
4. 동일한 네 층의 확인일 평균 제곱오차를 평가 일수로 가중한
   점추정도 기록한다. 공개 확인 구성의 본래 RMSE와 비교한다.
5. 이 재표집은 확인일이 평가일과 각 층 안에서 교환 가능하다는
   강한 가정을 둔다. 계절·급액·센서 차이, 과거 후보 선택,
   모델 재학습 불확실성은 반영하지 못한다. 따라서 비공개 RMSE의
   신뢰구간이나 제출 판정 근거로 해석하지 않는다.

출력은 작업 사본 `analysis/local/ec_target_mix_uncertainty/`의
새 실행 폴더에 JSON으로만 저장한다. 새 제출 예측이나 플랫폼
제출은 만들지 않는다.
