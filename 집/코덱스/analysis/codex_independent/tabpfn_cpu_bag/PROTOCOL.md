# TabPFN EC 4문맥 CPU 재현 — 실행 전 계획

기존 연구에서 미리 선택된 TabPFN v2 EC 혼합(기존 80%, TabPFN 20%)을
CPU에서 재현한다. 새 하이퍼파라미터 탐색이 아니다. CPU 단일 문맥
선별 결과 폴드0·문맥1에서 −4.80%였으나 우연 가능성이 크다.

고정 대상: 기존 탐색 폴드 0·2, 문맥 시드 1·2·3·4, 각 문맥 2,000 훈련행
비복원 균등 표본, TabPFN ModelVersion.V2, CPU float32,
n_estimators=4. 기준 모델은 3회차 EC 구성의 시드 7·101.
각 폴드에서 4문맥 예측을 먼저 평균하고 같은 기준 모델 80%와 혼합한다.
인과적 당일 누적 수축 0.5와 해당 훈련 분할 EC 범위 제한은 동일하다.

폴드0·문맥1은 바로 전 `tabpfn_cpu_probe` 결과를 **입력·코드·환경·분할·
검증 row_id가 모두 일치할 때만** 재사용한다. 이를 새 독립 시험으로
세지 않는다. 나머지 일곱 폴드×문맥 조합을 로컬 CPU에서 새로 예측한다.

사전 기준: 폴드 0·2 각각에서 기준 시드 7·101의 4문맥 혼합이 모두
기준보다 좋고, 네 상대 RMSE 감소율 평균이 1% 이상일 때 CPU 재현성의
후속 검증 후보로 남긴다. 한 조합이라도 악화되면 이번 고정 구성은
통과하지 못한 것으로 기록한다. 이 단계는 유의성 검정이 아니다.

확인용 폴드 8·9와 인접일은 계속 잠근다. 기존 연구에서 전체 공개
자료가 사용됐으므로 최종 확인도 완전히 새로운 독립 시험이 아니다.
이번 단계가 통과해도 나머지 탐색 폴드, A/B와 DIAG10, 최신 기준 구성,
온실·일 블록 신뢰구간 및 캠페인 다중 비교 보정, 끝단 인과성·재현 검사
전에는 채택하지 않는다. test_X 및 비공개 정답은 읽지 않는다.

CPU 단일 예측은 약 96초였다. 7개 새 예측의 예상 사용량은 약 12분.
각 문맥의 예측을 개별 체크포인트 CSV로 남겨 중단 시 완료된 계산을
재사용한다. 외부 조회·다운로드 없이 로컬 가중치만 사용한다.
