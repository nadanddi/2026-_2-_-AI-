# H18 / F1-4: 같은 출처의 이전 날 대비 현재 운전 상태 변화

2026-09-29 실행 전 등록. 카탈로그 6.4의 고EC는 2~3일 간격의 단발 스파이크이며, H12/H17의 과거 일사·VPD·밀폐 **절대 누적**은 높은 날 평균에 작은 이득을 보였지만 폴드 방향이 갈렸다. EC 수준의 급변이 며칠 쌓인 물리량보다 출처의 난방·차광·환기·포그 관리 **전환**과 함께 일어난다는 다른 기작을 검증한다. 동일 입력을 단순히 d−2로 옮기거나 H17의 기간을 조정하는 안이 아니다.

H12에서 사전 고정한 같은 F13/F47 기록의 입력 전용 인과 링크로 직전 같은 출처 날을 찾는다. 현재 행 h에서 `act_heating`, `act_shade`, `act_vent`, `act_fog`, `in_hum`, `in_temp` 각각의 `현재(h)−직전 출처 날(h)` 차이 6열과, 그 차이의 현재 날 0~h 누적평균 6열을 만든다. 같은 출처 이전 날 전체 입력은 현재 날보다 이전이므로 허용되며 현재 날의 h+1 이후 입력은 쓰지 않는다. 링크가 없거나 해당 이전 시각 입력이 결측이면 NaN이다. 훈련 특징 구축은 `train_X`만 사용하여 MASK(test_X=NaN)이며 다른 날 EC 정답·타 기록 입력은 쓰지 않는다.

동일 시드·훈련일에서 `FULL` 전용 ExtraTrees와 `FULL+전환 12열` ExtraTrees(`n_estimators=600`, `max_features=1.0`, `min_samples_leaf=1`, `n_jobs=4`, `random_state=seed`, 학습일 중앙값 결측 대체)를 짝지어 적합한다. 시드 7·101. 새 입력의 학습 효과만 저장 v2에 `0.24×` 반영하고 이 차이를 당일 현재까지 0.5:0.5 인과 수축한다. 단독 두 모델 RMSE도 보고한다. v2 출력값에 따른 문턱·비중·확대 규칙은 없다.

저장 OOF 0·2·4·6·8·9에서 검증일과 잠금 40일 ±1일을 두 모델 학습에서 제외한다. 두 시드×6폴드·양 농장 모두 v2보다 엄격히 개선하고, 날 단위 20,000회 MSE 재표집 `p_worse<0.025/12`일 때만 A/B/DIAG10 ×두 시드, EXT10·EXT12 무악화, 미사용 시드·최종 잠금 40일 1회 및 미래 교란·온실 격리·결정성 검사로 진행한다. 고EC 19일/나머지 215일, 0~6시/그 이후, 링크 있는 날/없는 날의 오차를 분리한다. 대리 출처 연결은 H12의 분석용 참조 정확도(135/170)를 재사용하되 학습에 넣지 않는다. 탈락 시 연결 오류와 상태 전환 특징 자체의 한계를 구분하고 열·시드·비중을 사후 조정하지 않는다. 온도·제출 파일은 만들거나 바꾸지 않는다.
