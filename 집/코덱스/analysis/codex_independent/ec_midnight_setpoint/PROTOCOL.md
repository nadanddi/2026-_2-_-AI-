# H2: 0시 입력에서 하루 EC 수준을 별도로 추정

2026-09-29 실행 전 등록. 비교 대상은 EC v2다.

D1에서 오차의 87.6%가 하루 수준이고, D2에서 0시 v2
예측만으로도 실제 고EC일 AUC 0.9638이었다. D3에서 현재행
팬<10·환기=0·v2≥0.6인 56일/965행이 전체 제곱오차
68.2%를 차지했으나 평균 잔차의 부호는 폴드마다 바뀌었다.
따라서 무조건 올리는 보정 대신, **0시의 관측 환경·구동기
상태에서 하루 EC 기준 수준을 독립 추정**하는 모델을 시험한다.
하루 수준 모델은 고정된 0시 입력만 쓰므로 이후 시각의
평가 행에서도 미래 입력이 아니다.

## 한 가지 후보

각 농장-날의 0시 입력 12개(`in_temp`, `in_hum`, `in_co2`,
`act_vent`, `act_shade`, `act_thermal`, `act_heating`,
`act_circfan`, `act_co2`, `act_fog`, `out_temp`, `out_hum`)와
현재 날 번호, 농장 F47 지시자를 사용해 그날 학습 정답의
24시간 평균 EC를 Ridge 회귀로 학습한다. 각 수치열은
**학습일에서만** 계산한 중앙값으로 결측을 채운다. 전부 결측인
열의 대체값은 0이다. 학습일 평균·표준편차로 표준화한다.
정규화 강도 `alpha=20`, 절편은 정규화하지 않는다.
다른 농장 입력이나 이전 날 정답을 평가 특징으로 쓰지 않는다.

현재행 v2 예측 `p` 및 현재행 `act_circfan<10`,
`act_vent==0`, `p>=0.6` 세 조건이 모두 참일 때만
`p_H2 = 0.8p + 0.2m0`를 사용한다(`m0`: 그 농장-날의
0시 입력에서 예측한 하루 EC 수준). 나머지 행은 v2 그대로다.
가중치·게이트·열·정규화·학습 방식은 결과 후 조정하지 않는다.

## 검증과 중단 기준

먼저 기존 OOF 6개 폴드(0·2·4·6·8·9)의 저장된 EC v2
예측에 적용한다. 매 폴드의 하루 수준 모델은 `train_X/y`에서
그 폴드 검증일 ±1일, `ec_final_lock/locked_days.json`의
최종 잠금 40일 ±1일을 빼고 새로 학습한다. 원본 v2를
재학습하지 않고 저장 예측과 동일한 검증 행만 비교하므로
v2에 유리한 보수적 선별이다. 날짜별 정답은 학습일에서만
평균내고, 검증 정답은 채점에만 사용한다.

6개 폴드와 두 농장의 RMSE가 모두 엄격히 감소하고,
전체 하루 단위 재표집 20,000회(난수 2902)의 MSE 차이
95% 상한이 0보다 작아야 다음 단계로 간다. 실패하면 H2
기각, 결합률·문턱을 바꿔 다시 쓰지 않는다.

통과하면 A/B/DIAG10×2개 이상 v2 시드에 같은 구조를
비교하며 각 칸 개선, DIAG10 `p_worse<0.025/k`,
EXT10·EXT12 무악화를 확인한다. 통과한 경우에만 미사용
시드와 잠금 40일을 딱 한 번 확인하고 미래 입력 교란·농장
격리·결정성 검사를 한다. 추가 검증 전 해당 계획도 커밋한다.

`test_X` 통계·비공개 정답·리더보드 역탐색을 쓰지 않고
제출 파일을 만들지 않는다.
