# EC 회귀기 계열 통제 비교

2026-09-29 집 코덱스. 실행 전에 main에 커밋한다.
질문: 기존 v2와 같은 공개 OOF 검증일에서, 동일한 38개 FULL 입력을 쓰는
회귀기 종류만 바꾸면 EC 예측 오차가 어떻게 달라지는가?

학습 특징은 train_X만으로 만들고 저장된 v2 검증 예측과 행ID로 맞춘다.
최종 잠금 40일과 ±1일, 각 검증일과 ±1일은 새 모델의 학습에서 제외한다.
검증은 기존 폴드 0·2·4·6·8·9, 시드 7·101. 잠금 40일은 채점하지 않는다.

고정 모델 2종: RandomForestRegressor(300트리, leaf=3, max_features=.8),
HistGradientBoostingRegressor(250반복, learning_rate=.05, leaf=15,
min_samples_leaf=40, l2=10). 전자는 학습 중앙값 대체 후 적합,
후자는 자체 NaN 처리를 쓴다. 회귀기 이외 특징·분할·라벨은 동일하다.
단독 RMSE, 농장·폴드별 RMSE와 기존 v2에 20% 고정 결합한 RMSE를 기록한다.
이 실험은 모델 계열 탐색으로 보고하며 기존 H11~H22의 기각을 뒤집거나
새 후보를 채택하지 않는다. 선별 지표는 양 시드×6폴드 전칸 개선과
DIAG10 날 단위 p_worse<0.025/2이며, 통과 시에만 별도 사전 등록 확증으로 간다.
