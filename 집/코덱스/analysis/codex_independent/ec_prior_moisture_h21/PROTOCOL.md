# H21 / F1-5: 같은 출처의 전날 수분수지 기억

2026-09-29 실행 전 등록. H20은 현재 날 수분 질량수지로 양 시드 평균 개선했으나 폴드 안정성이 없었다. EC가 배지 수분/염류 축적의 결과라면 **같은 출처의 이전 날** 수증기 배출·밀폐 축적이 현재 EC 수준에 더 직접적인 상태 기억일 수 있다. H17의 과거 일사·VPD·환기 누적과 달리 절대습도 수지의 **양수 배출·밀폐 상승·실내외 격차**를 이전 출처 날 단위로 집계한다.

H12 `build_links`를 바꾸지 않고 현재 날보다 작은, 같은 F13/F47 기록의 입력으로만 이전 출처 날을 연결한다. 이전 날 24시간 완료 입력의 (1) 양수 `AH실내−AH외기`×환기/100 합, (2) 양수 밀폐 수분 상승 합, (3) 평균 실내외 AH 격차를 세 특징으로 정의한다. 과거 날이 없으면 NaN. 현재 날 0~h 입력 외에 이후 시각 입력은 쓰지 않으며, 다른 날 EC 정답과 `test_X`로 학습 특징을 만들지 않는다. 연결 신뢰도는 H12의 대리 135/170(79.4%)에 제한된다.

동일 시드·학습일 `FULL` ExtraTrees와 `FULL+과거 수분 3열` ExtraTrees (`n_estimators=600`, `max_features=1.0`, `min_samples_leaf=1`, `n_jobs=4`, 학습 중앙값 대체)를 짝지어 비교한다. 시드 7·101, 저장 v2에 고정 `0.24×` 두 모델 차이를 당일 현재까지 0.5:0.5 인과 수축해 합한다. 단독 RMSE도 기록한다. 저장 OOF 폴드 0·2·4·6·8·9에서 검증일과 잠금 40일 ±1일을 학습에서 제외한다.

두 시드×6폴드 및 양 농장 전칸 개선, 날 단위 20,000회 MSE 재표집 `p_worse<0.025/12`일 때만 A/B/DIAG10 별도 재학습, EXT10·EXT12 무악화, 미사용 시드·잠금 40일 한 번, 미래 교란·온실 격리·결정성 검사로 진행한다. 고EC 19일/기타 215일 및 연결 가능일을 따로 보고한다. 실패 시 연결 오류 대 수분 정보 부족을 H20 현재날 효과와 비교해 진단하며 연결 규칙·가중치·시드 재조정은 하지 않는다. 온도와 제출 파일은 건드리지 않는다.
