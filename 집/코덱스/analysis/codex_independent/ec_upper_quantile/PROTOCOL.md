# H10: 전체 학습 행의 조건부 상위 EC 분위수

2026-09-29 실행 전 등록. D1에서 실제 고EC 19일의
평균 잔차는 +0.450이고 전체 제곱오차의 74.2%를
차지했다. H1의 일괄 고값 확대, H3의 고EC일
분류, H9의 희소 고라벨일 2배 가중은 모두
검증 폴드·시드에서 방향이 갈렸다. H10은 고EC
날 몇 개를 복제하거나 가중하지 않고, **모든 학습
행의 조건부 0.65 분위수**를 다른 손실 함수로
학습해 입력 체제별 상위 꼬리가 v2의 남은 수준
오차를 설명할 수 있는지 마지막 단일안으로 검증한다.

## 모델·후보 고정

`GradientBoostingRegressor(loss='quantile', alpha=0.65,
n_estimators=300, learning_rate=0.03, max_depth=3,
min_samples_leaf=40, subsample=0.8, max_features=0.9,
random_state=seed)`를 쓴다. 결측은 각 학습 폴드
특징의 중앙값으로 대체한다. 특징은 3회차 ET와
동일한 인과 `FULL` 열이며, 훈련에는 해당 폴드
`train_X`·`train_y`만 쓴다. 시드 7·101을
독립 적합한다. 이 확률적 트리의 분위수 출력 `q`
및 저장 EC v2 출력 `p`로, 현재행 `p≥0.6`이면
`H10=0.85p+0.15q`, 아니면 `H10=p`를 적용하고
학습 정답 범위로 자른다. 0.6 게이트는 H1 전에
정한 공개 고예측 구간 기준이며, 0.15 비중·0.65
분위수는 이 가설의 고정 단일안이다. 결과를 보고
튜닝하지 않는다. 출력에 실제 고EC 여부나 그날
EC 정답 평균을 쓰지 않는다.

원래 6개 공개 OOF 폴드(0·2·4·6·8·9)에서 검증일과
최종 잠금 40일±1일을 분위수 모델 학습에서 제외한다.
저장 v2는 잠금일 라벨을 학습했을 수 있으므로
1차 비교는 독립 확인이 아니라 탐색 선별이다.

## 채택 게이트

두 시드 각각 6개 폴드와 두 농장의 RMSE가 v2보다
모두 엄격히 낮고, 하루 단위 20,000회 재표집
(시드 2912) MSE 차이 95% 상한<0이어야 다음
단계로 간다. 미달 시 H10 기각, 비중·분위수·
게이트를 재조정하지 않는다. 통과하면 A/B/DIAG10
×두 시드의 전칸 개선, DIAG10 `p_worse<0.025/10`,
EXT10·EXT12 무악화, 미사용 시드·최종 잠금 40일
한 번 확인, 미래 입력 교란·온실 격리·결정성
검사를 실행 전 별도 등록한 뒤 검증한다.

`test_X` 통계, 비공개 정답, 공식 점수, 온도 모델을
사용하지 않고 제출 파일을 만들지 않는다.
