# EC 후보의 잠금 확인 구간 — 점수 열기 전 계획

2026-09-28. 탐색 폴드 0·2·4·6의 결과로 만든 **기존 로컬 후보**를
바꾸지 않고 DIAG10 폴드 8·9에서 한 번 평가한다. 후보는 EC 기준
ExtraTrees/LightGBM/MLP의 시드 7·101·2024 원시 예측 평균 80%와
CPU TabPFN-v2-reg 문맥 시드 1·2·3·4 평균 20%, 인과적 당일 수축
0.5 및 훈련 EC 범위 제한이다. 온도 예측은 이 시험의 대상이 아니다.

두 확인 폴드 및 같은 온실의 인접일은 **모든 확인 학습에서 제외**한다.
두 폴드의 검증 예측만 한 번 생성하고, 후보나 혼합 비율을 결과에
따라 수정하지 않는다. 기준 시드별 6개 비교와 실제 세 시드 평균의
폴드별·합산 RMSE를 모두 보고한다. 사전 통과 기준은 세 시드 평균
후보가 두 폴드 모두 개선되고 합산 RMSE 상대 감소율이 1% 이상인
것이다. 온실별·날짜별 변화와 5일 묶음 재표집 구간, 기존에 정의한
밀폐일(하루 전체 `act_circfan` 평균 10 미만 및 `act_vent=0`
비율 85% 초과)별 결과는 보조 진단이며 통과 기준을 사후에
바꾸지 않는다. 밀폐일은 미래 입력까지 쓰는 분류이므로 예측 특징에
넣지 않는다. 두 번째 문맥 묶음 5~8은
재현성 검사로만 보고 이 확인 구간의 후보 선택에 쓰지 않는다.

코드·입력·분할·라이브러리·가중치 해시를 기록하고 예측 행 ID와
값을 저장한다. 기준 모델 재적합 캐시는 정확한 학습/검증 입력과
코드 해시가 맞는 경우에만 사용한다. CPU 오프라인 실행이다.
공개 자료의 과거 연구가 전체 자료를 이미 살펴봤으므로 이 결과도
완전 독립 자료의 최종 일반화 증명은 아니다. test_X의 정답이나
플랫폼 점수를 읽지 않고, 이 확인 결과만으로 자동 제출하지 않는다.
