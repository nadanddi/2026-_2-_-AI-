# H1: 현재 행 EC 예측값의 완만한 수준 보정

2026-09-29. 실행 전 사전 등록. 기준은 EC v2
`0.8 × 3회차(day 포함) + 0.2 × TabPFN(문맥 4개)`다.

## 가설과 근거

D1에서 OOF 오차 제곱의 87.6%가 하루 수준이었고, D2에서
실제 높은 EC일의 평균 잔차가 +0.450이었다. v2는 높은 날의
순위 자체는 잘 잡지만(AUC 0.9745), 예측 0.6 이상 구간의
평균 잔차가 양수였다. 수축된 예측 수준을 현재 행에서만
약하게 늘리면 기준 v2의 RMSE가 줄어들 수 있다.

## 단일 후보와 금지 사항

현재 행의 v2 EC 예측을 `p`라 할 때 오직 한 후보를 시험한다.

`p_H1 = p + 0.10 × max(p − 0.60, 0)`

계수·문턱·클립·농장별 분기는 결과를 본 후 조정하지 않는다.
이전/미래 행 입력, 당일 평균, 실제 고EC 여부, `test_X` 통계,
리더보드 점수는 사용하지 않는다. 예측 변환 외에 v2 학습은
변경하지 않는다. 제출 파일을 만들지 않는다.

## 단계별 평가와 사전 중단 기준

1. 이미 저장된 **공개 OOF 234일**의 v2 3시드 평균 예측에
   위 변환만 적용한다. 탐색 0·2·4·6과 기존 확인 8·9의 각
   폴드 RMSE 및 전체·농장별 RMSE를 비교한다. 두 모델에
   동일한 행·정답만 사용한다. 하루 단위 재표집 20,000회,
   고정 난수 시드 2901로 `MSE(H1)−MSE(v2)`의 95% 구간과
   악화 비율을 계산한다. 이 단계는 과거 연구에서 이미 본
   날짜의 **선별**이며 독립 확인으로 부르지 않는다.
2. 6개 폴드와 두 농장의 RMSE가 모두 엄격히 감소하고,
   전체 하루 재표집 95% 상한이 0보다 작을 때에만 다음
   검증기로 넘어간다. 하나라도 실패하면 H1을 기각하고
   추가 시드/확인 날짜를 열지 않는다.
3. 선별 통과 시 별도 실행 계획을 먼저 커밋하고 동일한
   고정 변환을 A/B/DIAG10의 각 2시드 이상에 비교한다.
   전부 개선, DIAG10 각 시드 `p_worse < 0.025`(후보
   다중성은 캠페인 전체 횟수 `k`로 보정), EXT10/EXT12
   각 시드 무악화를 요구한다. 실패하면 기각한다.
4. 그 조건까지 통과한 경우에만 미사용 시드와 새 잠금 40일을
   단 한 번 확인한다. 잠금일 및 ±1일은 해당 모델 학습에서
   빼고, 미래 입력 교란·농장 분리·동일 입력 결정성도 검사한다.

최종 40일의 목록은 `../ec_final_lock/locked_days.json`으로
이미 고정됐다. 본 H1 선별 코드는 이 목록의 정답을 읽거나
예측하지 않는다. 선별 결과가 나쁘더라도 계수/문턱을 재탐색해
H1로 다시 제출하지 않는다.
