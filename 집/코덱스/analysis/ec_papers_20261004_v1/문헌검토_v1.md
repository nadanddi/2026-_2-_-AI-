## 전체 RMSE와 희귀값 손실의 차이

SERA는 관련도 φ(y)에 따라 제곱오차를 강조한다. 논문은 36개 자료를 80/20 무작위 분할하고 80% 안에서 10-fold 층화 CV로 튜닝했다. 본문 §5.3에서 SERA 최적화 모델이 원래 모델보다 전체 MSE가 낮았던 자료는 XGBoost **3/36**, LightGBM **11/36**이며, SERA가 낮았던 자료는 각각 **18/36**, **26/36**이다. 이 수치는 논문 서술 확인이며 EC 재현 수치가 아니다. 전체 MSE가 최종 목적이면 희귀값 개선을 그대로 채택 근거로 옮길 수 없다. [논문 본문](https://arxiv.org/pdf/2206.09991)

논문의 정의에서 다음 항등식이 나온다. 아래 단순화와 최적해는 이 검토에서 직접 유도한 것이다.

\[
\mathrm{SERA}=\int_0^1\sum_i 1\{\phi(y_i)\ge t\}(\hat y_i-y_i)^2dt
=\sum_i\phi(y_i)(\hat y_i-y_i)^2.
\]

φ를 학습 정답으로만 고정하면 gradient는 2φ(y)(ŷ−y), Hessian은 2φ(y)이다. 별도의 복잡한 수치 적분 없이 sample_weight로 구현 가능한 가중 제곱손실이다. φ=0인 일반 표본이 완전히 사라질 수 있으므로 우리 목적에 적용한다면 **MSE+λ·SERA**처럼 양의 바닥 가중치를 유지하는 편이 명확하다. 이는 원 논문 그대로의 재현이 아니다.

원래 RMSE를 최소화하는 모집단 예측은 E[Y|X=x]지만, w(Y)를 둔 제곱손실의 최적 예측은 E[w(Y)Y|X=x]/E[w(Y)|X=x]이다. 과소예측을 줄여도 목적 분포 자체를 바꾸면 보통 날 과대예측이 커질 수 있다. 이상적인 생성기가 p(x|y)를 맞추더라도 합성 표본의 y 분포를 바꾸면 같은 문제가 생긴다. p(y)/q(y) 중요도 가중으로 그 변화를 정확히 되돌리면 모집단 목표는 원래 평균으로 돌아간다. 따라서 합성이 새 정보의 확보를 자동으로 뜻하지 않는다. 유한 표본·모델의 표현력·정규화 측면의 이득은 별도로 시험할 수 있다.

독립적인 산술 반례: Y=0 확률 .9, Y=2 확률 .1이면 원래 평균은 .2, 전체 MSE는 .36이다. 높은 값만 3배 가중하면 최적 예측은 .5, 전체 MSE는 .45로 **25% 악화**하지만 가중 손실은 1.008→.9로 좋아진다. 이는 EC 관측치가 아니라 목적함수 차이를 검산한 예시다.

## SMOGN에서 가져올 것과 조심할 것

SMOGN은 일반값 undersampling과 희귀값 증강을 결합한다. 가까운 희귀 이웃은 보간하고 먼 이웃은 Gaussian noise로 대체하며 안전 거리 기준은 관련 구간 거리 중앙값의 절반이다. 20개 자료·4종 학습기에서 **Fφ1**을 주 지표로, 2×10-fold 층화 CV를 사용했다. RF/MARS에서 상대적으로 유리했고 SVM/NNET에서는 덜 유리했다. 본문은 recall 개선에 precision 손실이 따를 수 있음을 설명한다. 전체 RMSE의 일관된 개선을 증명한 실험이 아니다. [원 논문](https://proceedings.mlr.press/v74/branco17a/branco17a.pdf)

저자 `DIBSRegress.R`은 NA가 있으면 중단한다. 또한 수치 거리 d1/d2를 열마다 누적하지 않고 `=`로 덮어쓴다(L213–214, L278–279; 웹 도구의 0-based line). 마지막 수치열의 부모 값이 같으면 d1=d2=0이 되어 정답을 중간값으로 보간한다. 공통 보간계수 α가 있고 마지막 수치열 차이가 0이 아니면 비율이 상쇄될 수 있으므로 모든 생성 정답이 틀린다는 뜻은 아니다. 부모 y=1/3, α=.25, 수치열 차이 [4,0]인 반례에서는 전체 거리 가중 정답 **1.5** 대신 **2**가 나온다. 범주 거리와의 혼합도 별도 감사해야 한다. 이 정적 허점은 우리 과거 가중치 실험의 실패 원인이라는 증거가 아니다. [저자 코드](https://raw.githubusercontent.com/paobranco/SMOGN-LIDTA17/master/R_Code/DIBSRegress.R)

온실별 EC 보정 관계나 이력 상태가 다른데 EC가 높다는 이유만으로 이웃을 정하면 서로 다른 관계를 잇는 가상 관측치를 만들 수 있다. 시각·온실 ID·원본/파생 입력을 연속 수치처럼 보간하면 현재값, 0시값, 누적 평균의 항등식도 깨질 수 있다. 이는 대회 자료에 적용할 때의 방법론적 위험이며 해당 논문의 센서 실증 결론이 아니다.

## 국내 연구자의 TabOversample 코드 감사

PMLR 초록은 9개 벤치마크·13개 비교 방법·10개 시드에서 SERA 8/9 및 rare-RMSE 9/9 최고였다고 설명한다. 이 수치를 **전체 RMSE 9/9 개선**으로 바꾸어 말할 수 없다. 본문을 못 읽었으므로 전체 RMSE 변화의 크기, 희귀값 경계, 생성자료 비율, 시드의 실제 역할, 제약과 이론 가정을 확정하지 않는다. [PMLR 초록](https://proceedings.mlr.press/v337/kang26a.html)

README는 FiLM·혼합형 확산·DSE 생성 후 필터를 소개한다. 반면 **2026-10-04 웹 도구가 반환한 master 코드 사본**의 `ConditionalDenoisingMLP`는 noisy X/time/y embedding을 입력에서 concat한다. `oversample()`은 조건부 생성 직후 원본과 합치며 DSE를 호출하지 않는다. phi+.1을 평균1로 정규화해 생성기 손실에 쓴다. 논문 전체가 틀렸다는 판정이 아니라, 공개 코드 사본만으로 문서의 전체 방법을 재현했다고 할 수 없다는 판정이다. [README](https://github.com/nathanielkang/taboversample), [tabover.py](https://raw.githubusercontent.com/nathanielkang/taboversample/master/taboversample/tabover.py)

`diffusion.py` 또한 Gaussian 수치 MLP 기반 단순 구현이다. 범주형 multinomial diffusion을 이 파일에서 확인하지 못했다. 시각/온실 ID/제어 상태를 float로 넣고 이 결과를 그대로 쓰면 범주·시간·구조 보존은 보장되지 않는다. [diffusion.py](https://raw.githubusercontent.com/nathanielkang/taboversample/master/taboversample/diffusion.py)

`datasets.py`에는 6개 자료 loader와 고정 random_state=42의 70/30 행 분할이 있다. 수치 scaler는 학습만 fit하지만 범주 LabelEncoder는 분할 전에 전체 입력에 fit한다. [datasets.py](https://raw.githubusercontent.com/nathanielkang/taboversample/master/taboversample/datasets.py)

`run_experiments.py`는 7개 방법을 등록하고 자료를 seed 루프 밖에서 한 번 불러온다. 따라서 공개 코드의 seed 반복은 자료 분할 반복과 다르다. 평가 관련도는 `relevance_function(y_test)`로 시험 정답 분포에서 새로 계산한다. 이는 평가 가중치를 만드는 절차이고 그 자체가 모델 학습 정답 누수라는 뜻은 아니다. 다만 대회용 relevance를 fold 학습에서 고정해 검증에 옮기는 방식과 다르다. [run_experiments.py](https://raw.githubusercontent.com/nathanielkang/taboversample/master/taboversample/run_experiments.py)

`relevance.py`는 양쪽 꼬리 boxplot 관련도를 사용하고, 훈련 y를 50개 구간으로 나눈 평균 관련도로 합성 y를 뽑는다. 우리가 원하는 높은 EC 한쪽 꼬리와 다르다. 비어 있는 구간의 확률은 대체로 0이므로 관측 범위 안의 증강에 해당하며, 관측하지 못한 고EC 상태를 검증해 준다고 말할 수 없다. [relevance.py](https://raw.githubusercontent.com/nathanielkang/taboversample/master/taboversample/relevance.py)

공개 코드의 확정 commit hash는 웹에서 조회 실패했다. 따라서 향후 실제 구현을 택하면 논문 PDF와 저자 코드 revision을 확보하고 두 방법의 차이를 다시 확인해야 한다. 현재는 그대로 설치·실행할 우선순위가 낮다.

## 대회 제공 자료만으로 시험할 수 있는 설계

입력 범위는 대회 제공 49온실, EC 지도 목표는 기존 공개 OOF 8,640행의 사용 가능 정답으로 제한한다. 이 분모는 부모 작업과 기존 저장소의 고정 범위이며 이번 문헌 작업에서 새 원자료 집계로 확인한 수치가 아니다. 여러 온실의 입력이 있어도 EC 정답이 없는 온실이 EC 지도 표본이 되는 것은 아니다. 24시간 행은 같은 온실-일에 종속되어 독립 표본 24개로 취급하지 않는다.

### A. 약한 관련도 손실 대조 — 구현 가능, 가중치 계열과 중복 있음

기존 LGB 구성원·입력·분할·시드·앙상블 비중을 고정하고 손실만 바꾼다. 각 outer train의 y로 median m, Q3, IQR을 추정해 φhigh(y)=clip((y−m)/(Q3+1.5IQR−m),0,1), w=1+.25φhigh를 고정한다. 분모 퇴화 시 w=1로 고정한다. 검증 정답은 가중치·경로·하이퍼파라미터 선택에 쓰지 않는다. 기존 ET 고EC일 2/4배 가중과 **학습기·강도·시간별/일별 관련도 정의**가 다르나 완전히 별개의 새 정보원이 아니다.

공개 22fold×3seed 기존 분할, 동일 범위 baseline과 비교한다. 전체 RMSE가 주 판정이며 고EC RMSE/SERA/과소편향은 진단이다. 시드×검증기 방향·기존 family 보정·DIAG10 farm/기록일 bootstrap 조건을 실행 전에 부모 프로토콜로 고정한다. 이 문서에서 달라진 카탈로그 6.247 규칙을 임의 적용하지 않는다. 약한 가중도 일반일 악화를 만들면 기각한다. 성능이 좋아질 것이라는 근거는 아직 없다.

### B. 하루 곡선을 보존한 제한적 보간 — 구현 가능, 원 SMOGN 재현과 구분

outer train 안에서만 (farm,day)의 24시간 **MASK 후 원입력+EC 궤적**을 묶는다. h0/누적/계절 등 파생열을 따로 합성하지 않는다. 같은 farm이고 동일한 결측·제어 유형의 서로 다른 train day를 이웃으로 찾고 같은 α∈[0,1]를 모든 시각의 연속 원입력과 y에 쓴다. 범주/ID/hour는 보간하지 않고, 합성 후 기존 prefix 생성기로 h시까지의 특징을 다시 만든다. 부모 둘 중 하나라도 validation/제외일이면 생성 금지한다. MASK로 사용 금지된 센서를 생성기로 복원하여 모델에 넘기지 않는다.

희귀일 관련도와 거리 scaler는 train만 fit한다. 일반일은 버리지 않는다. 합성 수는 train rare day의 25%·전체 train day의 10% 중 작은 값으로 실행 전 제한하고 donor 두 개 미만이면 생성 없이 기록한다. 부족한 희귀일을 하루 복제로 늘린 대조와 비교해야 증강 자체의 이득을 분리할 수 있다. 합성이 관계를 올바르게 보간한다는 보장은 없으므로 정적 항등식, 범위, 하루 자기상관, label-입력 연결, 중복 거리부터 검증한다. 구조 검사는 성능 증명이 아니다.

외부 fit는 학습 행/학습 날짜만 사용한다. 생성된 24시간은 학습 자료의 joint structure일 수 있으나 **실제 query를 24시간 PCA/생성기 조건으로 압축해서 h시 예측에 쓰면 미래 입력 누수**다. query는 기존 현재·이전 prefix만 사용한다.

### C. 조건부 확산 — 아이디어는 남기되 착수 조건을 명확히 함

원 논문 전체와 일치하는 구현을 확인한 뒤 B와 같은 donor provenance/차단 조건을 적용한다. 하루 수준·저차원 shape 계수를 train만 fit하는 생성기가 전체 수백차원 시간열보다 검증하기 쉽지만, 소수 독립 고EC일에서 분포를 학습할 자료가 충분한지는 먼저 확인해야 한다. 49온실의 무라벨 입력을 이용한다면 outer train 날짜만으로 표현을 학습하고 EC 조건부 학습은 정답 있는 온실만 한다. 생성 자료의 온실·시각·관측 mask·제어 구조를 명시적으로 고정한다. 검증 정답으로 품질 필터를 고르지 않는다.

교사 EC 예측이 잘 맞는 합성 행만 남기는 필터는 원래 교사의 과소예측 성향을 재강화할 수 있다. DSE가 높은 행이 실제 EC 예측에 좋은 행이라는 보장도 본문 확인 전에는 주장하지 않는다. 희귀값 생성품질은 RMSE 채택 조건을 대신하지 못한다.

## 추가 검증과 비평

기존 공식 분할을 변경하지 않고, 그와 별도로 입력만으로 동일/동조 날씨 cluster를 만들어 train-validation 복제 관계를 감사할 수 있다. 같은 날씨라도 내부 EC가 다를 수 있으므로 target을 복사하거나 같다고 강제해서는 안 된다. cluster를 함께 제외하는 추가 검증은 baseline과 후보를 같은 조건으로 재학습해야 하며 기존 점수와 혼합하지 않는다. 현재 문헌 결과의 무작위 행 CV를 우리 시계열·복제 자료에 그대로 옮길 수 없다.

| 핵심 주장 | 비평가의 반론 | 판정·한계 |
|---|---|---|
| 희귀값 손실 개선은 전체 RMSE 개선과 다르다 | 손실을 바꾸면 표현력 제한 때문에 둘 다 개선될 수도 있다 | 맞다. 불가능성 주장이 아니라 전체 점수를 직접 시험하라는 조건. 신뢰도 높음: 본문 비교+직접 최적해 유도 |
| 시간행 독립 증강은 구조를 깰 수 있다 | 합성 행도 train 안에서만 만들면 누수는 없지 않나 | train-only면 일부 누수는 막지만 불가능한 자료 구조/표본 종속은 별개. 구조 증명과 성능 검증을 모두 요구. 신뢰도 높음, 실제 EC 영향 크기 미측정 |
| 저자 공개 코드만으로 논문 전체 재현을 확언할 수 없다 | 다른 branch나 아직 못 읽은 본문에 차이 설명이 있을 수 있다 | 현재 반환 사본의 정적 범위로 한정. 논문 전체 판정 보류. 신뢰도 중간: 최신 hash 미확정 |
| SMOGN 코드에 조건부 target 보간 허점이 있다 | 동일 α 때문에 거리 비율이 상쇄될 수 있다 | 일반적 경우 상쇄 가능함을 명시. 마지막 수치열 차이0 반례만 확인. 신뢰도 높음: 두 코드 위치+독립 산술. 대회 과거 실패와 연결할 증거 없음 |

검산: SERA 항등식은 φ=[.1,.9], 잔차=[1,2]에서 가중합과 구간 적분이 모두 **3.7**. 손실 목적 변경 반례는 최적해 방정식과 직접 기대손실로 .2/.5 및 .36/.45 확인. SMOGN 반례는 전체 거리 [1,0]/[3,0]의 가중값 1.5와 덮어쓰기 중간값2를 별도로 계산했다. 이 검산은 수학/정적 해석 검증이며 논문 재현 또는 실제 EC 성능 검증이 아니다.

당장 이어갈 우선순위는 진행 중인 RERF 결과 확인 → 가중치 계열의 새 목적함수 정의가 기존 실험과 얼마나 다른지 확인 → 제한적 하루 증강 A/B 대조다. 조건부 확산은 본문·구현 불일치와 독립 희귀일 표본 수를 먼저 해소한다. EC 개선을 포기할 근거는 어느 논문이나 이번 정적 검토에서도 얻지 못했다.
