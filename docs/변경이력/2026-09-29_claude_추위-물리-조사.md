# 추위 물리 조사 · 다른 온실 활용 검토 · 하루 오프셋의 정체

작성: Claude (연구실 PC) · 2026-09-29 · 브랜치 `codex-ec` 기반

## 한 줄

추운 구간의 배지 온도는 **물리적으로 충분히 설명되지만 남은 오차를 만들지 않으며**, 오차의 절반을 차지하는 "하루 통째로 어긋남"은 지속적 미관측 상태여서 평가 구조상 추적이 불가능하다는 것을 48개 온실 비교로 확인했습니다.

## 한 것

실험 스크립트 24개 추가 (`Claude/code/`), 로그 22개 (`Claude/logs/`), 결과 CSV 7개 (`Claude/results/`)

1. **추위 물리 3단계** (`cold_physics1~5.py`) — 공기 추종 / 난방 역효과 / 바닥 열저장 세 기작을 분리 측정
2. **다른 온실 활용** (`cold_testbed48.py`, `augment_cold.py`, `augment_weight.py`, `f32_probe.py`, `f32_pseudo.py`)
3. **하루 오프셋의 정체** (`day_offset48.py`, `offset_persist.py`)
4. **해상도·공선성 검사** (`rounding_cost.py`, `collinearity.py`, `offset_dist.py`)
5. **설명 가능성 검사** (`explainability.py`, `pdp_check.py`, `pdp_compare.py`, `what_matters.py`)

## 결과

### 추위의 물리 (신규)

| 기작 | 측정 | 모델 반영 여부 |
|---|---|---|
| 공기 추종 | 최적 시정수 F13/F47 3~4h, 다른 온실 12h | 반영됨 |
| **난방 역효과** | 같은 온도대에서 난방 0% vs 60%+ → gap −0.43~−0.74℃ | **이미 반영됨** (잔차-난방 상관 +0.024) |
| **바닥 열저장** | 48/48 온실에서 같은 부호 (중앙 +0.55) | 반영해도 개선 없음 |

바닥 열저장은 F13/F47에서만 약한데(+0.13), **이어붙임 때문에 72시간 평활이 남의 온실 기온을 섞기 때문**입니다. 출처별 사슬로 재계산하면 +0.36으로 복원됩니다(`cold_physics3.log`). 그러나 한랭 외삽 예측에서는 4개 보류 규모 전부 악화(`cold_physics5.log`).

### 다른 온실 활용 (전부 기각)

| 시도 | 결과 |
|---|---|
| 추운 행 빌려오기 (보정·선별·저가중 포함) | 40곳 중 34곳 이상 악화. **가중치 2%에서도 0.763 → 1.318** |
| 선형 기준선에만 반영 | 무해하나 이득 없음 (21/40, 차이 −0.003) |
| F32 활용 | 추운 행 16개뿐, 동역학 다름(지연 0h vs 3h), `act_heating` 없음 |

**기작**: 자기 온실만 쓰면 트리가 추운 구간에 분할을 못 만들어 선형 외삽에 맡기는데, 남의 추운 행을 조금이라도 넣으면 트리가 분할을 만들어 **남의 온실 물리를 자신 있게 보간**합니다. 6℃ 이하 구간의 온실 간 편차가 8℃(−1.6 ~ +6.5)라 대부분 틀린 방향입니다.

### 하루 오프셋 (가장 중요)

| | F13/F47 | 다른 48곳 |
|---|---|---|
| 오차 중 비중 | 53%, 52% | 중앙 43% |
| 그날 입력으로 설명 (R²) | −0.05 | 중앙 **+0.002** (24/48 양수) |
| **1일 자기상관** | **0.13, 0.16** | **중앙 0.64 (48/48 양수)** |
| 어제 오프셋 그대로 사용 | −75% (해로움) | **+29.5% 개선** (39/48) |

→ 하루 오프셋은 **잡음이 아니라 지속되는 미관측 상태**입니다. 연속 기록 온실은 정답 피드백으로 추적하지만, F13/F47은 ①어제가 다른 온실이고 ②평가 블록에 정답이 없어 **양쪽 경로가 모두 차단**됩니다.

### 부수 확인

- **1℃ 반올림은 공짜**: 입력·라벨 모두 정수로 반올림해도 성능 동일(`rounding_cost.log`). 다른 온실을 못 쓰는 이유는 해상도가 아니라 이질성
- **다중공선성**: 온도 98피처 중 VIF>10이 74개지만 가지치기해도 CV 변화 ±0.003 → 무해
- **온도 모델 설명 가능성**: `in_temp` 기여 86.3%, 실내온도 ±2℃ → 배지 ±0.8℃ 단조(100% 일관)

**기각 (반복 금지)**
- 다른 온실 추운 행 학습 투입 — 어떤 가중치·보정·선별에서도 악화

- 출처 사슬 저장고 피처 — 물리는 맞으나 예측 개선 없음
- 따뜻한 구간으로 추운 구간 오프셋 예측 — 표본 13곳, 중앙값 대비 개선 없음

**간접 확인**: 현재 온도 후보 `G_C2`의 "추운 행에서 트리를 빼고 선형으로" 설계가 옳다는 독립 증거를 얻었습니다. 40곳에서 선형+잔차가 트리 단독을 30/40으로 이깁니다.

## 정정

- 카탈로그 6.75의 **"32곳"** 선정 기준이 문서에 없습니다. 48곳 전부가 ≤6℃ 라벨을 갖고 있어(중앙 98행) 어떤 기준으로도 32가 나오지 않습니다. `cold_testbed48.py`로 40곳(기준 명시) 재현했고 순서·크기는 재현됐으나, **"0.4트리+0.6선형잔차" 비율의 추가 이득은 21/40으로 약합니다.** 지지되는 것은 "선형 기준선 + 트리 잔차" 구조입니다.
