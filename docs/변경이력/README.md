# 변경이력

**AI와 사람이 작업을 마칠 때마다 여기에 한 장씩 남깁니다.**
다른 기기·다른 세션에서 이어받는 사람이 "그동안 무슨 일이 있었나"를 5분 안에 파악하는 것이 목적입니다.

## 파일 이름

```
YYYY-MM-DD_주체_한줄요약.md

예)  2026-09-29_claude_추위-물리-조사.md
     2026-09-28_codex_EC-TabPFN-비율검증.md
```

## 틀

```markdown
# <제목>

작성: <주체> · <날짜> · 브랜치 <이름>

## 한 줄
(이 작업으로 무엇이 달라졌는지 한 문장)

## 한 것
- 실험/변경 내용을 항목으로

## 결과
| 실험 | 결과 | 판정 |
|---|---|---|

## 채택 / 기각
- 채택: (근거와 함께)
- 기각: (왜 안 되는지 — 다음 사람이 반복하지 않도록)

## 다음
- 이어서 할 일

## 파일
- 추가/수정한 파일 목록
```

## 규칙

1. **기각도 반드시 적습니다.** 실패 기록이 없으면 다음 사람이 같은 실험을 반복합니다.
2. **수치에는 근거 파일을 답니다.** (`Claude/logs/xxx.log`, `analysis/.../결과보고서.md`)
3. 카탈로그에 넣을 만한 발견이면 [`research/데이터_단서_카탈로그.md`](../../research/데이터_단서_카탈로그.md)에 **번호를 붙여 추가**하고, 여기서는 그 번호를 참조합니다.
4. 제출을 했으면 [`docs/현황.md`](../현황.md)의 표를 갱신합니다.
