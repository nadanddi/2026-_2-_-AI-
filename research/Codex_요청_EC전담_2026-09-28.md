## 3. 참고할 만한 미해결 사항

무엇을 먼저 할지는 Codex가 판단해 주세요. 아래는 Claude 쪽에서 본 미해결 사항 목록일 뿐이며 순서에 의미는 없습니다.

- **추운 날 외삽:** 평가 기간은 학습보다 춥고(평가 in_temp ≤ 8℃ 15%), 평가 60일 중 20일이 밀폐 날입니다. Claude는 시드 1개로 EC EXT10/EXT12에서 엇갈림을 봤습니다(6.68).

## 4. 온도 쪽에서 알려 둘 것 (Codex가 온도를 건드릴 경우 대비)

- 게이트 없이 온도에 TabPFN을 섞으면 **가장 추운 날에 TabPFN 없는 모델보다 나빠집니다**(EXT8: 없음 0.961 → 게이트 없는 0.1 혼합 0.972). TabPFN은 학습 범위 밖 추위에서 +1.8℃ 과대예측합니다(카탈로그 6.67~6.69).
- 온도는 Claude가 담당하므로 온도 열은 5회차 값을 유지하거나 Claude 후보를 받아 쓰면 됩니다.
