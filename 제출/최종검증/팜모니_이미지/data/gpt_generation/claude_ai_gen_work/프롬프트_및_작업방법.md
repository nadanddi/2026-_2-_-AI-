# GPT · Gemini 가짜 사진 만들기 — 프롬프트와 작업 방법

목적: 운영진 가짜와 같은 계열의 생성기(ChatGPT·Gemini 이미지 생성/편집)로 학습용 가짜를 만든다.
규정: 생성형 AI 사용은 허용된다(문제설명서 2절). 사용 도구·방법은 README에 적는다.

## 0. 폴더
```
연구실/클로드/local/ai_gen_work/
├─ 원본/              ← 업로드용 AI허브 실제 사진 100장 (src_001.jpg ~ src_100.jpg, 농장 9곳 고르게, 빨간 조명 없음)
├─ 원본_목록.csv       ← 원본 번호·농장·AI허브 원천 파일
├─ 결과_GPT/
│   ├─ 1_전체생성/   2_전체스타일/   3_부분생성/   4_부분스타일/
├─ 결과_Gemini/
│   ├─ 1_전체생성/   2_전체스타일/   3_부분생성/   4_부분스타일/
└─ 기록.csv           ← 만든 것마다 한 줄 (아래 형식)
```
- 결과는 **받은 그대로** 저장해 주세요. 크기 조정·자르기·캡처는 하지 않습니다. 배포 형식 변환은 제가 합니다.
- 파일 이름 규칙: `<원본번호 또는 g번호>_<짧은메모>.png` (예: `src_017_watercolor.png`, `g05_greenhouse.png`)
- `기록.csv`에 한 줄씩 적습니다: `도구,유형,결과파일,원본파일,프롬프트`
  - 예: `GPT,2_전체스타일,src_017_watercolor.png,src_017.jpg,"이 사진을 수채화로..."`
  - 프롬프트를 그대로 붙여 넣어 주세요. 원본이 없는 전체 생성은 원본파일 칸을 비웁니다.

## 2. 전체 생성 (원본 없이 문장만)
아래 문장 중 하나를 고르고, 괄호 안을 바꿔 가며 다양하게 만듭니다. 사진처럼 보이게 하는 것이 핵심입니다.

1. 딸기 수직농장 내부를 스마트폰으로 찍은 사진. 흰색 수경재배 홈통에 딸기 모종이 자라고, 검은 점적 호스가 늘어져 있고, 바닥에 자갈이 깔려 있다. 자연스러운 실내 조명, 사진처럼 사실적으로.
2. 비닐하우스 안 고설 재배대의 딸기 포기를 가까이서 찍은 사진. (흰 꽃 / 초록 열매 / 빨갛게 익은 딸기)가 보이고, 노란 끈끈이 트랩이 꽂혀 있다. 스마트폰 사진, 실제 같은 질감.
3. 검은 재배 용기에 심은 딸기 모종 줄을 옆에서 찍은 사진. 뒤로 온실 골조와 반투명 지붕이 보인다. 흐린 날 자연광, 현실적인 사진.
4. 흰색 플라스틱 포트가 줄지어 있는 딸기 수직농장. 포트마다 이름표가 붙어 있고 잎이 아래로 늘어져 있다. LED 백색 조명, 휴대폰 카메라 사진.
5. 코코피트 배지 봉투(흰 비닐)에 심은 딸기 포기들을 위에서 내려다본 사진. 잎 사이로 배지가 보인다. 사실적인 사진.
6. 딸기 런너(줄기)가 재배대 밖으로 늘어진 모습을 가까이 찍은 사진. 배경은 흐릿한 온실 내부. 실제 사진처럼.
7. 세로 구도의 딸기 잎 클로즈업 사진. 잎맥과 톱니 모양 가장자리가 선명하고 뒤에 노란 트랩이 크게 보인다. 사진처럼 사실적으로.
8. 딸기 재배 시설의 통로에서 찍은 사진. 양쪽에 재배대가 이어지고 딸기 포기가 빽빽하다. 스마트폰 광각 사진.

- 영어가 더 잘 되면: `A realistic smartphone photo of strawberry plants growing in white hydroponic gutters inside a vertical farm, black drip irrigation tubes, pebbles on the floor, natural indoor lighting, photorealistic.`
- 가로·세로를 섞어 주세요(세로 위주).

## 3. 전체 스타일 변환 (원본 업로드 → 사진 전체의 표현 방식 바꾸기)
**구도와 사물 위치는 그대로 두고 표현만 바꾸는 것**이 핵심입니다(공개 예시 kzbz·nriv·ttmn).

- 이 사진의 구도와 사물 위치는 그대로 두고, 사진 전체를 **(수채화 / 유화 / 색연필 그림 / 디지털 일러스트 / 동화책 삽화 / 애니메이션 배경화 / 파스텔화 / 매끈한 3D 렌더)** 스타일로 바꿔 주세요.
- 이 사진을 **사실적인 일러스트**처럼 다시 그려 주세요. 잎의 모양과 배치는 그대로 유지하고 색면과 윤곽만 그림처럼 정돈해 주세요.
- 이 사진을 **(따뜻한 오후 햇살 / 흐린 날 / 영화 같은 색감)** 의 회화풍으로 바꿔 주세요. 구도는 그대로 유지.
- 영어: `Keep the exact composition and object positions of this photo, but redraw the whole image in a (watercolor / oil painting / digital illustration / storybook illustration) style.`

## 4. 부분 생성 (원본 업로드 → 일부만 새로 그리기)
**사진처럼 자연스럽게, 일부만 바꾸는 것**이 핵심입니다(공개 예시 ftkc·mobg·uexm). 나머지는 그대로 두라고 꼭 적습니다.

- 이 사진에서 **(오른쪽 아래 / 왼쪽 위 / 가운데)** 의 **(잎 몇 장 / 빈 공간)** 에 **(흰 딸기 꽃 / 빨갛게 익은 딸기 / 초록 열매 / 새 잎)** 을 자연스럽게 추가해 주세요. 나머지는 그대로 두고 사진처럼 사실적으로.
- 이 사진의 **(이름표 / 노란 끈끈이 트랩 / 검은 호스 / 자갈 바닥)** 을 **(다른 모양의 이름표 / 지운 빈 공간 / 다른 위치의 트랩)** 으로 바꿔 주세요. 다른 부분은 건드리지 말고 자연스럽게.
- 이 사진의 **(가운데 포기 / 오른쪽 식물)** 을 비슷한 다른 딸기 포기로 바꿔 주세요. 조명과 색감은 원래 사진과 똑같이.
- 이 사진에서 **(시든 잎 / 배지 봉투 글씨)** 를 지우고 자연스럽게 채워 주세요.
- 영어: `Edit only the (lower-right) area of this photo: add (a white strawberry flower / a ripe strawberry). Keep everything else unchanged and photorealistic, matching the original lighting.`

## 5. 부분 스타일 변환 (원본 업로드 → 일부만 그림풍으로)
**식물 한 포기나 일부 영역만 질감·명암을 바꾸는 것**이 핵심입니다(공개 예시 dszm·elue·xeeo).

- 이 사진에서 **(가운데 식물 / 오른쪽 포기 / 앞쪽 잎들)** 만 **(유화 / 수채화 / 일러스트)** 스타일로 바꾸고, 나머지 배경은 원래 사진 그대로 두세요.
- 이 사진의 **(잎 부분)** 만 질감과 명암을 회화적으로 바꿔 주세요. 시설·배경·바닥은 사진 그대로.
- 영어: `Change only the (central plant) into a (painterly / watercolor) style; keep the rest of the photo exactly as it is.`

## 6. 주의
- **사람·얼굴·글씨 워터마크가 들어간 결과는 버립니다.**
- 생성기가 "편집 못 함"이라며 완전히 새 그림을 주면 → 그 결과는 `1_전체생성`에 넣습니다.
- 결과가 원본과 거의 같아 보여도(아주 미세한 변화) **버리지 말고 저장**해 주세요. 그런 것이 오히려 학습에 중요합니다.
- 마감을 고려해 **10/14(화) 저녁까지** 모인 것을 1차로 반영하고, 그 뒤 것은 최종 제출 전에 추가 반영합니다.
