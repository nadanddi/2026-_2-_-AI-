## 3. 문서로 대체하는 이미지: AI Hub 소재 16,197장
- **출처·이용조건·접근 절차·선별 기준:** `data/README_data.md` 1절
- **선별 목록과 원본 대응:** 각 manifest의 `source`(AI Hub `tar\파일`)와 `other`(합성에 쓴 두 번째 원본)
- **원본 대응 해시:** `data/source_sha256.csv`
  - 학습 이미지 한 장마다 대응하는 AI Hub 원본 파일 경로와 그 원본의 SHA256·크기를 적었습니다.
  - 합성 이미지는 원본 둘을 모두 적었습니다(`role` = source / other).
  - 표는 18,074행입니다(source 16,197 + other 1,877). AI Hub 원본은 7,116장이고, 학습 이미지 16,197장 모두 원본 해시가 있습니다.
  - GPT·Qwen 묶음의 `other` 열은 AI Hub 원본이 아니라 작업 번호(요청 사본 이름 `src_*.jpg`, Qwen 작업 번호 `q*`)라서 표에서 뺐습니다.
  - 원본 해시는 팀이 AI Hub tar에서 내려받아 추출한 원본 파일(가공 전)로 계산했습니다(2026-10-20).
  - 운영진이 같은 원본을 적법하게 받으면 파일 경로와 해시로 같은 사진인지 확인할 수 있습니다.
- **수량·라벨:** 위 1절 표와 각 manifest의 `label`·`kind`
- **생성·가공 절차와 설정:** 아래 코드와 manifest의 `info` 열(변수·모델·강도 등)
  - 코드: `code/claude_image/`의 `im03*`(필터·합성·스타일), `im07*`·`im15*`(SD·SDXL 생성·인페인팅), `im31_qwen_edit.py`(Qwen), `im42_make_h.py`(H 자료), `im45_jig_h3.py`(처리 흔들기), `im58_gptr_set.py`, `im21_gpt_set.py`
  - 묶음별 재현 순서: `README.md` ⑥ "전체 재학습 순서"
  - 무작위 시드는 원본 경로의 crc32로 고정했습니다.
- **다시 만들기 어려운 부분과 작업 기록**
  - GPT 편집·생성(gpt1~gpt3, gptr): ChatGPT 생성은 같은 지시문으로도 같은 결과가 나오지 않습니다. 요청 지시문·원본·결과 해시·검토 메모는 `data/gpt_generation/`에 있습니다.
  - SD·SDXL·Qwen 생성: 가중치를 받을 때 버전(revision)을 고정하지 않아, 같은 이름으로 다시 받으면 결과가 다를 수 있습니다(`README.md` ⑥). 서버 실행 로그는 `logs/logs/`에 있습니다.
  - 이 생성·편집본의 실제 파일(AI Hub 소재)은 재배포 제한 때문에 내지 않았습니다. 팀이 보관하고 있으며, 운영진이 이용조건 범위 안에서 확인을 요청하면 따르겠습니다.
