  - Hugging Face에서 받아 학습 자료 제작에만 썼습니다. 제출물에는 포함하지 않았습니다.
- 모든 가짜는 실제 사진과 같은 마지막 처리(768×1024, JPEG 92)로 저장했습니다.

### 3-3. 학습 방법
- 학습 가중치: 실제와 가짜가 각각 50%, 가짜 안에서는 6개 유형이 균등하도록 표본 가중을 줬습니다(기본 판별기). 전문가는 실제 대 해당 유형 가짜를 50:50으로 맞췄습니다.
- 국소 조각 전문가의 조각 라벨: 편집 위치를 아는 가짜(자체 인페인팅 되붙임판·부분 스타일, GPT 편집본은 원본과의 차이로 위치 추정)에서 편집 영역을 25% 이상 덮거나 편집 픽셀의 절반 이상을 담은 조각 = 가짜, 실제 사진 조각과 되붙임판의 편집 밖 조각 = 실제.
- 로지스틱 회귀: C=0.05, 입력 표준화.
- 결정나무 부스팅: max_iter 300, learning_rate 0.05, max_leaf_nodes 15, l2 1.0, random_state 0.
- 검증: 농장 코드 단위 5겹 교차검증(같은 원본의 실제·가짜는 같은 폴드)과 공개샘플 21장(학습 미사용)으로 구성을 골랐습니다.
- 제출 모델은 전체 자료로 다시 학습했습니다.
- 공개샘플 21장은 학습에 넣지 않았습니다.

## 4. 최종 출력 처리 (10/5 중간 안내 3절 항목)
| 항목 | 내용 |
|---|---|
| 계산식 | p1 = 로지스틱(CLIP 조각 평균 특징), p2 = 결정나무 부스팅(저수준 38특징), **p = (p1 + p2) / 2** |
| 원본 대조 규칙 | 이미지 12×16 RGB 지문과 DB 지문의 평균 절대차 중 1위 d1, 2위 d2, gap = d2 − d1. **3.5 < d1 < 20 이고 gap > 8 이고 p ≥ 0.25 이면 p ← max(p, 0.9)**, 아니면 p 그대로 (제출 01에서 p ≥ 0.25 조건 추가: 연속 촬영 이웃 사진 때문에 실제 사진에 규칙이 잘못 걸리는 경우를 줄임) |
| 전문가 결합 | 전문가 점수 s_k와 고정 문턱 θ_k(E_pg 0.7262, E_ps 0.8969, E_L 0.99908)로 g_k(s) = 0.5·s/θ_k (s<θ_k) 또는 0.5+0.5·(s−θ_k)/(1−θ_k), **최종 p = max(p, g_E_pg, g_E_ps, g_E_L)** |
| θ_k 결정 근거 | 학습 자료 농장 5겹 교차검증 OOF에서, 기본이 실제로 판단한 실제 사진 중 0.4%만 가짜로 뒤집는 값을 교차 적합(각 폴드는 다른 폴드의 실제 사진으로 결정)으로 구해 시드 6·7·8 × 5폴드 15개를 평균했습니다. 리더보드 점수·평가 자료는 쓰지 않았습니다. |
| 사용 값의 결정 근거 | 두 갈래 평균은 교차검증에서 단일 갈래보다 균형 정확도가 높았습니다. 원본 대조 규칙은 공개샘플 가짜 일부의 원본을 AI Hub에서 찾아 비교한 분석(원본은 거의 그대로이거나 일정 정도 변형됨)에서 착안했고, 문턱(3.5·20·8)은 학습 자료에서 측정한 분포로 정했습니다. 원본이 있는 실제 사진의 d1 99분위 3.29(축소·재확대한 실제 대조군은 3.72), 원본 없이 이웃 프레임만 있는 실제 사진의 gap 95분위 8.06이었습니다. 학습 자료 기준 규칙 발동률은 원본 있는 실제 약 0.5%, 원본 없는 실제 약 4%, 가짜 약 13%입니다. 0.9는 규칙 발동 시 가짜로 판정되도록 고정한 값입니다. |
| 결정에 사용한 자료 | 위 학습 자료(AI Hub 실제 + 자체 제작 가짜)와 공개샘플 21장(검증 참고)만 사용했습니다. 평가 자료나 그 통계는 쓰지 않았습니다. |
| 실행 중 갱신 | 없음 (모든 값 고정, 이미지마다 독립 계산) |
| 예외 대체 | 이미지별 고정 규칙: 저수준 특징 계산 실패 → p1만, CLIP 계산 실패 → p2만, 둘 다 실패 → 0.5, 결과가 NaN이면 0.5, 원본 대조 실패 시 규칙 미적용, 전문가 계산 실패 시 그 전문가 미적용 |
| 임계값 | 별도 임계값 없음 (운영위원회 기준 0.5 그대로) |
| 확률 보정 | 없음 |
| 앙상블 | 기본: 두 갈래 확률의 산술 평균(0.5/0.5 고정). 위원회: 기본과 전문가 셋의 변환 확률 중 최댓값 |
| (나단8·9) 전문가 H | 정밀 원본 대조 뒤에 p ← max(p, g(s_f), g(s_ps2), g(s_g7), g(s_gr)). 배포 형식 파일에만 적용(형식 게이트). θ·θ_rc는 config.json "h" |

## 5. 실행 관련 특이사항
- `load_model(model_dir)` / `predict(model, image_paths)` 계약을 유지했습니다. CLIP 계산도 이미지 1장(9조각)씩 하므로 함께 들어온 이미지나 입력 순서와 무관하게 결과가 같습니다.
- GPU가 있으면 CUDA(fp16)로, 없으면 CPU(fp32)로 동작합니다. 저수준 특징은 CPU 스레드로 병렬 계산합니다. GPU 없이 CPU만으로 실행되면 524장에 5분을 넘길 수 있습니다(ViT-L 계산).
- 실측
  - 자가검증 PASS(공개샘플 21장, 순서 독립성 OK)
  - 521장을 서버 GPU + CPU 2코어로 제한해 로딩 3.1초 + 추론 63.2초(제출 01은 46.3초). CLIP 계산 부분만 200장 13.5초(제출 01 7.5초). T4에서는 GPU 부분이 더 느려 5분 이내이지만 여유가 제출 01보다 작다고 추정합니다
  - T4 기준 5분 이내로 추정합니다.
- 사용 패키지: torch, numpy, pillow(기본), opencv-python, safetensors(추가 허용 목록, `requirements.txt`에 기재). 네트워크 접근·다운로드·설치 코드 없음.
- AI Hub 원본 사진과 파생 이미지는 제출물에 넣지 않았습니다. `fp_db.npz`는 원천 tar 306개의 사진별 12×16 색 평균값(사진당 576바이트)만 담은 파생 통계입니다.
