# IM 후보 H — 유형 1~5 전문가 추가 (v1, 실행 전 등록 2026-10-15 03:00)

## 목표
나단6 오답률 상위 5유형을 줄인다. 근거는 R2·봉인 기준이다.
1. 강한 JPEG 압축 필터 20.7%
2. 부분 스타일 16.1%
3. 국소 재생성(7판) 13.6%
4. 흐림 필터 9.1%
5. 잡음 필터 8.1%

## 구성 (나단6 출력 뒤에 덧붙임 — 진짜 확정 규칙이 덮어쓰지 못하게)
- p_H = max(p_나단6, g_f(s_f), g_ps(s_ps), g_g7(s_g7)), g는 나단6과 같은 θ 사상(g(θ) = .5)
- E_f(필터): 표준화 + 로지스틱. 입력은 저수준 38특징 + L/14 조각평균 임베딩 768이고, 진짜 대 필터 3종(jpeg·blur·noise)으로 학습한다.
- E_ps2(부분 스타일 조각): B/16 54조각 임베딩(512)의 로지스틱, 54조각 최댓값
  - 조각 라벨: 부분 스타일 가짜에서 마스크 겹침 ≥ .3인 조각 = 1, 진짜 조각 = 0
- E_g7(국소 재생성 조각): 같은 방식으로 7판 마스크를 쓴다.
- 모두 이미 계산하는 특징을 그대로 쓰므로 추론 시간·용량 증가가 거의 없다.
- θ_k: 진짜를 0.25% 뒤집는 값
  - 진짜 풀 = H 학습 진짜의 묶음 5폴드 교차 예측(OOF) + 학습에 안 쓴 진짜 세트(newreal 795, realg 300, realn 300)의 전체 모델 점수
  - θ_k = 그 풀의 99.75% 분위
