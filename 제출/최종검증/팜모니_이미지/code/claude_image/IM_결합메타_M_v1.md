# IM 후보 M — 결합 메타 모델(stacking) (실행 전 등록 2026-10-15 20:40, 연구실 클로드)

## 왜
- 나단9(= 나단8 + E_gr)의 결합은 p = max(p6, g(s_k))다. g(s) = .5·s/θ라서 θ 근처 전문가 점수가 모두 p .45~.5로 눌린다.
- 그 결과 놓친 가짜(R2·R3·R4)는 모두 p .40~.50에 있다. 진짜 대부분도 같은 구간에 있어 판정선을 옮겨서는 가를 수 없다(`IM_나단9_점검_v1.md`).
- 가설: 기본 판별기 점수와 전문가 점수 여러 개를 **더해서**(로지스틱 하나) 보면, "전문가 둘이 함께 조금씩 높은" 가짜를 진짜와 가를 수 있다.

## 구성 (후보 하나만, k = 1)
- **형식 게이트 안**(JPEG 4:2:0 + PIL Q92 양자화표, 나단8/9와 같음): p_M = 메타 로지스틱 출력. **게이트 밖**: p6 그대로(나단9와 같음).
- 메타 입력 7개: logit(p6), logit(ppre), rc(진짜 확정 0/1), logit(E_f), logit(E_ps2), logit(E_g7), logit(E_gr). logit은 [1e-4, 1−1e-4]로 자른 뒤 계산한다.
- 메타 = 표준화 + 로지스틱(C = 1, class_weight balanced). 판정선 .5(고정, 조정 안 함).
- 배포 시 전문가 = 나단9 전문가 그대로(h_model_h2 + ip_model_v1). 메타만 새로 학습한다.

## 메타 학습 자료와 OOF
- 자료: im_set_h3 3,600(진짜 1,800 + 필터 3종·부분 스타일·v7) + im_set_h3j 흔들기 진짜 1,800 + im_set_h3s 작은 부분 생성 450 + im_set_h3g SDXL 재그리기 500 + im_set_gptr 학습 절반 72 + 그 짝 진짜 72. (게이트 안·ok인 사진만)
- p6·ppre·rc: 나단6 고정 모델 출력. h3 원본은 나단6 학습 뒤 새로 뽑은 사진이라 표본 밖이다.
- **전문가 점수는 모두 OOF**: 촬영 묶음(group) 5폴드. 폴드마다 E_f·E_ps2·E_g7(im44 train 그대로, h3+h3j 학습 폴드)과 E_gr(im59 방식, 양성 = 학습 폴드의 GPT, 음성 = h3 진짜 + 흔들기 + 짝 진짜)을 다시 학습해 빠진 폴드 사진을 점수 매긴다. GPT 학습 2묶음은 서로 다른 폴드로 고정한다(im59와 같음).
- 메타 자체도 같은 폴드로 교차 예측해 학습 자료 안 성능을 참고로 낸다(나단9 규칙에 OOF 점수를 넣은 것과 비교).
