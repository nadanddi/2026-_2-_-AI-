# 후보 P: 부분생성 탐지 개선 — 조각 단위 판단 (2026-10-13, 결과 보기 전 등록)

## 문제
- 기준 모델은 GPT 부분생성 25장 중 56~60%만 잡는다(학습에 GPT 없음, `logs/G_eval.log`). 전체생성·전체스타일은 100%다.
- 가설: 지금은 9조각 임베딩을 **평균**한 뒤 판단한다. 그래서 한두 조각에만 있는 국소 편집 흔적이 평균에 묻힌다.

## 비교 (특징·자료 동일, 바꾸는 것 하나)
기준 A = 제출 01 구성(B2 9조각 평균 → 표준화 + 로지스틱 C=.05, 저수준 HGB와 평균, 자료 B = v4 + SD2 + 5판, GPT 학습 제외).

| ID | CLIP 쪽 변경 |
|---|---|
| P1 | 조각 평균 ‖ 조각 최대(차원별 max) 이어 붙이기(1536차원) → 같은 로지스틱 |
| P2 | 조각 단위 학습(MIL): 각 조각에 사진 라벨, 가중 w/9 → 사진 점수 = 조각 확률 상위 2개 평균 |

저수준 HGB와 L2 규칙은 모두 동일하다.

## 평가 (`im05r_eval_pgen.py`, 서버)
- 시드 0/1/2, 농장 폴드, GPT 100장은 학습에 넣지 않고 OOF 예측만 받는다(외부 생성기 시험대).
- 주 지표(L2 전 평균 확률)
  - ① 우리 자료 부분생성 OOF
  - ② GPT 부분생성 25장
- 판정(안 2개 → 본페로니 α=.025). 시드 3개 **모두**에서 다음을 만족하면 후보.
  1. ① 상승
  2. ② 상승
  3. 실제 OOF 오탐(L2 후) ≤ A + .01
  4. GPT 외 OOF 균형 정확도(L2 후) ≥ A − .003
  5. 부분생성 행(① ∪ ②)의 시드 평균 확률 차에 농장 단위 짝 부트스트랩(2000회) → p_worse < .025
  - 둘 다 후보면 균형 정확도가 높은 쪽.
- 진단: 부분스타일(우리 자료·GPT), 유형별 탐지율, 공개 21장, 판정에 쓰지 않는 CLIP 단독 비교.
