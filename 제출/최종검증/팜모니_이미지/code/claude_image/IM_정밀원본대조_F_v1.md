# 후보 F: 정밀 원본 대조 (2026-10-14, 지문 생성 중·결과 보기 전 등록)

## 아이디어
- 공개 진짜 3장 중 2장은 AI Hub 원본과 거의 같았다(거친 지문 d1 1.4).
- 가짜는 원본이 있어도 반드시 어딘가 바뀌어 있다.
- 지금 지문(12×16 RGB 평균)은 너무 거칠어서 블러(1.7~1.9)·작은 편집을 진짜(1.4)와 가르지 못한다.
→ **정밀 지문**으로 "원본과 거의 같음 = 진짜 / 원본은 있는데 다름 = 가짜"를 판정하고, **원본을 못 찾은 사진만 모델(나단5)이 판정**한다.

## 정밀 지문 (`colab_정밀지문.py`, AI Hub 원천 152k장, Colab에서 생성)
- g: 덮게 축소·가운데 크롭(세로 768×1024 통일) 후 흑백 24×32 평균(uint8)
- e: 64px 구역 12×16의 라플라시안 분산 log값(uint8)
- 시험 사진도 같은 함수로 계산한다(이미 배포 크기라 축소·크롭은 거의 그대로 통과).

## 대조 특징 (사진마다)
- 원본 후보: g의 L1 거리 최소 1·2위 → dg1, gap = dg2 − dg1
- 1위 후보와의 차이
  - dg_max: 칸별 |g 차|의 상위 2% 평균(국소 편집 위치)
  - de_mean: |e 차| 평균(전체 선명도 변화: 블러·노이즈·재그리기)
  - de_max: |e 차| 상위 5% 평균(국소 질감 변화)

## 규칙 (문턱은 학습 자료에서 사전 정의한 절차로 정함, `im36`)
- 정함 자료
  - 진짜: v4·v5 학습 진짜 중 자기 원본이 DB에 있는 사진
  - 가짜: v4·SD2·5판·6판·GPT1/2 가짜 중 원본이 DB에 있는 사진
- 원본 판정 조건(Match): dg1 ≤ T_m 이고 gap ≥ T_gap. T_m = 진짜 dg1의 99.5분위, T_gap = 진짜 gap의 1분위.
- Match 안에서
  - **진짜 확정:** dg_max ≤ 진짜 99분위 그리고 de_mean ≤ 진짜 99분위 그리고 de_max ≤ 진짜 99분위 → p ← min(p, 0.05)
  - **가짜 확정:** dg_max·de_mean·de_max 중 하나라도 진짜 99.9분위 초과 → p ← max(p, 0.95)
  - 그 사이 → 모델 그대로
- Match가 아니면(원본 없음) → 모델 그대로(기존 R1 규칙 포함)
- 진짜 99.9분위 기준으로 정하므로, 원본 있는 진짜의 오탐 증가는 약 0.1% 이하로 설계된다.
