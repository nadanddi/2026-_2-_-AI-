# 후보 G3 재등록 v2 (2026-10-13 저녁, v1 실행은 끝났으나 결과 미열람, 계획 비평 반영)

v1(`IM_GPT학습_G3_v1.md`)의 판정은 폐기한다. 자료와 안(A·G3a·G3b)은 v1 그대로다.

## 비평 반영
1. 이 시험은 GPT → GPT 전이만 본다. 통과해도 **"GPT 계열 한정 효과"**로만 표기한다.
   - 다른 생성기로의 전이는 G1·G2의 SD2 시험에서 이미 0으로 확인됐다.
2. 점수를 위로 미는 것만으로 통과하지 못하도록 **순위 능력(AUC)**을 주 조건에 넣는다.
3. **처리 경로 지름길 방지:** GPT 원본은 약 0.7배만 축소되지만 진짜 사진은 크게 축소된다. 이를 막기 위해 **CLIP 갈래 단독의 v3 AUC도 올라야** 한다.
4. L2 규칙 적중률, L2 전 탐지율, 농장 수를 출력한다.

## 판정 (A 대비, 시드 0/1/2 **모두**, 안 2개 → α=.0125)
1. v3 대 OOF 진짜 AUC(L2 전, 두 갈래 평균) 상승
2. v3 대 진짜 AUC(**CLIP 갈래 단독**) 상승
3. v3 탐지율(.5, L2 후) ≥ A + .05
4. 진짜 OOF 오탐(L2 후) ≤ A + .01
5. GPT 외 OOF 균형 정확도 ≥ A − .003
6. 농장 단위 짝 부트스트랩(v3 + 진짜 행, 시드 평균): **AUC(L2 전) 차**의 p_worse < .0125
- 둘 다 후보면 판정 1의 AUC가 높은 쪽.

## 진단 (판정과 무관)
- 저수준 갈래 단독 v3 AUC
- 진짜 오탐을 A와 같게 맞춘 임계값에서의 v3 탐지율
- 진짜 + v3 logloss
- 공개 21장 logloss
- v3를 1단계 / A방식 최종 / B방식 최종 / 부분스타일로 나눈 탐지율
- v3 L2 적중률
- v3 농장 수
