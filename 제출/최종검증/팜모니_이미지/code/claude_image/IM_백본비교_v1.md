## 지표 (각 시드 3개: 폴드 순열 + 90% 농장 부분표본)
1. OOF 균형 정확도(실제 .5 + 6유형 탐지 평균 .5), 전체·보조(공개 닮은 자료)
2. 실제 오탐(OOF)
3. 유형별 탐지
4. 공개 21장: 정확도·로그손실·AUC. **열람 상한을 이미 넘어 참고 서술만** 한다.

## 판정
- 순위는 지표 1(시드 평균)로 매긴다.
- 기준 B1 대비 '모든 시드에서 지표 1 상승 + 실제 오탐 비증가(+1%p 이내)'인 백본만 다음 단계 후보로 둔다(여럿이면 상위 2개).
- 최종 확인은 리더보드(사용자 결정)다.
- 가짜 제작 5판이 나오면 상위 후보로 다시 비교한다.

## 제약
- 제출 1GB: 백본 fp16 + 저수준 모델 + (L1이면 지문 DB) 합계가 넘지 않아야 한다.
- T4 5분: 524장 × 10보기. 패키지를 만들 때 실측한다.

## 추가 등록 (10-12, 결과 보기 전): 2개 앙상블
- 모든 쌍에 대해 (백본 A 확률 + 백본 B 확률)/2 → 저수준과 평균. 같은 지표·같은 시드.
- 용량: fp16 기준 큰 모델 두 개는 1GB를 넘는다 → 8비트 저장(로드 시 fp16 복원)으로 줄여야 한다. 실현 가능성과 정확도 손실은 제출 패키지 단계에서 실측한다.
- 채택 규칙은 단일 모델과 같다(B1 대비 모든 시드 상승 + 실제 오탐 비증가). 쌍이 많아 선택 편향이 크므로 최종은 리더보드로 확인한다.
