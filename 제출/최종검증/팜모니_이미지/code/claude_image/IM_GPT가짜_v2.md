# 후보 G 재등록 v2 (2026-10-13, v1 결과를 열어 보기 전, 비평 반영)

v1(`IM_GPT가짜_v1.md`) 판정은 폐기한다. 이유(계획 단계 비평): "GPT 탐지율 > A"는 같은 생성기를 학습하면 당연히 오르므로 질문(운영진의 모르는 생성기를 더 잘 잡나)에 답하지 못한다. v1 결과는 진단으로만 본다.

## 주 시험: 생성기 하나를 빼고 옮겨 가는지 (`im05q_eval_gpt_lopo.py`)
- 뺄 생성기 H 두 가지
  - H=XL: 5판 SDXL 4종(ai_gen_xl, full_style_xl, partial_gen_xl, partial_style_xl)
  - H=SD2: im_set_sd2의 가짜 전부
- H 가짜는 모든 안에서 학습에서 뺀다. 다른 가짜·실제·폴드·부분표본은 세 안이 같다.
  - A0: GPT 제외
  - G1: GPT 100장 추가(기존 가중)
  - G2: GPT 추가 + 유형 안 GPT 몫 25%
- 주 지표: H 가짜의 **L2 적용 전** OOF 평균 확률(연속값, 천장·동률 회피). 보조로 탐지율(L2 전·후)도 본다.
- 판정(안 2개 → 본페로니 α=.025). H 2개 **모두**에서 아래를 만족하면 후보.
  1. 시드 3개 모두 H 평균 확률 G > A0
  2. 농장 단위 짝 부트스트랩(시드 평균 예측 차, 2000회) p_worse < .025
  3. 실제 OOF 오탐(L2 후) ≤ A0 + .01, 시드 3개 모두
  - 둘 다 후보면 H 평균 확률 상승이 큰 쪽.

## 진단 (판정과 무관)
- v1의 GPT 자체 탐지율을 L2 전·후로 본다.
- 지름길 점검(A0 기준, 학습에 GPT 없음): GPT 탐지율을 CLIP 단독과 저수준 단독으로 따로 본다. 세로 사진만 따로도 본다.
  - 저수준만 GPT를 잘 잡으면 처리 경로 차이(축소 비율·단일 압축·가로 비율 23%)를 단서로 썼을 가능성이 있다.
- 공개 21장 정확도·로그손실은 참고만 한다.

## 비평에 대한 메모
- "GPT 부분 편집 = 사실상 전체 재그림" 지적 관련: 10-12에 공개 샘플을 원본과 대조해 보니 운영진 부분생성도 "전체 약한 재표현 + 일부 재생성"이었다. 그래서 이 점은 오히려 운영진과 비슷할 수 있다. 마스크로 편집 영역만 되붙인 판은 이번 결과를 보고 필요하면 따로 등록한다.
