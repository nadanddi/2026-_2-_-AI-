**부분생성 프롬프트 규칙** (원본마다 아래를 돌아가며 섞기)
- 무엇을: 추가 / 지우기 / 바꾸기를 고르게 섞는다.
  - 추가: 흰 딸기 꽃, 빨간 딸기, 초록 열매, 새 잎, 런너
  - 지우기: 시든 잎, 이름표, 호스 한 가닥, 끈끈이 트랩
  - 바꾸기: 포기 하나를 다른 딸기 포기로, 이름표를 다른 모양으로
- 크기: 사진의 **아주 작은 부분(잎 1~2장 크기)**부터 **포기 하나 크기**까지 섞는다. 작은 편집을 절반 이상으로 한다.
- 위치: 위·아래·왼쪽·오른쪽·가운데를 고르게 쓴다.
- 문장에 꼭 넣을 것:
  - "그 작은 영역만 새로 그리고 나머지 구도·사물·잎·시설·바닥·조명·색감은 그대로 보존"
  - "원래 사진과 구분 안 되게 사진처럼 사실적으로"
  - "원본과 같은 가로세로 비율"
  - "사람·얼굴·새 글씨·워터마크 없음, 결과 한 장만"

**부분스타일 프롬프트 규칙**
- 대상: 잎 몇 장 / 포기 하나 / 앞쪽 잎들 중 하나만
- 스타일: 수채화·유화·색연필·디지털 페인팅·파스텔
- 강도: **약하게(질감만 살짝)**와 **뚜렷하게**를 반반
- "나머지는 사진 그대로, 사진 전체를 다시 그리지 말 것"을 반드시 넣는다.

**기록:** 프롬프트 전문, 원본 파일, AI허브 원천(`원본2_목록.csv`의 열), 크기·sha256을 manifest에 적어 줘. 실패하거나 거절된 건은 README에 개수만 적어 줘.
