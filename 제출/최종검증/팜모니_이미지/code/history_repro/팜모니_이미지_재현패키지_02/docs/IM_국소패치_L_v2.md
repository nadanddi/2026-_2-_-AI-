# 후보 L 재등록 v2 (2026-10-14, v1 실행 전 중지·결과 미열람, 계획 비평 반영)

## 치명 수정
1. **양성 조각 기준**
   - 조건: 겹침 ≥ .25 **또는** 그 조각이 사진 전체 마스크 픽셀의 50% 이상을 담고 있음.
   - 이유: GPT 편집은 넓이 중앙값이 약 1.5%라 v1 기준으로는 양성이 0개인 사진이 59%였다.
2. **GPT 부분 편집에서는 음성 조각을 쓰지 않는다.**
   - GPT는 사진 전체를 다시 그리므로, 편집 밖 조각도 원본 픽셀이 아니다.
   - 음성 조각은 6판·5판(실제로 되붙인 판)과 진짜 사진에서만 뽑는다.

## 중요 수정
3. **θ를 교차 적합으로 정한다.**
   - 폴드 f의 θ는 **다른 폴드들의 OOF 진짜 사진**에서 정한다(뒤집힘 1.0% 기준).
   - 폴드 f 자신의 진짜 사진은 θ를 정하는 데 쓰지 않는다.
   - 공개 21장에는 다섯 θ의 평균을 쓴다.
4. **판정 1의 최소 증가폭:** GPT 검증 부분 편집 탐지율이 A보다 **+.03 이상** 올라야 한다(시드 3개 모두).
5. **시드 반복을 강하게:** 조각 표본 추출(진짜 12개·음성 6개 무작위)을 시드마다 다르게 한다.
6. **검산:** 6판·5판의 farm_code가 source 파일명의 접두와 같은지 assert한다.

## 판정 (안 1개, α=.025, 시드 3개 모두)
1. GPT 검증 부분 편집 탐지율 ≥ A + .03
2. 추정 정확도 > A
3. 진짜 오탐 ≤ A + .012 (θ를 교차 적합으로 정하므로 자동 통과가 아니다)
4. 농장 부트스트랩 p_worse < .025
