# 후보 G3c: GPT 학습 + 오탐 맞춤 임계값 (2026-10-13 밤, 결과 보기 전 등록)

## 근거
- G3 v2(`IM_GPT학습_G3_v2.md`): v3 탐지 .59 → .93~.97, CLIP AUC .86 → .98~.99로 다른 조건은 모두 통과했다.
  - 다만 GPT 외 균형이 −.004~−.010으로 기준 미달이었다.
  - 하락의 약 절반은 진짜 오탐 증가였다.
- 지름길 반증(`IM_G3_지름길반증_v1.md`): 지름길은 없었다.

## 안 (2개)
- **G3c1:** A 자료 + GPT v1·v2 250장, 유형 안 GPT 몫 **10%** + 임계값 τ
- **G3c2:** A 자료 + GPT 250장(기존 가중 = G3a) + 임계값 τ

## 임계값 τ (교차 적합, 리더보드 미사용)
- 폴드 f의 τ는 **다른 폴드들의 OOF 진짜 사진**(L2 후)에서 정한다.
  - 기준: 그 사진들에서 A(.5 기준)의 오탐률과 같아지는 값
  - 폴드 f 자신은 τ를 정하는 데 쓰지 않는다.
- 공개 21장에는 다섯 τ의 평균을 쓴다.

## 시드
- **3/4/5 (새 시드).** 0~2는 이미 결과를 본 시드다.

## 유의수준
- GPT 학습 질문에서 누적 안이 6개다(G1·G2·G3a·G3b·G3c1·G3c2).
- 본페로니 α = .025 / 6 ≈ **.004**

## 판정 (A(.5) 대비, 시드 3/4/5 **모두**)
1. v3 대 OOF 진짜 AUC(L2 전) 상승 **그리고** CLIP 단독 AUC 상승
2. v3 탐지율(τ) ≥ A + .05
3. 진짜 OOF 오탐(τ) ≤ A + .005
4. GPT 외 OOF 균형 정확도(τ) ≥ A − .003
5. 농장 부트스트랩(v3 + 진짜, 시드 평균): AUC 차의 p_worse < .004
- 둘 다 후보면 균형 정확도가 높은 쪽.
