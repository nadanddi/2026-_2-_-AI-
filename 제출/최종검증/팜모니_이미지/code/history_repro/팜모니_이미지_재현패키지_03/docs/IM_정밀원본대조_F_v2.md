# 후보 F 재등록 v2 (2026-10-14 오후, v1 실행 중지·결과 미열람, 계획 비평 반영)

정밀 지문 DB와 대조 방식은 v1과 같고, 특징·문턱·규칙·판정을 고친다.

## 고친 점
1. **사진 전체의 선명도 변화(de_mean)는 가짜 확정에 쓰지 않는다.** 운영진의 축소·압축 방식 차이로 진짜 전체가 밀릴 수 있다. 대신 국소 변화만 본다.
   - loc_g = |g 차| − 중앙값(|g 차|)의 상위 2% 평균
   - loc_e = |e 차 − 중앙값(e 차)|의 상위 5% 평균
   - glob_e = 중앙값(e 차)(전체 선명도 이동, 진단과 진짜 확정에만 사용)
2. **문턱은 '처리 흔들기' 진짜로 정한다.** 서버 원본(im_real_raw)에서 진짜 1,500장을 고르고, 사진마다 축소 방식 4종(LANCZOS / BICUBIC / BILINEAR / AREA) 중 하나와 JPEG 품질 70~95를 무작위로 적용해 배포 형식을 만든다. 1위 후보가 자기 원본인 것만으로 분위수를 잡는다.
3. 규칙
   - 원본 판정(Match): dg1 ≤ T_m(흔들기 진짜 99.5분위) 그리고 gap ≥ T_gap(흔들기 진짜 5분위)
   - **가짜 확정:** Match이고 (loc_g > 흔들기 진짜 99.9분위 또는 loc_e > 99.9분위) → p ← max(p, .95)
   - **진짜 확정:** Match이고 loc_g ≤ 95분위, loc_e ≤ 95분위, |glob_e| ≤ 95분위이고 **나단5 p < .8** → p ← min(p, .3)
   - 나머지는 나단5 그대로
4. 진단을 늘린다.
   - 흔들기 진짜 별도 표본 500장(문턱 정할 때 안 쓴 것)의 오탐 변화(운영진 처리 차이 대리)
   - 1위 후보 ≠ 자기 원본인 진짜(이웃 프레임)의 가짜 확정 비율
   - 공개 21장 개별 특징과 판정(jixx·qube 진짜 확정 여부, vfjx·jrtg 가짜 확정 여부)

## 판정 (모두, 탐색적)
1. R2 정확도 > 나단5, 묶음 부트스트랩 p_worse < .025
2. 흔들기 진짜 별도 500장 오탐: F ≤ 나단5 + .005
3. 봉인 진짜 400 오탐 ≤ 나단5, 판정용 밝음·갈변 오탐 ≤ 나단5
4. 봉인 가짜(Qwen + 7판) 탐지 ≥ 나단5
5. 공개 21장 정답 수 ≥ 나단5
