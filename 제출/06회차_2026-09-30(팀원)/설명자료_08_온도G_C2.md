## 1. 한 줄 요약

5회차 온도 모델에 **Codex 구성원과 TabPFN 구성원을 섞되, 실내온도에 따라 비율을 바꿉니다.** 따뜻한 행에서는 TabPFN을 20% 넣고, 학습 범위 밖의 추운 행에서는 TabPFN을 빼고 추운 날에 가장 강한 Codex 구성원의 몫을 60%로 올립니다.

## 2. 구성

```
g    = clip((현재 시각 실내온도 − 8) / 2, 0, 1)
예측 = (0.6 − 0.2(1−g)) × 기준 + (0.2 + 0.4(1−g)) × Codex + 0.2 g × TabPFN
```

| 실내온도 | 기준 | Codex | TabPFN | 평가 행 수 |
|---|---|---|---|---|
| 10℃ 이상 | 0.6 | 0.2 | 0.2 | 1,009 |
| 8~10℃ (선형 전환) | 0.4~0.6 | 0.2~0.6 | 0~0.2 | 216 |
| 8℃ 이하 | 0.4 | 0.6 | 0 | 215 |

| 구성원 | 내용 |
|---|---|
| 기준 | 5회차 온도 구성 그대로(피처 135개, 0.65 물리 선형+LGB 잔차 · 0.25 Ridge · 0.10 Nystroem, 시드 7·101·2024) |
| Codex | Ridge 물리 기준선 + LGB 잔차, 자정 재시작 잔차 피처 89개, 시드 726·727 평균 |
| TabPFN | v2 회귀, CPU, 학습 행 2,000개 문맥(5회차 가중치 비례 추출), 표본 1~8 평균 |

학습 행 가중치는 5회차와 같습니다(복원 행 + 잡음 낀 날 0.2, 9,600행 중 2,341행). 학습 행 피처는 **MASK 세계**(test 입력을 모두 비운 상태)에서 계산해 모델이 평가 입력을 보지 않습니다(카탈로그 6.30).

## 3. 왜 이 구성인가

- **TabPFN은 따뜻한 날에 강하고 추운 날에 크게 틀립니다.** 단독 성능은 진단 폴드에서 가장 좋지만(0.665), 학습 범위 밖 추위에서는 +1.8℃ 편향으로 무너집니다(6.67). 그래서 실내 8℃ 이하에서는 몫을 0으로 줄입니다.
- **추운 행에서는 Codex 구성원이 가장 강합니다.** 추운 날 외삽 검증 8℃ 이하 행에서 Codex 0.713, 기준 0.938(6.70). 다른 온실 32곳의 독립 점검에서도 "트리 0.4 + 선형 잔차 0.6" 비율이 추운 행에서 가장 좋았습니다(6.75).
- **섞는 이득은 오차가 달라서 생깁니다.** 기준과 같은 시야의 TabPFN을 더 넣거나(6.72), 구조가 같은 구성원을 섞으면(6.78) 이득이 사라졌습니다.

## 4. 검증 결과 (카탈로그 수치)

TabPFN 없는 구성(0.8 기준 + 0.2 Codex) 대비, 시드 2쌍 × TabPFN 표본 묶음 2개:

| 검증 | 변화 |
|---|---|
| DIAG10 (겹치지 않는 진단 폴드) | −3.0 ~ −3.3% |
| EXT10 (10℃ 미만 날 통째로 제외) | −1.8 ~ −2.0% |
| EXT12 | −3.1 ~ −3.2% |
| EXT8 (11일, 미사용 검증기) | 8℃ 이하 행 0.81 → 0.77 |

평가 날짜가 속한 2차 구간(179일 이후)만 보면 DIAG10 −1.9 ~ −2.1% 입니다. **기대 개선은 2% 안팎, 온도 약 0.535** 입니다(6.74).

## 6. 위험 — 제출 전에 알아야 할 것

**가장 추운 133행을 평균 0.18℃ 내립니다.** 4회차(한랭 힌지)도 추운 행을 약 0.1~0.3℃ 내렸다가 0.5624 → 0.5697로 나빠졌습니다.

- 4회차와 다른 점: 4회차는 "추울수록 배지가 더 차갑다"는 잘못된 전제(2.5b에서 철회)로 기준선 식을 바꿨고, 이번은 추운 날 검증 네 가지(EXT8/10/12, 다른 온실 32곳)에서 모두 좋았던 구성원 비율입니다.
- 같은 점: 추운 행의 방향이 "내림"이라는 것. 평가 행 9%가 6℃ 이하인데 학습 라벨은 21행뿐이라 **이 구간은 로컬 검증으로 확정할 수 없습니다**(6.54).
