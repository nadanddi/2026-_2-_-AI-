# 이미지 미션 제출 01 (팜모니_나단1) — 팀원용 설명

## 한 줄 요약
팀원 v5·v7과는 다른 계열의 모델입니다.
- 사진을 보는 부분은 **이미 학습된 CLIP(336px)** 을 그대로 쓰고, 위에 가벼운 판정기를 올렸습니다.
- **사진 신호 통계 판정기**와 확률을 평균합니다.
- AI허브 원본과 비교해 **"원본이 있는데 바뀐 사진"을 잡는 규칙**을 더했습니다.

## 1. 왜 이렇게 바꿨나
- v5·v7(고주파 ResNet18)은 리더보드 0.77에서 멈췄습니다. 같은 자료로 비교해 보니 약점은 두 가지였습니다.
  - **합성**을 거의 못 잡음
  - **부분 편집**이 패치 안에서 희석됨
- 이 계열(처음부터 학습하는 CNN)은 우리가 만든 가짜의 미세 흔적만 외우고 운영진 가짜로는 일반화되지 않았습니다. 연구실 CNN 실험에서 공개 21장 9~10장이었습니다.
- 이미 학습된 CLIP 특징 + 간단한 판정기는 운영진 가짜에 더 잘 일반화했습니다(공개 15~18장 → 최종 구성 19~21장).

## 2. 모델 구성
| 단계 | 내용 |
|---|---|
| ① 의미 판정 | CLIP ViT-L/14@336이 원해상도 336 조각 9개를 보고, 특징 평균 → 로지스틱 회귀 → p1 |
| ② 신호 통계 판정 | 잡음·선명도·JPEG 격자·채도·주파수 등 38개 통계 → 결정나무 부스팅 → p2 |
| ③ 결합 | p = (p1 + p2) / 2 |
| ④ 원본 대조 규칙 | AI허브 15만 장의 12×16 색 지문과 비교해, "가장 닮은 원본이 하나 뚜렷한데 중간 정도로 달라졌으면"(3.5 < d1 < 20, 2위와 간격 > 8) p를 0.9 이상으로 올림 |

용량은 661MB입니다(CLIP 581MB + 지문 DB 80MB).

## 3. 학습 자료
- **실제**: AI허브 596 원천 사진 2,467장
  - 농장·품종·축소 배율을 고르게 뽑았습니다. 빨간 조명 사진은 제외했습니다.
  - 배포 형식(덮게 축소 → 가운데 768×1024 → JPEG 92)으로 맞췄습니다.
- **가짜**: 7,124장. 문제설명서의 6유형을 직접 만들었습니다.
  - 필터: 블러·잡음·소금후추·JPEG
  - 합성: 작물 분할 / 잎 붙여넣기
  - 스타일·생성: SD1.5와 SDXL로 전체·부분 스타일, 부분 생성, 전체 생성
- "가짜 제작 5판"은 공개 가짜 7장의 **AI허브 원본을 찾아 픽셀 단위로 비교**한 뒤, 운영진 방식대로 만든 자료입니다.
  - 합성: 잎을 오려 붙임
  - 블러: 배포 크기에서 σ≈1.5
  - 부분 생성: 사진 전체를 약하게 다시 그린 뒤 일부를 재생성
- 공개 21장은 학습에 넣지 않았습니다(검증·설계 참고용).

## 4. 검증 결과 (로컬)
| 비교 | 결과 |
|---|---|
| 같은 보류 자료(농장 균형 실제 1,862 + 프로그램 가짜 1,862)에서 팀원 v7 대비 | 균형 정확도 v7 **0.783**(리더보드 0.77과 비슷) → 우리 **0.94**. 실제 정답률 95.1% → 96.9~98.3%, 합성 탐지 0.44 → 0.95, 부분 스타일 0.39 → 0.76. 단, 가짜가 우리 제작 방식이라 우리 쪽에 유리한 비교 |
| 공개 21장(학습 미사용) | 검증 시드별 21/21/20, 최종 모델 **19/21**(nriv·ftkc가 0.485로 아슬아슬하게 놓침). 공개 샘플을 설계에 여러 번 참고했으므로 낙관적인 값 |
| 실제 사진 오탐(우리 자료) | 원본이 있는 사진 3.6~4.3%, 원본 없이 이웃 프레임만 있는 사진 6.8~8.1% |

**예상 리더보드**: 보수적으로 0.85~0.90, 낙관적으로 0.93 이상입니다(추정). 확인은 이번 제출로 합니다.
