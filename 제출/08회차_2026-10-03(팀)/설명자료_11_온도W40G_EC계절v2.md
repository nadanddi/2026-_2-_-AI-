# 팜모니 — 정형데이터 미션 재현 패키지 (submission_11)

제1회 전국 농과계 대학 농업 AI 경진대회, 정형데이터 미션.
최종 답안 `submission_11.csv` (1,440행, row_id·sub_temp·sub_ec)는 두 부분으로 만들어집니다.

| 열 | 담당 | 폴더 | 산출 파일 |
|---|---|---|---|
| sub_temp | 온도 모델 W40G (7회차 W30G(실제 0.5193)에서 따뜻한 행 TabPFN 몫 0.3→0.4, 리더보드 판정용) | `온도/` | `temp_candidate_v12.csv` 의 sub_temp |
| sub_ec | EC 모델 계절 v2 (`day` 대신 계절 지표 `season`) | `EC/` | `submission_10.csv` 의 sub_ec (EC 전달본, sub_temp 빈칸) |

두 열은 `merge_temp_ec_v11.py` 가 row_id로 결합합니다(ID 유일성·같은 집합·1,440행·유한값 검사,
온도 파일 행 순서 = sample_submission 순서, UTF-8, 소수 6자리).

## 재현 절차

1. **온도**: `온도/README.md` 2절. 대회 원본 CSV 3개를 `온도/data/` 에 넣고
   ```bash
   cd 온도/code
   python make_submission_v12_temp.py ../output   # → 온도/output/temp_candidate_v12.csv (CPU 약 20분)
   python temp_v12_checks.py                       # 규정 검사 7개 ALL PASS
   ```
2. **EC**: `EC/설명자료_10_제출8회차.md` 와 `EC/PROTOCOL.md`. EC 패키지는 필요한 입력·체크포인트를 동봉합니다.
   ```bash
   cd EC
   python -B -u reproduce.py --output 새출력폴더    # → EC 전달본 (EC/submission_10.csv 와 같음, EC/verification.json)
   ```
3. **결합**
   ```bash
   python merge_temp_ec_v11.py 온도/output/temp_candidate_v12.csv EC/submission_10.csv 결합_새이름.csv
   ```
   결과가 동봉한 `submission_11.csv` 와 같아야 합니다.

사용하지 않습니다. 생성형 AI 사용 내역은 각 폴더 문서에 있습니다(Anthropic Claude: 온도, OpenAI Codex: EC).
