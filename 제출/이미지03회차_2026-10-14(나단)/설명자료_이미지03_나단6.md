## 2. 구성
| 부분 | 내용 |
|---|---|
| 기본 | 제출 01과 같은 판별기(CLIP ViT-L/14@336 + 저수준 38특징) |
| R1 | 거친 지문(12×16 RGB) 원본 대조. 기본 p ≥ .25일 때만 p ≥ .9 |
| 전문가 | E_pg·E_ps(B2 로지스틱), E_L(ViT-B/16 54조각) OR. θ = .7262 / .8969 / .99908 |
| 전문가 추가 자료 | 새 AI Hub 진짜 795, 되붙임 국소 편집(7판) 234, Qwen-Image-Edit(Apache-2.0) 지시문 편집 390. 봉인 원본을 쓴 사진은 제외 |
| 정밀 대조 | 원본 판정(dg1 ≤ 1.011, gap ≥ 3.474) + 국소 차이(loc_g > 6.569 또는 loc_e > 52.95) → p ≥ .95. 국소·전체 차이가 작고(≤ 3.933 / 24.24 / 13) 나단5 p < .8 → p ≤ .3 |

정밀 대조 문턱은 학습용 진짜에 축소 방식 4종·JPEG 70~95를 무작위로 적용한 사진의 분위수로 정했다.
