## 1. 판정 흐름 (사진 한 장이 들어오면)

```
사진 ─┬─ ① 기본 판별기 ─────────────── p = (p1 + p2) / 2
      │    p1: CLIP ViT-L/14@336, 3×3 조각 임베딩 평균 → 로지스틱
      │    p2: 저수준 통계 38개(잡음·선명도·JPEG 격자·채도·주파수 등) → 부스팅
      ├─ ② 원본 대조 규칙(거친 지문 12×16 색)
      │    AI Hub 원천 15만 장 중 비슷하지만 다른 원본이 있으면 → p ≥ 0.9
      ├─ ③ 전문가 위원회(나단3~5) → p = max(p, 전문가 점수)
      │    E_pg 부분 생성, E_ps 부분 스타일(L/14 임베딩)
      │    E_L 국소 조각(ViT-B/16 54조각, 편집 위치 마스크로 학습)
      ├─ ④ 정밀 원본 대조(나단6) — 흑백 24×32 + 64px 구역 선명도 지문
      │    원본과 거의 같은데 국소적으로 다르다 → 가짜 확정(p ≥ 0.95)
      │    원본과 거의 같고 차이도 작다 → 진짜 확정(p ≤ 0.3)
      └─ ⑤ 전문가 H(나단8, 새로 추가) — 배포 형식 파일에만 적용(게이트)
           E_f   필터(블러·가우시안 노이즈·JPEG 압축)
           E_ps2 부분 스타일 조각
           E_g7  국소 재생성 조각
           → p = max(p, 전문가 점수)
최종: p ≥ 0.5 이면 가짜
```

**⑤를 맨 뒤에 둔 이유**
- 나단6의 "진짜 확정"(④)이 압축·잡음 필터 가짜를 진짜로 바꾸는 부작용이 있었습니다.
  - 압축 필터 탐지 98% → 79%
  - 잡음 필터 탐지 97% → 92%
- 새 전문가가 마지막에 판정하면 이 부작용을 덮어쓸 수 있습니다.

**형식 게이트란?**
- 문제설명서에 따르면 시험 사진은 모두 JPEG입니다. 공개 21장은 모두 JPEG 품질 92, 크로마 4:2:0이었습니다.
- 새 전문가는 이 형식으로만 학습했습니다. 그래서 형식이 다른 파일(PNG, WebP, 4:4:4 등)에서는 전문가를 끄고 나단6과 똑같이 판정합니다.

**전문가 문턱 θ**
- 학습에 쓰지 않은 진짜 사진 약 5,000장에서, **진짜를 0.25%만 가짜로 뒤집는 값**으로 정했습니다.
- 진짜 확정된 사진은 0.1%로 더 엄격하게 둡니다.
- 전문가 셋을 합친 진짜 오탐은 0.40%입니다.
