## 1. 한 줄
제출 01(0.90) 모델을 "기본"으로 두고, 막히는 유형만 보는 **전문가 셋**을 붙였습니다. 기본이 가짜로 보거나 전문가 하나라도 자기 고정 문턱을 넘으면 가짜로 판정합니다. 전문가는 부분 생성·부분 스타일·국소 조각을 맡습니다. 원본 대조 규칙은 기본 확률이 0.25 이상일 때만 걸리도록 고쳤습니다(R1).

## 2. 왜 바꿨나
제출 01의 오답 약 52장은 대략 이렇게 나뉜다고 추정했습니다.
- 부분 생성 놓침 약 27
- 진짜 오탐 약 13
- 부분 스타일 놓침 약 10
- 기타 약 3

진단에서 확인한 것은 세 가지입니다.
- 우리가 SDXL로 만든 부분 생성은 98% 잡았습니다. 하지만 GPT로 만든 부분 편집은 35~40%, GPT가 사진 전체를 사실적으로 다시 그린 사진은 38~44%만 잡았습니다.
- 공개 운영진 부분 편집 6장 중 4장은 AI Hub에서 원본을 찾지 못할 만큼 바뀌어 있었습니다.
- 진짜 오탐의 약 36%가 원본 대조 규칙 때문이었습니다. 연속 촬영된 이웃 사진이 DB에 있어 오인된 경우입니다.

## 3. 구성
| 부분 | 내용 |
|---|---|
| 기본 | 제출 01과 같은 파일(CLIP ViT-L/14@336 조각 평균 로지스틱 + 저수준 38특징 부스팅 평균) |
| 원본 대조 R1 | 3.5<d1<20 · gap>8 · **기본 p≥0.25** → p≥0.9 |
| E_pg | 같은 임베딩, 진짜 대 부분 생성 가짜(우리 + GPT 125) 로지스틱, θ=0.5986 |
| E_ps | 같은 임베딩, 진짜 대 부분 스타일 가짜(우리 + GPT 75) 로지스틱, θ=0.8995 |
| E_L | ViT-B/16 54조각, 편집 위치 마스크로 조각 라벨 지정 → 조각 최댓값, θ=0.99939 |
| 결합 | p = max(기본, g_k(s_k)), g는 θ_k를 0.5로 옮기는 단조 변환 |

θ는 학습 자료 OOF에서 교차 적합(기본이 진짜로 본 진짜 사진을 전문가마다 0.4%만 뒤집는 값)으로 구한 15개 값의 평균입니다. 리더보드 점수는 쓰지 않았습니다.
