## 2. 회차별 상세

### 1회차 — 기준 모델 (연구실 PC, VS Code 클로드)
- **구성**: 온도 LightGBM(Huber) 98열, 3시드. EC ExtraTrees + LightGBM(Huber) 평균 68열(`--ec current`).
- **학습 자료**: 정답이 있는 F13·F47 9,600행만 사용. 다른 49개 온실은 검증에서 도움이 안 돼 제외.
- **결과**: 0.7450 / 0.2442. 기준선(온실 평균)은 4.62 / 0.41입니다.
- **배운 점**: 검증 분할에 따라 기대 점수가 크게 달랐습니다. 라벨까지 거리를 실제와 맞춘 "test 배치 평행이동 CV"가 실제 점수에 가장 가까웠습니다.
- **자료**: `연구실/클로드/README.md`, `연구실/클로드/HANDOFF.md`, 채점 화면 `1회차_채점결과.png`.

### 2회차 — 피처 축소와 모델 혼합 (집 노트북 클로드)
- **바꾼 것**:
  - EC 피처를 68개에서 14개로 줄였습니다.
  - 온도 피처는 98개에서 93개로 바꿨습니다(전일 집계 24개 제거, 새 파생 19개 추가).
  - 트리·Ridge·커널/MLP를 혼합했습니다.
  - EC 예측의 하루 안 흔들림을 눌렀습니다(모델이 만든 하루 안 변동은 실제와 상관 0.21).
- **노린 것**: EC는 실효 표본이 약 400 온실-일뿐이라 과적합을 줄이려 했습니다.
- **결과**: 0.6666 / 0.2287. 교차검증은 온도 개선을 과소평가(검증 −4.5%, 실제 −10.5%)했고, EC 개선은 과대평가(검증 −25%, 실제 −6.3%)했습니다.

### 3회차 — 데이터 구조 이해 (집 노트북 클로드)
- **바꾼 것**:
  - F13·F47은 한 온실의 연속 기록이 아니라 여러 온실의 하루치를 이어 붙인 것입니다. 그래서 날마다 출처 지문 피처를 넣었습니다.
  - 추운 평가 구간으로 외삽되도록 선형 물리 기준선을 두고 잔차를 학습했습니다.
  - 자정 재시작 필터를 넣었습니다.
- **결과**: 0.5624 / 0.2055. EC는 지금까지 최고입니다. 온도 개선은 거의 전부 가장 추운 평가 행에서 나왔습니다.

### 6회차 — 온도 G_C2 (팀원 제출, 파일 번호 08)
- **만든 곳**: 팀원이 제출했습니다. 설명자료 머리에는 "미제출 후보"로 적혀 있지만 실제로 6회차로 냈습니다(원본 문서는 고치지 않음).
- **바꾼 것**: 온도만 바꿨습니다. EC 열은 3회차(submission_04)와 똑같습니다(연구실 클로드 검산, 최대 차이 0).
  - `g = clip((현재 실내온도 − 8)/2, 0, 1)`
  - `예측 = (0.6 − 0.2(1−g))·기준 + (0.2 + 0.4(1−g))·Codex + 0.2g·TabPFN`
  - 기준은 5회차 온도 구성입니다. Codex 멤버는 자정 재시작 잔차 피처를 씁니다. TabPFN v2는 CPU에서 2,000행 문맥으로 8표본 평균을 냅니다.
  - 추운 행(8℃ 이하)에서는 TabPFN을 빼고 Codex 몫을 0.6으로 올렸습니다.
- **노린 것**:
  - TabPFN은 따뜻한 행에 강하고 학습 범위 밖 추위에서는 크게 틀립니다. 그래서 따뜻한 행에서만 섞었습니다.
  - 추운 행은 추운 날 검증에서 가장 강했던 Codex 멤버에게 맡겼습니다.
- **사전 예상**: 로컬 검증 DIAG10 −3.0~−3.3%, 평가 구간(2차) 기준 약 −2%(온도 약 0.535). 카탈로그 6.62·6.67·6.70·6.74.
- **5회차 대비 답안 변화**: RMS 0.22℃, 평균 −0.05℃. 가장 추운 133행(6℃ 이하)을 평균 0.18℃ 내렸습니다(4회차에서 실패한 것과 같은 방향).
- **결과**: 온도 **0.5251**(5회차 대비 **−3.8%**, 지금까지 최고)이고, 예상한 −2%보다 더 좋았습니다. EC **0.2055**(예상과 같음)입니다.
  - 추운 행을 내린 방향이 이번에는 맞았습니다. 4회차와 달리 추운 날 검증 여러 개로 고른 구성원 비율이라는 점이 차이였습니다.
  - 다만 추운 행과 따뜻한 행 중 어느 쪽이 이득을 냈는지는 점수 하나로 나눌 수 없습니다.
- **검산(연구실 클로드, 09-30)**: 답안 형식, 해시, EC 열, 구간별 변화, ZIP 속 기준 답안과 TabPFN 가중치 해시가 설명자료와 모두 일치했습니다. 재현 실행(CPU 약 20분)은 하지 않았습니다.
- **주의**: 설명자료가 드는 "다른 온실 32곳" 근거(6.75)는 이후 카탈로그 6b.9에서 약하다고 정정됐습니다.
