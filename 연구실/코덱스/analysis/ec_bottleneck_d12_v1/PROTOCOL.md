# D12 · EC 병목과 쉬운 해결 경로 진단

2026-09-30 연구실 코덱스. 실행 전에 이 문서와 코드를 main에 커밋한다.

## 목적과 순서
1. 원시 CSV의 row_id 유일성·입력/정답 정합성·평가 MASK와 직접 관리 채널의 가용성을 확인한다.
2. 이미 채점된 공개 OOF 6폴드(0,2,4,6,8,9), 234일·5,616행에서 3회차 기준과 v2의 오차를 독립 재계산한다.
3. 하루 수준 오차와 하루 안 모양 오차를 직교 분해한다. 각 성분을 정답으로 완벽히 제거했을 때의 RMSE는 진단용 이론 수치로만 쓴다. 실현 가능한 성능 하한이나 제출 성능으로 해석하지 않는다.
4. 고EC 기준은 기존 진단의 실제 일평균 EC≥1.2로 고정한다. 0·6·12·23시 예측의 고EC 구별 AUC와 수준 잔차를 계산한다. 실제 하루 평균은 사후 진단용이다.
5. 0·6시 예측≥0.8 그룹의 하루 평균 오차를 농장×폴드별로 확인한다. 보정식은 적합하지 않고 부호 일관성만 확인한다. 임계값을 결과에 맞춰 바꾸지 않는다.
6. v2가 기준보다 줄인 손실을 고EC/나머지와 하루 수준/모양으로 나누어 우선순위를 결정한다.

## 경계와 판정
- 신규 모델 학습·새 후보 채택·test_X 기반 가중치 학습·리더보드 역탐색·제출물 생성 없음.
- 최종 잠금 파일과 잠금일의 EC 값은 진단하지 않는다. 원시 train_y는 식별 정합성/가용 행수 확인에 읽지만 EC 수치 진단은 기존 공개 OOF 행에만 한정한다.
- test_X는 형식·결측 가용성 점검에만 사용한다. 학습 MASK는 평가에서 모두 결측인 채널을 제외하는 기존 규칙을 확인하는 데만 사용한다.
- OOF 정답과 원시 정답은 절대오차 1e-12 내 일치, row_id 중복 0개, 각 온실-일 24행, 오차 분해 항등식 1e-10 내 일치를 요구한다.
- 이 진단은 기존 OOF 재사용이므로 독립 확증이나 DIAG10 신규 통과로 부르지 않는다.
- 모델 시험이 필요해지면 별도의 새 사전 프로토콜에서 A/B/DIAG10×시드·EXT10/12·다중비교 기준·인과성·결정성을 등록한다. D12 수치를 보고 바로 보정하거나 기각 H1~H22의 혼합비를 재조정하지 않는다.
