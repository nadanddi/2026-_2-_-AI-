# 실행 전 보완 v2 — 2026-10-16 연구실 코덱스
PLAN_v1.md를 유지하며 아래를 우선 적용한다. 최초 성능실행 전 등록.

- 각 시드마다 R2/R3/R4 모두 비열세 AND 그중 적어도 한 자료 엄격개선. 나머지 안전조건도 모든 시드에서 통과해야 탐색 적합. 채택과 무관하다.
- 학습 source와 겹치는 평가 행은 겹친/비겹친 결과를 따로 표시한다. 겹친 행을 포함한 전체 점수는 기존 파이프라인 재현 참고이며 독립 평가라 하지 않는다. group 중복도 행별 표시한다. source 키는 기존 manifest 원문, 이름 alias 충돌 가능성은 별도 한계다.
- 기반 p6/ppre/rc의 모든 과거 학습·원본DB provenance는 이번에 완전 인증하지 못한다. 전문가 원본 비중복도 전체 독립성 증거가 아니다. 이번은 고정 기반 모델 위 교체형 결합 탐색이다.
- 세 분할의 전체 배정 해시가 달라야 한다. GPT 양성 2묶음의 일반화 제약은 시드 반복으로 해결되지 않는다.
- 모든 세트별 네 전이(고친 가짜/새 놓침/고친 진짜/새 오탐)를 CSV와 요약에 저장. 유형별 후분해는 실패 설명에만 사용한다.
- bootstrap은 같은 묶음을 두 모델·3seed에 공통 재표집해 시드별 BA 차이를 평균. 세트별로 보고하고 합친 확증 통계는 내지 않는다.
- OOF와 배포 분위 차이 보고. 배포 전문가·문턱·C 변경 금지. 기존 M_v2 기각 유지, R5 접근없음, 새 후보·제출 패키지 없음.
- 원본 제거 시뮬레이션은 이번 작업에서 실행하지 않음. ppre도 원본 대조 일부를 포함할 수 있으므로 실제 원본 없음 검증을 대체하지 못함.
