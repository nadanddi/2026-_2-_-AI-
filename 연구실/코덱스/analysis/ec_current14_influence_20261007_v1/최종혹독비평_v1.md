# 현재 EC14 확인·학습날 제외 진단 최종 독립비평

2026-10-07 연구실 코덱스. 기존 파일·후보·문턱을 변경하지 않았다. 독립 검토자의 신규 fit0, 원 train_y/test_X/EL1/잠금 정답 읽기0, 중복 fulltree 재구성0이다.

**산술·실행 감사는 PASS지만 날짜 삭제는 개선책으로 추천할 수 없다.** 139일 하나를 제외해도 높은 EC 학습지원이 다른 날로 재분배됐다. 139·231일을 함께 제외하면 선택 사례의 과대예측은 줄지만 큰 잔여 편향과 전체·고EC·공개 pass2 손실이 남는다. 삭제안은 사전 고정한 진단 결과이며 채택 PASS가 아니다.

## 독립 감사의 범위와 결과

현재 EC14 baseline30캐시/34560행, PFN40문맥, 삭제60캐시/69120행을 확인했다. train/query/removed ID 전체 순서·source/prep/NPZ SHA·47열 실수 frame hash·동일 입력의 PFN38열 및 RNG 문맥을 대조했다. 삭제안 신규 ET57개, no-op3캐시, BASE 추적용 ET1개가 별도 기록과 일치했다.

삭제안에서 고정한 LGB/MLP/PFN을 다시 결합하고 실제 seed raw 평균 ensemble, 일별 시간순 prefix평활, 원 bounds, 원본 package SG2와 최종 clip을 재계산했다. 후보/ref/calendar 일치, gate/delta, SG2 상호작용도 확인했다. 최종예측 최대차4.44e-16이다. csv/math.fsum으로 총5760일별점수/192집단점수/64사례와 두 판정을 대조했다. 그룹 SSE 최대차5.68e-14, delta SSE 최대차1.14e-13으로 모두 통과했다.

root가 작성·실행한 별도 `audit_support_v1.py`는1800tree/20,321,234node의 경로·학습행수·평균정답·잎·지원가중치·원 ET를 재구성했다. critic는 **그 코드·receipt·source/trace SHA를 독립 검토**했고, 트리 경로를 다시 실행하지 않았다. 세 trace sidecar의 arm/seed7/fold1/source와 원cachedET의 sidecar·ID·출력 연결도 별도 대조했다. 지원9profile의 학습날 가중치 합·기여 합·고ECday 비중, 모든 support shift와2880일변화/8집중도셀/48최대손익 사례는 경량 독립 재계산했다.

## 가장 중요한 실패와 해석 한계

| 현재 EC14 대비 실제 ensemble RMSE 변화 | D1 | D2 |
|---|---:|---:|
| 전체360일 | +0.010% | +1.283% |
| 일반 폐쇄61일 | −0.170% | −1.328% |
| 고EC31일 | −0.066% | +2.335% |
| 공개 pass2 46일 | +0.449% | +1.679% |

D2의 전체·고EC·공개 pass2 악화는 세 seed 모두 같은 방향이다. D2 일반 ensemble 순이득 SSE1.358822보다 선택된161일의 이득1.457456이 크다(107.2587%). 나머지 일반328일은 SSE+0.098633으로 합계 악화다. 여러 날이 개선됐다는 사실과 양립하는 결과다. 이미 실패를 보고 선정한161일 개선은 독립 일반화 증거가 아니다. D1의 음수 순이득에서 계산된 signed ratio를 “개선 기여율”로 소개하면 안 된다.

심각한 해석 오류가 될 수 있는 지점은 다음과 같다.

1. **231 단독 원인을 식별하지 않았다.** D2−D1은139가 빠진 조건에서231을 추가 제외한 ET 재학습 대조다. 231 단독 삭제 arm은 없다. 특정 입력·학습날이 물리적으로 EC를 만들었다는 인과가 아니다.
2. **삭제는 고정 forest 가중치 제거가 아니다.** ET median·분기·잎·무작위 구축 전체가 바뀐다. 다른 모델과 SG2 ref에는 삭제날 정답이 남는다. 전체 모델의 학습자료 삭제 효과로 해석할 수 없다.
3. **최종 효과에는 SG2 gate 변화가 섞인다.** ensemble gate flip은 D1 1행/D2 4행, 후보 변경0행이며, SG2 상호작용 최대약0.1464다. 양 clip은 전seed·arm에서 활성0이다. 최종손실을 raw ET 변화만의 직접 효과로 귀속하면 안 된다. F47_161은 pass1이어서 이 사례 자체에는 SG2가 적용되지 않는다.
4. **현재 F13_112 지원기전은 미추적이다.** 현재 과대예측 지속은 확인했지만, 중간 EC 학습지원 적용이라는 상세 근거는 원계절v2의 별도 추적이다. 현재 EC14에서도 동일 기전이라고 확정하지 않는다.
5. **공개 pass2는46일이다.** 실제 평가60일 효용, A/B·유의 기준 충족, 제출·채택은 이번에 검증하지 않았다. 같은 날의 seed 반복이나 두 진단 arm을 새로운 독립 표본으로 세지 않는다.

## 작업 안에서 반영한 개선과 최종 문안 검토

raw ET 판정 정의 고정, 실제 ensemble 순서 분리, SG2 원본 calendar/correct 동등성, 활성 actual-output prefix 섭동, PFN 실수 hash/context 독립 검산, 공개 pass2 분모 구별, percentage 분모와 severe 정의 명시, trace metadata 연결, 감사 주체 구별을 보완했다. 이는 검증·기록의 개선이며 모델 성능 개선이 아니다. 이전 실패 source와 로그를 보존했다.

`1단계_검토_v1.md`, `보완기록_v1.md`, `기존실험_대조_v1.md`, `진단결과_v1.md`의 주요 수치와 범위를 대조했다. 최종 진단 초안은 F13의 현재 과대예측과 원계절 지원기전을 구별하고, D1 signed gain을 개선율로 소개하지 않아 앞선 문안 지적을 해소했다. 기존6.181/코덱스6.205/6.215/6.65의 기각 설정도 원 카탈로그·코드·보고서와 일치했다. 카탈로그6.205 번호 충돌이 있으므로 최종본에 해당 원보고서 경로를 연결하는 것이 좋다. 최종 v2에서는 BASE138의 placeholder를0.71171%로 채우고 독립 감사 완료 상태로 갱신하면 된다. 원본을 덮어쓰지 않는다.

## 다음 실험과 이번 완료를 구별

현재 ET의 `in_co2_h0`/`act_heating_h0` 두 열만 제외하는 제안은 아직 미실행 가설이다. 기존 모든 h0 제거·변화량 교체의 실패와 설정이 다르지만 성공이 보장되지 않는다. 현재값·누적값·DP1 proxy가 남으므로 두 열 제거로 “자정 정보 전체 영향”을 측정했다고 해석할 수도 없다. 향후 별도 등록한다면 현재 레시피 재현, 전seed·전체집단·고EC·F13_112·공개 pass2·161 제외 분모를 결과 전에 고정하고 진단과 채택 기준을 구별해야 한다. 이번 결과를 보고 새로운 문턱이나 삭제날을 계속 바꾸는 탐색은 독립 평가가 아니다.

현재 작업은 원인 추적의 범위를 좁히고 날짜 삭제의 손익을 확인하는 데 진전이 있었다. 데이터 자체의 오류·숨은 물리 원인·입력으로 해결 불가능함·새 모델 효용은 입증하지 않았다. 최종 수치 감사 차단사항은 없으며, D1/D2 삭제를 해결책으로 추천하지 않는 결론을 유지한다.
