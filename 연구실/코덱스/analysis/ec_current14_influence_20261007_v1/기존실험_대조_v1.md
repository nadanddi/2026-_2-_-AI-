# 후속 방향을 정하기 전 기존 실험 대조

2026-10-07 연구실 코덱스. 현재 삭제안 전수 학습 중 작성했다. 아래는 기존 기록을 읽은 결과이며 이번에 다시 학습하거나 재채점한 결과가 아니다.

- 카탈로그6.181 DI1: ET에서 자정 고정10특징을 전부 제거한 실험은 DIAG10+5.1~5.6%, A+8.8~9.7%, B+3.0~3.8%로 기각됐다. 이번 지원 추적만으로 자정 특징 전체가 해롭다고 일반화하거나 같은 실험을 반복하지 않는다.
- 카탈로그6.205 EC_H0CHANGE: 기존 run_v3.py에서 모든 RAW의 h0 특징을 현재−h0 차이로 교체한 실험이다. DIAG10+2.770~3.435%로 기각됐다. 모든 자정 절대수준을 변화량으로 바꾸는 방안도 이미 시도됐다.
- 카탈로그6.215 FARM_ET: 기존 결과보고서에서 ‘현 ET에 농장 구분 한 열을 추가’한 실험으로 확인됐다. DIAG10−0.168~+0.370%, 전체 판정 기각이다. 단순 농장 식별자 추가와 농장별 학습을 같은 방법으로 부르지 않는다. 분리 학습의 효용은 이 기록만으로 확정되지 않는다.
- 카탈로그6.65: 폐쇄 학습날 가중치2배/3배는 시드·검증기 방향이 엇갈려 기각됐다. 일반 폐쇄날 전체를 일괄 증폭하는 처방을 새 단서로 소개하지 않는다.

이번 D1/D2는 실제 학습 지원에서 확인한 두 선택 날에 대한 조건부 의존도 진단이다. 실제 성능 방향·남은 지원·다른 날의 손익이 모두 확인된 뒤 후속 가설을 정한다. 기존 실패는 해당 설정의 실패이며 방법 전체의 불가능성 증명은 아니다.
