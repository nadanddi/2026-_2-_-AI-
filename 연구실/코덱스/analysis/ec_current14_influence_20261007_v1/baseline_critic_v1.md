## 판정

**1단계 수치 감사 PASS. 사전 고정된 ET-only 삭제 진단 실행을 막는 결함은 발견하지 않았다.** 현재 EC14에서도 선택된 과대예측이 남아 있다는 사실은 확인됐다. 이것은 현재 모델의 개선 채택이나 물리 원인 확정이 아니다. 전체 결과가 확보됐으므로 사전 등록한 raw ET24시간편향 판정을 사용해 다음 진단을 진행할 수 있다.

## 전수 검산

- R3 캐시30개에서 NPZ/sidecar/prep SHA, seed/fold, train/query ID 전체 순서, 각 출력 길이·유한값을 확인했다. PFN40개 입력·문맥 provenance는 앞선 별도 전수 감사 PASS다.
- BASE34560행은 8640개 query × seed3+실제 ensemble, 중복0이다. 별도 math.fsum 혼합→일별 시간순 prefix평활→학습bounds clip→원본 package SG2.correct→clip으로 재구성했다. raw혼합 최대차8.88e-16, SG2·최종 최대차4.44e-16이다. 원본 SG2에는 fold 학습 ref로 준비한 구조를 공급했으며, 전역 query 포함 표준화를 사용하지 않았다.
- 저장된 SG2 trace의 후보 label/ref membership, prefix 모델평균, .30 gate, .5 delta와 calendar/signature 후보 ranking을 전수 대조했다. no-candidate 판단 전체는 원본 SG2 출력과의 대조로 검사하고, 후보가 있는 행의 ranking은 별도 재계산했다.
- stdlib csv/math.fsum으로 BASE/원계절2880개 일별행과96개 그룹의 SSE·RMSE·편향·shape/level분해·분모·성공/심각행수·변화율을 독립 계산했다. 그룹 SSE 최대차5.68e-14, RMSE 최대차1.11e-16이다. 대표32개 case가 일별 결과의 정확한 부분집합임도 확인했다.

## 반영한 문안 개선과 남은 한계

score_v1의 `rmse_percent`는 BASE를 분모로 한 OLD/BASE−1이다. “현재 모델 대 원계절 변화율”로 읽으면 방향·분모가 잘못된다. 이번 `severe_days`는 일RMSE≥.2이며 이전 pair진단의 |일편향|≥.2와 다르다. 부모 에이전트가 별도 보완 기록에 두 정의를 명시했다. 다음 표에도 이를 유지한다.

삭제안의 효과는 ET median·forest 재학습과 후처리 gate 상호작용을 포함한다. ET 외 구성원과 SG2 ref에 삭제 날 label이 남으므로 전체 학습자료 삭제 효과가 아니다. 선택된 날 이득을 나머지·고EC 손실과 분리해 전부 보고한다. features/season/원본 SG2 함수 자체는 immutable 소스를 재사용했으며 모델 재fit에 의한 캐시 예측 재현 검사는 이번 독립 감사에서 하지 않았다. 물리 인과, PFN 내부 원인, A/B·잠금 검증, 제출·채택 효과는 이 감사 범위 밖이다.

1단계 완료 감사는 통과했고, 삭제안 수치 결과는 아직 미검증이다.
