# 9회차 온도 검토·단서 연결·개선 계획

사용자 직접 요청: 9회차 온도 모델의 적정성·누락을 비평가와 검사하고, 대회 데이터로 조사한 단서를 추합해 모델을 개선한다. 기존 역할 분담의 이번 온도 작업은 사용자 요청으로 허용된다. 재현검증은 실행가능/6자리일치실패 상태를 유지한다.

## 실행 범위
1. 원ZIP/환경/재현기록 정합성, 소스 입력경로·MASK·시각 인과·온실격리·가중치·계절표·모델별 시드·검증 증거를 감사한다. 독립 비평가가 source검토, root가 원함수의입력교란→특징/가중치 비교를 직접 실행한다. 원소스와기존결과는보존,own새버전만작성.
2. 공식 train_X/test_X/train_y의 sub_temp만사용한다. 숨김평가정답·EC잠금정답새채점0·대회외자료/그파생근거0. 원모델최종학습은공식400일, 개선검증의온도모집단/분할은기존온도규칙과맞추며EC40일잠금과온도검증을혼동하지않는다. 공유자료에타AI변경이있으면읽기만한다.
3. 기본감사: 학습9,600/평가1,440, TF가중치1/.2/.04전수집계, 등록정보와실제fit seed확인. 원평가입력을농장별두cut후변경/다른농장변경/전부변경하며MASK학습특징·가중치불변과허용query특징불변을검사한다. 예측비트인과는이특징검사와다르므로원temp_v13_checks실행범위를별도기록한다.
4. 단서 연결: 기존온도실패(H-A/H-A2/H-B/평활/EC전이/계절TK/VW1)와이번관측(CO₂거칠기·실내배지결합·관측부족·자정·역할)을관측/원인/허용구현/효용으로구분. 근거가없거나이미동일기각안은재포장하지않는다. 독립단서비평도병행한다.
5. 개선안의구체변경·기준선·캐시호환·분할·시드·bootstrap조건을 별도 실험등록v1에고정하고계획비평후실행한다. 모델fit전에후보수를고정하여본페로니적용. 현재9회차를소급재채택하지않고, 새후보는온도 DIAG10/EXT10/EXT12 모든새시드 같은방향 + DIAG p_worse<.025/k,CI상단<0기준. EXT10실패를EC검증기로덮지않는다. 개선을보장하지않고실패도그대로기록한다.
6. 기존캐시를쓸경우원자료/rowIDs/분할·purge/학습특징/가중치/season/문맥·CPUvsGPU를확인한다. TK의W30G캐시를정확W40G-S실행캐시라고부르지않는다. OOF후처리학습은outer정답을보지않는nested구조가필요하다. 비교가능하지않으면재학습/추가확정검증또는채택보류.
7. 첫결과중간비평→전수검산→최종비평, 모델과기준선·입력불변성 및수치독립검산을마친다. 공식평가예측CSV/제출패키지/확정구성은제출요청전만들지않는다. 연구용개선소스·OOF·보고서만own에저장. HANDOFF/일지/카탈로그에현재상태·완료/미완료범위·다음작업을연결한다.

새현재해석표는온도주제를별도로작성한다. 이전temp_round9_reproduction의문맥1결정성과1223행차이를수정하지않는다. 정적감사/특징검사/예측규정검사/성능검증의범위를분리한다.
