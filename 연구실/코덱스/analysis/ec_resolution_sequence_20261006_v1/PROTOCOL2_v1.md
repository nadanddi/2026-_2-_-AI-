# 단계2~4: 실제 중첩 OOF 위험학습과 제한 보정 선행검사

2026-10-06 연구실 코덱스. 단계1 완료 및 독립32캐시/1152행 검산 PASS 뒤 고정한다. 한 후보만 실행하며 결과를 보고 문턱·계수·특징을 재탐색하지 않는다.

## 가설과 한계

같은 학습집합에서도 F47 성공/실패 차이가 남았으며, 공통seed7 0시 ET에서는 CO₂·난방 입력 묶음의 예측 차이가 컸다. F13은 난방·계절 차이가 컸고 LGB도 높은 예측을 내므로 LGB를 정답이나 안전 기준으로 가정하지 않는다. 아래 낮은 LGB 쪽 보정은 특정한 제한 후보일 뿐이다. 실제 고EC 손실이 증가하면 기각한다. 특징 제거의 효과나 물리 인과는 이번에 판정하지 않는다.

## 단계2: 위험 점수

- 기존 실제 계절v2의 완전 outer-tr nested OOF가 확보된 DIAG10 fold0~3만 사용한다. 12개의 fold×seed 학습/외부검증 쌍을 그대로 유지한다. 전역OOF 재분할, 원train_y/test_X/EL1/잠금정답 사용은 없다.
- 라벨은 **그 시각 A − 공개 EC 정답 > .15**. 하루 정답 수준·high·inner_j·row_id 등은 입력 특징이 아니다.
- 특징은 고정 원 FULL38열과 risk_core_v2.design의12파생열, 총50열이다. farm_F47은 명시한 온실 식별 특징이다. A와평활된4모델현재점수·A의현재까지평균·모델간차이/범위만 추가한다. FULL38 중 계절은 해당inner/outer 학습집합만으로 변환한다. 모든 fit 변환은 해당 outer-tr 안에서만한다.
- median imputer(keep_empty_features=True), StandardScaler, L2 logistic regression(C=1, solver=lbfgs, tol=1e-8, max_iter=2000, seed=각7/101/2024), class_weight 없음. 각하루 전체24행의 총가중치를1로 두도록 sample_weight=1/24. 위험 점수는 분류기 출력이며 외부 보정/확률보정을 하지 않는다.
- 학습라벨 두종류가 모두없을 경우 그학습라벨의 상수평균으로 예측하고 fallback을 기록한다. 수렴하지 않으면 시험을 중지한다.
- 내부 base 모델이 외부 모델보다 적은 학습날을 사용한다는 분포 차이가 남는다. 시드3개가 독립날3배를 뜻하지 않는다.

## 단계3: 한정된 하향 보정

현재시각까지 환기0 비율≥.8, 팬 평균<10일 때만 고려한다. 하루전체사후환기/팬 정보나 실제 EC는 gate에 넣지 않는다.

위험 점수 r>.8인 경우:

`delta = min(max(A − smooth_lgb, 0), .10, A) × clip((r − .8)/.2, 0, 1)`

위 gate밖은 delta=0이며 후보=A−delta. 상한 .10과0하한 고정. 별도의 평활/clip/재학습은 없다. LGB가 A보다 높으면 수정하지 않는다. 따라서 모든 기존 실패일을 고칠 것으로 기대하지 않는다.

## 단계4: 고EC 보호와 기각 규칙

- 외부141일/3384행(3seed반복10152행)에서 전체, 일반날(하루실제평균<1), 고EC날(≥1), 온실·기록구간·fold·수정시간/날을 기록한다. 라벨은 이 사후채점에만 쓴다.
- 세 seed 각각 전체RMSE와 일반날RMSE가 엄격히 감소하고 고EC RMSE가 악화하지 않아야 선행선별 통과. 고EC 비교 허용오차1e-12만 수치반올림용이다. pass2 RMSE가2%이상 악화하면 중지한다. 하나라도 실패하면 이 후보를 기각한다. 변경0은 엄격 개선이 아니다.
- 위험 AUC·precision·recall, 위험점수≥.8와실제수정행의 구분, 실제 고EC 수정 손실, 사례별SSE도 보고한다. 이는 선행검사의 진단 수치이다.
- 통과하더라도 **SCREEN_PASS_NEEDS_FULL**만 선언한다. 전체80 nested receipt/검산과 모든seed×DIAG10/A/B 같은방향·DIAG10 p_worse<.025(여러후보본페로니), 현재EC14 대조를 확보하기 전 채택 불가. 실패는 **SCREEN_REJECT**이며 기존 채택모델을 바꾸지 않는다. 이번부분자료만으로 전체판정·제출물을 만들지 않는다.
- 숫자·학습변환/계수·보정수식은 독립 혹독비평 및 전수 검산한다. 원파일 보존, 보완은 새버전. main 사전등록 후에만 위험fit.
