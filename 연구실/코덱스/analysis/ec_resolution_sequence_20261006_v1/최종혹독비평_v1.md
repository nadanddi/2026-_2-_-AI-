# 순차 실험 최종 독립 혹독비평과 개선사항

2026-10-06 연구실 코덱스. 격차·성공/실패 사례 진단 이후 진행한 동일학습집합 비교, 모델함수 설명, 부분중첩 위험학습, 제한보정, 고EC보호 판정을 검토했다. 최종 단계에서는 관련9개 독립감사를 다시 실행했다. 원코드·원결과·후보계수·문턱은 변경하지 않았고 reviewer 새fit0이다.

## 최종 평가

**계산과 판정은 독립 재현됐다. 이번 위험보정 후보는 기각이며, EC 오차 해결책으로 채택할 수 없다.** 원인 추적은 입력 대비에 따른 일부 모델함수의 반응까지 진전했다. 전체 실패의 단일 원인, 실제 물리 인과, 평가60일 또는 현재EC14의 개선효과는 입증되지 않았다.

| 평가 항목 | 판정 |
|---|---|
| 원레시피·학습ID·특징·예측의 재현 | 감사 PASS |
| outer/inner 라벨분리·명시50열 경계 | 검토·검산 범위 내 PASS |
| 위험12fit의 전처리·계수·예측 및 보정·채점 | 감사 PASS |
| 후보의 등록된 고EC 무악화 조건 | **SCREEN_REJECT** |
| pass2, 전체DIAG/A/B, 최신EC14 성능 | **미검증** |
| 모델 채택·확정구성·제출 | 진행하지 않음 |

감사 PASS는 산술과 규칙을 제대로 실행했다는 뜻이다. 후보 효용 PASS와 혼동하면 이 작업의 핵심 결론이 뒤집힌다.

## 1. 무엇을 확인했고 무엇이 남았나

단계1에서는 네 대상날과 같은온실±1일을 배제한 네 학습조건의 query 특징이 동일했다. 같은 학습집합에서도 두 성공날과 대응 실패날의 차이가 남아, 원래 서로 다른 fold라는 사정만으로 대비 전체를 설명할 수 없음을 확인했다. 다만 F13_112는 네조건 모두 성공문턱 RMSE .1을 넘었지만 심각오류 |일편향|≥.2는 2/4조건이었다.

ET/LGB의 공통학습·seed7·0시 32개 인공조합에 대한 grouped Shapley 산술도 재현했다. F47 ET에서는 CO₂·난방 묶음, F13 ET에서는 난방·계절 묶음이 해당 고정함수의 예측차에 큰 항을 만들었다. 입력묶음·기준날·모델에 의존하는 함수 설명이며 PFN/MLP, 3seed 평균, 하루전체 최종오차 또는 물리 조작효과의 설명은 아니다. 저장된 coalition 예측의 산술을 독립 재계산했고, reviewer가 hybrid 모델을 다시 fit한 것은 아니다.

위험보정은 부분 외부141일 중 일반133일·고EC8일을 검사했다. 전부 day<179이며 pass2 query는 0행이다. F13_98도 이부분 외부검증에는 없다. 따라서 후기 기록구간 보호나 평가60일 효과를 통과했다고 말할 근거가 없다.

## 2. 후보의 문제는 작은 부작용 하나에만 있지 않다

세seed의 일반날 RMSE는 약 .539~1.098% 감소했다. 그러나 seed101 고EC RMSE가 .332452845→.332455997로 증가해 사전 무악화 조건을 위반했다. 증가가 작아도 사전에 정한 1e-12 숫자 허용을 넘었으며, 결과를 본 뒤 허용범위를 늘릴 수 없다.

그 한행은 F13_177_00이다. 실제 .979인데 기존 .894920113을 .892560082로 더 낮춰 SSE가 .000402432 증가했다. 해당날 하루 실제평균은 **1.005125**이므로 고EC날 분류가 맞다. 0시 실제값만 보고 이행을 일반날로 재분류하면 사전 기준을 바꾸는 것이다.

더 큰 한계는 **이득의 편중과 미탐**이다.

- 순SSE이득의 99.94~100.50%가 실험 전에 이미 선택한 F47_161 한날에 집중됐다. 100%초과는 다른날 손해가 그날 이득 일부를 상쇄했다는 뜻이다. 넓은 실패영역에 고르게 유효한 보정이라는 증거가 아니다.
- 그날을 제외한 나머지140일의 전체 RMSE 변화는 seed7 −.000447%, 101 +.001894%, 2024 +.000332%다. 일반날 나머지132일에서도 101/2024가 악화했다. 이는 사후 편중감도이며 새로운 기각조건이나 튜닝 근거가 아니다.
- F47_161 평균예측은 약1.135→1.109로 낮아졌지만 실제.646과의 차이는 여전히 크다. F13_112는 위험최대 .263~.310으로 수정0이었다. 여러 구성원이 함께 과대한 이 대표사례를 고치지 못했다.
- AUC .8375~.8536은 위험라벨 순위구분의 결과다. 실제수정 precision .8421~.9444와 함께 recall .0510~.0547, 보정크기, 고EC 피해를 봐야 한다. 높은 AUC나 precision만으로 안전한 회귀보정이 되지 않는다.
- 수정57개는 seed반복행이다. 고유 시간행22개/날4개이며 57개의 독립 성공사건이 아니다.

따라서 기각은 계산실수 때문에 생긴 실패가 아니다. 낮은 LGB를 향해 당기는 이 고정 보정정책이 일부 과대오류는 줄였지만, 위험점수의 오탐으로 이미 낮은 예측을 더 낮췄고 넓은 오류범위를 해결하지 못한 결과다. LGB를 정답 또는 전역 안전기준으로 가정하지 않은 사전 판단은 타당했다.

## 3. 작업 안에서 적용된 개선과 독립 확인

다음 보완은 후보를 다시 튜닝하지 않고 작업의 정확성과 검토가능성을 개선했다.

| 개선 | 확인 내용 |
|---|---|
| 유한 보정파라미터 계약 | 원v1 NaN-cap 결함을 보존하고 v2에서 거부. 3200유한조합·16비정상 경계 재검산 |
| 실제 feature 목록 고정 | FULL38+12=50열을 명시. 24CSV 라벨·메타·순서·미래·타온실 경계 검사 |
| 위험진단과 실제수정 경계 구분 | 진단 risk≥.8와 실제보정 risk>.8을 별도 유지. 원파일·RED→GREEN 기록 보존 |

위험점수 재구성 최대차 **4.44e-16**, L2 정규화 gradient 최대 **7.71e-8**이었다. gradient는 근접정상성 감사이지 등록된 후보 통과기준을 새로 정한 것이 아니다. 10152행의 gate·하향수식·상한·0하한, seed별 전체부분집합·일별·seed평균 점수, AUC와 precision/recall, 고EC 한행 손실을 전수 재현했다.

## 4. 현재 작업에 추가할 수 있는 개선

추가 모델·계수 탐색 없이 가능한 개선의 우선순위다. 상당부분은 보완기록_v1.md와 결과보고서v2에 이미 반영됐다.

1. **완료 상태를 별도 관리한다.** 실행완료, 산술감사, 후보기각, 지원부족, 채택 여부를 하나의 PASS로 합치지 않는다. 이번 최종 상태는 `감사완료 / SCREEN_REJECT / pass2미검증 / 채택0`이다.
2. **학습 전 coverage를 필수 산출물로 만든다.** 온실×기록구간×고EC의 지원날수와 빠진 대표사례를 준비receipt에 기록한다. 실제0행이면 미검증을 명시하고, 요구범위의 보호를 자동으로 통과 처리하지 않는다. 이번 기각조건을 사후 변경하라는 뜻은 아니다.
3. **이득의 넓이와 피해를 기본 보고항목으로 둔다.** 총RMSE와 함께 고유 수정날수, 이미선택한 사례의 이득 집중, 수정된 과소예측, 대표미탐, seed반복을 보고한다. 사후진단을 새 모델선택에 돌려쓰지 않는다.
4. **캐시와 설명의 범위를 추적가능하게 남긴다.** source/prep/feature/ID/runtime 서명, PFN 문맥, raw/평활/clip의 정의를 보존한다. ET 첫분기 표와 Shapley를 서로 다른 설명으로 표시한다. 다음 원인추적에서 전체경로를 독립 확인하려면 처음 fit할 때 필요한 경로/모델 산출물을 저장하는 계획이 필요하다.
5. **기록의 분모와 비용을 명확히 한다.** R3 묶음은 ET/LGB/MLP 세학습이다. 단계1 replay 포함 고전45fit+PFN17fit, 함수설명2fit, 위험12fit이며 reviewer 감사는 새fit0이다. 실제 학습을 fit0로 부르거나 seed행을 독립날로 세지 않는다.

## 5. 다음 모델 실험은 별도로 설계해야 한다

이번 후보는 재개·미세튜닝하지 않는다. 다음 실험을 한다면 다음 순서가 우선이다.

1. **자료 지원과 기준을 먼저 확보한다.** 전체nested 완료·서명을 확인하고 pass2에 대응하는 공개검증 지원, 고EC·온실·기간별 사례를 확보한다. 현재EC14를 비교하려면 원계절v2와 혼합기준이 다르다는 점을 별도로 정합화한다. 새test/잠금정답을 확보하거나 읽자는 뜻이 아니다.
2. **실패 유형과 보정목표의 차이를 먼저 규정한다.** 구성원 불일치가 큰 F47형과 여러 구성원이 함께 틀린 F13형, 실제 과소예측의 피해를 구분한다. `A−y>.15` 분류위험과 특정하향보정의 실제 SSE이득은 같은 목표가 아니다. 이미 실패한 비용GATE 계열의 선행기록을 검토한 후, 중복되지 않는 한가설만 별도 사전등록한다. 이번 진단만으로 비용학습이나 새gate의 성공을 단정하지 않는다.
3. **후속 평가의 독립성과 보호를 먼저 정한다.** 어떤자료를 설계에 이미 사용했는지 표시하고 새후보·화이트리스트·분할·보정·보호·기각규칙을 실행 전에 고정한다. 선행실패시 기각하고 같은표본의 문턱/계수 재탐색을 하지 않는다. 전체seed×DIAG/A/B 및 원통계기준, 최신기준 대조가 없으면 채택하지 않는다.

이번 결과는 이런 다음 설계를 요청할 근거이지, 그 설계의 효과를 보장하는 근거는 아니다.

## 최종 문안 검토와 근거

순차실험_결과_v2.md와 보완기록_v1.md를 확인했다. 감사PASS/후보기각, 일반133·고EC8·모두pass1, 한날 이득편중과 대표미탐, EC14미대조, 함수설명의범위를 구별했고 현재 문안의 완료를 막는 수치·범위 오류는 발견하지 않았다. family25 선행기각 원문은 이번 fresh 감사 범위 밖의 출처로 표시됐으며 본후보의 감사결론은 그 기록에 의존하지 않는다.

최종감사_목록_v1.json은 단계1·summary/설명·nested입력·legacy/수정helper·실제feature경계·위험결과·사후진단·coverage감도의 코드/receipt를 연결한다. legacy helper의 NaN-cap 결함 재현은 보존결함 확인이며 후보는 수정v2를 사용했다. 원80nested/A/B/EC14의 미검증과 SCREEN_REJECT는 그대로 유지된다.
