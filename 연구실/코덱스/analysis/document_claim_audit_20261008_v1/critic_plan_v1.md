# 계획 독립 비평 v1 — 2026-10-08 · 연구실 코덱스

검토 대상: PLAN_v1.md, 사용자 제공 전수조사.txt 전체, 공개 정답·채택 메모리, 기존 현재 EC14 runner_v4.py 및 preparation_v4.json의 구조. 신규 모델 학습/채점/정답 통계 계산은 하지 않았다.

## 판정

공식 대회 자료만 사용하고 독립 센서 정답이 없다는 점을 인정한 방향은 적절하다. 다만 아래 사항을 실행 전 새 계획/코드에서 고정해야 한다. 현 상태를 '모든 주장의 정확 재현 계획'으로 부르면 과장이다. 원 주장 수치의 원정의가 없는 항목은 새로운 대리 진단 또는 미검증으로 끝나야 한다.

## 실행 전 보완

1. **거친 날 정의의 구현 공백.** lag1 자기상관은 signed CO₂ 차분인지 절대 차분인지 명시한다. 중앙값 최소 표본 수, 연속 시각 판정(시간 차 정확히 1), 결측/중복/상수 차분/자기상관 분모 0 처리를 고정한다. 관측 24시간이 없는 날의 결측률과 제외 수를 따로 보고한다. R1>14는 원문 정의가 아니라 이번 임의 고정 진단 문턱임을 표시한다. 21.6/4.8은 원문 집단 구분을 모르면 정확 재현할 수 없다. 특히 거침으로 정의한 집단의 거침 차이 자체는 센서 불일치 증거가 아니다.
2. **전수와 공개 부분집합 분리.** 입력 통계는 F13/F47 전체 train_X 400일과 test_X 60일에서 가능하나 정답/OOF는 공개 360일이다. 각 표에 분모를 붙이고 13%와 손실 몫 비교가 서로 다른 분모를 쓰지 않게 한다. 공개 제한의 선택 편향을 명시한다. 다른 49온실은 허용된 입력 결측/CO₂ 기준선 분석은 가능하지만 잠금 정책 때문에 정답 42개를 재계산하지 못하는 사유를 표기한다.
3. **MASK의 행별 의미.** 'test_X의 전부 NaN인 열'이 전체 평가 CSV 기준인지 농장별인지 명시한다. 원대회 평가 마스킹 구조와 동일한 농장×열 MASK를 적용해야 하며, 통계용 원입력과 허용입력 통계를 구분한다. 부분 결측을 관측치만으로 처리할 때 표본/시각 집합이 달라져 생기는 효과도 기록한다.
4. **센서 대리 지표 정의.** K1의 EWMA 대상(실내온도인지 배지온도인지), 초기값/adjust/min_periods와 상관할 상대를 고정한다. K2의 종속/독립변수, 절편 포함, day 내 적합 여부와 유효 시각 집합을 고정한다. K2가 회귀계수를 적합한다면 '모델fit0' 대신 '신규 예측모델 학습 0, 사후 설명 회귀 있음'이라고 정확하게 표현한다. 온도 반응 지연/센서 위치/온도 범위가 달라도 상관·잔차가 바뀌므로 대리 지표가 낮다고 센서 혼입으로 판정할 수 없다.
5. **A/B 대리표지의 식별 불가능성.** 날마다 기록번호 작은/큰 순서로 정한 역할은 실제 동 정답이 아니다. 같은 역할 지속성이 높아도 '같은 실제 동은 매끄럽다' 또는 '주기는 착시'를 입증하지 않는다. 두 역할을 하루씩 바꾸면 같은날 상관·평균은 보존되지만 역할 간 지속성은 달라진다. 일치 외기 4×24는 날짜 후보 동치집합일 뿐 독립 달력 인증이 아니므로 묶음 크기 분포, 중복·불완전 제외 수, 일치가 여러 날일 가능성을 제시한다. 이전 10기록 중 비교할 이전 같은 역할/다른 역할 선택 규칙(가장 가까운지 모두인지)과 쌍 수, 격차를 고정한다.
6. **분모·통계량 고정.** 농장 간 EC 0.25~0.37은 일평균 Pearson인지 시간행인지 불명확하므로 이번 정의를 표시한다. 고EC는 일평균>=1로 고정하고 '동시'는 두 역할 중 하나라도 고EC인지 역할별 쌍인지 고정한다. 자정은 absolute jump인지 signed jump인지 명시하고 0시 한 시각 결과를 0~2시 전체나 0시 특징의 피해로 일반화하지 않는다. 높은 예측 AUC는 하루 평균 예측/편향 단위로 명시하고 seed별·ensemble별 양성/음성 수와 ties=0.5, 단일 클래스 처리 방식을 고정한다.
7. **OOF 안전성은 해시 하나로 끝나지 않음.** 입력/정답 허용 경로와 ID allowlist를 먼저 만들고, train_y는 row_id 검사 후 허용행만 float 파싱한다. 기존 baseline_rows.csv에서 arm=BASE, seed 세 개와 ensemble, 각 row_id 정확히 1회/24행 하루/8640행, 공식 train_y 일치 및 finite를 검사한다. preparation/receipt와 구성 요소 provenance를 연결해 외부 출처 표와 잠금 정답이 피처/모델 적합에 들어오지 않았음을 확인한다. 기존 runner의 raw train_X 전부 참조는 정답 사용과 다르므로 입력 구조 참조와 정답 누출을 구분한다.

## 원문 대비 빠진 항목

- 'CO₂ 거친 날의 온도 SSE 38%'는 EC OOF로 검증할 수 없다. 허용 provenance가 확실한 기존 공개 온도 OOF의 수치 검산 범위만 별도 검토하거나 **미검증**으로 남긴다. 담당 밖 모델 신규 학습은 하지 않는다.
- '밀폐 A 과대/B 과소'는 공개 EC OOF와 A/B 대리표지로 기술 검산할 수 있다. 농장별/seed별 role 표본 수·편향·RMSE를 보고한다. '입력 AUC .83'은 실제 동 정답이 없고 새 분류기를 안 맞추므로 **수치 미재현 및 실제 동 식별 미입증**으로 명시한다. 대리 역할 분류 AUC를 실제 동 AUC로 바꾸지 않는다.
- '갑자기 시작'/'전조 없음'/'2주 지속'은 별개 주장이다. 대리 순서상 급변의 유무만 기술 가능하며 실제 동·연속 달력·시작 전 전부 신호를 확정할 수 없어 나머지는 미입증이다. 이를 통째로 빠뜨리지 않는다.
- 'NaN 주변 이상한 패턴 없음'은 결측률 표만으로 검증되지 않는다. 주변 변화량을 정의해 진단하지 않으면 이 세부 주장도 미검증으로 남긴다. 결측이 인위적이라는 사실 및 모든 보간 허용을 뒷받침하지 않는다.
- 모델 특징 소진, 밀폐 고EC 과잉 일반화의 단일 원인, 높은 구간 보정의 성능 개선, 주기 특징 폐기, 동별 모델 불필요, 라벨 뒤바뀜 배제는 각각 별도의 추론/행동 권고다. 관측과 구분해 미입증으로 표에 넣는다.
- 6.445/6.451 및 외부 전용 58일 같은 기록은 이번 공식자료 통계로 검증할 명제가 아니라 출처 미확인 또는 금지 자료 연관 기록이다. 금지 원자료나 파생 정답표를 찾아 재구성하지 않는다.

## 중간/최종 점검 요구

중간에는 실제 허용 입력 파일 manifest·MASK 요약·allowlist 생성 경로·read-before-filter 유무·OOF key와 정답 일치·R1/R2 유효표본·A/B 생성 코드만 먼저 확인한다. 유리한 문턱이나 연결 정의를 사후 선택하지 않는다. 최종에는 원문 각 문장을 빠짐없이 fact/수치/인과/권고/과거실험기록으로 나눈 판정표와 계산 결과의 직접 대응을 확인한다. 표본이 적은 역할/농장/phase 교차칸에는 수치만 보고 증거가 확실하다고 하지 않는다.

비평의 결론은 **보완 후 기술적 진단 진행 가능, 개선·채택·센서/동 확정 증거로 사용 불가**이다.
