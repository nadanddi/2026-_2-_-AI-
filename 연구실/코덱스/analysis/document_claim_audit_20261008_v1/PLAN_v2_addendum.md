# 실행 전 계획 보완 v2 — critic_plan_v1 반영

PLAN_v1과 함께 읽으며 충돌 시 이 파일을 우선한다. 아직 실제 계산 실행 전이다.

1. R1: CO2 인접 관측 signed 차분 Δ=c[h]−c[h−1], 그 절댓값 중앙>14; 24시각 모두 정렬, 유효 차분 최소12. R2의 ac는 signed 차분의 corr(Δ[1:22],Δ[2:23]), 유효 쌍 최소8, 양쪽 분산>0. 불충분하면 판정불가(NaN), 거칠지 않은 날로 세지 않음. 실제 대상 데이터에서 유효성 전수 확인하고 미충족이면 실행 중단 후 별도 보고.
2. MASK는 농장별 test_X에서 전부 NaN인 열을 학습 같은 농장에 적용한다. 전시각 요약은 사후 진단이며 운영/검증 특징으로 사용하지 않는다. 원자료 열별 결측률도 마스킹 전후 모두 보존한다.
3. CO2 비율: 학습입력400일/공개360일/평가입력60일 별도 보고. 13%,21.6/4.8,온도오차38%의 원집단 정의가 없으므로 근사 수치로 정확 재현을 주장하지 않는다. 현재 EC14 OOF 모델은 원문 모델 불명과 구분한다.
4. K1: EWMA 최초 실내온도에서 초기화, alpha=1−0.5^(1/4), adjust=False; 미래 보간 없음. K1/K2는 h3..23 동일 관측 마스크. K2는 각 날 절편을 둔 최소제곱 회귀 잔차RMSE이며 표본내 진단 회귀 계산이다. 불충분/상수 입력은 NA. 새 EC/온도 예측모델 학습은 0; 진단 회귀·역할 분류기를 모델 개선 실험이라 부르지 않는다.
5. 기존 현재EC14 공개 OOF: receipt/prepare/runner/adapter/model SHA, 모든 train/query ID가 공개8640 내인지, query train 분리, 공식 y와 모든34560예측행 라벨 일치 확인. 공개360 범위 기준선의 EC14 재구현임을 명시(실제 평가성능/원문수치 모델 아님). PFN provenance는 기존40문맥 감사·공식 입력 기반 생성 소스를 근거로 하고 새 재학습하지 않는다.
6. 외기정확일치=동일 입력 묶음(실제 같은 날짜 확정 아님). 같은농장 묶음 정확히2개에만 번호순 A/B 역할; 연속번호인 쌍만을 주 통계로, 비연속쌍은 별도 개수 보고. 지속성도 연속쌍 A/B 역할끼리, 앞10기록 안/같은 pass/다른 묶음에 한정. 두농장 상관은 공통묶음 평균이므로 문서의 동별 상관과 직접 같지 않음.
7. 자정은 관측번호 d−1,d의 23→0이고 실제 다음 달력날 아님. 같은/다른 역할 및 같은/다른 외기묶음 수를 모두 보고. 역할이 다른 경계에 같은 날 두 복사 기록 경계가 포함될 수 있음. 온도 R²는 연속쌍 표본내 회귀이며 외부일반화 아님.
8. 누락 주장 검증: 밀폐한 A/B의 현재 EC14 편향은 공개 연속쌍 역할만의 서술로 재계산한다. 입력으로 A/B AUC는 공식 train_X 연속쌍에서만 LogisticRegression(C=1,max_iter=1000), 입력10종 평균(24h 사후 진단) 및 h0만 두 고정 입력, 농장별 같은 외기묶음을 단위로 번호순5연속 fold와 번갈이5fold 비교, fold 학습쪽 median/standardization만 사용. 모든 결과 보고, 좋은 것을 선택하지 않음. 출처 정답/실제동 정확도가 아니라 번호역할 분류이다. 데이터가 없는 농장/fold는 NA. 소형 진단 분류만 허용; OOF EC 보정기 학습은 없음.
9. 온도SSE38%는 허용자료로 만든 대응 OOF·모델 정보 없으면 미검증. 원문 다른49온실42개는 해당 정답의 잠금정책/정의 미확인으로 임의 신규 채점하지 않는다. 고EC 시작·전조전무·실제2주 지속은 실제 동/달력일 식별불가를 보고. 0.99→0.73~0.86·156/400·114/58은 정확 생성 코드 없으므로 별도 미확인 항목. NaN은 관측 분포만 확인, 삭제의도/안전한 양방향보간을 입증하지 않음.

최종 주장표에는 모든 문장을 개별 연결한다. 외부자료/외부파생표 사용0, 잠금정답 수치파싱0, EC/온도 예측모델 신규학습0, 제출0. 분류 진단 수는 별도 기록한다.
