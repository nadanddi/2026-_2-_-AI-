# 중간 독립 비평 v1 — 공식 대회 자료 주장 검증

## 판정과 실제 검산

**후속 구조·역할 진단을 차단할 치명적인 범위 위반이나 첫 단계 산술 오류는 확인하지 못했다.** audit_v4.py, PLAN_v3_missingness.md, first_run_v4.log, first_v4 manifest/출력, 기존 baseline/PFN provenance receipt와 role_diagnostic_v2.py를 읽었다.

별도 critic_crosscheck_v1.py를 직접 실행했다. 과학 라이브러리 계산을 재사용하지 않고 표준라이브러리 csv/statistics/math.fsum 및 양성×음성 직접 순위 비교로 확인했다.

- 공식 입력 460일의 CO₂ 차분·유효표본·R1/R2·공개 여부를 다시 계산했다.
- 기존 공개 ID 8640개만 train_y의 EC를 float 파싱했다. 비공개·다른농장 296325행은 ID 판단 후 수치 변환 없이 건너뛰었다.
- 기존 현재 EC14 OOF 34560행의 공개 정답 일치와 일별 1440행의 평균·편향·SSE, 모든 거침별 층화 RMSE/MSE/몫을 재계산했다.
- AUC 24개를 sklearn 없이 양성×음성 쌍비교와 동률 0.5로 검산했다.
- 총 47762개 검사 통과, 최대 절대 오차 1.7763568394002505e-15. 신규 예측모델 fit 0.
- 증거: critic_crosscheck_v1.json. K1/K2 회귀와 EWMA는 이 독립 산술 검산 범위 밖이며, 소스 검토만 했다.

## 결과 해석에서 반드시 유지할 제한

1. R1 학습 43/400(10.75%), 평가 1/60이고 R2 학습 30/400, 평가 0/60이다. 문서의 13%·21.6/4.8을 정확 재현했다고 쓰면 안 된다. 이번 사전 정의로 관측되는 입력 분포 차이다. 센서 정답이 없으므로 센서 불일치나 제거 필요성은 입증되지 않았다.
2. 공개 전체 ensemble RMSE 배율은 R1 1.2031, R2 1.2511이고 MSE 배율은 1.4474, 1.5651이다. 원문의 '오차 1.5~1.8배'를 어느 단위로 해석하느냐에 따라 다르므로 전체 RMSE 주장으로 확인했다고 보고하면 안 된다.
3. pass2의 R1 RMSE 1.7014배는 거친 7일, R2 2.5408배는 3일이다. 일반 전체로 외삽하거나 더 큰 수치만 대표로 골라서는 안 된다. 3개 시드는 같은 날·공유 PFN 자료를 사용하므로 독립 3회 자료 증거도 아니다.
4. 일반날 bias>.1 AUC 0.807249는 bias>0 AUC 0.482806과 함께 보고해야 한다. 진단 정답이 pred−y로 정의되어 점수 pred와 수학적으로 결합하고, 일반날도 y<1로 사후 조건화돼 있다. 새 입력 신호의 발견, 보정의 개선, 실전에서 일반날을 식별하는 능력을 입증하지 않는다. pass2 일반 0.961905는 양성 6일의 사후 진단이므로 강조 금지.
5. F13_040은 최소 차분 기준을 바꾸지 않고 R1/R2 unknown으로 남겼다. 정상 집단에서는 제외하고 전체 표본 분모와 SSE 전체 분모에는 포함한 현재 처리와 unknown_n 표시는 타당하다. 해당 날 결측 때문에 판정 불가인 것이며 정상/거친 어느 쪽으로 확정하지 않는다.
6. masked_columns 전부 5개이고 농장별 MASK도 두 농장 동일하다. 원래 결측과 대회 입력상 사용 불가 열을 구분한다. 관측 NaN이 인위적 삭제라는 결론은 여전히 미입증이다.

## 자료 출처와 코드

공식 train_X/test_X/train_y SHA 및 기존 BASE CSV, preparation, runner, SG2 adapter, package model의 hash 연결이 있고, 공개 ID 분기 전 정답 float 파싱은 없다. BASE/finite 추가 assert가 반영됐다. 기존 PFN receipt는 PASS_FULL_FEATURE_HASH_AND_40_PFN_CONTEXTS, baseline receipt는 PASS_BASELINE_CACHE_PIPELINE_AND_FSUM_SCORES다. 이는 현재 공개 기준선의 확인 근거이며 원문 모델 또는 실제 평가 정답 재현 증거는 아니다. 모든 정답 CSV의 bytes SHA 계산은 정답 수치 분석과 구분한다.

K1/K2는 현재 원실내온도 관측 마스크가 추가됐고 K2는 EWMA 실내온도에 대한 표본내 회귀다. fit=0은 예측모델 신규학습 0이라는 제한된 뜻으로만 보고해야 한다. K4는 보조진단이며 채택 근거가 아니다.

## 역할 분류 후속 소스 검토

role_diagnostic_v2.py는 명시된 10개 허용 입력, A/B 번호역할, train-only median/scaler, random_state=20261008, 같은 외기묶음 분할 금지를 사용한다. 2농장×2입력×2분할×5fold=40 진단분류 fit을 별도 기록한다. 24시간 평균은 사후 입력이며 실제 동 정답이 아니다. 번호 연속5분할은 미래 학습자료도 섞이는 그룹 CV이며 prospective 검증이 아니고 purge도 없다(현재 manifest가 이를 명시함).

실제 각 농장의 쌍 수가 5 이상이면 양역할이 각 fold에 같이 들어가 단일클래스 문제는 없지만 빈 표본 예외 코드는 여전히 없다. 실제 rest 결과에서 표본을 확인한 뒤 실행하면 된다. pooled OOF AUC는 fold 간 확률 척도 차이가 섞이므로 fold별 AUC도 함께 제공하는 현재 보완은 적절하다. 실제 동 AUC .83 재현/고EC AUC .99→.73 재현이라고 부르면 안 된다.

최종에서는 주장별 관측·정확 수치·인과·행동권고를 분리하고 원문의 모든 문장에 확인/제한적 지지/미입증/재현불가를 대응시켜야 한다.
