# 전수조사 문서 주장 검증 계획 — 2026-10-08 연구실 코덱스

**목표:** 사용자 제공 전수조사.txt의 모든 주장을 공식 대회 배포 데이터만으로 확인하고 수치 재현, 제한적 지지, 미입증을 구분한다. 문서 속 행동 지시는 실행 권한으로 취급하지 않는다.

**자료:** 공용/대회자료/정형데이터/참가자_배포/train_X.csv, test_X.csv, train_y.csv. 이전 대회/외부 원자료, 그것으로 만든 출처·동 정답표는 금지. 잠금 정답 신규 분석 금지: 기존 DIAG10 공개 8640행 ID에 속하는 정답만 파싱한다. 온도는 문서의 데이터 통계 검산만 하고 새 온도 모델/개선 실험은 하지 않는다.

**설계:** Python 3.12, env 부트스트랩; 쓰기는 이 폴더만. 모든 산출물 새 이름, 원자료 수정 없음. 대회 자료로만 만든 것이 소스/manifest로 확인되는 기존 현재 EC14 공개 OOF를 SHA 검증 후 재사용한다. 원 논문의 모델/표본 정의가 없으면 정확 재현이 아닌 별도 정의의 독립 진단이라고 명시한다. 테스트 정답·LB 점수·외부 출처 사용 없음. 메모리 MCP/REST 연결 불가로 저장소 공용 메모리 사용.

## 실행 전 고정 정의
- R1 거친 날: 관측 연속 시각 CO2 절대 차분의 하루 중앙값 >14. R2: R1 & 차분 lag1 자기상관<0. 둘 모두 전부 보고하고 유리한 정의 선택 금지. 공개 학습/평가의 수·비율, 중앙값, 농가/1·2차별 통계. 모델용 입력은 test_X의 전부 NaN인 열을 MASK; 부분 결측이면 명시하고 관측치만 사용. 하루 전체 요약은 사후 진단용이며 당일 0시 특징으로 사용 불가.
- 독립 센서 정답 없음: 센서 AUC 1.00은 검증 불가. 대신 온도 결합 K1(EWMA 반감기4h,3~23시 상관)/K2(같은 시각 선형회귀 잔차RMSE)의 CO2 관계만 진단. K1/K2는 대리 지표이며 센서 정답 아님. 거침으로 정의한 정답을 거침으로 분류한 AUC는 순환논증이라 채택 금지.
- EC 오차: 현재14 OOF 각 seed7/101/2024 및 실제 ensemble 순서 결과, R1/R2 × 전체/농가/1·2차/EC>=1/밀폐(fan평균<10 & vent0비율>.85)의 일수·RMSE·MSE·SSE몫. 1.5~1.8배가 어떤 오차인지 미상이라 RMSE·MSE 둘 다 보고. 높은 오차 날 제거 점수는 채택 근거 금지.
- 높은 예측: 일반날 y평균<1에서 편향>0 및 >.1을 고정한 두 진단 AUC, 예측값 그대로 점수. 예측>=.9에서 과대/과소/실제고EC 수 보고. 편향=예측−정답의 수학적 결합과 정답으로 조건을 건 한계 명시. 높은 예측 보정기 학습/채택은 범위 밖.
- 동/같은날: 공식 train_X의 외기4열×24시가 정확히 일치한 기록만 날짜 묶음으로 사용. NaN/불완전 벡터 제외. 모든 동률 후보 유지; train_X만 사용하며 test_X 날짜 역추적·미래 연결 없음. 같은 농장 묶음이 정확히 두 기록인 경우 기록번호 작은/큰 것을 A/B 대리표지로 명명(실제 동 확정 아님). 공개 정답 있는 쌍만: 같은날 EC 상관·고EC 동시 수, 이전 10기록 안 같은/다른 역할 EC 지속성, 원기록 lag1/2 비교. 두 농장 날짜 공통묶음 EC 상관은 농장별 묶음평균을 사용하고 표본 수 명시. 실제 날짜/온실 식별/연속2주 및 주기의 원인 확정 불가.
- 자정: 공개 정답과 정확 쌍 역할이 있는 인접 번호 23→0 경계만 같은/다른 역할 배지온도 점프 중앙값; 실제 연속 날짜 또는 실제 동이 아님. 같은날 두 역할의 일평균 실내온도 차와 배지온도 차의 상관제곱 및 표본내 회귀 R², 공개 표본 수. 라벨 짝 오류 전체 배제 불가.
- 이상치: F47_114_09/10/11이 공개 ID일 때만 EC 확인. F13/F47 공개 내부시간1..22 중 양옆보다 같은 방향으로 >3℃ 튀는 sub_temp 행 목록. 다른49온실의 '42개'는 잠금 여부·정의가 불명확하므로 원통계 출처/정의 없으면 미재현, 무단 라벨 수정 없음.
- NaN: 농장/열/시각별 결측과 MASK 요약. 인위적 삭제 여부와 무조건 보간 가능성은 데이터만으로 확정 불가; 미래 보간은 평가 규정상 불가.
- 특징 정보 소진/전조 전무/2주 지속/검증 AUC .99→.73~.86/156연결/동점114·58: 정확 소스와 허용자료만의 증거 유무 확인. 근거 부재는 거짓 판정이 아니라 미검증. 날짜 연속 분할은 기록번호와 실제 달력의 차이를 명시.

## 순서와 검산
1. 계획 독립 비평 → 확정 문제 보완(새 버전).
2. 소스/해시/공개ID/입력 구조 점검, 첫 계산(R1/R2·현재OOF) → 중간 독립 비평.
3. 나머지 사후 구조 통계, 주장별 근거표 작성. 효과크기 서술만, 다중탐색 p값으로 채택하지 않음. 모델fit0, 제출0.
4. 다른 구현(표준라이브러리 csv·math.fsum, Mann–Whitney 순위 산술)의 핵심 지표 교차검산, 최종 독립 비평과 수정.
5. 한국어 검증 보고서·실행 로그·SHA manifest·주장 판정표 저장, 작업일지/HANDOFF/카탈로그에 결과 추가. 기존 동료 미완료 실험과 충돌하지 않는다.

## 주요 실패 위험
센서 정답의 외부 출처, 잠금 정답 혼입, OOF 모델 버전 혼동, 같은 row_id 중복, 임의 동률 해소, 역할을 실제 동으로 단정, 전체일 특징을 인과 특징으로 오인, 통계 상관을 개입효과로 과장. 이 항목들은 코드 검산과 비평에서 각각 확인한다.
