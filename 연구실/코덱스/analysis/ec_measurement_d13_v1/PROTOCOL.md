# D13 EC 측정 정의의 공개 데이터 진단

2026-09-30 연구실 코덱스. 실행 전 코드와 함께 main 커밋.

4번 조사: 공식 문제설명서에서 목표는 시간평균 배지 EC, 단위 dS/m. 센서 모델·bulk/pore·참조온도 설정 미제공. 기존 400일 감사에서 일내 logEC-배지온도 기울기 .0204이나 온도 환산 모델은 기각됐다. 이 기울기를 센서 설정 증명으로 쓰지 않는다.

이미 공개 채점된 234일 5616행만 선택하고 train_y의 sub_temp를 그 행에만 결합한다. 기존 최종 잠금 파일을 읽거나 그 날짜를 분석하지 않는다. test_X 미사용. 온도 모델 개발/수정 없음.

고정 진단: (1) 일내 중심화 logEC~sub_temp 기울기; (2) 농장×시각과 날 효과 제거; (3) 농장×시각+날 효과 후 sub_temp·in_temp·VPD·일사/100·환기/100 통제; (4) 같은 날 1~5시 1차 차분. 농장별, 전체 보고. 234일 block bootstrap 2000회(seed=300913), OLS 기울기만 확인. logEC<=0 행은 배제하고 수를 기록. 모델이나 보정식을 선택/학습하지 않는다. 일내 상관은 계측 온도효과·생리·수분 변동을 식별하지 못하며, 어떤 결과도 미보상 EC 확정으로 쓰지 않는다.

이전 로그와 현재 공개 subset의 범위가 달라 숫자 차이를 곧바로 정정하지 않는다. 관측이 계측 가설과 맞는지, 다른 기작도 남는지 구분해 연구실/코덱스/research/ec_comprehensive_20260930_v1의 조사와 연결한다.
