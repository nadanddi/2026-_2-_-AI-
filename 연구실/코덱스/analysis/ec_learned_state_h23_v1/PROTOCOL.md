# H23 관측 환경 반응을 학습한 중간 상태의 EC 추가정보

2026-09-30 연구실 코덱스. 사용자 중간변수 예측 제안 및 진행 지시. 실행 전 코드와 본 프로토콜을 main 커밋한다. 단일 사전 가설, 재가중/재시드 선별 금지.

## 질문·한계
직접 관수/배액/함수율 정답이 없으므로 실제 물량의 oracle 또는 감독학습은 불가능하다. 대신 이전 실내 상태와 현재 날씨·운전·온도로 현재 절대습도(AH) 변화 및 CO2 변화를 학습한다. 예상 변화·관측 혁신(실제-예상)·그 당일 누적이 환경 운전 상태를 표현해 EC에 추가 정보가 있는가? 이들은 물/이온 수지 또는 급액량의 실측치가 아니다. 온도 정답/모델은 사용·수정하지 않는다.

## 입력·교차학습
F13/F47 train_X 400일만 사용. MASK 제외 in_rad/act_side/act_valve/act_cool/act_pump. 현재/이전 같은 온실·같은 날, 자정 초기화; 최장 lag6. 상대 day·시각·온실표시와 14개 가용 원시 열(실내3/구동기7/외기4) lag1~6, 현재 날씨4·구동기7·실내온도만 보조학습 입력. 현재 RH/CO2 및 이를 포함하는 현재 누적요약은 보조 입력에 넣지 않는다. 보조 정답은 현재 AH−이전AH와 현재CO2−이전CO2. 결측/0시 보조정답은 학습 제외, 예측 혁신은 NaN 유지. 시간 누락은 해당 lag을 NaN 처리.

보조기 ExtraTrees 다중출력 200 trees/leaf8/max_features1/seed7 또는101/n_jobs4, 정답 단위는 보조 학습행 std로 표준화. 최종 EC 모델 학습행 보조 예측은 온실-일 3분할 교차학습((day//14+farm번호)%3); 각 inner 검증일 ±1일 제외。14일 블록을 사용해 날마다 교대할 때 ±1일 purge가 학습일 전체를 없애는 문제를 방지한다. outer 검증일·기존 공개확인 fold8/9·최종잠금40일 ±1일은 EC와 보조 모델 학습에서 모두 제외한다. 보조기 검증일 실제 RH/CO2는 추론 시 현재 가용 센서로 혁신 계산에만 사용, 적합에는 사용하지 않음.

## 대조·실행
기존 FULL38 특징(원시10/day/시각/자정/0시/구동기누적), 직접 대조군=FULL38+현재외기4+원시14 lag1~6+현재 관측 AH/CO2 변화. 중간상태군=직접 대조군+보조 예측2/혁신2/각 당일누적4(총8). EC ExtraTrees는 세 군 모두 400trees/leaf1/max_features1/seed7,101. 각 outer 학습 EC min/max로 clip.

기존 v2를 기준으로 candidate=clip(v2+.24*shrink(중간상태ET−FULL38ET)); direct=clip(v2+.24*shrink(직접ET−FULL38ET)). shrink=.5현재차이+.5당일현재까지평균차이. 기존 H20에서 사용한 고정 .24를 재탐색 없이 사용. 목적은 중간 표현과 원시 이력의 차이를 분리하는 것으로, H20 특징 재가중이 아니다.

outer 공개 folds0/2/4/6/8/9 × seeds7/101, 234일/5616행. 단계1 선별: 후보가 v2 및 direct보다 모든12칸 RMSE 감소, 두 농장 모두 감소, 각 seed 날단위 paired bootstrap20000회 후보-v2 및 후보-direct p_worse<.025/2 및 97.5% CI 상한<0(두 비교 본페로니). 보조 ΔAH와 ΔCO2의 pooled OOF MSE 각각 persistence(0변화)보다 감소해야 중간예측 성공. 범위 전체/고EC/0~6시 별도 진단은 사후 후보 선택에 사용하지 않는다.

실패 시 H23 이 구현 기각·종료. 통과 시 후보 채택은 하지 않고 A/B/DIAG10×2시드·EXT10/12·새시드·인과/결정성·잠금 확증을 별도 사전등록으로 이어간다. 이번 프로토콜에서는 final lock 채점 금지, test_X 읽기 금지, 제출물 생성 금지. 공개 OOF 재사용 및 같은 모자료 출처 반복 가능성은 독립 확증 한계다.
