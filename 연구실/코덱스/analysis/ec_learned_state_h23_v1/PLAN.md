# H23 실행 계획

목표: 중간 환경반응 예측의 정확성과 EC 추가정보를 직접 이력 대조군으로 분리한다.
설계 및 고정 수치는 PROTOCOL.md를 따른다. 사용자 실험 자율 진행/main/내 폴더 규칙이 승인·worktree 기본값에 우선한다. 이 세션에서 직접 구현한다.

- [ ] 테스트 먼저 작성: 미래/다른온실/행순서/prefix 인과, 현재 보조타깃 배제, 결측·자정·시각누락, ±1일 제외 및 nested 분리.
- [ ] run.py 구현: 인과 특징, 보조 교차학습, 3개 EC 대조, 고정 후보, paired bootstrap, 학습일 감사·해시.
- [ ] 테스트 PASS 확인 후 프로토콜·코드 경로만 main 사전커밋. 재학습 중 원본 수정 금지.
- [ ] 6폴드×2시드 모두 실행. 선별실패면 중단; 더 넓은 검증기를 통과했다고 주장하지 않는다.
- [ ] 독립 저장예측 산술 검산, 코드·입력 해시, 학습일 감사 및 인과/결정성 결과 확인.
- [ ] 결과보고서 새 파일·작업일지 세션·공용 HANDOFF·카탈로그 새 번호 작성. 사용자에게 결과와 한계 보고.
