# N3 동일 0시 분해 해석 검토 v2

2026-10-10 연구실 코덱스. v1의 언어 혼입을 바로잡은 한국어 완전본이다. 원 v1은 보존하지만 해석 근거로는 이 v2를 사용한다. 수치·검산·판정 변경은 없다.

`n3_baseline_decomposition_v1.py/.json`을 실제 읽고 별도 Python으로 저장 JSON 42항목을 산술 검산했다. critic 새 fit/predict·원정답 CSV/NPZ 재로딩 0. 새 모델 결과·인과 기여율·채택 판정 0.

**판정: 기준에도 같은 0시 분해를 적용한 추가 진단은 이전 비평의 비교 부족을 보완했다. DIAG10/EXT10에서는 0시 기준 변화 오차 MSE가 줄었지만 음의 교차항이 덜 음수가 되어 전체 MSE가 증가했다. EXT12에서는 0시 수준 오차도 크게 증가했다는 서술이 수치와 일치한다.**

## 구현·산술 확인

두 모델 모두 같은 query ID/공개 온도 정답에 대해 `e0=pred0−truth0`, `es=(pred−pred0)−(truth−truth0)`를 사용한다. 각 모델의 최종 예측을 동일한 좌표계로 비교했다. 원 NPZ의 receipt SHA를 검사하고 query truth는 예측 종료 후 진단에만 사용한다. 같은 fold의 0시 query 행을 찾는 고정 row_id 서식을 전제로 한다.

별도 JSON 산술에서 각 모델의 항등식, 중심 공분산 변환, 모든 delta, delta 항등식, sqrt(totalMSE)와 기존 RMSE 일치를 42번 검산했다. 최대 차이는 2.22e−16이다. 이번 critic은 원정답에서 분해를 다시 계산하거나 bootstrap을 추가 실행하지 않았다.

|검증기|Δ0시 수준 MSE|Δ0시 기준 변화 MSE|Δ교차항|Δ전체 MSE|
|---|---:|---:|---:|---:|
|DIAG10|+.014377|−.226824|+.471841|+.259394|
|EXT10|+.003804|−.239852|+.422469|+.186421|
|EXT12|+1.564654|−.473145|+.560319|+1.651829|

단위는 ℃²이며 RMSE 차이나 비율이 아니다. 교차항은 `2E[e0·es]`, 중심 공분산 항은 `2Cov(e0,es)`로 서로 다르다.

## 사용할 수 있는 해석과 제한

DIAG10의 교차항은 기준 −1.30348→N3 −.83164, EXT10은 −1.53278→−1.11031이다. 0시 기준 변화 MSE 감소보다 이 교차항 증가가 커서 전체 오차가 악화했다. EXT12는 수준 MSE 1.78468→3.34934 증가에 더해 교차항도 −2.25966→−1.69934로 바뀌어 모양 오차 감소로 상쇄하지 못했다. EXT12의 0시 수준 평균편향도 +.470℃→+1.370℃로 증가했다.

다만 정의상 `es=e(h)−e0`이므로 두 항은 같은 0시 오차를 공유한다. 음의 교차항에는 이 대수적 결합도 있다. **‘기준 모델이 물리적으로 수준 오차를 모양으로 보상했다’, ‘상쇄를 학습하는 능력이 실패 원인이다’라는 기전 설명은 입증되지 않았다.** ‘동일 0시 좌표계에서 음의 오차 교차항에 의한 상쇄가 약해졌다’라는 기술적 서술로 제한한다.

‘모양이 개선됐다’도 정확히는 **‘이 0시 기준 변화 예측의 MSE가 감소했다’**이다. 평균을 제거한 직교 모양 평가나 실제 열 응답 개선을 뜻하지 않는다. 세 항의 delta는 정확한 회계 분해이지만 각 항을 전체 delta로 나눠 독립 인과 기여율을 만들지 않는다. 좋은 모양 부분만 기준 모델의 수준과 합치는 것은 새 후보이며 이번 N3의 채택 결과가 아니다.

## 현재 해석 갱신

이전의 ‘기준에 동일 분해가 없어 비교 기여를 단정할 수 없다’는 부족은 보완됐다. 현재 사용 문장은 **‘N3는 0시 기준 변화 MSE를 줄였지만 DIAG/EXT10에서는 교차항의 상쇄가 약해졌고, EXT12에서는 수준도 악화해 전체 FAIL이었다’**이다. 전문가의 배지 상태·멀칭·수온 설명을 입증한 결과는 아니다. 사후 분해를 보고 계수 최적화로 N3를 다시 채택하지 않고 실패 기록을 유지한다.
