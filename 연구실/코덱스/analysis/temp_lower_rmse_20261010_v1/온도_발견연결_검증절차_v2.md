# 온도 발견을 연결하고 해석을 갱신하는 절차

2026-10-10 연구실 코덱스. 공식 대회 자료와 기존 결과를 연결한다. 새로운 외부 수치자료를 특징에 넣지 않는다. 현재 N4 전체 예비실험은 진행 중이다.

## 연결에서 보존할 것

각 발견은 다음을 함께 보존한다: 원문·실행 코드·결과 파일, 원 모델/버전, 입력의 출처와 MASK 여부, 검증 배치/시드, 지표의 수학적 정의, 관찰과 원인 추정의 구별, 구현이 사용하는 정보, 실제 타깃 효용. 이름이나 점수가 비슷하다는 이유만으로 동일한 발견으로 묶지 않는다.

| 관찰 | 이어지는 가설 | 이번 구현·시험 | 해석 갱신 |
|---|---|---|---|
| 공식 다른 농장의 Δ온도도 예측 가능 | 다른 농장의 변화 prior가 F13/F47에 도움 | N2 48농장 LOFO→누적1열 CODEX | LOFO41/48 개선과 타깃 효용은 다른 주장. 타깃 gate 실패. 도메인 차이/중복/drift 원인 미확정 |
| TK1 W30G의 하루 평균 오차 비중이 큼 | 현재 모델의 하루 기준을 따로 예측하면 도움 | N3 train y0 수준+당일 변화 두 머리 | 평균 오차와0시 오차는 다른 좌표. 변화 MSE 감소에도 전체 악화. 공유anchor 교차항을 물리 보상 원인으로 읽지 않음 |
| 전문가가 배지-공기 분리·관수 수온·흰색 멀칭 가능성을 설명 | 기존BASE 일사량 대리 특징을 CODEX에 넣으면 도움(분석자 가설) | IRR4 기존BASE proxy와 day-reset lag1/3/8 | 새 관측자료가 아니다. DIAG 신호와 EXT10 악화가 공존. 물리효과와 관리패턴 대리효과는 분리되지 않음 |
| IRR4 추운 검증 실패·원9회8~10℃ gate 존재 | 기존gate로 보완을 제한하면 전체 조합에 도움 | N4 c_new=c+g*(IRR4-c), 같은BASE/PFN 공유 | 별도 사후 가설. 신규배치도 기존 정답을 재사용한다. 전체12fold/PFN49 한 표본은 원9회PFN8/모든 실제seed/평가점수의 증거가 아님 |

## 순서

1. 기존 기각과 원문을 확인한다. 새 자료·새 방법인지, 기존 방법의 재포장인지 표시한다.
2. 관찰에서 구현으로 이동한 가정을 명시한다. 평균→0시, 다른농장→타깃, 구성원→전체 조합처럼 이동한 단계는 새 가설이다.
3. 허용 입력과 타깃 경계를 코드에서 고정한다. query 정답 제거, 같은 온실 현재·과거 입력, 학습 MASK, fold-local 전처리, hash/ordered IDs를 먼저 확인한다.
4. 판정과 범위를 실행 전에 고정하고 독립 계획 비평을 받는다. 첫 배치 뒤 중간 비평, 최종 수치·문장 뒤 최종 비평을 남긴다.
5. 구성원 오차와 전체 조합의 오차를 구별한다. 보완값 δ에 대해 `MSE_new-MSE_base=2E[e_base*δ]+E[δ²]`도 확인한다. 이는 산술 관계이며 인과효과가 아니다.
6. 실패로 기존 관찰을 어디까지 갱신할 수 있는지 한정한다. 구현 실패를 물리 현상의 부재로 확대하지 않는다. 채택 근거가 부족하면 채택0을 유지한다.
7. 정정은 새 문서·카탈로그 새 번호로 연결하고 일지/HANDOFF의 최신 경로를 갱신한다.

## 이미 알 수 있었던 것과 새로 확인한 것

TK1의 하루 평균 정의는 기존 문서14행에 이미 명시돼 있었다. 새 외부 자료가 필요해서 몰랐던 내용이 아니다. 기존 요약의 ‘수준 비중’만 구현의0시 기준과 연결하면 정의 차이를 놓칠 수 있다. 이번에는 원 모델과 분해 정의까지 직접 연결하고 같은 좌표의 기준 모델 분해를 추가했다.

전문가 답변에 일사량 직접 설명은 없다. 일사량 연결은 기존BASE 특징과 전문가 설명을 연결하려는 분석자의 가설이다. 전문가 답변은10-09 자료이며 관수 수온·멀칭·실제 배드ID를 관측값으로 제공하지 않는다. 설명 가능성과 특징의 이용 가능성을 구별한다. 이미 BASE에 들어 있던 일사량 특징을 새로운 물리지식 발견이라고 주장하지 않는다.

N2 타깃 효과, N3 같은좌표 기준 비교, N4 전체 조합의 조건부 효용은 실제 새 실험으로만 확인할 수 있는 부분이다. 소급해서 ‘알고 있었다’거나 원인까지 증명했다고 하지 않는다.
