## 발견을 연결하며 바뀐 해석

1. **다른 농장에서 변화 예측이 가능해도 타깃에 도움이 되는 것은 아니다.** N2 48농장 LOFO41/48 개선 후 F13/F47 누적prior 적용은 DIAG-.0481/EXT10+.2157/EXT12+.4020%로 실패했다. 도메인 차이·기존정보 중복·누적drift 중 원인은 미확정이다.
2. **하루 평균 오차와0시 오차를 구별해야 한다.** 옛TK1(W30G)의 ‘하루 수준 비중’은 하루 평균 오차였다. N3는0시 기준으로 새 가설을 시험했다. 변화MSE는 세 검증 모두 감소했으나 전체RMSE는+21.26/+11.16/+72.51%로 악화했다. 같은 좌표로 기준까지 분해하니 일반 검증의 음수 교차항 상쇄가 줄었고, EXT12 수준MSE도 증가했다. 공유anchor의 대수결합을 물리 보상 능력으로 해석하지 않는다. 정의는 기존 문서에 있었으며 새 자료가 필요했던 정보가 아니다.
3. **추운 날과 현재 추운 순간은 다른 조건이다.** EXT10은 FULL 연속EWMA3h의 일최소<10인 날이고, 기존gate는 현재온도8~10이다. N5의 raw 당일prefix최소도 filter/reset/관측시각/threshold가 다른 대리 조건이다. 이 차이를 발견해 새 가설을 시험했지만 효용은 확인되지 않았다.
4. **전문가의 설명과 분석자의 가설을 구별한다.** 원 답변은 배지-공기 분리·관수 수온·흰색 멀칭을 설명했고 일사량 직접 설명은 없었다. IRR4/N4/N5의 일사량 연결은 기존BASE 대리 특징을 이용한 분석자 가설이다. 문서비평 지적을 절차v2와 카탈로그6.482에서 정정했다. 실제 수온·멀칭·배드ID·센서 깊이를 새 수치 특징으로 만들지 않았다.

## 검사와 비평

- N4 계획/첫배치/최종 독립 비평 완료. 독립 전체12fold source·data·buffer·weights·season·context표본순서 및33,948산술/20k bootstrap 검산이 일치했다. root144검산도 통과했다.
- N5 계획·코드 보완·첫배치 비평 완료. 원자료 finite-orNaN/460일×24h/결측prefix/일별gate비증가/두 타깃열 거부,23개 미래시각 suffix·다른온실·행순서 감사149,040 비교값 통과. root 전체155검산과 scalar prefix/원parent배열/혼합/20k bootstrap도 일치했다. 이는 새 gate와 수치의 검사이며 전체 PFN 예측 인과 검사가 아니다.
- 전문가 직접발언 오귀속과 첫배치 재개 옵션 문제가 비평에서 발견돼 새 버전으로 보완됐다. 조정한 것은 출처 설명과 실행 안정성이며 결과를 본 뒤 사전 수치 기준을 고치지 않았다.
- 전체 학습 전처리와 원9회 계절CSV의 최대차2.84e-14/raw exact false, 가중치 개수1=7259/.2=2318/.04=23, 열순서 보존. 이것은 원9회 전체모델의 정확 재현 증거가 아니다.

원9회 소수6자리 정확 재현 불일치(최대.004595℃)는 미해결이다. 이번 예비 후보가 실패해 PFN8 전체·추가 실제 stochastic seed·확인배치 개선 검증으로 진입하지 않았다. 기존 정답을 재사용한 사후 탐색이며 Bonferroni7만으로 모든 과거 선택 편향이 해결되지 않는다.
