# 온도 발견 연결 독립 문서 비평 v1

2026-10-10 · 연구실 · 코덱스

검토 대상은 `온도_발견연결_검증절차_v1.md`와 `N3_발견연결_분해좌표_v1.md`다. 같은 폴더의 N2 LOFO 결과·타깃 최종 비평, N3 결과·기준 동일분해·독립 해석 비평, N4 계획 보완·첫 fold 중간 비평·전체학습 전처리 JSON, 원 TK1 오차지도와 사용자 제공 전문가 답변을 대조했다. 신규 fit/predict·정답 재채점 0, 새로운 외부/이전 대회 자료 및 산출물 사용 0. 기존 파일 수정 0.

## 수정이 필요한 주장

**[P2] 전문가 발언과 분석자의 일사량 가설을 분리한다.** 절차 표의 “전문가가 배지-공기 분리·일사량 영향 가능성을 설명”은 제공된 `공용/전문가_질의응답/2026-10-09_딸기_배지온도_EC_답변.txt`에 완전히 대응하지 않는다. 원문은 배지 온도가 실내 온도와 따로 움직이는 것이 정상이라는 설명, 관수 물 온도에 따른 변화 가능성, 흰색 멀칭의 온도 저하 가능성을 말한다. 일사량 영향을 직접 설명한 문장은 없다.

권장 연결은 “전문가는 배지-공기 분리와 관수 수온·멀칭의 가능성을 설명했다 → 분석자가 기존 일사량 대리 특징의 추가 효용을 별도 가설로 제안했다 → IRR4를 시험했다”다. 전문가 답변이 일사량 특징의 물리 타당성이나 효과를 직접 뒷받침하는 듯한 출처 귀속을 피한다. 본문에서 관리패턴 대리효과와 물리효과를 구분하고 새 관측자료가 아니라고 표시한 제한은 적절하며 유지한다.

## 근거와 일치한 연결

| 검토 항목 | 확인과 판정 |
|---|---|
| N2 타농장 관찰 → 타깃 prior | LOFO 결과에는 48농장, 두 기준보다 개선한 비율 41/48, gate 통과가 있다. 타깃 최종 비평은 DIAG의 미세 평균 개선에도 유의성·EXT 방향 실패로 구성원 screen 실패와 전체 혼합 미진입을 구분한다. 문서의 “타깃 gate 실패·원인 미확정”은 적절하다. 타농장 전체 전이 불가능이나 전체 W40G-S 무효로 확대하지 않는다. |
| TK1 평균 수준 → N3 0시 기준 | TK1 원문 14행의 평균 오차²×행수/전체 SSE 정의를 정확히 옮겼다. W30G와 원9회 W40G-S도 구분했다. 하루 평균의 직교 분해를 0시 anchor로 바꾸는 것은 새 가설이며 직접 재현이나 필연적 해결책이 아니라는 판정이 타당하다. |
| N3 동일좌표 비교 | 기준/N3를 같은 0시 좌표에서 비교한 JSON·독립 비평에 맞는다. DIAG/EXT10은 변화 MSE 감소보다 교차항 증가가 크고, EXT12는 수준 MSE도 증가한다. `es=e(h)-e0`의 대수적 결합을 물리 보상 원인으로 읽지 않았으며, N3 구현 실패가 TK1 관찰을 반박하지 않는다는 제한이 적절하다. |
| N4 구성원 → 전체 조합 | `c_new=c+g*(IRR4-c)`는 CODEX 변경 정의로 읽혀야 한다. 전체 혼합 변화는 계획 v2의 `(0.6-0.4*g)*g*(IRR-CODEX)`이며 구성원 변화와 동일하지 않다. 절차가 구성원/전체 오차를 분리하고 최종 보완값의 MSE 항등식을 요구하므로 현재 주장에는 충돌이 없다. 원PFN8·모든 stochastic seed·평가점수 증거로 확대하지 않는 제한도 적절하다. |
| 허용 구현 | query 정답 제거, 같은 온실 현재·과거 입력, 학습 MASK, fold-local 전처리와 ID/hash를 요구한다. N2 최종 비평 및 N4 중간 비평의 범위와 대응한다. 이는 문서·저장 receipt 대조이며 본 검토자가 전체 특징을 독립 재생성하거나 전체모델 인과성을 증명한 것은 아니다. |
| 전체학습 전처리 → 원모델 재현 | JSON은 train/query season 최대 차이 2.842170943040401e-14, 양쪽 raw exact false, 가중치 개수 .04계열 23/.2 2318/1 7259, 열순서 보존을 기록한다. 문서가 이를 전처리 계약 확인으로만 쓰고 전체 원모델 정확 재현과 분리한 것은 적절하다. 가중치 개수 동일 자체는 행별 배정/모델/최종 예측 동일성을 보장하지 않는다. |

## 범위 유지

N4는 문서 작성 시점의 진행 중 예비실험이다. 첫 fold 검산과 수치가 전체 12fold 효용·원9회 8문맥 재현·평가 점수 개선의 증거가 아니라는 제한을 유지한다. 신규 배치에서도 기존 정답을 재사용하므로 새 독립 표본이라고 부르지 않는다. 전체학습 전처리 검사에서 평가 예측을 생성하지 않았다는 JSON도 확인했다.

특징 감사 셀 수를 독립 표본 수나 모든 예측에 대한 규정 실증으로 확대하지 않았고, 채택 0·새 제출 0 및 원9회 정확 재현/전체 예측 인과검사 미해결을 명시한 것도 적절하다.

**판정:** 두 문서의 주요 관찰→가설→허용 구현→타깃 효용 구분은 근거에 부합한다. 전문가에게 일사량 주장을 귀속한 한 문장을 새 버전에서 수정할 필요가 있다. 이 비평은 문서 연결 검토이며 N4 최종 수치·문장 비평, 전체 원모델 재현, 물리 인과 검증을 대신하지 않는다.
