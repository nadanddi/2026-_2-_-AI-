# 온도 모델 품질 보완·CO₂ 잔차 진단 계획

사용자가 중지된 온도 개선을 재개했다. 공식 대회 입력과 sub_temp만 사용한다. EC 수치·대회외 자료는 로드하지 않는다. 원 제출/재현 소스는 보존하며 새 코드는 연구실 코덱스에 둔다.

## 기존 발견과 변경 이유
- 정확 재현은 6.474의 6자리 불일치 상태 유지. 현재 환경에서 기준/후보를 함께 재학습하며 원 제출과 동일하다고 하지 않는다.
- 가중치 교집합 .04를 실제 집계하고, CV에서는 제외된 날이 가중치 rank/EWMA에 들어가지 않도록 학습 원입력만 사용한다. 계절도 fold 훈련 날씨만 fit한다. 이 보완은 후보와 기준 모두에 적용한다.
- TX1(6.459)의 날 제거/가중치 완화 기각을 반복하지 않는다. CO₂ 거칠기 관측은 센서 오류 원인·온도 개선의 증거가 아니다.
- N1 후보 두 개를 한 번만 진단한다: DROP5 = CODEX 잔차 입력의 in_co2/current,h0,mean,std,diff 다섯 열 제거; MED3 = 같은 날 과거 포함 3개 시간의 CO₂ 중앙값으로 이 다섯 열만 재생성. 물리 Ridge 19열은 CO₂가 없어 유지. 구동기 act_co2와 BASE/PFN은 변경하지 않는다. MED3은 현재/과거만이며 당일 reset, min_periods=1, 미래 보간 없음.

## 품질 검사
- 원 패키지 build_frames의 MASK 학습 특징/가중치: 평가 원입력 전부 변조해 불변 확인. 같은 온실 미래 두 cut, 다른 온실 전체 변조로 현재·이전 query 특징 불변 확인(원 BASE135+물리+CODEX89 포함). 모델 예측 규정 전체 검사와는 구분한다.
- 후보 MED3 특징에 대해 동일 교란과 행순서 셔플 검사. fold-local weights의 제외일 변조 불변 및 원 가중치 빈도 저장.
- 원 데이터 SHA/원 패키지 SHA를 전후 비교. sub_temp만 읽고 harness용 sub_ec 열은 NaN 생성.

## 실행 및 판단
1. 계획 비평 뒤 무학습 품질 검사. 첫 결과에서 중간 비평 후 전체 실행.
2. CODEX의 물리 Ridge + LGB 잔차 구성원만 재학습해 진단. 원 DIAG10/EXT10/EXT12, 같은 fold의 기준/후보, fold-local 가중치·계절. 원 LGB는 결정적이므로 시드 차이가 독립 증거라고 주장하지 않는다. 고정 seed 9109 한 번, 두 후보 k=2, farm×floor(day/5) 블록 20,000회 RNG=20261009.
3. 이 단계는 비용을 제한한 구성원 진단이며 W40G-S 전체 개선 검증이 아니다. 모든 검증기 구성원 RMSE 방향 개선 및 DIAG bootstrap p_worse<.0125, CI 97.5% 상단<0일 때만 전체 혼합/새 BASE 시드+PFN 문맥 검증으로 진행한다. 미달 후보는 이번 진단에서 보류하고 전체 개선/효과 없음을 확정하지 않는다. 실패 후 새 임계값·추가 후보 튜닝 금지.
4. 전체 검증에 진입하면 사전 별도 등록 및 비평을 받고 DIAG10/EXT10/EXT12 모든 새 시드 방향 + DIAG p<.025/k 기준으로 판정한다. 현재 단계만으로 채택하지 않는다.
5. 농장×전후반·시간대·day-level 오차 진단과 독립 산술/최종 비평. 신규 제출 CSV/ZIP·공식 평가 예측 생성 없음.

이번 turn의 완료 범위는 검증 경계를 갖춘 새 연구 코드, 실행된 품질 검사, 두 후보의 구성원 진단 및 전체 검증 진행 여부다. 성능 개선을 약속하지 않는다.

## 계획 비평 반영
- MED3은 같은 온실·기록일의 실제 시각 h-2,h-1,h 3칸이다. 누락 시각은 NaN 격자로 채운다. 관측 직전 3행으로 대체하지 않는다.
- 매 fold 검증일 및 purge일을 포함한 훈련 외 입력을 NaN으로 바꾼 CODEX/MED3 세계를 재생성해 훈련행 특징이 query FULL 세계의 같은 학습행과 정확히 같음을 assert한다. CODEX의 당일 reset과 whole-day 제외가 안전한지 실제 검사한다. BASE 재학습은 이번 구성원 진단 범위 밖이며 향후 full 모델에서는 별도로 fold-MASK 세계를 구성한다. 기존 all-world BASE 특징을 그대로 CV에 사용하지 않는다.
