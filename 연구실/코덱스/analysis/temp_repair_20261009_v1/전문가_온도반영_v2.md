## 모델 구조에 대한 구체 제안

큰 수준 차이를 삭제하거나 공기온도로 강제 수축시키기보다, 현재 물리 Ridge + 잔차 + PFN 구조에서 **느린 열 반응을 유지하고 현재 입력으로 설명 가능한 상호작용을 보완**하는 쪽을 우선한다. 현재 CODEX 물리열은 실내/외기·일사·난방과각1/3/8시간 필터를 이미 포함한다. BASE에도 유효일사·커튼 항이 존재하므로 새 모델 전체의 새 지식이라고 부르면 안 된다.

다음 독립 후보는 CODEX 잔차에만 `out_rad * act_shade/100 * act_thermal/100`와 당일1/3/8시간 EWMA를 추가하는 좁은 변경이다. 이 식은 기존 BASE의 입력 정의를 옮긴 대리변수이며 전문가가 보장한 물리식이 아니다. 커튼 방향 해석·missing 처리·mask/현재과거경계, 기존 동일 구현 기각 이력을 먼저 확인하고 별도 사전 등록/다중비교/비평 후 실행한다. 흰색 멀칭 효과를 고정 계수로 가정하지 않는다.

이번 고정 CO₂ 구성원 진단의 후보·threshold·판정은 바꾸지 않는다. 전문가 의견은 현재 해석을 갱신하는 자료이며 대회 데이터의 OOF 성능 증거를 대체하지 않는다. 전문가가 언급한 과거 해커톤 자료는 열거나 모델에 쓰지 않았다.

## 원 질문·비평 추가 반영
- 질문지의 '공기보다 평균 약0.8도 낮고 따라간다'는 질문자가 제시한 관측 설명이다. 전문가가 모든 온실에 보장한 관계가 아니므로 모델을 일괄 -0.8도로 보정하지 않는다.
- 물탱크가 온실 안에 있다는 답변은 관수 수온이 현재 공기온도와 같다는 뜻이 아니다.
