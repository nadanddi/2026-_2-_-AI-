# 중간 품질 비평 반영

- 계획 v1에 불명확했던 MED3 시간창을 v2에서 h-2..h 격자로 고정했다.
- audit_v1은 매일 h>cut을 모두 변조해 다음 날의 허용된 과거도 바꾸는 검사 정의 오류가 있었다. 독립 비평가가 지적했고 해당 실행(session19973)은 fit 없이 중단했다. PASS/FAIL 결과를 내지 않았다.
- audit_v2는 같은 온실 전체 시간축 t=day*24+hour의 단일 절단점 뒤만 변조하고 절단점 이전의 모든 평가행을 비교한다. 이전 평가일의 입력을 정상적으로 사용할 수 있는 BASE 연속 이력과 충돌하지 않는다.
- run_v2는 새 후보를 추가하지 않고 run_v1에 cache NPZ SHA 및 query row_id 메타데이터 대조를 보완했다. 모델 fit 전 새 실행 소스 해시를 등록한다.
- 원 모델 소스는 고치지 않았다. 원 모델의 규정 위반이 발견된 것이 아니라 새 검사 구현의 오류를 고친 것이다.
