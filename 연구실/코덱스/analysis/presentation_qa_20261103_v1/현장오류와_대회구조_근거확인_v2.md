# 현장 오류 복원과 대회 자료 구조 의존의 구분 — 근거 확인 v2

2026-11-03 연구실 코덱스. v2는 v1의 PCH4 카탈로그 번호를 6.983으로 정정한 최종 확인본이다. 질문: 대회 자료의 제약 때문에 생긴 복원 작업을 대회 규칙성 이용과 혼동하지 않았는가? 같은 물리 동의 로그가 ID 사이에 섞인 것으로 볼 근거와, 현장 대응 가능성은 어느 수준인가?

## 1. 확인 결과

**날짜·동 식별자가 부족하거나 불일치하는 자료를 복원하는 것 자체를 현장 적용성이 낮다는 근거로 삼을 수 없다.** 실제 측정 대상의 이력·측정 시각·전날 상태는 현장 대응물이 있다. 특히 상대 일차 순 이력, 전날 실측 앵커, 전날 예측 사슬을 일괄적으로 대회 특성 이용이라고 평가한 앞선 설명은 과했다.

다만 다음 세 문장은 증거 수준이 다르다.

1. **확인 사실:** 서로 다른 ID의 기록 사이에서 온도·EC·외기 연속성이 동시에 성립하는 고확신 연결이 있다. 원본 CSV로 190쌍 중 40쌍(21.05%)을 재현했다.
2. **타당한 해석:** 같은 물리 동의 기록이 여러 ID에 분산됐거나 식별 정보가 혼합됐다는 설명과 부합한다. 센서값을 이용한 이력 복원의 필요성을 지지한다.
3. **미확인:** 실제 원천 동 ID, 수집 시스템 변경 이력, 운영위의 가공 이력이 없으므로 이번 자료가 현장의 센서 매핑 오류 때문에 이렇게 됐다는 원인은 확정할 수 없다. 그 현상이 온실 현장에서 흔하다는 발생 빈도도 확인하지 않았다.

따라서 현재 가장 강하게 말할 수 있는 것은 **“제공된 ID만으로 설명되지 않는 기록 간 연속성을 확인하고, 관측 연속성으로 과거 이력을 복원했다. 이 복원 정보는 현장의 날짜·동 식별자·최근 센서값에 대응한다”**이다. 실제 오류 원인을 확정하거나, 다른 물리 동의 상태를 같은 동처럼 전용해도 된다는 뜻은 아니다.

**중요한 추가 한계:** 코드 머리말과 setup에서 날짜 CAL을 전체 정답 보유 날의 외기로 한 번 복원해 알려진 날짜처럼 고정한다. 따라서 ‘실제 달력을 정확히 안다는 조건’의 근거이지, 날짜가 망가진 현장에서도 미래 관측 없이 온라인으로 날짜 복원까지 성공했다는 증거는 아니다. 이 실험은 최종 HR5·앵커 포함 전체 구성도 아니다.

## 6. 실제 시스템 오류와 대응한다는 외부 근거

1. **시각 오류·중복·누락은 제조사가 직접 설명하는 실제 데이터로거 문제다.** Campbell Scientific LoggerNet 매뉴얼은 시계 조정으로 시각이 건너뛰거나, 서로 다른 값에 중복 시각이 붙거나, 계산된 과거 시각이 틀릴 수 있다고 설명한다. 따라서 시간 순서·정렬 복원은 단지 대회에서만 존재하는 문제가 아니다. 다만 이는 ‘여러 온실 ID가 뒤섞이는 현상이 실제로 발생했다’는 사례 증거는 아니다. [Setting the Clock](https://help.campbellsci.com/loggernet-manual/ln_manual/setting_the_clock.htm)
2. **센서·측정 대상·측정 시각은 서로 다른 정보다.** OGC SensorThings 1.1의 8.2.4·8.2.7·8.2.8절은 Datastream과 Sensor·Thing, Observation의 phenomenonTime·FeatureOfInterest 등을 구분한다. 따라서 CSV의 ID와 실제 물리 측정 대상이 같은지 확인해야 한다는 구분은 타당하다. 표준 자체가 현장 ID 오매핑의 발생 빈도나 이번 자료의 원인을 증명하지는 않는다. [OGC SensorThings API Part 1: Sensing 1.1](https://docs.ogc.org/is/18-088/18-088.html)

**이번 확인에서 확보하지 못한 외부 근거:** 실제 온실의 동 A 로그가 동 B 식별자로 잘못 저장된 것을 장비 이력과 대조해 입증한 구체적인 현장 사례. 그러므로 ‘그런 오류로 설명 가능한 시스템 구조’와 ‘이번 현상의 실제 발생 원인 확인’을 구분한다. 원문 접근이 실패한 관련 논문은 확정 근거로 사용하지 않았다.

### 외기 그룹 수에 대한 주의

원자료에서 24시간×4 외기 값을 소수 1자리까지 완전히 같은 것으로 묶으면 159개 그룹, 모든 셀의 70% 초과 일치(차이 <1e−6) 연결요소로 묶으면 126개 그룹이 나왔다. 기존 카탈로그 6.407의 128은 그 분석의 별도 판정 결과이며 이번 두 정의로는 동일하게 재현되지 않는다. 따라서 ‘정확히 128개의 실제 날짜·4개 실제 동으로 이루어졌다’를 확정 사실로 삼지 않는다. 부분 변형·결측·그룹 기준에 따라 수가 바뀐다. **날짜 그룹은 실제 날짜 확인값이 아니라 데이터 유사성에 따른 추정이라는 점이 핵심**이다. 결과는 [weather_groups_recomputed_v1.json](C:/work/farmai/연구실/코덱스/analysis/presentation_qa_20261103_v1/weather_groups_recomputed_v1.json)에 보관했다. 모든 기록을 함께 쓴 이 집계는 사후 서술용이며 평가 특징 생성·모델 선택에는 사용하지 않았다.

## 8. 5점 해석과 다음에 필요한 확인

정형의 ‘복원이 필요하다’는 사실만으로 2점 상한을 정할 근거는 없다. 대응하는 현장 정보와 사슬 일반성 근거가 있어 5점을 논의할 논리적 경로는 유지된다. 반면 이번 확인으로 최종 전체 구성의 현장 성능이나 5점 획득이 확정된 것은 아니다. 10-12 세부 배점 원본은 이번에도 확보하지 못했으며 배점 판단은 기록된 기준을 참고한 해석이다.

적절한 비교는 다음을 따로 측정하는 것이다.

1. **식별 정보가 정상인 조건:** 알려진 날짜·동의 전날 정보로 같은 예측 코어를 실행.
2. **식별 정보가 훼손된 조건:** 허용된 과거·현재 관측만으로 복원한 전날 정보로 실행.
3. **과거 목표 센서 정보 자체가 없는 조건:** 앵커 없이, 온도 사슬의 연속 결측 길이까지 구분해 실행.

1 대 2가 복원 오류의 손해, 1 대 3이 과거 상태 정보의 가치다. 현장에서는 날짜·동이 주어진다는 이유로 링커만 필요 없어지는 것이지, 전날 상태 정보까지 사라져야 하는 것은 아니다. 정답 연속성으로 확인한 표를 1의 참고 기준으로 쓸 때는 진단용 오라클임을 밝히고, 선택 편향·검증 정답 사용 범위를 통제해야 한다. 이번에는 이 새 비교 실험을 실행하지 않았다.

이번 작업은 문서·코드 확인, 원본 CSV의 연결 집계 재현, 저장 PCH4 표 집계만 수행했다. 발표자료·제출 모델·기존 질문예상 문서는 수정하지 않았다. EC 단위와 외기 그룹 수에 대한 추가 확인·정정은 이 새 파일에 보존한다.
