# 발견 연결 절차·현재해석표 수정 확인 v2

2026-10-08 · 연구실 · 코덱스 · 독립 검토자

검토 대상: `PROCESS_v3.md`, `현재해석_v3.md`. 이전 `REVIEW_v1.md`의 지적 반영 여부만 확인했다. 신규 fit 0, 정답 재채점 0, 다른 폴더 변경 0. 원 숫자의 독립 재계산과 다른 주제 전수 검토는 수행하지 않았다.

| 이전 지적 | 최신 문서 확인 | 판정 |
|---|---|---|
| EC-C04의 6.429 FC3 누락 | 6.429를 연결하고 후보·묶음 평균·표준화 가림, h23 RMSE .113 대 SG2 .088을 명시. 실패를 미래시각만으로 설명하지 않고 가림 범위 차이를 반영 | 닫힘 |
| 하루 전체 입력 금지의 시각 조건 부족 | h23에서 해당 날 0~23시 입력 자체는 허용됨을 명시. 이른 시각의 미래창과 다른 평가 기록 제한을 구분 | 닫힘 |
| 6.251을 단일 예측분산 실패로 축약 | 나무별 예측 분포·문턱 확률·분위수 진단으로 정밀화. 실제 잎의 학습일 기여·혼합·집중도는 별개이며 전체 효용 미검증 유지 | 닫힘 |
| 6.205 직접 정정 인용 | EC-C02에 C6.205와 6.207 직접 정정을 명시. PROCESS에서 6.421은 다른 번호 충돌의 대응표라고 구분 | 닫힘 |
| 가까운 번호만 검색하여 후속 정정 누락할 위험 | PROCESS 시작 절차에 실험명·핵심 주장으로 후속 검산/정정/기각을 끝까지 찾아 연결하도록 추가 | 닫힘 |

**판정:** REVIEW_v1의 필수 보완과 용어 정밀화가 반영되어 이번 절차·현재해석표 문서 검토는 완료한다. 이는 새 성능 증거, 모델 채택, 전체 카탈로그 검토 완료를 의미하지 않는다.

현재 EC14와 RW1 근사 R3의 구분, 미실행 지원진단의 표시, 기존 파일 보존, 별도 실행 승인·제출 기준을 추가하지 않는 원칙은 유지되어 있다. 메모리/HANDOFF 링크의 최종 연결 확인은 root의 별도 작업이다.

기존 `document_claim_audit_20261008_v1`의 보고서 최종문장 및 RW1 후속 독립 비평은 이번 검토 대상이 아니므로 **미완료 상태를 그대로 유지**한다. 현재해석표도 이를 명시한다.
