# 현재 EC14 ET의 자정 CO₂·난방 두 열 제외 진단

2026-10-07 연구실 코덱스. 사용자의 ‘다음 진행해’로 이전 보고서에서 제안한 좁은 대조를 실행한다. 자정10열 전체 제거와 모든 자정값의 변화량 교체는 기존 기각안이고 이번은 두 열만 함께 제외하는 다른 설정이다.

## 질문과 고정한 비교

현재 EC14에서 ET가 in_co2_h0와 act_heating_h0 두 열을 직접 사용하지 못하면 일반날의 높은 EC 지원 혼동이 줄어드는가? 실제 높은 EC 날짜에 필요한 정보도 함께 잃는가?

- 단일 arm TWO_H0_DROP: 현재 ET47열 중 위 두 열만 제외해45열로 재학습. 단독 열별 삭제안·새 특징·새 문턱·데이터 삭제는 추가하지 않는다. 남은 열의 순서는 유지한다.
- 학습 자료/정답/분할/시드/ET설정/계절 변환은 기준과 같다. R3의 LGB·MLP·PFN 예측과 SG2 학습 통계·정답 참조·bounds는 모두 기준에서 고정한다. 실제 raw3시드 평균 후 후처리 순서도 유지한다.
- 기준은 ec_current14_influence_20261007_v1의 완료·독립 감사된 현재 EC14 공개 검증. 기존30 R3캐시와40 PFN문맥을 ID/실수hash/RNG/SHA 검사 후 재사용한다. 새 학습은 ET30회이며 다른 모델 신규fit0이다.
- 공개 DIAG10 10fold×3seed(7/101/2024), 360고유날·8640시간행과 실제 ensemble을 평가한다. 원 train_y/test_X/EL1/잠금 정답은 새로 읽지 않는다. 이전 공개 y만 사용한다.

## 결과 전에 고정한 진단과 분모

- 선택 F47_161의 **후처리 전 raw ET24시간 평균 편향 절대값이 세 시드 모두 감소**하는지 판정한다. 감소와 관계없이 세 시드 편향>0.20 여부도 보고한다. 선택 사례이므로 개선의 독립 일반화 증거로 부르지 않는다.
- 전체360/일반329/고EC31/일반 폐쇄61·나머지268/폐쇄×팬낮음50/공개pass2 46/각농장/선택161 제외359/일반161 제외328일을 모두 보고한다. 대표F47_160·161/F13_98·112 및 모든날 손익도 보존한다.
- 기준·변경의 raw ET→raw혼합→평활→clip→SG2→clip을 보존한다. SG2 후보 선택은 입력/ref가 고정돼 같아야 하고 gate 변화와 상호작용·양clip 활성수를 별도 감사한다.
- fold1 seed7 F47_161의 변경 forest전체/훈련-query배열/정답/leaf/weight를 저장한다. 기준은 이전에 보존한 동일fold/seed forest를 재사용한다. raw0h/rawday/평활day의 고EC 학습날 지원과 top날을 비교한다. 나머지시드의 상세 지원까지 추적했다고 표현하지 않는다.
- 모든 시드 DIAG10 전체 RMSE감소 여부와 실제 ensemble의 paired block-bootstrap을 보고한다. block=농장+기록일차//5,20,000회, RNG32617, 95%구간·p_worse는부트스트랩RMSE변화≥0 비율. 실제rawensemble 경로를 사용하고 시드별최종값 평균으로 대신하지 않는다. 반복공개검증·학습집합 중첩·블록정의 한계는 명시한다.
- 모든시드 전체개선과ensemble p_worse<0.025가 함께 나오면 같은설정의A/B확장검증 대상이라고만 기록한다. 개선모델 채택은 DIAG10/A/B 모든시드 같은방향과사용자유의규칙이필요하며, 공개pass2≥2%악화시보호조건검토가필요하다. 이번진단 자체로채택/제출은없다. 조건미충족시A/B 추가학습없이결과·비평을정리한다.
