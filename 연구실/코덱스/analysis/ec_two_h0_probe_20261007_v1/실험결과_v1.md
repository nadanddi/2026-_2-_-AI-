# 현재 EC14에서 자정 CO₂·난방 두 열 제외 진단

2026-10-07 연구실 코덱스. 학습·전수 채점·트리 산술감사·독립 수치 검산은 완료됐다. 최종 혹독비평 문서는 정리 중인 초안이다.

**두 열을 빼면 F47_161의 과대예측은 줄지만, 다른 일반날과 실제 고EC 날을 더 못 맞힌다. 이번 삭제 설정은 기각하며 기존 EC14를 유지한다.** 이 결과는 두 자정 특징이 전체적으로 쓸모없다는 가설을 지지하지 않는다. 특정 사례의 실패를 만든 학습 표현과 여러 날에서 유효한 정보가 함께 있다는 쪽으로 다음 진단을 좁힌다.

## 비교와 범위

사전 main7f13d0e 등록 후 단일 TWO_H0_DROP을 실행했다. ET47열에서 in_co2_h0·act_heating_h0 두 열만 제외해45열로 학습했다. 다른 입력의 값·순서, 학습 자료·시드·ET설정·계절 변환은 유지했다. LGB·MLP·PFN 출력과 SG2 학습 통계·정답 참조·bounds도 고정했다.

공개 DIAG10 10fold×3seed(7·101·2024) ET30개를 신규 학습했다. 기준30 R3캐시와 PFN40문맥을 서명/ID/실수hash/RNG 검증 후 재사용했다. 다른 모델 신규fit0이고, 원 train_y/test_X/EL1/잠금 정답은 새로 읽지 않았다. 이전 공개 정답360날/8640시간행만 평가했다. 세 시드별 예측과 실제raw평균후후처리ensemble을 별도로 계산했다.

공개 후반기(pass2)는46일이다. 실제 평가60일의 효과나 제출 바이트 재현이 아니다. 두 열의 공동 제외 효과를 보는 진단이며 각 열의 독립 영향과 물리적인 EC 발생 원인은 식별하지 않는다. 열 수가 바뀌면 forest의 무작위 구축·분기·잎 전체도 달라진다.

## 고정 재표집과 판정

실제 ensemble 기준, 농장별 층화·복원 재표집으로 기록일차//5 블록을20,000회 뽑았다. 각 농장 안에서 관측블록수와 같은 개수를 표집하고 기준·변경에 같은 표집을 적용했다. RNG32617이다. 반복별행수가 달라질 수 있어 SSE/행수로 RMSE를 계산했다.

- 변경RMSE가 기준 이상인 반복:19,287/20,000, p_worse=0.96435.
- RMSE 변화율95% percentile구간:[−0.423775%, +9.862782%].
- 세 시드 전체개선 AND ensemble p_worse<.025인 사전 DIAG 확장screen은 미충족이다.
- 공개pass2≥2%악화 보호flag는 충족해 채택보류 상태다. screen실패이므로 A/B확장 신규학습은0이다. 새모델채택·제출0, 기존EC14 유지다.

95%구간에0이 포함되므로 ‘양측95% 유의한 악화’라고 표현하지 않는다. 점추정의 전시드 악화와 사전 개선screen 실패를 근거로 이번 설정을 기각한다. 공개검증을 반복 사용한 조건부 진단이고, 모델 학습집합의 중첩이나 블록경계 안의 모든 의존성까지 통제한 독립 시험은 아니다.

## 입력 관계와 해석의 경계

0시 raw 현재 CO₂와 CO₂_h0는397일에서 관측값이 같고3일은 둘 다 NaN이었다. 난방은400일 모두 관측값이 같았다. 1시에는 남아 있는현재난방·누적평균으로 자정난방=2×누적평균−현재난방을 복원할 수 있었다. 이는 train_X400일 입력만 확인한 항등식이며 정답을 읽거나 예측동등성을 검증한 결과가 아니다.

둘 다 CO₂ 결측인 경우 기준 모델의 현재CO₂ 미디언과 자정CO₂ 미디언이 다를 수 있다. 이번fold에서 현재미디언403~408과자정410~416으로 차이가 있었다. 따라서 raw동일식을 ‘실제모델입력까지400일모두같음’으로 확대하지 않는다. 선택161의0시CO₂480·난방0은 관측값이다. 이 입력점검으로 결측이161 실패원인이라고 결론내리지 않는다.

현재값·누적값·DP1에 관련정보가남는다. 이번은두열의직접사용을막은학습표현대조이지 자정정보완전제거가아니다. 두열이161의오차에미치는순수고정forest기여,각각의독립원인,난방/CO₂의물리EC효과는식별하지않았다.

## 작업 안에서 보완한 검증과 다음 방향

결과전에농장층화복원·block수·가변행수분모·실제rawensemble·bootstrap percent구간/RNG·DIAGscreen과pass2 보호flag관계를명확히했다. 실제45열hash와기준47열의투영, retained median, strict기준캐시읽기,서명·ID·원본SG2·지원·재표집을검산했다. 검토자의초기‘400일CO₂모두관측’가정실패는파일/로그를보존하고관측397·양NaN3으로검사를수정했다. 모델worker·데이터·문턱은변경하지않았다.

다음은추가특징삭제나두열각각의무작정반복보다 **기준모델을고정해161일과다른일반실패/성공사례의지원선택차이를비교하는진단**이우선이다. 예를들어161이개선된반면231·233·130이악화한입력조합에서,자정수준과이후허용prefix 운영/센서가일치하는지확인한다. 이를통해자정값을버리지않고신뢰성·상태구분을개선할단서를찾는다. 이방향은아직미실행가설이며새규칙은학습전에고정해야한다. 입력정보가충분하다거나신뢰도보정이효과있다는결론은아니다.

이번결과로확인된것은 ‘두자정열의공동제외는선택한과대예측을낮추지만일반/고EC양쪽의더큰손실을만든다’는점이다. 전체61/268 격차의유일한원인이나 EC의물리발생원인은여전히확인하지않았다.
