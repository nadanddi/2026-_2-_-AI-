# 학습 사례 추적의 검토 피드백과 보완

2026-10-07 연구실 코덱스. 모델설정·학습사례·보정계수를 변경하지 않았다.

- 실제 모델의 float32 입력으로 경로를 추적했다. 초기표시 평균의결측0대체를 imputer 적용값과결측지원가중치로구분한v2를만들었다.
- 첫분기의부모지원EC평균/고EC가중비중/지원날수를 추가했다. 자식집합평균과최종잎예측을같은기여도로보지않았다.
- 원준비경로가버전치환으로잘못바뀐v3를보존하고v4로보완했다. v4준비PASS→main78da2e5→6ET재현 순서다. 재학습은총6회이며실패버전은fit0이다.
- 사례표v1의Windows cp949 기본읽기 오류를보존하고v2의UTF-8명시로보완했다. v3에는 F13실패일의실제최대지원인타온실F47_112를추가했다. 저장된배열만읽었고 모델학습은0이다.
- 보고서v2에서는59.67%가 행 개수비율이아닌 **고EC시간행의지원가중치비중**임을명확히했다. 고EC학습날가중치77.83%와도구분했다.
- 원fold0/1의다른학습집합과공통학습통제,0시와평활하루평균,한seed의편향분해와전체RMSE,함수기여와물리인과를나눠설명했다.
- 다른온실지원이성공사례에도있다는반례를남겼다. 온실식별자추가나훈련날삭제의개선효과는미검증이다.
- 독립검산자는3600트리의전체경로·노드평균을재구성했고가중치Shapley를120개변화순서로재계산했다. 감사코드v1괄호오타의SyntaxError는원파일을보존하고v2로고쳤으며원모델의오류와구분한다.

새개선모델은만들지않았다. 이번근거로확인한것은실제입력→학습지원→ET예측→최종편향의연결이다. 선행모델의오차가왜반복되는지나물리적EC상태는별도고정설계로조사해야한다.
