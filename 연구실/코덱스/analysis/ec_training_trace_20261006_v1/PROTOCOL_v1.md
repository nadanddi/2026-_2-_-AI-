# ET 학습 사례 역추적

2026-10-06 연구실 코덱스. 사용자 “추적해봐” 요청에 따른 진단이다. 기존실험 결과와 모델을 수정하지 않는다. 체계적 원인추적 및 독립 혹독비평 절차를 적용한다.

## 질문
초기 CO₂·난방·계절 차이가 실제 ET의 어떤 학습 행/날/온실과 연결되어 F47_161 및 F13_112의 점수를 올렸는가? 학습에서 선택된 높은 정답과 목표날의 낮은 정답을 연결해 예측오류를 산술적으로 설명한다. 입력 유사도 이웃 대신 실제 잎의 지원행을 사용한다.

## 고정 범위
- 앞선 실제 계절v2의 동일학습 준비자료를 읽기전용 재사용. 공개360일 OOF 정답과 원train_X만 사용. 원train_y/test_X/EL1/잠금정답은 새로 읽지 않는다. 최신EC14 효과·모델개선·제출판정이 아니다.
- ET600개씩 총6회재현: common_intersection seed7/101/2024, trainfold1_purged seed7, 실제 원fold0 seed7의 heldout F47_160/F13_112, 실제 원fold1 seed7의 heldout F47_161. 원래학습했던날을 외부검증처럼 비교하지 않는다.
- 학습행순서/특징/정답/seed/ET설정은 기존과 동일. 각모델 재예측과 원캐시 raw_et 차이≤1e−10을 먼저검사한다. bootstrap=False·가중치없음을 확인한다.
- 각query행의 예측을 실제tree잎에속한 학습정답의 평균600개로재현한다. 훈련행가중치 `w_i=sum_t 1(i∈leaf_t)/(600*n_leaf_t)`, sum(w)=1, raw_ET=sum(w*y)를 확인한다. 실제leaf/행가중치·전체tree배열·변환된훈련/query 입력·IDs/y를내local에보존한다.
- 시간별/하루평균 지원날·온실·고EC시간행(y≥1)·고EC날(y_day≥1) 비중과 top날을 구분한다. 잘못맞춘날과성공날의 signed weight 및정답기여차도저장한다. 시드·tree반복을독립사건으로세지않는다.
- 공통seed7의두쌍0시에는 기존과동일한5입력가족/32인공조합을 재생성한다. 예측Shapley뿐아니라 **훈련행가중치 Shapley**를 계산해 CO₂/난방/계절 반응을 실제훈련날의 signed contribution에연결한다. 가중치합변화0, 훈련정답내적=기존exact Shapley를검증한다. raw기여와훈련정답평균을뺀centered기여를둘다보고한다.
- 실제첫공통분기에서 parent/좋은날child/실패날child의훈련n·EC평균·고EC비중/입력threshold를검사한다. tree노드평균과훈련정답평균의정합성을검산한다. 첫분기귀속표를인과기여로해석하지않는다.
- 추가삭제재학습/계수탐색/모델채택은하지않는다. 결과에의한새가설은 별도등록한다.

## 해석과 감사
선택된학습정답이예측을올린 계산경로는 식별할수있다. 물리적EC원인, 모든모델/PFN의학습메커니즘, 운영정보부재, 현평가구간개선은 이번증거만으로확정하지않는다. 독립검토자가 fulltree·훈련/query 입력에서경로/잎/지원행을재구성하고예측합·프로필·기여도·문안을검산한다. 결과코드·분할·지원분모·설명범위를 사전에 고정한다.
