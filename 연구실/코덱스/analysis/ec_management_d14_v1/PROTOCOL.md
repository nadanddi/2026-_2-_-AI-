# D14 새 하루 관리 대리 입력의 추가 정보 진단

2026-09-30 연구실 코덱스. 4번 EC 기작·측정 정의 조사 후, 5번의 첫 진단이다. 실행 전에 이 문서와 코드 main 커밋.

## 질문과 고정 입력
기존 H20은 절대습도 격차·환기×격차 누적·밀폐 공기 수증기 증가만 시험했다. 이번에는 0~6시까지의 (1) 밀폐 공기 수증기 감소, (2) 팬 가동×VPD 노출, (3) 고습 냉각 노출, (4) 난방 가동×VPD 노출 네 요약의 추가 정보를 확인한다. 이들은 관수량·응결량·뿌리 흡수량의 측정값이 아니다.

- closed_sink: 전/현재 천창=0, 전/현재 포그=0일 때 max(AH전−AH현재,0) 합. 습공기 비체적/압력·침기·수증기 농도 센서 오차 미측정이므로 실제 수분수지로 부르지 않는다.
- fan_vpd: VPD×clip(팬,0,100)/100 합.
- saturation_cooling: 전시각 RH≥95일 때 max(T전−T현재,0) 합. 95는 자료를 보고 고르지 않는 근포화 노출 경계. 잎/피복 온도가 없어 실제 결로 확정 불가.
- heat_vpd: VPD×clip(난방,0,100)/100 합. act_heating은 복합 최대 지표이며 열량이 아니다.

합은 0~6시 입력이 완전한 해당 물리 항에만 계산하며 결측 있는 항은 NaN 유지. 당일 재시작, 다른 날짜/온실·미래 입력·정답 사용 금지. test_X 미사용, 최종 잠금 파일/그 날짜 채점 금지. 데이터는 이미 공개 채점한 234일만의 train_X와 OOF.

## 교란 통제와 판정
잔차 = 실제 일평균EC − 6시 v2. 기본 통제: 농장·day·후반(day≥179)·6시 v2와 제곱, 0/6시 raw10 입력, 0~6시 구동기7 평균, 실내3 평균/std, H20 3특징, 실내3 차분 MAD 거칠기(각 채널 |Δ²x| 평균), 실내3 비결측 비율. 기존 신호/입력/잡음과 구별되는 선형 추가 정보만 평가한다. 결측은 진단 내 농장 중앙값으로 채우고 결측률·rank·조건수를 보고한다. 이는 제출 모델 전처리가 아니다.

네 partial-r, 농장별 r, 한 폴드씩 제외 r, 통제 잔차 절댓값 상위5일 제외 r, 고EC(일평균≥1.2) 제외 r를 **모두** 계산한다. 상대일차는 물리 달력임이 보장되지 않으므로 계절 통제의 근사에 불과하다.

농장×폴드 층화 잔차 순열 10,000회 seed=300914. nuisance projection 후 순열된 잔차도 재투영(Freedman-Lane 형태)하고 4신호 최대 |r|로 다중비교 통제. finite sample exchangeability는 가정이며 독립 확증 아님.

새 모델 캠페인을 검토할 진단 기준: p_max<.01, 두 농장 같은 방향·각 |r|≥.15, 6 leave-fold-out 방향 동일, 상위5일 제외/고EC일 제외 방향 동일·각 |r|≥.10. 농장별 complete-case n≥80. 이 기준을 통과해도 모델 채택 아님. 모델 채택은 별도 A/B/DIAG10×시드·EXT10/12·새 시드·인과/결정성·잠금 확증 필요. 실패해도 물리 기작의 부재/전체 계열 불가능으로 부르지 않는다.

입력 인과성: 함수에 6시 이후 행을 교란하거나 모두 삭제한 결과의 0~6시 네 특징이 같아야 한다. 폴드·다중비교 결과로 정의나 threshold 변경하지 않는다. 저장은 연구실/코덱스/local/ec_management_d14_v1/<KST시각>/.
