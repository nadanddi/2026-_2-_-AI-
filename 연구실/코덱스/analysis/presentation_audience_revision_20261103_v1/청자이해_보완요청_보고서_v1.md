## 1. 핵심 진단

내부 명칭을 설명하기 전에 사용하고, 자료·지표·실험 조건이 달라지는 지점의 연결 설명이 부족하다. 심사용 노트에 설명이 있어도 발표자가 읽는 대본에 없으면 일반 청자에게 전달되지 않는다. 화면 문구를 늘리기보다 내부 약어를 기능 중심 표현으로 바꾸고, 대본에서 첫 등장 시 뜻을 풀어 설명할 것을 요청한다.

## 4. 대본에 넣을 설명 예시

“검증 사진 묶음 1·2·3은 사진 자체를 학습에 넣지 않은 세 묶음입니다. 다만 모델 선택에 사용했고 농장·촬영 묶음은 학습과 겹칩니다. 따라서 새 농장 성능을 뜻하지는 않습니다.”

### 전날 정보와 오류 복원

“대회 자료에는 실제 날짜와 온실 세부 정보가 제공되지 않았습니다. 기록 간 연속성으로 같은 동의 과거 이력을 복원했습니다. 현장에서는 날짜와 동 식별자가 정상적으로 관리되면 이 정보를 직접 확보할 수 있습니다. 전날 상태를 사용하는 예측 원리와 그 기록을 복원하는 절차는 구분해야 합니다.”

### 그래프 읽는 법

“왼쪽은 원본 대조와 저장 형식 조건을 끈 뒤의 균형 정확도로 높을수록 좋습니다. 오른쪽은 제출 모델이 처리한 진짜 사진을 가짜로 본 비율로 낮을수록 좋습니다. 서로 다른 조건의 비교입니다.”
