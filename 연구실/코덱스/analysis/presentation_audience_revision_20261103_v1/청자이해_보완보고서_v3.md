# 청자 이해 관점 보완 보고서 및 수정 내역 v3

2026-11-03 연구실 코덱스. 대상: **G05v4 원본 33장과 노트**, 발표자 안내서 v4. 본문 1~16장은 실제 PowerPoint 렌더 이미지와 [말할 것]을 함께 검토했다. 부록 17~33장은 용어·근거 연결을 확인하고 최종 렌더 검사에 포함했다.

사용자의 추가 요청에 따라 보고서만 작성하는 범위에서 **새 PPTX와 발표 대본까지 수정하는 범위**로 확대했다. 클로드 폴더의 원본·생성기는 수정하지 않았다. 기존 디자인·33장 구성·표·편집 가능한 차트를 유지한 새 사본이다. 기존 분석 Q01은 보존하고 이 보고서를 Q02로 구분한다.

## 1. 진단

핵심 문제는 자료가 적다는 것보다 **내부 명칭을 정의하기 전에 사용하고, 서로 다른 자료·지표·실험을 같은 흐름에서 설명해 청자가 관계를 추측하게 한다는 점**이다. 심사용 노트에 근거가 있어도 발표자가 읽는 [말할 것]에 없으면 일반 청자에게 전달되지 않는다.

특히 다음을 구분하기 어려웠다.

- R2·R3·R4·R5가 검증 사진 묶음이라는 것, R2만 대표 성능에서 제외한 이유.
- EXT10·DIAG10·EL1이 모델 이름이 아니라 정답을 가리는 검증 방식이라는 것.
- F13·F47이라는 제공 ID와 실제 물리 동의 차이.
- ‘전날 오차가 비슷하다’는 학습 자료 분석과 ‘전날 실측을 쓴다’는 추론 방법의 차이.
- 정확도·균형 정확도·RMSE와 %·%p의 차이.
- 원본 대조와 저장 형식 조건이 언제 켜지고, 꺼졌을 때 무엇이 남는지.

수정 방향은 **화면에는 역할을 설명하는 이름, 대본에는 처음 등장할 때 짧은 뜻풀이, 노트에는 원래 코드명과 근거**를 두는 것이다. 쉬운 표현을 만들면서 실제로 측정하지 않은 현장 성능이나 새 데이터 구성을 만들어 넣지 않았다.

## 5. 발표에서 특히 오해를 줄여야 하는 문장

### ① 내부 이름을 설명하느라 시간을 쓰지 않기

기존에는 R3·R4·R5라고 불렀지만, 새 대본은 **“학습에 사진 자체를 넣지 않은 세 검증 묶음”**이라고 먼저 말한다. 기술 노트에서만 기존 이름을 대응시킨다. 숫자 1~3은 구분자이며 새로운 자료·난도·출처를 뜻하지 않는다.

### ② ‘과거 오차가 닮음’과 ‘과거 정답으로 보정’을 구분하기

대본은 학습 정답으로 하루 수준 오차를 분석했다는 사실과, 추론에서는 전날 실측 또는 앞선 예측을 사용한다는 사실을 나눈다. 오늘 정답이나 오늘 오차를 알고 보정하는 것으로 들리지 않도록 6장에도 명시했다.

### ③ 복원 절차를 없애는 것과 과거 정보를 없애는 것은 다름

정상적인 현장에서는 날짜·동 정보로 전날을 확인할 수 있다. 9장 제거 실험은 그 정보가 있어도 사용할 수 있는 앵커·사슬까지 제거한 비교다. 새 대본·23장 표현은 이를 ‘현장으로 바꾸면 반드시 생기는 손해’로 설명하지 않는다.

### ④ 학습 미사용은 완전한 독립 시험과 다름

검증 1~3은 사진 자체를 학습에 넣지 않았고 같은 원본 겹침도 없지만, 농장·촬영 묶음은 겹친다. 후보 선택에 사용했으므로 ‘완전히 처음 보는 최종 시험’으로 설명하지 않는다. ‘봉인’이라는 단어만 바꾸고 이 조건을 숨기는 방식은 피했다.

## 6. 10분 발표에서의 운영

본문 장수는 16장으로 유지했다. 새 설명을 모두 뒤에 덧붙이지 않고 기존의 내부 약어·방법 목록을 대체했다. 본문에서는 기능과 결과를 말하고 정확한 코드명·거리 문턱·라이선스 등은 노트·부록에서 확인한다.

- 1~4장: 과제·용어·자료 단위를 먼저 이해시키기.
- 5~9장: 오차 관찰, 과거 상태 활용, 검증 범위와 현장 조건의 흐름 유지.
- 10~14장: 학습 자료를 만든 이유, 판별 방법, 검증 사진의 성격, 처리 변화 취약성 설명.
- 15~16장: 팀의 판단·도구의 역할과 두 과제의 성과·한계 정리.

**실제 발표 시간은 아직 재지 않았다.** 수정 대본을 읽는 리허설에서 10분을 넘으면 세부 데이터 품질 분류·내부 채택 사례를 줄이고, 배지/EC 정의·검증 묶음 뜻·그래프 방향·현장 한계는 유지하는 것이 좋다. 이 보고서는 10분 충족을 확인했다는 뜻이 아니다.
