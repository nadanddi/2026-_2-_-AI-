# 9회차 온도 재현 환경 연결

대상은 `제출/09회차_2026-10-06(팀)/팜모니_정형데이터_재현패키지_14.zip`의 `온도/code/make_submission_v13_temp.py`이다. W40G-S = BASE0.4 + CODEX(0.2+0.4(1−g)) + TABPFN0.4g, g=clip((현재실내온도−8)/2,0,1). BASE 시드7/101/2024, CODEX726/727, TabPFN v2 CPU 문맥2000행·시드1..8·각4추정기의 원설정이다.

## 이번에 연결한 것

- 원ZIP은 그대로 두고 `연구실/코덱스/local/temp_round9_reproduction_20261008_v1/extracted/`에 새로 추출했다.
- 온도패키지의 data/에는 원본3CSV가 없으므로 공식배포본을 추출본에 복사했다. 동봉 manifest_12.json의 SHA3개와 일치한다. 파일명12와 실제 name=temp_candidate_v13 차이는 기존 패키지의 표기이며 바꾸지 않았다.
- 온도폴더에는 별도체크포인트가 없다. 같은ZIP의 EC/tabpfn-v2-regressor.ckpt를 tasklocal model_cache로 복사했다. SHA2ab5a07d… 일치. TabPFN의공식model_cache_dir설정과offline환경으로 동봉모델을 사용한다.
- 기본Python의전역패키지대신 저장소 `.analysis-tools/python`, `.analysis-tools/extra`, `.analysis-tools/msvc`를 연결했다. NumPy2.5.3/Pandas3.0.1/SciPy1.18.1/sklearn1.9.1/LGB4.7.0/Torch2.14.0+cpu/TabPFN9.0.0은패키지요구와 일치한다. Python은3.12.10이며기록의3.12.4와patch버전만 다르다.
- env/common 등 모델용 모듈은 추출본code/에서 import됨을 기록·검사한다. 저장소의 다른 모델 소스를 대신 실행하지 않는다.

`run_v1.py`는 환경과 새 출력 경로만 연결해 원본 스크립트를 실행한다. 모델 소스·시드·특징·가중치·문맥·CPU예측방식은 변경하지 않았다. 기존 출력 덮어쓰기를 거부한다. 재실행이 필요하면 새 추출본/새 출력 경로/새 버전 receipt를 먼저 만든다.

## 결과를 판정하는 범위

학습·예측 완료와 정확 재현은 별도다. `compare_v2.py`로 공식 제출9회차의1440개 row_id·행순서·온도값을 Decimal 소수6자리로 전수대조하고, npz의8문맥/게이트/혼합식을 별도 fsum으로 검산한다. 정확 숫자일치가아니면근사차이를그대로보고한다.

원스크립트 출력CSV의EC열은submission_04를복사한다. 이 파일은온도재현용이며9회차EC를재현한파일이나새제출파일이아니다. 9회차종합CSV의전체byteSHA일치와온도값일치는서로다르다. 평가정답이없으므로 플랫폼온도점수0.5127 자체를새로채점할수는없다.

추가 규정검사 `temp_v13_checks.py`는이번요청의온도값재현에필요한실행과구분하고 자동실행하지않았다. 과거규정검사7개를이번에도실행했다고보고하지않는다.

최종결과는 `comparison_v2.json`, 독립최종검산receipt 및 최종보고서에서 확인한다. 이안내는 실행환경·검증범위 설명이며 실행중에작성돼 결과PASS를주장하지않는다.
