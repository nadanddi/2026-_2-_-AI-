# 고정 ET에서 실패·대조날의 입력 조합과 학습지원 비교

2026-10-07 연구실 코덱스. 사용자 ‘161일과 다른 실패날에서 어떤 입력 조합이 높은 EC 학습지원을 선택하게 만드는지 기준 모델을 고정해 비교해봐’에 따라 실행한다. 이전 진단의 새로운 삭제안이나 제출모델은 만들지 않는다.

## 두 관점

1. **원래 OOF 모델 고정:** 현재 EC14 ET47열·seed7의 fold1(F47_161),fold4(F47_130),fold8(F13_231·233)을 그대로 복원하고 원캐시 raw ET와≤1e−10 일치시킨다. fold1은이미보존한fullforest를재사용하고fold4/8만동일설정으로복원한다. 각실패–대조쌍은동일한원래ET 안에서비교한다. 서로다른fold의지원풀차이가남으므로모든실패가같은model을통과한결과라고하지않는다.
2. **같은 모델 비교:** 위세fold 학습행의교집합에서모든실패·대조날±1을추가제외한공통집합으로현재ET레시피를seed7/101/2024 한 번씩학습한다. 이후모델·계절mapping·미디언·훈련정답을고정하고모든사례에동일하게적용한다. 이는현재ET와같은레시피의진단모델이며원OOF나실제제출예측재현이아니다. 학습자료가줄어드는변화는따로보고한다.

신규학습은원기준ET복원2+공통진단ET3=5회,새LGB/MLP/PFN/SG2학습0이다. ET학습지원에집중하고전체EC14/SG2 효과나성능개선채택으로확대하지않는다.

## 사례와 대조 선택

- 대상: F47_161/F47_130/F13_231/F13_233. 사전에알려진실패사례로서새독립성능증거가아니다.
- 각대상원fold의원query안에서같은farm의일반날,현재EC14 ensemble 하루RMSE≤.1,세seed ET평활하루평균의실제일평균대비절대편향≤.1인날을대조후보로한다.
- 선택우선순위: 같은pass 및실제EC차≤.2→pass제한없이EC차≤.2→EC차≤.3→같은farm의기준성공후보전체. 첫지원집합에서0h의season와RAW10종h0를원fold학습미디언/표준편차로표준화한평균제곱거리최소1날을고른다. 동률은day오름차순. 후보수·선택단계·거리·EC차를보고하고사후재선택하지않는다. 실제정답을쓰는매칭이므로진단대조이지평가행선택규칙이아니다.
- 추가역사대조: F47_161↔F47_160. 160은원fold1의원query가아니지만학습행과는분리돼있음을검사한다. 이대조를정식OOF 또는대조날±1까지같은purge를받은검증이라고하지않는다. 공통진단모델에서는160±1도제외한다.
- 원fold 모델에서는대상query의계절값을그대로사용한다. 추가160은같은학습집합의mapping으로계산한다. 공통모델에서는새공통학습mapping을쓴다. 모델사이의season 차이를기록하며46개비계절열은동일한관측특징이어야한다.

## 고정한 입력 그룹과 모든 조합

47열을season,온도,습도,CO₂센서,환기,난방,커튼(차광·보온과공유전환기록),CO₂제어,순환팬,포그,시각의11개서로겹치지않는그룹으로분할한다. 제어의현재/h0/누적값과그제어의DP1파생값을함께바꾼다. 커튼공유파생값은커튼통합그룹에속한다.

각쌍의24시간곡선을같은hour끼리맞추고,전체하루에서값이달라지는그룹의모든2^n 조합을구성한다. 제어그룹내동일날의관측곡선·h0·누적기록을함께옮기며시각은동일하다. 혼합된서로다른입력그룹이물리적으로가능한날이라고보장하지않는다.

- 각조합의raw ET하루평균과prefix평활하루평균,실제잎의훈련행가중치합을구한다. 평활하루지원은고정선형hour가중치로계산한다.
- 모든교체순서의평균인그룹Shapley로기준대조→실패의예측차이와고EC학습날지원차이를분해한다. 합이실제차이와맞아야한다. 고EC학습날은훈련날정답평균≥1,지원비중은발생확률이아니다.
- 두그룹조합은대조문맥및실패문맥각각에서 ‘두그룹동시교체변화−각그룹단독변화합’을구한다. 단순비가산성지표이며두특징의독립인과나물리시너지가아니다. 출발문맥과대조선택에따라결과가달라진다.
- 실제지원상위학습날·가중정답평균·고EC비중·같은farm지원,0/6/12/23시의처음갈라지는tree분기와공유prefix조건도보존한다. 첫분기빈도나한tree조건을전체모델의충분조건으로표현하지않는다.

## 해석·감사·완료

원모델과공통모델의그룹기여·조합이동일방향인지,공통세seed가일치하는지보고한다. 다른실패에서같은고EC지원기전이없으면중간수준지원등다른유형으로구분한다. 어떤그룹이항상원인이라는새문턱을사후선택하지않는다.

설계·준비hash/대조선택/재현서명·단위검사→독립사전비평→main등록→고정모델복원/진단fit→전체완료receipt→지원/조합/분기숫자검산·혹독비평→보고서/인계 순서다. fullforest는seed7 원fold4/8과공통모델만새저장하고원fold1 기존snapshot을재사용한다. 다른공통seed는leaf/지원/조합배열을보존하고원fit·예측서명을연결한다. 전체tree 경로감사는새seed7 forest에한정하고다른seed까지전수재routing했다고표현하지않는다.
