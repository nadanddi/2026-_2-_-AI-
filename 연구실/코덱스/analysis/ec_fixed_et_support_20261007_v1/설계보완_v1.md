# 실행 전 설계 명확화

그룹의 정확한 47열 대응표는 core_v1.py GROUPS와 preparation_v1.json에 고정했다. 거리의 표준편차는 ddof=0, 0 표준편차는 1, 결측은 원fold의 열별 학습 미디언을 사용한다. 적격 대조가 없으면 중단한다. 공통학습 제외는 같은 농장의 대상·대조 각각 ±1일이며 완전한 24행 날짜만 허용한다.

조합은 실제 모델이 받는 미디언 대체 후 float32 입력의 차이를 기준으로 한다. 원래 관측값이 달라도 대체 후 완전히 같으면 모델 관점에서는 차이가 없어 활성 그룹에서 제외한다. 양끝 입력 재현과 Shapley 합, raw 및 prefix 평활 지원 재현을 검사한다. 두 문맥의 비가산성은 같은 방향의 두 그룹 교체에 대한 조건부 이차 차분이다. 나무의 첫 분기는 600개 모두 보존하며 갈라지지 않는 나무도 분모에 넣는다.

선정한 대조는 F47_165, F47_127, F13_232(두 실패 공통)이며 추가 역사 대조는 F47_160이다. 원래 학습집합의 교집합과 추가 제외 후 공통 학습은 173일이다. 대조는 정답과 기존 성공을 이용한 사후 진단용이고 독립 평가 증거가 아니다.

저장 코드를 통일하기 위해 공통 seed101/2024도 전체 forest를 보존한다. 전수 경로 감사 범위는 계획대로 새 seed7 forest 세 개이며 다른 seed까지 전수 감사를 했다고 표현하지 않는다. 신규 학습은 원fold4/8 복원 2회와 공통 3회, 합계 5회다.
