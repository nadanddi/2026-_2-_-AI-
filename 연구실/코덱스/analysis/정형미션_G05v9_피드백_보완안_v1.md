# G05v9 정형 미션 보완안

2026-11-04 · 화면 교체 문구, 발표 대사, 근거 배치 제안. 장 번호는 G05v9 기준이다.

## 장 구성 결정

**4장은 두 온실의 기록이 왜 이어지는지, 별도 한 장은 어떤 온실 자료를 어디에 썼는지** 설명한다. 이 두 질문을 한 장에 담으면 기존 그림이 다시 표와 경쟁한다. 현재 3장 구분 표지를 4장 제목에 합치면 자료 비교 한 장을 확보할 수 있다. 온도와 EC 모델 설명도 각각 독립된 장으로 두는 편이 명확하다. EC 장을 추가하는 경우 기존 공통 설명과 중복 대사를 덜고 실제 넘김을 포함해 시간을 잰다.

## 1~2. 결과 요약과 정형 도입

- **2장** 큰 제목은 **결과 요약**. 표에 온도 0.4608℃, EC 0.1148 dS/m, 이미지 97%를 한 번씩만 표시한다. 발표자는 “온도와 EC는 오차가 낮을수록 좋고, 사진은 정답률이 높을수록 좋습니다”로 읽는 법을 짚는다.
- **3장** 배지·EC의 별도 정의 문단을 걷고 “온실 센서 기록으로 같은 시각의 배지 온도와 전기전도도(EC)를 추정” 한 줄을 4장 도입에 합친다.

## 3~4. 어떤 온실을 어떻게 썼나

**문제·자료 장** 그림1은 유지한다. 그림 제목은 **제공 ID가 달라도 전날 기록이 이어지는 경우가 있었다**. 같은 물리 동이라는 해석과 수집 원인 미확인은 대사에서 구분한다. 표1 아래는 “하루 기록 하나는 24시간입니다. 채점 대상 60개는 모두 기록 번호 179 이상입니다.” 두 문장으로 끝낸다.

**자료 비교 장** 제목은 **채점 대상 두 온실로 학습하고, 나머지 온실에서 방법을 확인했다**.

| 자료 | 확인한 차이 | 어떻게 썼나 |
|---|---|---|
| F13·F47 | 채점 대상이며 배지 온도·EC 정답과 센서·구동기 입력을 제공 | 최종 모델 학습과 검증 |
| 다른 49곳 | 배지 EC 정답 없음. 대부분 입력 항목이 적고 정수 단위 기록. F32는 입력이 더 많지만 배지·공기 온도 관계가 다름 | 온도 학습에 섞는 시험과, 전날 상태를 쓰는 방법의 별도 확인 |

**대사** “F13과 F47은 우리가 임의로 고른 온실이 아니라 대회가 지정한 채점 대상입니다. 다른 온실에는 EC 정답이 없었고, 온도 모델에 섞는 방법도 시험했지만 추운 날 검증 오차가 약 3~4% 늘었습니다. 그래서 최종 학습에는 두 온실 기록을 쓰고, 다른 온실은 방법이 다른 곳에서도 도움이 되는지 확인하는 데 썼습니다.” 3~4%는 카탈로그 6.45의 T1 추운 날 비교에 한정한다. 다른 방식에서도 일관된 개선을 확보하지 못했다. 다른 49곳을 최종 모델 학습에서 제외한 사실과 개발 중 활용을 구분한다. 근거는 정형 README 79~81줄, 카탈로그 6.44·6.45·6.983·6.997이다.

## 5. 표2는 세 숫자만 두고, 뜻은 대사로

| 무엇을 확인했나 | 다른 49개 온실의 중앙값 |
|---|---:|
| 하루 전체가 높거나 낮게 빗나간 몫 | 제곱오차의 49% |
| 그날 센서 요약으로 이 어긋남을 예측 | 설명력 −0.64 |
| 전날과 오늘의 평균 오차가 닮은 정도 | 상관 0.64 |

**대사** “하루 종일 1도씩 높게 맞혔다고 생각해 보세요. 시간별 변화는 따라갔어도 하루 전체가 위로 밀린 겁니다. 다른 49개 온실에서도 이런 어긋남이 제곱오차의 절반 가까이를 차지했습니다. 그날 센서 요약으로 이 어긋남을 예측하는 실험은 평균값보다 못했고, 연속한 날의 평균 오차는 닮아 있었습니다. 그래서 전날 배지 상태를 단서로 삼았습니다.” 표에 R² 공식이나 상관 정의를 추가하기보다 이 예시를 말한다. 49%·−0.64·0.64는 다른 49곳의 중앙값이며, 오차 상관 자체가 보정 효과를 입증한 결과는 아니다. 근거는 카탈로그 6.997이다.

## 6~7. 온도 기본 예측과 비중

**표 3. 온도 기본 예측에 쓰는 세 모델**

| 모델 | 무엇을 보나 |
|---|---|
| 모델 A | 실내외 센서와 난방·환기 기록, 앞선 며칠의 변화까지 함께 봄 |
| 모델 B | 오늘 0시부터 지금까지 온실 센서와 구동기가 어떻게 변했는지 봄 |
| 모델 C | 표 자료로 미리 학습한 모델에 기존 온실 기록을 예시로 주고 지금의 배지 온도를 추정 |

노트에 A=BASE, B=CODEX, C=TabPFN을 명시한다. A와 B 모두 물리 기준 예측에 학습한 보정을 더한다. B의 계절 지표·온실 ID는 노트에 남긴다.

**표 4. 실내 온도에 따른 모델 비중**

| 실내 온도 | A | B | C |
|---|---:|---:|---:|
| 10℃ 이상 | 40% | 20% | 40% |
| 9℃ 예시 | 40% | 40% | 20% |
| 8℃ 이하 | 40% | 60% | 0% |

화면 하단은 “8~10℃에서는 C의 비중을 0%에서 40%까지 서서히 늘리고, B의 비중은 그만큼 줄입니다.” 대사에서는 “추운 기록에서 C의 오차가 커 8도 이하에서 뺐습니다. 8도와 10도 사이에 모델 비중이 갑자기 바뀌지 않게 했습니다. 10도 이상에서 C에 40%를 준 것은 내부 검증이 엇갈려 공개 점수로 두 후보를 비교한 결과입니다.” 8~10℃가 비어 있는 구간이라는 인상을 표에서 바로 해소한다. 여러 경계도 비슷하게 작동했고, 8·10℃가 보편적인 최적 문턱이라는 근거는 없다. 근거는 정형 README 90~97·218줄, 카탈로그 6.67·6.69·6.198이다. 기존 표4 이후 표 번호와 대본·노트의 참조를 함께 맞춘다.

## 8~11. 온도 보정과 EC 모델을 분리

**온도 보정 장** 제목은 **전날 상태를 이어받고, 추운 날의 과소예측을 보정한다**. 소제목은 **전날 상태 활용**, **추운 조건의 온도 보정**으로 바꾼다. 단계 번호는 걷는다.

**전날 상태 활용 화면**

1. **후보 찾기** — 앞 기록 23시와 오늘 0시의 외기·실내·구동기 흐름이 자연스럽게 이어지는지 비교.
2. **믿을 만할 때만 사용** — 전날 23시 실측이 있으면 반영. 실측 없이 쓸 수 있는 전날 예측이 있으면 줄여 반영.
3. **둘 다 없으면** — 전날 상태 보정을 생략하고 기본 예측과 적용 가능한 저온 보정을 사용.

**대사·질의응답** “비슷한 날씨만으로는 틀릴 수 있어 실내와 구동기 흐름도 함께 비교합니다. 학습 자료에서 연결을 확인할 수 있었던 짝 중 높은 확신 구간은 약 91%가 맞았습니다. 평가 기록의 실제 연결 정답은 확인하지 못했습니다.” 91%는 확신 점수 0.8 이상 구간이다. 0.5~0.8 구간은 약 72%였으며, 실제로 연결을 틀린 짝의 자정 온도 추정 RMSE는 1.99℃, 맞힌 짝은 0.19℃였다. 이 숫자는 진단 표본에 한정해 노트에 둔다. 실내 자정 변화 1.5℃ 이내, 중간 확신 예외와 별도 일치 조건, 동일 ID 앞 기록만 쓰는 온도 예측 이어받기 요건은 상세 노트에 남긴다. 계수 그림은 **전날 실측 보정 반영률**이라고 표시한다. 근거는 정형 README 100~120줄, 카탈로그 6.944이다.

**추운 조건의 온도 보정 화면** “EC 예측이 높은 동의 추운 시간에는 배지 온도를 낮게 예측하는 경향 → 최대 0.25℃ 올림.” 대사에서 “학습 정답에서 확인한 온도 차이를 반영하되, 실내가 따뜻해지거나 EC 예측이 낮으면 보정을 줄였습니다”로 이유를 붙인다. 노트에는 0시~현재 EC 기본 예측 평균이 0.8 이하이면 0, 0.8~1.2에서 강도를 올리고, 실내 8℃ 이하는 저온 쪽 최대 강도, 8~10℃에서 줄여 10℃ 이상이면 0이라는 두 조건을 적는다. 최대치는 두 조건이 모두 최대일 때다. 0.25℃는 학습 자료에서 관찰한 차이를 근거로 한 값이다. TX3 재검증 44개 조건에서 개선 방향이 같았고 주 검증 EXT10 RMSE 약 0.44% 감소, 블록 재표본 악화 비중 0.0047이었다. 초기 TX2의 문턱 미달과 후속 TX3의 통과를 구분한다. 근거는 정형 README 114~115·223줄, 카탈로그 6.799·6.931이다.

**EC 모델 장** 제목은 **EC는 오늘의 흐름으로 기본값을 잡고, 전날 실측이 있으면 보정한다**. 화면 흐름은 “① 지금까지의 센서·구동기 기록으로 기본 EC 예측 → ② 하루 전체가 높거나 낮게 빗나갈 정도를 추정해 조정 → ③ 연결 조건을 만족하고 전날 EC 실측이 있으면 추가 조정.” 온도 보정에서 쓰는 EC는 이 경로의 **하루 수준 보정까지 적용한 기본 EC**이며, ③까지 적용한 최종 EC나 오늘의 정답이 아니다. 노트에 EC 기본 혼합 80/20과 하루 수준 보정, 전날 실측 보정식을 남긴다. 근거는 정형 README 114~115·122~138줄이다.

## 12. 현장 전환 표

| 구분 | 대회 자료에서 한 일 | 실제 현장에서는 |
|---|---|---|
| 제거 | 기록 번호 구간과 평가 기록의 존재 여부로 모델을 바꾸던 규칙 제거 | 연속 관측에서 같은 방식으로 예측 |
| 유지 | 센서 흐름으로 같은 동의 전날 기록을 찾아 배지 상태 반영 | 날짜·동 ID가 잘 기록돼 있으면 전날 기록을 직접 조회 |
| 남은 확인 | 외기 기록에서 복원한 계절 지표 사용 | 실제 달력 날짜로 바꾼 뒤 성능을 다시 측정해야 함 |

‘현장에서는 해당 없음’ 대신 현장에서 무엇을 하는지 적는다. 현장 성능 확인 여부는 마지막 행에서 분명히 말한다.

## 13~14. 채택 기준과 표5

**채택 기준** 아래 두 항목을 독립된 줄로 두고 간격을 벌린다.

1. **검증 자료와 학습 난수를 바꿔도 오차가 줄어야 함**
2. **기록 묶음을 다시 뽑아 비교했을 때, 개선이 없거나 오차가 늘어난 비율이 2.5% 미만**

화면은 위 두 줄이면 충분하다. 발표에서는 “한 번 우연히 좋아진 결과를 거르기 위해 실행 전에 정한 규칙”이라고 설명한다. 노트에 `P(worse) < 0.025`와 기록 묶음 단위 재표본 방법을 적는다. 화면에 일반적인 ‘p값’이라는 말만 추가하면 새 용어가 생기고, 실제로 효과가 있을 확률처럼 오해될 수 있다.

| 회차 | 바뀐 것 교체 문구 | 선택 경로 |
|---|---|---|
| 19 | 실측이 없는 전날의 온도 예측을 이어받음 | 기준 통과 |
| 20 | 번호 순서 대신 같은 동의 전날을 찾아 입력 이력을 연결 | 기준 미달 |
| 21 | 전날 온도 예측을 이어받는 조건을 넓힘 | 기준 통과 |
| 22 | 학습 범위보다 추운 날의 온도 보정을 확대 | 기준 미달 |
| 23 | 외기 또는 실내 흐름으로 연결을 재확인해 온도 실측 보정 확대 | 공개 점수 비교 |
| 24 | 온도 예측 이어받기와 전날 EC 실측 보정 확대 | 공개 점수 비교 |

점수 열 값과 그래프는 유지한다. 표 제목은 **온도 공개 점수와 변경별 선택 경로**. 캡션은 “온도 RMSE는 낮을수록 좋습니다. ▲는 직전 최고보다 오차가 큰 경우입니다.” 17회차는 그래프 출발점이라고 짧게 표시한다. 화면 공간이 부족하면 23회차를 ‘연결 재확인 후 온도 실측 보정 확대’로 줄이고 외기·실내 조건은 노트에 둔다. 근거는 정형 README ⑤, 제출 성능 정리 23·24회차 및 G05v9 표5 노트다.

## 15. EC 검증 막대 이름

제목은 **전날 보정을 빼면 EC 오차가 얼마나 커지나**. 세로축은 **기존 모델 대비 RMSE 증가율(%)**. 막대는 **학습 기록 무작위 분할**, **채점과 같은 번호 구간에서 여러 기록을 함께 제외**, **같은 구간에서 하루 기록씩 제외**로 표시한다. 공간이 부족하면 두 번째와 세 번째를 “여러 기록 함께 제외”, “하루 기록씩 제외”로 줄이고 두 막대에 공통으로 **채점 대상과 같은 기록 번호 구간**을 붙인다. 대사는 “제외한 기록의 정답을 학습에 쓰지 않고 예측해 비교했습니다” 한 문장으로 푼다. 각각 8.3%, 30.5%, 11.0%와 현행 RMSE를 분모로 한 정의는 유지한다. 근거는 정형 README 37줄, 카탈로그 7.069다.

## 적용 순서

1. 자료 범위 비교와 온도·EC 경계를 먼저 확정한다. 구분 표지를 합쳐 확보할 장과 새 EC 장의 시간을 정한다.
2. 표1~5의 정보와 대사를 함께 짧게 맞춘다. 화면에는 결론과 읽는 데 필요한 숫자를, 대사에는 예시와 선택 이유를, 노트에는 조건·수식·한계를 둔다.
3. 표 번호와 노트·대본 참조, 모델 코드명 대응, 비중과 점수 원값을 대조한다.
4. PowerPoint 렌더에서 표 줄바꿈과 그래프 축을 확인하고, 실제 장 넘김으로 10분 리허설을 잰다. 시간이 넘으면 회차별 설명이나 반복 결론부터 줄인다.
