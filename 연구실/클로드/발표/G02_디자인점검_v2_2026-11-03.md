### 1.2 우리 팀이 고른 것(출처에서 가져온 것과 구분)
- **출처에서 가져온 것**: 본문 장의 제목 자리에 주장 문장을 두고 그림·표 하나로 받치는 방식(Alley·Garner & Alley).
- **팀의 구성 선택(출처 근거 아님)**: 장 구성·순서(요약 → 문제 → 발견 → 모델 → 정리 → 검증 → 현장)는 유지. 이유는 운영위 11-01 메일 "발표 본문의 구성이나 방향을 바꾸실 필요는 없습니다"와 10-30 공지의 '발표에 담을 내용' 순서(전략 → 데이터 → 모델 근거 → 검증·실패 → 농업적 해석·현장 조건 → AI/팀)를 이미 따르고 있기 때문.
