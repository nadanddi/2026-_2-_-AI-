## 2. 운영위원 관점 — 피드백과 처리

**M1. 2.3에 이미지 '실패 → 개선' 사례가 화면에 없음 → 반영(필수)**
- 문제: G05v12에서 같은 값을 그리던 그래프를 빼면서, 장 제목 '검증과 개선 과정'의 '개선'이 화면에서 사라졌다. 공지 항목 '실패 사례와 개선 과정'에 대응하는 이미지 쪽 화면 근거가 없다.
- 근거: 이미지 README ⑤ 'E_gpt의 rc 제외 결정'
  - 첫 판은 놓친 26장 중 14장을 새로 잡았다.
  - 그러나 실제 오탐 +0.12%p, 검증 3 −0.28%p로 사전 기준을 근소하게 넘어 불통과였다.
  - 새 실제 오판 대부분이 진짜 확정(rc) 사진이고 GPT 가짜 600장 중 rc는 0장이어서, rc 사진에는 적용하지 않기로 했다.
  - 다만 불통과를 본 뒤 같은 자료로 정한 변형이라 낙관적일 수 있다.
  - 리더보드는 쓰지 않았다.
- 교체 문구(2.3 맨 아래 두 줄): "개선 사례: GPT 편집 가짜를 잡는 판별기 첫 판은 진짜 사진 오탐이 기준을 근소하게 넘어 불통과 → 원본과 같다고 확인된 사진에는 쓰지 않게 바꿔 채택(같은 자료로 정한 변형이라 낙관적일 수 있음)"
- 대사: 시간 때문에 넣지 않는다. 대본의 '덧붙일 문장'과 질의응답에 둔다.

**M2. 4장 이미지 향후 계획 '휴대폰 처리에 재학습' → 반영(권장)**
- 문제
  - 2.4에서 잰 것은 '검증 1 실제 사진을 선명화·WebP 등으로 다시 저장한 오탐'이다.
  - '휴대폰 처리'와의 연결은 재지 않았다. 부록 A8의 표현도 "약할 수 있음"으로 유보형이다.
  - G07_R01 검수에서 2.4 결론을 실험 범위로 좁혔으니, 정리 장도 같은 범위로 맞춘다.
- 교체 문구: 표 10 이미지 계획 둘째 줄을 "선명화·WebP 저장 사진으로 확인·재학습"으로 바꾼다.
- 대사: "새 농장과 휴대폰 사진으로 확인하는 것"을 "새 농장 사진과 다시 저장한 사진으로 확인하는 것"으로 바꾼다.
- 노트: 같은 뜻으로 맞춘다.

**M3. 1.3 표 3을 예측 대상 F13·F47 기준으로 → G05v13에서 반영함(사용자 지적)**
- 사용자 지적(11-04): "예측에 쓰는 건 F13·F47인데 왜 다른 49곳 중앙값이 기준인가"
- 다시 잰 결과(카탈로그 7.078)
  - 하루 몫: F13 49%, F47 53%
  - 가장 나쁜 10% 날의 몫: 59%, 49%
  - 설명력: −0.18, −0.12
  - 상관을 진짜 전날 짝 190쌍으로 다시 재면 F13·F47은 0.27로 약하다(다른 49곳은 0.64).
- 처리
  - 표 3을 F13·F47 열 중심으로 바꿨다. 다른 49곳은 확인 열로 남겼다.
  - 상관 줄은 화면에서 뺐다.
  - 제목은 문제 진단("오차의 절반은 하루 전체가 통째로 밀린 것이고, 그날 센서로는 맞히지 못했다")으로 바꿨다.
  - '어제'의 효과는 1.9의 끄기 실험으로만 말한다.
- 이번 회차에 검수를 요청한다. 근거 스크립트: `연구실/클로드/code/dlv1b_true_pair_corr_v1.py`, `dlv1c_day_types_v1.py`.

**M4. 농업적 해석의 깊이 → 안 함(이번 판)**
- 1.9·2.4는 현장 조건·한계 중심이다.
- 해석을 넓히려면 근거 자료가 필요하다. 근거 없이 일반론을 더하는 것은 과장 금지 원칙에 맞지 않아 이번 판에서는 손대지 않는다.

**M5. 결과 요약에 비교 기준(출발점·기준선)이 없음 → 안 함**
- 청자가 0.4608이 좋은지 판단하기 어렵다.
- 그러나 근거 있는 비교값(같은 조건의 단순 기준선 점수)을 덱에 둔 적이 없다. 새로 만들면 새 실험이 된다.
- 회차별 변화는 1.8 그림 4에 있다.

## 3. 처음 듣는 청자 관점 — 피드백과 처리

**L1. 1.8 표 7의 20회차 칸이 낱말 중간에서 끊김 → 반영(가독성)**
- "입력 이 / 력을"로 끊긴다. 낱말 경계에 줄바꿈을 직접 넣는다: "번호 순서 대신 같은 동의 전날을 찾아 / 입력 이력을 연결"

**L2. '하루 밀림'(1.3)과 '하루 수준 조정'(1.6)이 같은 대상인데 이름이 다름 → 반영(권장)**
- 1.3에서 "하루 전체가 밀린 몫"이라고 말한 대상을 1.6 ②에서는 "하루 수준 조정"이라고 부른다.
- 1.6 ② 제목을 "하루 밀림 조정"으로 바꾼다. 본문 "하루 전체가 높거나 낮게 빗나갈 정도를 추정해 조정"은 그대로 둔다.
- 노트와 대본 이름표: "하루 밀림 조정(= HR5, 이전 화면 이름 '하루 수준 조정')"
- 대사는 이미 "하루 전체가 빗나갈 정도를 추정해 조정"이라 바꾸지 않는다.

**L3. 2.4 제목(균형 정확도 하락)과 대사의 무게(오탐률)가 다름 → 안 함**
- 제목은 왼쪽 그래프, 아래 결론은 오른쪽 그래프를 말한다. 두 축 모두 장 안에 있다.
- 제목을 바꾸면 정의·근거 대조를 다시 해야 해서 이득이 작다.
