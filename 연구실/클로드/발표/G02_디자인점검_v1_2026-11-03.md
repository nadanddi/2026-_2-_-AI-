# G02 AI 느낌 줄이기 — 조사·점검표 v1 (2026-11-03, 연구실 클로드)

## 1. 참고한 발표 형식 (완료 기준 ①)
| 출처 | 확인한 내용 | 우리 덱에 쓰는 것 |
|---|---|---|
| 주장-근거(Assertion-Evidence) 슬라이드 — Michael Alley, *The Craft of Scientific Presentations*; Garner & Alley (2012) *Int. J. Engineering Education* 29(6) 1564–1579; Penn State 안내 [eye_presenting.pdf](https://writing.engr.psu.edu/eye_presenting.pdf), Harvard Catalyst [slides](https://catalyst.harvard.edu/writing-communication-center/visualize-science/slides), Aalto [AE checklist](https://mycourses.aalto.fi/pluginfile.php/1938299/mod_page/content/15/AE-checklist.pdf) | 본문 장마다 **제목 자리에 주장 한 문장**(왼쪽 정렬, 두 줄 이내)을 두고, 그 아래는 그 주장을 받치는 **그림·표 하나**. 글머리 목록 대신 시각 근거 | 주제어 제목(예: '1.2 핵심 발견')을 작은 꼬리표로 내리고, 지금 부제목(주장 문장)을 제목으로 올림 |
| 경진대회 우승팀 발표 — 예: Kaggle Winner Presentation 템플릿(Google Slides, [링크](https://docs.google.com/presentation/d/1dp_aiAHJFNfYwG9j9EFUsyiVc8zQ00p_/htmlpresent)), Owen Zhang "Winning Data Science Competitions"([SlideShare](https://www.slideshare.net/slideshow/winning-data-science-competitions-presented-by-owen-zhang/44086154)) | 결과 → 자료 → 모델 구성 → 잘 된 것·안 된 것(검증·실패) → 질의응답 순서. 공개/비공개 리더보드 차이를 경고 | 지금 본문 순서(요약 → 문제 → 발견 → 모델 → 검증 → 현장)가 이미 이 흐름과 같음 → 순서는 유지(운영위 "구성 바꿀 필요 없음") |

- 조사 범위의 한계: 검색 결과는 대학 안내문과 공개 발표 예시이며, 학회별 공식 양식 규정을 찾은 것은 아님. 글자 수 상한 같은 수치 기준은 출처에 없음(Alley 쪽은 '제목 두 줄 이내'만).

## 2. 운영위 공지 PDF와 겹치는 디자인 요소 (완료 기준 ②)
비교 대상: `공용/대회자료/공고/양명균-개막설명회.pdf`(41장 슬라이드형), `온라인미션_중간안내_20261005.pdf`, 10-30 공지(문서형). 그림: `연구실/클로드/local/발표렌더/공지/개막_sheet.png`, `중간안내_1.png`.

| # | 공지 PDF의 요소 | 우리 v10·G01 덱 | 바꿀 방향 |
|---|---|---|---|
| D1 | 모든 장 같은 틀: 왼쪽 위 제목 + 그 아래 회색 부제목 한 줄 + 아래 각주·쪽수 | 같음(장 번호 + 제목 + 회색 부제목 + 가는 선 + 각주·쪽수) | 주장 문장을 제목으로, 장 번호·주제는 작은 꼬리표. 제목 아래 가로선과 바닥 가로선 없앰 |
| D2 | 큰 숫자 세 개를 가로로 나란히(개막 3쪽 "18팀 / 80명 / 11개 대학") | 요약(0.4608 / 0.1148 / 0.97), 1.2(0.49 / −0.64 / 0.64) | 큰 숫자 줄 대신 작은 표(지표·값·출처)로 |
| D3 | 상자 + 화살표 흐름도(개막 9쪽 입력 → 1시간 → 출력) | 1.3 세 단계 상자, 2.1 네 단계 상자, 2.2 판별 순서 상자 | 테두리 상자를 없애고 세로 가는 선으로 나눈 단계 열(번호·이름·설명)로. 2.2의 점선 '대회 자료용 장치' 상자는 뜻이 있어 남김 |
| D4 | 바닥 각주 왼쪽 + 쪽수 오른쪽('n / 41'), 가는 선 | 각주 + 쪽수 + 가는 선 | 선 없앰, 쪽수는 숫자만 |
| D5 | 번호 원(①②③) 목록 | 없음 | 해당 없음 |
| D6 | 색: 남색·파랑 강조, 회색 글 | 흙갈색·올리브·황토(사용자 선택) | 색은 사용자 선택이라 유지. 겹치지 않음 |
| D7 | 글꼴: 고딕 계열 | 함초롬바탕·함초롬돋움(사용자 선택) | 유지 |
