# 후보 D1c: 6판 중 넓은 편집만 (2026-10-13 밤, 결과 보기 전 등록)

## 근거
- D1a·D1b는 불채택이었다(`IM_부분생성_D1_v1.md`).
- 진단(`im05s_diag_v6.py`, 서버 `logs/D1_diag.log`, 시드 0): 6판 확률이 실제 사진과 얼마나 갈리는지(실제 대비 AUC)는 인페인터와 무관하고 마스크 넓이에 따라 단조로 변한다.

| 마스크 넓이 | 실제 대비 AUC (A 기준) |
|---|---|
| < 5% | .64~.65 |
| 5~10% | .71~.73 |
| 10~15% | .79~.83 |
| ≥ 15% | .82~.89 |

- 그래서 작은 편집은 지금 특징으로는 실제 사진과 거의 구분되지 않는다. 학습에 넣으면 라벨 잡음처럼 작용해 오탐을 올린다고 본다.

## 판정
- 같은 질문의 안이 누적 3개(D1a·D1b·D1c)이므로 본페로니 α = .025 × 2/3 ≈ **.0167**을 쓴다.
- 기준 A 대비 시드 0/1/2 **모두**에서 아래를 만족하면 후보:
  1. GPT 부분생성(125장) 대 실제 AUC 상승
  2. 균형 정확도 ≥ A − .003
  3. 실제 오탐 ≤ A + .01
  4. GPT 부분생성 행만 농장 부트스트랩 → p_worse < .0167
- 진단(판정과 무관): GPT 부분스타일 AUC(v1 25 + v2 50), 공개 부분생성 3장, 유형별 탐지.
