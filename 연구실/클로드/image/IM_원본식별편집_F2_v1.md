# IM 후보 F2 — 원본 식별 + 편집 흔적 가짜 확정 (v1, 실행 전 등록 2026-10-15 01:20)

## 배경
- 나단6(F)은 원본과 거의 같을 때(dg1 ≤ m=1.011)만 원본으로 판정한다. 원본은 분명히 찾았지만(gap 큼) 재압축으로 설명할 수 없을 만큼 다른 사진은 손대지 않는다.
- 공개 21장의 가짜 중에도 그런 사진이 있다(필터 jrtg dg1 1.45/gap 24, 부분 스타일 xeeo 4.27/12, 전체 스타일 ttmn 8.78/14, 부분 생성 uexm 14.7/14, 합성 yuag 10.3/12.6).
- 결과를 보기 전에 등록한다. R2와 봉인 자료의 특징 분포는 보지 않았다.

## 규칙 (나단6 출력 q에 덧붙임, 가짜 쪽만)
- F2a: dg1 > m2 그리고 gap ≥ g2 → q = max(q, .95)
- F2b: dg1 ≤ m, gap ≥ 3.474(F 원본판정), |glob_e| > e2 → q = max(q, .95)
- 문턱은 진짜 사진에서만 정한다(가짜 분포는 보지 않음).
  - 자료: im_real_raw를 F v2와 같은 시드로 섞은 뒤 [2000:] 구간(F v2에서 안 쓴 사진). R2·봉인 원본과 이름이 같은 사진은 뺀다.
  - 그중 1800장 × 흔들기 2회 = 문턱용, 나머지 = 별도 확인용(흔들기 1회, 다른 시드)
  - "자기 원본 포함" 대조와 "자기 원본 제외" 대조(이웃 프레임만 있는 진짜를 흉내)를 둘 다 계산한다.
  - m2 = 자기 원본 포함 dg1의 99.9% 분위
  - g2 = 자기 원본 제외 gap의 99.9% 분위
  - e2 = 자기 원본 포함 |glob_e|의 99.9% 분위

## 채택 기준 (탐색적, 모두 만족)
1. R2 보류 정확도(균형) 나단6 < F2, 묶음 부트스트랩 p_worse < .025
2. 별도 확인용 진짜에서 F2 발동률이 자기 원본 포함 ≤ .5%, 자기 원본 제외 ≤ .5%
3. 봉인 real/bright/brown 오탐이 늘지 않음
4. 공개 21장 21/21 유지
- 시간·용량 영향 없음(이미 계산하는 특징만 사용).
