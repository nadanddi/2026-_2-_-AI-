# 후보 D1: 부분생성 6판(되붙임판) (2026-10-13, 결과 보기 전 등록)

## 근거 (계획 비평 10-13)
- v5 `partial_gen_xl`은 인페인팅 결과를 그대로 반환한다. 그래서 사진 전체가 VAE를 두 번 거친다(전역 img2img + 인페인팅).
- 그 결과 모델은 국소 편집 대신 전역 SDXL 지문을 배웠을 가능성이 있다. 우리 부분생성 OOF는 98%를 잡는데 GPT 부분생성은 56%다.

## 6판 (`im15c_pgen_v6.py`, 900장)
- 전역 재표현 없음.
- 마스크 둘레 정사각 창만 인페인팅한 뒤 **마스크 영역만** 깃털로 되붙인다.
- 인페인터: SDXL-inpaint / SD1.5-inpaint 반반.
- 마스크 넓이 2~15%.

## 판정 (`im05s_eval_pgen6.py`, 안 2개 → 본페로니 α=.025, 시드 0/1/2 **모두**)
1. **주 지표:** GPT 부분생성 25장 대 실제 사진(OOF, L2 전)의 AUC 상승. 임계값과 무관하므로 실제 점수가 같이 오르는 착시를 피한다.
2. GPT 외 OOF 균형 정확도(L2 후) ≥ A − .003
3. 실제 OOF 오탐(L2 후) ≤ A + .01
4. GPT 부분생성 행만 농장 단위 부트스트랩(시드 평균 예측의 AUC 차, 2000회) → p_worse < .025
- 둘 다 후보면 AUC가 높은 쪽.
- 한계: 시험 표본이 25장이라 검출력이 낮다. 작은 효과는 "효과 없음"이 아니라 "검출 못 함"일 수 있다.
