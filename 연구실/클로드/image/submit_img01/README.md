# 팜모니 — 이미지 미션 제출물 (나단1)

## 1. 사용 모델
두 갈래 판별기의 확률 평균에 원본 대조 규칙을 더한 구성입니다.

| 갈래 | 입력 | 모델 | 파일 |
|---|---|---|---|
| 의미 갈래 | 리사이즈 없이 원해상도 336×336 조각 3×3(9개) | CLIP ViT-L/14@336 시각부(고정) → 조각별 L2 정규화 후 평균 → 표준화 + 로지스틱 회귀 | `vit.py`, `model/b2_visual_fp16.safetensors`, `model/b2_lr.npz` |
| 저수준 갈래 | 이미지 전체 | 잡음 잔차·선명도·JPEG 8×8 격자·채도·주파수·128px 타일 편차 등 38개 통계 → 결정나무 부스팅(HistGradientBoosting 학습 후 노드 값을 numpy 배열로 저장해 계산) | `lowfeat.py`, `model/low_hgb.npz` |
| 원본 대조 규칙 | 이미지 12×16 색 지문 | AI Hub 이용 승인 데이터(596번) 원천 사진 152,043장의 12×16 색 평균 지문(파생 통계)과의 최소 평균 절대차로 원본의 존재·변형 정도 판단 | `model/fp_db.npz` |

- `vit.py`는 CLIP 시각부 구조를 순수 PyTorch로 직접 작성한 것입니다(제3자 코드 동봉 없음). 학습 때 특징을 뽑은 open_clip 3.3.0 `ViT-L-14-336`(활성화 GELU, 클래스 토큰, ln_post 후 proj)과 같은 계산이며 출력이 같음을 확인했습니다(최대 차 0).
- 용량: 약 0.66GB(가중치 581MB, 지문 DB 80MB, 나머지 1MB 미만).

## 2. 사전학습 가중치 출처
- OpenAI CLIP ViT-L/14@336px(MIT 라이선스). 학습 PC에서 open_clip(`ViT-L-14-336`, pretrained=`openai`)으로 받은 시각부 가중치를 fp16 safetensors로 저장했습니다.
- CLIP 가중치는 고정했고 추가 학습하지 않았습니다. 추론 중 다운로드는 없습니다.

## 3. 학습 자료 출처와 구성
### 3-1. 실제 사진(라벨 0)
- **출처**: AI Hub 「지능형 수직농장 통합 데이터(딸기)」(데이터셋 번호 596).
  - 과학기술정보통신부의 재원으로 한국지능정보사회진흥원(NIA)의 지원을 받아 구축된 데이터입니다.
- **받은 방법**: AI Hub 이용 신청·승인 후 팀원 계정으로 내려받은 원천데이터 tar를 썼습니다(연구·AI 학습 목적).
  - Training `원천데이터_add_20260807` 271개
  - Validation `원천데이터` 36개
- **고른 방법**
  - tar마다 개체를 돌아가며 고르게 추출했습니다. 품종 균형, 농장 균형, 축소 배율 구간 균형으로 추가 추출했습니다.
  - 붉은 LED 조명 사진(평균 R−G>25)은 제외했습니다.
- **처리**: 배포 형식에 맞춰 덮게 축소 → 가운데 768×1024(가로 1024×768) 크롭 → JPEG 품질 92로 저장했습니다.
- 실제 2,467장(같은 처리 후 0.75배 축소·재확대한 대조군 일부 포함)을 사용했습니다.

### 3-2. 생성·변형 사진(라벨 1) — 자체 제작, 7,124장
위 실제 사진에 문제설명서의 6개 유형을 적용했습니다.

| 유형 | 제작 방법 |
|---|---|
| 지정 필터 | 가우시안 블러(배포 크기 σ 1.0~2.2 / 원본 해상도 σ 1~5), 가우시안 노이즈, 소금·후추, JPEG 압축률 변경(원본 해상도 적용 후 축소) |
| 합성 | 작물(녹색 영역)을 분할해 다른 사진 배경 위에 놓기, 다른 사진의 잎 단위 영역 붙여넣기, 흰 여백 |
| 전체 스타일 변환 | 색 전이·톤·대비 조정, SDXL img2img(구도 유지, strength .30~.55), SD1.5 img2img |
| 부분 스타일 변환 | 위 변환을 작물 모양·덩어리 마스크 영역에만 적용 |
| 부분 생성 | SDXL / SD1.5 인페인팅으로 일부 영역 재생성(전체를 약하게 재표현한 뒤 일부 재생성 포함) |
| 전체 생성 | SDXL / SD1.5 텍스트-이미지 생성(딸기 시설재배 장면 문장) |

- **생성 모델**: Stable Diffusion v1.5 및 v1.5 inpainting(CreativeML OpenRAIL-M), SDXL base 1.0 및 SDXL inpainting 0.1, sdxl-vae-fp16-fix(OpenRAIL++/MIT).
  - Hugging Face에서 받아 학습 자료 제작에만 썼습니다. 제출물에는 포함하지 않았습니다.
- 모든 가짜는 실제 사진과 같은 마지막 처리(768×1024, JPEG 92)로 저장했습니다.

### 3-3. 학습 방법
- 학습 가중치: 실제와 가짜가 각각 50%, 가짜 안에서는 6개 유형이 균등하도록 표본 가중을 줬습니다.
- 로지스틱 회귀: C=0.05, 입력 표준화.
- 결정나무 부스팅: max_iter 300, learning_rate 0.05, max_leaf_nodes 15, l2 1.0, random_state 0.
- 검증: 농장 코드 단위 5겹 교차검증(같은 원본의 실제·가짜는 같은 폴드)과 공개샘플 21장(학습 미사용)으로 구성을 골랐습니다.
- 제출 모델은 전체 자료로 다시 학습했습니다.
- 공개샘플 21장은 학습에 넣지 않았습니다.

## 4. 최종 출력 처리 (10/5 중간 안내 3절 항목)
| 항목 | 내용 |
|---|---|
| 계산식 | p1 = 로지스틱(CLIP 조각 평균 특징), p2 = 결정나무 부스팅(저수준 38특징), **p = (p1 + p2) / 2** |
| 원본 대조 규칙 | 이미지 12×16 RGB 지문과 DB 지문의 평균 절대차 중 1위 d1, 2위 d2, gap = d2 − d1. **3.5 < d1 < 20 이고 gap > 8 이면 p ← max(p, 0.9)**, 아니면 p 그대로 |
| 사용 값의 결정 근거 | 두 갈래 평균은 교차검증에서 단일 갈래보다 균형 정확도가 높았습니다. 원본 대조 규칙은 공개샘플 가짜 일부의 원본을 AI Hub에서 찾아 비교한 분석(원본은 거의 그대로이거나 일정 정도 변형됨)에서 착안했고, 문턱(3.5·20·8)은 학습 자료에서 측정한 분포로 정했습니다. 원본이 있는 실제 사진의 d1 99분위 3.29(축소·재확대한 실제 대조군은 3.72), 원본 없이 이웃 프레임만 있는 실제 사진의 gap 95분위 8.06이었습니다. 학습 자료 기준 규칙 발동률은 원본 있는 실제 약 0.5%, 원본 없는 실제 약 4%, 가짜 약 13%입니다. 0.9는 규칙 발동 시 가짜로 판정되도록 고정한 값입니다. |
| 결정에 사용한 자료 | 위 학습 자료(AI Hub 실제 + 자체 제작 가짜)와 공개샘플 21장(검증 참고)만 사용했습니다. 평가 자료나 그 통계는 쓰지 않았습니다. |
| 실행 중 갱신 | 없음 (모든 값 고정, 이미지마다 독립 계산) |
| 예외 대체 | 이미지별 고정 규칙: 저수준 특징 계산 실패 → p1만, CLIP 계산 실패 → p2만, 둘 다 실패 → 0.5, 결과가 NaN이면 0.5, 원본 대조 실패 시 규칙 미적용 |
| 임계값 | 별도 임계값 없음 (운영위원회 기준 0.5 그대로) |
| 확률 보정 | 없음 |
| 앙상블 | 위 두 갈래 확률의 산술 평균 1회 (가중치 0.5/0.5 고정) |

## 5. 실행 관련 특이사항
- `load_model(model_dir)` / `predict(model, image_paths)` 계약을 유지했습니다. CLIP 계산도 이미지 1장(9조각)씩 하므로 함께 들어온 이미지나 입력 순서와 무관하게 결과가 같습니다.
- GPU가 있으면 CUDA(fp16)로, 없으면 CPU(fp32)로 동작합니다. 저수준 특징은 CPU 스레드로 병렬 계산합니다. GPU 없이 CPU만으로 실행되면 524장에 5분을 넘길 수 있습니다(ViT-L 계산).
- 실측
  - 자가검증 PASS(공개샘플 21장, 순서 독립성 OK)
  - 525장을 GPU + CPU 2코어로 제한해 47.7초(로딩 포함)
  - T4 기준 5분 이내로 추정합니다.
- 사용 패키지: torch, numpy, pillow(기본), opencv-python, safetensors(추가 허용 목록, `requirements.txt`에 기재). 네트워크 접근·다운로드·설치 코드 없음.
- AI Hub 원본 사진과 파생 이미지는 제출물에 넣지 않았습니다. `fp_db.npz`는 원천 tar 306개의 사진별 12×16 색 평균값(사진당 576바이트)만 담은 파생 통계입니다.
