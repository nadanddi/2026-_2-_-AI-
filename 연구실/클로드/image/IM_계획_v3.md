# IM — 이미지 미션 계획 v3 (2026-10-10 밤, 연구실 클로드)

v2 + v2 재비평(치명 2·중요 5) + 사용자 결정(검증 구조 '1안', 빨간 조명 제외) + 팀원 v5 자료.
**아래 검증·채택 규칙은 v3 평가 결과를 보기 전에 고정한다.**

## 1. 자료
- 실제: AI허브 원본 1,560장 중 빨간 조명 원본 163개를 뺀 1,397장. 사용자 결정이다.
  - 빨간 조명 행은 진단만 한다.
- 프로그램 가짜 v3(`im03c`)
  - 필터는 원본 해상도에서 적용한 뒤 축소한다(팀원 v5와 우리 측정 근거).
  - 배포 처리는 덮게 축소 → 가운데 크롭 → Q92.
  - 색·톤만 바꾼 가짜는 `pstyle_color`로 따로 표시한다.
- SD 가짜(`im07b`): 부분 생성·부분 스타일은 원해상도 타일, 전체 스타일·ai_gen은 축소본에서 생성한다.
  - 빨간 조명 원본과 `tile_whole=1`(2행)은 평가에서 뺀다.
- 리샘플 실제(라벨 0)는 확대된 SD 가짜 수와 **학습 가중 합이 같게** 맞춘다.

## 2. 검증 (사용자 확정 '1안')
### 중심 V2: 공개 21장 (학습 사용 금지)
- 지표: 정확도(0.5), **로그손실**, AUC, 실제 3장 오탐 수, 유형별 맞힌 수.
- 모델은 우리 자료 전체로 학습하고 공개 21장은 예측만 한다.

### 보조 V3: 공개 샘플을 닮은 우리 자료 (OOF 예측)
- 공개 유형과 우리 kind를 이렇게 대응한다.

  | 공개 유형 | 우리 kind |
  |---|---|
  | AI_gen | ai_gen |
  | composite | composite |
  | filter | filter_* |
  | full_style | pstyle_color, full_style_sd |
  | partial_gen | partial_gen_sd |
  | partial_style | partial_style, partial_style_sd |

- 공개 샘플 3장과 CLIP 특징(패치 평균)의 코사인 거리가 가장 가까운 우리 가짜를 유형별 **40장** 고른다.
- 실제는 공개 실제 3장과 가장 가까운 **240장**을 고른다.
- 선택에는 공개 21장의 **특징만** 쓰고 라벨은 유형 대응에만 쓴다. 공개 사진은 학습에 들어가지 않는다.
- 예측은 farm_code 그룹 5폴드의 OOF다.
- 지표는 **균형 정확도** = 0.5×실제 정답률 + 0.5×(공개 6유형 탐지율의 평균). 평가 구성(실제 50%, 6유형)에 맞춘다.

### 시드
- 시드 s ∈ {0, 1, 2}마다 폴드 배정(farm_code 순열), HistGB random_state, 학습 표본 순서를 바꾼다.

### 진단(판정 미사용)
- 빨간 조명 행: 실제 정답률과 그 가짜의 탐지율.
- 전체 OOF 균형 정확도, leave-one-family-out(가짜 탐지율 + 같은 폴드 실제 오탐률).

## 3. 채택 규칙 (후보 vs 현재 기준, 고정)
후보는 아래를 **모두** 만족해야 채택한다.
1. V2 공개 21장
   - 정확도가 기준보다 낮지 않다.
   - 로그손실이 기준보다 낮다.
   - 실제 3장 오탐이 늘지 않는다.
2. V3 보조 균형 정확도
   - 시드 3개 모두 기준보다 높다.
   - **farm_code 군집 부트스트랩**(2,000회) p_worse < .025.
   - 후보가 k개면 .025/k(본페로니).
- 공개 21장 정확도만 오르고 V3가 받쳐 주지 않으면 채택하지 않는다(21장 과적합 방지).

## 4. 오늘 밤 ~ 내일 순서
1. (밤, CPU) 평가 v3 코드를 저수준 특징으로 확인한다. SD 생성은 계속 돈다.
2. (아침, GPU) SD를 멈추고 v3·SD 자료의 CLIP 특징을 뽑는다 → 기준(stack) 확정과 후보 비교 → **중간 비평**.
3. 팀원 v5 진단(우리 실제의 오탐률, 우리 가짜의 탐지율).
4. 패치 CNN 갈래: 팀원 v5 구조(고주파 + ResNet18 + cover/top5)를 우리 v3+SD 자료와 쌍 패치로 재학습. 위 규칙으로 비교한다.
5. 최종 구성 → 최종 비평 → (사용자 지시 시) 제출 패키지.
   - 공개 21장을 최종 학습에 넣을지는 그때 사용자가 결정한다(넣으면 효과 측정 불가).
