# 후보 묶음 E: 해상도·조각 수 (2026-10-12 밤, 결과 보기 전 등록)

근거: B1(224) → B2(336)에서 결합 균형 .896 → .927, 부분 생성 .43 → .63 (백본 비교).
기준: **제출 01 구성 = B2 9조각 + 저수준, 학습 자료 B(v4 + SD2 + 5판)**, L2는 모든 후보에 동일하게 덧씌움.

| ID | 변경(하나만) |
|---|---|
| E1 | B2 조각 9 → **12 (cover 격자: 336 조각으로 사진 전체를 덮으면 3×4=12)**, 조각 평균 |
| E2 | E1 + **좌우 반전 TTA** (조각마다 원본·반전 임베딩 평균) |
| E3 | 백본 **SigLIP SO400M-14-384** (조각 384 3×3) |
| E4 | B2 9조각 + **좌우 반전 TTA** |

평가: 서버, `im05n`과 같은 방식(시드 3개, 같은 농장 폴드, 90% 부분표본 모델로 공개 예측).
- 지표
  - OOF 균형 정확도(전체)
  - 실제 오탐(원본 있음/없음)
  - 유형별 탐지
  - 공개 21장 정확도·로그손실(참고, 이미 여러 번 열람)
- 판정(로컬): 기준 대비 OOF 균형 정확도가 시드 3개 모두 상승 AND 실제 오탐 +1%p 이내 AND 공개 로그손실 비악화 → 다음 제출 후보. 여럿이면 균형 정확도 최고 1개.
- 제약: SigLIP-384는 fp16 약 0.85GB + 지문 DB 80MB → 1GB 경계. 넘으면 지문 DB를 6×8(22MB)로 줄이는 안을 같이 검토한다.
