# IM 후보 H v2 (실행 전 등록 2026-10-15 03:30, v1 미실행)

v1(`IM_유형1to5_H_v1.md`)에 계획 비평(수정 후 진행)을 반영했다.

## 바뀐 점
1. 진짜 확정(rc)된 사진: 전문가 θ를 더 엄격하게 둔다.
   - θ_rc = 진짜 풀 중 rc 사진 점수의 99.9% 분위
   - rc가 아닌 사진은 θ = 99.75% 분위
   - 진짜 풀 오탐은 세 전문가 합집합으로 보고한다.
2. R3는 정밀 대조를 끈 상태(ppre 기준, 참고)도 보고한다. R3 가짜는 AI Hub 원본에서 만들었으므로, 정밀 대조가 이미 잡는 몫과 분리해서 본다.
3. 스타일 참조 사진은 같은 role(htrain/hold) 안에서만 고른다. hold ↔ htrain 누수를 막기 위함이다.
4. cpu·gpu 제작은 manifest를 따로 쓰고 나중에 merge한다. 필터 뒤 크롭은 별도 시드로 뽑는다.
5. 조각 라벨용 마스크는 > .5로 이진화한다(부분 스타일은 페더 값).

## 채택 기준 (모두 만족)
1. R3 균형 정확도 나단6 < H, 묶음 부트스트랩 p_worse < .025, R3 고친 가짜 장수 > 새 진짜 오탐 장수
2. R3 진짜 오탐 증가 ≤ 3장
3. 봉인 진짜 합계(555) 오탐 증가 ≤ 3장
4. 공개 21/21
5. 흔들기 진짜 500 오탐 증가 ≤ 3%p (참고)
6. R2(탐색적) 균형 정확도가 낮아지지 않음
