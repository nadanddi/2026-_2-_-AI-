# IM 후보 G — 진짜 확정 조건 좁히기 (v1, 실행 전 등록 2026-10-15 01:50)

## 배경 (F2 v2 실행 중 확인한 R2 오답 분석)
- 나단6의 진짜 확정 규칙(원본 판정 + 국소·전체 차이 작음 + 나단5 p<.8 → p≤.3)이 필터 가짜를 진짜로 바꾼다.
  - filter_jpeg: 나단5 .979 → 나단6 .793
  - filter_noise: .966 → .919
  - 진짜는 .957 → .983으로 좋아졌다.
- 원인 추정: 진짜 확정 문턱을 정할 때 처리 흔들기(JPEG q70~95 등)를 넓게 잡았다. 그래서 원본 + 압축·잡음 필터가 "처리된 진짜"와 구별되지 않는다.
- 이 분석으로 R2를 이미 봤다. 따라서 이번 결과는 탐색적이다.

## 규칙
- 나단6 진짜 확정 조건에 "필터 점수 s < t"를 추가한다. 가짜 확정과 나머지는 그대로 둔다.
- s 모델
  - 정밀 대조 특징 5개(dg1, loc_g, loc_e, glob_e, |glob_e|)의 로지스틱 회귀(표준화)
  - 학습 자료: im_set_v2·v4에서 R2·봉인과 촬영 묶음(group)이 겹치는 행을 뺀 것 중, 원본 판정되고 가짜 확정이 아닌 행
  - 진짜(real, real_resampled) 대 필터 가짜(filter_jpeg, filter_noise, filter_blur)
- t = 학습 자료 진짜 중 현재 진짜 확정 조건(국소·전체 차이)을 만족하는 사진의 97.5%가 계속 확정되도록 하는 분위.
- 추론 시간 증가 없음(이미 계산하는 특징 5개 + 내적 1번).

## 채택 기준 (탐색적, 모두 만족)
1. R2 균형 정확도 나단6 < G, 묶음 부트스트랩 p_worse < .025
2. 봉인 진짜 합계(real+brown+bright 555장) 오탐 증가 ≤ 3장
3. 흔들기 별도 진짜 500(F v2 보류분) 오탐 증가 ≤ 3%p (흔들기는 운영진 처리보다 가혹하므로 참고 수준)
4. 공개 21/21
5. im_set_h1(묶음 제외) 균형 정확도가 낮아지지 않음
