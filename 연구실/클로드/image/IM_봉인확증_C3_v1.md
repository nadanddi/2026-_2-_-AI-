# 봉인 확증: 나단4(C3) 대 나단1 (2026-10-14 아침, 결과 보기 전 등록)

## 목적
C3 검증은 탐색적이었다(`IM_조합후보_C_해석제한_v1.md`). 이번에는 **한 번도 열지 않은 새 자료**로, 실제 제출 패키지를 그대로 한 번만 채점해 확증한다.

## 비교 대상 (패키지 그대로, `predict` 출력 ≥ .5 = 가짜)
- A = `팜모니_나단1`(제출 01, LB .90)
- C3 = `팜모니_나단4`(나단3과 같은 모델의 속도 개선판)

## 봉인 자료 (`im32_sealed_sets.py`, 두 모델 모두 학습에 쓰지 않음)
- **봉인 진짜 400장:** 새 AI Hub 추출 role=sealed. 학습 쪽과 촬영 묶음이 겹치지 않는 27개 묶음이다. 배포 처리(덮게 축소·크롭·JPEG 92)를 거친다.
- **봉인 Qwen 약 300장:** Qwen-Image-Edit 지시문 편집 700장 중 id crc32 % 7 < 3. 종류별로 섞이고 배포 처리를 거친다. GPT·SD와 다른 새 생성기다.
- **봉인 7판 약 150장:** SDXL/SD1.5 되붙임 국소 편집 400장 중 파일 crc32 % 8 < 3(마스크 10~30%).
- 나머지 Qwen·7판·진짜는 개선판 학습용으로 남기고, 이번 판정에는 쓰지 않는다.

## 판정 (한 번만 실행)
1. **진짜 오탐 비열등:** C3 오탐(봉인 진짜) ≤ A + .01
2. **가짜 탐지 우월:** C3 탐지(Qwen ∪ 7판) ≥ A + .05
3. **추정 정확도** = .5 × (1 − 오탐) + .5 × 탐지(Qwen ∪ 7판)
   - C3 > A
   - 촬영 묶음 단위 부트스트랩(2000회) 차의 p_worse < .025
- 셋 다 만족하면 **확증 통과** → 오늘 22:00 나단4 제출 근거로 쓴다.
- 하나라도 못 미치면 원인을 보고하고, 나단1 재제출을 포함해 사용자와 결정한다.
