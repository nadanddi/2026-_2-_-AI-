## 1. 문제 요약 (공식 문서 직접 읽음)
- 실제 촬영(0) vs 생성·변형(1) 이진 분류. 평가 524장 = 실제 262 + 생성 262(6유형 → 유형당 약 44장으로 추정, 문서에 유형 비율은 없음).
- 판정 0.5 고정, Accuracy. 제출 = inference.py + model/(≤1GB) + README. T4에서 524장 5분 이내, 오프라인.
- 학습자료 자유(권리 있는 공개 데이터, 생성형 AI, 사전학습 모델 허용). README에 출처 기재. 최종 검증 때 학습 원본 이미지 제출.
- 평가 입력 통계로 판정 기준 조정 금지(10-05 안내) → 임계값·보정은 학습 자료로 정하고 README에 적음.
- 공개 21장의 실제 사진은 AI허브 '지능형 수직농장 통합 데이터(딸기)'와 같은 시설(포트 라벨 "B02_001" 등). 전체 생성 예시는 다른 온실 장면.

## 2. 핵심 가설
1. **배포 파이프라인 일치가 가장 중요.** 평가의 실제 사진은 AI허브 원본 → 크롭·크기 조정(1024×768) → JPEG 저장. 우리 학습 실제 사진도 같은 처리를 해야 모델이 '처리 흔적'을 라벨로 배우지 않는다. 생성 사진도 같은 마지막 처리를 거친다.
2. 유형마다 신호가 다르다.
   - 지정 필터·부분 변형: 저수준(잡음 잔차, 이중 JPEG, 선명도) 신호
   - 전체 생성·스타일 변환: 의미/질감 신호 → CLIP 같은 사전학습 특징이 일반화에 강하다(UnivFD 계열, 일반 지식)
3. 그래서 **CLIP 전역 특징 + 저수준 패치 특징**을 합친 판별기가 단일 ResNet18보다 유형 전반에 강할 것이다(검증 필요).

## 3. 자료
- 실제: AI허브 원천(G: Drive의 TS tar). 농장·개체 단위로 학습/검증을 나눔.
- 생성(우리가 제작, 실제 원본과 분리된 원본에서):
  - 필터: 가우시안 블러, 가우시안 잡음, 소금·후추, JPEG 품질 변경(강도 범위 무작위)
  - 합성: 식물 영역(녹색 마스크)을 다른 배경 사진·흰 배경에 붙임
  - 전체 스타일: OpenCV 스타일화·유화·색 양자화 등 + (가능하면) 확산 모델 img2img
  - 부분 스타일: 위 스타일을 마스크 영역에만
  - 부분 생성: 확산 인페인팅(가능하면) / cv2 inpaint 대용
  - 전체 생성: 확산 모델 txt2img(연구실 GPU 1050Ti 4GB라 소량)
- 공개 21장: **학습에 쓰지 않음.** 최종 외부 점검용으로만 사용(유형당 3장이라 판정 근거가 아니라 큰 실패 감지용).

## 4. 검증 (실행 전 고정)
- 주 검증기 V1: 실제·생성 모두 **원본 농장/개체가 학습과 겹치지 않는** 홀드아웃. 유형별 정확도와 전체 정확도(실제:생성 = 1:1로 맞춤, 생성은 6유형 균등).
- 보조 점검 V2: 공개 21장(학습 미사용). 실제 3장 오탐 0 + 생성 18장 중 탐지 수를 서술.
- 채택 규칙: 후보가 기준보다 V1 전체 정확도에서 시드 3개 모두 높고, 이미지 단위 부트스트랩 p_worse < 0.025. V2에서 기준보다 많이 틀리면 보류(서술).
- 한계: V1의 생성 이미지는 우리가 만든 것이라 평가의 생성기와 다르다 → V1 점수는 낙관적. 리더보드 제출은 사용자 결정(가설 검정용 제출 허용, 규칙 5 해석).

## 5. 첫 단계
1. 환경: `연구실/클로드/local/venv_img`(torch cu121, open_clip 등). 공용 환경 무변경.
2. 공개 21장 파일 특성(JPEG 양자화표, 크기, EXIF) 확인 → 배포 파이프라인 추정.
3. AI허브 실제 원본 소량(농장별) 추출 → 파이프라인 재현 → 필터·합성·스타일 자동 생성 → CLIP 선형 판별기 기준선 B0.
4. 비평(계획·중간·최종) 각 단계에서 실시.
