# IM 후보 I' — GPT 재그리기 전문가 (실행 전 등록 2026-10-15 18:05)

## 배경
- 후보 I는 SDXL 대리 재그리기로 학습했지만 GPT 재그리기(gpt3_s1)로 일반화하지 못해 기각됐다.
- 연구실 코덱스가 GPT 이미지 생성으로 itrain 원본(R4와 묶음 분리)의 "전체 재그리기" 약 162장을 만들었다(`연구실/코덱스/local/gpt_regen_20261015/`).

## 구성 = 나단8 + E_gr 하나
- E_gr: 표준화 + 로지스틱. 입력은 저수준 38 + L/14 조각평균 임베딩 768
  - 양성 = GPT 재그리기 학습 절반
  - 음성 = h3 진짜 1,800 + 흔들기 진짜 1,800, 균형 가중
- 자료 처리: GPT PNG를 배포 처리(dist_cover → 768×1024 → JPEG Q92)한다. im21c와 같은 방식이다.
- 분할: 원본 촬영 묶음(group) 단위로 나눈다. 학습 절반 / 확인 절반(GT-hold). (결과 전 수정: crc 짝/홀로는 5묶음이 모두 학습 쪽이라, 큰 묶음부터 장수가 적은 쪽에 배정)
- 다른 전문가(E_f·E_ps2·E_g7 = 나단8)와 형식 게이트는 그대로 둔다. 후보 I의 E_g7 재학습·E_rg는 쓰지 않는다(기각).
- θ_gr: 진짜 풀(h3·흔들기 OOF + newreal·realg·realn, N≈4995)에서 0.25%(진짜 확정 0.1%)부터 시작한다.
  - 네 전문가 합집합 진짜 오탐이 0.5%를 넘으면 0.15% → 0.1% → 0.05%로 조인다.
  - 그래도 넘으면 불채택한다.

## 채택 기준 (모두)
1. GT-hold(학습 미사용 GPT 재그리기 절반) 탐지율이 나단8보다 높고, +5장 이상
2. gpt3_s1(GPT v3, 다른 시기·다른 원본, 50장) 탐지율이 나단8(.820)보다 높다
3. 진짜 오탐 증가
   - R4 진짜 355(이번에 1회 개봉) ≤ 2장
   - R3 진짜 ≤ 2장
   - 봉인 진짜 750 ≤ 2장
   - jig500 ≤ 2장
4. R4 가짜 7종 각각의 탐지 장수가 나단8보다 줄지 않고, R4 균형 정확도 ≥ 나단8 (R4에는 GPT가 없으므로 무손해 확인)
5. 공개 21/21
