## 분할 수정 (`im34b_make_c3v2_sets.py`)
1. **갈변·밝음 후보는 촬영 묶음 단위로 나눈다**(group crc32 % 2 == 0 학습, == 1 판정). 파일 단위로 나누면 이웃 프레임이 양쪽에 들어간다.
2. **봉인 Qwen·봉인 7판이 쓴 원본(AI Hub 파일)을 쓴 사진은 학습에서 뺀다**(Qwen·7판이 원본 약 100장을 공유해 교차 누수가 생긴다).

## 판정 (봉인 자료 두 번째 열람 — 개선 표적을 그 자료의 진단에서 골랐으므로 **탐색적**)
패키지마다 **별도 프로세스**로 실행한다. 차이의 촬영 묶음 단위 짝 부트스트랩 p_worse(2000회)를 함께 본다.
1. 판정용 밝음 진짜(학습 안 한 묶음) 오탐: 나단5 ≤ 나단4
2. 판정용 갈변 진짜 오탐: 나단5 ≤ 나단4 + .01
3. 봉인 진짜 400 오탐: 나단5 ≤ 나단4 + .005
4. 봉인 7판 140 탐지: 나단5 ≥ 나단4 + .03 **그리고** p_worse < .05
5. 봉인 Qwen 291 탐지: 나단5 ≥ 나단4 − .01
- 모두 만족하면 '탐색적 후보' → self_check + Colab T4 실측(사용자) 270초 이하면 10/15 회차 후보(사용자 결정).
