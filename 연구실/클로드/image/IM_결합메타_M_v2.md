## 구성
- m = 표준화 + 로지스틱(C = 1, balanced). 입력 4개 = logit(E_f), logit(E_ps2), logit(E_g7), logit(E_gr)(OOF 점수로 학습).
- 메타 학습 자료: h3 + h3j(흔들기 진짜) + h3s(작은 부분 생성) + h3g(SDXL 재그리기) + gptr·gptr_src 학습 절반. 형식 게이트 안·ok만.
- θ_m: 진짜 풀 = (학습 자료 진짜의 메타 OOF m: 폴드마다 메타를 다른 폴드로 학습) + (newreal·realg·realn에 배포 m). 99.75% 분위, 진짜 확정 행은 99.9%.
- 합집합 예산: 나단9 전문가 4개 + m 중 하나라도 발동하는 진짜 비율 ≤ 0.5%. 넘으면 .0015 → .001 → .0005 순으로 조이고, 그래도 넘으면 불채택.
- 게이트 밖: p6(나단9와 같음).
- 분포 점검(고정 규칙): newreal·realg·realn에서 전문가별로 배포 모델과 폴드 모델(5개 평균) logit 점수의 99%·99.75% 분위를 비교한다. 차이가 하나라도 logit 0.3을 넘으면 → 메타 입력에 배포 모델 대신 폴드 모델 5개 평균 점수를 쓴다(패키지에 폴드 모델 포함).

## 탐색 지표 (R5 열기 전, 모두 통과해야 연다)
- G1 R2 균형 정확도 ≥ 나단9 (구조상 가짜 손실은 0)
- G2 R3·R4 각각 균형 정확도 ≥ 나단9
- G3 진짜 오탐: 봉인 진짜 3종 새 오탐 합 ≤ 2 · jig500 ≤ 나단9 + 1%p · R3 처리 sharp·area(게이트 안인 두 종만 셈) ≤ 나단9 + 1%p · 공개 21/21 · gptr 짝 진짜 확인 절반 새 오탐 ≤ 1
- G5 원본 제외 시뮬레이션(진짜 풀 newreal·realg·realn·jig500·봉인 진짜): rc = 0, p6 대신 ppre로 놓고 계산한 진짜 오탐률이 나단9 시뮬레이션 + 0.5%p 이하
- 참고(판정 아님): 학습 자료 안 메타 OOF, gpt3·gpt1·sd2·qwen·v7 탐지 변화
