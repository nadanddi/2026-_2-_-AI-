# IM — 이미지 미션 계획 v2 (2026-10-10 밤, 연구실 클로드)

v1(`IM_계획_v1.md`) → 계획 비평(치명3·중요5·경미6) 반영 + 사용자 결정 반영. **결합 평가 결과를 보기 전에 고정.**

## 1. v1 이후 사실
- B0(CLIP L/14 + 로지스틱, 만화풍 가짜 v1): 농장 CV .95, 공개 21장 13/21. 부분 생성 0/3. → 낙관 CV, 가짜 분포 불일치 확인.
- 저수준 손특징만(v2 자료): 공개 21장 15/21(AI_gen 3/3, 필터 3/3, 합성 0/3). CLIP과 상보적.
- 실제 원본 1,560장 중 163장(10%)은 빨간 조명.
  - **사용자 결정(10-10): 학습에서 제외.** 근거는 공개 샘플 중 사진 기반 15장에 빨간 조명이 0장이라는 점이다.
  - 제외한 모델로 빨간 실제와 그 가짜를 예측해 진단만 한다.

## 2. 비평 반영 (v2 자료·코드)
| 비평 | 반영 |
|---|---|
| C1 만화풍 가짜 ≠ 평가의 사진풍 변형 | 프로그램 스타일 = LAB 색 전이·톤·CLAHE·약한 디테일/평활(만화·양자화 삭제). SD 스타일 = 사진풍·화풍 반반, 사진풍 strength .2~.45 |
| C2 SD 가짜만 확대 흔적 | 부분 생성·부분 스타일 = 원해상도 512 타일 제자리 합성(확대 없음). 전체 스타일·ai_gen은 확대 → 실제 25%에 리샘플 대조군(라벨0) |
| C3 빨간 조명 제외 위험 | 사용자 결정으로 제외. 진단 행으로 위험을 측정한다 |
| I1 합성 조잡 | 다른 실제의 식물 덩어리 붙여넣기(색 맞춤·페더), 흐린·탈색 배경 교체(bpem형), 여백 10%로 축소 |
| I2 cv2 inpaint 지름길 | 삭제 → SD 인페인팅 |
| I3 0.5 과신 | 클래스 가중 균형. 임계값은 0.5 고정. 아래 V1b로 미탐 경향을 측정 |
| I4 검증 | V1b leave-one-family-out 추가, ai_gen GEN0~4 분산, composite 배경 같은 농장 안 |
| I5 CLIP 224 한계 | 저수준 손특징 갈래(im06) 추가. 패치 CNN 갈래는 다음 단계 |

## 3. 고정한 평가 (im05b_eval_v2.py)
- V1: farm_code GroupKFold(5). 빨간 조명 원본 행 제외.
- V1b: 가짜 계열 하나를 학습에서 빼고 그 계열 탐지율을 본다(처음 보는 제작 방식 일반화).
- V2: 공개 21장(학습 미사용).
- 진단: 빨간 조명 행.
- 모델: clip(로지스틱 C=.05, 패치 평균 P), low(HistGB), stack(두 확률 평균).

## 4. 채택 규칙 (후보 비교용, 실행 전 고정)
- 새 후보는 현재 최선 대비 V1 정확도에서 시드 3개 모두 같은 방향이어야 한다. 이미지 단위 부트스트랩 p_worse < .025.
- **그리고** V1b 평균 탐지율이 나빠지지 않아야 한다.
- **그리고** 공개 21장에서 실제 3장 오탐이 늘지 않아야 한다.
- 공개 21장 정확도는 표본이 작아 순위 근거로 쓰지 않는다. 큰 실패(유형 전멸, 실제 오탐) 감지에만 쓴다.
