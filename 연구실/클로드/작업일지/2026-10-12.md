# 2026-10-12 · 연구실 · 클로드 (이미지 미션)

## 한 줄
리더보드 상위 팀(0.91~1.00)과의 차이를 보고 원본 대조 가설을 확인했고, 연구실 GPU 서버를 연결해 백본 비교와 가짜 제작 5판을 진행했다. **B2(CLIP L/14@336) + 5판 + L2 원본 대조**로 이미지 첫 제출(팜모니_나단1)을 올렸다(R14 대상).

## 한 것
- 리더보드(사용자 제공): ANEI 1.00, 2·3위 .98, 팜모니 .77(10위). 팀원 v7도 .77.
- **원본 대조 가설**
  - 공개 21장을 AI허브 152,043장 지문 DB(`im11`, 12×16 RGB, tar 306개)와 대조했다(`im10`·`im12`).
  - 실제 2/3은 원본과 거의 같았다(지문 차 1.4, 원해상도 1.75~1.95). ovvx는 원본이 없었다.
  - 가짜 5장(bpem·yuag·ttmn·uexm·xeeo)은 원본은 있었지만 변형돼 있었다(d1 4~16, 간격 5~12).
  - 원본 비교로 운영진 변형 방식을 측정했다: 합성 = 잎·포기 오려 붙이기, 블러 = 배포 크기 σ≈1.5, 부분 생성 = 사진 전체 약한 재표현 + 일부 재생성, 스타일 = 구도 유지 재표현.
- **L1/L2**(`im13`·`im14`·`im05i`·`im05l`)
  - L1(학습형 결합)은 원본 없는 실제 오탐이 19~20%라 불채택.
  - L2(좁은 규칙: 3.5<d1<20, 간격>8 → p≥.9)는 균형 정확도 +.002~.003, 원본 없는 실제 오탐 +4%p라 사전 규칙상 불채택.
- **연구실 GPU 서버(ADILAB, RTX 6000 Ada ×2) 연결**
  - 사용자가 SSH 키를 등록했다. 관리자 규칙은 메모리 `lab-gpu-server-rules`에 기록했다.
  - nadan 환경 구성, 자료 13GB 전송, GPU 0번만 사용. 시작 전 nvidia-smi로 확인하되, 우리 작업 메모리는 다른 사람 사용량에서 뺀다.
- **백본 비교**(`im16`·`im05k`, `IM_백본비교_v1.md`)
  - 순위: **B2 CLIP L/14@336 .927**(실제 오탐 2.7%) > B6 ConvNeXt-CLIP .913(공개 약함) > B1 .896 > EVA02·SigLIP·DINOv2·OpenCLIP-LAION.
  - 2개 앙상블은 모두 B2 단독 이하였다.
- **가짜 제작 5판**(`im15`, 서버): 블러 400, 합성 5b(잎 단위) 808, SDXL 전체 생성·전체 스타일·부분 스타일·부분 생성 각 900.
  - 합성 첫판은 직선 경계 문제로 제외했다.
- **5판 비교**(`im05m`, B2)
  - B(기존 + 5판) 공개 20/19/18, 로그손실 .33~.39 (A 17/18/16, .38~.45).
  - 실제 오탐 +1~2%p라 사전 규칙상 로컬 불채택 → 리더보드 후보.
- **B + L2**(`im05n`)
  - 공개 21/21/20, 로그손실 .24~.29. ttmn·uexm을 규칙이 잡았다.
  - 원본 없는 실제 오탐 6.8~8.1%.
- **팀원 v7 비교**(`im08b`, 같은 R2 보류 자료)
  - 균형 정확도 v7 .783(리더보드 .77과 비슷) 대 우리 .94.
  - 우리 방식 가짜라 우리 쪽에 유리한 비교다.
- **부분 스타일 진단**(`im08c`): 면적이 작거나 변형이 약하면 놓친다. 색만 바꾼 변형은 질감 변형보다 어렵다.
- **제출(사용자 '제출해보자')**: 구성 ② B2 + 5판 + L2
  - 최종 학습·내보내기 `im20`. 제출 코드 `image/submit_img01/`. vit.py는 순수 torch로 작성했고 open_clip과 차이 0.
