# 2026-10-08 · 연구실 · 클로드 (EC)

## 한 줄
사용자 지시("새 특징 말고 데이터와 검증을 먼저 의심")로 검증기 수준, 라벨 이상, 입력 변화폭, CO₂ 거친 날, 실내 센서 불일치를 진단했다. 거친 날의 가중치를 낮추는 RW1을 시험했는데 FAIL이었다. 모든 실험은 계획·중간·최종 비평을 거쳤다.

## 한 것 (카탈로그 6.435~6.439)
- **DV** (6.435): 검증 수준과 리더보드의 관계, 가림 범위 쌍대 비교, 라벨 이상 점수.
  - 계획 v1의 "검증이 평가보다 2배 비관" 주장은 철회했다.
  - 2차 RMSE: P2LOO .195 [.135, .246]. 리더보드와는 판별 불가.
  - 판정은 2~3일(F47_231·F13_217·F13_243)에 걸려 있다.
  - 고EC 라벨 오류 증거는 없다. S4 단절은 출처 전환과 같은 날에 일어난다.
- **HC1/HC1b** (6.436): 시간당 변화폭(사용자 요청).
  - 평가와 학습 2차의 변화폭은 같은 과정으로 보인다(계절을 맞추면 본페로니를 넘는 변수 0개).
  - 구동기만 학습 쪽에 가공된 흔적은 없다.
- **CO2R** (6.437): CO₂ 거친 날을 다시 확인했다(사용자 질문 "21.6 대 4.8").
  - 중앙값 21 대 4이고, 학습 1차 10%·2차 16%·평가 0~1일이다. F47에서 연속 구간으로 나타나며, 잡음형이다.
  - 검증 오차와 연결된다는 주장은 교란이었다(F47_229·231 고EC 밀폐 날 때문).
- **SM1/SM2** (6.438): "실내 입력이 정답과 다른 센서" 가설(사용자).
  - 실내–배지 결합 약화, 수준 차, 온습도 상관 약화는 실재한다.
  - 다른 기록을 복사한 날은 아니다(평균 절대차 < .2℃ 0일).
  - 환기 대안은 지지되지 않는다.
  - 같은 센서의 느린 교란인지 다른 센서인지는 판별 불가다.
- **RW1** (6.439): 거친 날 30일의 학습 가중치를 0.2로 낮춤 → **FAIL**.
  - DIAG10·A·B 모든 시드가 1.3~3.5% 악화했다(거친 날을 빼고 채점해도 같다). 주로 ET에서 악화했다.
  - 부풀림 진단: 검출되지 않았다(검정력 제한). A·B에서는 거친 날이 오히려 쉽다.

## 비평에서 배운 것
- 층을 다시 가중하면 꼬리가 부풀려진다.
- 리더보드로 층별 상한을 정하는 것은 금지(규정 위험).
- 흰잡음 시뮬레이션은 허수아비 반증이다.
- 연속 구간인 날들은 서로 독립이 아니다.
- 허용범위를 상대 ±25%로 잡으면 제약이 되지 않는다.
- 오차로 날을 고른 뒤 라벨을 의심하면 회귀 효과가 생긴다.
