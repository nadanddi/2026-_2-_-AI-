# MP1 — 평가 덩어리 양쪽 고정 보간 (계획 v1, 2026-10-07 연구실 클로드)

## 1. 근거 (전제 검산, 출처 완벽 가정 상한)
- **MP0:** 정답 사슬(CH2 1:1, EC 점프 < .05; 사슬 19개, 다른 ID 연결 104) 위에서 앞날 정답 23시 하나에서 모델의 하루 안 변화로 전파했다.
  - 1단계 .067, 2단계 .118, 3단계 .157 (모델 .17/.17/.15).
  - 수준은 하루 단위로 빠르게 흩어진다.
- **MP0b:** 길이 L 구간을 가리고 앞 노드 EC23·뒤 노드 EC0에서 각각 전파한 뒤 위치 가중으로 보간했다(양쪽).
  - L=5: 모델 .128 → **.065** (2차 .147 → .062, 일반 .122 → .060, 고EC .230 → .136)
  - L=3: .057, L=7: .080
- **운영진 (6.388):** 외부 자료 없이 최상위인 팀이 있다.

## 2. 실제로 풀어야 할 것: 출처 식별
덩어리를 지나가는 출처마다 다음 세 가지가 필요하다.
- (a) 덩어리 앞 마지막 정답 노드 = 사슬 '끝'
- (b) 덩어리 뒤 첫 정답 노드 = 사슬 '시작'
- (c) 덩어리 안 각 평가 기록이 어느 출처인지, 그리고 그 출처 안에서 몇 번째 날인지

## 3. 0단계 — 실제 조건 모의 (이번 실행 범위)
**가림 (평가 배치 흉내)**
- 정답 기록에서 같은 ID 연속 L=5 기록을 덩어리로 정한다.
- 같은 날짜 묶음의 다른 ID 기록도 함께 가린다(평가 덩어리는 두 ID가 같은 날짜).
- 덩어리 양옆 1기록(+그 날짜 묶음)은 '없음'(빈칸)으로 지운다.
- 덩어리 시작 위치는 정답 기록 전체에서 겹치지 않게 순서대로 잡는다.

**단계 A (학습 자료만)**
- 남은 정답 기록으로 CH2 사슬을 만든다.
- 가린 구간 직전 날짜의 사슬 끝들(E)과 직후 날짜의 사슬 시작들(S)을 모은다.
- 날짜는 학습 기록 외기 쌍둥이 묶음과 1차 순서로 정한다.

**단계 B (학습 자료만)**
- E와 S를 헝가리안으로 짝짓는다.
- 비용 = ((EC23(e) − EC0(s)) / (.07·√(span+1)))² + 운영 서명 차.
  - .07은 MP0의 1단계 표준 이동 폭이다.
  - span은 가린 날짜 수다.
  - 운영 서명 = 실내 밤 온도·CO2·구동기 하루 평균의 표준화 거리.

**단계 C (가린 기록 b: 자기 0시·1시 입력 + 같은 ID 앞번호 가린 기록 입력만)**
- b의 날짜 위치: 같은 ID 덩어리 안 순서와 외기 쌍둥이(같은 날짜 짝)로 정한다. 날짜 i = 1..span.
- b의 출처: i=1이면 E 중 0시 비용 최소, i>1이면 같은 ID 앞번호 가린 기록 중 0시 비용 최소를 따라간다(그 기록의 출처를 상속).
- 1:1 소비는 같은 ID 앞번호 기록끼리만 한다.

**추정**
- 출처의 (e, s) 짝에서 위치 i의 양쪽 보간(MP0b 식)을 쓴다.
- 짝이 없으면 앞쪽 전파 + 혼합 가중(MP0b), 그것도 없으면 모델.

**비교**
- 같은 기록의 모델(DIAG10 OOF R3S+DP1) 하루 평균.

**판정 (0단계 관문, 고정)**
- 2차 가린 기록에서 하루 수준 RMSE가 모델보다 낮을 것.
- 덩어리 단위 부트스트랩 P(worse) < .025.
- 함께 보고: 단계 A·B·C 각각의 정답 대비 정확도, 전체 기록, 일반 날·고EC 날.
- 통과하면 1단계(시각별 인과, SG2·제출 구성 위, 검증기 9칸)로 다시 사전 고정한다.

## 4. 규정
- 학습 자료(두 ID, 덩어리 뒤 날짜 정답·입력)를 참조한다. 2절 '학습 자료 저장·참조, 시점 제한 없음'에 근거하며, 7절 문의가 필요하다.
- 평가 행 b가 쓰는 입력: 자기 0..h시, 같은 ID 앞번호 평가 기록.
- 다른 ID 평가 입력은 쓰지 않는다.
- 평가 입력으로 무언가를 학습·갱신하지 않는다.

## 5. 위험
- 사슬 끝·시작이 가림 때문에 헝가리안이 다른 연결로 메울 수 있다(DT2 비평 6.377).
- 고EC 상태가 가린 구간 안에서 시작·끝나면 양쪽 보간이 틀린다.
- 0단계는 덩어리 단위가 기본이다. 2차 기록만으로는 n이 작다.
