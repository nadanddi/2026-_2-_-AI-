# RF2 — 운영 지문 기반 시각별 인과 '하루 잔차 보정기' (계획 v1, 2026-10-07 연구실 클로드)

## 1. 근거 (전제 검산)
- **RF0b:** 원래 운영 지문(하루 전체) ExtraTrees가 DIAG10 OOF(R3S+DP1) 하루 잔차를 교차적합 R² .172로 설명한다(2차 −18%). 단 하루 전체 지문이라 미래 시각을 포함한다.
- **RF1(`code/ec_rf1_causal_day_residual_premise_v1.py`):** 시각별 인과판이다.
  - h시 행 특징: 0..h시 구동기 누적평균·0비율, 실내·외기 누적평균, h
  - 목표: 그날 하루 잔차
  - 모델: ExtraTrees(300, leaf 20, max_features .5)
  - 교차적합: 날짜 묶음 5분할
  - 결과(시드 3 모두 같은 방향): 전체 −7%, 2차 −12%, 2차 일반 −2%, 고EC −12%. 효과는 12~23시에 집중(−12%)되고 0~4시는 −0.5%.
- 비슷한 기존 시도: TS1(6.182, 2단계 하루 평균 보정)은 근소 불합격이었다. 차이는 입력이 운영 지문·외기 누적이고 목표가 하루 잔차라는 점이다(TS1 입력 확인 필요).

## 2. 방법 (고정)
**기준 예측**
- 9회차 근사 구성 = CUR(0.8 R3_DP1 + 0.2 PFN, WT1 OOF 시드 47/1414/6464).
- 2차 행은 SG2 적용 후 값을 쓴다(RV2 preds의 sg).
- DIAG10은 360일 전체가 있다(1차 행은 CUR, 2차 행은 CUR+SG2).

**보정기 학습**
- 기준 예측의 OOF 하루 잔차(y_day − p_day, 학습 정답)를 목표로 RF1과 같은 특징·모델을 쓴다.
- 보정: pred_h = p_h + r̂_h.

**검증 (보정기 교차적합 폴드는 아래 각 검증 배치의 폴드와 맞춤)**
- V-a. DIAG10: 폴드 = DIAG10 폴드. 그 폴드 날은 보정기 학습에서 빼고, ±1 기록일도 뺀다.
- V-b. 연속 블록: 같은 ID 연속 10기록 블록, 블록 단위 10분할, ±1 기록일 제외. 실제 평가 덩어리를 흉내 낸다.
- V-c. P2LOO·EL1 (2차 행): 해당 폴드 날과 ±1을 보정기 학습에서 뺀다. 기준은 각 검증기의 CUR+SG2.

**판정 (고정)**
- (a) 시드 3 × {V-a 2차, V-b 2차, P2LOO, EL1} 12칸 모두 2차 시간 RMSE 개선
- (b) 같은 칸에서 2차 일반 날 악화 ≤ 1%
- (c) V-a DIAG10 전체(1·2차) 시드 3 모두 개선
- (d) DIAG10 2차 온실×5기록 묶음 부트스트랩 P(worse) < .025
- 함께 보고: 시각대별, 고EC, 바뀐 정도, 기여 특징(중요도)

## 3. 규정
- 평가 행 특징은 같은 온실의 현재 기록 0..h시 입력만 쓴다(외기·실내·구동기 누적).
- 보정기는 학습 자료(입력+정답)로만 학습한다. 평가 입력으로는 학습·갱신하지 않는다.
- MASK: 대상 온실 학습 행과 평가 행의 특징 정의가 같고, 특징에 쓰는 열은 평가에도 존재한다(in_rad 등 전부 결측 열은 쓰지 않음).

## 4. 위험
- 보정기가 날씨 누적으로 '달력 근처 날의 잔차'를 기억해 이웃 날 정답에 기대는 효과일 수 있다. 실제 평가 덩어리 안에서는 그 이웃이 없다 → V-b로 확인한다.
- 기준 모델과 같은 정보(지문 특징이 이미 R3 입력에 있음)의 재사용일 수 있다 → 효과가 오후 시간에 몰린 점이 '하루 수준을 직접 목표로 학습한 효과'인지 확인이 필요하다.
