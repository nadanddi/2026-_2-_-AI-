# TO1 — 평가 전용 날짜 기록의 같은 출처 앞날 찾기: 정확도 관문 (계획 v1, 2026-10-07 연구실 클로드)

## 1. 왜
- 격자 배제법(GX3, 6.384)은 같은 날짜에 정답 기록이 3개 있는 깨끗한 경우에만 작동한다. 실제 평가에서는 8개만 결정됐다.
- 평가 60 중 15개는 같은 날짜(외기 쌍둥이)에 정답 기록이 하나도 없는 '평가 전용 날짜'다. 그래서 배제법이 불가능하다.
- C3(1차에 없는 날짜) 기록은 SG2 2차 오차의 61~70%를 차지하고(6.375), 평가에 25개 있다.
- 0시 수준을 알면 2차 행 RMSE가 .258 → .091이 된다(6.376 상한, 구성상 결과이므로 참고만).

## 2. 방법 (이번 범위 = 정확도 관문만, 수준 보정·SG2 비교 없음)
**가림 (학습 데이터로 평가 전용 날짜 모의)**
- 정답 기록 b마다 b의 날짜 묶음 전체(두 ID의 같은 날짜 기록 모두)를 '정답·입력 없음'으로 가린다. b 자신의 입력은 쓴다.
- 실제 평가 60도 정답 없음으로 둔다.

**후보 앞날**
- 보이는 정답 기록 중 b의 묶음이 아닌 것.

**1단계: 날짜**
- 후보 날짜 묶음마다 외기 날짜 비용을 계산한다.
  - 비용 = 묶음 대표 기록 23시·22시 → b의 0시·1시 외기 점프, 추세 보정, 표준화 제곱합 가중 1/1/.3/1.
  - 대표 = 그 묶음 정답 기록 중 외기 결측이 없는 첫 기록. 외기는 묶음 안에서 같다.
- 최소 비용 묶음 P를 고른다.

**2단계: 기록**
- P의 정답 기록 중 b 0시 실내(온·습·CO2) 점프 비용이 최소인 것을 a*로 고른다.

**결정 조건 (실행 전 고정, 사후 조정 금지)**
- 날짜 비용 2위 − 1위 ≥ 1.0
- 기록 비용 2위 − 1위 ≥ 0.5 (P 정답이 1개면 이 조건 없음)
- 결측이 있으면 결정하지 않는다.

**적중**
- |EC0(b) − EC23(a*)| < .05. 비순환 기준이다(선택에 EC를 쓰지 않음).
- 무작위 대조: P의 임의 정답 기록, 그리고 외기 2위 묶음에서 같은 방식으로 고른 기록.

**보고**
- 전체 정답 기록 400에 대한 적중을 낸다.
- 다음 하위집단별로 따로 낸다.
  - 2차 기록
  - 실제로 C3인 기록
  - 평가 전용 날짜와 닮은 기록(같은 날짜 묶음 크기가 작은 것)

## 3. 관문 (고정)
- 2차 정답 기록(56)에서 결정된 기록의 적중 Wilson 95% 하한 ≥ .90, 결정 ≥ 15 → 2단계(수준 보정 실험) 설계로 간다.
- 미달이면 종료한다.
- 전체 400의 적중은 보조로 보고한다.

## 4. 규정
- b 쪽: 자기 0·1시 외기·실내만 쓴다(5시 이후 행 적용 예정이라 시간 규칙 충족).
- 후보 쪽: 학습 자료(두 ID, 앞뒤 날짜 포함)다.
- 같은 ID 앞번호 평가 기록은 이번 관문에서 쓰지 않는다.
- 평가 입력으로 무언가를 학습·갱신하지 않는다.
- 실제 사용 전에는 운영위 7절 문의가 필요하다.

## 5. 이전 기록
- CH4(6.348): 날짜 묶음 적중 37%. 정답 사슬과 폴드 가림 조건이었다.
- DT1 v2(6.375): 외기만으로 진짜 앞날 날짜 1위 약 55%. 다만 진짜 정의에 외기가 들어가 부풀려졌다(6.376).
- 이번 차이:
  - 결정 조건(비용 여유)으로 확신 있는 경우만 골라 정확도를 본다.
  - 적중을 비순환 기준으로 잰다.
