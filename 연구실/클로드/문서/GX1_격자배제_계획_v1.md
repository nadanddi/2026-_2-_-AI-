# GX1 — 출처 4 × 날짜 128 격자 배제법 (계획 v1, 2026-10-07 연구실 클로드)

## 1. 근거
**구조 (6.378)**
- F13·F47의 460 기록은 날짜 묶음 128개(외기 완전 쌍둥이)로 나뉜다.
- 묶음 크기 4가 82개(F13 2 + F47 2), 3이 42개다. 즉 출처 4 × 약 128일 격자이고, 출처는 ID를 넘나든다.

**평가 60의 같은 날짜 묶음**
- 나머지가 모두 정답 기록: 27
- 평가 2개 묶음: 12
- 전부 평가: 14
- 기타: 7

**GX0 전제 검산** (`code/ec_gx0_grid_exclusion_premise_v1.py`; 가린 기록 b의 정답·입력 미사용, 날짜 묶음 판정용 외기만 사용)
- 전날 묶음 P 찾기: 같은 날 다른 정답 기록들의 CH2 비용 최소 앞 기록이 속한 묶음 중 최빈값.
- 배제: P 정답 기록과 G\{b} 정답 기록을 헝가리안으로 짝짓고, 짝 없는 1개를 b의 앞날로 본다. 다음날도 대칭으로 한다.
- 결과
  - 결정된 날 전날 38 / 다음날 30, 적중 .74 / .80
  - 추정 있는 33일 하루 RMSE .083 vs SG2 .179/.209/.258 (일반 31일 .085 vs .089/.197/.096)
  - 가짜 대조(짝 있는 기록) .417
- 한계: b 하나만 가렸다(낙관적). C3는 3일만 포함.

## 2. 방법 (고정)
**날짜 묶음**
- 외기 24h 완전 쌍둥이 연결 성분(z-RMSE ≤ .05; 표준화 = 학습 기록 평균·표준편차).
- 평가 행 시각별: 0..h시 외기로 쌍둥이 판정(h ≥ 5, SG2 규칙). h < 5는 보정하지 않는다.
- 묶음 구성원 판정에 쓰는 다른 기록은 학습 기록과 기록 번호가 더 작은 같은 ID 평가 기록뿐이다.

**정답 기록 비용**
- CH2: (EC 자정 점프/.02)² + 외기 날짜 비용 + 실내 비용/4. 학습 자료끼리만 계산한다.

**전날/다음날 묶음 찾기**
- b와 같은 묶음의 정답 기록 c 각각에 대해, 비용 최소인 앞(뒤) 정답 기록의 묶음을 구하고 그중 최빈값을 쓴다.

**배제**
- 이웃 묶음의 정답 기록과 같은 묶음 정답 기록을 헝가리안으로 짝짓는다.
- 짝 없는 정답 기록이 정확히 1개일 때만 결정한다. 2개 이상이거나 0개면 결정하지 않는다.

**값**
- v = 평균(앞날 EC23, 다음날 EC0) 중 있는 것.

**예측 (h시 행)**
- pred_h = sg_h − pm_h + v, pm_h = SG2 0..h시 누적 평균. 결정되지 않은 날은 sg.
- 대안 V2 (k=2): 보호 |v − pm_h| ≤ .50.

## 3. 검증 (평가와 같은 동시 가림)
- 검증기 DIAG10 · DIAG10y · EL1의 폴드마다, 폴드 기록을 정답 없음으로 둔다. 실제 평가 60도 정답 없음.
- 가림 기록은 배제의 '정답 기록'에서 빠진다. 그래서 묶음 안에 가림·평가 기록이 여럿이면 결정되지 않는 경우가 늘어난다(실제 조건).
- 기준선은 SG2 저장 OOF 시드 3이고, 대상은 2차 46일 전체 시간 행이다.

**판정 (고정)**
- 9칸(검증기 3 × SG2 시드 3) 모두 SG2보다 낮을 것.
- 시드 평균에서 두 온실 모두 개선.
- 일반 날·고EC 날 각각 악화 1% 이하.
- DIAG10y에서 온실×5기록 묶음 부트스트랩 P(worse) < .025/2.
- 함께 보고: 결정 비율, 적중률(정답 사용 진짜 앞날 기준), 가짜 대조.

## 4. 규정 점검
- 평가 행: 같은 ID 현재 기록 0..h시 외기(묶음 판정) + 기록 번호가 더 작은 같은 ID 평가 기록 외기만 쓴다. 실내 입력은 쓰지 않는다.
- 학습 자료(다른 ID, 뒤 날짜 포함)는 2절에 따라 참조 가능하다. 다른 ID 학습 자료 참조와 '뒤 날짜 학습 정답' 사용은 7절 문의를 권한다.
- 평가 입력이나 예측으로 학습·갱신하지 않는다. 다른 평가 기록의 선택이 b에 영향을 주지 않는다(배제는 정답 기록만으로 한다).

## 5. 위험
- 동시 가림 조건에서 결정 비율이 크게 줄 수 있다.
- 묶음 크기 3(출처 하나가 그날 없음)에서 배제가 잘못될 수 있다.
- 적중 74~80%는 b 단독 가림에서 잰 값이다.
