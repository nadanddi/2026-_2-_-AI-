# GX3 — 격자 배제법 + 안전장치 (계획 v1, 2026-10-07 연구실 클로드)

## 1. 근거 (카탈로그 6.383, GX2 최종 비평)
- **식별력은 실재한다.** 묶음이 깨끗할 때(앞날 후보 전원이 같은 묶음, 짝 비용 작음, a*가 0시 비용 최소) 검증 17건에서 17/17이었다.
- **GX2 실패 원인은 셋이다.**
  - (i) 검증은 '같은 날짜에 가린 기록이 b 하나'인 경우가 대부분이었고, 평가는 여러 평가 기록이 함께 있는 경우가 많았다.
  - (ii) 앞날 묶음이 동률인데도 하나를 골랐고, 비용이 비정상인 짝도 결정했다.
  - (iii) 이득이 이틀(F13 217·214)에 몰려 있었다.

## 2. 규칙 (고정; GX2 와 같은 CST·날짜 묶음·attach(0..5시 외기, b 제외))
**결정 후보 조건**
- 앞날 묶음 P의 보이는 정답 수 = G의 보이는 정답 수 + 1 → 남은 1개 a*.

**안전장치 (모두 충족해야 결정)**
- **S1**
  - G의 정답 기록마다 고른 앞 기록(pick)이 모두 같은 묶음 P에 있을 것.
  - pick 비용과 헝가리안 짝 비용이 모두 ≤ q95. q95는 학습 진짜 연결 CST(앞 기록 최소 비용 & EC 점프 < .05)의 95% 분위로, 학습 자료로 계산한다.
- **S2**
  - a*가 P 정답 기록 중 b의 0시 비용(외기+실내/4, EC 없음)이 최소일 것.
  - 2위와의 차가 ≥ 1.0일 것.
- **S3**
  - 같은 ID에서 기록 번호가 b보다 작은 '정답 없는' 기록(평가·가림)이 0..5시 외기로 G 또는 P에 붙으면 결정하지 않는다.
  - 다른 ID 평가 입력은 쓰지 않는다(2절).

**추정**
- A2만 쓴다(GX2에서 더 나았던 안. 사후 선택임을 명시).
- h ≥ 5: pred_h = sg_h − pm_h + EC23(a*). 그 밖은 sg_h.

## 3. 검증
**M1 (GX2와 같음)**
- 가림 = b + 실제 평가 60.

**M2 (평가형, 새로 추가)**
- 가림 = b를 가운데로 한 같은 ID 연속 5기록(b−2..b+2, 실제 평가 덩어리 최소 길이) + 실제 평가 60.
- 대상은 b만 센다(SG2 OOF가 있는 2차 46일).

**기준선**
- SG2 OOF 3 검증기 × 시드 3 = 9칸. 판정 단위는 결정 기록이다.

**판정 (고정; 누적 본페로니 GX1·GX2(2안)·GX3 = 4 → α = .025/4)**
1. M1 결정 ≥ 15.
2. M1과 M2 모두 결정 기록에서 9칸 전부 SG2보다 낮을 것.
   - M2는 결정 < 10이면 '판정 불가'로 보고하고, 이 기준을 충족하지 않은 것으로 본다.
3. M1 DIAG10 결정 기록 부트스트랩 P(worse) < .00625.
4. 한 건 빼기: M1에서 이득이 가장 큰 기록을 빼도 9칸 모두 개선.

**함께 보고**
- 적중(|EC0(b) − EC23(a*)| < .05)
- 안전장치별 탈락 수
- 실제 평가 60의 결정 수와 '큰 불일치'(|v − 제출14 하루평균| > .15) 목록
- 리더보드 산술은 진단만 하고 거르기에 쓰지 않는다.

## 4. 규정
- 평가 행 b에서 쓰는 것
  - 자기 0..5시 외기(묶음 붙이기)
  - 0·1시 외기·실내(S2 0시 비용)
  - 같은 ID 앞번호 기록의 0..5시 외기(S3)
- 그 밖은 학습 자료다(다른 ID·뒤 날짜 포함, 2절 학습 자료 참조. 7절 문의 권장).
