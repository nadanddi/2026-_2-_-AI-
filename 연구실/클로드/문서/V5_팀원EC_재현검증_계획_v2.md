# V5r — 팀원 EC 파이프라인 문서 기반 재구현 + 판정 (계획 v2, 2026-10-09 연구실 클로드)

## v1에서 바꾼 것 (비평 → 수정)
1. **치명 — 판정에 쓴 SLSQP 가중이 판정 라벨을 봄.** DIAG10 10폴드는 8640행 전체를 덮으므로 "DIAG10에서 적합해 A·B·EL1에 적용"해도 모든 라벨을 본다.
   → **판정 후보 = ET/LGB/CAT 1/3 고정 가중(라벨 미사용)**. SLSQP(DIAG10 전체 적합)는 서술(낙관 표시)로만.
2. **clip 공정성.** 후보만 9600행 전체 범위(.062/3.46, 검증·잠금 라벨 포함)로 잘랐다.
   → 검증에서는 후보도 기준처럼 **폴드 학습 범위(lo/hi)** 로 자른다. 고정 범위는 test 재현에만.
3. 시드 평균 방식을 기준과 맞춤: 시드별 clip 후 평균.
4. 인과 assert 추가: 16개 날에 대해 "그 날 이후 행을 지운 train으로 다시 만든 특징 = 전체 특징".
5. 재현 기준 사전 고정: 온실별 상관 ≥ .95 **그리고** RMS 차이 < DIAG10 RMSE/3 일 때만 "재현됨". 아니면 결론은 **V5r(문서 기반 재구현)** 에 대한 것이고 팀원 모델 자체의 결론이 아니다.
6. 서술 추가: 2차(day ≥ 179)만의 추세선 단독 RMSE. GKF(팀원 방식)는 "낙관(같은 day 번호 두 온실 한 묶음, ±1일 제외 없음)"으로 표기.
7. 기타: CatBoost 파일 쓰기 끔, SLSQP 시작점 4개·success 확인, WT1 병합 validate, 기준과 폴드별 학습 범위(lo/hi) 일치 assert(학습 행 일치 확인).

## 판정 (고정)
PASS = 독립 시드 3쌍(후보 42/1004/2026, 기준 47/1414/6464) 모두 × DIAG10·A·B에서 V5r(1/3) RMSE < 기준 R3, **그리고** DIAG10 시드평균 블록 부트스트랩 P(worse) < .025. 후보 1개. 안전장치: EL1 또는 DIAG10 2차 +2% 이상 악화 시 보류. 판정 후보를 나중에 바꾸려면 새 계획 + 본페로니.
