# PD2 — 날짜가 확정된 2차 기록의 '두 온실 ID 통합' 전날 연결 (계획 v1, 2026-10-07 연구실 클로드)

## 1. 근거 (실행 전 전제 검산, 정답은 판정에만 사용)
- **PD0 (같은 날짜 짝 차이)은 실패했다.** 같은 날짜 기록 3~4개끼리 EC 차이 표준편차가 .47이고, 입력 차이로 예측해도 일반 날 .32로 모델(.10)보다 나쁘다. EC 수준은 날짜가 아니라 출처별 상태다.
- **PD1 v1 (같은 온실 ID 안 전날 후보)도 부족했다.**
  - 날짜가 확정된 기록: 2차 정답 56개 중 32개 (1차 쌍둥이 기준)
  - 진짜 앞날이 후보 안에 있는 비율: 62%
  - 후보 중 정답에 가까운 것을 고르는 오라클도 일반 날 .142로 모델(.100)보다 나쁘다.
- **PD1 v2 (두 온실 ID 통합 후보)에서 처음으로 신호가 나왔다.**
  - 후보 3~4개 (자기 ID 1~2개 + 다른 ID 1~2개)
  - 진짜 앞날이 후보 안에 있는 비율: 75% (다른 ID 쪽 6개)
  - 일반 날 하루 RMSE: 오라클 선택 **.079** vs 모델 .100
  - 입력 자정연속 선택(실내 온도·습도·CO2의 23→0시 점프)은 .117로, 오라클과 74% 일치
- 배경(카탈로그 첫 줄·3.2): F13·F47은 각각 한 온실이 아니라 여러 온실의 하루치 기록을 이어 붙인 것이다. 같은 날짜를 기록 4개가 공유한다.
- 사슬·앞날 탐색(CH·MC·LINK·BR)은 모두 **같은 온실 ID 안**에서만 했다. 카탈로그에 다른 ID 연결 시도는 없다.

## 2. 규칙 (고정)
**대상**
- 2차 기록 b 중 날짜가 확정되는 것.
- 날짜 확정 = b의 외기 0..h시가 학습 1차 정답 기록과 완전 쌍둥이(z-RMSE ≤ .05, h ≥ 5; SG2의 쌍둥이 규칙과 같음).
- 같은 ID 1차 쌍둥이가 없으면 다른 ID 1차 쌍둥이로 날짜를 정하는 경우도 포함한다.

**후보**
- 그 날짜의 바로 앞 날짜 묶음에 있는 학습 정답 기록(두 ID 모두).
- "앞 날짜 묶음" = 1차 기록 순서에서 쌍둥이 묶음 바로 앞 묶음.

**선택**
- 비용 = Σ_{온도·습도·CO2} ((b 0시 − 후보 23시)/σ)².
- σ는 학습 기록의 시간 차분 표준편차이고, 두 ID를 합쳐 계산한다.
- 최소 비용 후보를 고르고, 확신 조건은 (2등 비용 − 1등 비용) ≥ 1.0일 때만 사용한다.

**보정**
- v = 고른 후보의 23시 EC.
- h시 행: |v − pm_h| ≤ .30이면 pred_h = sg_h + (v − pm_h), 아니면 sg_h.
- pm_h = 0..h시 SG2 예측 누적 평균, sg = SG2 예측.
- h < 5(날짜 미확정)는 보정하지 않는다.

**고정 값**
- .05, h ≥ 5, 확신 차 1.0, 보호 .30, 반영 비율 1.
- 모두 실행 전에 고정하고, 사후에 바꾸지 않는다.

## 3. 검증
- SG2 저장 OOF(ec3_SG2_all.csv)의 DIAG10, DIAG10y, EL1 2차 46일을 쓴다.
- 각 검증 배치에서 그 폴드의 가린 기록은 후보에서 뺀다.
- 1차 기록은 대부분 가려지지 않는다. 실제 평가와 같은 조건이다.

**판정 (고정)**
- 세 검증 배치 × SG2 시드 3 = 9칸 모두에서, 2차 전체 시간 RMSE가 SG2보다 낮아야 한다.
- 시드 평균으로 두 온실 모두 개선, 일반 날·고EC 날 각각 +1% 넘게 악화하지 않아야 한다.
- 온실×5기록 묶음 부트스트랩 P(worse) < .025: 세 배치 중 DIAG10y(처음 쓰는 배치에 가장 가까움)에서 잰다.
- 바뀐 날 수와 날짜 목록을 사전에 공개한다.
- 바뀐 날이 8일 미만이면 판정 불가로 처리한다.

**실제 평가 적용 범위**
- 평가 60개 중 같은 ID 1차 쌍둥이 27개 + 다른 ID 쌍둥이 추가분.
- 실행 전에 세되, 정답 없이 입력만으로 센다.

## 4. 규정 점검 (중간 안내 2·3절)
- **b 쪽:** 같은 온실 ID의 현재 기록 0..h시 입력만 쓴다. 외기는 쌍둥이 판정용, 실내는 0시 값만.
- **후보 쪽:** 학습 자료(train_X·train_y)이므로 시점·ID 제한 없이 참조한다.
- **확인 필요:** "다른 온실 ID의 학습 자료를 참조"하는 것이 2절 '같은 온실' 조항과 충돌하는지. 2절의 '같은 온실' 제한은 평가 행 특징을 만드는 관측 입력에 대한 것이고, 학습 자료 참조는 별도로 허용된다고 읽힌다. 확인은 7절 문의 대상이다.
- 평가 입력이나 예측값으로 학습·갱신하지 않는다. 규칙에 학습되는 부분이 없다.

## 5. 위험
- "진짜 앞날"을 정답 자정 연속(< .05)으로 판정하는데, 같은 판정을 받는 기록이 많다(중앙 50개). 그래서 75%·.079는 너그러운 상한일 수 있다.
- 표본은 날짜 확정 2차 정답 기록 32개, 그중 일반 날 24개다.
- SG2와 겹친다. SG2도 달력 이웃의 정답을 쓰므로 얹었을 때 이득이 작을 수 있다.
