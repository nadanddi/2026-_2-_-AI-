# DT2 — 사슬 끝 조각 맞추기로 평가형 기록의 같은 출처 앞날 찾기 (계획 v1, 2026-10-07 연구실 클로드)

## 1. 근거 (전제 검산, 정답은 판정·오라클에만)
- **DT0:** 2차 기록을 날짜 확정 경로로 나눴다.
  - 1차에 없는 날짜(C3)인 정답 기록 13일이 SG2 2차 오차의 61~70%를 차지한다(세 검증기 일관).
  - 평가 60개 중 C3는 25개다.
- **DT1 v2:** 진짜 앞날을 엄격히 정의했다(EC 자정 점프 + 외기 날짜 점프 결합 비용, CH2 식).
  - 외기만으로 앞날의 날짜 묶음을 고르면 C3 16개 중 1위 9, 3위 이내 14다(121묶음 중).
- **DT1 v3 (상한):** 진짜 앞날 23시 EC를 하루 수준으로 그대로 쓰면 2차 46일 RMSE .048(일반 .031, C3 .065)이다. SG2는 .244였다.
  - 합법 파이프라인(외기 1위 날짜 → 실내 연속 최선 기록)은 앞날 적중 50%로 .352, SG2보다 나쁘다.
  - 보호 .30을 씌우면 오라클도 .237로 효과가 사라진다.
  - 결론: 병목은 식별 정확도다. 정확도가 높으면 보호 없이 쓰는 것이 맞다.
- **구조 단서 (CH2 6.346):** 정답 기록 400개는 1:1 자정 연속 배정으로 사슬 27개로 묶인다(연결 373, 끝 27).
  - 이 사슬은 학습 자료 전처리라 허용된다(6.309 2절 학습 자료 참조).
  - 평가 기록이 이어 붙을 수 있는 앞 기록은 다음 둘뿐이다.
    - 정답 기록 사슬의 '끝' (후계가 없는 기록, 약 27개)
    - 앞선 평가 기록
  - 지금까지(LINK·PD·DT1)는 정답 기록 전체(~400)를 후보로 두었다.

## 2. 방법 (실행 전 고정)
- **(a) 정답 기록 사슬 (학습 자료 전처리):** 참조 정답 기록끼리 CH2 비용 = (EC 자정 점프/.02)² + 외기 날짜 비용 + 실내 비용/4. 1:1 헝가리안, '연결 없음' 비용 C0 = 12. 두 온실 ID를 통합한다(다른 ID 앞날이 실제로 있음, DT1 v2).
- **(b) 후보:** 참조 기록 중 사슬 후계가 없는 '끝' 기록 + 기록 번호가 더 작은 평가형 기록(같은 ID; 다른 ID 평가 기록은 입력 참조 불가).
- **(c) 선택 (평가형 기록 b, h시 행):**
  - 비용 = 외기 날짜 비용(b의 0·1시 외기; h=0이면 추세 보정을 앞 기록 쪽만) + 실내 비용(b 0시 온·습·CO2)/4. 시각에 따라 바뀌지 않는다(0·1시만 사용).
  - 최소 비용 후보를 고른다.
- **(d) 값:** 고른 후보가 정답 기록이면 23시 EC. 평가형 기록이면 그 기록의 추정 하루 수준 + 모델의 (23시 − 하루평균) 모양.
- **(e) 예측:** pred_h = sg_h − pm_h + v. pm_h는 0..h시 SG2 누적 평균, 보호는 두지 않는다.
  - 대안 V2 (k=2): 비용 1등과 2등 차가 1.0 이상일 때만 적용, 아니면 SG2.
- **(f) 순서:** 같은 ID 안 평가형 기록을 기록 번호 순으로 처리한다(앞선 평가형 기록의 추정이 먼저 정해짐).
- **(g) 1:1 제약:** 한 사슬 끝은 하나의 평가형 기록에만 배정한다. 앞선 기록이 먼저 가져간다(인과).

## 3. 검증
- 검증기: DIAG10, DIAG10y, EL1.
- 각 폴드에서 가림 = 폴드 기록. 참조 정답 기록 = 정답 − 가림 − 잠금(SG2와 같게). 사슬은 폴드마다 참조 기록으로 다시 만든다.
- 평가형 기록 = 그 폴드의 2차 가림 기록 + 실제 평가 기록 60(입력만, 후보·사슬 연결 대상).
- 기준선: SG2 저장 OOF 시드 3. 대상: 2차 46일의 모든 시간 행.

**판정 (고정)**
- 검증기 3 × SG2 시드 3 = 9칸 모두 SG2보다 낮을 것.
- 두 온실 모두 개선.
- 일반 날·고EC 날 각각 악화 1% 이하.
- 온실×5기록 묶음 부트스트랩 P(worse) < .025/2 (V1·V2 두 변형, 각 검증기).
- 함께 보고: 식별 적중률(정답 사슬 기준), 가짜 대조(후보에서 진짜 끝 제외 시).

## 4. 규정 점검
- **평가 행:** 같은 ID의 현재 기록 0·1시 입력 + 기록 번호가 더 작은 같은 ID 평가 기록 입력만 쓴다.
- **학습 자료:** 다른 ID 포함 전부 참조 가능(2절). 7절 문의를 권한다.
- **사슬 (a):** 학습 기록끼리만 만든다. 평가 입력은 쓰지 않는다.
- **'끝' 판정:** 학습 자료만으로 한다. 평가 입력으로 무언가를 학습·갱신하지 않는다.
- **1:1 제약 (g):** 앞선 평가 기록의 선택에 따라 후보가 줄어든다. 이는 앞선 평가 입력에서 유도된 처리이므로 허용 범위로 읽힌다(확인 필요).

## 5. 위험
- 사슬 끝 수가 폴드 가림에서 늘어난다(가린 기록 자리마다 끝이 생김). 그래서 실제 평가보다 어렵다.
- 진짜 앞날이 평가형 기록인 경우 오차가 누적된다.
- 0·1시 정보만으로 고르므로 날짜 1위 적중률(~55%)이 병목일 수 있다.
