# ST1 — 맞바꿈형 보정기들의 장점만 가져오기 (계획 v1, 2026-10-07 연구실 클로드)

## 1. 왜
- 기각된 보정기 다수가 '맞바꿈형'이었다. 한쪽(고EC 날·특정 검증기·특정 날)은 좋아지고 다른 쪽은 나빠졌다.
  - 예: HM1, AF0, HG1 계열은 고EC −15~−30%, 일반 날 +5~+54%.
- 보정기마다 실패하는 날이 다르다면, 여러 보정기를 묶을 때 각자의 실수는 상쇄되고 공통된 장점만 남을 수 있다.

## 2. 자료
- R3S(계절 R3, 시드 7/101/2024)를 기준으로 저장된 OOF 18개를 쓴다.
  - HM1, HM2, LG1, LR1, TS1, TS2, ST5, ST8, SB1, SE3, TF1, MW1, DB1, DC6, DC7, DI1, DP1, DP2 (`집/클로드/research/local/ec3_*_all.csv`)
- 검증기 6개: DIAG10, A, B, EXT10, EXT12, EL1.
- 각 보정기의 시드 평균 예측에서 R3S 시드 평균을 뺀 값을 Δ_j(행 단위)라 한다.

## 3. 방법 (실행 전 고정, 3안 → 본페로니 3)
- **K1 중앙값 합의**
  - pred = R3S + median_j Δ_j
  - 보정기마다 실수가 서로 다르면 중앙값이 그 실수를 걸러낸다.
- **K2 부호 합의 문턱**
  - 보정기의 ≥ 75%가 같은 부호일 때만 pred = R3S + mean_j Δ_j, 아니면 R3S.
- **K3 중첩 스태킹 (학습형)**
  - 검증기마다 폴드 k를 뺀 나머지 폴드의 OOF 행으로 릿지(α=10, 표준화)를 학습한다.
  - 목표는 y − R3S, 입력은 Δ_1..Δ_18, R3S, 0..h 누적평균 R3S, 시각이다.
  - 학습한 모델로 폴드 k를 예측한다. 폴드 k 정답은 쓰지 않는다.
  - A/B처럼 같은 행이 여러 폴드에 나오는 검증기는 폴드 단위로 그대로 쓴다.

## 4. 판정 (고정)
기준선은 DP1(R3S + DP1, 현재 제출 구성의 R3 부분)이다. 각 안이 다음을 모두 충족해야 한다.
- 6개 검증기 모두에서 시간 RMSE가 DP1보다 낮을 것.
- DIAG10에서 일반 날(하루평균 정답 < 1)과 고EC 날이 각각 DP1 대비 악화 ≤ 1%일 것 → '장점만'의 정의.
- DIAG10 온실×5기록 묶음 부트스트랩 2000에서 P(worse) < .025/3.
- 2차 구간(DIAG10의 day ≥ 179 행)이 DP1 대비 악화 ≤ 1%일 것(평가 구간 보호).

**함께 보고**
- 보정기별 단독 성적
- 보정기 간 Δ 상관(서로 다른 실수인지)
- 고EC·일반 날 분해
- K3의 계수

## 5. 주의
- DP1 자체가 보정기 18개 중 하나다. 따라서 K1~K3이 DP1을 이기려면 다른 보정기에서 추가 정보가 나와야 한다.
- 대부분의 보정기는 2차 구간에서 판정된 적이 없다(R3S 위 전체 검증).
- SG2·TabPFN은 R3S 기준 OOF가 없어 이번 조합에서 빠진다. 통과하면 제출 구성 위에서 다시 확인해야 한다.
