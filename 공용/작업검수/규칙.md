# 작업·검수 반복 규칙 (2026-11-03 사용자 지시)

클로드가 작업하고 GPT(코덱스)가 검수합니다. 목표 하나를 PASS할 때까지 작업과 검수를 되풀이하고, PASS하면 다음 목표로 넘어갑니다.

## 폴더
| 파일 | 쓰는 쪽 | 내용 |
|---|---|---|
| `목표.md` | 사용자(클로드가 상태만 갱신) | 목표 목록, 순서, 완료 기준, 상태 |
| `라운드/G<목표>_R<회차>_작업.md` | 클로드 | 이번 회차에 한 일, 바뀐 파일, 확인 방법, 지난 수정 요청 처리 결과 |
| `라운드/G<목표>_R<회차>_검수.md` | GPT | 판정(PASS / 수정요청)과 수정 요청 목록 |
| `확인.ps1` | 둘 다 | 상대 파일이 생겼는지 확인하는 스크립트 |

- 번호는 두 자리입니다(예: `G01_R03_작업.md`).
- **반쯤 쓴 파일을 상대가 읽지 않게** 먼저 `<이름>.md.part`로 쓰고, 다 쓴 뒤 `.md`로 이름을 바꿉니다. 확인 스크립트는 `.part`를 무시합니다.
- 작업물 자체(코드·문서·결과)는 원래 자리(클로드는 `<장소>/클로드/`)에 두고, 작업 파일에는 그 경로만 적습니다.

## 순서
1. **클로드**: `목표.md`의 진행 중 목표를 작업 → `G01_R01_작업.md`를 올림 → **5분 기다린 뒤** `G01_R01_검수.md`가 있는지 확인, 없으면 **2분마다** 다시 확인.
   ```
   powershell -File 공용\작업검수\확인.ps1 -Role claude -FirstWaitSec 300
   ```
2. **GPT**: 시작하자마자 검수할 작업 파일(짝이 되는 검수 파일이 없는 작업 파일)이 있는지 확인, 없으면 **2분마다** 다시 확인.
   ```
   powershell -File 공용\작업검수\확인.ps1 -Role gpt
   ```
   찾으면 `목표.md`의 그 목표 완료 기준에 맞춰 검수하고 `G01_R01_검수.md`를 올림 → 다시 확인 대기.
3. **클로드**: 검수 파일이 `수정요청`이면 요청대로 고쳐 `G01_R02_작업.md`를 올리고 1로. `PASS`면 `목표.md`에서 그 목표를 `완료`로 바꾸고 다음 목표를 `진행 중`으로 바꾼 뒤 `G02_R01`로 시작.
4. 목표가 더 없으면 클로드는 `라운드/끝.md`를 올리고 멈춥니다. GPT는 `끝.md`를 보면 멈춥니다.

## 검수 파일 형식 (GPT)
```
# G01_R01 검수
판정: PASS | 수정요청
## 수정 요청
1. [필수] 무엇이 / 어디서(파일:줄) / 왜 / 어떻게 고치면 되는지
2. [권장] ...
## 확인한 것
- 실제로 열어 보거나 다시 계산한 것
```
- `[필수]`가 하나라도 있으면 판정은 `수정요청`입니다. `[권장]`만 남으면 PASS할 수 있습니다.
- 목표의 완료 기준 밖의 새 요구는 `[권장]`으로만 적습니다.

## 작업 파일 형식 (클로드)
```
# G01_R02 작업
목표: G01 <목표 이름>
## 이번에 한 일
## 바뀐/새 파일
## 지난 수정 요청 처리   (R02부터: 요청 번호마다 고침 / 안 고침과 이유)
## 검수자가 확인할 방법
```

## 멈춤
- 같은 목표에서 5회차가 넘도록 PASS가 안 나오면 둘 다 멈추고 사용자에게 묻습니다.
- 확인 스크립트는 기본 4시간 동안 파일이 안 생기면 끝납니다(종료 코드 2). 그때는 다시 실행하거나 사용자에게 알립니다.
- 제출·삭제·대회 규정 관련 결정은 이 반복 안에서 하지 않고 사용자에게 묻습니다(기존 규칙 그대로).
