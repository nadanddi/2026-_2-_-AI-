# G07_R01 검수

판정: **수정요청**

## 필수 수정

1. **13장 그림 7 캡션.** ‘현장 사진에서는 거의 꺼짐’은 실제 현장 사진에서 작동 비율을 측정한 것처럼 읽힌다. **‘원본이 DB에 없거나 지정 JPEG 설정과 다르면 해당 장치를 건너뜀’**처럼 장치별 조건을 적는다. 두 조건 중 하나가 맞지 않으면 두 장치가 함께 꺼진다는 뜻이 되지 않도록 주의한다.
2. **15장 하단 결론.** ‘현장 사진으로 다시 학습·검증하기 전에는 선명화·WebP 사진을 판별에 쓰기 어렵다’는 문장은 특정 처리 실험에서 모든 선명화·WebP 입력과 재학습 필요성까지 일반화한다. **‘검증 1의 실제 사진을 선명화하거나 WebP로 다시 저장하자 오탐이 높았다. 현장 사진에서도 같은 문제가 나타나는지 별도로 확인해야 한다.’**로 범위를 맞춘다. ABL2는 검증 1 실제 사진 429장을 재처리한 결과다.

## 작업자 질문에 대한 판단

- **12장 공개 샘플 21장.** ‘정답 붙은 학습 사진이 없어’와 공개 샘플의 존재는 양립한다. 제목을 ‘별도 학습용 정답 사진이 제공되지 않아’로 쓰면 더 명확하다. 화면의 ‘학습에는 안 넣음’과 노트·질의응답의 형식 확인, 후보 비교, 유지 점검 구분은 유지한다.
- **14장 표 중심 배치.** 중복 그래프를 없앤 방향은 적절하다. 본편에서 검증 1~3의 범위와 후보 선택에 썼다는 점만 짚으면 된다. 운영진 97%는 다른 지표임을 표시했다. 여유가 있으면 운영진 결과를 표 밖에 한 줄로 분리하면 열 제목 ‘균형 정확도’와의 혼동이 더 줄어든다.
- **15장 어느 숫자를 읽을지.** 장치를 끈 조건의 86.5%, 75.8%를 말하고 제출 모델 값은 화면에 두는 방식으로 충분하다. 두 조건의 비교를 직접 말한다면 WebP 37.5→75.8% 한 예만 골라 말한다. 수치는 자료점검 문서 2절의 ABL2 집계와 일치한다.

## 확인 범위

작업 기록의 장별 채택·보류·기각 사유를 확인했다. 제공 PowerPoint 검사표의 문제 0건과 이미지 본편 12~15장 PNG를 확인했다. ABL2의 처리 오탐률 및 검증 1 표본 범위를 G00 자료점검 문서와 대조했다. 위 두 문구 수정 후 바뀐 화면과 대사를 재검수한다.
