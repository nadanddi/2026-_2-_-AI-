# G06_R01 검수

판정: **수정요청**

## 필수 수정

1. **3장 그림 1과 포인팅을 맞출 것.** 화면은 ‘오늘(4일)의 어제는 다른 ID에 있을 수 있다’고 적었지만, 강조된 4일과 전날인 3일은 둘 다 F47 줄에 있다. 대본 §3의 포인팅도 이 두 점을 가리킨다. 실제로 ID가 바뀌는 **F13의 2일 → F47의 3일**을 강조하고 화면 문구와 포인팅을 함께 맞춘다. 개념도라는 표기는 유지한다.
2. **9장 제목을 표의 범위에 맞출 것.** ‘대회 자료에만 있는 표식은 빼고 … 어제만 남겼다’는 제목은 같은 화면에서 대회 외기로 복원한 계절 지표를 사용한다고 밝히는 내용보다 넓다. 제목을 **‘기록 번호·평가 기록 유무에 따른 분기를 제거했다’**처럼 실제 제거 범위로 한정한다. 오른쪽의 현장 운영안과 실제 달력 전환 성능 미측정은 유지한다.

## 적용 확인 및 권장

| 보완안 항목 | 확인 결과 |
|---|---|
| 1~2 결과·도입 | 2장 제목 단순화, 정의 문단을 별도 화면에서 걷고 필요한 정의는 대사에 배치 |
| 3~4 자료 | 3장 표1과 4장 51곳 비교를 분리. 다른 49곳의 ‘최종 모델에는 안 씀’ 표기는 개발 중 활용과 최종 학습의 차이를 전달한다. 그림1은 위 필수 수정 |
| 5 오차 분해 | 5장 49%·−0.64·0.64 및 다른 49곳의 중앙값, 1도 예시 대사 반영 |
| 6~7 모델과 비중 | 6장 A/B/C 설명, 9℃ 40/40/20, 연속 전환과 저온 제외·공개 점수 선택의 역할 분리 확인 |
| 8~11 온도와 EC | 7·8장 분리, 전날 연결·실측과 예측의 조건·없을 때 기본값·최대 0.25℃·EC 별도 경로 반영. 온도 보정용 EC는 하루 수준 조정까지 적용한 값으로 구분 |
| 12 현장 전환 | 9장 표는 실제 변경과 현장 운영안을 구분. 제목은 위 필수 수정 |
| 13~14 검증과 개선 | 10장 기준 두 줄, 짧은 회차 설명과 선택 경로 반영. p값 표기를 화면에 추가할 필요는 없음 |
| 15 그래프 | 11장 공통 집계 구간과 검증 방식 명시. ‘최종 모델 대비 RMSE 증가율’은 실제 분모를 드러내므로 채택. 온도와 EC를 함께 그린 제목도 적절 |

- 4·6·7·8장 일부 문장이 단어 중간에서 줄바꿈된다. 짧은 어구로 줄이면 읽기 편해진다. 9분20~37초는 추정 범위다. 목표 9분20초에 맞추려면 실제 리허설에서 겹치는 설명부터 줄인다.

## 확인한 범위

G05v10의 화면 XML과 대본 v6를 열어 확인했다. 18장 낭독 문장이 공백·강조 표기를 정리한 뒤 해당 노트에 들어 있음을 확인했다. 클로드가 생성한 PowerPoint 검사표는 문제 0건이며, 제공된 정형 본문 3~11장 PNG를 직접 확인했다. 이번 회차에서는 제공 렌더를 사용했다. 새 작업본에서 위 두 수정과 해당 화면·포인팅 참조를 집중 재검수한다.
