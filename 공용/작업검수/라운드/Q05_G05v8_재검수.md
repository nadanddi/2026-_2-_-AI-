### K01 [필수] 온도 이어받기의 사용 조건을 남은 답변까지 맞출 것

- **어디:** 6장2단계, 9장 현장 조건, 대본 §6·§9, 질의응답 J01.

### K02 [필수] 6장의 모델A/B를 구분하고, 정보 추가 대신 설명 단위를 재배치할 것

  - 화면에는 기능을 짧게 구분하고, 노트에는 `A=BASE / B=CODEX`를 명시한다. 기능 이름은 실제 특징·구성에 맞춰 정한다.
  - ‘비중은 오른쪽 아래 표’ 같은 안내 문장은 포인팅으로 대신하고 삭제할 수 있다.
  - “8~10℃는 사이를 직선으로”는 “8~10℃는 두 비중 사이에서 연속 전환”처럼 완결된 뜻으로 쓴다.
  - 기본 모델·비중 선택과 어제 상태 보정을 서로 다른 설명 단위로 나누는 배치를 권한다. 한 장 유지 시에도 두 내용을 동시에 읽게 하지 말고 대사 순서와 시선을 정리한다. 부족하면 구분 표지와 인접 장의 중복을 합쳐 공간·시간을 확보한다.

### K03 [필수] 8장의 선-수치 겹침을 해소하고 기준·사례의 읽기 순서를 단순화할 것

- **23회차 표현:** “실측 보정 확대(두 판단 일치)”는 선택 경로 자체는 맞지만 ‘어떤 두 판단인지’ 새 내부 용어처럼 들린다. “전날 선택을 재확인해 실측 보정 확대”처럼 기능을 먼저 적고 정확한 TAG2 조건을 노트로 연결하는 방식을 권한다. 외기·실내 판단 모두가 반드시 일치해야 한다고 새 조건을 만들지는 않는다.

### K04 [필수] 그림3의 새 %축과 상세 노트의 이전 축 표현을 맞출 것

### 2.1 이전 대사를 노트에 남긴 방식

**현재 대사 동기화 요청은 충족했다.** `[참고: G05 v7까지의 대사 — 발표에서 읽지 않음]`이라는 경계도 명시돼 있어, 이전 대사를 현재 대사로 잘못 집계하지 않았다.

다만 새 대사 뒤·현재 상세 근거 앞에 이전 대사가 길게 들어간다. 7장의 ‘한계 하나’, 9장의 이전 센서 조건, 13장의 옛 코드명 같은 내용을 발표자가 스크롤하다 다시 읽을 가능성은 남는다. 실제 발표자가 혼동한 것을 관찰한 것은 아니지만, 의도적으로 두 버전을 나란히 둘 실익은 작다.

**권장:** 다음 버전PPT에는 현재 대사와 현재 상세 근거만 두고, 이전 대사는 보존된G05v7에서 추적한다. 원본v7을 지우거나 고치라는 뜻이 아니다. 부득이하게 이력을 남기면 현재 상세 노트 뒤로 보내고 ‘구버전 이력’으로 분리한다. 이 권장만으로 F01을 미반영 처리하지는 않는다.

## 3. A02·A03·A01 핵심 사실 확인

### 3.1 6장 모델과 비중

실제 식은 정형 README97줄의 `g=clip((실내온도−8)/2,0,1)`, `0.4×BASE+(0.2+0.4×(1−g))×CODEX+0.4×g×TabPFN`이다.

카탈로그6.60~6.70은 초기 혼합의 비교·재확인·저온조정을 다룬다. **현재 최종40%까지 전부 해당 사전 기준을 통과한 것은 아니다.** 카탈로그6.198과 정형 README218줄에 따뜻한 구간30/40%안이 내부 검증에서 엇갈려 공개 점수.5193→.5160 비교로40%를 유지한 경위가 있다. 새 화면과 대본은 이를 정확히 밝혔다. 최적 비중을 입증했다는 새 주장은 없다.

### 3.2 8장 채택 기준과23·24회차

- 화면의 두 줄은 README⑤의 ‘모든 검증기·시드 개선 방향+P<.025’를 쉬운 말로 옮긴 요약이다. 실제 판정은 해당 실험이 실행 전에 고정한 규칙으로 추적해야 한다. 모든 시기의 모든 부품이 단일 규칙만 거쳤다는 선언으로 넓히지 않는다.
- “기록 묶음 재추출에서 나빠지거나 같은 비중”은 기존 README의 “실제로는 나빠졌을 확률”보다 계산 방법을 직접 드러내는 설명이다. 개선이 참일 사후 확률97.5%라고 말하지 않은 점도 적절하다.
- 플랫폼23회차는 파일번호33, 온도 TAG2 실측 보정 확장이다. 24회차는35e로, 33에 CHT 온도 사슬 확장을 더한34의 온도와 EC TAG2 실측 보정 확장을 합친 최종 구성이다. `제출/성능_정리.md`37~38줄 및 정형 README의 TAG2·CHT·EC TAG2 채택 경위와 새 표의 요지가 맞는다.

## 5. C — 대본v4와 시간

### 5.1 정합성·오해 가능성

- 본문16장의 현재 낭독 대사와 외부 대본은 정규화 비교16/16 동일이다. §6은 오른쪽 비중표·왼쪽 그래프, §8은 기준 두 줄·선택 경로, §13은 세 항목을 가리키므로 새 배치와 지시도 맞는다.

### 5.2 길이

- 제목·화면 지시·시간 조절·질의응답을 제외한 본편 대사의 한글은 독립 집계 **1,889음절**이다. 작성자의 약1,891과2음절 차이로 사실상 같은 수준이다. 숫자·영어·단위의 발화량은 이 수에 충분히 포함되지 않는다.
- 장별 배정 시간 합계는 **530초=8분50초**다. 넘김15~30초를 더하면9분5~20초로 시간표 산술은 맞다. 하지만 실제 낭독·포인팅 실측은 없다.
- 전체 음절 수는v3보다 약20 줄었지만, 설명 난도가 높은6·8장에 내용이 집중됐다. **전체 문자 수가 줄었다고 같은 속도로 더 잘 전달된다고 볼 수 없다.**
- 특히1장은129음절/20초, 6장은251음절/55초다. 현재 배정으로 초당 약6.45·4.56 한글 음절이며 영어·숫자 읽기와 정지도 별도다. 이 계산은 속도 위험을 찾는 지표일 뿐 적정 발화 속도를 확정하는 기준은 아니다.
- **10분 이내는 가능하지만 미확인**이다. 새 배치로6장의 포인팅·비중 설명 시간을 실제로 재고, 짧은 표지 대사로 시작부 부담을 줄인다. 9분20~30초 안팎의 전체 리허설을 확인하는 것을 권한다. 실제 측정 없이9분25초 이내라고 확정하지 않는다.

삭제 순서가 이전보다 개선돼 정의·그래프 뜻·EC 구분을 보호했다. 추가로 5장의 하루 평균 오차 예시는 처음 듣는 사람을 돕는 문장이므로, 가능하면 중복 결론이나 세부 사례부터 줄인다.

## 6. D — 숫자·주장 범위·부록 비교

### 6.1 차트 수치

G05v7·v8의 차트 XML 수치 캐시를 7개 대조했다.

- **6개 차트는 원수치 동일:** 8장 공개 점수, 9장 온도·EC 증가율, 13장 균형 정확도, 14장 균형 정확도·처리 오탐률.
- **6장 그림3만 의도한 표시 변환:** 예 `.7648→76.5`, `.1264→12.6`. 원비율×100 후 소수1자리 반올림이다. 24점 모두 변환과 일치하며 최대 반올림 차이는 **.05%p**다. 실험 결과를 새로 바꾼 것이 아니다.
- 그림3은 %, 그림4는 ℃, 그림5는 좌우 모두 %다. 그림5는 각 현행 RMSE를 분모로 한 증가율이므로 온도·EC의 공통 단위가 맞다.
- 표의 최종 수치와 비중표에서도 새로운 수치 변경은 확인되지 않았다.

### 6.2 화면·부록

- 텍스트가 바뀐 본문은 4·5·6·8·9·11·12·13·14장이다.
- **실제17~33장, 총17장의 부록 화면 텍스트는 모두 G05v7과 동일**하다. ‘부록17장’을 실제17번 한 장으로만 좁혀 검사하지 않았다.
- 이 결과는 화면 텍스트가 같다는 뜻이다. 모든 PPTX 내부 파일의 바이트 동일이나 부록 노트 전부 동일이라고 확대하지 않는다.

### 6.3 ABL3정정

카탈로그7.077은 7.076을 남기고 해석을 정정했다. 9장 노트도 아래 내용을 한곳에 명시한다.

1. 알려진 짝190쌍 안에서 교체, 밖에서는 현행 유지.
2. 실제 날짜·동을 넣은 최종 현장 성능이 아님.
3. 연결 상대·적용 범위·EC강도 q=1·온도 ID 간 이어받기가 함께 변함.
4. 감소율 분모는 현행C2; 62~95%는 RMSE 감소 폭의 비.
5. 오라클 정답 선정과 현행 링커 전체 적합의 양쪽 편향, 엄밀한 상하한이 아님.
6. EC 2차 부트스트랩 .060은 .025 미달, 서술용 평균 비교.

새 QA는 이 중 핵심 범위를 유지하고, 더 물으면 62~95%의 뜻을 설명한다. 현행 편향은 별도J03과 9장 노트에 있다. 답변이 독립적으로 읽힐 상황에는 “현행 링커도 전체 학습 자료에 맞췄다는 한계가 있습니다”를 연결하면 좋다. **ABL3 해석이 이전보다 좁아졌으며, 새로 현장 효과로 과장된 곳은 확인하지 못했다.**
