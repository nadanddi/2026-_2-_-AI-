# 집 노트북 이전 안내 (OneDrive 폴더 → `C:\work\farmai`, 1회)

2026-09-29 연구실에서 저장소 구조를 바꿨습니다.
- 폴더: 집/연구실 × 클로드/코덱스 + 공용 + 제출
- 브랜치: `main` 하나
- 집 노트북도 연구실과 똑같이 **`C:\work\farmai`** 에서 작업하도록 옮깁니다.

**왜 옮기나**
- 지금 폴더(`C:\Users\aozks\OneDrive\바탕 화면\2026_2학기_농업AI경진대회`)는 OneDrive 안에 있습니다. `.git`과 Python 환경 약 3GB가 OneDrive로 동기화되며, 그 위에 Google Drive "다른 컴퓨터" 백업까지 걸려 있습니다. 파일이 잠기거나 깨질 위험이 있습니다.
- 두 컴퓨터의 경로가 같으면 명령과 안내문이 하나로 통일됩니다.

**걸리는 시간**: 약 20~40분(대부분 Drive 업로드·다운로드 대기)
**원칙**: 옛 폴더에 있는 작업을 **먼저 GitHub와 Drive에 모두 올린 뒤** 새 폴더에 받습니다. 옛 폴더는 새 폴더가 잘 동작하는 걸 확인할 때까지 지우지 않습니다.

명령은 모두 **PowerShell**에 한 줄씩 붙여 넣습니다. 경로에 공백("바탕 화면")이 있으니 따옴표를 그대로 두세요.

## 2. main으로 옮기고 옛 브랜치 합치기

```powershell
git fetch --prune
git switch main
git pull
git merge feature/rmse-improvement
```

- `Already up to date.`가 나오면 올리지 않은 커밋이 없던 것입니다(정상). `not something we can merge`가 나오면 그 로컬 브랜치가 없는 것이니 넘어갑니다.
- 1단계에서 `codex-ec` **로컬** 브랜치가 보였다면 이것도 합칩니다.

```powershell
git merge codex-ec
```

- 옛 위치(`research/…` 등)에 있던 새 커밋 파일은 git이 새 위치(`집/클로드/research/…`)로 자동으로 옮겨 합칩니다.
- **충돌(CONFLICT)** 이 나면 멈추고, 이 폴더에서 Claude 앱을 열어 "git 병합 충돌 해결해줘"라고 합니다. 대부분 `HANDOFF.md`나 카탈로그 충돌입니다.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 2단계 `git switch main` 실패: "would be overwritten" | 1-1 커밋을 안 한 것. `git add -A; git commit -m "작업분"` 후 다시 |
| 2단계 병합 충돌(CONFLICT) | 옛 폴더에서 Claude 앱을 열고 "git 병합 충돌 해결해줘" |
| 4단계 `sync_end`가 "not main" 오류 | 2단계를 먼저 마쳐야 함 |
| 4단계 robocopy 오류 | 앱·VS Code·탐색기 창이 옛 폴더를 잡고 있는 것. 모두 닫고 다시 |
| 7단계 `No module named ...` | 6단계의 `setup_env.ps1`로 새로 설치 |
| `farmai_sync not found` | Google Drive 로그인 확인. `내 드라이브` 바로 아래에 `farmai_sync`가 있어야 함 |
| 무엇이든 확실하지 않을 때 | 옛 폴더를 지우지 말고, 연구실 PC의 Claude에게 "집 노트북 이전 상태 확인해줘"라고 하면 GitHub 기록으로 확인해 줌 |
