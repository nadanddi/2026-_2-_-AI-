---
name: no-exaggeration
description: Report exactly what was done — never present general knowledge as research, abstracts as full reads, or partial checks as exhaustive
metadata:
  type: feedback
---

State the real basis of every claim: "제 일반 지식", "초록만 확인", "전문 확인", "검색 결과 목록만" etc. Never call something a survey/조사/검증 when it wasn't.

**Why:** 2026-10-01 I described hypotheses from my own general knowledge as "공개된 재배 지식으로 예측", and answered fast; the user asked whether I had actually surveyed papers and said "과장하지 마".

**How to apply:** in reports, label provenance and coverage (n sources read, which databases searched, what was not covered). For literature work keep a search log so later sessions can exclude already-checked material. Related: [[check-catalog-before-new]].
