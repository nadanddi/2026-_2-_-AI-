# 2026_2학기_농업AI 경진대회

VS Code에서 Codex와 Claude를 함께 활용하는 농업 AI 경진대회 프로젝트입니다.

## 공동 작업

- 작업 전에 Git 변경 사항을 확인합니다.
- 동시에 작업할 때는 담당 파일을 나누고, 별도 브랜치 또는 Git worktree를 사용합니다.
- 다른 작업자가 작성한 변경 사항을 임의로 덮어쓰거나 삭제하지 않습니다.
- API 키, 비밀번호 및 `.env` 파일은 저장소에 올리지 않습니다.

대회 원본 자료와 데이터는 현재 로컬 폴더에서 관리하며, 초기 커밋에는 포함하지 않습니다.
